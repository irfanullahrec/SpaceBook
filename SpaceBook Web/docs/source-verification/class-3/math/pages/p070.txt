# Multiply a number by 0 and 1 || کسی عدد کو 0 اور 1 سے ضرب || یو عدد په 0 او 1 ضرب
p How many toffees are there in each jar. || ہر مرتبان میں کتنی ٹافیاں ہیں۔ || په هر لوښي کې څو ټافۍ دي.
p There are three empty jars of toffees. It means that there is no toffee in each of the jars. || ٹافیوں کے تین خالی مرتبان ہیں۔ اس کا مطلب ہے کہ کسی بھی مرتبان میں کوئی ٹافی نہیں ہے۔ || د ټافیو درې تش لوښي دي. مطلب دا چې په هېڅ لوښي کې ټافي نشته.
m The sum of toffees in three jars = 0 + 0 + 0 = 0
p or || یا || یا
m Multiply 0 by 3 = 0 × 3 = 0
p Similarly, || اسی طرح، || همداسې،
m Multiply 3 by 0 = 3 × 0 = 0
p Multiplying a number by 0 we always get 0. || کسی عدد کو 0 سے ضرب دینے پر ہمیشہ 0 ملتا ہے۔ || یو عدد په 0 کې د ضربولو سره تل 0 لاسته راځي.
p There are three baskets and in each basket there is only one apple. || تین ٹوکریاں ہیں اور ہر ٹوکری میں صرف ایک سیب ہے۔ || درې ټوکرۍ دي او په هره ټوکرۍ کې یوازې یوه مڼه ده.
m The total number of apples = 1 + 1 + 1
m Similarly 3 × 1 = 3
