q 4 | 13 Given the following data, find index number for 1973 taking 1963 as base year by (i) Laspeyre's formula (ii) Paasche's formula || 13 درج ذیل اعداد و شمار دیے گئے ہیں، 1963 کو بنیادی سال لے کر 1973 کے لیے اشاریہ عدد معلوم کریں (i) لاسپیئر کے فارمولے (ii) پاشے کے فارمولے سے || 13 لاندې معلومات ورکړل شوي دي، د 1963 د بنسټیز کال په نیولو سره د 1973 لپاره شاخص شمېره ومومئ د (i) Laspeyre فورمول (ii) Paasche فورمول په واسطه
sol (i) Laspeyre's index = Σp1q0/Σp0q0 x 100 = (10x50 + 8x10 + 4x5)/(2x50 + 3x10 + 4x5) x 100 = 600/150 x 100 = 400.00. (ii) Paasche's index = Σp1q1/Σp0q1 x 100 = (10x40 + 8x5 + 4x5)/(2x40 + 3x5 + 4x5) x 100 = 460/115 x 100 = 400.00. ## Laspeyre's (base-year weights) and Paasche's (current-year weights).
