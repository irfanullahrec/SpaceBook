p (ii) Chain base method || (ii) زنجیری بنیاد کا طریقہ || (ii) زنځیري بنسټ طریقه
p A method, in which the base period is not fixed but changes with the current period i.e. every preceding period is taken as the base period, is called chain base method. Index numbers computed by this method are called link relatives. || وہ طریقہ جس میں بنیادی مدت مقررہ نہیں ہوتی بلکہ موجودہ مدت کے ساتھ تبدیل ہوتی ہے یعنی ہر پچھلی مدت کو بنیادی مدت لیا جاتا ہے زنجیری بنیاد کا طریقہ کہلاتا ہے۔ اس طریقے سے حساب کیے گئے اشاریہ اعداد کڑی اضافتیں کہلاتے ہیں۔ || هغه طریقه چې په کې بنسټیزه دوره ټاکلې نه وي بلکې د اوسنۍ دورې سره بدلېږي یعنې هره تېره دوره د بنسټیزې دورې په توګه اخیستل کېږي زنځیري بنسټ طریقه بلل کېږي. پدې طریقه محاسبه شوې شاخص شمېرې پیوندي نسبتونه بلل کېږي.
