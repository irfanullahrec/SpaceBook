(b) د لاندې معلوماتو 9, 11, 14, 18, 21, 23 او 27 لپاره د اوسط شاوخوا لومړي څلور مومنټونه محاسبه کړئ، (i) په مستقیمه طریقه، (ii) په لنډه طریقه.
sol (a) Moments are the mean values of the powers of the deviations of the observations from a fixed value: the r-th moment about the mean is m_r = Σ(x - mean)^r/n (central or mean moments), about the origin m'_r = Σx^r/n (raw moments), and about any value A, m'_r = Σ(x - A)^r/n. m1 = 0 and m2 = variance. (b) n = 7, mean = 123/7 = 17.5714. Direct method: m1 = 0, m2 = 37.1020, m3 = 11.3528, m4 = 2333.5402. Shortcut method (assumed mean A = 18, d = x - 18: Σd = -3, Σd² = 261, Σd³ = -255, Σd⁴ = 16485): raw moments about 18 are -0.4286, 37.2857, -36.4286, 2355.0000, and converting them gives m1 = 0, m2 = 37.1020, m3 = 11.3528, m4 = 2333.5402, the same as the direct method. ## Direct and shortcut methods agree.

(c) Evaluate the Karl Pearson measure of skewness for the data given below: 2000, 2030, 2100, 2100, 2200, 2300 || 23 (الف) تشاکل اور کجی میں فرق کریں۔ مثبت اور منفی کجی کی بھی تعریف کریں۔ (ب) درج ذیل اعداد و شمار کے لیے باؤلے کی کجی کا پیمانہ معلوم کریں: 33, 35, 44, 34, 41, 45, 39, 46, 36, 47۔ (ج) نیچے دیے گئے اعداد و شمار کے لیے کارل پیئرسن کی کجی کا پیمانہ معلوم کریں: 2000, 2030, 2100, 2100, 2200, 2300 || 23 (a) په تناسب او کوړوالي کې توپیر وکړئ. مثبت او منفي کوړوالی هم تعریف کړئ. (b) د لاندې معلوماتو لپاره د Bowley د کوړوالي اندازه ومومئ: 33, 35, 44, 34, 41, 45, 39, 46, 36, 47. sol (a) A distribution is symmetrical when the values are spread equally on both sides of the centre (mean = median = mode); skewness is the lack of symmetry. Positive skewness: the longer tail is to the right (mean > median > mode, Sk > 0); negative skewness: the longer tail is to the left (mean < median < mode, Sk < 0). (b) Ordered data: 33, 34, 35, 36, 39, 41, 44, 45, 46, 47; Q1 = 2.75th value = 34.75, Q2 = 5.5th value = 40.00, Q3 = 8.25th value = 45.25; Bowley's Sk = (Q3 + Q1 - 2Q2)/(Q3 - Q1) = (45.25 + 34.75 - 80.00)/(45.25 - 34.75) = 0.000, so the distribution is symmetrical. (c) Mean = 2121.67, mode = 2100 (it occurs twice), S.D = 101.72; Karl Pearson's Sk = (mean - mode)/S.D = 0.213, a slight positive skewness. ## Bowley and Karl Pearson's coefficients.
q 3 | 24 From the following frequency table Compute Bowley's coefficient of skewness and interpret the result. || 24 درج ذیل تعدد جدول سے باؤلے کی کجی کا عددی سر حساب کریں اور نتیجے کی تشریح کریں۔ || 24 له لاندې فریکونسي جدول څخه د Bowley د کوړوالي ضریب محاسبه کړئ او پایله تفسیر کړئ.
sol n = 3044; cumulative frequencies 26, 227, 900, 1901, 2640, 2950, 3030, 3043, 3044. Q1 = (n+1)/4 = 761.25-th value = 12; Q2 = (n+1)/2 = 1522.5-th value = 13; Q3 = 3(n+1)/4 = 2283.75-th value = 14. Bowley's coefficient = (Q3 + Q1 - 2Q2)/(Q3 - Q1) = (14 + 12 - 26)/(14 - 12) = 0/2 = 0.000. The coefficient is zero (or nearly so), so the middle half of the distribution is symmetrical. ## Bowley's coefficient of skewness.
