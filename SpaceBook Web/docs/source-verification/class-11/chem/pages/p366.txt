## Example 12.3 || مثال 12.3 || بېلګه 12.3
p Let us balance the following equation by oxidation number method, by using the above mentioned steps. || آئیے مندرجہ بالا مراحل استعمال کر کے درج ذیل مساوات کو تکسیدی عدد کے طریقے سے متوازن کریں۔ || راځئ لاندې معادله د اکسیډیشن شمېرې په طریقه، د پورتنیو ګامونو په کارولو سره انډول کړو.
p (i) Zn + HNO₃ → Zn(NO₃)₂ + NO + H₂O || (i) Zn + HNO₃ → Zn(NO₃)₂ + NO + H₂O || (i) Zn + HNO₃ → Zn(NO₃)₂ + NO + H₂O
p (ii) Oxidation number of Zn is 0, oxidation number of Zn in Zn(NO₃)₂ is +2. Oxidation numbers of Zn increases from 0 to +2, so it is oxidized and is a reducing agent. Oxidation number of N decreases from +5 in HNO₃ to +2 in NO so it is reduced and acts as an oxidizing agent. || (ii) Zn کا تکسیدی عدد 0 ہے، Zn(NO₃)₂ میں Zn کا تکسیدی عدد +2 ہے۔ Zn کا تکسیدی عدد 0 سے +2 تک بڑھتا ہے اس لیے یہ تکسید شدہ اور تخفیفی ایجنٹ ہے۔ N کا تکسیدی عدد HNO₃ میں +5 سے NO میں +2 تک کم ہوتا ہے اس لیے یہ تخفیف شدہ ہے اور تکسیدی ایجنٹ کے طور پر کام کرتا ہے۔ || (ii) د Zn د اکسیډیشن شمېره 0 ده، په Zn(NO₃)₂ کې د Zn د اکسیډیشن شمېره +2 ده. د Zn د اکسیډیشن شمېره له 0 څخه +2 ته زیاتېږي نو دا اکسیډیز شوی او ریډیوسینګ اجنټ دی. د N د اکسیډیشن شمېره په HNO₃ کې له +5 څخه په NO کې +2 ته کمېږي نو دا ریډیوس شوی او د اکسیډېزنګ اجنټ په توګه عمل کوي.

eq \text{b)}\ \mathrm{HN^{+5}O_3+3e^-\longrightarrow N^{2+}O}\quad\text{(N reduced)}
p (v) Multiply equation (a) by 3 and (b) by 2, so that the number of electrons gained becomes equal to the number of electrons lost.
