## 2.5.1 Principle Quantum Number (n) || 2.5.1 اصل کوانٹم عدد (n) || 2.5.1 اصلي کوانتمي شمېره (n)
p This quantum number denotes the principal shell to which the electron belongs. This quantum number represents the main energy level or shell in which the electron is present. It represents the average distance of the electron from the nucleus. The principal quantum number ‘n’ can have non-zero, positive, integral values n = 1, 2, 3... || یہ کوانٹم عدد اس اصل خول کو ظاہر کرتا ہے جس سے الیکٹران تعلق رکھتا ہے۔ یہ توانائی کی بنیادی سطح یا خول ظاہر کرتا ہے جس میں الیکٹران موجود ہوتا ہے۔ یہ مرکزے سے الیکٹران کا اوسط فاصلہ ظاہر کرتا ہے۔ اصل کوانٹم عدد ‘n’ کی غیر صفر، مثبت، صحیح عددی قدریں n = 1, 2, 3... ہو سکتی ہیں۔ || دا کوانتمي شمېره هغه اصلي پوښ ښيي چې الکترون ورپورې تړلی وي. دا د انرژۍ اساسي کچه یا پوښ ښيي چې الکترون پکې موجود وي. دا له هستې څخه د الکترون منځنی واټن ښيي. اصلي کوانتمي شمېره ‘n’ ناصفر، مثبت، بشپړ عددي ارزښتونه n = 1, 2, 3... لرلای شي.
