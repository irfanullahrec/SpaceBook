There is no home where there is not a lack of livelihood. In nobody’s state is there any betterment at all. Now for the name of Agra there is no comfort; before a cowrie the paths have been shut thus. || هغه کوم زړه دی چې فرسودګي نه لري هغه کور نشته چې د روزۍ نابودي پکې نه وي د چا په حال کې هیڅکله بهبود نشته اوس د اګرې نوم ته آسودګي نشته د کوډۍ په وړاندې لارې داسې بندې شوې
