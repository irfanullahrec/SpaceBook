## d. Language Processor || د۔ لینگوئج پراسیسر || د. د ژبې پروسیسر
p Language processor or translator is a type of system software that translates a source program (other than machine language) into object program (Machine language). || لینگوئج پراسیسر یا مترجم سسٹم سافٹ ویئر کی ایک قسم ہے جو سورس پروگرام (مشین زبان کے علاوہ) کو آبجیکٹ پروگرام (مشین زبان) میں ترجمہ کرتا ہے۔ || د ژبې پروسیسر یا ژباړن د سیسټم سافټویر یو ډول دی چې یو سرچینه پروګرام (له ماشین ژبې پرته) د هدف پروګرام (ماشین ژبه) ته ژباړي.
p There are three types of language processors. || لینگوئج پراسیسرز کی تین اقسام ہیں۔ || د ژبې د پروسیسرونو درې ډولونه دي.
## i. Interpreter || i۔ انٹرپریٹر || i. تفسیرکوونکی (Interpreter)
p A language processor that translates a high level language program line-by-line (statement-by-statement) and carries out the specified actions in sequence is called Interpreter. It translates and runs the program at the same time. It converts one program statement into machine language, executes it, and then proceeds to the next statement. Examples of languages that use interpreters include BASIC, LISP, Smalltalk, PHP and PERL. || وہ لینگوئج پراسیسر جو اعلیٰ سطح کی زبان کے پروگرام کو سطر بہ سطر (بیان بہ بیان) ترجمہ کرتا ہے اور مخصوص عمل ترتیب سے انجام دیتا ہے انٹرپریٹر کہلاتا ہے۔ یہ ایک ہی وقت میں پروگرام کا ترجمہ کرتا اور چلاتا ہے۔ یہ پروگرام کے ایک بیان کو مشین زبان میں بدلتا ہے، اسے چلاتا ہے اور پھر اگلے بیان کی طرف بڑھتا ہے۔ انٹرپریٹر استعمال کرنے والی زبانوں کی مثالوں میں بیسک، لسپ، اسمال ٹاک، پی ایچ پی اور پرل شامل ہیں۔ || هغه د ژبې پروسیسر چې یو لوړې کچې ژبې پروګرام کرښه په کرښه (بیان په بیان) ژباړي او ټاکل شوي عملونه په ترتیب ترسره کوي تفسیرکوونکی (Interpreter) بلل کېږي. دا په یو وخت کې پروګرام ژباړي او چلوي. دا د پروګرام یو بیان ماشین ژبې ته بدلوي، پلی یې کوي او بیا بل بیان ته ځي. د هغو ژبو بېلګې چې انټرپرېټر کاروي BASIC، LISP، Smalltalk، PHP او PERL دي.
## ii. Compiler || ii۔ کمپائلر || ii. ترتیبوونکی (Compiler)
p Compiler is a program that translates source code (written by programmer in a high-level language e.g., C++) into a set of machine-language instructions that can be understood by a digital computer’s CPU. Compilers are very large programs, with error-checking and other abilities. Examples of languages that use compilers include COBOL, FORTRAN, C/C++, JAVA, etc. || کمپائلر ایک پروگرام ہے جو سورس کوڈ (جو پروگرامر نے اعلیٰ سطح کی زبان، مثلاً سی++ میں لکھا ہو) کو مشین زبان کی ہدایات کے ایسے مجموعے میں ترجمہ کرتا ہے جسے ڈیجیٹل کمپیوٹر کا سی پی یو سمجھ سکے۔ کمپائلرز بہت بڑے پروگرام ہیں جن میں غلطیاں جانچنے اور دیگر صلاحیتیں ہوتی ہیں۔ کمپائلر استعمال کرنے والی زبانوں کی مثالوں میں کوبول، فورٹران، سی/سی++، جاوا وغیرہ شامل ہیں۔ || کمپایلر یو پروګرام دی چې سرچینه کوډ (چې پروګرامر په لوړه کچه ژبه، لکه C++ کې لیکلی) د ماشین ژبې د لارښوونو هغه ټولګې ته ژباړي چې د ډیجیټل کمپیوټر CPU پرې پوهېدای شي. کمپایلرونه ډیر لوی پروګرامونه دي چې د غلطیو کتلو او نورې وړتیاوې لري. د هغو ژبو بېلګې چې کمپایلر کاروي COBOL، FORTRAN، C/C++، JAVA او نور دي.
## iii. Assembler || iii۔ اسمبلر || iii. راټولوونکی (Assembler)
p An assembler is a translator which is used to convert an assembly language program into a machine-language program for later execution. Assembly language is also called a Symbolic language. || اسمبلر ایک مترجم ہے جو اسمبلی زبان کے پروگرام کو بعد میں چلانے کے لیے مشین زبان کے پروگرام میں بدلنے کے لیے استعمال ہوتا ہے۔ اسمبلی زبان کو علامتی زبان بھی کہا جاتا ہے۔ || اسمبلر یو ژباړن دی چې د اسمبلي ژبې پروګرام وروسته د چلولو لپاره د ماشین ژبې پروګرام ته بدلولو لپاره کارول کېږي. اسمبلي ژبې ته سمبولیکه ژبه هم ویل کېږي.
## 1.2.3 Types of Application Software || ۱.۲.۳ ایپلیکیشن سافٹ ویئر کی اقسام || ۱.۲.۳ د اپلیکېشن سافټویر ډولونه
p Application software includes a variety of programs that can be subdivided into general-purpose and customized categories. || ایپلیکیشن سافٹ ویئر میں مختلف قسم کے پروگرام شامل ہیں جنہیں عمومی مقصد اور حسبِ ضرورت زمروں میں تقسیم کیا جا سکتا ہے۔ || اپلیکېشن سافټویر مختلف ډوله پروګرامونه لري چې په عمومي موخه او دودیز ډلو وېشل کېدای شي.
