## Class C || کلاس سی || C ټولګی
p Class C is used for the small networks. The binary address for the class C starts with 110. The range addresses in the class C is between 192 to 223 and the default subnet mask for this class is 255.255.255. Its Network part consists of 3 octets and Host part consists of 1 octet. An example of the Class C IP address is 210.190.100.150. || کلاس سی چھوٹے نیٹ ورکس کے لیے استعمال ہوتی ہے۔ کلاس سی کا بائنری ایڈریس ۱۱۰ سے شروع ہوتا ہے۔ کلاس سی میں ایڈریسز کی حد ۱۹۲ سے ۲۲۳ کے درمیان ہے اور اس کلاس کا طے شدہ سب نیٹ ماسک ۲۵۵.۲۵۵.۲۵۵ ہے۔ اس کا نیٹ ورک حصہ ۳ آکٹیٹس اور ہوسٹ حصہ ۱ آکٹیٹ پر مشتمل ہے۔ کلاس سی آئی پی ایڈریس کی ایک مثال ۲۱۰.۱۹۰.۱۰۰.۱۵۰ ہے۔ || C ټولګی د کوچنیو شبکو لپاره کارول کېږي. د C ټولګي دوتایي پته له ۱۱۰ نه پیلېږي. په C ټولګي کې د پتو کچه له ۱۹۲ نه ۲۲۳ ترمنځ ده او د دې ټولګي ډیفالټ فرعي شبکې ماسک ۲۵۵.۲۵۵.۲۵۵ دی. د شبکې برخه یې ۳ اکټېټونه او د کوربه برخه ۱ اکټېټ لري. د C ټولګي IP پتې یوه بېلګه ۲۱۰.۱۹۰.۱۰۰.۱۵۰ ده.

## Class D || کلاس ڈی || D ټولګی
p Class D is for special use for multicasting. The binary addresses for the class D starts with 1110 and the IP address ranges from 224 to 239. An example of the class D IP address is 230.150.110.11 || کلاس ڈی ملٹی کاسٹنگ کے خصوصی استعمال کے لیے ہے۔ کلاس ڈی کے بائنری ایڈریسز ۱۱۱۰ سے شروع ہوتے ہیں اور آئی پی ایڈریس کی حد ۲۲۴ سے ۲۳۹ ہے۔ کلاس ڈی آئی پی ایڈریس کی ایک مثال ۲۳۰.۱۵۰.۱۱۰.۱۱ ہے۔ || D ټولګی د څو غوښتنې (ملټي کاسټینګ) ځانګړي کارونې لپاره دی. د D ټولګي دوتایي پتې له ۱۱۱۰ نه پیلېږي او د IP پتې کچه له ۲۲۴ نه ۲۳۹ ده. د D ټولګي IP پتې یوه بېلګه ۲۳۰.۱۵۰.۱۱۰.۱۱ ده.
## Class E || کلاس ای || E ټولګی
p Class E is under experimental research. The binary address can start with 111 and the decimal can be in range from 240 to 255. An example of the class E IP address is 245.101.110.110 || کلاس ای تجرباتی تحقیق کے تحت ہے۔ بائنری ایڈریس ۱۱۱ سے شروع ہو سکتا ہے اور اعشاری ۲۴۰ سے ۲۵۵ کی حد میں ہو سکتا ہے۔ کلاس ای آئی پی ایڈریس کی ایک مثال ۲۴۵.۱۰۱.۱۱۰.۱۱۰ ہے۔ || E ټولګی د تجربوي څېړنې لاندې دی. دوتایي پته له ۱۱۱ نه پیلېدای شي او لسیزه کچه له ۲۴۰ نه ۲۵۵ کېدای شي. د E ټولګي IP پتې یوه بېلګه ۲۴۵.۱۰۱.۱۱۰.۱۱۰ ده.
