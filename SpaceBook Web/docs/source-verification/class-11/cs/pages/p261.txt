## 8.1.3 Creating and Saving an Access Database || ۸.۱.۳ ایکسیس ڈیٹا بیس بنانا اور محفوظ کرنا || ۸.۱.۳ د Access ډېټابېس جوړول او ساتل
p The following steps are used to create and save a new database. || نیا ڈیٹا بیس بنانے اور محفوظ کرنے کے لیے درج ذیل اقدامات استعمال ہوتے ہیں۔ || د نوي ډېټابېس د جوړولو او ساتلو لپاره لاندې ګامونه کارول کېږي.
p First step in creating an Access database is to create a blank database file. This is done from the Getting Started Window when user runs the Access program. As shown in Figure 8.1. || ایکسیس ڈیٹا بیس بنانے کا پہلا قدم خالی ڈیٹا بیس فائل بنانا ہے۔ یہ اس وقت آغاز ونڈو سے کیا جاتا ہے جب صارف ایکسیس پروگرام چلاتا ہے۔ جیسا کہ شکل ۸.۱ میں دکھایا گیا ہے۔ || د Access ډېټابېس د جوړولو لومړی ګام تش ډېټابېس فایل جوړول دي. دا د پیل کړکۍ نه ترسره کېږي کله چې کاروونکی د Access پروګرام چالوي. لکه څنګه چې ۸.۱ انځور کې ښودل شوی.
p Click the Blank Database icon to bring the Blank Database side bar on the right side of the screen as shown in Figure 8.1. || خالی ڈیٹا بیس آئیکن پر کلک کریں تاکہ اسکرین کے دائیں طرف خالی ڈیٹا بیس سائیڈ بار آ جائے جیسا کہ شکل ۸.۱ میں دکھایا گیا ہے۔ || د تش ډېټابېس انځورن کلیک کړئ ترڅو د سکرین په ښي خوا کې د تش ډېټابېس څنګ پټه راشي لکه څنګه چې ۸.۱ انځور کې ښودل شوی.
p Enter a file name for database file in File Name bar. For example Student. || فائل نیم بار میں ڈیٹا بیس فائل کے لیے فائل نام درج کریں۔ مثلاً اسٹوڈنٹ۔ || د فایل نوم پټه کې د ډېټابېس فایل لپاره فایل نوم ولیکئ. د بېلګې په توګه Student.
p Click the folder icon and browse for selecting a location for saving the database. || فولڈر آئیکن پر کلک کریں اور ڈیٹا بیس محفوظ کرنے کے لیے جگہ منتخب کرنے کے لیے براؤز کریں۔ || د پوښۍ انځورن کلیک کړئ او د ډېټابېس د ساتلو لپاره د ځای د ټاکلو لپاره وکړئ.
p Click the Create button to create and save the database. The database the user just created will open for work on. || ڈیٹا بیس بنانے اور محفوظ کرنے کے لیے تخلیق بٹن پر کلک کریں۔ صارف کا ابھی بنایا ہوا ڈیٹا بیس کام کے لیے کھل جائے گا۔ || د ډېټابېس د جوړولو او ساتلو لپاره د جوړولو تڼۍ کلیک کړئ. هغه ډېټابېس چې کاروونکي اوس جوړ کړ د کار لپاره به پرانیستل شي.

## 8.1.4 Database Objects || ۸.۱.۴ ڈیٹا بیس آبجیکٹس || ۸.۱.۴ د ډېټابېس څیزونه
p The following are the main objects of Access database. || درج ذیل ایکسیس ڈیٹا بیس کے بنیادی آبجیکٹس ہیں۔ || لاندې د Access ډېټابېس اصلي څیزونه دي.
p Tables || ٹیبلز || جدولونه
p Queries || کوئریز || پوښتنې
p Forms || فارمز || فورمونه
p Reports || رپورٹس || راپورونه
p Tables: In Access 2007, data is stored in tables. A table is a set of columns and rows, with each column referred to as a field and each row of a table is referred to as a record. || ٹیبلز: ایکسیس ۲۰۰۷ میں ڈیٹا ٹیبلز میں محفوظ ہوتا ہے۔ ٹیبل کالموں اور قطاروں کا مجموعہ ہے، جس میں ہر کالم کو فیلڈ اور ٹیبل کی ہر قطار کو ریکارڈ کہا جاتا ہے۔ || جدولونه: په Access 2007 کې ډېټا په جدولونو کې ساتل کېږي. جدول د ستونونو او قطارونو یوه ټولګه ده، چې هر ستون ته ساحه او د جدول هر قطار ته ثبت ویل کېږي.
p Queries: Queries are used to retrieve specific data from database and to answer questions about the data. For example, a user can use a query to find the names of the employees in the database who are in grade 18. || کوئریز: کوئریز ڈیٹا بیس سے مخصوص ڈیٹا حاصل کرنے اور ڈیٹا کے بارے میں سوالات کے جواب دینے کے لیے استعمال ہوتی ہیں۔ مثلاً صارف کوئری استعمال کر کے ڈیٹا بیس میں ان ملازمین کے نام تلاش کر سکتا ہے جو گریڈ ۱۸ میں ہیں۔ || پوښتنې: پوښتنې له ډېټابېس نه ځانګړې ډېټا ترلاسه کولو او د ډېټا په اړه پوښتنو ځواب ورکولو لپاره کارول کېږي. د بېلګې په توګه کاروونکی کولای شي د پوښتنې په کارولو سره په ډېټابېس کې د هغو کارکوونکو نومونه ومومي چې په ۱۸ درجه کې دي.
