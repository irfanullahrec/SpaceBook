## SUMMARY || خلاصہ || لنډیز
p Data is a collection of facts, figures, numbers or ideas that can be organized and processed. || ڈیٹا حقائق، اعداد و شمار، نمبروں یا خیالات کا مجموعہ ہے جسے منظم اور پراسیس کیا جا سکتا ہے۔ || ډېټا د حقایقو، شمېرو، عددونو یا مفکورو ټولګه ده چې منظم او پروسس کېدای شي.
p When facts, figures or numbers (data) are processed and converted into meaningful form that can be used for decision making or any other useful activity, it is called Information. || جب حقائق، اعداد و شمار یا نمبرز (ڈیٹا) کو پراسیس کر کے بامعنی شکل میں تبدیل کیا جائے جو فیصلہ سازی یا کسی اور مفید سرگرمی کے لیے استعمال ہو سکے تو اسے معلومات کہتے ہیں۔ || کله چې حقایق، شمېرې یا عددونه (ډېټا) پروسس شي او مانادار بڼې ته بدل شي چې د پرېکړې کولو یا کوم بل ګټور فعالیت لپاره کارېدای شي، نو دې ته معلومات ویل کېږي.
p File Management system also known as Conventional file system or simply file system is a method of storing and organizing collection of data in the form of files on the secondary storage devices. || فائل مینجمنٹ سسٹم، جسے روایتی فائل سسٹم یا محض فائل سسٹم بھی کہتے ہیں، ثانوی ذخیرہ آلات پر فائلوں کی شکل میں ڈیٹا کے مجموعے کو ذخیرہ اور منظم کرنے کا ایک طریقہ ہے۔ || د فایل مدیریت سیسټم، چې دودیز فایل سیسټم یا یوازې فایل سیسټم هم ورته ویل کېږي، په ثانوي ذخیره وسایلو کې د فایلونو په بڼه د ډېټا د ټولګې د ساتلو او منظمولو یوه طریقه ده.
p Database is a shared collection of logically related data (and a description of this data i.e. metadata), designed to meet the information needs of multiple users in an organization. || ڈیٹا بیس منطقی طور پر متعلقہ ڈیٹا (اور اس ڈیٹا کی تفصیل یعنی میٹا ڈیٹا) کا مشترکہ مجموعہ ہے جو کسی ادارے میں متعدد صارفین کی معلوماتی ضروریات پوری کرنے کے لیے بنایا گیا ہو۔ || ډېټابېس د منطقي اړوندې ډېټا (او د دې ډېټا تشریح یعنې میټا ډېټا) ګډه ټولګه ده، چې په یوه اداره کې د ډیرو کاروونکو د معلوماتي اړتیاوو د پوره کولو لپاره ډیزاین شوې ده.
p A database management system (DBMS) is a set of programs that allow users to create a database, edit and update data in database files, store and retrieve data from those database files. || ڈیٹا بیس مینجمنٹ سسٹم (ڈی بی ایم ایس) پروگراموں کا ایک مجموعہ ہے جو صارفین کو ڈیٹا بیس بنانے، ڈیٹا بیس فائلوں میں ڈیٹا میں ترمیم اور اپ ڈیٹ کرنے اور ان فائلوں سے ڈیٹا محفوظ اور حاصل کرنے کی اجازت دیتا ہے۔ || د ډېټابېس مدیریت سیسټم (DBMS) د پروګرامونو یوه ټولګه ده چې کاروونکو ته اجازه ورکوي ډېټابېس جوړ کړي، په ډېټابېس فایلونو کې ډېټا سمه او تازه کړي، له هغو ډېټابېس فایلونو نه ډېټا ذخیره او ترلاسه کړي.
p A database model is a set of rules or specifications which state that how data can be stored, organized and manipulated in a database system. || ڈیٹا بیس ماڈل قواعد یا وضاحتوں کا مجموعہ ہے جو بیان کرتا ہے کہ ڈیٹا بیس سسٹم میں ڈیٹا کو کیسے ذخیرہ، منظم اور اس میں ترمیم کی جا سکتی ہے۔ || د ډېټابېس ماډل د قواعدو یا مشخصاتو یوه ټولګه ده چې بیانوي چې په ډېټابېس سیسټم کې ډېټا څنګه ذخیره، منظم او کار ترې اخیستل کېدای شي.
p Hierarchal Database Model is a type of model in which data is organized into a tree-like structure. || ہائیرارکل ڈیٹا بیس ماڈل ایسا ماڈل ہے جس میں ڈیٹا درخت نما ساخت میں منظم ہوتا ہے۔ || درجه بندي ډېټابېس ماډل یو ډول ماډل دی چې په هغه کې ډېټا د ونې غوندې جوړښت کې منظمه کېږي.
p A network database is similar to a hierarchical database except that each child can have more than one parent record. || نیٹ ورک ڈیٹا بیس ہائیرارکیکل ڈیٹا بیس سے مشابہ ہے سوائے اس کے کہ ہر بچے کے ایک سے زیادہ والدین ریکارڈ ہو سکتے ہیں۔ || شبکه ډېټابېس د درجه بندي ډېټابېس غوندې ده پرته له دې چې هر ماشوم کېدای شي له یوه څخه ډیر د مور ثبتونه ولري.
p Relational Database Model uses a collection of tables to represent both data and the relationship among those data. Each table has multiple columns and each column has a unique name. || ریلیشنل ڈیٹا بیس ماڈل ڈیٹا اور ان ڈیٹا کے درمیان تعلق دونوں کو ظاہر کرنے کے لیے ٹیبلز کا مجموعہ استعمال کرتا ہے۔ ہر ٹیبل کے متعدد کالم ہوتے ہیں اور ہر کالم کا منفرد نام ہوتا ہے۔ || اړونده ډېټابېس ماډل د جدولونو ټولګه کاروي ترڅو ډېټا او د دغو ډېټا ترمنځ اړیکه دواړه وښیي. هر جدول څو ستونونه لري او هر ستون ځانګړی نوم لري.
p Object-Oriented database Model is a database model in which information is represented in the form of objects as used in object-oriented programming. || آبجیکٹ اورینٹڈ ڈیٹا بیس ماڈل ایسا ڈیٹا بیس ماڈل ہے جس میں معلومات آبجیکٹس کی شکل میں ظاہر ہوتی ہیں جیسا کہ آبجیکٹ اورینٹڈ پروگرامنگ میں استعمال ہوتا ہے۔ || څیز پر بنسټ ډېټابېس ماډل یو ډېټابېس ماډل دی چې په هغه کې معلومات د څیزونو په بڼه ښودل کېږي لکه څنګه چې په څیز پر بنسټ پروګرامنګ کې کارول کېږي.
p Object relational database model add new object storage capabilities to the relational systems at the core of modern information systems. || آبجیکٹ ریلیشنل ڈیٹا بیس ماڈل جدید معلوماتی نظاموں کے مرکز میں موجود ریلیشنل سسٹمز میں نئی آبجیکٹ ذخیرہ صلاحیتیں شامل کرتا ہے۔ || څیز اړونده ډېټابېس ماډل د مدرنو معلوماتي سیسټمونو په مرکز کې اړوندو سیسټمونو ته نوې څیز ذخیرې وړتیاوې زیاتوي.
p SQL (Structured Query Language) is the standard language for relational database systems. || ایس کیو ایل (سٹرکچرڈ کوئری لینگویج) ریلیشنل ڈیٹا بیس سسٹمز کے لیے معیاری زبان ہے۔ || SQL (جوړښت لرونکې پوښتنې ژبه) د اړوندو ډېټابېس سیسټمونو لپاره معیاري ژبه ده.
