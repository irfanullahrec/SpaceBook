qp i | What is the function of ALU in the computer? || کمپیوٹر میں اے ایل یو کا کیا کام ہے؟ || په کمپیوټر کې د ALU څه دنده ده؟
sol Model answer: The ALU (Arithmetic Logic Unit) performs all arithmetic operations (addition, subtraction, multiplication, division) and logical operations (comparisons such as equal to, greater than, less than, and AND, OR, NOT) on the data given to it. It takes the data from registers and memory, and the result is sent back to a register or memory. ## Unit 3 ALU.
qp ii | What is the function of control unit in the computer? || کمپیوٹر میں کنٹرول یونٹ کا کیا کام ہے؟ || په کمپیوټر کې د کنټرول واحد څه دنده ده؟
sol Model answer: The control unit (CU) directs and coordinates the work of all parts of the computer. It fetches instructions from memory, decodes them, and sends control signals to the ALU, memory and input/output devices so that each instruction is carried out in the right order and at the right time. It does not process data itself. ## Unit 3 control unit.
qp iii | What is a microprocessor? || مائیکرو پراسیسر کیا ہے؟ || مایکروپروسیسر څه دی؟
sol Model answer: A microprocessor is a complete CPU built on a single integrated circuit (chip). It contains the ALU, the control unit and registers, and sometimes cache, and it carries out the instructions of a program. Examples: Intel Core i5, AMD Ryzen. ## Unit 3 introduction.
qp iv | Define system bus. || سسٹم بس کی تعریف کریں۔ || سیسټم بس تعریف کړئ.
sol Model answer: The system bus is a set of parallel wires on the motherboard that connects the CPU with main memory and input/output devices and carries data, addresses and control signals between them. It consists of the data bus, the address bus and the control bus. ## Unit 3 system bus.
qp v | Write short note on Memory Buffer Register (MBR). || میموری بفر رجسٹر (ایم بی آر) پر مختصر نوٹ لکھیں۔ || د حافظې د بفر رجستر (MBR) لنډ نوټ ولیکئ.
sol Model answer: The Memory Buffer Register (MBR), also called memory data register, is a CPU register that temporarily holds the data or instruction that has just been read from memory or is about to be written to memory. All data going between the CPU and main memory passes through it; the Memory Address Register holds the address of the location involved. ## Unit 3 registers.
qp vi | What is CPU operation? || سی پی یو کا عمل کیا ہے؟ || د CPU عمل څه دی؟
sol Model answer: CPU operation is the work the CPU does to run a program: it repeatedly fetches an instruction from memory, decodes it to find out what is to be done, executes it with the ALU or other units, and stores the result. This fetch-decode-execute process is repeated for every instruction. ## Unit 3 instruction cycle.
qp vii | What is meant by an instruction? || ہدایت سے کیا مراد ہے؟ || د لارښوونې نه څه مراد دی؟
sol Model answer: An instruction is a single command given to the CPU in machine language that tells it which operation to perform and on which data, for example to add two numbers or move data from memory to a register. A program is a sequence of instructions. ## Unit 3 instructions.
qp viii | Differentiate between op-code and operand? || او پی کوڈ اور آپرینڈ میں فرق کریں۔ || د op-code او عملوند ترمنځ توپیر وکړئ؟
sol Model answer: The op-code (operation code) is the part of the instruction that tells the CPU which operation to perform (for example ADD, MOV, JMP). The operand is the part that gives the data, or the address of the data, on which the operation is to be done (a register, a memory address or a value). An instruction always has an op-code and zero or more operands. ## Unit 3 instruction format.
qp ix | Show computer instruction format with the help of a diagram and label its parts. || ایک خاکے کی مدد سے کمپیوٹر ہدایت کی شکل دکھائیں اور اس کے حصوں پر لیبل لگائیں۔ || د یو ډیاګرام په مرسته د کمپیوټر د لارښوونې بڼه وښيئ او د هغې برخو ته لیبل ورکړئ.
sol Model answer: Instruction format: a rectangular box divided into two fields placed side by side: [ OP-CODE | OPERAND(S) / ADDRESS FIELD ]. The op-code field (for example 7 bits, bit 0 to 7) names the operation; the operand field holds the address or value of the data. Formats: zero-address (op-code only, e.g. HALT), one-address (op-code + one operand, e.g. LDA, JMP) and two-address (op-code + two operands, e.g. MOV). ## The diagram has to be drawn from this description.
qp x | Differentiate between CISC and RISC processor architecture. || سی آئی ایس سی اور آر آئی ایس سی پراسیسر ڈھانچے میں فرق کریں۔ || د CISC او RISC پروسیسر جوړښت ترمنځ توپیر وکړئ.
sol Model answer: CISC (Complex Instruction Set Computer) has a large set of complex instructions, each doing several low-level jobs, needs fewer instructions per program but many clock cycles per instruction, uses variable-length instructions and little pipelining (Intel x86). RISC (Reduced Instruction Set Computer) has a small set of simple instructions, each executed in about one clock cycle, uses fixed-length instructions, many registers and pipelining, and needs more instructions per program (ARM, used in mobile phones). ## Unit 3 processor architectures.

qp i | What is CPU? Describe basic components of CPU in detail. || سی پی یو کیا ہے؟ سی پی یو کے بنیادی اجزاء تفصیل سے بیان کریں۔ || CPU څه دی؟ د CPU بنسټیز اجزا په تفصیل سره بیان کړئ.
sol Model answer: The CPU (central processing unit) is the brain of the computer; it executes program instructions and controls the other parts. Basic components: (1) Arithmetic Logic Unit (ALU): does arithmetic and logical operations. (2) Control Unit (CU): fetches and decodes instructions and controls and coordinates all parts. (3) Registers: very fast storage locations in the CPU that hold the data, instructions and addresses currently in use. These parts are joined by internal buses and connected to memory and devices by the system bus. ## Unit 3 CPU and its components.
qp ii | What is a register? Explain different types of registers. || رجسٹر کیا ہے؟ رجسٹرز کی مختلف اقسام کی وضاحت کریں۔ || رجستر څه دی؟ د رجسترونو مختلف ډولونه تشریح کړئ.
sol Model answer: A register is a small, very fast memory location inside the CPU that holds data, instructions or addresses temporarily. Types: Accumulator/general registers: AX (accumulator, arithmetic results), BX (base register, holds addresses and has special addressing abilities), CX (counter register, used in loops and counting), DX (data register, used in multiply/divide and I/O). Special-purpose registers: Program Counter (address of the next instruction), Instruction Register (the instruction being executed), Memory Address Register (address of the memory location), Memory Buffer Register (data going to or coming from memory), Stack Pointer and Status/Flag register. ## Unit 3 registers.
qp iii | What is a system bus? Explain different types of buses used in computers. || سسٹم بس کیا ہے؟ کمپیوٹرز میں استعمال ہونے والی بسوں کی مختلف اقسام کی وضاحت کریں۔ || سیسټم بس څه دی؟ په کمپیوټرونو کې کارېدونکي بسونو مختلف ډولونه تشریح کړئ.
sol Model answer: A system bus is a group of parallel wires that connects the CPU, memory and I/O devices and carries signals between them. Types: (1) Data bus: carries the data in both directions (its width, for example 32 or 64 bits, gives the word size). (2) Address bus: carries the address of the memory location or device from the CPU; it is one-directional and its width decides how much memory can be addressed. (3) Control bus: carries control and timing signals (read, write, clock, interrupt) between the CPU and other parts. ## Unit 3 system bus.
qp iv | Explain different types of CPU instructions. Also give examples. || سی پی یو ہدایات کی مختلف اقسام کی وضاحت کریں۔ مثالیں بھی دیں۔ || د CPU د لارښوونو مختلف ډولونه تشریح کړئ. بېلګې هم ورکړئ.
sol Model answer: Types of CPU instructions: (1) Data transfer instructions move data between registers and memory, e.g. MOV, LDA (load), STA (store). (2) Arithmetic instructions: ADD, SUB, MUL, DIV, INC, DEC. (3) Logical instructions: AND, OR, NOT, XOR, CMP (compare). (4) Control (branch) instructions change the order of execution: JMP, LOOP, CALL, RET. (5) Input/output instructions: IN, OUT. (6) Machine control: HALT, STOP, NOP. ## Unit 3 types of instructions.
qp v | What is Instruction cycle? Explain different phases of CPU instruction cycle. || ہدایتی چکر کیا ہے؟ سی پی یو کے ہدایتی چکر کے مختلف مراحل کی وضاحت کریں۔ || د لارښوونې دوره څه ده؟ د CPU د لارښوونې د دورې مختلف پړاوونه تشریح کړئ.
sol Model answer: The instruction cycle (machine cycle) is the series of steps the CPU repeats to execute each instruction. Phases: (1) Fetch: the control unit gets the instruction from memory at the address in the program counter and puts it in the instruction register; the counter moves on to the next address. (2) Decode: the control unit interprets the op-code and finds out the operation and operands. (3) Execute: the ALU or another unit performs the operation. (4) Write back (store): the result is written to a register or to memory. Then the cycle starts again with the next instruction. ## Unit 3 instruction cycle.
