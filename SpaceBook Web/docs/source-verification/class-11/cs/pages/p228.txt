## c. Table/Relation || ج۔ ٹیبل/ریلیشن || ج. جدول/اړیکه
p A table is set of values that are organized using vertical named columns and horizontal rows. A table has a specified number of columns, but may have any number of rows. Whereas in terms of relational database, a table can be considered as relation, but the two are not equivalent. For example a table may contain duplicate rows, but a true relation cannot contain duplicate rows. || ٹیبل قدروں کا مجموعہ ہے جو عمودی نام والے کالموں اور افقی قطاروں کے ذریعے منظم ہوتا ہے۔ ٹیبل میں کالموں کی ایک مقررہ تعداد ہوتی ہے لیکن قطاروں کی کوئی بھی تعداد ہو سکتی ہے۔ جبکہ ریلیشنل ڈیٹا بیس کے لحاظ سے ٹیبل کو ریلیشن سمجھا جا سکتا ہے لیکن دونوں برابر نہیں ہیں۔ مثلاً ٹیبل میں نقل شدہ قطاریں ہو سکتی ہیں لیکن حقیقی ریلیشن میں نقل شدہ قطاریں نہیں ہو سکتیں۔ || جدول د ارزښتونو ټولګه ده چې د عمودي نومول شویو ستونونو او افقي قطارونو په کارولو سره منظم شوې وي. جدول یو ټاکلی شمېر ستونونه لري، خو هر شمېر قطارونه لرلای شي. پداسې حال کې چې د اړوند ډېټابېس په اړه جدول د اړیکې په توګه ګڼل کېدای شي، خو دا دواړه برابر نه دي. د بېلګې په توګه یو جدول کېدای شي تکراري قطارونه ولري، خو یوه ریښتینې اړیکه تکراري قطارونه نشي لرلای.
## d. View || د۔ ویو || د. لید
p A view is a dynamic and virtual table that may not exist in the database but is derived from one or more base tables. In simple words there is no stored table that represents the view instead a definition or query representing the view is stored in the database. || ویو ایک متحرک اور مجازی ٹیبل ہے جو ڈیٹا بیس میں موجود نہ ہو لیکن ایک یا زیادہ بنیادی ٹیبلز سے اخذ ہو۔ سادہ الفاظ میں ویو کی نمائندگی کرنے والا کوئی ذخیرہ شدہ ٹیبل نہیں ہوتا بلکہ ویو کی نمائندگی کرنے والی تعریف یا کوئری ڈیٹا بیس میں محفوظ ہوتی ہے۔ || لید یو متحرک او مجازي جدول دی چې شاید په ډېټابېس کې شتون ونه لري خو له یو یا ډیرو بنسټیزو جدولونو اخیستل شوی وي. په ساده کلمو کې د لید ښودونکی هېڅ ذخیره شوی جدول نشته، پر ځای یې د لید ښودونکی تعریف یا پوښتنه په ډېټابېس کې ساتل کېږي.
## e. Data Type || ہ۔ ڈیٹا ٹائپ || ه. د ډېټا ډول
p Data type is the classification of a particular type of information. It is easy for human beings to distinguish among different types of data but most database systems require the user to specify the type of each data field. Integer, floating-point and character (text) are the common data types. || ڈیٹا ٹائپ معلومات کی کسی مخصوص قسم کی درجہ بندی ہے۔ انسانوں کے لیے ڈیٹا کی مختلف اقسام میں فرق کرنا آسان ہے لیکن زیادہ تر ڈیٹا بیس سسٹمز کو صارف سے ہر ڈیٹا فیلڈ کی قسم متعین کرنا درکار ہوتا ہے۔ انٹیجر، فلوٹنگ پوائنٹ اور کریکٹر (ٹیکسٹ) عام ڈیٹا ٹائپس ہیں۔ || د ډېټا ډول د یو ځانګړي ډول معلوماتو طبقه بندي ده. د انسانانو لپاره د ډېټا د مختلفو ډولونو ترمنځ توپیر کول اسان دي خو ډیری ډېټابېس سیسټمونه له کاروونکي غواړي چې د هرې ډېټا ساحې ډول وټاکي. بشپړ عدد، لامبوونکی ټکی او توری (متن) عام د ډېټا ډولونه دي.
## f. Key || و۔ کی || و. کیلي
p In order to track and analyze data effectively, each record in a table requires an identifier that uniquely indentifies it, is called a key. The key must be completely unique to a particular record. For example student’s roll number, employee number, and customer number, etc. are key fields. || ڈیٹا کو مؤثر طریقے سے ٹریک اور تجزیہ کرنے کے لیے ٹیبل کے ہر ریکارڈ کو ایک شناخت کنندہ درکار ہوتا ہے جو اسے منفرد طور پر شناخت کرے، اسے کی کہتے ہیں۔ کی کسی مخصوص ریکارڈ کے لیے مکمل طور پر منفرد ہونی چاہیے۔ مثلاً طالب علم کا رول نمبر، ملازم نمبر اور کسٹمر نمبر وغیرہ کی فیلڈز ہیں۔ || د ډېټا د اغېزمن تعقیب او تحلیل لپاره په جدول کې هر ثبت یو پېژندونکي ته اړتیا لري چې په ځانګړي ډول یې وپېژني، دې ته کیلي ویل کېږي. کیلي باید د یو ځانګړي ثبت لپاره بشپړه ځانګړې وي. د بېلګې په توګه د زده کوونکي رول شمېره، د کارکوونکي شمېره، او د پېرېدونکي شمېره او نور کیلي ساحې دي.
