## 2.1 Introduction || ۲.۱ تعارف || ۲.۱ پېژندنه
p Computer memory is one of the important and compulsory components of every computer system. It is the electronic holding place for instructions and data which can be accessed by computer. Computer memory is used to store data or programs on a temporary or permanent basis for use in a computer. From the moment user turn the computer on until the time it is shut down, the CPU of the computer is constantly using memory. Memory is sometimes distinguished from storage, or the physical medium that holds the much larger amounts of data for later use. || کمپیوٹر میموری ہر کمپیوٹر سسٹم کے اہم اور لازمی اجزاء میں سے ایک ہے۔ یہ ہدایات اور ڈیٹا کی برقی جائے رکھنے کی جگہ ہے جس تک کمپیوٹر رسائی حاصل کر سکتا ہے۔ کمپیوٹر میموری ڈیٹا یا پروگرام کو کمپیوٹر میں استعمال کے لیے عارضی یا مستقل بنیاد پر محفوظ کرنے کے لیے استعمال ہوتی ہے۔ صارف کے کمپیوٹر آن کرنے کے لمحے سے بند کرنے تک کمپیوٹر کا سی پی یو مسلسل میموری استعمال کرتا رہتا ہے۔ میموری کو بعض اوقات اسٹوریج سے ممتاز کیا جاتا ہے، یعنی اس طبعی وسیلے سے جو بعد کے استعمال کے لیے ڈیٹا کی بہت بڑی مقدار رکھتا ہے۔ || د کمپیوټر حافظه د هر کمپیوټر سیسټم له مهمو او لازمي اجزاوو نه یو ده. دا د لارښوونو او ډېټا برېښنايي ساتلو ځای دی چې کمپیوټر ورته لاسرسی موندلای شي. د کمپیوټر حافظه ډېټا یا پروګرامونه په کمپیوټر کې د کارونې لپاره په لنډمهاله یا دایمي بنسټ ساتلو لپاره کارول کېږي. هغه شېبې نه چې کاروونکی کمپیوټر روښانه کوي تر هغه وخته چې بند شي، د کمپیوټر CPU په دوامداره توګه حافظه کاروي. حافظه ځینې وخت له ذخیرې نه جلا ګڼل کېږي، یا هغه فزیکي رسنۍ چې وروسته د کارونې لپاره ډیر لوی مقدار ډېټا ساتي.
p Computer memory is divided into two main types. || کمپیوٹر میموری کو دو بنیادی اقسام میں تقسیم کیا جاتا ہے۔ || د کمپیوټر حافظه په دوو اصلي ډولونو وېشل کېږي.
p Primary or Main or Internal Memory || بنیادی یا مرکزی یا اندرونی میموری || لومړنۍ یا اصلي یا دننني حافظه
p Secondary or Auxiliary or Backing Storage Memory || ثانوی یا معاون یا پشتی ذخیرہ میموری || دویمي یا مرستندویه یا ملاتړي ذخیرې حافظه
p Primary or Main memory holds instructions and data when a program is executed, while secondary memory (also called auxiliary memory) holds data and programs not currently in use and provides long-term storage. || بنیادی یا مرکزی میموری پروگرام چلنے کے وقت ہدایات اور ڈیٹا رکھتی ہے جبکہ ثانوی میموری (جسے معاون میموری بھی کہتے ہیں) وہ ڈیٹا اور پروگرام رکھتی ہے جو فی الحال استعمال میں نہیں ہیں اور طویل مدتی ذخیرہ فراہم کرتی ہے۔ || لومړنۍ یا اصلي حافظه هغه وخت لارښوونې او ډېټا ساتي کله چې پروګرام پلی کېږي، پداسې حال کې چې دویمي حافظه (چې مرستندویه حافظه هم ورته ویل کېږي) هغه ډېټا او پروګرامونه ساتي چې اوس مهال په کارونه کې نه دي او اوږدمهاله ذخیره برابروي.

## a. Bit || الف۔ بٹ || الف. بټ
p A bit or binary digit is the basic unit of information in computing. A bit is the smallest amount of memory a computer can recognize. A bit can hold only one of two values, either ‘0’ or ‘1’. It is also applied to a unit of computer memory corresponding to the ability to store the result of a choice between two alternatives. Computers represent information in binary code, written as || بٹ یا بائنری ہندسہ کمپیوٹنگ میں معلومات کی بنیادی اکائی ہے۔ بٹ میموری کی وہ سب سے چھوٹی مقدار ہے جسے کمپیوٹر پہچان سکتا ہے۔ ایک بٹ صرف دو قدروں میں سے ایک رکھ سکتا ہے، یا ’۰‘ یا ’۱‘۔ یہ کمپیوٹر میموری کی اس اکائی پر بھی لاگو ہوتا ہے جو دو متبادل کے درمیان انتخاب کا نتیجہ محفوظ کرنے کی صلاحیت کے مطابق ہے۔ کمپیوٹرز معلومات کو بائنری کوڈ میں ظاہر کرتے ہیں، جو لکھا جاتا ہے || بټ یا بائنري عدد په کمپیوټینګ کې د معلوماتو بنسټیز واحد دی. بټ د حافظې تر ټولو کوچنی مقدار دی چې کمپیوټر یې پېژندلای شي. یو بټ د دوو ارزښتونو یوازې یو ساتلای شي، یا ‘۰’ یا ‘۱’. دا د کمپیوټر د حافظې په هغه واحد هم پلي کېږي چې د دوو بدیلونو ترمنځ د انتخاب د پایلې د ساتلو وړتیا سره سمون لري. کمپیوټرونه معلومات په بائنري کوډ کې ښیي، چې لیکل کېږي
