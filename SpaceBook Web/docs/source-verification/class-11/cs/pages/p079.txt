qp i | Briefly explain the processor internal memory and its types. || پراسیسر کی اندرونی میموری اور اس کی اقسام مختصراً بیان کریں۔ || د پروسیسر دننني حافظه او د هغې ډولونه په لنډه توګه تشریح کړئ.
sol Model answer: Processor internal memory is the memory that is placed inside the processor (CPU) or very close to it, so that the CPU gets its data without delay. Its types: (1) Registers: tiny, fastest memory units in the CPU that hold current data, instructions and addresses. (2) Cache memory: small fast memory that keeps frequently used data and instructions; L1 cache is inside the processor core, L2 is larger and slightly slower, L3 is shared between cores. ## Unit 2 processor internal memory.
qp ii | Explain RAM and ROM along with their types in detail. || ریم اور روم کی ان کی اقسام کے ساتھ تفصیل سے وضاحت کریں۔ || RAM او ROM د هغو د ډولونو سره په تفصیل سره تشریح کړئ.
sol Model answer: RAM (random access memory) is the main memory of the computer; the CPU can read and write any location directly; it is volatile (data is lost when power is off). Types: DRAM (dynamic RAM, needs refreshing, cheaper) and SRAM (static RAM, faster, used for cache); SDRAM and DDR are improved forms of DRAM. ROM (read only memory) holds permanent instructions such as the boot program; it is non-volatile and normally only read. Types: MROM (mask ROM, programmed by the maker), PROM (programmable once by the user), EPROM (erased by ultraviolet light) and EEPROM (erased electrically). ## Unit 2 RAM and ROM.
qp iii | What is meant by secondary storage devices also explain the difference between Sequential access and Random access. || ثانوی ذخیرہ آلات سے کیا مراد ہے؟ نیز ترتیب وار رسائی اور بلا ترتیب رسائی کا فرق بھی بیان کریں۔ || د دویمي ذخیرې له وسایلو نه څه مراد دی؟ همدارنګه د ترتیبي لاسرسي او تصادفي لاسرسي توپیر هم تشریح کړئ.
sol Model answer: Secondary storage devices are devices that store data and programs permanently outside the main memory, for example hard disks, optical discs, magnetic tapes and flash drives. In sequential access, data is read in order from the beginning, so to reach the last record all earlier ones must pass (magnetic tape); it is slow. In random (direct) access, the device can go straight to the wanted location without passing the others (hard disk, DVD, flash); it is fast. ## Unit 2 secondary storage and access methods.

qp • | a) Magnetic tapes || a) مقناطیسی ٹیپس || a) مقناطیسي ټیپونه
sol Model answer: Magnetic tape is a long plastic strip coated with magnetic material that stores data sequentially in tracks, like an audio cassette. Advantages: low cost, large capacity, easy to store and good for backup and archiving. Disadvantages: slow because of sequential access, affected by heat, dust and magnetic fields, and wears out with use. ## Unit 2 magnetic tapes.
qp • | b) Magnetic disks || b) مقناطیسی ڈسکس || b) مقناطیسي ډیسکونه
sol Model answer: Magnetic disks (hard disk, floppy disk) store data in tracks and sectors on round plates coated with magnetic material. Advantages: large capacity, fast random access, reusable and cheap per byte. Disadvantages: moving parts that can fail, can be damaged by shock, heat or magnets, and slower than flash and RAM. ## Unit 2 magnetic disks.
qp c | Optical disks (CD, DVD, Blue Ray) || آپٹیکل ڈسکس (سی ڈی، ڈی وی ڈی، بلیو رے) || نظري ډیسکونه (CD، DVD، Blue Ray)
qp • | a) Flash Memory || a) فلیش میموری || a) فلش حافظه
sol Model answer: Flash memory is non-volatile electronic memory that can be erased and rewritten in blocks; it has no moving parts (USB flash drive, SSD). Advantages: fast, silent, small, light, durable, low power use and keeps data without power. Disadvantages: costlier per gigabyte than hard disks and each cell can be rewritten only a limited number of times. ## Unit 2 flash memory.
qp • | b) Memory Cards || b) میموری کارڈز || b) حافظې کارتونه
sol Model answer: Memory cards (SD, microSD, CompactFlash) are small removable flash-memory cards used in cameras, mobile phones and tablets. Advantages: very small, portable, can be swapped to increase storage, reasonably cheap and fast. Disadvantages: easy to lose or damage, limited capacity compared to hard disks, and they wear out after many writes. ## Unit 2 memory cards.
