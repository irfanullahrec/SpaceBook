p Update Queries let users modify the values of a field or fields in a table. You can specify the records to modify by applying a filter (WHERE clause) and linking the table to other tables and queries. || اپ ڈیٹ کوئریز صارفین کو ٹیبل میں ایک یا زیادہ فیلڈز کی قدریں تبدیل کرنے دیتی ہیں۔ آپ فلٹر (وہیئر کلاز) لگا کر اور ٹیبل کو دیگر ٹیبلز اور کوئریز سے جوڑ کر ترمیم کے لیے ریکارڈز متعین کر سکتے ہیں۔ || د Update پوښتنې کاروونکو ته اجازه ورکوي چې په جدول کې د یوې یا ډیرو ساحو ارزښتونه تعدیل کړي. تاسو کولای شئ د چاڼګر (WHERE بند) په پلي کولو او جدول له نورو جدولونو او پوښتنو سره د نښلولو په واسطه د تعدیل لپاره ثبتونه وټاکئ.
p The updated value can be: || اپ ڈیٹ شدہ قدر یہ ہو سکتی ہے: || تازه شوی ارزښت دا کېدای شي:
p The same value for all records. || تمام ریکارڈز کے لیے ایک ہی قدر۔ || د ټولو ثبتونو لپاره ورته ارزښت.
p A value from another field in that table (updates the field based on a field’s value in its own record). || اسی ٹیبل کی کسی دوسری فیلڈ کی قدر (فیلڈ کو اس کے اپنے ریکارڈ میں کسی فیلڈ کی قدر کی بنیاد پر اپ ڈیٹ کرتی ہے)۔ || په هماغه جدول کې د بلې ساحې ارزښت (ساحه د خپل ثبت په یوې ساحې ارزښت پر بنسټ تازه کوي).
p A value from a field in a linked table. || منسلک ٹیبل کی کسی فیلڈ کی قدر۔ || په نښلول شوي جدول کې د یوې ساحې ارزښت.
p An expression based on values in the table or linked tables (multiple fields can be used to calculate the new value). || ٹیبل یا منسلک ٹیبلز کی قدروں پر مبنی اظہار (نئی قدر کا حساب لگانے کے لیے متعدد فیلڈز استعمال ہو سکتی ہیں)۔ || په جدول یا نښلول شوو جدولونو کې د ارزښتونو پر بنسټ څرګندونه (د نوي ارزښت د محاسبې لپاره څو ساحې کارېدای شي).
p A function value which can include field values as its parameters || فنکشن کی قدر جس میں فیلڈ کی قدریں اس کے پیرامیٹرز کے طور پر شامل ہو سکتی ہیں || د فنکشن ارزښت چې کولای شي د ساحې ارزښتونه د خپلو پارامېټرونو په توګه ولري
p User defined function that may or may not include field values as parameters. || صارف کا متعین کردہ فنکشن جس میں فیلڈ کی قدریں پیرامیٹرز کے طور پر شامل ہو بھی سکتی ہیں اور نہیں بھی۔ || د کاروونکي لخوا تعریف شوی فنکشن چې کېدای شي د ساحې ارزښتونه د پارامېټرونو په توګه ولري یا ونه لري.
p Example: In Students’ database let us create an update query to change the Section of all students to “G”. || مثال: اسٹوڈنٹس ڈیٹا بیس میں آئیے ایک اپ ڈیٹ کوئری بنائیں جو تمام طلبہ کا سیکشن ’’جی‘‘ میں بدل دے۔ || بېلګه: د زده کوونکو په ډېټابېس کې راځئ یوه Update پوښتنه جوړه کړو چې د ټولو زده کوونکو برخه “G” ته بدله کړي.
p Create a new query using the Student table. Include the fields that are going to be used to update the records. || اسٹوڈنٹ ٹیبل استعمال کر کے نئی کوئری بنائیں۔ وہ فیلڈز شامل کریں جو ریکارڈز کو اپ ڈیٹ کرنے کے لیے استعمال ہوں گی۔ || د زده کوونکي جدول په کارولو نوې پوښتنه جوړه کړئ. هغه ساحې شاملې کړئ چې د ثبتونو د تازه کولو لپاره کارول کېږي.
p Select Update from Query Type, as shown in Figure 8.34. || کوئری ٹائپ سے اپ ڈیٹ منتخب کریں، جیسا کہ شکل ۸.۳۴ میں دکھایا گیا ہے۔ || له Query Type نه Update وټاکئ، لکه څنګه چې ۸.۳۴ انځور کې ښودل شوی.
p Type “G” for Section field in Update To row, as shown in Figure 8.34. || اپ ڈیٹ ٹو قطار میں سیکشن فیلڈ کے لیے ’’جی‘‘ ٹائپ کریں، جیسا کہ شکل ۸.۳۴ میں دکھایا گیا ہے۔ || د Update To قطار کې د Section ساحې لپاره “G” ټایپ کړئ، لکه څنګه چې ۸.۳۴ انځور کې ښودل شوی.
