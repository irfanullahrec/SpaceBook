## b. Network Database Model || ب۔ نیٹ ورک ڈیٹا بیس ماڈل || ب. شبکه ډېټابېس ماډل
p A network database is similar to a hierarchical database model except that each child can have more than one parent record. A child record is referred to as a “member” and a parent record is referred to as an “owner”. The advantage of the network database is its ability to establish relationships between different branches of data records and thus offer increased access capability for the manager. Figure 7.2 shows a network database model. || نیٹ ورک ڈیٹا بیس ہائیرارکیکل ڈیٹا بیس ماڈل سے مشابہ ہے سوائے اس کے کہ ہر بچے کے ایک سے زیادہ والدین ریکارڈ ہو سکتے ہیں۔ بچے کے ریکارڈ کو ’’ممبر‘‘ اور والدین کے ریکارڈ کو ’’اونر‘‘ کہا جاتا ہے۔ نیٹ ورک ڈیٹا بیس کا فائدہ یہ ہے کہ یہ ڈیٹا ریکارڈز کی مختلف شاخوں کے درمیان تعلقات قائم کر سکتا ہے اور اس طرح منتظم کے لیے رسائی کی بڑھی ہوئی صلاحیت پیش کرتا ہے۔ شکل ۷.۲ نیٹ ورک ڈیٹا بیس ماڈل دکھاتی ہے۔ || شبکه ډېټابېس د درجه بندي ډېټابېس ماډل غوندې ده پرته له دې چې هر ماشوم کېدای شي له یوه څخه ډیر د مور ثبتونه ولري. د ماشوم ثبت “غړی” او د مور ثبت “مالک” بلل کېږي. د شبکې ډېټابېس ګټه د ډېټا ثبتونو د مختلفو څانګو ترمنځ د اړیکو جوړولو وړتیا ده او په دې توګه د مدیر لپاره د لاسرسي زیاته وړتیا برابروي. ۷.۲ انځور د شبکې ډېټابېس ماډل ښيي.
