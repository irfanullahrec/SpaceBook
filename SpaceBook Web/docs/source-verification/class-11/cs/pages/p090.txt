## 3.2.1 Instructions and their types || ۳.۲.۱ ہدایات اور ان کی اقسام || ۳.۲.۱ لارښوونې او د هغو ډولونه
p An instruction (or instruction code) is a group of bits that tells the computer to perform a specific operation. Instruction is an elementary operation that the processor can accomplish. Instructions are stored in the main memory, waiting to be processed by the processor. An instruction has two fields: || ہدایت (یا ہدایتی کوڈ) بٹس کا ایک گروپ ہے جو کمپیوٹر کو ایک مخصوص عمل کرنے کو کہتا ہے۔ ہدایت ایک ابتدائی عمل ہے جسے پراسیسر انجام دے سکتا ہے۔ ہدایات مین میموری میں محفوظ ہوتی ہیں اور پراسیسر کے ذریعے پراسیس ہونے کا انتظار کرتی ہیں۔ ایک ہدایت کے دو حصے (فیلڈز) ہوتے ہیں: || لارښوونه (یا د لارښوونې کوډ) د بټونو یوه ډله ده چې کمپیوټر ته وايي یو ځانګړی عمل وکړي. لارښوونه یو لومړنی عمل دی چې پروسیسر یې ترسره کولای شي. لارښوونې په اصلي حافظه کې ساتل کېږي او د پروسیسر په واسطه د پروسس انتظار کوي. یوه لارښوونه دوه ساحې لري:
p Operation code, which represents the action that the processor execute. || آپریشن کوڈ، جو اس عمل کو ظاہر کرتا ہے جو پراسیسر انجام دیتا ہے۔ || د عملیې کوډ، چې هغه عمل ښیي چې پروسیسر یې پلي کوي.
p Operand code, which defines the parameters of the action. The operand code depends on the operation. It can be data or a memory address. || آپرینڈ کوڈ، جو عمل کے پیرامیٹرز کی تعریف کرتا ہے۔ آپرینڈ کوڈ عمل پر منحصر ہوتا ہے۔ یہ ڈیٹا یا میموری پتہ ہو سکتا ہے۔ || د عملوند کوډ، چې د عمل پارامیټرونه تعریفوي. د عملوند کوډ په عملیه پورې اړه لري. دا ډېټا یا د حافظې پته کېدای شي.

p Most of the operations of the CPU are data transferring. These instructions are used when the data needs to be moved from memory location to register. These instructions transfer data from one location in the computer to another location without changing the data content.
