## 8.2.2 Data Types in MS-Access 2007 || ۸.۲.۲ ایم ایس ایکسیس ۲۰۰۷ میں ڈیٹا ٹائپس || ۸.۲.۲ په MS-Access 2007 کې د ډېټا ډولونه
p There are nine types of field data types which are used in Access 2007. || ایکسیس ۲۰۰۷ میں استعمال ہونے والی فیلڈ ڈیٹا ٹائپس کی نو اقسام ہیں۔ || په Access 2007 کې د کارېدونکو ساحو د ډېټا ډولونو نهه ډولونه شته.
p 1. Text: Access assigns Text as the default data type to all fields. The maximum size of text field is 255 characters. All types of characters i.e. alphabets, numbers and special characters are allowed in text data type. || ۱۔ ٹیکسٹ: ایکسیس تمام فیلڈز کو ڈیفالٹ ڈیٹا ٹائپ کے طور پر ٹیکسٹ تفویض کرتا ہے۔ ٹیکسٹ فیلڈ کا زیادہ سے زیادہ سائز ۲۵۵ حروف ہے۔ ٹیکسٹ ڈیٹا ٹائپ میں ہر قسم کے حروف یعنی حروفِ تہجی، اعداد اور خصوصی علامات کی اجازت ہے۔ || ۱. متن (Text): Access متن د ټولو ساحو لپاره د ډیفالټ ډېټا ډول په توګه ټاکي. د متن ساحې اعظمي کچه ۲۵۵ توري دي. د متن په ډېټا ډول کې د هر ډول توري یعنې الفبا، عددونه او ځانګړي نښې اجازه لري.
p 2. Memo: Memo data type allows as many as 63999 characters to fields. Users use them to provide descriptive text comments. Access displays the contents of Memo fields in a Datasheet view. A memo field cannot be a Primary key field. || ۲۔ میمو: میمو ڈیٹا ٹائپ فیلڈز کو ۶۳۹۹۹ حروف تک کی اجازت دیتی ہے۔ صارفین انہیں وضاحتی متنی تبصرے فراہم کرنے کے لیے استعمال کرتے ہیں۔ ایکسیس میمو فیلڈز کے مواد کو ڈیٹا شیٹ ویو میں دکھاتا ہے۔ میمو فیلڈ پرائمری کی فیلڈ نہیں ہو سکتی۔ || ۲. یادښت (Memo): د یادښت د ډېټا ډول ساحو ته تر ۶۳۹۹۹ توري اجازه ورکوي. کاروونکي هغه د تشریحي متني نظرونو لپاره کاروي. Access د یادښت ساحو منځپانګه په ډېټا شیټ لید کې ښيي. د یادښت ساحه د لومړنۍ کیلي ساحه نشي کېدای.
p 3. Number: Number data type is assigned to numeric fields. Various numeric data subtypes are available in the Field Properties pane of Table Design || ۳۔ نمبر: نمبر ڈیٹا ٹائپ عددی فیلڈز کو تفویض کی جاتی ہے۔ ٹیبل ڈیزائن کے فیلڈ پراپرٹیز پین میں مختلف عددی ڈیٹا ذیلی اقسام دستیاب ہیں || ۳. شمېره (Number): د شمېرې د ډېټا ډول عددي ساحو ته ټاکل کېږي. د جدول ډیزاین د ساحې ملکیتونو پټه کې مختلف عددي ډېټا فرعي ډولونه شته
