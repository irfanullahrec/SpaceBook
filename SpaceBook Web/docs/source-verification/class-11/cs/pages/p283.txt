p 2. Move the mouse pointer to the required location and click to add button. The Command Button Wizard opens, as shown in Figure 8.24. || ۲۔ ماؤس پوائنٹر کو مطلوبہ جگہ پر لے جائیں اور بٹن شامل کرنے کے لیے کلک کریں۔ کمانڈ بٹن ویزرڈ کھلتا ہے، جیسا کہ شکل ۸.۲۴ میں دکھایا گیا ہے۔ || ۲. د موږک ګوته غوښتل شوي ځای ته یوسئ او د تڼۍ د زیاتولو لپاره کلیک وکړئ. د Command Button Wizard پرانیستل کېږي، لکه څنګه چې ۸.۲۴ انځور کې ښودل شوی.
p Select the type of command from the Categories list. (For example Record Navigation) || زمرہ فہرست سے کمانڈ کی قسم منتخب کریں۔ (مثلاً ریکارڈ نیویگیشن) || د Categories لیست نه د حکم ډول وټاکئ. (د بېلګې په توګه Record Navigation)
p Select the specific action the command button to perform from the Actions list. (For example Find Next) || ایکشنز فہرست سے وہ مخصوص عمل منتخب کریں جو کمانڈ بٹن انجام دے۔ (مثلاً فائنڈ نیکسٹ) || د Actions لیست نه هغه ځانګړې کړنه وټاکئ چې د حکم تڼۍ یې ترسره کوي. (د بېلګې په توګه Find Next)
p Click Next. || نیکسٹ پر کلک کریں۔ || د Next تڼۍ کلیک کړئ.
