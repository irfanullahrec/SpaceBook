## c. Delete Query || ج۔ ڈیلیٹ کوئری || ج. د Delete پوښتنه
p Delete query is used to delete records from a single database table or multiple tables. Delete query removes records from tables permanently. As with the other types of action queries, the delete query works with a group of records that meet specified criteria that user apply. User can use the delete query to remove all records or only records that meet the defined criteria. || ڈیلیٹ کوئری ایک ڈیٹا بیس ٹیبل یا متعدد ٹیبلز سے ریکارڈز حذف کرنے کے لیے استعمال ہوتی ہے۔ ڈیلیٹ کوئری ٹیبلز سے ریکارڈز مستقل طور پر ہٹا دیتی ہے۔ دیگر ایکشن کوئریز کی طرح ڈیلیٹ کوئری ان ریکارڈز کے گروپ کے ساتھ کام کرتی ہے جو صارف کے لاگو کردہ متعین معیار پر پورا اترتے ہوں۔ صارف ڈیلیٹ کوئری سے تمام ریکارڈز یا صرف وہ ریکارڈز ہٹا سکتا ہے جو متعین معیار پر پورا اترتے ہوں۔ || د Delete پوښتنه له یو ډېټابېس جدول یا څو جدولونو نه د ثبتونو د حذف کولو لپاره کارول کېږي. د Delete پوښتنه ثبتونه له جدولونو نه په دایمي توګه لېرې کوي. لکه د نورو کړنو پوښتنو په څېر، د Delete پوښتنه د ثبتونو له هغې ډلې سره کار کوي چې د کاروونکي لخوا پلي شوی ټاکل شوی معیار پوره کوي. کاروونکی کولای شي د Delete پوښتنه د ټولو ثبتونو یا یوازې هغو ثبتونو د لېرې کولو لپاره وکاروي چې ټاکل شوی معیار پوره کوي.
p Example: In Students database let us create a Delete query to remove the records of students of Section “B” in Student table. || مثال: اسٹوڈنٹس ڈیٹا بیس میں آئیے ایک ڈیلیٹ کوئری بنائیں جو اسٹوڈنٹ ٹیبل میں سیکشن ’’بی‘‘ کے طلبہ کے ریکارڈز ہٹا دے۔ || بېلګه: د زده کوونکو په ډېټابېس کې راځئ یوه Delete پوښتنه جوړه کړو چې د زده کوونکي جدول کې د “B” برخې د زده کوونکو ثبتونه لېرې کړي.
p Create a new query using the Student table. Include those fields that are going to be used to delete the records. || اسٹوڈنٹ ٹیبل استعمال کر کے نئی کوئری بنائیں۔ وہ فیلڈز شامل کریں جو ریکارڈز حذف کرنے کے لیے استعمال ہوں گی۔ || د زده کوونکي جدول په کارولو نوې پوښتنه جوړه کړئ. هغه ساحې شاملې کړئ چې د ثبتونو د حذف کولو لپاره کارول کېږي.
p In the query design view, click on the drop-down arrow to the right of the Query Type button and choose Delete Query. || کوئری ڈیزائن ویو میں کوئری ٹائپ بٹن کے دائیں طرف ڈراپ ڈاؤن تیر پر کلک کریں اور ڈیلیٹ کوئری منتخب کریں۔ || د پوښتنې ډیزاین لید کې د Query Type تڼۍ ښي لوري ښکته کېدونکي غشي کلیک کړئ او Delete Query وټاکئ.
p Type “B” for Section field in Criteria row, as shown in Figure 8.36. || کرائٹیریا قطار میں سیکشن فیلڈ کے لیے ’’بی‘‘ ٹائپ کریں، جیسا کہ شکل ۸.۳۶ میں دکھایا گیا ہے۔ || د Criteria قطار کې د Section ساحې لپاره “B” ټایپ کړئ، لکه څنګه چې ۸.۳۶ انځور کې ښودل شوی.
