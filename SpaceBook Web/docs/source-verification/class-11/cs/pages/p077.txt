q  | Q1. Select the best choice for the following MCQs. || سوال ۱: درج ذیل کثیر انتخابی سوالات کے لیے بہترین جواب منتخب کریں۔ || ۱ پوښتنه: د لاندې څو انتخابي پوښتنو لپاره غوره ځواب وټاکئ.
qp i | ____________ memory holds data and programs not currently in use and provides long-term storage. A. Primary B. Secondary C. Main C. Internal || ____________ میموری وہ ڈیٹا اور پروگرام رکھتی ہے جو فی الحال استعمال میں نہیں ہیں اور طویل مدتی ذخیرہ فراہم کرتی ہے۔ A۔ بنیادی B۔ ثانوی C۔ مرکزی C۔ اندرونی || ____________ حافظه هغه ډېټا او پروګرامونه ساتي چې اوس مهال په کارونه کې نه دي او اوږدمهاله ذخیره برابروي. A. لومړنۍ B. دویمي C. اصلي C. دننني
sol B. Secondary ## Secondary memory (hard disk, DVD, flash) stores data and programs not in current use for the long term.
qp ii | ____________ is the smallest amount of memory a computer can hold? A. Byte B. KB C. Bit C. MB || ____________ میموری کی وہ سب سے چھوٹی مقدار ہے جو کمپیوٹر رکھ سکتا ہے؟ A۔ بائٹ B۔ کے بی C۔ بٹ C۔ ایم بی || ____________ د حافظې تر ټولو کوچنی مقدار دی چې کمپیوټر یې ساتلای شي؟ A. بایټ B. KB (کیلوبایټ) C. بټ C. MB (میګابایټ)
sol C. Bit ## A bit is the smallest unit of memory (0 or 1). Note: the book prints the letter C twice; the correct choice is "Bit".
qp iii | Which of the following is the fastest memory? A. RAM B. ROM C. Cache memory D. PROM || درج ذیل میں سے کون سی میموری سب سے تیز ہے؟ A۔ ریم B۔ روم C۔ کیش میموری D۔ پی روم || لاندې له حافظو نه کومه یوه تر ټولو ګړندۍ ده؟ A. RAM (رام) B. ROM (روم) C. کېش حافظه D. PROM (پي روم)
sol C. Cache memory ## Of the choices, cache memory is the fastest; it sits between the CPU and RAM.
qp iv | How much is 1 Mega Byte memory equal to? A. 1024 K Bytes B. 1000 K Bytes C. 1024 K Bits D. 1024 G Bytes || ۱ میگا بائٹ میموری کتنی کے برابر ہے؟ A۔ ۱۰۲۴ کے بائٹس B۔ ۱۰۰۰ کے بائٹس C۔ ۱۰۲۴ کے بٹس D۔ ۱۰۲۴ جی بائٹس || ۱ میګابایټ حافظه له څومره سره برابره ده؟ A. ۱۰۲۴ کیلوبایټه B. ۱۰۰۰ کیلوبایټه C. ۱۰۲۴ کیلوبټه D. ۱۰۲۴ ګیګابایټه
sol A. 1024 K Bytes ## 1 MB = 1024 KB.
qp v | Which material is used to make memory chips? A. Iron B. Gold C. Silver D. Silicon || میموری چپس بنانے کے لیے کون سا مادہ استعمال ہوتا ہے؟ A۔ لوہا B۔ سونا C۔ چاندی D۔ سلیکون || د حافظې چپونو جوړولو لپاره کوم مواد کارول کېږي؟ A. اوسپنه B. سره زر C. سپین زر D. سلیکون
sol D. Silicon ## Memory chips are made of silicon.
qp vi | Which of the following is volatile memory? A. RAM B. ROM C. PROM D. EEPROM || درج ذیل میں سے کون سی غیر مستقل میموری ہے؟ A۔ ریم B۔ روم C۔ پی روم D۔ ای ای پی روم || لاندې له حافظو نه کومه یوه بې ثباته حافظه ده؟ A. RAM (رام) B. ROM (روم) C. PROM (پي روم) D. EEPROM (ای ای پي روم)
sol A. RAM ## RAM is volatile: its contents are lost when power is switched off. ROM, PROM and EEPROM keep their contents.
qp vii | Which of the following is called internal processor memory? A. RAM B. ROM C. Cache D. DRAM || درج ذیل میں سے کون سی پراسیسر کی اندرونی میموری کہلاتی ہے؟ A۔ ریم B۔ روم C۔ کیش D۔ ڈی ریم || لاندې له حافظو نه کومه یوه د پروسیسر دننني حافظه بلل کېږي؟ A. RAM (رام) B. ROM (روم) C. کېش D. DRAM (ډي رام)
sol C. Cache ## Cache (together with the registers) is the memory inside or next to the processor, that is the processor's internal memory.
