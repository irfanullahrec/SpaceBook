## ii. Registers || ii۔ رجسٹرز || ii. رجسترونه
p Registers are small memory units. There are a large number of registers inside the processor. There function is to temporarily store binary information and pass it to the other parts of the processor or main memory during the execution of program instructions. Some commonly used registers inside the microprocessors are accumulator, instruction register, program counter and memory address registers. They store the operands and the result of an operation. The number of registers varies from processor to processor. The more is the number the faster is the instruction execution. || رجسٹرز چھوٹی میموری اکائیاں ہیں۔ پراسیسر کے اندر رجسٹرز کی بڑی تعداد ہوتی ہے۔ ان کا کام پروگرام کی ہدایات کے عمل کے دوران بائنری معلومات کو عارضی طور پر محفوظ کرنا اور پراسیسر کے دوسرے حصوں یا مین میموری تک پہنچانا ہے۔ مائیکرو پراسیسرز کے اندر عام طور پر استعمال ہونے والے کچھ رجسٹرز ایکیومولیٹر، انسٹرکشن رجسٹر، پروگرام کاؤنٹر اور میموری ایڈریس رجسٹرز ہیں۔ یہ آپرینڈز اور کسی عمل کا نتیجہ محفوظ کرتے ہیں۔ رجسٹرز کی تعداد پراسیسر سے پراسیسر مختلف ہوتی ہے۔ تعداد جتنی زیادہ ہو ہدایات کا عمل اتنا ہی تیز ہوتا ہے۔ || رجسترونه کوچني حافظې واحدونه دي. د پروسیسر دننه د رجسترونو ډیر شمېر شته. د هغوی دنده د پروګرام د لارښوونو د پلي کېدو پر مهال بائنري معلومات په لنډمهاله توګه ساتل او د پروسیسر نورو برخو یا اصلي حافظې ته لېږدول دي. د مایکروپروسیسرونو دننه ځینې عام کارېدونکي رجسترونه ایکیومولېټر، د لارښوونې رجستر، پروګرام شمېرونکی او د حافظې د پتې رجسترونه دي. دا عملوندونه او د عمل پایله ساتي. د رجسترونو شمېر له پروسیسر نه تر پروسیسر توپیر لري. څومره چې شمېر ډیر وي همدومره د لارښوونو پلي کېدل ګړندي وي.
