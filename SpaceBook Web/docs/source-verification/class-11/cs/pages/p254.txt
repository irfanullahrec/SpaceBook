qp i | Define the terms database and DBMS. || اصطلاحات ڈیٹا بیس اور ڈی بی ایم ایس کی تعریف کریں۔ || د ډېټابېس او DBMS اصطلاحات تعریف کړئ.
sol Model answer: A database is an organised collection of related data stored together so that it can be easily accessed, managed and updated, for example the records of students of a college. A DBMS (database management system) is the software that creates, stores, manages and controls access to the database, and lets users add, change, delete and search data, for example MS Access, MySQL, Oracle. ## Unit 7 introduction.
qp ii | Give three examples of data and information. || ڈیٹا اور معلومات کی تین مثالیں دیں۔ || د ډېټا او معلوماتو درې بېلګې ورکړئ.
sol Model answer: Data is raw facts and figures with no meaning by themselves; information is data that has been processed and has meaning. Examples: (1) data: 45, 78, 90 (marks) → information: the average marks of the class is 71. (2) data: "Ali", "Class 11", "A" → information: Ali of Class 11 got grade A. (3) data: 1500, 2300, 1800 (daily sales) → information: total sales of the week or the best sale day. ## Unit 7 data and information.
qp iii | Write three disadvantages of file management system. || فائل مینجمنٹ سسٹم کے تین نقصانات لکھیں۔ || د فایل مدیریت سیسټم درې زیانونه ولیکئ.
sol Model answer: Disadvantages of a file management system: (1) Data redundancy and inconsistency: the same data is stored in many files, wasting space, and the copies may disagree. (2) Difficulty in accessing data: a new query needs a new program. (3) Data isolation and dependence: data is in different files and formats, and programs depend on the file structure. (Also: weak security, no control of concurrent access, integrity problems and no backup/recovery.) ## Unit 7 file system.
qp iv | Give any four advantages of database system. || ڈیٹا بیس سسٹم کے کوئی چار فوائد بیان کریں۔ || د ډېټابېس سیسټم هر څلور ګټې ورکړئ.
sol Model answer: Advantages of a database system: (1) Reduced data redundancy and better consistency, because data is stored once. (2) Data sharing: many users and applications use the same data. (3) Data security and integrity: access can be controlled and rules enforced. (4) Easy and fast access to data with query languages. (5) Data independence, and backup and recovery facilities. ## Unit 7 database advantages; any four.
qp v | Differentiate between DDL and DML. || ڈی ڈی ایل اور ڈی ایم ایل میں فرق کریں۔ || په DDL او DML کې توپیر وکړئ.
sol Model answer: DDL (Data Definition Language) defines and changes the structure of the database: CREATE, ALTER, DROP, TRUNCATE; it deals with tables, fields and keys. DML (Data Manipulation Language) works on the data inside the structure: SELECT (retrieve), INSERT (add), UPDATE (change) and DELETE (remove records). ## Unit 7 SQL types.
qp vi | What is data model? || ڈیٹا ماڈل کیا ہے؟ || د ډېټا ماډل څه دی؟
sol Model answer: A data model is a set of rules or a specification that defines how data is stored, organised and manipulated in a database system, and how the data items are related. Common models: hierarchical, network, relational and object-oriented. ## Unit 7 data models.
qp vii | Differentiate between cardinality and modality. || کارڈینالٹی اور موڈیلٹی میں فرق کریں۔ || په کارډینالټي او موډالټي کې توپیر وکړئ.
sol Model answer: Cardinality is the maximum number of times an instance (record) of one entity can be related to instances of another entity: one-to-one (1:1), one-to-many (1:M) or many-to-many (M:N). Modality is the minimum number: it says whether the relationship is optional (0, an instance may exist without a related one) or mandatory (1, at least one related instance must exist). For example, a customer may place many orders (cardinality 1:M); an order must belong to a customer (modality 1). ## Unit 7 ERD.
qp viii | What is primary key and foreign key? || پرائمری کی اور فارن کی کیا ہیں؟ || لومړنۍ کیلي او بهرنۍ کیلي څه دي؟
sol Model answer: A primary key is a field (or combination of fields) whose value is unique for every row of a table and is never empty, so it identifies each record (for example Roll_No in a Student table). A foreign key is a field in one table that refers to the primary key of another table and so links the two tables (for example Roll_No in the Marks table that refers to Student). ## Unit 7 keys.
qp ix | What is Relation? || ریلیشن کیا ہے؟ || اړیکه څه ده؟
sol Model answer: A relation is a table of data in a relational database, made of rows (tuples/records) and columns (attributes/fields). Each column has a unique name and holds one type of data, and each row holds the data of one entity instance. ## Unit 7 relational model terms.
qp x | What is the role of DBA? || ڈی بی اے کا کردار کیا ہے؟ || د DBA رول څه دی؟
sol Model answer: The database administrator (DBA) has central control over the data and programs. Roles: designs and creates the database structure, gives access rights to users and keeps it secure, monitors performance and tunes it, takes backups and recovers data after failure, keeps data integrity, and trains and helps users and programmers. ## Unit 7 DBA.
