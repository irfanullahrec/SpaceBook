## iii. Foreign Key || iii۔ فارن کی || iii. بهرنۍ کیلي
p A foreign key is generally a primary key from one table that appears as a field in another table where the first table has relationship to the second. For example, if we have a table A with a primary key X that is linked to a table B where X is a field in B, then X would be a foreign key in B. || فارن کی عموماً ایک ٹیبل کی پرائمری کی ہوتی ہے جو دوسرے ٹیبل میں فیلڈ کے طور پر ظاہر ہوتی ہے جہاں پہلے ٹیبل کا دوسرے سے تعلق ہو۔ مثلاً اگر ہمارے پاس پرائمری کی ایکس والا ٹیبل اے ہے جو ٹیبل بی سے منسلک ہے جہاں ایکس بی میں ایک فیلڈ ہے تو ایکس بی میں فارن کی ہو گی۔ || بهرنۍ کیلي معمولاً د یوه جدول لومړنۍ کیلي ده چې په بل جدول کې د ساحې په توګه ښکاري چېرته چې لومړی جدول له دویم سره اړیکه لري. د بېلګې په توګه که موږ یو جدول A ولرو چې لومړنۍ کیلي X لري او له جدول B سره نښلول شوی وي چېرته چې X په B کې یوه ساحه ده، نو X به په B کې بهرنۍ کیلي وي.
