## 8.1 INTRODUCTION || ۸.۱ تعارف || ۸.۱ پېژندنه
p Database development is the creation, organization, management and manipulation of database systems for organizations. DBMS (Database Management System) is used to develop a database. A database management system is a set of software programs that allows users to create, edit and update data in database files, and store and retrieve data from those database files. Data in a database can be added, deleted, changed, sorted or searched using a DBMS. || ڈیٹا بیس ڈیولپمنٹ اداروں کے لیے ڈیٹا بیس سسٹمز کی تخلیق، تنظیم، انتظام اور ان میں ترمیم ہے۔ ڈیٹا بیس بنانے کے لیے ڈی بی ایم ایس (ڈیٹا بیس مینجمنٹ سسٹم) استعمال ہوتا ہے۔ ڈیٹا بیس مینجمنٹ سسٹم سافٹ ویئر پروگراموں کا ایک مجموعہ ہے جو صارفین کو ڈیٹا بیس فائلوں میں ڈیٹا بنانے، ترمیم اور اپ ڈیٹ کرنے، اور ان فائلوں سے ڈیٹا محفوظ اور حاصل کرنے کی اجازت دیتا ہے۔ ڈیٹا بیس میں ڈیٹا کو ڈی بی ایم ایس کے ذریعے شامل، حذف، تبدیل، ترتیب یا تلاش کیا جا سکتا ہے۔ || د ډېټابېس جوړونه د ادارو لپاره د ډېټابېس سیسټمونو جوړول، تنظیم، مدیریت او کار ترې اخیستل دي. DBMS (د ډېټابېس مدیریت سیسټم) د ډېټابېس جوړولو لپاره کارول کېږي. د ډېټابېس مدیریت سیسټم د سافټویر پروګرامونو یوه ټولګه ده چې کاروونکو ته اجازه ورکوي چې په ډېټابېس فایلونو کې ډېټا جوړه، سمه او تازه کړي، او له هغو ډېټابېس فایلونو نه ډېټا ذخیره او ترلاسه کړي. په ډېټابېس کې ډېټا د DBMS په کارولو سره زیاتېدای، حذفېدای، بدلېدای، ترتیبېدای یا لټېدای شي.

## a. Microsoft Access || الف۔ مائیکروسافٹ ایکسیس || الف. مایکروسافټ اېکسېس
p Microsoft Access, also known as Microsoft Office Access, is a database management system. Figure 8.1 shows MS Access 2007 main screen. An Access database is a collection of database objects i.e. tables, queries, forms, reports, macros, and modules. Users can design new objects or open existing ones to work with their databases. Unlike many database programs, an Access database can contain all of the objects that make up a database application in a single file with the .mdb file name extension. For this reason, an Access database file is sometimes called a database container. || مائیکروسافٹ ایکسیس، جسے مائیکروسافٹ آفس ایکسیس بھی کہتے ہیں، ڈیٹا بیس مینجمنٹ سسٹم ہے۔ شکل ۸.۱ ایم ایس ایکسیس ۲۰۰۷ کی مرکزی اسکرین دکھاتی ہے۔ ایکسیس ڈیٹا بیس ڈیٹا بیس آبجیکٹس کا مجموعہ ہے یعنی ٹیبلز، کوئریز، فارمز، رپورٹس، میکروز اور ماڈیولز۔ صارفین اپنے ڈیٹا بیسز کے ساتھ کام کرنے کے لیے نئے آبجیکٹس ڈیزائن کر سکتے ہیں یا موجودہ آبجیکٹس کھول سکتے ہیں۔ بہت سے ڈیٹا بیس پروگراموں کے برعکس ایکسیس ڈیٹا بیس ڈیٹا بیس ایپلیکیشن بنانے والے تمام آبجیکٹس کو .mdb فائل نام ایکسٹینشن والی ایک ہی فائل میں رکھ سکتا ہے۔ اسی وجہ سے ایکسیس ڈیٹا بیس فائل کو کبھی کبھی ڈیٹا بیس کنٹینر کہا جاتا ہے۔ || مایکروسافټ اېکسېس، چې مایکروسافټ آفس اېکسېس هم ورته ویل کېږي، یو ډېټابېس مدیریت سیسټم دی. ۸.۱ انځور د MS Access 2007 اصلي سکرین ښيي. د Access ډېټابېس د ډېټابېس د څیزونو ټولګه ده یعنې جدولونه، پوښتنې، فورمونه، راپورونه، میکروګانې او ماډلونه. کاروونکي کولای شي د خپلو ډېټابېسونو سره د کار لپاره نوي څیزونه ډیزاین کړي یا موجود څیزونه پرانیزي. د ډیرو ډېټابېس پروګرامونو برعکس، د Access ډېټابېس کولای شي ټول هغه څیزونه چې د ډېټابېس اپلېکېشن جوړوي په یوه فایل کې د .mdb فایل نوم پراخوالي سره ولري. د دې لپاره د Access ډېټابېس فایل ته ځینې وخت د ډېټابېس کانټینر ویل کېږي.
