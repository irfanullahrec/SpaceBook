p Level 1 cache is built into the actual processor core. It is a piece of high speed memory, which operates at the same speed as the CPU. It is directly accessed by the computer’s processor and holds data that the processor needs to execute instructions. It is the fastest memory and closest to the CPU but very expensive and small in size (typically 8, 16, 20, 32, 64 or 128 Kbytes). || لیول ۱ کیش اصل پراسیسر کور میں بنی ہوتی ہے۔ یہ تیز رفتار میموری کا ایک ٹکڑا ہے جو سی پی یو کی رفتار پر ہی کام کرتا ہے۔ کمپیوٹر کا پراسیسر اس تک براہِ راست رسائی حاصل کرتا ہے اور اس میں وہ ڈیٹا ہوتا ہے جو پراسیسر کو ہدایات چلانے کے لیے درکار ہوتا ہے۔ یہ سب سے تیز میموری ہے اور سی پی یو کے سب سے قریب ہے لیکن بہت مہنگی اور سائز میں چھوٹی ہے (عموماً ۸، ۱۶، ۲۰، ۳۲، ۶۴ یا ۱۲۸ کلو بائٹس)۔ || ۱ کچې کېش د پروسیسر په اصلي کور کې جوړه شوې ده. دا د لوړ ګړندیتوب حافظې یوه ټوټه ده چې د CPU په ګړندیتوب کار کوي. د کمپیوټر پروسیسر ورته مستقیم لاسرسی لري او هغه ډېټا لري چې پروسیسر ته د لارښوونو د چلولو لپاره پکار وي. دا تر ټولو ګړندۍ حافظه ده او CPU ته تر ټولو نژدې خو ډیره ګرانه او په کچه کوچنۍ ده (معمولاً ۸، ۱۶، ۲۰، ۳۲، ۶۴ یا ۱۲۸ کیلوبایټه).
## L2 cache || ایل ۲ کیش || L2 کېش
p Level 2 cache pulls information from the system’s main memory (RAM), which is then accessed by the L1 cache. It is reasonably fast memory, bigger in size and less expensive than L1 cache. It is normally 64 KB to 16 MB. The purpose of the L2 cache is to constantly read in slightly larger quantities of data from RAM, so that these are available to the L1 cache. || لیول ۲ کیش سسٹم کی مین میموری (ریم) سے معلومات کھینچتی ہے جس تک پھر ایل ۱ کیش رسائی حاصل کرتی ہے۔ یہ مناسب حد تک تیز میموری ہے، سائز میں بڑی اور ایل ۱ کیش سے کم مہنگی۔ یہ عموماً ۶۴ کے بی سے ۱۶ ایم بی تک ہوتی ہے۔ ایل ۲ کیش کا مقصد ریم سے قدرے بڑی مقدار میں ڈیٹا مسلسل پڑھنا ہے تاکہ وہ ایل ۱ کیش کے لیے دستیاب ہو۔ || ۲ کچې کېش د سیسټم له اصلي حافظې (RAM) نه معلومات راکاږي چې بیا L1 کېش ورته لاسرسی موندي. دا مناسبه ګړندۍ حافظه ده، په کچه لویه او له L1 کېش نه لږ ګرانه. دا معمولاً ۶۴ KB نه تر ۱۶ MB پورې ده. د L2 کېش موخه دا ده چې له RAM نه یو څه لوی مقدار ډېټا په دوامداره توګه ولولي ترڅو هغه L1 کېش ته شته وي.

## L3 cache || ایل ۳ کیش || L3 کېش
p Level 3 cache is specialized memory that works hand-in-hand with L1 and L2 cache to improve computer performance. L3 cache is the biggest cache || لیول ۳ کیش ایک خصوصی میموری ہے جو کمپیوٹر کی کارکردگی بہتر بنانے کے لیے ایل ۱ اور ایل ۲ کیش کے ساتھ مل کر کام کرتی ہے۔ ایل ۳ کیش سب سے بڑی کیش || ۳ کچې کېش یوه ځانګړې حافظه ده چې د کمپیوټر د فعالیت ښه کولو لپاره له L1 او L2 کېش سره لاس په لاس کار کوي.
