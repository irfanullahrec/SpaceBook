## Layer 6: PRESENTATION LAYER || تہہ ۶: پریزنٹیشن لیئر || طبقه ۶: د وړاندې کولو طبقه
p The presentation layer converts incoming and outgoing data from one presentation format to another (for example, from a text stream into a popup window with the newly arrived text). The presentation layer is sometimes called as the syntax layer. It can be viewed as the translator for the network. The presentation layer provides the following functions. || پریزنٹیشن لیئر آنے والے اور جانے والے ڈیٹا کو ایک پیشکش کی شکل سے دوسری میں تبدیل کرتی ہے (مثلاً متن کے دھارے سے نئے آنے والے متن کے ساتھ پاپ اپ ونڈو میں)۔ پریزنٹیشن لیئر کو کبھی کبھی سنٹیکس لیئر بھی کہتے ہیں۔ اسے نیٹ ورک کے مترجم کے طور پر دیکھا جا سکتا ہے۔ پریزنٹیشن لیئر درج ذیل افعال فراہم کرتی ہے۔ || د وړاندې کولو طبقه راتلونکې او وتونکې ډېټا له یوې وړاندې کولو بڼې نه بلې ته بدلوي (د بېلګې په توګه له متن جریان نه د نوي راغلي متن سره په پاپ اپ کړکۍ). د وړاندې کولو طبقې ته ځینې وخت د ترکیب طبقه هم ویل کېږي. دا د شبکې د ژباړونکي په توګه کتل کېدای شي. د وړاندې کولو طبقه لاندې دندې برابروي.
p Character code translation: for example, ASCII to EBCDIC. || کریکٹر کوڈ کا ترجمہ: مثلاً اسکی سے ای بی سی ڈی آئی سی۔ || د توري کوډ ژباړه: د بېلګې په توګه ASCII نه EBCDIC ته.
p Data compression: reduces the number of bits that need to be transmitted on the network. || ڈیٹا کمپریشن: ان بٹس کی تعداد کم کرتا ہے جنہیں نیٹ ورک پر منتقل کرنا پڑتا ہے۔ || د ډېټا فشار: د هغو بټونو شمېر کموي چې په شبکه باید ولېږدول شي.
p Data encryption: encrypt data for security purposes. For example, password encryption. || ڈیٹا انکرپشن: سیکیورٹی کے مقاصد کے لیے ڈیٹا کو خفیہ کرنا۔ مثلاً پاس ورڈ انکرپشن۔ || د ډېټا کوډ کول: د امنیت موخو لپاره ډېټا کوډ کول. د بېلګې په توګه د پټنوم کوډ کول.
p Specifies architecture-independent data transfer format. || تعمیر سے آزاد ڈیٹا منتقلی کی شکل متعین کرتی ہے۔ || د جوړښت نه خپلواک د ډېټا د لېږد بڼه ټاکي.
## Layer 7: APPLICATION LAYER || تہہ ۷: ایپلیکیشن لیئر || طبقه ۷: د اپلېکېشن طبقه
p The application layer serves as the user interface for users and application processes to access network services. The application layer is responsible for displaying data and images to the user in a human-recognizable format. It provides an interface with the presentation layer. Everything at this layer is application-specific. This layer performs the following functions. || ایپلیکیشن لیئر صارفین اور ایپلیکیشن پروسیسز کے لیے نیٹ ورک خدمات تک رسائی کے صارف انٹرفیس کا کام کرتی ہے۔ ایپلیکیشن لیئر صارف کو ڈیٹا اور تصاویر انسان کے پہچاننے کے قابل شکل میں دکھانے کی ذمہ دار ہے۔ یہ پریزنٹیشن لیئر کے ساتھ انٹرفیس فراہم کرتی ہے۔ اس تہہ پر ہر چیز ایپلیکیشن کے لیے مخصوص ہے۔ یہ تہہ درج ذیل افعال انجام دیتی ہے۔ || د اپلېکېشن طبقه د کاروونکو او اپلېکېشن پروسو لپاره د شبکې خدمتونو ته د لاسرسي د کاروونکي انټرفیس په توګه کار کوي. د اپلېکېشن طبقه کاروونکي ته د ډېټا او انځورونو د انسان د پېژندلو وړ بڼه کې د ښودلو مسؤله ده. دا د وړاندې کولو طبقې سره انټرفیس برابروي. پدې طبقه هر څه د اپلېکېشن ځانګړي دي. دا طبقه لاندې دندې ترسره کوي.
p Resource sharing || وسائل کا اشتراک || د سرچینو ګډون
p Remote file access || دور دراز فائل رسائی || د لیرې فایل لاسرسی
p Network management || نیٹ ورک انتظام || د شبکې مدیریت
p Directory services || ڈائریکٹری خدمات || د لارښود خدمتونه
p Electronic messaging (such as e-mail) || برقی پیغام رسانی (جیسے ای میل) || برېښنايي پیغام لېږل (لکه برېښنالیک)
