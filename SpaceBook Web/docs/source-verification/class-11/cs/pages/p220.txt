p A database combines records previously stored in separate files into a shared pool of data records that provides data for many applications. The data stored in a database is independent of the application programs using it and the type of secondary storage devices on which it is stored. || ڈیٹا بیس پہلے الگ الگ فائلوں میں محفوظ ریکارڈز کو ڈیٹا ریکارڈز کے مشترکہ ذخیرے میں یکجا کرتا ہے جو بہت سی ایپلیکیشنز کو ڈیٹا فراہم کرتا ہے۔ ڈیٹا بیس میں محفوظ ڈیٹا اسے استعمال کرنے والے ایپلیکیشن پروگراموں اور اس ثانوی ذخیرہ آلات کی قسم سے آزاد ہوتا ہے جن پر وہ محفوظ ہے۔ || ډېټابېس هغه ثبتونه چې مخکې په جلا فایلونو کې ساتل کېدل د ډېټا ثبتونو په ګډ ذخیره کې یوځای کوي چې ډیرو اپلېکېشنونو ته ډېټا برابروي. په ډېټابېس کې ساتل شوې ډېټا د هغو اپلېکېشن پروګرامونو چې یې کاروي او د ثانوي ذخیره وسایلو ډول چې په هغو ساتل کېږي خپلواکه ده.
## 7.1.4 Database Management System (DBMS) || ۷.۱.۴ ڈیٹا بیس مینجمنٹ سسٹم (ڈی بی ایم ایس) || ۷.۱.۴ د ډېټابېس مدیریت سیسټم (DBMS)
p A database management system (DBMS) is a set of programs that allow users to create, maintain and manipulate database, and store or retrieve data from those database files. Manipulation of data includes the following. || ڈیٹا بیس مینجمنٹ سسٹم (ڈی بی ایم ایس) پروگراموں کا ایک مجموعہ ہے جو صارفین کو ڈیٹا بیس بنانے، برقرار رکھنے اور اس میں ترمیم کرنے، اور ان ڈیٹا بیس فائلوں سے ڈیٹا محفوظ یا حاصل کرنے کی اجازت دیتا ہے۔ ڈیٹا میں ترمیم میں درج ذیل شامل ہیں۔ || د ډېټابېس مدیریت سیسټم (DBMS) د پروګرامونو یوه ټولګه ده چې کاروونکو ته اجازه ورکوي ډېټابېس جوړ کړي، وساتي او ترې کار واخلي، او له هغو ډېټابېس فایلونو نه ډېټا ذخیره یا ترلاسه کړي. د ډېټا کارونه لاندې شاملوي.
p Adding new data, for example adding details of new student. || نیا ڈیٹا شامل کرنا، مثلاً نئے طالب علم کی تفصیلات شامل کرنا۔ || نوې ډېټا زیاتول، د بېلګې په توګه د نوي زده کوونکي تفصیلات زیاتول.
p Deleting unwanted data, for example deleting the details of students who have completed course. || غیر ضروری ڈیٹا حذف کرنا، مثلاً ان طلبہ کی تفصیلات حذف کرنا جنہوں نے کورس مکمل کر لیا ہو۔ || غیر اړین ډېټا حذف کول، د بېلګې په توګه د هغو زده کوونکو تفصیلات حذف کول چې کورس یې بشپړ کړی.
p Changing existing data, for example modifying the fee paid by the student. || موجودہ ڈیٹا میں تبدیلی کرنا، مثلاً طالب علم کی ادا کردہ فیس میں ترمیم کرنا۔ || موجوده ډېټا بدلول، د بېلګې په توګه د زده کوونکي لخوا ورکړل شوې فیس تعدیل کول.
p The DBMS helps to create an environment in which users have better access to data. DBMS helps to give an integrated view of the organization’s operations. The DBMS makes it possible to share the data in the database among multiple applications and users. || ڈی بی ایم ایس ایسا ماحول بنانے میں مدد دیتا ہے جس میں صارفین کو ڈیٹا تک بہتر رسائی حاصل ہو۔ ڈی بی ایم ایس ادارے کے عمل کا مربوط منظر دینے میں مدد دیتا ہے۔ ڈی بی ایم ایس ڈیٹا بیس میں موجود ڈیٹا کو متعدد ایپلیکیشنز اور صارفین کے درمیان شیئر کرنا ممکن بناتا ہے۔ || DBMS داسې چاپېریال جوړولو کې مرسته کوي چې په هغه کې کاروونکي ډېټا ته ښه لاسرسی لري. DBMS د ادارې د عملیاتو یو مدغم لید ورکولو کې مرسته کوي. DBMS دا ممکنه کوي چې په ډېټابېس کې ډېټا د ډیرو اپلېکېشنونو او کاروونکو ترمنځ ګډه شي.
p The following are few examples of the database systems, managed by DBMS. || درج ذیل ڈیٹا بیس سسٹمز کی چند مثالیں ہیں جو ڈی بی ایم ایس کے زیر انتظام ہیں۔ || لاندې د ډېټابېس سیسټمونو څو بېلګې دي چې د DBMS لخوا اداره کېږي.

p Typical DBMS include Microsoft Access, Microsoft SQL Server, Sybase, IBM DB2, Oracle, Ingres and MySQL. || عام ڈی بی ایم ایس میں مائیکروسافٹ ایکسیس، مائیکروسافٹ ایس کیو ایل سرور، سائی بیس، آئی بی ایم ڈی بی ٹو، اوریکل، انگریس اور مائی ایس کیو ایل شامل ہیں۔ || عادي DBMS مایکروسافټ اېکسېس، مایکروسافټ SQL سرور، سایبېس، IBM DB2، اوریکل، انګریس او MySQL شاملوي.
