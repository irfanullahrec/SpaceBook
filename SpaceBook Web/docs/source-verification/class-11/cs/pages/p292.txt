## a. Select Query || الف۔ سلیکٹ کوئری || الف. د Select پوښتنه
p A select query is a type of database object that shows information in Datasheet view. A query can get its data from one or more tables, from existing queries, or from a combination of the two. The tables or queries from which a query gets its data are referred to as its record-source. || سلیکٹ کوئری ڈیٹا بیس آبجیکٹ کی ایک قسم ہے جو ڈیٹا شیٹ ویو میں معلومات دکھاتی ہے۔ کوئری اپنا ڈیٹا ایک یا زیادہ ٹیبلز، موجودہ کوئریز یا ان دونوں کے امتزاج سے حاصل کر سکتی ہے۔ وہ ٹیبلز یا کوئریز جن سے کوئری اپنا ڈیٹا حاصل کرتی ہے اس کا ریکارڈ سورس کہلاتے ہیں۔ || د Select پوښتنه د ډېټابېس د څیز یو ډول دی چې په ډېټا شیټ لید کې معلومات ښيي. پوښتنه کولای شي خپله ډېټا له یو یا ډیرو جدولونو، موجودو پوښتنو، یا د دواړو له ګډون نه ترلاسه کړي. هغه جدولونه یا پوښتنې چې پوښتنه ترې خپله ډېټا اخلي د هغې د ثبت سرچینې په توګه یادېږي.
## Basic steps to create a select query: || سلیکٹ کوئری بنانے کے بنیادی اقدامات: || د Select پوښتنې د جوړولو بنسټیز ګامونه:
p User can create a select query by using the Query Wizard or by working in Design view. Some design elements are not available when users use the wizard, but user can add these elements later by using Design view. Although the two methods are somewhat different from each other, the basic steps are essentially the same. || صارف سلیکٹ کوئری کوئری ویزرڈ استعمال کر کے یا ڈیزائن ویو میں کام کر کے بنا سکتا ہے۔ ویزرڈ استعمال کرتے وقت کچھ ڈیزائن عناصر دستیاب نہیں ہوتے لیکن صارف انہیں بعد میں ڈیزائن ویو کے ذریعے شامل کر سکتا ہے۔ اگرچہ دونوں طریقے ایک دوسرے سے کچھ مختلف ہیں، بنیادی اقدامات بنیادی طور پر ایک جیسے ہیں۔ || کاروونکی کولای شي د Select پوښتنه د Query Wizard په کارولو یا په ډیزاین لید کې د کار کولو په واسطه جوړه کړي. کله چې کاروونکي مرستندوی کاروي نو ځینې ډیزاین عناصر شته نه وي، خو کاروونکی کولای شي دا عناصر وروسته د ډیزاین لید په کارولو زیات کړي. که څه هم دواړه لارې یو له بل نه یو څه توپیر لري، بنسټیز ګامونه په اصل کې ورته دي.
p Choose the tables or queries that to use as sources of data. || وہ ٹیبلز یا کوئریز منتخب کریں جنہیں ڈیٹا کے ماخذ کے طور پر استعمال کرنا ہو۔ || هغه جدولونه یا پوښتنې وټاکئ چې د ډېټا د سرچینو په توګه کارول کېږي.
p Specify the fields that user wants to include from the data sources. || وہ فیلڈز متعین کریں جنہیں صارف ڈیٹا ماخذ سے شامل کرنا چاہتا ہے۔ || هغه ساحې وټاکئ چې کاروونکی یې له ډېټا سرچینو نه شاملول غواړي.
p Optionally, specify criteria to limit the records that the query returns. || اختیاری طور پر ان ریکارڈز کو محدود کرنے کے لیے معیار متعین کریں جو کوئری واپس کرتی ہے۔ || اختیاري توګه، د هغو ثبتونو د محدودولو لپاره معیار وټاکئ چې پوښتنه یې بېرته ورکوي.
p After user has created a select query, it can be run to see the results. || سلیکٹ کوئری بنانے کے بعد نتائج دیکھنے کے لیے اسے چلایا جا سکتا ہے۔ || وروسته له دې چې کاروونکي د Select پوښتنه جوړه کړه، دا د پایلو د کتلو لپاره چلېدای شي.
## b. Update Query || ب۔ اپ ڈیٹ کوئری || ب. د Update پوښتنه
p An Update Query is an action query (SQL statement) that changes a set of records according to criteria (search conditions) user specify. It is a very powerful feature and a fundamental part of relational databases since the user can modify a huge number of records at one time. Understanding and using Update Queries improves the performance of applications (versus doing the same changes manually or in code), and makes them easier to maintain. || اپ ڈیٹ کوئری ایک ایکشن کوئری (ایس کیو ایل اسٹیٹمنٹ) ہے جو صارف کے متعین کردہ معیار (تلاش کی شرائط) کے مطابق ریکارڈز کے ایک مجموعے کو تبدیل کرتی ہے۔ یہ ایک بہت طاقتور خصوصیت اور ریلیشنل ڈیٹا بیسز کا بنیادی حصہ ہے کیونکہ صارف ایک وقت میں بہت بڑی تعداد میں ریکارڈز میں ترمیم کر سکتا ہے۔ اپ ڈیٹ کوئریز کو سمجھنا اور استعمال کرنا ایپلیکیشنز کی کارکردگی بہتر بناتا ہے (بمقابلہ وہی تبدیلیاں ہاتھ سے یا کوڈ میں کرنے کے) اور انہیں برقرار رکھنا آسان بناتا ہے۔ || د Update پوښتنه یوه کړنې پوښتنه (SQL بیان) ده چې د ثبتونو یوه ټولګه د هغه معیار (د لټون شرطونو) سره سم بدلوي چې کاروونکی یې ټاکي. دا یوه ډیره پیاوړې ځانګړتیا او د اړوندو ډېټابېسونو بنسټیزه برخه ده ځکه چې کاروونکی کولای شي په یو وخت کې ډیر لوی شمېر ثبتونه تعدیل کړي. د Update پوښتنو پوهېدل او کارول د اپلېکېشنونو فعالیت ښه کوي (د همدغو بدلونونو لاسي یا په کوډ کې د کولو په پرتله) او ساتنه یې اسانوي.
