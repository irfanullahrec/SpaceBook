p The counter register acts as a counter for repeating or looping instructions. || کاؤنٹر رجسٹر ہدایات کو دہرانے یا لوپ کرنے کے لیے کاؤنٹر کے طور پر کام کرتا ہے۔ || شمېرونکی رجستر د لارښوونو د تکرار یا ګرځېدو لپاره د شمېرونکي په توګه کار کوي.
p Data register has a special role in multiply and divide operations. It works like a buffer and holds anything that is copied from the memory ready for the processor to use it. || ڈیٹا رجسٹر کا ضرب اور تقسیم کے اعمال میں خاص کردار ہے۔ یہ بفر کی طرح کام کرتا ہے اور میموری سے نقل شدہ ہر چیز رکھتا ہے جو پراسیسر کے استعمال کے لیے تیار ہو۔ || د ډېټا رجستر په ضرب او تقسیم عملونو کې ځانګړی کردار لري. دا د بفر په څېر کار کوي او هر هغه څه ساتي چې له حافظې نه کاپي شوي وي ترڅو پروسیسر یې وکاروي.
p Special purpose registers are used to hold the state of a program. They include program counter, instruction register, memory address register and memory buffer registers. || خصوصی مقصد کے رجسٹرز پروگرام کی حالت رکھنے کے لیے استعمال ہوتے ہیں۔ ان میں پروگرام کاؤنٹر، انسٹرکشن رجسٹر، میموری ایڈریس رجسٹر اور میموری بفر رجسٹرز شامل ہیں۔ || د ځانګړې موخې رجسترونه د یو پروګرام د حالت ساتلو لپاره کارول کېږي. په هغو کې پروګرام شمېرونکی، د لارښوونې رجستر، د حافظې د پتې رجستر او د حافظې د بفر رجسترونه شامل دي.
p Instruction register is a part of control unit, which stores the instructions currently being executed. || انسٹرکشن رجسٹر کنٹرول یونٹ کا ایک حصہ ہے جو اس وقت چلائی جانے والی ہدایات محفوظ کرتا ہے۔ || د لارښوونې رجستر د کنټرول واحد یوه برخه ده چې اوس مهال پلي کېدونکې لارښوونې ساتي.
p Memory address register holds the memory address, the memory address from which data will be provided to the CPU or will have the address to which data will be sent and then stored. || میموری ایڈریس رجسٹر میموری کا پتہ رکھتا ہے، وہ میموری پتہ جس سے ڈیٹا سی پی یو کو فراہم کیا جائے گا یا اس پتے کو رکھے گا جس پر ڈیٹا بھیجا اور پھر محفوظ کیا جائے گا۔ || د حافظې د پتې رجستر د حافظې پته ساتي، هغه د حافظې پته چې له هغې نه ډېټا CPU ته برابرېږي یا هغه پته به ولري چې ډېټا ورته لېږل کېږي او بیا ساتل کېږي.
p Memory buffer register holds the contents of the memory which are to be moved from memory to other components or from components to the memory. || میموری بفر رجسٹر میموری کے وہ مندرجات رکھتا ہے جو میموری سے دیگر اجزاء کی طرف یا اجزاء سے میموری کی طرف منتقل کیے جانے ہوں۔ || د حافظې د بفر رجستر د حافظې هغه منځپانګه ساتي چې له حافظې نه نورو اجزاوو ته یا له اجزاوو نه حافظې ته لېږدول کېږي.
p Program counter is also known as instruction pointer, it is a processor register that holds either the address of the instruction being executed or the address of the next instruction to be executed. || پروگرام کاؤنٹر کو انسٹرکشن پوائنٹر بھی کہا جاتا ہے، یہ ایک پراسیسر رجسٹر ہے جو یا تو چلائی جانے والی ہدایت کا پتہ رکھتا ہے یا اگلی چلائی جانے والی ہدایت کا پتہ۔ || پروګرام شمېرونکی ته د لارښوونې اشاره کوونکی هم ویل کېږي، دا د پروسیسر یو رجستر دی چې یا د پلي کېدونکې لارښوونې پته ساتي یا د راتلونکې پلي کېدونکې لارښوونې پته.
p Data bus is the bidirectional bus. It can communicate in two ways, but in one direction at a time. || ڈیٹا بس دو طرفہ بس ہے۔ یہ دو طریقوں سے رابطہ کر سکتی ہے لیکن ایک وقت میں ایک سمت میں۔ || د ډېټا بس دوه لورې بس دی. دا په دوو لارو اړیکه نیولای شي، خو په یو وخت کې په یو لوري.
p Address bus carries addresses not data. || ایڈریس بس پتے لے جاتی ہے، ڈیٹا نہیں۔ || د پتې بس پتې وړي، ډېټا نه.
