p Computer software is a step by step set of instructions that directs the computer what to do and how to do. It turns the data into information - that makes a computer useful. || کمپیوٹر سافٹ ویئر مرحلہ وار ہدایات کا مجموعہ ہے جو کمپیوٹر کو بتاتا ہے کہ کیا کرنا ہے اور کیسے کرنا ہے۔ یہ ڈیٹا کو معلومات میں بدل دیتا ہے - جو کمپیوٹر کو مفید بناتا ہے۔ || د کمپیوټر سافټویر د لارښوونو یوه ګام په ګام ټولګه ده چې کمپیوټر ته وايي څه وکړي او څنګه یې وکړي. دا ډېټا په معلوماتو بدلوي - چې کمپیوټر ګټور کوي.
p System software are set of programs that operate and control the computer system. || سسٹم سافٹ ویئر پروگراموں کا وہ مجموعہ ہے جو کمپیوٹر سسٹم کو چلاتا اور کنٹرول کرتا ہے۔ || سیسټم سافټویر د پروګرامونو هغه ټولګه ده چې د کمپیوټر سیسټم چالانوي او کنټرولوي.
p Application software is a type of software that can be used for a variety of tasks according to the user requirements. || ایپلیکیشن سافٹ ویئر ایک قسم کا سافٹ ویئر ہے جو صارف کی ضروریات کے مطابق مختلف کاموں کے لیے استعمال ہو سکتا ہے۔ || اپلیکېشن سافټویر د سافټویر یو ډول دی چې د کاروونکي د اړتیاوو مطابق د مختلفو کارونو لپاره کارول کېدای شي.
p Operating system is a set of programs that manages and coordinates the hardware of a computer and provides services to application software, programmers and users of computer. || آپریٹنگ سسٹم پروگراموں کا وہ مجموعہ ہے جو کمپیوٹر کے ہارڈ ویئر کا انتظام اور ہم آہنگی کرتا ہے اور ایپلیکیشن سافٹ ویئر، پروگرامرز اور کمپیوٹر صارفین کو خدمات فراہم کرتا ہے۔ || عملیاتي سیسټم د پروګرامونو هغه ټولګه ده چې د کمپیوټر هارډویر اداره او همغږی کوي او اپلیکېشن سافټویر، پروګرامرانو او د کمپیوټر کاروونکو ته خدمتونه برابروي.
p A device driver is a program that controls a particular type of device that is attached to the computer. || ڈیوائس ڈرائیور ایک پروگرام ہے جو کمپیوٹر سے منسلک ایک خاص قسم کے آلے کو کنٹرول کرتا ہے۔ || د وسیلې چلوونکی یو پروګرام دی چې د کمپیوټر سره وصل یو ځانګړی ډول وسیله کنټرولوي.
p Utility software is a kind of system software designed to analyze, configure, optimize and maintain the computer. || یوٹیلٹی سافٹ ویئر سسٹم سافٹ ویئر کی ایک قسم ہے جو کمپیوٹر کا تجزیہ، ترتیب، بہتری اور دیکھ بھال کرنے کے لیے بنایا گیا ہے۔ || ګټور سافټویر د سیسټم سافټویر یو ډول دی چې د کمپیوټر د تحلیل، تنظیم، ښه کولو او ساتنې لپاره جوړ شوی.
p Language processor or translator is a type of system software that translates a source program (other than machine language) into object program (Machine language). || لینگوئج پراسیسر یا مترجم سسٹم سافٹ ویئر کی ایک قسم ہے جو سورس پروگرام (مشین زبان کے علاوہ) کو آبجیکٹ پروگرام (مشین زبان) میں ترجمہ کرتا ہے۔ || د ژبې پروسیسر یا ژباړن د سیسټم سافټویر یو ډول دی چې یو سرچینه پروګرام (له ماشین ژبې پرته) د هدف پروګرام (ماشین ژبه) ته ژباړي.
p General-purpose applications software are programs that perform common information processing jobs for end users. || عمومی مقصد کے ایپلیکیشنز سافٹ ویئر وہ پروگرام ہیں جو آخری صارفین کے لیے عام معلوماتی پراسیسنگ کے کام انجام دیتے ہیں۔ || عمومي موخې اپلیکېشن سافټویر هغه پروګرامونه دي چې د پای کاروونکو لپاره عام معلوماتي پروسس کارونه ترسره کوي.
p The software that is designed to perform a specific task is known as special purpose application software. || وہ سافٹ ویئر جو ایک مخصوص کام انجام دینے کے لیے بنایا گیا ہو خصوصی مقصد کا ایپلیکیشن سافٹ ویئر کہلاتا ہے۔ || هغه سافټویر چې د یو ځانګړي کار د ترسره کولو لپاره جوړ شوی وي د ځانګړې موخې اپلیکېشن سافټویر په نوم پېژندل کېږي.
p The productivity software is a type of application software that are used to produce documents, presentations, databases, charts and graphs. || پروڈکٹیویٹی سافٹ ویئر ایپلیکیشن سافٹ ویئر کی ایک قسم ہے جو دستاویزات، پریزنٹیشنز، ڈیٹا بیس، چارٹس اور گراف بنانے کے لیے استعمال ہوتی ہے۔ || تولیدي سافټویر د اپلیکېشن سافټویر یو ډول دی چې د اسنادو، وړاندیزونو، ډېټابېسونو، چارټونو او ګرافونو جوړولو لپاره کارول کېږي.
p Licensed or Proprietary Software is a computer software that is licensed, giving the right to use the software under certain conditions, but restricted from other uses, such as modification, further distribution and re-building under exclusive legal right of the copyright holder. || لائسنس یافتہ یا ملکیتی سافٹ ویئر ایک کمپیوٹر سافٹ ویئر ہے جو لائسنس یافتہ ہو، جو کچھ شرائط کے تحت سافٹ ویئر استعمال کرنے کا حق دیتا ہے لیکن دیگر استعمالات، جیسے ترمیم، مزید تقسیم اور دوبارہ تعمیر، کاپی رائٹ ہولڈر کے خصوصی قانونی حق کے تحت ممنوع ہوتے ہیں۔ || جواز لرونکی یا ملکیتي سافټویر یو کمپیوټر سافټویر دی چې جواز لري، د ځانګړو شرطونو لاندې د سافټویر د کارولو حق ورکوي خو نور کارونې، لکه تعدیل، نور ویش او بیا جوړول، د کاپي رایټ خاوند د ځانګړي قانوني حق لاندې بندې وي.
p Open Source Software is computer software of which source code is also available to the user. || اوپن سورس سافٹ ویئر وہ کمپیوٹر سافٹ ویئر ہے جس کا سورس کوڈ بھی صارف کو دستیاب ہو۔ || پرانیستې سرچینې سافټویر هغه کمپیوټر سافټویر دی چې سرچینه کوډ یې هم کاروونکي ته شته.
p Shareware is also called trial-ware and refers to licensed software that is delivered to the user without payment for trial uses with limited functionality and for a specific period after which it expires. || شیئر ویئر کو ٹرائل ویئر بھی کہا جاتا ہے اور اس سے مراد وہ لائسنس یافتہ سافٹ ویئر ہے جو محدود فعالیت کے ساتھ اور ایک مخصوص مدت کے لیے آزمائشی استعمال کے لیے بغیر ادائیگی کے صارف کو دیا جاتا ہے جس کے بعد یہ ختم ہو جاتا ہے۔ || شیئرویر ته ټرایل ویر هم ویل کېږي او هغه جواز لرونکي سافټویر ته ویل کېږي چې د ازموینې کارونې لپاره د محدودې فعالیت سره او د ټاکلې مودې لپاره پرته له تادیې کاروونکي ته ورکول کېږي چې وروسته یې پای ته رسېږي.
