q  | Q2. Give short answers to the following questions. || سوال ۲: درج ذیل سوالات کے مختصر جواب دیں۔ || ۲ پوښتنه: د لاندې پوښتنو لنډ ځوابونه ورکړئ.
qp i | What is computer memory? || کمپیوٹر میموری کیا ہے؟ || د کمپیوټر حافظه څه ده؟
sol Model answer: Computer memory is the part of the computer that stores data, instructions and results, either temporarily or permanently, so that the processor can use them. It consists of primary memory (RAM, ROM, cache and registers) and secondary storage (hard disk, optical disc, flash). ## Unit 2 introduction.
qp ii | Define bit, byte and memory word. || بٹ، بائٹ اور میموری ورڈ کی تعریف کریں۔ || بټ، بایټ او د حافظې کلمه تعریف کړئ.
sol Model answer: Bit: the smallest unit of data in a computer; it is a binary digit, 0 or 1. Byte: a group of 8 bits; it stores one character (a letter, digit or symbol). Memory word: the number of bits (for example 16, 32 or 64) that the computer handles or transfers as one unit at a time; it is the natural unit of data for the processor. ## Unit 2 memory units.
qp iii | What is the importance of cache memory in a computer? || کمپیوٹر میں کیش میموری کی کیا اہمیت ہے؟ || په کمپیوټر کې د کېش حافظې څه اهمیت دی؟
sol Model answer: Cache memory is a small, very fast memory between the CPU and the main memory (RAM). It keeps copies of the data and instructions that the CPU uses most often, so the CPU does not have to wait for the slower RAM. This increases the overall speed of the computer. Cache comes in levels L1 (inside the processor, fastest), L2 and L3. ## Unit 2 cache memory.
qp iv | Give some uses of secondary memory. || ثانوی میموری کے کچھ استعمالات بتائیں۔ || د دویمي حافظې ځینې کارونې ووایئ.
sol Model answer: Secondary memory is used to store data and programs permanently (long term) for later use; to keep the operating system and installed software; to keep backup copies of important files; to move or share data between computers (flash drive, DVD); and to hold data that is too large for primary memory. Examples: hard disk, SSD, CD/DVD, flash drive. ## Unit 2 secondary storage.
qp v | What is the role of registers in computer? || کمپیوٹر میں رجسٹرز کا کیا کردار ہے؟ || په کمپیوټر کې د رجسترونو څه کردار دی؟
sol Model answer: Registers are small, extremely fast memory locations inside the CPU. They temporarily hold the data, instructions and addresses that the CPU is working on at that moment, for example the accumulator, program counter, instruction register and memory address/buffer registers. Because the CPU reads them directly, they make processing fast. ## Unit 2 processor memory and Unit 3 registers.
qp vi | Differentiate between DRAM and SRAM. || ڈی ریم اور ایس ریم میں فرق کریں۔ || د DRAM او SRAM ترمنځ توپیر وکړئ.
sol Model answer: DRAM (dynamic RAM) stores each bit in a capacitor that leaks, so it must be refreshed again and again; it is slower, cheaper, needs less space and is used as main memory. SRAM (static RAM) stores each bit in a flip-flop (transistors), needs no refreshing, is faster, more expensive and bigger in area, and is used for cache memory. ## Unit 2 types of RAM.
qp vii | Give few characteristics of secondary storage devices. || ثانوی ذخیرہ آلات کی کچھ خصوصیات بیان کریں۔ || د دویمي ذخیرې د وسایلو ځینې ځانګړتیاوې ووایئ.
sol Model answer: Characteristics of secondary storage devices: (1) Non-volatile: data stays when power is off. (2) Large capacity (gigabytes and terabytes). (3) Low cost per byte. (4) Slower than primary memory. (5) Not directly accessed by the CPU; data is first loaded into RAM. (6) Some are portable (flash, DVD) and can be removed from the computer. ## Unit 2 secondary storage.
qp viii | Differentiate between the following. || درج ذیل میں فرق کریں۔ || د لاندې ترمنځ توپیر وکړئ.
sol Model answer: This question has parts (a) Chip memory and Magnetic memory, (b) Cache and Register, (d) Magnetic tapes and Magnetic disks, (e) EPROM and EEPROM (the book prints the letters a, b, d, e). Each part has its own answer under its own question. ## Heading of a multi-part question.
qp • | a) Chip memory and Magnetic memory || a) چپ میموری اور مقناطیسی میموری || a) چپ حافظه او مقناطیسي حافظه
sol Model answer: Chip memory is made of silicon chips (RAM, ROM, flash); it has no moving parts, is very fast and uses electronic signals. Magnetic memory (hard disk, tape) stores data as magnetised spots on a coated surface; it has moving parts, is slower, but has a much larger capacity at a lower cost. ## Unit 2 memory types.
qp • | b) Cache and Register || b) کیش اور رجسٹر || b) کېش او رجستر
sol Model answer: A register is a very small memory inside the CPU that holds the data or address being processed right now; it is the fastest memory and has a capacity of a few bits to bytes. Cache is a larger (kilobytes to megabytes) fast memory between the CPU and RAM that holds frequently used data and instructions; it is a little slower than registers. ## Unit 2 cache and registers.
qp c | Volatile and non-volatile memory || غیر مستقل اور مستقل میموری || بې ثباته او ثابته حافظه
qp • | d) Magnetic tapes and Magnetic disks || d) مقناطیسی ٹیپس اور مقناطیسی ڈسکس || d) مقناطیسي ټیپونه او مقناطیسي ډیسکونه
sol Model answer: Magnetic tape stores data sequentially on a long plastic tape; to read some data one has to wind the tape to its place, so it is slow, but it is cheap and good for backup and archives. Magnetic disk (hard disk, floppy) stores data on round platters and allows direct (random) access to any place, so it is much faster and used for everyday storage. ## Unit 2 sequential and random access devices.
qp • | e) EPROM and EEPROM || e) ای پی روم اور ای ای پی روم || e) EPROM او EEPROM
sol Model answer: EPROM (erasable programmable ROM) can be erased by exposing the chip to ultraviolet light, and is then reprogrammed; the whole chip is erased at once and the chip must be removed from the computer. EEPROM (electrically erasable programmable ROM) is erased and rewritten electrically, even a single byte at a time, without removing it from the circuit (used for BIOS and flash memory). ## Unit 2 types of ROM.
