qp i | What is a Computer? || کمپیوٹر کیا ہے؟ || کمپیوټر څه دی؟
sol Model answer: A computer is an electronic machine that accepts data as input, processes it by following a stored set of instructions (a program), stores the data and results, and gives out useful information as output. It works quickly and accurately and can repeat the same work any number of times. ## Definition of a computer from Unit 1.
qp ii | What is processing operation? || پراسیسنگ عمل کیا ہے؟ || د پروسس عمل څه دی؟
sol Model answer: Processing is the operation in which the computer's CPU works on the data that was entered: it performs arithmetic operations (add, subtract, multiply, divide) and logical operations (compare, AND, OR, NOT) according to the program, and turns raw data into information that can be stored or shown as output. ## Processing is one of the four basic operations of a computer (input, processing, output, storage).
qp iii | Show basic operations of a computer with the help of a block diagram. || بلاک ڈایاگرام کی مدد سے کمپیوٹر کے بنیادی عمل دکھائیں۔ || د بلاک ډیاګرام په مرسته د کمپیوټر بنسټیز عملونه وښيئ.
sol Model answer: Block diagram: INPUT UNIT (keyboard, mouse, scanner) sends data and instructions into the PROCESSING UNIT = CPU (Control Unit + Arithmetic Logic Unit), which works together with the STORAGE UNIT (primary memory and secondary storage) in both directions; the processed result goes from the CPU to the OUTPUT UNIT (monitor, printer, speaker). In short: Input → (CPU ↔ Memory/Storage) → Output; the control unit directs every unit. ## The picture itself has to be drawn from this description in the answer sheet.
qp iv | What is a notebook computer? || نوٹ بک کمپیوٹر کیا ہے؟ || نوټبک کمپیوټر څه دی؟
sol Model answer: A notebook computer is a small, light, battery-powered portable computer that is about the size of a paper notebook. It has a built-in screen, keyboard and touch pad, can run the same software as a desktop and can be carried and used anywhere. ## Portable computers are described in Unit 1 under classification by size.
qp v | State five differences between hardware and software. || ہارڈ ویئر اور سافٹ ویئر میں پانچ فرق بیان کریں۔ || د هارډویر او سافټویر ترمنځ پنځه توپیرونه بیان کړئ.
sol Model answer: Hardware vs software: (1) Hardware is the physical parts of the computer that can be touched; software is the set of programs and instructions that cannot be touched. (2) Hardware is made of electronic and mechanical parts; software is written in a programming language. (3) Hardware does not work without software; software cannot run without hardware. (4) Hardware can be damaged by dust, heat or shock; software is affected by viruses and bugs. (5) Hardware is repaired or replaced physically; software is repaired by reinstalling or updating it. Examples: keyboard, monitor, CPU (hardware); Windows, MS Word (software). ## Five differences; any five correct differences earn full marks.
qp vi | Differentiate between an Interpreter and a compiler. || انٹرپریٹر اور کمپائلر میں فرق کریں۔ || د تفسیرکوونکي او ترتیبوونکي ترمنځ توپیر وکړئ.
sol Model answer: Interpreter vs compiler: An interpreter translates and executes a program line by line, so it stops at the first error and no separate object file is made; it is slower in running. A compiler translates the whole source program into machine code at once, shows all errors together after compilation, makes an object file that can be run again without the compiler, and runs faster. Examples: Python (interpreter), C and C++ (compiler). ## Language processors are part of system software in Unit 1.
qp vii | How Application software help Users? || ایپلیکیشن سافٹ ویئر صارفین کی کیسے مدد کرتا ہے؟ || اپلیکېشن سافټویر کاروونکو سره څنګه مرسته کوي؟
sol Model answer: Application software helps users to do particular jobs: writing and formatting documents (word processor), calculations and charts (spreadsheet), storing and finding records (database), presentations, drawing and photo editing, web browsing and email, games and education. It saves time, reduces errors and increases the productivity of the user. ## Application software section of Unit 1.
qp viii | Differentiate between shareware and freeware. || شیئر ویئر اور فری ویئر میں فرق کریں۔ || د شیئرویر او فریویر ترمنځ توپیر وکړئ.
sol Model answer: Shareware is copyrighted software given free for a trial period or with limited features; the user must pay to get the full version or to keep using it (examples: WinZip, trial antivirus). Freeware is copyrighted software that can be used free of charge for as long as one wants, but the user cannot change its source code or sell it (examples: Adobe Reader, Skype). ## Types of software by licence in Unit 1.
qp ix | What is Licensed Software? || لائسنس یافتہ سافٹ ویئر کیا ہے؟ || جواز لرونکی سافټویر څه دی؟
sol Model answer: Licensed software (proprietary or commercial software) is software that the user buys under a licence agreement from the owner. The licence allows installation and use on a stated number of computers but does not allow copying, sharing or changing it. Examples: Microsoft Windows, MS Office, Adobe Photoshop. ## Types of software by licence in Unit 1.
qp x | What is firmware? || فرم ویئر کیا ہے؟ || فرمویر څه دی؟
sol Model answer: Firmware is a small, fixed program stored permanently in ROM or flash memory inside an electronic device to control it, for example the BIOS of a computer, or the programs inside a mobile phone, router, printer or washing machine. It sits between hardware and software and is changed only by a firmware update. ## Definition of firmware from Unit 1.
