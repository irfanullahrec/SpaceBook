## b. Subnet Masks || ب۔ سب نیٹ ماسک || ب. فرعي شبکې ماسکونه
p Subnet Mask indicates the network portion of an IP address. Like the IP address, the subnet mask is a dotted-decimal number. Usually all hosts within a LAN use the same subnet mask. Subnet mask is a 32-bit combination used to describe which portion of an address refers to the subnet and which part refers to the host. Figure 5.31 shows default subnet masks for usable IP addresses that are mapped to the first three classes of IP addresses. || سب نیٹ ماسک آئی پی ایڈریس کے نیٹ ورک حصے کی نشاندہی کرتا ہے۔ آئی پی ایڈریس کی طرح سب نیٹ ماسک بھی ڈاٹڈ ڈیسیمل نمبر ہے۔ عموماً لین کے اندر تمام ہوسٹس ایک ہی سب نیٹ ماسک استعمال کرتے ہیں۔ سب نیٹ ماسک ۳۲ بٹ کا مجموعہ ہے جو یہ بیان کرنے کے لیے استعمال ہوتا ہے کہ ایڈریس کا کون سا حصہ سب نیٹ سے اور کون سا ہوسٹ سے متعلق ہے۔ شکل ۵.۳۱ آئی پی ایڈریسز کی پہلی تین کلاسز سے ملنے والے قابلِ استعمال آئی پی ایڈریسز کے طے شدہ سب نیٹ ماسک دکھاتی ہے۔ || فرعي شبکې ماسک د IP پتې د شبکې برخه ښيي. د IP پتې په څېر فرعي شبکې ماسک هم یوه نقطه لرونکې لسیزه شمېره ده. معمولاً په LAN کې ټول کوربه ورته فرعي شبکې ماسک کاروي. فرعي شبکې ماسک ۳۲ بټ ګډون دی چې د دې بیانولو لپاره کارول کېږي چې د پتې کومه برخه فرعي شبکې ته او کومه برخه کوربه ته اشاره کوي. ۵.۳۱ انځور د IP پتو لومړیو درېیو ټولګیو سره نښلول شوي د کارونې وړ IP پتو لپاره ډیفالټ فرعي شبکې ماسکونه ښيي.
