p These are directly accessible to the CPU and are extremely fast. ## i. Cache Memory || i۔ کیش میموری || i. کېش حافظه
p Cache (pronounced as cash) memory is extremely fast Static RAM (SRAM) that is built into a computer’s central processing unit (CPU), or located next to it on a separate chip. The CPU uses cache memory to store instructions that are repeatedly required to run programs, improving overall system speed. This memory is mainly used to store some active portion of main memory (RAM). When any information is required by the processor, first it will look up in the cache memory, and if it is not available in the cache then it will fetch it from the RAM. Figure 2.3 shows cache memory interface in the computer. There are three levels of cache memory. || کیش (جس کا تلفظ کیش ہے) میموری انتہائی تیز اسٹیٹک ریم (ایس ریم) ہے جو کمپیوٹر کے مرکزی پراسیسنگ یونٹ (سی پی یو) میں بنی ہوتی ہے یا اس کے ساتھ ایک الگ چپ پر ہوتی ہے۔ سی پی یو کیش میموری کو ان ہدایات کو محفوظ کرنے کے لیے استعمال کرتا ہے جو پروگرام چلانے کے لیے بار بار درکار ہوتی ہیں، جس سے سسٹم کی مجموعی رفتار بہتر ہوتی ہے۔ یہ میموری بنیادی طور پر مین میموری (ریم) کے کسی فعال حصے کو محفوظ کرنے کے لیے استعمال ہوتی ہے۔ جب پراسیسر کو کوئی معلومات درکار ہوں تو وہ پہلے کیش میموری میں تلاش کرتا ہے اور اگر وہ کیش میں دستیاب نہ ہو تو اسے ریم سے حاصل کرتا ہے۔ شکل ۲.۳ کمپیوٹر میں کیش میموری کا انٹرفیس دکھاتی ہے۔ کیش میموری کی تین سطحیں ہیں۔ || کېش (چې تلفظ یې کېش دی) حافظه ډیره ګړندۍ جامده RAM (SRAM) ده چې د کمپیوټر په مرکزي پروسس واحد (CPU) کې جوړه شوې ده، یا د هغې تر څنګ په یو جلا چپ کې ایښودل شوې ده. CPU کېش حافظه هغو لارښوونو ساتلو لپاره کاروي چې د پروګرامونو چلولو لپاره په تکراري ډول اړینې وي، چې د سیسټم ټوله ګړندیتوب ښه کوي. دا حافظه په عمده توګه د اصلي حافظې (RAM) د یوې فعالې برخې ساتلو لپاره کارول کېږي. کله چې پروسیسر ته کوم معلومات پکار وي نو لومړی به د کېش په حافظه کې لټوي، او که په کېش کې نه وي موجود نو له RAM نه به یې راوړي. ۲.۳ انځور د کمپیوټر کې د کېش حافظې انټرفیس ښیي. د کېش حافظې درې کچې شته.
