## b. SQL Server || ب۔ ایس کیو ایل سرور || ب. SQL خدمتګار
p Microsoft SQL Server is a relational database management system developed by Microsoft. Its primary function is to store and retrieve data as requested by other software applications. SQL Server offers a variety of tools for database development, maintenance and administration. It has different versions suitable from small applications for a number of users to big applications for thousands of users. It is also used to create and manage Web-based databases. || مائیکروسافٹ ایس کیو ایل سرور مائیکروسافٹ کا تیار کردہ ریلیشنل ڈیٹا بیس مینجمنٹ سسٹم ہے۔ اس کا بنیادی کام دوسری سافٹ ویئر ایپلیکیشنز کی درخواست پر ڈیٹا محفوظ اور حاصل کرنا ہے۔ ایس کیو ایل سرور ڈیٹا بیس کی ترقی، دیکھ بھال اور انتظام کے لیے مختلف اوزار پیش کرتا ہے۔ اس کے مختلف ورژن ہیں جو چند صارفین کے لیے چھوٹی ایپلیکیشنز سے لے کر ہزاروں صارفین کے لیے بڑی ایپلیکیشنز تک موزوں ہیں۔ یہ ویب پر مبنی ڈیٹا بیسز بنانے اور ان کا انتظام کرنے کے لیے بھی استعمال ہوتا ہے۔ || مایکروسافټ SQL خدمتګار یو اړوند ډېټابېس مدیریت سیسټم دی چې د مایکروسافټ لخوا جوړ شوی. د دې لومړنۍ دنده د نورو سافټویر اپلېکېشنونو د غوښتنې سره سم ډېټا ذخیره او ترلاسه کول دي. SQL خدمتګار د ډېټابېس د جوړولو، ساتنې او مدیریت لپاره مختلف وسایل وړاندې کوي. دا مختلفې نسخې لري چې د یو شمېر کاروونکو لپاره له کوچنیو اپلېکېشنونو نه د زرګونو کاروونکو لپاره تر لویو اپلېکېشنونو پورې مناسبې دي. دا د ویب پر بنسټ ډېټابېسونو جوړولو او مدیریت لپاره هم کارول کېږي.
## c. OpenOffice Base || ج۔ اوپن آفس بیس || ج. اوپن آفس بیس
p OpenOffice Base is the database module of OpenOffice Suite. It is an open source application program. OpenOffice Base is a fully featured database management system. It has wizards to help new users to create database design, that is, to create tables, queries, forms and reports. It allows users to create interactive databases where they can manage data related to payroll, inventory, assets, budgets, customers, sales orders and invoices, etc. || اوپن آفس بیس اوپن آفس سویٹ کا ڈیٹا بیس ماڈیول ہے۔ یہ اوپن سورس ایپلیکیشن پروگرام ہے۔ اوپن آفس بیس مکمل خصوصیات والا ڈیٹا بیس مینجمنٹ سسٹم ہے۔ اس میں نئے صارفین کو ڈیٹا بیس ڈیزائن بنانے، یعنی ٹیبلز، کوئریز، فارمز اور رپورٹس بنانے، میں مدد دینے کے لیے ویزرڈز ہیں۔ یہ صارفین کو انٹرایکٹو ڈیٹا بیسز بنانے کی اجازت دیتا ہے جن میں وہ پے رول، انوینٹری، اثاثوں، بجٹ، کسٹمرز، سیلز آرڈرز اور انوائسز وغیرہ سے متعلق ڈیٹا کا انتظام کر سکتے ہیں۔ || اوپن آفس بیس د اوپن آفس ټولګې د ډېټابېس ماډل دی. دا یو پرانیستی سرچینه اپلېکېشن پروګرام دی. اوپن آفس بیس یو بشپړ ځانګړتیاوو لرونکی ډېټابېس مدیریت سیسټم دی. دا مرستندویان لري چې نوي کاروونکو سره د ډېټابېس ډیزاین جوړولو کې، یعنې جدولونه، پوښتنې، فورمونه او راپورونه جوړولو کې، مرسته کوي. دا کاروونکو ته اجازه ورکوي متقابل عملي ډېټابېسونه جوړ کړي چېرته چې هغوی کولای شي د معاش، موجودۍ، شتمنیو، بودیجو، پېرېدونکو، د پلور فرمایشونو او بیلونو او نور پورې اړوند ډېټا اداره کړي.
## 8.1.2 MS ACCESS 2007 || ۸.۱.۲ ایم ایس ایکسیس ۲۰۰۷ || ۸.۱.۲ MS ACCESS 2007
p Microsoft Access 2007 is the common and best suited DBMS for developing and managing databases. Microsoft Access 2007 provides a powerful set of tools that help users to quickly start tracking, reporting, and sharing information. Users can rapidly create attractive and functional tracking applications by customizing one of several predefined templates, converting an existing database, or creating a new database. By using Access 2007, it is easy to adapt database applications and reports to changing business needs. The enhanced support for Windows SharePoint Services 3.0 in Access 2007 helps users to share, manage, edit, and back up data easily. || مائیکروسافٹ ایکسیس ۲۰۰۷ ڈیٹا بیسز بنانے اور ان کا انتظام کرنے کے لیے عام اور سب سے موزوں ڈی بی ایم ایس ہے۔ مائیکروسافٹ ایکسیس ۲۰۰۷ طاقتور اوزار کا ایک مجموعہ فراہم کرتا ہے جو صارفین کو معلومات کا سراغ لگانے، رپورٹنگ اور شیئرنگ جلد شروع کرنے میں مدد دیتے ہیں۔ صارفین کئی پہلے سے متعین ٹیمپلیٹس میں سے ایک کو اپنی مرضی کے مطابق بنا کر، موجودہ ڈیٹا بیس کو تبدیل کر کے یا نیا ڈیٹا بیس بنا کر پرکشش اور فعال ٹریکنگ ایپلیکیشنز تیزی سے بنا سکتے ہیں۔ ایکسیس ۲۰۰۷ استعمال کر کے ڈیٹا بیس ایپلیکیشنز اور رپورٹس کو بدلتی ہوئی کاروباری ضروریات کے مطابق ڈھالنا آسان ہے۔ ایکسیس ۲۰۰۷ میں ونڈوز شیئر پوائنٹ سروسز ۳.۰ کی بہتر حمایت صارفین کو ڈیٹا شیئر، منظم، ترمیم اور بیک اپ کرنے میں آسانی دیتی ہے۔ || مایکروسافټ Access 2007 د ډېټابېسونو د جوړولو او مدیریت لپاره عام او غوره مناسب DBMS دی. مایکروسافټ Access 2007 د پیاوړو وسایلو یوه ټولګه برابروي چې کاروونکو سره د معلوماتو د تعقیب، راپور ورکولو او ګډولو چټکه پیل کې مرسته کوي. کاروونکي کولای شي د څو مخکې ټاکل شویو کېنډونو یو ځانګړی کولو، موجود ډېټابېس بدلولو، یا نوی ډېټابېس جوړولو په واسطه په چټکۍ سره زړه راښکونکي او فعال تعقیبي اپلېکېشنونه جوړ کړي. د Access 2007 په کارولو سره د ډېټابېس اپلېکېشنونو او راپورونو د بدلېدونکو سوداګریزو اړتیاوو سره سمول اسان دي. په Access 2007 کې د Windows SharePoint Services 3.0 ښه شوی ملاتړ کاروونکو سره د ډېټا په اسانۍ ګډولو، اداره کولو، سمولو او بیک اپ کولو کې مرسته کوي.
