## 1. Basic Input Output System (BIOS) || ۱۔ بیسک ان پٹ آؤٹ پٹ سسٹم (بائیوس) || ۱. بنسټیز دخل وتل سیسټم (BIOS)
p Basic Input Output System (BIOS) also known as the System BIOS or simply BIOS is the firmware built into the computer system. Firmware is a fixed, usually small program that controls various electronic devices. BIOS is the first program run by a computer when it is powered on. The main function of the BIOS is to load and start an operating system (OS). The first job of BIOS is to check and initialize system devices such as the video card, keyboard, mouse, hard disk and other hardware. BIOS then locates OS on hard disk or CD or flash memory drive. After loading and executing the OS, BIOS gives control to the system. This process is called booting or booting up the system. || بیسک ان پٹ آؤٹ پٹ سسٹم (بائیوس)، جسے سسٹم بائیوس یا محض بائیوس بھی کہتے ہیں، کمپیوٹر سسٹم میں بنا ہوا فرم ویئر ہے۔ فرم ویئر ایک مقررہ، عموماً چھوٹا پروگرام ہے جو مختلف برقی آلات کو کنٹرول کرتا ہے۔ بائیوس وہ پہلا پروگرام ہے جو کمپیوٹر کے آن ہونے پر چلتا ہے۔ بائیوس کا بنیادی فعل آپریٹنگ سسٹم (او ایس) کو لوڈ کرنا اور شروع کرنا ہے۔ بائیوس کا پہلا کام ویڈیو کارڈ، کی بورڈ، ماؤس، ہارڈ ڈسک اور دیگر ہارڈ ویئر جیسے سسٹم آلات کو جانچنا اور ابتدائی ترتیب دینا ہے۔ پھر بائیوس ہارڈ ڈسک یا سی ڈی یا فلیش میموری ڈرائیو پر او ایس تلاش کرتا ہے۔ او ایس لوڈ اور اجرا کرنے کے بعد بائیوس سسٹم کو کنٹرول دے دیتا ہے۔ اس عمل کو بوٹنگ یا سسٹم کو بوٹ اپ کرنا کہتے ہیں۔ || بنسټیز دخل وتل سیسټم (BIOS)، چې د سیسټم BIOS یا یوازې BIOS په نوم هم پېژندل کېږي، د کمپیوټر سیسټم کې جوړ شوی فرمویر دی. فرمویر یو ټاکلی، معمولاً کوچنی پروګرام دی چې مختلف برېښنايي وسایل کنټرولوي. BIOS هغه لومړی پروګرام دی چې کمپیوټر کله چې روښانه کېږي چلوي. د BIOS اصلي دنده د عملیاتي سیسټم (OS) پورته کول او پیلول دي. د BIOS لومړی کار د سیسټم وسایلو لکه ویډیو کارت، کیبورډ، موږک، هارډ ډیسک او نورو هارډویر ازمول او لومړنی تنظیمول دي. بیا BIOS په هارډ ډیسک یا CD یا فلش حافظې ډرایو کې OS لټوي. د OS د پورته کولو او پلي کولو وروسته BIOS سیسټم ته کنټرول ورکوي. دې پروسې ته بوټینګ یا سیسټم بوټ کول ویل کېږي.

p Configure hardware || ہارڈ ویئر کی ترتیب || هارډویر تنظیم کړي
p Set the system clock || سسٹم کلاک مقرر کرنا || د سیسټم ساعت وټاکي
p Enable or disable system components || سسٹم اجزاء کو فعال یا غیر فعال کرنا || د سیسټم اجزا فعال یا غیر فعال کړي
p Select bootable device sequence || بوٹ ہونے والے آلے کی ترتیب منتخب کرنا || د بوټ کېدونکې وسیلې ترتیب وټاکي
