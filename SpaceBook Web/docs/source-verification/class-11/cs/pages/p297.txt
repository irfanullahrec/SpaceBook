p Access offers tools that allow users to create and format a report. The Report Wizard takes users through the steps of creating a report. The Report command, however, is much easier to use, and all of the formatting options are still available in Layout View once the report is created. With these tools, user can create a report based on a table or a query. || ایکسیس ایسے اوزار پیش کرتا ہے جو صارفین کو رپورٹ بنانے اور اس کی فارمیٹنگ کرنے دیتے ہیں۔ رپورٹ ویزرڈ صارفین کو رپورٹ بنانے کے مراحل سے گزارتا ہے۔ تاہم رپورٹ کمانڈ استعمال کرنا بہت آسان ہے اور رپورٹ بن جانے کے بعد فارمیٹنگ کے تمام اختیارات لے آؤٹ ویو میں اب بھی دستیاب ہیں۔ ان اوزار کے ساتھ صارف ٹیبل یا کوئری پر مبنی رپورٹ بنا سکتا ہے۔ || Access داسې وسایل وړاندې کوي چې کاروونکو ته د راپور د جوړولو او بڼه کولو اجازه ورکوي. د Report Wizard کاروونکي د راپور د جوړولو ګامونو له لارې بیایي. د Report حکم، خو، د کارولو لپاره ډیر اسان دی، او د بڼې ټول اختیارونه لا هم په Layout View کې شته وروسته له دې چې راپور جوړ شي. له دغو وسایلو سره کاروونکی کولای شي د جدول یا پوښتنې پر بنسټ راپور جوړ کړي.
## 8.5.1 Using the Report Wizard to generate a Report || ۸.۵.۱ رپورٹ ویزرڈ کے ذریعے رپورٹ بنانا || ۸.۵.۱ د Report Wizard په کارولو راپور جوړول
p The following steps are used to generate a report using Report Wizard. || رپورٹ ویزرڈ کے ذریعے رپورٹ بنانے کے لیے درج ذیل اقدامات استعمال ہوتے ہیں۔ || د Report Wizard په کارولو د راپور د جوړولو لپاره لاندې ګامونه کارول کېږي.
