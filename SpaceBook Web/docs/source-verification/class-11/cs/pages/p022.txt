## 1.2.2 Types of System Software || ۱.۲.۲ سسٹم سافٹ ویئر کی اقسام || ۱.۲.۲ د سیسټم سافټویر ډولونه
p System software falls into following categories. || سسٹم سافٹ ویئر درج ذیل زمروں میں آتا ہے۔ || سیسټم سافټویر په لاندې ډلو کې راځي.
p Operating System || آپریٹنگ سسٹم || عملیاتي سیسټم

## a. Operating System || الف۔ آپریٹنگ سسٹم || الف. عملیاتي سیسټم
p Operating system is a set of programs that manages and coordinates the hardware of a computer and provides services to application software, programmers and users of computer. Without operating system a computer cannot do anything useful. || آپریٹنگ سسٹم پروگراموں کا وہ مجموعہ ہے جو کمپیوٹر کے ہارڈ ویئر کا انتظام اور ہم آہنگی کرتا ہے اور ایپلیکیشن سافٹ ویئر، پروگرامرز اور کمپیوٹر صارفین کو خدمات فراہم کرتا ہے۔ آپریٹنگ سسٹم کے بغیر کمپیوٹر کوئی مفید کام نہیں کر سکتا۔ || عملیاتي سیسټم د پروګرامونو هغه ټولګه ده چې د کمپیوټر هارډویر اداره او همغږی کوي او اپلیکېشن سافټویر، پروګرامرانو او د کمپیوټر کاروونکو ته خدمتونه برابروي. پرته له عملیاتي سیسټم کمپیوټر هیڅ ګټور کار نشي کولای.
p Some common examples of operating systems include Windows, Macintosh Operating System, UNIX, Linux, OS/2, and DOS. || آپریٹنگ سسٹمز کی کچھ عام مثالوں میں ونڈوز، میکنٹوش آپریٹنگ سسٹم، یونکس، لینکس، او ایس/۲ اور ڈاس شامل ہیں۔ || د عملیاتي سیسټمونو ځینې عامې بېلګې ویندوز، میکنټوش عملیاتي سیسټم، UNIX، لینکس، OS/2 او DOS دي.
## b. Device Driver || ب۔ ڈیوائس ڈرائیور || ب. د وسیلې چلوونکی
p A device driver is a program that controls a particular type of device that is attached to the computer. Without driver, a hardware device would not be able to work with the computer. There are device drivers for printers, monitors, CD-ROM drives, diskette drives, etc. When we buy an operating system, many device drivers are built into the product. However, if we later buy a new type of device that the operating system did not anticipate, we will have to install the new device driver. || ڈیوائس ڈرائیور ایک پروگرام ہے جو کمپیوٹر سے منسلک ایک خاص قسم کے آلے کو کنٹرول کرتا ہے۔ ڈرائیور کے بغیر ہارڈ ویئر آلہ کمپیوٹر کے ساتھ کام نہیں کر سکے گا۔ پرنٹرز، مانیٹرز، سی ڈی روم ڈرائیوز، ڈسکیٹ ڈرائیوز وغیرہ کے لیے ڈیوائس ڈرائیورز ہوتے ہیں۔ جب ہم آپریٹنگ سسٹم خریدتے ہیں تو بہت سے ڈیوائس ڈرائیورز مصنوعات میں شامل ہوتے ہیں۔ تاہم اگر ہم بعد میں کسی نئی قسم کا آلہ خریدیں جس کی آپریٹنگ سسٹم نے توقع نہیں کی تھی تو ہمیں نیا ڈیوائس ڈرائیور انسٹال کرنا ہوگا۔ || د وسیلې چلوونکی یو پروګرام دی چې د کمپیوټر سره وصل یو ځانګړی ډول وسیله کنټرولوي. پرته له چلوونکي یوه هارډویر وسیله د کمپیوټر سره کار نشي کولای. د پرنټرونو، مانیټرونو، CD-ROM ډرایوونو، ډیسکیټ ډرایوونو او نورو لپاره د وسیلو چلوونکي شته. کله چې موږ عملیاتي سیسټم اخلو نو ډیر د وسیلو چلوونکي په محصول کې جوړ شوي وي. خو که موږ وروسته یو نوی ډول وسیله واخلو چې عملیاتي سیسټم یې تمه نه وه کړې نو موږ باید نوی د وسیلې چلوونکی نصب کړو.
## c. Utility Software || ج۔ یوٹیلٹی سافٹ ویئر || ج. ګټور سافټویر
p Utility software is a kind of system software designed to analyze, configure, optimize and maintain the computer. A single piece of utility software is usually called a utility or tool. Utility software usually focuses on how the computer infrastructure operates. Most of the operating systems come with several pre-installed utilities. Examples of utility software are Disk Defragmentation, Disk Cleaner, Backup, Antivirus etc. || یوٹیلٹی سافٹ ویئر سسٹم سافٹ ویئر کی ایک قسم ہے جو کمپیوٹر کا تجزیہ، ترتیب، بہتری اور دیکھ بھال کرنے کے لیے بنایا گیا ہے۔ یوٹیلٹی سافٹ ویئر کے ایک حصے کو عموماً یوٹیلٹی یا ٹول کہا جاتا ہے۔ یوٹیلٹی سافٹ ویئر عموماً اس پر توجہ دیتا ہے کہ کمپیوٹر کا بنیادی ڈھانچہ کیسے کام کرتا ہے۔ زیادہ تر آپریٹنگ سسٹمز کئی پہلے سے انسٹال شدہ یوٹیلٹیز کے ساتھ آتے ہیں۔ یوٹیلٹی سافٹ ویئر کی مثالیں ڈسک ڈی فریگمنٹیشن، ڈسک کلینر، بیک اپ، اینٹی وائرس وغیرہ ہیں۔ || ګټور سافټویر د سیسټم سافټویر یو ډول دی چې د کمپیوټر د تحلیل، تنظیم، ښه کولو او ساتنې لپاره جوړ شوی. د ګټور سافټویر یو واحد برخه معمولاً یوټیلټي یا وسیله بلل کېږي. ګټور سافټویر معمولاً پر دې تمرکز کوي چې د کمپیوټر بنسټیز جوړښت څنګه کار کوي. ډیر عملیاتي سیسټمونه د ډیرو مخکې نصب شویو یوټیلټیو سره راځي. د ګټور سافټویر بېلګې د ډیسک ډیفراګمنټېشن، ډیسک پاکوونکی، بېکاپ، انټي وایرس او نور دي.
