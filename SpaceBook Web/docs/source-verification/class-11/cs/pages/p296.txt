p Run the query, using the Run button to delete the data in Student table that meets the criteria that is applied. The warning dialog box indicates the number of records that will be deleted, click Yes to accept. || کوئری کو رن بٹن کے ذریعے چلائیں تاکہ اسٹوڈنٹ ٹیبل میں وہ ڈیٹا حذف ہو جو لاگو کیے گئے معیار پر پورا اترے۔ تنبیہی ڈائیلاگ باکس حذف ہونے والے ریکارڈز کی تعداد بتاتا ہے، قبول کرنے کے لیے ہاں پر کلک کریں۔ || پوښتنه د Run تڼۍ په کارولو چلوئ ترڅو په زده کوونکي جدول کې هغه ډېټا حذف شي چې پلي شوی معیار پوره کوي. د خبرتیا خبرې اترې بکس د هغو ثبتونو شمېر ښيي چې حذفېږي، د منلو لپاره Yes کلیک کړئ.
p Remember that the query will permanently delete records from the specified table(s), Therefore it is very important that the user has backed up the table(s) or database before running this object. || یاد رکھیں کہ کوئری متعین ٹیبل(ز) کے ریکارڈز کو مستقل طور پر حذف کر دے گی، اس لیے یہ بہت اہم ہے کہ صارف نے اس آبجیکٹ کو چلانے سے پہلے ٹیبل(ز) یا ڈیٹا بیس کا بیک اپ لے رکھا ہو۔ || په یاد ولرئ چې پوښتنه به ټاکل شوي جدول(ونو) ثبتونه په دایمي توګه حذف کړي، نو ډیر مهم دی چې کاروونکي د دې څیز د چلولو مخکې جدول(ونه) یا ډېټابېس بیک اپ کړی وي.
p Check the Delete Query Results by running the Student table. || اسٹوڈنٹ ٹیبل چلا کر ڈیلیٹ کوئری کے نتائج کی جانچ کریں۔ || د Student جدول په چلولو سره د Delete پوښتنې پایلې وکتئ.

## 8.5 GENERATING REPORTS || ۸.۵ رپورٹس بنانا || ۸.۵ راپورونه جوړول
p A report is an Access object. It is used to display data in an organized manner so that users can print it. A report is an effective way to present data using an attractive layout. || رپورٹ ایکسیس کا آبجیکٹ ہے۔ یہ ڈیٹا کو منظم انداز میں دکھانے کے لیے استعمال ہوتی ہے تاکہ صارفین اسے پرنٹ کر سکیں۔ رپورٹ پرکشش ترتیب کے ساتھ ڈیٹا پیش کرنے کا مؤثر طریقہ ہے۔ || راپور یو د Access څیز دی. دا د ډېټا په منظم ډول د ښودلو لپاره کارول کېږي ترڅو کاروونکي یې چاپ کړي. راپور د زړه راښکونکي ترتیب په کارولو سره د ډېټا د وړاندې کولو یوه اغېزمنه لار ده.
