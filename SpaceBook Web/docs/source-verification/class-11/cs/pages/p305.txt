qp i | Name different types of database management systems. || ڈیٹا بیس مینجمنٹ سسٹمز کی مختلف اقسام کے نام بتائیں۔ || د ډېټابېس مدیریت سیسټمونو د مختلفو ډولونو نومونه ووایئ.
sol Model answer: Types of DBMS: hierarchical DBMS, network DBMS, relational DBMS (RDBMS) and object-oriented DBMS. Examples of products: MS Access, OpenOffice Base, MySQL, Oracle, Microsoft SQL Server, PostgreSQL, IBM DB2. ## Unit 8 introduction.
qp ii | What is OpenOffice Base? || اوپن آفس بیس کیا ہے؟ || اوپن آفس بیس څه دی؟
sol Model answer: OpenOffice Base is the database program of the free, open-source Apache OpenOffice suite. It lets users create tables, forms, queries and reports, and can also connect to other databases (MySQL, Access). It is a free alternative to MS Access. ## Unit 8 OpenOffice Base.
qp iii | How forms are useful in database? || ڈیٹا بیس میں فارمز کیسے مفید ہیں؟ || فورمونه په ډېټابېس کې څنګه ګټور دي؟
sol Model answer: Forms are useful because they give a friendly screen to enter, view and edit the data of a table one record at a time, so users do not work directly in the table. They reduce mistakes with controls such as drop-down lists and check boxes, can show data from more than one table, hide fields not meant for the user, and have navigation buttons to move among records. ## Unit 8 forms.
qp iv | Name common Access database objects. || ایکسیس ڈیٹا بیس کے عام آبجیکٹس کے نام بتائیں۔ || د Access ډېټابېس عام څیزونو نومونه ووایئ.
sol Model answer: Common Access database objects: Tables (store data), Queries (find and combine data), Forms (enter and view data), Reports (print data), Macros (automate actions) and Modules (Visual Basic code). ## Unit 8 Access objects.
qp v | How primary key is assigned in a table? || ٹیبل میں پرائمری کی کیسے تفویض کی جاتی ہے؟ || په جدول کې لومړنۍ کیلي څنګه ټاکل کېږي؟
sol Model answer: To assign a primary key: open the table in Design view, click the row selector of the field (or fields, with Ctrl) that is to be the key, and click the Primary Key button on the Design tab (or right-click the field and choose Primary Key). A key symbol appears next to the field name; Access does not allow duplicate or empty values in it. Save the table. ## Unit 8 primary key.
qp vi | What is a report? || رپورٹ کیا ہے؟ || راپور څه دی؟
sol Model answer: A report is a database object that displays the data of tables or queries in an organised, formatted way so that it can be viewed on screen and printed, with headings, grouping, totals and page numbers. ## Unit 8 reports.
qp vii | How relationship can be edited in Access. || ایکسیس میں تعلق میں ترمیم کیسے کی جا سکتی ہے۔ || په Access کې اړیکه څنګه سمېدای شي.
sol Model answer: To edit a relationship in Access: on the Database Tools tab click Relationships; right-click the line (join) between the two tables and choose Edit Relationship (or double-click the line). In the dialog change the fields, tick or untick Enforce Referential Integrity, Cascade Update Related Fields and Cascade Delete Related Records, or change the join type, then click OK. ## Unit 8 relationships.
qp viii | Name different navigation buttons in a form. || فارم میں مختلف نیویگیشن بٹنوں کے نام بتائیں۔ || په فورم کې د لارښوونې مختلفې تڼۍ نومونه ووایئ.
sol Model answer: Navigation buttons at the bottom of a form: First Record, Previous Record, Next Record, Last Record, and New (blank) Record; there is also a box for the current record number. ## Unit 8 forms.

qp i | Explain the following database objects. || درج ذیل ڈیٹا بیس آبجیکٹس کی وضاحت کریں۔ || لاندې د ډېټابېس څیزونه تشریح کړئ.
sol Model answer: This question has the parts (a) Tables, (b) Forms and (d) Reports (the book prints the letters a, b, d). Each part has its own answer under its own question. ## Heading of a multi-part question.
qp • | a) Tables || a) ٹیبلز || a) جدولونه
sol Model answer: A table is the basic database object that stores data in rows and columns. Each column is a field (attribute) with a name and a data type, and each row is a record. All other objects (queries, forms, reports) work on the data stored in tables. ## Unit 8 tables.
qp • | b) Forms || b) فارمز || b) فورمونه
sol Model answer: A form is a window in which data is displayed, entered and edited, usually one record at a time. It is designed with labels, text boxes, combo boxes, check boxes and buttons, makes data entry easier and less error-prone, and gives the user a view of the data without opening the table. ## Unit 8 forms.
qp c | Queries || کوئریز || پوښتنې
qp • | d) Reports || d) رپورٹس || d) راپورونه
sol Model answer: A report presents data from tables or queries in a printed layout. It can group and sort records, calculate totals and averages, and add titles, headers, footers and page numbers; reports are used for printing lists, bills and summaries. Reports show data only; they do not change it. ## Unit 8 reports.
qp ii | Explain different data types used in Access. || ایکسیس میں استعمال ہونے والی مختلف ڈیٹا ٹائپس کی وضاحت کریں۔ || په Access کې کارېدونکي مختلف د ډېټا ډولونه تشریح کړئ.
sol Model answer: Data types in Access: Text (letters and numbers, up to 255 characters); Memo (long text); Number (numeric values); Date/Time; Currency (money); AutoNumber (a number added automatically for each new record); Yes/No (logical: true/false); OLE Object (pictures, files from other programs); Hyperlink (web or file addresses); Attachment; Lookup Wizard (choose a value from a list or another table). ## Unit 8 data types.
qp iii | Describe two ways of creating a table in Access. || ایکسیس میں ٹیبل بنانے کے دو طریقے بیان کریں۔ || په Access کې د جدول د جوړولو دوه لارې بیان کړئ.
sol Model answer: Two ways to create a table in Access: (1) Datasheet view: Create > Table opens a blank datasheet; type the field names in the column headings and the data in the cells, and Access guesses the data types. (2) Design view: Create > Table Design; type each field name, choose its data type, set field properties and the primary key, then save the table and enter data in Datasheet view. (Table templates and importing are other ways.) ## Unit 8 creating tables.
qp iv | Explain the process of creating forms in Access. || ایکسیس میں فارمز بنانے کے عمل کی وضاحت کریں۔ || په Access کې د فورمونو د جوړولو پروسه تشریح کړئ.
sol Model answer: Creating a form in Access: (1) Select the table or query in the navigation pane. (2) On the Create tab click Form for an automatic form, or Form Wizard for a guided one. (3) In the wizard choose the fields to display, the layout (columnar, tabular, datasheet or justified) and the style, and give the form a title. (4) Click Finish. The form opens in Form view to enter data, and Design view can be used to change the layout. ## Unit 8 forms.
qp v | Write the steps for creating relationships between tables. || ٹیبلز کے درمیان تعلقات بنانے کے اقدامات لکھیں۔ || د جدولونو ترمنځ د اړیکو د جوړولو ګامونه ولیکئ.
sol Model answer: Steps to create a relationship between tables: (1) Close all open tables. (2) On the Database Tools tab click Relationships. (3) In the Show Table box select the tables and click Add, then Close. (4) Drag the primary key field of one table onto the matching foreign key field of the other table. (5) In the Edit Relationships box check the fields and tick Enforce Referential Integrity if wanted. (6) Click Create; a join line appears. Save the relationships. ## Unit 8 relationships.
qp vi | Explain different types of queries used in Access. || ایکسیس میں استعمال ہونے والی کوئریز کی مختلف اقسام کی وضاحت کریں۔ || په Access کې کارېدونکې د پوښتنو مختلف ډولونه تشریح کړئ.
sol Model answer: Types of queries in Access: (1) Select query: gets data from one or more tables and shows it (the most common). (2) Parameter query: asks for a value when it is run. (3) Crosstab query: shows summarised data in rows and columns like a spreadsheet. (4) Action queries change data: Make-Table, Append, Update and Delete queries. ## Unit 8 queries.
qp vii | How can one-to-many relationship can be created between two tables? Give example. || دو ٹیبلز کے درمیان ایک سے کئی تعلق کیسے بنایا جا سکتا ہے؟ مثال دیں۔ || د دوو جدولونو ترمنځ د یو-ته-ډیر اړیکه څنګه جوړېدای شي؟ بېلګه ورکړئ.
sol Model answer: A one-to-many relationship is created by taking the primary key of the "one" table as a foreign key in the "many" table and joining them in the Relationships window (drag the key field from the "one" table to the foreign key field of the "many" table). Example: Customer (CustomerID primary key) and Orders (OrderID primary key, CustomerID foreign key): one customer can have many orders, but each order belongs to only one customer. ## Unit 8 relationships.
qp viii | What is a query? How query is created using wizard option in Access 2007? || کوئری کیا ہے؟ ایکسیس ۲۰۰۷ میں ویزرڈ آپشن استعمال کر کے کوئری کیسے بنائی جاتی ہے؟ || پوښتنه څه ده؟ په Access 2007 کې د مرستندوي اختیار په کارولو پوښتنه څنګه جوړېږي؟
sol Model answer: A query is a database object that asks a question of the database: it searches one or more tables for records that satisfy given conditions and shows the result, and it can also sort data or perform calculations. Using the Simple Query Wizard in Access 2007: (1) Create > Query Wizard > Simple Query Wizard > OK. (2) Choose the table or query and move the wanted fields to the Selected Fields list. (3) Click Next, choose Detail or Summary. (4) Give the query a title. (5) Click Finish; the result opens as a datasheet. ## Unit 8 queries.
