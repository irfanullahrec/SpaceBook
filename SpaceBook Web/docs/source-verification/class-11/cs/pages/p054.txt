## 2.2.2 Volatile and Non-Volatile memory || ۲.۲.۲ غیر مستقل اور مستقل میموری || ۲.۲.۲ بې ثباته او ثابته حافظه
p Memory, on the basis of retention of data, can be divided into two types i.e. volatile and non-volatile memory. || میموری کو ڈیٹا برقرار رکھنے کی بنیاد پر دو اقسام میں تقسیم کیا جا سکتا ہے، یعنی غیر مستقل اور مستقل میموری۔ || حافظه د ډېټا د ساتلو پر بنسټ په دوو ډولونو وېشل کېدای شي یعنې بې ثباته او ثابته حافظه.
## a. Volatile memory || الف۔ غیر مستقل میموری || الف. بې ثباته حافظه
p Volatile memory is computer memory that requires power (electricity) to maintain the stored information. Volatile memory retains the information as long as power supply remains on, but when power supply goes off or interrupted, the stored data is lost. It is also known as temporary memory. Examples of such memory are RAM (Random access memory) and Registers. || غیر مستقل میموری وہ کمپیوٹر میموری ہے جسے محفوظ معلومات برقرار رکھنے کے لیے بجلی کی ضرورت ہوتی ہے۔ غیر مستقل میموری اس وقت تک معلومات برقرار رکھتی ہے جب تک بجلی کی فراہمی جاری رہے لیکن جب بجلی بند یا منقطع ہو جائے تو محفوظ ڈیٹا ختم ہو جاتا ہے۔ اسے عارضی میموری بھی کہا جاتا ہے۔ ایسی میموری کی مثالیں ریم (رینڈم ایکسیس میموری) اور رجسٹرز ہیں۔ || بې ثباته حافظه هغه د کمپیوټر حافظه ده چې د ساتل شویو معلوماتو د ساتلو لپاره بریښنا ته اړتیا لري. بې ثباته حافظه معلومات تر هغه ساتي څومره چې د بریښنا رسول روان وي، خو کله چې بریښنا بنده یا قطع شي، ساتل شوې ډېټا له منځه ځي. دې ته لنډمهاله حافظه هم ویل کېږي. د داسې حافظې بېلګې RAM (تصادفي لاسرسي حافظه) او رجسترونه دي.
## b. Non-Volatile memory || ب۔ مستقل میموری || ب. ثابته حافظه
p Non-volatile memory is a permanent memory that can retain the stored information even if power supply is off. Examples of non-volatile memory include ROM (Read-only memory), flash memory, magnetic storage devices (e.g. hard disks and magnetic tape), optical disks, and blue-ray disk. Non-volatile memory is typically used for secondary storage, or long-term storage for future use. || مستقل میموری ایک مستقل میموری ہے جو بجلی کی فراہمی بند ہونے پر بھی محفوظ معلومات برقرار رکھ سکتی ہے۔ مستقل میموری کی مثالوں میں روم (ریڈ اونلی میموری)، فلیش میموری، مقناطیسی ذخیرہ آلات (مثلاً ہارڈ ڈسکس اور مقناطیسی ٹیپ)، آپٹیکل ڈسکس اور بلیو رے ڈسک شامل ہیں۔ مستقل میموری عموماً ثانوی ذخیرے یا مستقبل کے استعمال کے لیے طویل مدتی ذخیرے کے لیے استعمال ہوتی ہے۔ || ثابته حافظه یوه دایمي حافظه ده چې د بریښنا د رسولو د بندېدو سره هم ساتل شوي معلومات ساتلای شي. د ثابتې حافظې بېلګې ROM (یوازې لوستلو حافظه)، فلش حافظه، مقناطیسي ذخیرې وسایل (لکه هارډ ډیسکونه او مقناطیسي ټیپ)، نظري ډیسکونه او بلیو-رې ډیسک دي. ثابته حافظه معمولاً د دویمي ذخیرې یا د راتلونکې کارونې لپاره د اوږدمهالې ذخیرې لپاره کارول کېږي.
