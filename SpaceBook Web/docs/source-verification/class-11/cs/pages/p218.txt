## Limitations of File Management System || فائل مینجمنٹ سسٹم کی حدود || د فایل مدیریت سیسټم محدودیتونه
## i. Data Redundancy || i۔ ڈیٹا ری ڈنڈنسی || i. د ډېټا تکرار
p Independent data files include a lot of duplicated data; the same data is recorded and stored in several files. This data redundancy causes problems when data is to be updated. Hence data redundancy is more in case of file approach. || آزاد ڈیٹا فائلوں میں بہت سا نقل شدہ ڈیٹا ہوتا ہے؛ ایک ہی ڈیٹا کئی فائلوں میں ریکارڈ اور محفوظ ہوتا ہے۔ یہ ڈیٹا ری ڈنڈنسی ڈیٹا اپ ڈیٹ کرتے وقت مسائل پیدا کرتی ہے۔ اس لیے فائل اپروچ کی صورت میں ڈیٹا ری ڈنڈنسی زیادہ ہوتی ہے۔ || خپلواک ډېټا فایلونه ډیره نقل شوې ډېټا لري؛ همدا ډېټا په څو فایلونو کې ثبتېږي او ساتل کېږي. دا د ډېټا تکرار د ډېټا د تازه کولو پر مهال ستونزې رامنځته کوي. نو د فایل طریقې په صورت کې د ډېټا تکرار ډیر وي.
## ii. Inconsistency || ii۔ عدم مطابقت || ii. ناسمون
p In this system, data is not consistent due to redundant storage. If a data item is changed all the files containing that data item need to be changed and updated properly. If all the files are not updated properly there may be high risk of inconsistency. || اس نظام میں غیر ضروری ذخیرے کی وجہ سے ڈیٹا مطابقت پذیر نہیں ہوتا۔ اگر کسی ڈیٹا آئٹم کو بدلا جائے تو وہ ڈیٹا آئٹم رکھنے والی تمام فائلوں کو مناسب طریقے سے بدلنا اور اپ ڈیٹ کرنا ضروری ہے۔ اگر تمام فائلیں مناسب طور پر اپ ڈیٹ نہ ہوں تو عدم مطابقت کا بڑا خطرہ ہو سکتا ہے۔ || پدې سیسټم کې ډېټا د تکراري ذخیرې له امله همغږې نه ده. که یو ډېټا توکی بدل شي نو ټولې هغه فایلونه چې دا ډېټا توکی لري باید په سمه توګه بدل او تازه شي. که ټول فایلونه په سمه توګه تازه نه شي نو د ناسمون لوړ خطر کېدای شي.
## iii. Intensive Coding || iii۔ زیادہ کوڈنگ || iii. ډیر کوډ کول
p The processing tasks like searching, editing, deletion and updating should have separate programs. It means there are no built in functions available and needs coding every time to perform these operations. || تلاش، ترمیم، حذف اور اپ ڈیٹنگ جیسے پراسیسنگ کاموں کے لیے الگ پروگرام ہونے چاہئیں۔ اس کا مطلب ہے کہ کوئی بلٹ اِن فنکشن دستیاب نہیں اور ان کارروائیوں کے لیے ہر بار کوڈنگ کرنی پڑتی ہے۔ || د پروسس کولو دندې لکه لټون، سمون، حذف او تازه کول باید جلا پروګرامونه ولري. دا مانا لري چې هېڅ جوړ شوي فنکشنونه نشته او د دغو عملیاتو د ترسره کولو لپاره هر ځل کوډ کولو ته اړتیا ده.
## iv. Data Isolation || iv۔ ڈیٹا کی علیحدگی || iv. د ډېټا جلاوالی
p Data is scattered in various files and the files may be in different format. The users have to write new application program to retrieve data from these files. This is difficult, time-consuming, and costly. || ڈیٹا مختلف فائلوں میں بکھرا ہوتا ہے اور فائلیں مختلف فارمیٹ میں ہو سکتی ہیں۔ صارفین کو ان فائلوں سے ڈیٹا حاصل کرنے کے لیے نیا ایپلیکیشن پروگرام لکھنا پڑتا ہے۔ یہ مشکل، وقت طلب اور مہنگا ہے۔ || ډېټا په مختلفو فایلونو کې ویشل شوې ده او فایلونه کېدای شي په مختلفو بڼو کې وي. کاروونکي باید د دغو فایلونو نه د ډېټا ترلاسه کولو لپاره نوی اپلېکېشن پروګرام ولیکي. دا ستونزمن، وخت نیوونکی او قیمتي دی.
## v. Data Program Dependence || v۔ ڈیٹا پروگرام انحصار || v. د ډېټا پروګرام تکیه
p In file management systems, changes in the format and structure of data and records in a file require that changes be made to all of the programs that use that file. This program maintenance effort is a major burden of file management systems. || فائل مینجمنٹ سسٹمز میں کسی فائل میں ڈیٹا اور ریکارڈز کی شکل اور ساخت میں تبدیلیاں اس بات کا تقاضا کرتی ہیں کہ اس فائل کو استعمال کرنے والے تمام پروگراموں میں تبدیلیاں کی جائیں۔ پروگرام کی دیکھ بھال کی یہ کوشش فائل مینجمنٹ سسٹمز کا ایک بڑا بوجھ ہے۔ || د فایل مدیریت سیسټمونو کې د فایل کې د ډېټا او ثبتونو په بڼه او جوړښت کې بدلونونه غواړي چې په ټولو هغو پروګرامونو کې بدلونونه وشي چې دا فایل کاروي. د پروګرام د ساتنې دا هڅه د فایل مدیریت سیسټمونو لوی بار دی.
