## b. Adding Fields to a Table || ب۔ ٹیبل میں فیلڈز شامل کرنا || ب. جدول ته ساحې زیاتول
p Access offers two ways to add fields to a Table. || ایکسیس ٹیبل میں فیلڈز شامل کرنے کے دو طریقے پیش کرتا ہے۔ || Access جدول ته د ساحو زیاتولو دوه لارې وړاندې کوي.
p Working in Datasheet View, which looks like a spreadsheet || ڈیٹا شیٹ ویو میں کام کرنا، جو اسپریڈ شیٹ جیسا لگتا ہے || په ډېټا شیټ لید کې کار کول، چې د سپریډ شیټ غوندې ښکاري
p Working in Design View, where users are able to set more controls for the fields. || ڈیزائن ویو میں کام کرنا، جہاں صارفین فیلڈز کے لیے مزید کنٹرولز ترتیب دے سکتے ہیں۔ || په ډیزاین لید کې کار کول، چېرته چې کاروونکي کولای شي د ساحو لپاره نور کنټرولونه وټاکي.
## i. Adding Fields in Datasheet View || i۔ ڈیٹا شیٹ ویو میں فیلڈز شامل کرنا || i. په ډېټا شیټ لید کې ساحې زیاتول
p By default, Access creates one field in each new table, the ID field, which can be renamed as required by the user. || پہلے سے طے شدہ طور پر ایکسیس ہر نئے ٹیبل میں ایک فیلڈ بناتا ہے، آئی ڈی فیلڈ، جس کا نام صارف ضرورت کے مطابق بدل سکتا ہے۔ || په ډیفالټ توګه Access په هر نوي جدول کې یوه ساحه جوړوي، د ID ساحه، چې نوم یې کاروونکی د اړتیا سره سم بدلولای شي.
