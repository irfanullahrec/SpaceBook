## c. Relational Database Model || ج۔ ریلیشنل ڈیٹا بیس ماڈل || ج. اړونده ډېټابېس ماډل
p A relation is a table with columns and rows. The Relational model uses a collection of tables/relations to represent both data and the relationship among those data. Each table has multiple columns and each column has a unique name. Information about particular entity is represented in rows (also called tuples) and columns. Figure 7.3 illustrates an example showing an Entity-Relationship (E-R) diagram that represents entities (tables) and their relationships for a sample relational model. || ریلیشن کالموں اور قطاروں والا ٹیبل ہے۔ ریلیشنل ماڈل ڈیٹا اور ان ڈیٹا کے درمیان تعلق دونوں کو ظاہر کرنے کے لیے ٹیبلز/ریلیشنز کا مجموعہ استعمال کرتا ہے۔ ہر ٹیبل کے متعدد کالم ہوتے ہیں اور ہر کالم کا منفرد نام ہوتا ہے۔ کسی مخصوص انٹیٹی کے بارے میں معلومات قطاروں (جنہیں ٹپلز بھی کہتے ہیں) اور کالموں میں ظاہر ہوتی ہیں۔ شکل ۷.۳ ایک مثال دکھاتی ہے جس میں انٹیٹی-ریلیشن شپ (ای-آر) ڈایاگرام نمونہ ریلیشنل ماڈل کے لیے انٹیٹیز (ٹیبلز) اور ان کے تعلقات ظاہر کرتا ہے۔ || اړیکه یو جدول دی چې ستونونه او قطارونه لري. اړونده ماډل د جدولونو/اړیکو ټولګه کاروي ترڅو ډېټا او د دغو ډېټا ترمنځ اړیکه دواړه وښیي. هر جدول څو ستونونه لري او هر ستون ځانګړی نوم لري. د یوه ځانګړي وجود په اړه معلومات په قطارونو (چې ټپلونه هم ورته ویل کېږي) او ستونونو کې ښودل کېږي. ۷.۳ انځور یوه بېلګه ښيي چې د نمونوي اړوند ماډل لپاره وجودونه (جدولونه) او د هغو اړیکې ښیي چې د وجود-اړیکې (E-R) انځور څخه ښودل کېږي.

## d. Object-Oriented Database Model || د۔ آبجیکٹ اورینٹڈ ڈیٹا بیس ماڈل || د. څیز پر بنسټ ډېټابېس ماډل
p Object-Oriented database Model is a database model in which information is represented in the form of objects as used in object-oriented programming. Object oriented databases are different from relational databases and belong together to the broader database management system. When database capabilities are combined with object-oriented programming language capabilities, the result is an object-oriented database model. || آبجیکٹ اورینٹڈ ڈیٹا بیس ماڈل ایسا ڈیٹا بیس ماڈل ہے جس میں معلومات آبجیکٹس کی شکل میں ظاہر ہوتی ہیں جیسا کہ آبجیکٹ اورینٹڈ پروگرامنگ میں استعمال ہوتا ہے۔ آبجیکٹ اورینٹڈ ڈیٹا بیسز ریلیشنل ڈیٹا بیسز سے مختلف ہیں اور وسیع تر ڈیٹا بیس مینجمنٹ سسٹم کا حصہ ہیں۔ جب ڈیٹا بیس کی صلاحیتیں آبجیکٹ اورینٹڈ پروگرامنگ زبان کی صلاحیتوں کے ساتھ ملا دی جائیں تو نتیجہ آبجیکٹ اورینٹڈ ڈیٹا بیس ماڈل ہوتا ہے۔ || څیز پر بنسټ ډېټابېس ماډل یو ډېټابېس ماډل دی چې په هغه کې معلومات د څیزونو په بڼه ښودل کېږي لکه څنګه چې په څیز پر بنسټ پروګرامنګ کې کارول کېږي. څیز پر بنسټ ډېټابېسونه له اړوندو ډېټابېسونو نه توپیر لري او په یوځای د پراخ ډېټابېس مدیریت سیسټم پورې اړه لري. کله چې د ډېټابېس وړتیاوې د څیز پر بنسټ پروګرامنګ ژبې له وړتیاوو سره یوځای شي، پایله یې د څیز پر بنسټ ډېټابېس ماډل دی.
