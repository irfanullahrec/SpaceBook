p An IP address can be static or dynamic. A static IP address will never change and it is a permanent Internet address. A dynamic IP address is a temporary address that is assigned each time a computer or device accesses the Internet. The address is made up of 32 binary bits, which can be divided into a network portion and host portion with the help of a subnet mask. The 32 binary bits are broken into four octets (1 octet = 8 bits). Each octet is represented in decimal and separated by a period (dot). For this reason, an IP address is expressed in dotted decimal format (e.g., 172.16.81.100). The value in each octet ranges from 0 to 255 in decimal, or 00000000 - 11111111 in binary. || آئی پی ایڈریس جامد یا متحرک ہو سکتا ہے۔ جامد آئی پی ایڈریس کبھی نہیں بدلتا اور یہ مستقل انٹرنیٹ ایڈریس ہے۔ متحرک آئی پی ایڈریس ایک عارضی ایڈریس ہے جو ہر بار کمپیوٹر یا آلے کے انٹرنیٹ تک رسائی حاصل کرنے پر تفویض ہوتا ہے۔ ایڈریس ۳۲ بائنری بٹس پر مشتمل ہوتا ہے جنہیں سب نیٹ ماسک کی مدد سے نیٹ ورک حصے اور ہوسٹ حصے میں تقسیم کیا جا سکتا ہے۔ ۳۲ بائنری بٹس چار آکٹیٹس میں تقسیم ہوتے ہیں (۱ آکٹیٹ = ۸ بٹس)۔ ہر آکٹیٹ اعشاری میں ظاہر کیا جاتا ہے اور نقطے (ڈاٹ) سے الگ کیا جاتا ہے۔ اسی وجہ سے آئی پی ایڈریس ڈاٹڈ ڈیسیمل فارمیٹ (مثلاً ۱۷۲.۱۶.۸۱.۱۰۰) میں ظاہر کیا جاتا ہے۔ ہر آکٹیٹ کی قدر اعشاری میں ۰ سے ۲۵۵ یا بائنری میں ۰۰۰۰۰۰۰۰ سے ۱۱۱۱۱۱۱۱ تک ہوتی ہے۔ || IP پته ثابته یا متحرکه کېدای شي. ثابته IP پته هېڅکله نه بدلېږي او دایمي انټرنېټ پته ده. متحرکه IP پته یوه لنډمهاله پته ده چې هر ځل کله چې کمپیوټر یا وسیله انټرنېټ ته لاسرسی ومومي ټاکل کېږي. پته له ۳۲ دوتایي بټونو جوړه ده چې د فرعي شبکې د ماسک په مرسته په شبکې برخه او کوربه برخه وېشل کېدای شي. ۳۲ دوتایي بټونه په څلورو اکټېټونو (۱ اکټېټ = ۸ بټونه) ماتېږي. هر اکټېټ په لسیزه کې ښودل کېږي او په نقطه جلا کېږي. د دې لپاره IP پته په نقطه لرونکې لسیزه بڼه (د بېلګې په توګه ۱۷۲.۱۶.۸۱.۱۰۰) کې بیانېږي. په هر اکټېټ کې ارزښت په لسیزه کې له ۰ نه ۲۵۵ پورې، یا په دوتایي کې ۰۰۰۰۰۰۰۰ - ۱۱۱۱۱۱۱۱ پورې دی.
