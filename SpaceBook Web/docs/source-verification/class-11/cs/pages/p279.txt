## 8.3.1 Creating Access Form || ۸.۳.۱ ایکسیس فارم بنانا || ۸.۳.۱ د Access فورم جوړول
p Access 2007 has several automatic tools for creating forms. These tools are located in the Forms group on the Create tab in the Ribbon. The Access 2007 forms tools include: || ایکسیس ۲۰۰۷ میں فارمز بنانے کے کئی خودکار اوزار ہیں۔ یہ اوزار ربن میں کریٹ ٹیب پر فارمز گروپ میں واقع ہیں۔ ایکسیس ۲۰۰۷ کے فارمز اوزار میں شامل ہیں: || Access 2007 د فورمونو جوړولو لپاره څو اتومات وسایل لري. دا وسایل په ربن کې په Create ټب د Forms ډله کې موقعیت لري. د Access 2007 د فورمونو وسایل شاملوي:
p The Form command makes a basic form, showing a single record at a time. || فارم کمانڈ ایک بنیادی فارم بناتی ہے جو ایک وقت میں ایک ہی ریکارڈ دکھاتا ہے۔ || د Form حکم یو بنسټیز فورم جوړوي چې په یو وخت کې یو واحد ثبت ښيي.
p The Split Form command creates a form showing one record on top, and includes the datasheet view of entire source table on the bottom. || اسپلٹ فارم کمانڈ ایسا فارم بناتی ہے جو اوپر ایک ریکارڈ دکھاتا ہے اور نیچے پورے ماخذ ٹیبل کا ڈیٹا شیٹ ویو شامل کرتا ہے۔ || د Split Form حکم داسې فورم جوړوي چې په پورتنۍ برخه یو ثبت ښيي او په ښکتنۍ برخه کې د ټول سرچینې جدول د ډېټا شیټ لید شاملوي.
p The Multiple Items command creates a form that shows all the records at once, which looks very similar to the source table in datasheet view. || ملٹیپل آئٹمز کمانڈ ایسا فارم بناتی ہے جو تمام ریکارڈز ایک ساتھ دکھاتا ہے، جو ڈیٹا شیٹ ویو میں ماخذ ٹیبل سے بہت مشابہ لگتا ہے۔ || د Multiple Items حکم داسې فورم جوړوي چې ټول ثبتونه په یو ځل ښيي، چې د ډېټا شیټ په لید کې د سرچینې جدول سره ډیر ورته ښکاري.
p The Form Wizard is hidden under the More Forms command. It takes users through the process of creating more customized forms. || فارم ویزرڈ مور فارمز کمانڈ کے نیچے چھپا ہوا ہے۔ یہ صارفین کو زیادہ حسبِ ضرورت فارمز بنانے کے عمل سے گزارتا ہے۔ || د Form Wizard د More Forms حکم لاندې پټ دی. دا کاروونکي د ډیرو دودیزو فورمونو د جوړولو پروسې له لارې بیایي.
## a. To Create a Form using the Form Command || الف۔ فارم کمانڈ استعمال کر کے فارم بنانا || الف. د Form حکم په کارولو فورم جوړول
p The basic Form command is the one that allows the person entering data to see just one record at a time. It also includes all the fields in the source table and the user can modify the layout of the basic form to hide fields or add controls. || بنیادی فارم کمانڈ وہ ہے جو ڈیٹا درج کرنے والے شخص کو ایک وقت میں صرف ایک ریکارڈ دیکھنے کی اجازت دیتی ہے۔ اس میں ماخذ ٹیبل کی تمام فیلڈز شامل ہوتی ہیں اور صارف بنیادی فارم کی ترتیب میں ترمیم کر کے فیلڈز چھپا سکتا ہے یا کنٹرولز شامل کر سکتا ہے۔ || بنسټیز Form حکم هغه دی چې ډېټا دخلوونکي کس ته اجازه ورکوي چې په یو وخت کې یوازې یو ثبت وګوري. دا د سرچینې جدول ټولې ساحې هم شاملوي او کاروونکی کولای شي د بنسټیز فورم ترتیب بدل کړي ترڅو ساحې پټې کړي یا کنټرولونه زیات کړي.
p The following steps are used to create a form using this command. || اس کمانڈ کے ذریعے فارم بنانے کے لیے درج ذیل اقدامات استعمال ہوتے ہیں۔ || د دې حکم په کارولو فورم جوړولو لپاره لاندې ګامونه کارول کېږي.
p Highlight the table to use as a source table. || وہ ٹیبل نمایاں کریں جسے ماخذ ٹیبل کے طور پر استعمال کرنا ہو۔ || هغه جدول روښانه کړئ چې د سرچینې جدول په توګه کارول کېږي.
p With the source table highlighted, select the Form command from the Forms command group in the Create tab on the Ribbon. || ماخذ ٹیبل نمایاں ہونے کے ساتھ ربن پر کریٹ ٹیب میں فارمز کمانڈ گروپ سے فارم کمانڈ منتخب کریں۔ || د سرچینې جدول روښانه ټاکلو سره په ربن د Create ټب کې د Forms د حکمونو ډلې نه د Form حکم وټاکئ.
p The new form is created and opens in the object pane. Figure 8.22 shows a form created for Student table. || نیا فارم بن جاتا ہے اور آبجیکٹ پین میں کھل جاتا ہے۔ شکل ۸.۲۲ اسٹوڈنٹ ٹیبل کے لیے بنایا گیا فارم دکھاتی ہے۔ || نوی فورم جوړېږي او د څیز پټه کې پرانیستل کېږي. ۸.۲۲ انځور د زده کوونکي جدول لپاره جوړ شوی فورم ښيي.
