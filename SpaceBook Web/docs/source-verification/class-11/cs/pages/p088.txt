## 3.1.3 System Bus || ۳.۱.۳ سسٹم بس || ۳.۱.۳ سیسټم بس
p A bus is a data communication path over which information is transferred a byte or word at a time. System bus connects the central processing unit to main memory on the motherboard. The majority of system buses are made up of 50 to 100 distinct lines for communication. ## a. Data Bus || الف۔ ڈیٹا بس || الف. د ډېټا بس
p Data bus is the bidirectional bus. It can communicate in two ways, but in one direction at a time. It handles the transfer of data and instructions. The data bus is used to transfer instructions from memory to the CPU for execution. It carries data (operands) to and from the CPU and memory as required. It is also used to transfer data between memory and I/O devices during input output operations. A typical data bus is 32-bits wide. This means that up to 32-bits of data can travel through a data bus every second. New computers have 64-bit data buses and even more. || ڈیٹا بس دو طرفہ بس ہے۔ یہ دو طریقوں سے رابطہ کر سکتی ہے لیکن ایک وقت میں ایک سمت میں۔ یہ ڈیٹا اور ہدایات کی منتقلی سنبھالتی ہے۔ ڈیٹا بس ہدایات کو میموری سے عمل کے لیے سی پی یو میں منتقل کرنے کے لیے استعمال ہوتی ہے۔ یہ ضرورت کے مطابق سی پی یو اور میموری کی طرف اور وہاں سے ڈیٹا (آپرینڈز) لے جاتی ہے۔ یہ ان پٹ آؤٹ پٹ اعمال کے دوران میموری اور آئی / او آلات کے درمیان ڈیٹا منتقل کرنے کے لیے بھی استعمال ہوتی ہے۔ ایک عام ڈیٹا بس ۳۲ بٹ چوڑی ہوتی ہے۔ اس کا مطلب ہے کہ ہر سیکنڈ میں ۳۲ بٹس تک ڈیٹا ڈیٹا بس سے گزر سکتا ہے۔ نئے کمپیوٹرز میں ۶۴ بٹ ڈیٹا بسیں اور اس سے بھی زیادہ ہیں۔ || د ډېټا بس دوه لورې بس دی. دا په دوو لارو اړیکه نیولای شي، خو په یو وخت کې په یو لوري. دا د ډېټا او لارښوونو لېږد اداره کوي. د ډېټا بس لارښوونې له حافظې نه د پلي کولو لپاره CPU ته لېږدولو لپاره کارول کېږي. دا ډېټا (عملوندونه) د اړتیا مطابق CPU او حافظې ته او له هغو نه وړي. دا د دخل وتل د عملونو پر مهال د حافظې او I/O وسایلو ترمنځ ډېټا لېږدولو لپاره هم کارول کېږي. یو عادي ډېټا بس ۳۲ بټه پلن دی. دا مانا چې تر ۳۲ بټه ډېټا هره ثانیه د ډېټا بس له لارې تېرېدای شي. نوي کمپیوټرونه ۶۴ بټه ډېټا بسونه او حتی ډیر لري.
## b. Address Bus || ب۔ ایڈریس بس || ب. د پتې بس
p Address bus carries addresses not data. An address is defined as a label, symbol, or other set of characters used to designate a location or register where information is stored. Before data or instructions can be written into or read from memory by the CPU or I/O sections, an address must be transmitted to memory over the address bus. The number of lines on the bus determines the number of addressable memory elements. For example an 8-bit bus can represent 2^8 i.e. 256 unique addresses. A 16-bit bus can address 65536 unique addresses. || ایڈریس بس پتے لے جاتی ہے، ڈیٹا نہیں۔ پتہ ایک لیبل، علامت یا حروف کے دوسرے سیٹ کے طور پر بیان کیا جاتا ہے جو اس مقام یا رجسٹر کی نشاندہی کرتا ہے جہاں معلومات محفوظ ہوں۔ اس سے پہلے کہ سی پی یو یا آئی / او حصے میموری میں ڈیٹا یا ہدایات لکھ سکیں یا اس سے پڑھ سکیں، ایک پتہ ایڈریس بس کے ذریعے میموری کو منتقل کرنا ضروری ہے۔ بس پر لائنوں کی تعداد قابلِ پتہ میموری اجزاء کی تعداد کا تعین کرتی ہے۔ مثلاً ۸ بٹ بس ۲^۸ یعنی ۲۵۶ منفرد پتے ظاہر کر سکتی ہے۔ ۱۶ بٹ بس ۶۵۵۳۶ منفرد پتوں کو مخاطب کر سکتی ہے۔ || د پتې بس پتې وړي، ډېټا نه. پته د یو لیبل، نښې یا د توریو یوې بلې ټولګې په توګه تعریف کېږي چې د هغه ځای یا رجستر ټاکلو لپاره کارول کېږي چېرته چې معلومات ساتل کېږي. مخکې له دې چې CPU یا I/O برخې په حافظه ډېټا یا لارښوونې ولیکي یا له هغې نه ولولي، یوه پته باید د پتې بس له لارې حافظې ته ولېږدول شي. په بس د کرښو شمېر د پته کېدونکو حافظې عناصرو شمېر ټاکي. د بېلګې په توګه یو ۸ بټه بس ۲^۸ یعنې ۲۵۶ ځانګړې پتې ښودلای شي. یو ۱۶ بټه بس ۶۵۵۳۶ ځانګړې پتې پتهولای شي.
