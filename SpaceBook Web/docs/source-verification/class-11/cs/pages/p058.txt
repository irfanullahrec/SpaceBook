## b. RAM (Random Access Memory) || ب۔ ریم (رینڈم ایکسیس میموری) || ب. RAM (تصادفي لاسرسي حافظه)
p Random Access Memory (RAM) is the common type of computer memory. It is the Read and Write (R/W) memory of a computer. The User can write information to it and read information from it. RAM is a volatile memory; it means information written to it can be accessed as long as power is on and when the power is off, it cannot be accessed. RAM holds data and processing instructions temporarily until the CPU needs them. || رینڈم ایکسیس میموری (ریم) کمپیوٹر میموری کی عام قسم ہے۔ یہ کمپیوٹر کی پڑھنے اور لکھنے (آر / ڈبلیو) والی میموری ہے۔ صارف اس میں معلومات لکھ سکتا ہے اور اس سے معلومات پڑھ سکتا ہے۔ ریم ایک غیر مستقل میموری ہے؛ اس کا مطلب ہے کہ اس میں لکھی ہوئی معلومات تک اس وقت تک رسائی ہو سکتی ہے جب تک بجلی چالو ہو اور بجلی بند ہونے پر اس تک رسائی نہیں ہو سکتی۔ ریم ڈیٹا اور پراسیسنگ کی ہدایات کو عارضی طور پر اس وقت تک رکھتی ہے جب تک سی پی یو کو ان کی ضرورت ہو۔ || تصادفي لاسرسي حافظه (RAM) د کمپیوټر حافظې عام ډول دی. دا د کمپیوټر د لوستلو او لیکلو (R/W) حافظه ده. کاروونکی پکې معلومات لیکلای شي او له هغې نه معلومات لوستلای شي. RAM یوه بې ثباته حافظه ده؛ مانا دا چې په هغې کې لیکل شوي معلوماتو ته تر هغه وخته لاسرسی کېدای شي څومره چې بریښنا روانه وي او کله چې بریښنا بنده شي نو لاسرسی نشي کېدای. RAM ډېټا او د پروسس لارښوونې په لنډمهاله توګه تر هغه ساتي چې CPU ورته اړتیا ولري.
p In RAM, transistors make up the individual storage cells which can each “remember” an amount of data. Physically, RAM consists of small electronic chips which are mounted in modules (small printed circuit boards). These modules are installed in the Computer’s motherboard using sockets. Different types of RAM modules are shown in Figure 2.4. || ریم میں ٹرانزسٹرز انفرادی ذخیرہ خانے بناتے ہیں جن میں سے ہر ایک ڈیٹا کی ایک مقدار ’’یاد‘‘ رکھ سکتا ہے۔ طبعی طور پر ریم چھوٹی برقی چپس پر مشتمل ہوتی ہے جو ماڈیولز (چھوٹے پرنٹڈ سرکٹ بورڈز) میں لگی ہوتی ہیں۔ یہ ماڈیولز کمپیوٹر کے مدر بورڈ میں ساکٹس کے ذریعے نصب کیے جاتے ہیں۔ ریم ماڈیولز کی مختلف اقسام شکل ۲.۴ میں دکھائی گئی ہیں۔ || په RAM کې ټرانزیستورونه انفرادي ذخیره حجرې جوړوي چې هر یو یې د ډېټا یو مقدار ‘یادولای’ شي. په فزیکي توګه RAM له وړو برېښنايي چپونو جوړ دی چې په ماډولونو (وړو چاپ شویو سرکټ بورډونو) کې نصب وي. دا ماډولونه د کمپیوټر په مدربورډ کې د ساکټونو په کارولو نصبېږي. د RAM ماډولونو مختلف ډولونه ۲.۴ انځور کې ښودل شوي دي.
