## Data Register || ڈیٹا رجسٹر || د ډېټا رجستر
p Data Register has a special role in multiply and divide operations. It works like a buffer and holds anything that is copied from the memory ready for the processor to use it. || ڈیٹا رجسٹر ضرب اور تقسیم کے عمل میں خاص کردار رکھتا ہے۔ یہ بفر کی طرح کام کرتا ہے اور میموری سے نقل کی گئی ہر چیز کو پراسیسر کے استعمال کے لیے تیار رکھتا ہے۔ || د ډېټا رجستر د ضرب او وېش په عملیاتو کې ځانګړی رول لري. دا د بفر په څېر کار کوي او هر هغه څه ساتي چې له حافظې نه کاپي شوي او د پروسیسر د کارولو لپاره چمتو وي.

## Database || ڈیٹا بیس || ډېټابېس
p Database is a shared collection of logically related data (and a description of this data i.e. metadata), designed to meet the information needs of multiple users in an organization. || ڈیٹا بیس منطقی طور پر متعلقہ ڈیٹا (اور اس ڈیٹا کی تفصیل یعنی میٹا ڈیٹا) کا مشترکہ مجموعہ ہے جو کسی ادارے میں متعدد صارفین کی معلوماتی ضروریات پوری کرنے کے لیے بنایا گیا ہو۔ || ډېټابېس د منطقي اړوندې ډېټا (او د دې ډېټا تشریح یعنې میټا ډېټا) ګډه ټولګه ده، چې په یوه اداره کې د ډیرو کاروونکو د معلوماتي اړتیاوو د پوره کولو لپاره ډیزاین شوې ده.
## Database management system (DBMS) || ڈیٹا بیس مینجمنٹ سسٹم (ڈی بی ایم ایس) || د ډېټابېس مدیریت سیسټم (DBMS)
p A database management system (DBMS) is a set of programs that allow users to create a database, edit and update data in database files, store and retrieve data from those database files. || ڈیٹا بیس مینجمنٹ سسٹم (ڈی بی ایم ایس) پروگراموں کا ایک مجموعہ ہے جو صارفین کو ڈیٹا بیس بنانے، ڈیٹا بیس فائلوں میں ڈیٹا میں ترمیم اور اپ ڈیٹ کرنے اور ان فائلوں سے ڈیٹا محفوظ اور حاصل کرنے کی اجازت دیتا ہے۔ || د ډېټابېس مدیریت سیسټم (DBMS) د پروګرامونو یوه ټولګه ده چې کاروونکو ته اجازه ورکوي ډېټابېس جوړ کړي، په ډېټابېس فایلونو کې ډېټا سمه او تازه کړي، له هغو ډېټابېس فایلونو نه ډېټا ذخیره او ترلاسه کړي.
## Database model || ڈیٹا بیس ماڈل || ډېټابېس ماډل

## DDR SDRAM || ڈی ڈی آر ایس ڈی ریم || ډي ډي آر ایس ډي ریم (DDR SDRAM)
