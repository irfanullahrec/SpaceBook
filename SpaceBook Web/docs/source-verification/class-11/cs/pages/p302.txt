## SUMMARY || خلاصہ || لنډیز
p Database development is the creation, organization, management and manipulation of database systems for organizations. || ڈیٹا بیس ڈیولپمنٹ اداروں کے لیے ڈیٹا بیس سسٹمز کی تخلیق، تنظیم، انتظام اور ان میں ترمیم ہے۔ || د ډېټابېس جوړونه د ادارو لپاره د ډېټابېس سیسټمونو جوړول، تنظیم، مدیریت او کار ترې اخیستل دي.
p Microsoft Access is a database management system. || مائیکروسافٹ ایکسیس ڈیٹا بیس مینجمنٹ سسٹم ہے۔ || مایکروسافټ Access یو ډېټابېس مدیریت سیسټم دی.
p Microsoft SQL Server is a relational database management system used to store and retrieve data as requested by other software applications. || مائیکروسافٹ ایس کیو ایل سرور ریلیشنل ڈیٹا بیس مینجمنٹ سسٹم ہے جو دوسری سافٹ ویئر ایپلیکیشنز کی درخواست پر ڈیٹا محفوظ اور حاصل کرنے کے لیے استعمال ہوتا ہے۔ || مایکروسافټ SQL خدمتګار یو اړوند ډېټابېس مدیریت سیسټم دی چې د نورو سافټویر اپلېکېشنونو د غوښتنې سره سم ډېټا ذخیره او ترلاسه کولو لپاره کارول کېږي.
p OpenOffice Base is the database module of OpenOffice. It is a fully featured database management system. || اوپن آفس بیس اوپن آفس کا ڈیٹا بیس ماڈیول ہے۔ یہ مکمل خصوصیات والا ڈیٹا بیس مینجمنٹ سسٹم ہے۔ || اوپن آفس بیس د اوپن آفس د ډېټابېس ماډل دی. دا یو بشپړ ځانګړتیاوو لرونکی ډېټابېس مدیریت سیسټم دی.
p A table is a set of columns and rows, with each column referred to as a field and each row of a table is referred to as a record. || ٹیبل کالموں اور قطاروں کا مجموعہ ہے، جس میں ہر کالم کو فیلڈ اور ٹیبل کی ہر قطار کو ریکارڈ کہا جاتا ہے۔ || جدول د ستونونو او قطارونو یوه ټولګه ده، چې هر ستون ته ساحه او د جدول هر قطار ته ثبت ویل کېږي.
p Form is a window that displays data for viewing, entering and editing information. || فارم ایک ونڈو ہے جو معلومات دیکھنے، درج کرنے اور ترمیم کے لیے ڈیٹا دکھاتی ہے۔ || فورم یوه کړکۍ ده چې د معلوماتو د لیدلو، دخلولو او سمولو لپاره ډېټا ښيي.
p Query is used to gather information based on one or more criteria. || کوئری ایک یا زیادہ معیارات کی بنیاد پر معلومات جمع کرنے کے لیے استعمال ہوتی ہے۔ || پوښتنه د یو یا ډیرو معیارونو پر بنسټ د معلوماتو راټولولو لپاره کارول کېږي.
p Report is used for printing information from database. || رپورٹ ڈیٹا بیس سے معلومات پرنٹ کرنے کے لیے استعمال ہوتی ہے۔ || راپور له ډېټابېس نه د معلوماتو د چاپولو لپاره کارول کېږي.
p Text is the default data type to all fields. The maximum size of text field is 255 characters. || ٹیکسٹ تمام فیلڈز کے لیے طے شدہ ڈیٹا ٹائپ ہے۔ ٹیکسٹ فیلڈ کا زیادہ سے زیادہ سائز ۲۵۵ حروف ہے۔ || متن د ټولو ساحو لپاره ډیفالټ د ډېټا ډول دی. د متن ساحې اعظمي کچه ۲۵۵ توري دي.
p Memo data type allows as many as 63999 characters to fields. Users use them to provide descriptive comments. || میمو ڈیٹا ٹائپ فیلڈز کو ۶۳۹۹۹ حروف تک کی اجازت دیتی ہے۔ صارفین انہیں وضاحتی تبصرے فراہم کرنے کے لیے استعمال کرتے ہیں۔ || د یادښت د ډېټا ډول ساحو ته تر ۶۳۹۹۹ توري اجازه ورکوي. کاروونکي هغه د تشریحي نظرونو لپاره کاروي.
p Number data type is assigned to numeric fields. || نمبر ڈیٹا ٹائپ عددی فیلڈز کو تفویض کی جاتی ہے۔ || د شمېرې د ډېټا ډول عددي ساحو ته ټاکل کېږي.
p AutoNumber field is a numeric (Long Integer) value that Access automatically fills in for each new record that is added to a table. || آٹو نمبر فیلڈ ایک عددی (لانگ انٹیجر) قدر ہے جو ایکسیس ٹیبل میں شامل ہونے والے ہر نئے ریکارڈ کے لیے خود بخود بھرتا ہے۔ || د اتومات شمېرې ساحه یو عددي (اوږده بشپړ عدد) ارزښت دی چې Access د هر نوي ثبت لپاره چې جدول ته زیاتېږي په اتوماتیک ډول ډکوي.
p Yes/No is logical data type which uses 1 for Yes (True) and 0 for No (False). || ہاں/نہیں منطقی ڈیٹا ٹائپ ہے جو ہاں (درست) کے لیے ۱ اور نہیں (غلط) کے لیے ۰ استعمال کرتی ہے۔ || هو/نه یو منطقي د ډېټا ډول دی چې د هو (سم) لپاره ۱ او د نه (غلط) لپاره ۰ کاروي.
p Date/Time data type is used to assign special fixed format for date/time data. || تاریخ/وقت ڈیٹا ٹائپ تاریخ/وقت کے ڈیٹا کے لیے خصوصی مقررہ شکل تفویض کرنے کے لیے استعمال ہوتی ہے۔ || د نېټې/وخت د ډېټا ډول د نېټې/وخت ډېټا لپاره ځانګړې ټاکلې بڼې ټاکلو لپاره کارول کېږي.
