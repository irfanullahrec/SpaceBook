## 1.3.3 Difference between Soft Copy and Hard Copy || ۱.۳.۳ سافٹ کاپی اور ہارڈ کاپی میں فرق || ۱.۳.۳ د سافټ کاپي او هارډ کاپي توپیر
table سافٹ کاپی اور ہارڈ کاپی میں فرق || Difference between Soft Copy and Hard Copy || د سافټ کاپي او هارډ کاپي توپیر
th | No. | Soft Copy | Hard Copy
tr | 1 | The output which is stored in a memory and displayed on the screen is called Soft Copy | The output which is printed on a paper is called Hard Copy.
tr | 2 | It is easy to modify and correct. | It is hard to modify and correct.
tr | 3 | An electronics medium is required to read out softcopy output. | No electronics medium is required to read out hard copy output.
tr | 4 | Soft copy is intangible | Hard copy is tangible.
tr | 5 | Soft Copy is electronic/digital version of a document. | Hard copy is a physical version of a document printed on paper.
tr | 6 | Soft copy can be transmitted electrically to any place. | Hard copy can only be transmitted physically from one place to the other.
endtable
