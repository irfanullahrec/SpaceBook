## b. Saving the Query || ب۔ کوئری محفوظ کرنا || ب. پوښتنه ساتل
p The following steps are used to save the query for later use. || کوئری کو بعد میں استعمال کے لیے محفوظ کرنے کے لیے درج ذیل اقدامات استعمال ہوتے ہیں۔ || پوښتنه د وروستي کارونې لپاره د ساتلو لپاره لاندې ګامونه کارول کېږي.
p Right click on the query tab. || کوئری ٹیب پر رائٹ کلک کریں۔ || د پوښتنې ټب په ښي کلیک وکړئ.
p When the Save As dialog box opens, give query a meaningful name. || جب سیو ایز ڈائیلاگ باکس کھلے تو کوئری کو بامعنی نام دیں۔ || کله چې د Save As خبرې اترې بکس پرانیستل کېږي، پوښتنې ته مانادار نوم ورکړئ.
p Click OK. || ٹھیک ہے پر کلک کریں۔ || OK کلیک کړئ.
p The query will now be listed in the object list on the left side of the Access window. || کوئری اب ایکسیس ونڈو کے بائیں طرف آبجیکٹ لسٹ میں درج ہو گی۔ || پوښتنه به اوس د Access کړکۍ په کیڼه خوا کې د څیزونو لیست کې لیست شي.
