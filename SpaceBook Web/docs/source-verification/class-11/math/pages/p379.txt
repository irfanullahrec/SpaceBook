p However if we restrict the domain to the interval $\left(-\dfrac\pi2,\dfrac\pi2\right)$, the restricted function $y=\tan x,\ -\dfrac\pi2<x<\dfrac\pi2$ is one-to-one and hence has an inverse. This is called the **principal tangent function** and is denoted by $y=\text{Tan}\,x$ (Capital T). This leads to the definition of inverse tangent function as follows. The inverse tangent function $\text{Tan}^{-1}$ is defined by $y=\text{Tan}^{-1}x$ if and only if $x=\text{Tan}\,y$, where $-\infty<x<\infty,\ -\dfrac\pi2<y<\dfrac\pi2$. example 20 | Find the exact values of (i) $\text{Tan}^{-1}(1)$ (ii) $\text{Tan}^{-1}(-\sqrt3)$ (iii) $\text{Tan}\left(\dfrac{3\pi}2\right)$ || صحیح قیمتیں معلوم کریں (i) $\text{Tan}^{-1}(1)$ (ii) $\text{Tan}^{-1}(-\sqrt3)$ (iii) $\text{Tan}\left(\dfrac{3\pi}2\right)$ || دقیق ارزښتونه پیدا کړئ (i) $\text{Tan}^{-1}(1)$ (ii) $\text{Tan}^{-1}(-\sqrt3)$ (iii) $\text{Tan}\left(\dfrac{3\pi}2\right)$
p **Solution:** Let $y=\text{Tan}^{-1}(1)$. We seek the angle $y,\ -\dfrac\pi2<y<\dfrac\pi2$ whose tangent equals 1, i.e., $\text{Tan}\,y=1$, for $-\dfrac\pi2<y<\dfrac\pi2\Rightarrow y=\dfrac\pi4$. Therefore $y=\text{Tan}^{-1}(1)=\dfrac\pi4$. (ii) Let $y=\text{Tan}^{-1}(-\sqrt3)$. We seek the angle $y$ where $-\dfrac\pi2<y<\dfrac\pi2$ whose tangent $-\sqrt3$, that is $\text{Tan}\,y=-\sqrt3,\ -\dfrac\pi2<y<\dfrac\pi2$. The reference angle in the first quadrant is $\dfrac\pi3$. Since $\tan(-\theta)=-\tan\theta$. || **حل:** فرض کریں $y=\text{Tan}^{-1}(1)$۔ ہم زاویہ $y,\ -\dfrac\pi2<y<\dfrac\pi2$ تلاش کرتے ہیں جس کا ٹینجنٹ 1 کے برابر ہو، یعنی $\text{Tan}\,y=1$، $-\dfrac\pi2<y<\dfrac\pi2\Rightarrow y=\dfrac\pi4$۔ لہٰذا $y=\text{Tan}^{-1}(1)=\dfrac\pi4$۔ (ii) فرض کریں $y=\text{Tan}^{-1}(-\sqrt3)$۔ ہم زاویہ $y$ تلاش کرتے ہیں جہاں $-\dfrac\pi2<y<\dfrac\pi2$ اور جس کا ٹینجنٹ $-\sqrt3$ ہے، یعنی $\text{Tan}\,y=-\sqrt3,\ -\dfrac\pi2<y<\dfrac\pi2$۔ پہلے ربع میں حوالہ زاویہ $\dfrac\pi3$ ہے۔ چونکہ $\tan(-\theta)=-\tan\theta$۔ || **حل:** فرض کړئ $y=\text{Tan}^{-1}(1)$. موږ هغه زاویه $y,\ -\dfrac\pi2<y<\dfrac\pi2$ لټوو چې ټینجنټ یې د 1 سره برابر وي، یعنې $\text{Tan}\,y=1$، د $-\dfrac\pi2<y<\dfrac\pi2\Rightarrow y=\dfrac\pi4$ لپاره. له دې امله $y=\text{Tan}^{-1}(1)=\dfrac\pi4$.
