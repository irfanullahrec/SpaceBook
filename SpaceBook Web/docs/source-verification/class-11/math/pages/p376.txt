p The principal cosine function has an inverse denoted by $\text{Cos}^{-1}$. The inverse cosine function $\text{Cos}^{-1}$ is defined by $y=\text{Cos}^{-1}x$ if and only if $x=\text{Cos}\,y$, for $-1\le x\le1$, and $0\le y\le\pi$. This is also referred to Arc cosine function. Using general properties of inverse functions, we obtain $\text{Cos}(\text{Cos}^{-1}x)=\text{Cos}(\text{Arc}\cos x)=x$, if $-1\le x\le1$, $\text{Cos}^{-1}(\text{Cos}\,y)=\text{Arc}\cos(\text{Cos}\,y)=y$, if $0\le y\le\pi$. The notation Arc $\cos x$ (Capital A) is sometimes used instead of $\text{Cos}^{-1}x$. The graph of the inverse cosine function can be found by reflecting the bold portion of Figure 12.38 in the line $y=x$. p **Solution:** (i) Let $y=\text{Cos}^{-1}0$, we know that $y=\text{Arc}\cos(0)$ if and only if $\cos y=0$ and $y\in[0,\pi]$.
