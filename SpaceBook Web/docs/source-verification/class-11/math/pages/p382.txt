example 22 | Evaluate: (i) $\text{Arc}\sec2$ (ii) $\text{Arc}\sec(-2)$ (iii) $\text{Arc}\tan(3.5)$ (iv) $\text{Arc}\tan(-2.3)$ || قیمت معلوم کریں: (i) $\text{Arc}\sec2$ (ii) $\text{Arc}\sec(-2)$ (iii) $\text{Arc}\tan(3.5)$ (iv) $\text{Arc}\tan(-2.3)$ || ارزښت پیدا کړئ: (i) $\text{Arc}\sec2$ (ii) $\text{Arc}\sec(-2)$ (iii) $\text{Arc}\tan(3.5)$ (iv) $\text{Arc}\tan(-2.3)$
p **Solution:** (i) Let $\theta=\text{Arc}\sec2$, which is an inverse function. By definition, $\sec\theta=2$, where $\theta\in[0,\pi]-\left\{\dfrac\pi2\right\}$. We know that $\sec\dfrac\pi3=2\Rightarrow\theta=\dfrac\pi3$ (printed as $\dfrac\pi2$) $\in[0,\pi]$. (ii) Let $\theta=\text{Arc}\sec(-2)$. This is an inverse relation not a function. Therefore, there are infinitely many values for $\theta$. Since $\sec\theta$ is negative, the reference angle lies both in the quadrants (II) and (III) which are $\theta_1=\pi-\dfrac\pi3=\dfrac{2\pi}3$ and $\theta_2=\pi+\dfrac\pi3=\dfrac{4\pi}3$. || **حل:** (i) فرض کریں $\theta=\text{Arc}\sec2$ جو معکوس تفاعل ہے۔ تعریف کے مطابق $\sec\theta=2$، جہاں $\theta\in[0,\pi]-\left\{\dfrac\pi2\right\}$۔ ہم جانتے ہیں کہ $\sec\dfrac\pi3=2\Rightarrow\theta=\dfrac\pi3$ (چھپا ہوا $\dfrac\pi2$) $\in[0,\pi]$۔ (ii) فرض کریں $\theta=\text{Arc}\sec(-2)$۔ یہ معکوس نسبت ہے تفاعل نہیں۔ لہٰذا $\theta$ کی لامحدود قیمتیں ہیں۔ چونکہ $\sec\theta$ منفی ہے، حوالہ زاویہ ربع (II) اور (III) دونوں میں ہے جو ہیں $\theta_1=\pi-\dfrac\pi3=\dfrac{2\pi}3$ اور $\theta_2=\pi+\dfrac\pi3=\dfrac{4\pi}3$۔ || **حل:** (i) فرض کړئ $\theta=\text{Arc}\sec2$ چې معکوس تابع ده. د تعریف له مخې $\sec\theta=2$، چېرته چې $\theta\in[0,\pi]-\left\{\dfrac\pi2\right\}$. موږ پوهېږو چې $\sec\dfrac\pi3=2\Rightarrow\theta=\dfrac\pi3$ (چاپ شوی $\dfrac\pi2$) $\in[0,\pi]$. (ii) فرض کړئ $\theta=\text{Arc}\sec(-2)$. دا معکوسه اړیکه ده، تابع نه ده. له دې امله د $\theta$ بې شمېره ارزښتونه شته. ځکه چې $\sec\theta$ منفي دی، مرجع زاویه په (II) او (III) دواړو ربعو کې ده چې دي $\theta_1=\pi-\dfrac\pi3=\dfrac{2\pi}3$ او $\theta_2=\pi+\dfrac\pi3=\dfrac{4\pi}3$.
