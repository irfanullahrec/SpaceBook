example 4 | Simplify each expression, given that $0<x<\pi/2$. (i) $\sin(\pi/2+x)$ (ii) $\cos(\pi/2+x)$ (iii) $\tan(3\pi/2+x)$ (iv) $\cot(2\pi-x)$ (v) $\sin(\pi+x)$ (vi) $\cos(2\pi+x)$ || ہر اظہار کو سادہ کریں، دیا گیا ہے کہ $0<x<\pi/2$۔ (i) $\sin(\pi/2+x)$ (ii) $\cos(\pi/2+x)$ (iii) $\tan(3\pi/2+x)$ (iv) $\cot(2\pi-x)$ (v) $\sin(\pi+x)$ (vi) $\cos(2\pi+x)$ || هر عبارت ساده کړئ، ورکړل شوی دی چې $0<x<\pi/2$. (i) $\sin(\pi/2+x)$ (ii) $\cos(\pi/2+x)$ (iii) $\tan(3\pi/2+x)$ (iv) $\cot(2\pi-x)$ (v) $\sin(\pi+x)$ (vi) $\cos(2\pi+x)$
p **Solution:** (i) $(\pi/2+x)$ is in the second quadrant, so $\sin(\pi/2+x)=\cos x$. (ii) $(\pi/2+x)$ is in the second quadrant, so $\cos(\pi/2+x)=-\sin x$. (iii) $(3\pi/2+x)$ is in the fourth quadrant, so $\tan(3\pi/2+x)=-\cot x$. (iv) $(2\pi-x)$ is in the fourth quadrant, so $\cot(2\pi-x)=-\cot x$ (printed as $-\sin x$). (v) $(\pi+x)$ is in the third quadrant, so $\sin(\pi+x)=-\sin x$ (printed as $-\cot x$). (vi) $(2\pi+x)$ is in the first quadrant, so $\cos(2\pi+x)=\cos x$. || **حل:** (i) $(\pi/2+x)$ دوسرے ربع میں ہے اس لیے $\sin(\pi/2+x)=\cos x$۔ (ii) $(\pi/2+x)$ دوسرے ربع میں ہے اس لیے $\cos(\pi/2+x)=-\sin x$۔ (iii) $(3\pi/2+x)$ چوتھے ربع میں ہے اس لیے $\tan(3\pi/2+x)=-\cot x$۔ (iv) $(2\pi-x)$ چوتھے ربع میں ہے اس لیے $\cot(2\pi-x)=-\cot x$ (چھپا ہوا $-\sin x$)۔ (v) $(\pi+x)$ تیسرے ربع میں ہے اس لیے $\sin(\pi+x)=-\sin x$ (چھپا ہوا $-\cot x$)۔ (vi) $(2\pi+x)$ پہلے ربع میں ہے اس لیے $\cos(2\pi+x)=\cos x$۔ || **حل:** (i) $(\pi/2+x)$ په دویم ربع کې دی نو $\sin(\pi/2+x)=\cos x$. (ii) $(\pi/2+x)$ په دویم ربع کې دی نو $\cos(\pi/2+x)=-\sin x$. (iii) $(3\pi/2+x)$ په څلورم ربع کې دی نو $\tan(3\pi/2+x)=-\cot x$. (iv) $(2\pi-x)$ په څلورم ربع کې دی نو $\cot(2\pi-x)=-\cot x$ (چاپ شوی $-\sin x$). (v) $(\pi+x)$ په دریم ربع کې دی نو $\sin(\pi+x)=-\sin x$ (چاپ شوی $-\cot x$). (vi) $(2\pi+x)$ په لومړي ربع کې دی نو $\cos(2\pi+x)=\cos x$.
