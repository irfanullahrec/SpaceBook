example 14 | Use graph to find the solution of the equation $\cos\theta-\theta=0$ in the interval $-\dfrac\pi2\le\theta\le\dfrac\pi2$. || وقفے $-\dfrac\pi2\le\theta\le\dfrac\pi2$ میں مساوات $\cos\theta-\theta=0$ کا حل معلوم کرنے کے لیے گراف استعمال کریں۔ || په وقفه $-\dfrac\pi2\le\theta\le\dfrac\pi2$ کې د معادلې $\cos\theta-\theta=0$ د حل د موندلو لپاره ګراف وکاروئ.
p **Solution:** The equation $\cos\theta-\theta=0$ can be written as $\cos\theta=\theta$. Let $y=\cos\theta$ and $y=\theta$. If we draw the graphs of these two functions on the same set of coordinate axes, then their intersection point (if any) must be the solution of the given equation. We construct the tables of values of the two functions as follows: || **حل:** مساوات $\cos\theta-\theta=0$ کو $\cos\theta=\theta$ لکھا جا سکتا ہے۔ فرض کریں $y=\cos\theta$ اور $y=\theta$۔ اگر ہم ان دونوں تفاعل کے گراف ایک ہی محددی محوروں پر بنائیں تو ان کا نقطۂ تقاطع (اگر ہو) دی گئی مساوات کا حل ہوگا۔ ہم دونوں تفاعل کی قیمتوں کے جدول درج ذیل طرح بناتے ہیں: || **حل:** معادله $\cos\theta-\theta=0$ د $\cos\theta=\theta$ په توګه لیکل کېدای شي. فرض کړئ $y=\cos\theta$ او $y=\theta$. که موږ د دغو دوو تابعګانو ګرافونه په یوه همغږي محورونو رسم کړو نو د هغوی د تقاطع ټکی (که وي) باید د ورکړل شوې معادلې حل وي. موږ د دواړو تابعګانو د ارزښتونو جدولونه داسې جوړوو:

p We see that the graphs intersect at point A. The point lies about midway between 0 and $\dfrac\pi2$. Thus, we estimate this solution as $\theta=\dfrac\pi4$. **Verification.** Substituting the value of $\theta$ in the original equation, we obtain $\cos\left(\dfrac\pi4\right)-\dfrac\pi4=0$ || ہم دیکھتے ہیں کہ گراف نقطہ A پر ایک دوسرے کو کاٹتے ہیں۔ یہ نقطہ 0 اور $\dfrac\pi2$ کے تقریباً درمیان میں ہے۔ یوں ہم اس حل کا اندازہ $\theta=\dfrac\pi4$ لگاتے ہیں۔ **تصدیق۔** $\theta$ کی قیمت اصل مساوات میں رکھنے پر ہمیں ملتا ہے $\cos\left(\dfrac\pi4\right)-\dfrac\pi4=0$ || موږ ګورو چې ګرافونه په ټکي A کې سره مخېږي. ټکی د 0 او $\dfrac\pi2$ تر منځ نږدې په منځ کې پروت دی. په دې توګه موږ دا حل $\theta=\dfrac\pi4$ اټکل کوو. **تصدیق.** د $\theta$ ارزښت په اصلي معادله کې ایښودو سره موږ ترلاسه کوو $\cos\left(\dfrac\pi4\right)-\dfrac\pi4=0$
