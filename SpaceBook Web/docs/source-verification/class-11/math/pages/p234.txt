p Although $f$ is often used as a convenient function name and $x$ is often used as the independent variable, other letters can also be used. For example, $f(x)=x^2-7x+12$, $f(t)=t^2-7t+12$, and $g(s)=s^2-7s+12$ all define the same function. || اگرچہ $f$ اکثر آسان تفاعلی نام کے طور پر اور $x$ آزاد متغیر کے طور پر استعمال ہوتا ہے، دوسرے حروف بھی استعمال کیے جا سکتے ہیں۔ مثلاً $f(x)=x^2-7x+12$، $f(t)=t^2-7t+12$ اور $g(s)=s^2-7s+12$ سب ایک ہی تفاعل متعین کرتے ہیں۔ || که څه هم $f$ ډېر وخت د تابع د اسانه نوم په توګه او $x$ د خپلواک تغیر پذیر په توګه کارول کېږي، نور توري هم کارېدای شي. د بېلګې په توګه $f(x)=x^2-7x+12$، $f(t)=t^2-7t+12$ او $g(s)=s^2-7s+12$ ټول یو شان تابع ټاکي.
endbox
### 8.1.2 Domain and Range of a Function || 8.1.2 تفاعل کا دائرہ اور سعت || 8.1.2 د تابع ډومین او رینج
p Let $f:X\to Y$ be a function from a set $X$ to a set $Y$. Then set $X$ is called **domain** and the set $Y$ is called **codomain** of the function $f$. The set of all those elements of $Y$ which $f$ is assuming is called **range** of the function $f$. || فرض کریں $f:X\to Y$ سیٹ $X$ سے سیٹ $Y$ تک ایک تفاعل ہے۔ تب سیٹ $X$ تفاعل $f$ کا **دائرہ** اور سیٹ $Y$ اس کا **شریک دائرہ** کہلاتا ہے۔ $Y$ کے ان تمام عناصر کا سیٹ جو $f$ اختیار کرتا ہے تفاعل $f$ کی **سعت** کہلاتا ہے۔ || فرض کړئ $f:X\to Y$ د سېټ $X$ نه سېټ $Y$ ته یو تابع دی. نو سېټ $X$ د تابع $f$ **ډومین** او سېټ $Y$ **کو-ډومین** بلل کېږي. د $Y$ د ټولو هغو عناصرو سېټ چې $f$ یې اخلي د تابع $f$ **رینج** بلل کېږي.
p If the domain is not specified, then it is assumed to be the set of all real numbers. If $f$ is a function of $X$ into $Y$, the range is a subset of $Y$ but need not be all of $Y$. This has been shown in (Figure 8.4). || اگر دائرہ متعین نہ کیا گیا ہو تو فرض کیا جاتا ہے کہ وہ تمام حقیقی اعداد کا سیٹ ہے۔ اگر $f$، $X$ کا $Y$ میں تفاعل ہو تو سعت $Y$ کا ایک ذیلی سیٹ ہے مگر ضروری نہیں کہ پورا $Y$ ہو۔ یہ (شکل 8.4) میں دکھایا گیا ہے۔ || که ډومین ټاکل شوی نه وي نو فرض کېږي چې د ټولو حقیقي عددونو سېټ دی. که $f$ د $X$ نه $Y$ ته تابع وي، رینج د $Y$ فرعي سېټ دی خو اړینه نه ده چې ټول $Y$ وي. دا په (شکل 8.4) کې ښودل شوی دی.

p **Function Notation** $y=f(x)$. $f$ is the *name* of the function. $y$ is the dependent variable. $x$ is the independent variable. $y$ is the value of the function at $x$. || **تفاعلی علامت** $y=f(x)$۔ $f$ تفاعل کا *نام* ہے۔ $y$ تابع متغیر ہے۔ $x$ آزاد متغیر ہے۔ $y$، $x$ پر تفاعل کی قیمت ہے۔ || **د تابع نښه** $y=f(x)$. $f$ د تابع *نوم* دی. $y$ تړلی تغیر پذیر دی. $x$ خپلواک تغیر پذیر دی. $y$ په $x$ کې د تابع ارزښت دی.

### 8.1.3 One-to-one and onto Function || 8.1.3 ایک ایک اور پر تفاعل || 8.1.3 یو-یو او پر تابع
p (a) A function $f:X\to Y$ is said to be **one-to-one** (or **injective**) if distinct elements of $X$ have distinct images in $Y$ i.e. if $x_1$ and $x_2$ are distinct elements of $X$, then $f(x_1)\ne f(x_2)$ in $Y$. Equivalently, if $f(x_1)=f(x_2)$, then $x_1=x_2$. Sometimes we write 1-1 function for one-to-one function. || (a) تفاعل $f:X\to Y$ **ایک ایک** (یا **انجیکٹو**) کہلاتا ہے اگر $X$ کے مختلف عناصر کی $Y$ میں مختلف شبیہیں ہوں، یعنی اگر $x_1$ اور $x_2$، $X$ کے مختلف عناصر ہوں تو $Y$ میں $f(x_1)\ne f(x_2)$ ہو۔ مساوی طور پر اگر $f(x_1)=f(x_2)$ ہو تو $x_1=x_2$ ہو۔ کبھی ہم ایک ایک تفاعل کے لیے 1-1 تفاعل لکھتے ہیں۔ || (a) تابع $f:X\to Y$ **یو-یو** (یا **انجیکټیو**) بلل کېږي که د $X$ جلا عناصر د $Y$ په کې جلا انځورونه ولري، یعنې که $x_1$ او $x_2$ د $X$ جلا عناصر وي نو په $Y$ کې $f(x_1)\ne f(x_2)$ وي. په برابره توګه که $f(x_1)=f(x_2)$ وي نو $x_1=x_2$ وي. ځینې وختونه موږ د یو-یو تابع لپاره 1-1 تابع لیکو.
p (b) A function $f:X\to Y$ is said to be **onto** (or **surjective**) if each element of $Y$ is the image of some element in $X$ i.e. the range of $f$ is the whole set $Y$. || (b) تفاعل $f:X\to Y$ **پر** (یا **سرجیکٹو**) کہلاتا ہے اگر $Y$ کا ہر عنصر $X$ کے کسی عنصر کی شبیہ ہو، یعنی $f$ کی سعت پورا سیٹ $Y$ ہو۔ || (b) تابع $f:X\to Y$ **پر** (یا **سرجیکټیو**) بلل کېږي که د $Y$ هر عنصر د $X$ د کوم عنصر انځور وي، یعنې د $f$ رینج ټول سېټ $Y$ وي.
