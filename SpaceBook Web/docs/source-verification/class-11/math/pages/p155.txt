@issue Example 45: "$(\sqrt a-\sqrt b)^2>0$, which is always true" holds only for $a\neq b$ (equality when $a=b$); transcribed as printed
m $\therefore\ A>G\qquad(1)$
m $G>H$ if $\sqrt{ab}>\dfrac{2ab}{a+b}$
m $a+b>2\sqrt{ab}$
m $(\sqrt{a}-\sqrt{b})^2>0$, which is always true
m $\therefore\ G>H\qquad(2)$
m (1) and (2) $\Rightarrow A>G>H$
endexample
