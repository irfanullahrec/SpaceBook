p The rarefaction reflects from the closed end and returns to the lip, drawing the air stream into the pipe and producing a new compression. This sets the air column into vigorous, large-amplitude vibration and creates a stationary wave. A node forms at the closed end; an antinode forms at the open end because air molecules move freely there (Figure 8.29). (a) FIRST HARMONIC. For pipe length L and sound wavelength λ₁, L = λ₁/4, so λ₁ = 4L and f₁ = v/λ₁ = v/(4L). This is the fundamental or first harmonic. (b) THIRD HARMONIC. For the third harmonic, L = 3λ₃/4, λ₃ = 4L/3 and f₃ = v/λ₃ = 3v/(4L) = 3f₁. (c) FIFTH HARMONIC. For the fifth harmonic, L = 5λ₅/4 and f₅ = 5v/(4L) = 5f₁. Thus a closed pipe supports frequencies fₙ = nv/(4L) for odd n = 1, 3, 5, …; f₁ is the fundamental and higher odd multiples are harmonics. || rare­faction بند سرے سے منعکس ہو کر lip پر واپس آتی ہے، ہوا کی دھار کو پائپ میں کھینچتی ہے اور نئی compression بناتی ہے۔ اس سے ہوا کا ستون بڑے amplitude سے زور دار ارتعاش کرتا اور ساکن موج بناتا ہے۔ بند سرے پر node اور کھلے سرے پر antinode بنتا ہے کیونکہ ہوا کے سالمات وہاں آزادانہ حرکت کرتے ہیں (شکل 8.29)۔ (a) پہلا harmonic۔ پائپ کی لمبائی L اور صوتی wavelength λ₁ کے لیے L = λ₁/4، اس لیے λ₁ = 4L اور f₁ = v/λ₁ = v/(4L)۔ یہ بنیادی یا پہلا harmonic ہے۔ (b) تیسرا harmonic۔ تیسرے harmonic کے لیے L = 3λ₃/4، λ₃ = 4L/3 اور f₃ = v/λ₃ = 3v/(4L) = 3f₁۔ (c) پانچواں harmonic۔ پانچویں harmonic کے لیے L = 5λ₅/4 اور f₅ = 5v/(4L) = 5f₁۔ یوں بند پائپ طاق n = 1، 3، 5، … کے لیے fₙ = nv/(4L) frequencies پیدا کرتا ہے؛ f₁ بنیادی اور اس کے اوپر طاق مضرب harmonics ہیں۔ || Rarefaction له تړلي سر څخه منعکسېږي او lip ته راګرځي، هوا pipe ته راکاږي او نوې compression جوړوي. دا هوايي ستون په لوړه amplitude اهتزازوي او stationary wave جوړوي. په تړلي سر node او په پرانيستي سر antinode وي، ځکه هلته د هوا مالیکولونه ازاد خوځېږي (8.29 شکل).
