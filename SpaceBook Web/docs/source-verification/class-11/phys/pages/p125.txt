p Now we have to calculate the total work done. (i) Work done between C and B: ΔWc→b = w·d₂ = wd₂ cos 90° = 0. (ii) Work done between B and A: ΔWb→a = wd₁ cos 180° = −wd₁. (iii) Work done between A and C: ΔWa→c = wd cos θ = w(d cos θ) (i). From the right-angle triangle, d₁ = d cos θ. Then Eq. (i) becomes ΔWa→c = w(d cos θ) = wd₁, so ΔWa→c = wd₁. || اب کل کام معلوم کرتے ہیں۔ (i) C اور B کے درمیان کام: ΔWc→b = w·d₂ = wd₂ cos 90° = 0۔ (ii) B اور A کے درمیان کام: ΔWb→a = wd₁ cos 180° = −wd₁۔ (iii) A اور C کے درمیان کام: ΔWa→c = wd cos θ = w(d cos θ) (i)۔ قائمہ مثلث سے d₁ = d cos θ۔ لہٰذا مساوات (i) سے ΔWa→c = w(d cos θ) = wd₁، یعنی ΔWa→c = wd₁۔ || اوس ټول کار محاسبه کوو. (i) د C او B ترمنځ کار: ΔWc→b = w·d₂ = wd₂ cos 90° = 0. (ii) د B او A ترمنځ کار: ΔWb→a = wd₁ cos 180° = −wd₁. (iii) د A او C ترمنځ کار: ΔWa→c = wd cos θ = w(d cos θ) (i). له قائمې زاویې مثلث څخه d₁ = d cos θ. نو له (i) معادلې ΔWa→c = w(d cos θ) = wd₁، یعنې ΔWa→c = wd₁.
p Total work done in closed path ACBA is Wₜ = ΔWc→b + ΔWb→a + ΔWa→c. Putting the values, Wₜ = 0 + (−wd₁) + wd₁ = 0; thus Wₜ = 0. Since total work done in the closed path ACBA in a gravitational field is zero, the gravitational field is a conservative field. || بند راستے ACBA میں کل کام Wₜ = ΔWc→b + ΔWb→a + ΔWa→c ہے۔ قدریں رکھنے سے Wₜ = 0 + (−wd₁) + wd₁ = 0، لہٰذا Wₜ = 0۔ چونکہ ثقلی میدان میں بند راستے ACBA پر کیا گیا کل کام صفر ہے، اس لیے ثقلی میدان محافظ میدان ہے۔ || په تړلې ACBA لار کې ټول کار Wₜ = ΔWc→b + ΔWb→a + ΔWa→c دی. د ارزښتونو په اېښودلو Wₜ = 0 + (−wd₁) + wd₁ = 0؛ نو Wₜ = 0. ځکه چې په جاذبي میدان کې پر تړلې ACBA لار ټول کار صفر دی، جاذبي میدان محافظوي دی.
