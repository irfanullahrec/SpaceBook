p When θ is very small, or Δt = t₂ − t₁ is very small, point B is very near point A and S = vt. Then vΔt / r = Δv / v (provided Δt is very very small), or Δv / Δt = v² / r. In the limit Δt → 0, Δv / Δt = ainst; therefore ainst = v² / r. || جب θ بہت چھوٹا ہو، یا Δt = t₂ − t₁ بہت چھوٹا ہو، تو B، A کے بہت قریب ہوتا ہے اور S = vt۔ پھر vΔt / r = Δv / v (بشرطیکہ Δt بہت ہی چھوٹا ہو)، یا Δv / Δt = v² / r۔ حد Δt → 0 میں، Δv / Δt = ainst؛ لہٰذا ainst = v² / r۔ || کله چې θ یا Δt = t₂ − t₁ ډېر کوچنی وي، B ټکی A ته ډېر نږدې وي او S = vt. نو vΔt / r = Δv / v (که Δt ډېر کوچنی وي)، یا Δv / Δt = v² / r. په Δt → 0 حد کې، Δv / Δt = ainst؛ نو ainst = v² / r.
p This acceleration is also called centripetal acceleration. Thus ac = v² / r. Vectorially, a⃗c = (v² / r) r̂ (5.7). || اس تعجیل کو مرکز مائل تعجیل بھی کہتے ہیں۔ لہٰذا ac = v² / r۔ سمتی صورت میں، a⃗c = (v² / r) r̂ (5.7)۔ || دې تعجیل ته مرکز مایله تعجیل هم ویل کېږي. نو ac = v² / r. په برداري بڼه، a⃗c = (v² / r) r̂ (5.7).
eq \vec{a}_c=\left(\frac{v^2}{r}\right)\hat{r}\quad(5.7)
p Here r⃗ is the radius vector directing outward from the centre of the circle. From Figure 5.8, ac and r⃗ are oppositely directed. Hence a⃗c = −(v² / r²) r⃗ (5.8). The direction of a⃗ at each instant is perpendicular to velocity and toward the centre of the circle. || یہاں r⃗ دائرے کے مرکز سے باہر کی طرف اشارہ کرنے والا رداس بردار ہے۔ شکل 5.8 میں ac اور r⃗ مخالف سمتوں میں ہیں۔ لہٰذا a⃗c = −(v² / r²) r⃗ (5.8)۔ ہر لمحے a⃗ کی سمت رفتار پر عمود اور دائرے کے مرکز کی طرف ہوتی ہے۔ || دلته r⃗ د دایرې له مرکز څخه بهر ته د شعاع بردار دی. په 5.8 شکل کې ac او r⃗ مخالف لوري لري. نو a⃗c = −(v² / r²) r⃗ (5.8). په هره شېبه کې د a⃗ لوری پر سرعت عمودي او د دایرې مرکز ته وي.
eq \vec{a}_c=-\left(\frac{v^2}{r^2}\right)\vec{r}\quad(5.8)
p Using the previous relation v = rω, where ω is angular velocity, the angular form of centripetal acceleration is a⃗c = −ω² r⃗ (5.9). Using Newton’s 2nd law, Fc = mac, where Fc is centripetal force. Putting ac = v² / r, the force relation continues on the next page. || پچھلا تعلق v = rω استعمال کرتے ہوئے، جہاں ω زاویائی رفتار ہے، مرکز مائل تعجیل کی زاویائی صورت a⃗c = −ω² r⃗ (5.9) ہے۔ نیوٹن کے دوسرے قانون کے مطابق Fc = mac، جہاں Fc مرکز مائل قوت ہے۔ ac = v² / r رکھنے سے قوت کا تعلق اگلے صفحے پر جاری ہے۔ || د v = rω پخوانۍ اړیکې په کارولو، چې ω زاویوي سرعت دی، د مرکز مایلې تعجیل زاویوي بڼه a⃗c = −ω² r⃗ (5.9) ده. د نیوټن د دویم قانون له مخې Fc = mac، چې Fc مرکز مایله قوه ده. د ac = v² / r په ایښودلو د قوې اړیکه په راتلونکې پاڼه کې دوام لري.
eq \vec{a}_c=-\omega^2\vec{r}\quad(5.9)
