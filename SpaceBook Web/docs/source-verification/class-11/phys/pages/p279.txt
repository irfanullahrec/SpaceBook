p With mass per unit length μ = M/L, the fundamental frequency becomes f₁ = (1/2L)√(T/μ) (8.21). This is the characteristic vibration frequency called the fundamental or first harmonic. If a string of length L and linear density μ is plucked at one quarter of its length, it vibrates in two loops (Figure 8.25). For wavelength λ₂, L = 2(λ₂/2), so λ₂ = L and f₂ = v/λ₂ = v/L = 2f₁ (8.22); the two-loop frequency is double the fundamental. If the same string is plucked at one sixth of its length, it vibrates in three segments (Figure 8.26). For this mode L = 3(λ₃/2), so λ₃ = 2L/3. The frequency is f₃ = v/λ₃ = 3v/(2L) = 3f₁ (8.23). || فی اکائی لمبائی کمیت μ = M/L ہو تو بنیادی frequency f₁ = (1/2L)√(T/μ) (8.21) بنتی ہے۔ یہ ارتعاش کی خاص frequency ہے جسے fundamental یا پہلا harmonic کہتے ہیں۔ L لمبائی اور μ خطی کثافت والی تار کو لمبائی کے ایک چوتھائی مقام سے چھیڑنے پر دو loops میں ارتعاش ہوتا ہے (شکل 8.25)۔ wavelength λ₂ کے لیے L = 2(λ₂/2)، اس لیے λ₂ = L اور f₂ = v/λ₂ = v/L = 2f₁ (8.22)؛ دو loops کی frequency بنیادی frequency سے دوگنی ہے۔ اسی تار کو لمبائی کے ایک چھٹے مقام سے چھیڑنے پر یہ تین حصوں میں ارتعاش کرتی ہے (شکل 8.26)۔ اس mode کے لیے L = 3(λ₃/2)، لہٰذا λ₃ = 2L/3۔ frequency f₃ = v/λ₃ = 3v/(2L) = 3f₁ (8.23) ہے۔ || که د واحد اوږدوالي کتله μ = M/L وي، بنسټيز frequency f₁ = (1/2L)√(T/μ) (8.21) کېږي. دا ځانګړې اهتزازي frequency د fundamental يا لومړي harmonic په نوم يادېږي. د L اوږدوالي او μ خطي کثافت لرونکی تار چې د اوږدوالي په څلورمه برخه کې ووهل شي، په دوو loops کې اهتزاز کوي (8.25 شکل). د λ₂ wavelength لپاره L = 2(λ₂/2)، نو λ₂ = L او f₂ = v/λ₂ = v/L = 2f₁ (8.22)؛ د دوو loops frequency د بنسټيز دوه برابره ده. هماغه تار د اوږدوالي په شپږمه برخه کې ووهل شي، په درې برخو کې اهتزاز کوي (8.26 شکل). د دې mode لپاره L = 3(λ₃/2)، نو λ₃ = 2L/3. frequency يې f₃ = v/λ₃ = 3v/(2L) = 3f₁ (8.23) ده.
