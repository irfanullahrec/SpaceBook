p 9.4 COHERENT SOURCES. The source defines sources producing waves of the same frequency, “eq[clipped] comparable amplitude,” and constant phase difference as “co[clipped] sources.” Our most important source of light and life-sustaining radiation is the Sun. The source says most artificial light sources are hot bodies radiating visible and infrared radiation. Each source emits a very large number of waves with random phases. Light is emitted in short bursts when electrons in individual atoms undergo energy changes very quickly and randomly; phase changes abruptly as different atoms act. This is true for light from different parts of the same source except a laser.
