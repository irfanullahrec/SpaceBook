p For the closed organ pipe, the third harmonic frequency is f₃ = 3v/(4L) = 3f₁; for the fifth harmonic f₅ = 5v/(4L) = 5f₁. Possible frequencies are v/(4L), 3v/(4L), 5v/(4L), …, (2n−1)v/(4L), where n = 1, 2, 3, … . The lowest frequency v/(4L) is the fundamental; higher odd multiples are harmonics. OPEN ORGAN PIPE. A pipe whose end opposite the blowing end is open is an open organ pipe. Both ends are open, so both have antinodes and there is a node in the middle. (a) FUNDAMENTAL FREQUENCY.
