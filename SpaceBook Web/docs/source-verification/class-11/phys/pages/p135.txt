p For successive intervals, ΔWₙ₋₂→ₙ₋₁ = GmMₑ(1/rₙ₋₂ − 1/rₙ₋₁) and ΔWₙ₋₁→ₙ = GmMₑ(1/rₙ₋₁ − 1/rₙ). Adding all these gives ΔW₁→ₙ = ΔW₁→₂ + ΔW₂→₃ + ΔW₃→₄ + … + ΔWₙ₋₂→ₙ₋₁ + ΔWₙ₋₁→ₙ. Putting corresponding values, the terms cancel successively, resulting in ΔW₁→ₙ = GmMₑ(1/r₁ − 1/rₙ). (iii) || پے در پے وقفوں کے لیے ΔWₙ₋₂→ₙ₋₁ = GmMₑ(1/rₙ₋₂ − 1/rₙ₋₁) اور ΔWₙ₋₁→ₙ = GmMₑ(1/rₙ₋₁ − 1/rₙ)۔ ان سب کو جمع کرنے سے ΔW₁→ₙ = ΔW₁→₂ + ΔW₂→₃ + ΔW₃→₄ + … + ΔWₙ₋₂→ₙ₋₁ + ΔWₙ₋₁→ₙ ملتا ہے۔ متعلقہ قدریں رکھنے پر درمیانی ارکان یکے بعد دیگرے منسوخ ہو جاتے ہیں اور نتیجہ ΔW₁→ₙ = GmMₑ(1/r₁ − 1/rₙ) ہے۔ (iii) || د پرله‌پسې واټنونو لپاره ΔWₙ₋₂→ₙ₋₁ = GmMₑ(1/rₙ₋₂ − 1/rₙ₋₁) او ΔWₙ₋₁→ₙ = GmMₑ(1/rₙ₋₁ − 1/rₙ) دي. د ټولو په جمع کولو ΔW₁→ₙ = ΔW₁→₂ + ΔW₂→₃ + ΔW₃→₄ + … + ΔWₙ₋₂→ₙ₋₁ + ΔWₙ₋₁→ₙ کېږي. د اړوندو ارزښتونو په اېښودلو منځني غړي یو په بل پسې حذفېږي او پایله ΔW₁→ₙ = GmMₑ(1/r₁ − 1/rₙ) ده. p If the nth point N lies at infinity, then rₙ = ∞, and (iii) becomes ΔW₁→∞ = GmMₑ(1/r₁ − 1/∞) = GmMₑ/r₁. (iv) If we displace the body from Earth’s surface, of radius Rₑ, replace r₁ by Rₑ: ΔW = GmMₑ/Rₑ. Thus, from Earth’s surface up to infinity, absolute potential energy = GmMₑ/Rₑ. || اگر نقطہ N لامحدود فاصلے پر ہو تو rₙ = ∞، اور مساوات (iii) سے ΔW₁→∞ = GmMₑ(1/r₁ − 1/∞) = GmMₑ/r₁ ملتا ہے۔ (iv) اگر جسم کو رداس Rₑ والی زمین کی سطح سے منتقل کریں تو r₁ کی جگہ Rₑ رکھیں: ΔW = GmMₑ/Rₑ۔ لہٰذا زمین کی سطح سے لامحدود فاصلے تک مطلق وضعی توانائی = GmMₑ/Rₑ۔ || که nمه نقطه N په لایتناهي کې وي، rₙ = ∞ او له (iii) څخه ΔW₁→∞ = GmMₑ(1/r₁ − 1/∞) = GmMₑ/r₁ ترلاسه کېږي. (iv) که جسم د Rₑ شعاع لرونکې ځمکې له سطحې ولېږدوو، r₁ پر Rₑ بدلوو: ΔW = GmMₑ/Rₑ. نو د ځمکې له سطحې تر لایتناهي پورې مطلقه پوتنشیالي انرژي = GmMₑ/Rₑ.
