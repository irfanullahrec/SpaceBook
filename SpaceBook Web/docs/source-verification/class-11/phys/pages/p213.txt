p By Bernoulli’s equation P₁ + ½ρv₁² + ρgh₁ = P₂ + ½ρv₂² + ρgh₂. Substituting appropriate values and rearranging: P + ½ρ(0)² + ρgh₁ = P + ½ρv² + ρgh₂; or P − P + ρgh₁ − ρgh₂ = ½ρv². Hence ρg(h₁−h₂) = ½ρv², as h₁−h₂ = h. Therefore ρg(h) = ½ρv² or 2gh = v². Taking the square root on both sides, √(v²) = √(2gh); therefore v = √(2gh) (6.7). The speed is the same as the vertical velocity which a body gains after falling freely through a height h. Equation 6.7 is termed Torricelli’s equation for the speed of fluid emerging from water storage. || برنولی کی مساوات P₁ + ½ρv₁² + ρgh₁ = P₂ + ½ρv₂² + ρgh₂ ہے۔ مناسب قدریں رکھنے اور ترتیب دینے سے: P + ½ρ(0)² + ρgh₁ = P + ½ρv² + ρgh₂؛ یا P − P + ρgh₁ − ρgh₂ = ½ρv²۔ لہٰذا ρg(h₁−h₂) = ½ρv²، کیونکہ h₁−h₂ = h۔ اس لیے ρg(h) = ½ρv² یا 2gh = v²۔ دونوں طرف جذر لینے پر √(v²) = √(2gh)؛ لہٰذا v = √(2gh) (6.7)۔ یہ رفتار اس عمودی رفتار کے برابر ہے جو جسم h بلندی سے آزادانہ گرنے پر حاصل کرتا ہے۔ مساوات 6.7 ذخیرے سے نکلتے سیال کی رفتار کے لیے ٹوریسیلی کی مساوات کہلاتی ہے۔ || د برنولي معادله P₁ + ½ρv₁² + ρgh₁ = P₂ + ½ρv₂² + ρgh₂ ده. مناسب ارزښتونه ږدو او ترتیب یې بدلوو: P + ½ρ(0)² + ρgh₁ = P + ½ρv² + ρgh₂؛ یا P − P + ρgh₁ − ρgh₂ = ½ρv². نو ρg(h₁−h₂) = ½ρv²، ځکه h₁−h₂ = h. له همدې امله ρg(h) = ½ρv² یا 2gh = v². د دواړو خواوو جذر اخلو: √(v²) = √(2gh)؛ نو v = √(2gh) (6.7). دا سرعت له هغه عمودي سرعت سره برابر دی چې جسم یې له h لوړوالي څخه په ازاد لوېدو ترلاسه کوي. 6.7 معادله د زېرمتون څخه د وتونکي سیال د سرعت لپاره د تورېچیلي معادله بلل کېږي.
