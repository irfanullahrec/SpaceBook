p (A) mth BRIGHT FRINGE. Substitute the constructive-interference path difference to obtain bright-fringe positions: (y)bright = 0, Lλ/d, 2Lλ/d, 3Lλ/d, … . Thus (yₘ)bright = mLλ/d (9.4). || (A) mویں روشن fringe۔ تعمیری تداخل کا path difference رکھنے سے روشن fringes کی جگہیں ملتی ہیں: (y)bright = 0، Lλ/d، 2Lλ/d، 3Lλ/d، … ۔ لہٰذا (yₘ)bright = mLλ/d (9.4)۔ || (A) mمه روښانه fringe. د رغنده تداخل path difference په ايښودلو د روښانه fringes ځایونه ترلاسه کېږي: (y)bright = 0، Lλ/d، 2Lλ/d، 3Lλ/d، … . نو (yₘ)bright = mLλ/d (9.4).
eq y_m=mLλ/d
p mth DARK FRINGE. Substituting the destructive-interference condition gives (y)dark = Lλ/(2d), 3Lλ/(2d), 5Lλ/(2d), … . Thus (yₘ)dark = (m + 1/2)Lλ/d (9.5). || mویں تاریک fringe۔ تخریبی تداخل کی شرط رکھنے سے (y)dark = Lλ/(2d)، 3Lλ/(2d)، 5Lλ/(2d)، … ملتا ہے۔ لہٰذا (yₘ)dark = (m + 1/2)Lλ/d (9.5)۔ || mمه تياره fringe. د تخريبي تداخل شرط په ايښودلو (y)dark = Lλ/(2d)، 3Lλ/(2d)، 5Lλ/(2d)، … ترلاسه کېږي. نو (yₘ)dark = (m + 1/2)Lλ/d (9.5).
eq y_m=(m+1/2)Lλ/d
p FRINGE SPACING. The distance between consecutive bright or dark fringes is fringe spacing. Between first- and second-order bright fringes: spacing = 2Lλ/d − Lλ/d = Lλ/d. Between first- and second-order dark fringes: spacing = 3Lλ/(2d) − Lλ/(2d) = Lλ/d. Therefore fringe spacing = Lλ/d (9.6). || FRINGS کا فاصلہ۔ مسلسل روشن یا تاریک fringes کے درمیان فاصلہ fringe spacing ہے۔ پہلے اور دوسرے درجے کی روشن fringes کے درمیان: فاصلہ = 2Lλ/d − Lλ/d = Lλ/d۔ پہلے اور دوسرے درجے کی تاریک fringes کے درمیان: فاصلہ = 3Lλ/(2d) − Lλ/(2d) = Lλ/d۔ لہٰذا fringe spacing = Lλ/d (9.6)۔ || د FRINGE واټن. د پرله‌پسې روښانه يا تياره fringes ترمنځ واټن د fringe spacing دی. د لومړۍ او دويمې درجې روښانه fringes ترمنځ: واټن = 2Lλ/d − Lλ/d = Lλ/d. د لومړۍ او دويمې درجې تياره fringes ترمنځ: واټن = 3Lλ/(2d) − Lλ/(2d) = Lλ/d. نو fringe spacing = Lλ/d (9.6).
eq Δy=Lλ/d
