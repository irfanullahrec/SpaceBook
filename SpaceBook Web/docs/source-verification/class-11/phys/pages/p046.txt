p If k is a scalar and A⃗ is a vector, then the scalar multiple is the vector whose length is k times the length of A⃗ and whose direction depending upon the value k. || اگر k اسکیلر اور A⃗ ویکٹر ہو تو اسکیلر مضروب ایسا ویکٹر ہے جس کی لمبائی A⃗ کی لمبائی سے k گنا اور سمت k کی قدر پر منحصر ہوتی ہے۔ || که k سکالر او A⃗ ویکتور وي، نو سکالري حاصل هغه ویکتور دی چې اوږدوالی یې د A⃗ له اوږدوالي څخه k چنده وي او لوری یې د k په ارزښت پورې تړلی وي.
p If k = 0 then kA⃗ = 0⃗. || اگر k = 0 ہو تو kA⃗ = 0⃗۔ || که k = 0 وي، نو kA⃗ = 0⃗.
p If k > 0 then +k·A⃗ = kA⃗. || اگر k > 0 ہو تو +k·A⃗ = kA⃗۔ || که k > 0 وي، نو +k·A⃗ = kA⃗.
p If k < 0 then −k·A⃗ = −kA⃗. || اگر k < 0 ہو تو −k·A⃗ = −kA⃗۔ || که k < 0 وي، نو −k·A⃗ = −kA⃗.
