p For a string plucked at an arbitrary point, it may resonate in n loops with (n + 1) nodes and n antinodes. Wavelength λₙ = 2L/n (8.24) and frequency fₙ = nf₁ = (n/2L)√(T/μ) (8.25). CONCLUSIONS. (i) A string resonates in whole segments, each segment being the distance between adjacent nodes. A string firmly fixed at both ends resonates only when its length is a whole-number multiple of half-wavelength: λ/2, 2λ/2, 3λ/2, … . (ii) As the number of loops increases, frequency increases and wavelength decreases correspondingly; their product remains equal to wave speed. 8.12 FUNDAMENTAL AND OVERTONE VIBRATIONS. A string fixed at both ends resonates only at particular frequencies f₁, f₂, …, fₙ. The lowest characteristic vibration frequency f₁ is the fundamental or first harmonic.
