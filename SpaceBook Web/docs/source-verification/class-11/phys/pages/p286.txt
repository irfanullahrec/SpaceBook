p For the open pipe fundamental, λ₁ = 2L and f₁ = v/(2L). (b) SECOND HARMONIC / FIRST OVERTONE. L = 2(λ₂/2) = λ₂, so λ₂ = L and f₂ = v/λ₂ = 2(v/2L) = 2f₁. (c) THIRD HARMONIC / SECOND OVERTONE. The wavelength is λ₃ = 2L/3 and f₃ = v/λ₃ = 3(v/2L) = 3f₁. In general, for the nth harmonic λₙ = 2L/n and fₙ = nv/(2L) = nf₁ (8.26).
