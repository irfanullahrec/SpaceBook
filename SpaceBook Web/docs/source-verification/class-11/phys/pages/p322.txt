p DESTRUCTIVE INTERFERENCE. Darkness occurs when the path difference is an odd integral multiple of half a wavelength: d = λ/2, 3λ/2, 5λ/2, …; equivalently d = (m + 1/2)λ, where m = 0, 1, 2, 3, … (equation 9.8). If mirrors M₁ and M₂ are equidistant from plate A, the beams travel optically similar paths. Plate B introduces in beam 2 the same retardation introduced in beam 1 by its two passages through A. Thus path difference is zero and a bright fringe occurs by constructive interference. || تخریبی تداخل۔ جب path difference، نصف wavelength کا طاق صحیح عددی مضرب ہو تو تاریکی ہوتی ہے: d = λ/2، 3λ/2، 5λ/2، …؛ یعنی d = (m + 1/2)λ، جہاں m = 0، 1، 2، 3، … (مساوات 9.8)۔ اگر mirrors M₁ اور M₂، plate A سے یکساں فاصلے پر ہوں تو شعاعیں بصری طور پر ملتے جلتے راستے طے کرتی ہیں۔ Plate B، beam 2 میں اتنی ہی تاخیر پیدا کرتی ہے جتنی beam 1 میں A سے دو بار گزرنے سے ہوتی ہے۔ اس طرح path difference صفر اور تعمیری تداخل سے روشن fringe بنتی ہے۔ || تخريبي تداخل. تياره هغه وخت وي چې path difference د نيم wavelength طاق بشپړ عددي مضرب وي: d = λ/2، 3λ/2، 5λ/2، …؛ يعنې d = (m + 1/2)λ، چې m = 0، 1، 2، 3، … دی (9.8 معادله). که M₁ او M₂ هندارې له A تختې يو شان لرې وي، beamونه نږدې يو شان نوري لارې وهي. p ALTERNATE BRIGHT AND DARK FRINGES. If mirror M₁ is moved backward through λ/4, the path difference becomes λ/2 and a dark fringe appears. Moving it a further λ/4 makes the path difference λ and a bright band appears. Thus, as M₁ moves slowly by λ/4 each time, bright and dark fringes appear alternately.
