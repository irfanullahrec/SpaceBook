### Machine Independence || مشین سے آزادی || له ماشین څخه خپلواکي
p Program written in high-level language is machine independent. It means that a program written on one type of computer can be executed on another type of computer. || ہائی لیول زبان میں لکھا گیا پروگرام مشین سے آزاد ہوتا ہے۔ یعنی ایک قسم کے کمپیوٹر پر لکھا گیا پروگرام دوسری قسم کے کمپیوٹر پر چلایا جا سکتا ہے۔ || په لوړې کچې ژبه لیکل شوی پروګرام له ماشین څخه خپلواک وي. یعنې په یوه ډول کمپیوټر لیکل شوی پروګرام په بل ډول کمپیوټر اجرا کېدای شي.

### C Language || C زبان || C ژبه
p C is a general-purpose computer programming language developed in 1972 by Dennis Ritchie at AT&T Bell Laboratories of USA. C is a simple and structure oriented programming language. It is a procedural programming language. It is highly portable among platforms and therefore widely used in industry and among computer professionals. The operating system UNIX was written in C. || C ایک عمومی مقصد کی کمپیوٹر پروگرامنگ زبان ہے جو 1972 میں ڈینس رچی نے امریکہ کی AT&T بیل لیبارٹریز میں تیار کی۔ C ایک سادہ اور ساخت پر مبنی پروگرامنگ زبان ہے۔ یہ ایک پروسیجرل پروگرامنگ زبان ہے۔ یہ مختلف پلیٹ فارمز پر آسانی سے منتقل ہو سکتی ہے اس لیے صنعت اور کمپیوٹر ماہرین میں وسیع پیمانے پر استعمال ہوتی ہے۔ آپریٹنگ سسٹم UNIX زبان C میں لکھا گیا۔ || C یوه عمومي موخې کمپیوټري پروګرامي ژبه ده چې په ۱۹۷۲ کې ډېنس ریچي د امریکا په AT&T بیل لابراتوارونو کې جوړه کړه. C یوه ساده او جوړښت محوره پروګرامي ژبه ده. یوه procedural پروګرامي ژبه ده. د پلیټفارمونو ترمنځ ډېره لېږدېدونکې ده نو په صنعت او کمپیوټري متخصصینو کې پراخه کارېږي. د UNIX عامل سیسټم په C لیکل شوی.
