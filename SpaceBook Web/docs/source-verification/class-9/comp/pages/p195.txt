p The HTML document in Figure 7.19 demonstrates the use of all the heading tags. || شکل 7.19 کی HTML دستاویز تمام ہیڈنگ ٹیگز کا استعمال دکھاتی ہے۔ || د ۷.۱۹ شکل HTML سند د ټولو سرلیک tags کارونه ښيي.

m </body>
m </html>
