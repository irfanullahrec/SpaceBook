### 7.3.2 Text Formatting Tags and their Use || 7.3.2 ٹیکسٹ فارمیٹنگ ٹیگز اور ان کا استعمال || ۷.۳.۲ د متن د بڼې tags او کارونه یې
p HTML provides us with the ability for formatting text just like we do it in MS Word or any text editing tool. Text formatting tags are used to format the text. Some commonly used text formatting tags are described below. || HTML ہمیں متن کو اسی طرح فارمیٹ کرنے کی صلاحیت دیتی ہے جیسے ہم MS Word یا کسی ٹیکسٹ ایڈیٹنگ ٹول میں کرتے ہیں۔ متن کی فارمیٹنگ کے لیے ٹیکسٹ فارمیٹنگ ٹیگز استعمال ہوتے ہیں۔ چند عام ٹیگز درج ذیل ہیں۔ || HTML موږ ته د متن د بڼې ورکولو وړتیا راکوي لکه په MS Word یا بل متن سمونکي کې. د متن د بڼې tags د دې لپاره کارېږي. ځینې عام tags لاندې بیان شوي.
### Bold <b></b> || بولڈ <b></b> || Bold <b></b>
p The text in between the tags will be bold, and stand out against text around it, the same as in a word processor. || ٹیگز کے درمیان متن بولڈ ہوگا اور ورڈ پروسیسر کی طرح اردگرد کے متن سے نمایاں ہوگا۔ || د tags ترمنځ متن bold کېږي او د word processor په څېر له شاوخوا متن برجسته ښکاري.
p For example: <b>Chapter 7 Input Devices</b> — Result: **Chapter 7 Input Devices** || مثال: <b>Chapter 7 Input Devices</b> — نتیجہ: **Chapter 7 Input Devices** || بېلګه: <b>Chapter 7 Input Devices</b> — پایله: **Chapter 7 Input Devices**
### Underline <u></u> || انڈر لائن <u></u> || Underline <u></u>
p These tags will underline the text that is within the tags. It is important to note that html links are already underlined and don't need the extra tag. || یہ ٹیگز اپنے اندر کے متن کو انڈر لائن کریں گے۔ یاد رہے کہ html لنکس پہلے سے انڈر لائن ہوتے ہیں اور انہیں اضافی ٹیگ کی ضرورت نہیں۔ || دا tags خپل دننه متن underline کوي. پام وکړئ چې html لینکونه مخکې underline وي او اضافي tag ته اړتیا نه لري.
p For example: <u>Please Note:</u> — Result: Please Note: (underlined) || مثال: <u>Please Note:</u> — نتیجہ: Please Note: (انڈر لائن) || بېلګه: <u>Please Note:</u> — پایله: Please Note: (underline)
### Italic <i></i> || اٹالک <i></i> || Italic <i></i>
p These tags are used to make the text italic that is within the tags. || یہ ٹیگز اپنے اندر کے متن کو اٹالک بنانے کے لیے استعمال ہوتے ہیں۔ || دا tags خپل دننه متن italic کوي.
p For Example: <i>Pakistan Cricket Team</i> — Result: *Pakistan Cricket Team* || مثال: <i>Pakistan Cricket Team</i> — نتیجہ: *Pakistan Cricket Team* || بېلګه: <i>Pakistan Cricket Team</i> — پایله: *Pakistan Cricket Team*
