### Object Oriented Programming languages || آبجیکٹ اورینٹڈ پروگرامنگ زبانیں || شي محوره پروګرامي ژبې
p In Object Oriented Programming, the program is developed by using a set of objects. An ***object*** is a component of program that has a set of modules and data structures. It is a modern and easy technique to design the program. Once an object for any program is designed, it can be re-used in any other program. Some popular and commonly used Object Oriented Programming (OOP) languages are C++ and JAVA. || آبجیکٹ اورینٹڈ پروگرامنگ میں پروگرام آبجیکٹس کے مجموعے سے تیار کیا جاتا ہے۔ ***آبجیکٹ*** پروگرام کا ایک جزو ہے جس میں ماڈیولز اور ڈیٹا سٹرکچرز کا مجموعہ ہوتا ہے۔ یہ پروگرام ڈیزائن کرنے کی ایک جدید اور آسان تکنیک ہے۔ کسی پروگرام کا آبجیکٹ ایک بار ڈیزائن ہو جائے تو اسے کسی بھی دوسرے پروگرام میں دوبارہ استعمال کیا جا سکتا ہے۔ چند مشہور اور عام استعمال ہونے والی آبجیکٹ اورینٹڈ پروگرامنگ (OOP) زبانیں C++ اور JAVA ہیں۔ || په شي محوره پروګرام جوړونه کې پروګرام د objects د ټولګې په مرسته جوړېږي. ***object*** د پروګرام یوه برخه ده چې د modules او ډېټا جوړښتونو ټولګه لري. دا د پروګرام د ډیزاین نوی او اسانه تخنیک دی. کله چې د یوه پروګرام object یو ځل ډیزاین شي، په هر بل پروګرام کې بیا کارېدای شي. ځینې مشهورې او عامې OOP ژبې C++ او JAVA دي.
### 2.1.3 Characteristics of High Level Languages || 2.1.3 ہائی لیول زبانوں کی خصوصیات || ۲.۱.۳ د لوړې کچې ژبو ځانګړنې
p The following are some common characteristics of High Level Language. || ہائی لیول زبان کی چند عام خصوصیات درج ذیل ہیں۔ || د لوړې کچې ژبې ځینې عامې ځانګړنې دا دي.
### Easy to Learn || سیکھنے میں آسان || زده کول یې اسانه
p The high-level languages are easier to learn than low-level languages. The statements written for the program are similar to English like statements. || ہائی لیول زبانیں لو لیول زبانوں کی نسبت سیکھنے میں آسان ہیں۔ پروگرام کے لیے لکھی گئی اسٹیٹمنٹس انگریزی جیسی ہوتی ہیں۔ || لوړې کچې ژبې تر ټیټې کچې ژبو زده کول اسانه دي. د پروګرام لپاره لیکل شوي بیانونه انګلیسي ته ورته وي.
### Easy to Understand || سمجھنے میں آسان || پوهېدل یې اسانه
p The program written in high-level language by one programmer can easily be understood by another programmer because the program instructions are similar to the English language. || ایک پروگرامر کا ہائی لیول زبان میں لکھا پروگرام دوسرا پروگرامر آسانی سے سمجھ سکتا ہے کیونکہ پروگرام کی ہدایات انگریزی زبان جیسی ہوتی ہیں۔ || د یوه پروګرامر په لوړې کچې ژبه لیکل شوی پروګرام بل پروګرامر په اسانۍ پوهېدای شي ځکه لارښوونې یې انګلیسي ته ورته دي.
### Easy to Write Program || پروگرام لکھنے میں آسان || پروګرام لیکل یې اسانه
p In high-level language, a new program can easily be written in a very short time. The larger and complicated software can be developed in few days or months. || ہائی لیول زبان میں نیا پروگرام بہت کم وقت میں آسانی سے لکھا جا سکتا ہے۔ بڑے اور پیچیدہ سافٹ ویئر چند دنوں یا مہینوں میں تیار کیے جا سکتے ہیں۔ || په لوړې کچې ژبه کې نوی پروګرام په ډېر لږ وخت کې په اسانۍ لیکل کېدای شي. لوی او پېچلي سافټوېرونه په څو ورځو یا میاشتو کې جوړېدای شي.
### Easy to Detect & Remove Errors || غلطیاں تلاش کرنا اور دور کرنا آسان || د تېروتنو موندل او لرې کول اسانه
p The errors in a program can be easily detected and removed. Mostly the errors are occurred during the compilation of new program. || پروگرام کی غلطیاں آسانی سے تلاش اور دور کی جا سکتی ہیں۔ زیادہ تر غلطیاں نئے پروگرام کی کمپائلیشن کے دوران سامنے آتی ہیں۔ || د پروګرام تېروتنې په اسانۍ موندل او لرې کېدای شي. ډېری تېروتنې د نوي پروګرام د compilation پر مهال رامنځته کېږي.
### Built-in Library Functions || بلٹ ان لائبریری فنکشنز || جوړ شوي کتابتون فنکشنونه
p Each high-level language provides a large number of built-in functions or procedures that can be used to perform specific tasks during designing of new programs. In this way, a lot of time of programmer is saved. || ہر ہائی لیول زبان بڑی تعداد میں بلٹ ان فنکشنز یا پروسیجرز فراہم کرتی ہے جو نئے پروگرام ڈیزائن کرتے وقت مخصوص کام انجام دینے کے لیے استعمال ہو سکتے ہیں۔ اس طرح پروگرامر کا بہت سا وقت بچ جاتا ہے۔ || هره لوړې کچې ژبه ډېر جوړ شوي فنکشنونه یا procedures برابروي چې د نویو پروګرامونو د ډیزاین پر مهال د ځانګړو دندو لپاره کارېدای شي. په دې ډول د پروګرامر ډېر وخت سپمېږي.
