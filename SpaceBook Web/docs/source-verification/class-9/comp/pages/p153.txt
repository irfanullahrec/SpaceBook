### Exclusive-OR Gate (XOR) || ایکسکلوسو-OR گیٹ (XOR) || Exclusive-OR دروازه (XOR)
p The gate whose output is '0' when all the inputs are either 0s or 1s is called XOR gate. So XOR gate produces '0' output for same input values, and produces '1' for different input values. || وہ گیٹ جس کا آؤٹ پٹ 0 ہو جب تمام ان پٹ یا تو 0 ہوں یا 1، XOR گیٹ کہلاتا ہے۔ یوں XOR گیٹ ایک جیسے ان پٹ پر 0 اور مختلف ان پٹ پر 1 دیتا ہے۔ || هغه دروازه چې output یې 0 وي کله چې ټول inputs یا 0 یا 1 وي، XOR بلل کېږي. نو XOR د یو شان inputs لپاره 0 او د بېلابېلو لپاره 1 ورکوي.
p If A and B are the two inputs to XOR gate and Y is the output, then the block diagram and truth table of XOR gate is shown in the figure 6.6 below. || اگر A اور B XOR گیٹ کے دو ان پٹ اور Y آؤٹ پٹ ہو تو اس کا بلاک ڈایاگرام اور ٹروتھ ٹیبل نیچے شکل 6.6 میں ہے۔ || که A او B د XOR دوه inputs او Y output وي، ډیاګرام او truth table یې په ۶.۶ شکل کې دي.
