qp v | What are the characteristics of high level languages? || ہائی لیول زبانوں کی خصوصیات کیا ہیں؟ || د لوړې کچې ژبو ځانګړنې څه دي؟
sol Model answer ## High-level languages are easy to read and write (English-like), machine independent (portable), have fewer errors and are easy to debug, support structured programming and need a compiler or interpreter to translate them.
qp vi | Differentiate between compiler and interpreter. || کمپائلر اور انٹرپریٹر میں فرق کریں۔ || د compiler او interpreter ترمنځ توپیر وکړئ.
sol Model answer ## A compiler translates the whole source program into machine code at once and then reports all errors; it runs fast afterwards (C, C++). An interpreter translates and executes the program one statement at a time and stops at the first error; it is slower in running (Python, BASIC).
qp vii | What is header file? || ہیڈر فائل کیا ہے؟ || header فایل څه دی؟
sol Model answer ## A header file has the declarations of library functions and macros (e.g. stdio.h for printf and scanf) and is added to the program with the #include directive before compiling.
qp viii | Differentiate between source program and object program. || سورس پروگرام اور آبجیکٹ پروگرام میں فرق کریں۔ || د source پروګرام او object پروګرام ترمنځ توپیر وکړئ.
sol Model answer ## The source program is the program written by the programmer in a high-level language (a .c file); the object program is the machine-language form produced by the compiler (a .obj file) that is linked and run.
qp ix | What are reserved words? || مخصوص الفاظ کیا ہیں؟ || ساتل شوې کلمې څه دي؟
sol Model answer ## Reserved words (keywords) are words with a fixed meaning in the language that cannot be used as names of variables, e.g. int, float, if, else, while, for, return.
qp x | Write rules for variable names. || متغیر ناموں کے قواعد لکھیں۔ || د متغیر نومونو قواعد ولیکئ.
sol Model answer ## Rules for variable names: begin with a letter or underscore, not a digit; use only letters, digits and underscore (no spaces or symbols); do not use a reserved word; C is case sensitive (Sum and sum differ); keep the name meaningful and not too long.

q 3 | What is programming language? Explain different types of low level languages. || پروگرامنگ زبان کیا ہے؟ لو لیول زبانوں کی مختلف اقسام کی وضاحت کریں۔ || پروګرامي ژبه څه ده؟ د ټیټې کچې ژبو بېلابېل ډولونه تشریح کړئ.
sol Model answer ## A programming language is a set of words and rules used to write instructions for a computer. Low-level languages: machine language is made of binary 0s and 1s directly executed by the CPU; assembly language uses short mnemonic codes (ADD, MOV) and needs an assembler to change it to machine code. They are fast and hardware dependent.
q 4 | What are high level languages? Explain any five types of high level languages. || ہائی لیول زبانیں کیا ہیں؟ ہائی لیول زبانوں کی کوئی سی پانچ اقسام کی وضاحت کریں۔ || لوړې کچې ژبې څه دي؟ د لوړې کچې ژبو هر پنځه ډولونه تشریح کړئ.
sol Model answer ## High-level languages are written in English-like words and are machine independent. Five types: C (a general purpose, structured language for system programs), C++ (object oriented), Java (portable, object oriented), Python (simple, popular for scripting and AI) and BASIC (easy for beginners); others are COBOL (business) and FORTRAN (science).
q 5 | What is the basic structure of C-program? Also explain different types of preprocessor directives. || C پروگرام کا بنیادی ڈھانچہ کیا ہے؟ پری پروسیسر ڈائریکٹوز کی مختلف اقسام کی بھی وضاحت کریں۔ || د C پروګرام بنسټیز جوړښت څه دی؟ د preprocessor لارښوونو بېلابېل ډولونه هم تشریح کړئ.
sol Model answer ## A C program has: preprocessor directives (#include), the main function, braces, declarations of variables, and statements ending with semicolons, plus comments. Example: #include <stdio.h> ; void main() { printf("Hello"); }. Preprocessor directives begin with # and are handled before compiling: #include adds a header file and #define defines a constant or macro; also #ifdef, #ifndef and #undef.
q 6 | What are constants and variables? Differentiate them with examples. || کانسٹنٹس اور متغیرات کیا ہیں؟ مثالوں سے ان میں فرق کریں۔ || ثابتونه او متغیرونه څه دي؟ په بېلګو یې توپیر وکړئ.
sol Model answer ## A constant is a fixed value that does not change during execution (5, 3.14, 'A', defined with const or #define). A variable is a named memory location whose value can change (int age = 15; age = 16;). A constant holds one value only, while a variable can be reassigned.
q 7 | Explain different data types used in C-language with examples. || C زبان میں استعمال ہونے والی مختلف ڈیٹا ٹائپس کی مثالوں سے وضاحت کریں۔ || په C ژبه کې کارېدونکي بېلابېل ډېټا ډولونه په بېلګو تشریح کړئ.
sol Model answer ## Data types in C: int (whole numbers, e.g. 25), float (real numbers with decimals, e.g. 3.14), double (larger precision decimals), char (a single character, e.g. 'A'), and void (no value). Examples: int age = 15; float price = 25.5; char grade = 'A';
q 8 | What is type casting? Explain with examples. || ٹائپ کاسٹنگ کیا ہے؟ مثالوں سے وضاحت کریں۔ || type casting څه دی؟ په بېلګو یې تشریح کړئ.
sol Model answer ## Type casting is converting a value from one data type to another. Implicit conversion is done by the compiler (int to float in mixed expressions); explicit casting is done by the programmer: float avg = (float) total / 3; or int x = (int) 7.9; which gives 7.
q 9 | How variables are declared and initialized in C-language? Give examples. || C زبان میں متغیرات کا اعلان اور ابتدائی قدر کیسے دی جاتی ہے؟ مثالیں دیں۔ || په C ژبه کې متغیرونه څنګه اعلان او پیلنی ارزښت ورکول کېږي؟ بېلګې ورکړئ.
sol Model answer ## A variable is declared by giving its data type and name: int a; float b; char c;. It is initialized by assigning a value, either at declaration (int a = 10;) or later (a = 10;); several variables can be declared together (int x, y, z;).
