sol See 2.1–2.4 ## i: Syntax = rules for the structure of statements (like grammar); semantic = the meaning / steps a statement performs. ii: Low level languages are close to hardware (machine, assembly), hard for humans; high level languages are English-like, easy, machine independent and need a translator. iii: An IDE is software that brings editor, compiler, linker, debugger etc. into one environment to create, compile and run programs. iv: Object Oriented Programming builds programs from reusable objects (modules + data structures), e.g. C++, Java. v: Easy to learn, understand and write; easy to detect and remove errors; built-in library functions; machine independence. vi: A compiler translates the whole program at once into object code; an interpreter translates and executes one statement at a time. vii: A .h file of standard library function declarations, included with #include. viii: Source program = the programmer's code (.c); object program = its machine-code translation by the compiler (.obj). ix: Words with fixed meaning reserved by C (32 keywords such as int, if, while). x: Start with a letter (or underscore), no spaces, no keywords, no special characters, length depends on compiler, one name for one data type. xi: To define a named constant whose initialized value cannot change. || i: سنٹیکس = اسٹیٹمنٹس کی ساخت کے قواعد (گرامر کی طرح)؛
