q 2 | Explain different types of looping structures with examples. || لوپنگ اسٹرکچرز کی مختلف اقسام کی مثالوں سے وضاحت کریں۔ || د لوپ جوړښتونو ډولونه په بېلګو تشریح کړئ.
sol Model answer ## Loops repeat a block of statements. for loop: for(i = 1; i <= 5; i++) printf("%d ", i); (counted loop, initialization, condition and increment in one place). while loop: i = 1; while(i <= 5) { printf("%d ", i); i++; } (condition tested before each pass). do-while loop: i = 1; do { printf("%d ", i); i++; } while(i <= 5); (body runs at least once, condition tested after). All three print 1 2 3 4 5.
q 3 | Differentiate between the *do-while* and *while* loops. Explain with program examples. || *do-while* اور *while* لوپس میں فرق کریں۔ پروگرام کی مثالوں سے وضاحت کریں۔ || د *do-while* او *while* لوپونو توپیر وکړئ. د پروګرام په بېلګو یې تشریح کړئ.
sol Model answer ## The while loop tests the condition first, so the body may never run; the do-while loop runs the body once before testing the condition at the end, so it executes at least once, and it ends with a semicolon. Example with i = 10: while(i < 5) prints nothing, but do { printf("%d", i); } while(i < 5); prints 10 once.
q 4 | Write a program in C to calculate and print the product of the even numbers from 1 to 100 by using the *while* loop. || *while* لوپ سے 1 سے 100 تک جفت اعداد کا حاصلِ ضرب معلوم کر کے پرنٹ کرنے کا C پروگرام لکھیں۔ || د *while* لوپ په مرسته له ۱ تر ۱۰۰ پورې د جفتو عددونو حاصل ضرب محاسبه او چاپ کړئ.
sol Model answer ## #include <stdio.h> ; void main() { long product = 1; int n = 2; while (n <= 100) { product = product * n; n = n + 2; } printf("Product = %ld", product); } (the product is too large for an int and overflows; use double for the exact scale).
q 5 | Write a program to display alphabets from A to Z using for loop. || for لوپ سے A سے Z تک حروفِ تہجی دکھانے کا پروگرام لکھیں۔ || د for لوپ په مرسته له A تر Z توري وښیئ.
sol Model answer ## #include <stdio.h> ; void main() { char ch; for (ch = 'A'; ch <= 'Z'; ch++) printf("%c ", ch); }
q 6 | Write a program to display the following output using nested for loop. || نیسٹڈ for لوپ سے درج ذیل آؤٹ پٹ دکھانے کا پروگرام لکھیں۔ || د ځالي for لوپ په مرسته لاندې output وښیئ.
