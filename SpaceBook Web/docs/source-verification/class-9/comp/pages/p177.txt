### Web Browser || ویب براؤزر || وېب براوزر
p A web browser is a type of software that allows you to retrieve information on the websites. Information on the web is accessed by the URLs (Uniform Resource Locators). Web browsers allow users to open multiple websites at the same time, either in different browser windows or in different tabs of the same window. There are many different web browsers, but some of the most common ones include Google Chrome, Internet Explorer, Microsoft Edge, and Mozilla Firefox which are shown in Figure 7.3(a), 7.3(b), 7.3(c) and 7.3(d) respectively. All these browsers have graphical interface which is very easy to learn and use. || ویب براؤزر ایسا سافٹ ویئر ہے جو آپ کو ویب سائٹس سے معلومات حاصل کرنے دیتا ہے۔ ویب پر معلومات URLs (یونیفارم ریسورس لوکیٹرز) کے ذریعے حاصل کی جاتی ہیں۔ ویب براؤزر صارفین کو ایک وقت میں کئی ویب سائٹس مختلف ونڈوز یا ایک ہی ونڈو کے مختلف ٹیبز میں کھولنے دیتے ہیں۔ بہت سے ویب براؤزر ہیں، مگر سب سے عام گوگل کروم، انٹرنیٹ ایکسپلورر، مائیکروسافٹ ایج اور موزیلا فائر فاکس ہیں جو بالترتیب شکل 7.3(a)، 7.3(b)، 7.3(c) اور 7.3(d) میں دکھائے گئے ہیں۔ ان سب کا گرافیکل انٹرفیس سیکھنے اور استعمال کرنے میں بہت آسان ہے۔ || وېب براوزر هغه سافټوېر دی چې له وېب سایټونو معلومات ترلاسه کوي. په ویب کې معلومات د URLs له لارې لاسته راځي. براوزرونه کاروونکو ته اجازه ورکوي چې په یو وخت ډېر وېب سایټونه په بېلو کړکیو یا د یوې کړکۍ په بېلو tabs کې پرانیزي. ډېر براوزرونه شته، خو تر ټولو عام Google Chrome، Internet Explorer، Microsoft Edge او Mozilla Firefox دي چې په ترتیب سره په ۷.۳(a)، ۷.۳(b)، ۷.۳(c) او ۷.۳(d) شکلونو کې ښودل شوي. ټول ګرافیکي انټرفېس لري چې زده کول او کارول یې ډېر اسانه دي.
