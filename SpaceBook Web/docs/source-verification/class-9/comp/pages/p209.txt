p **<img> tag:** It is the HTML tag that inserts an image in a web page. It has attributes but no closing tag. || **<img> ٹیگ:** یہ HTML ٹیگ ویب پیج میں تصویر داخل کرتا ہے۔ اس کی خصوصیات ہیں مگر بند ہونے والا ٹیگ نہیں۔ || **<img> tag:** دا HTML tag وېب پاڼې ته انځور ورداخلوي. attributes لري خو تړونکی tag نه لري.
p ***src* attribute:** It stands for source. It tells the browser where the image file is located. <img> tag has many attributes but *src* is the most important one. || ***src* خصوصیت:** اس سے مراد سورس (ماخذ) ہے۔ یہ براؤزر کو بتاتی ہے کہ تصویر کی فائل کہاں ہے۔ <img> ٹیگ کی بہت سی خصوصیات ہیں مگر *src* سب سے اہم ہے۔ || ***src* attribute:** د source معنا لري. براوزر ته وايي چې د انځور فایل چېرې دی. <img> ډېر attributes لري خو *src* تر ټولو مهم دی.
p The HTML document in Figure 7.35 demonstrates how to display an image in a page. Assume that the image file, *mosque.jpg* and HTML document are in the same folder. || شکل 7.35 کی HTML دستاویز دکھاتی ہے کہ صفحے پر تصویر کیسے دکھائی جائے۔ فرض کریں تصویر کی فائل *mosque.jpg* اور HTML دستاویز ایک ہی فولڈر میں ہیں۔ || د ۷.۳۵ شکل HTML سند ښيي چې په پاڼه کې انځور څنګه وښودل شي. فرض کړئ *mosque.jpg* او HTML سند په یوه فولډر کې دي.
