### 2.3.3 Basic Structure of C Program || 2.3.3 C پروگرام کا بنیادی ڈھانچہ || ۲.۳.۳ د C پروګرام بنسټیز جوړښت
p A C program consists of three main parts. These are: || C پروگرام تین بنیادی حصوں پر مشتمل ہوتا ہے۔ یہ ہیں: || C پروګرام له دریو اصلي برخو جوړ دی. دا دي:
- **Preprocessor Directives** || **پری پروسیسر ڈائریکٹوز** || **Preprocessor لارښوونې**
- **The main () function** || **main () فنکشن** || **main () فنکشن**
- **Body of main { }** || **main کا جسم { }** || **د main بدنه { }**
### Preprocessor Directives || پری پروسیسر ڈائریکٹوز || Preprocessor لارښوونې
p The instructions that are given to the compiler before the start of the actual program are called Preprocessor Directives. These are also known as Compiler Directives. The preprocessor directives consist of instructions for the compiler. The compiler adds special instructions or code from these directives into the program at the time of compilation. || اصل پروگرام شروع ہونے سے پہلے کمپائلر کو دی جانے والی ہدایات پری پروسیسر ڈائریکٹوز کہلاتی ہیں۔ انہیں کمپائلر ڈائریکٹوز بھی کہا جاتا ہے۔ پری پروسیسر ڈائریکٹوز کمپائلر کے لیے ہدایات پر مشتمل ہوتے ہیں۔ کمپائلر کمپائلیشن کے وقت ان ڈائریکٹوز سے خاص ہدایات یا کوڈ پروگرام میں شامل کرتا ہے۔ || هغه لارښوونې چې د اصلي پروګرام له پیل مخکې compiler ته ورکول کېږي Preprocessor Directives بلل کېږي. دې ته Compiler Directives هم وايي. Preprocessor لارښوونې د compiler لپاره لارښوونې لري. Compiler د compilation پر مهال له دې لارښوونو ځانګړې لارښوونې یا کوډ پروګرام ته ورزیاتوي.
p These preprocessor directives normally start with hash sign # and the keyword, e.g., ***#include, #define,*** etc. || یہ پری پروسیسر ڈائریکٹوز عموماً ہیش کی علامت # اور کی ورڈ سے شروع ہوتے ہیں، مثلاً ***#include، #define*** وغیرہ۔ || دا preprocessor لارښوونې معمولاً د hash نښې # او keyword سره پیلېږي، لکه ***#include، #define*** او نور.

p The **#include** directive allows external header files to be processed by the compiler. When this preprocessor is carried out by the C compiler, it will search for the header file that is written within the angle brackets < > and copy it into the source file. || **#include** ڈائریکٹو بیرونی ہیڈر فائلوں کو کمپائلر کے ذریعے پروسیس ہونے دیتا ہے۔ جب C کمپائلر یہ پری پروسیسر انجام دیتا ہے تو وہ زاویہ دار بریکٹس < > میں لکھی ہیڈر فائل تلاش کر کے اسے سورس فائل میں کاپی کر دیتا ہے۔ || **#include** لارښوونه بهرنیو header فایلونو ته اجازه ورکوي چې د compiler له خوا پروسس شي. کله چې C compiler دا preprocessor ترسره کړي، هغه header فایل لټوي چې په زاویه ییزو قوسونو < > کې لیکل شوی او source فایل ته یې کاپي کوي.
