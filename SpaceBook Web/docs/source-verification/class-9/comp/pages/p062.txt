### 2.4.5 Type Casting || 2.4.5 ٹائپ کاسٹنگ || ۲.۴.۵ Type Casting
p The process of converting one data type into another data type during execution is known as **type casting.** Type casting can be performed in two ways. || چلنے کے دوران ایک ڈیٹا ٹائپ کو دوسری ڈیٹا ٹائپ میں بدلنے کا عمل **ٹائپ کاسٹنگ** کہلاتا ہے۔ ٹائپ کاسٹنگ دو طریقوں سے کی جا سکتی ہے۔ || د اجرا پر مهال د یوه ډېټا ډول بل ډول ته د اړولو بهیر **type casting** بلل کېږي. Type casting په دوو لارو ترسره کېدای شي.
- Implicit type casting || ضمنی (Implicit) ٹائپ کاسٹنگ || ضمني (implicit) type casting
- Explicit type casting || صریح (Explicit) ٹائپ کاسٹنگ || ښکاره (explicit) type casting
### 1. Implicit Type Casting || 1. ضمنی ٹائپ کاسٹنگ || ۱. ضمني type casting
p Implicit type casting is performed automatically by the C compiler. The operands in arithmetic operation must be of similar types. If the data types of operands are different, the value with lower data type is converted into higher data type. || ضمنی ٹائپ کاسٹنگ C کمپائلر خودبخود کرتا ہے۔ حسابی عمل کے آپرینڈز ایک جیسی اقسام کے ہونے چاہئیں۔ اگر آپرینڈز کی ڈیٹا ٹائپس مختلف ہوں تو نچلی ڈیٹا ٹائپ والی قدر کو اعلیٰ ڈیٹا ٹائپ میں بدل دیا جاتا ہے۔ || ضمني type casting د C compiler له خوا پخپله ترسره کېږي. په حسابي عملیه کې operands باید یو شان ډول ولري. که د operands ډېټا ډولونه بېل وي، د ټیټ ډېټا ډول ارزښت لوړ ډېټا ډول ته اړول کېږي.
