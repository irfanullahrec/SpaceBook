### 4. Loader || 4. لوڈر || ۴. Loader
p It is a program that loads C-language programs into memory and then executes them. || یہ ایک پروگرام ہے جو C زبان کے پروگراموں کو میموری میں لوڈ کرتا ہے اور پھر انہیں چلاتا ہے۔ || دا یو پروګرام دی چې د C ژبې پروګرامونه حافظې ته پورته کوي او بیا یې اجرا کوي.
### 5. Debugger || 5. ڈیبگر || ۵. Debugger
p In computers, ***debugging*** is the process of locating and fixing bugs (errors) in computer program code. || کمپیوٹرز میں ***ڈیبگنگ*** کمپیوٹر پروگرام کے کوڈ میں بگز (غلطیاں) تلاش کرنے اور ٹھیک کرنے کا عمل ہے۔ || په کمپیوټرونو کې ***debugging*** د کمپیوټري پروګرام په کوډ کې د bugs (تېروتنو) د موندلو او سمولو بهیر دی.
p A C-language debugger is a computer program that lets users run the program, line by line and examine the values of variables or look at values passed into functions and helps in finding and removing errors in the program. || C زبان کا ڈیبگر ایک کمپیوٹر پروگرام ہے جو صارفین کو پروگرام سطر بہ سطر چلانے، متغیرات کی قدریں جانچنے یا فنکشنز کو بھیجی گئی قدریں دیکھنے دیتا ہے اور پروگرام کی غلطیاں تلاش کرنے اور دور کرنے میں مدد دیتا ہے۔ || د C ژبې debugger یو کمپیوټري پروګرام دی چې کاروونکو ته اجازه ورکوي پروګرام کرښه په کرښه وچلوي، د متغیرونو ارزښتونه وازمويي یا فنکشنونو ته لېږل شوي ارزښتونه وګوري، او د پروګرام د تېروتنو په موندلو او لرې کولو کې مرسته کوي.

### Getting Started With C || C کا آغاز || له C سره پیل
p C is a popular and efficient programming language which is widely used for system and application software. In order to create and run a C program, you need a C-language compiler. There are many free and professional C-language compilers available. || C ایک مقبول اور مؤثر پروگرامنگ زبان ہے جو سسٹم اور ایپلی کیشن سافٹ ویئر کے لیے وسیع پیمانے پر استعمال ہوتی ہے۔ C پروگرام بنانے اور چلانے کے لیے آپ کو C زبان کا کمپائلر درکار ہے۔ بہت سے مفت اور پیشہ ورانہ C کمپائلر دستیاب ہیں۔ || C یوه مشهوره او اغېزمنه پروګرامي ژبه ده چې د سیسټم او اپلیکېشن سافټوېر لپاره پراخه کارېږي. د C پروګرام د جوړولو او چلولو لپاره د C ژبې compiler ته اړتیا لرئ. ډېر وړیا او مسلکي C compilers شته.
