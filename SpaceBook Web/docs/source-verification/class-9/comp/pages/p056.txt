### Body of *main()* || *main()* کا جسم || د *main()* بدنه
p After parenthesis of *main* function, the body of *main* function starts with an opening curly "{" brace and ends with a closing curly brace "}". When the function is executed, the instructions written within it perform their task. Inside the body of *main* function, C statements are written. || *main* فنکشن کے قوسین کے بعد *main* فنکشن کا جسم کھلنے والے خمیدہ بریکٹ "{" سے شروع ہوتا ہے اور بند ہونے والے خمیدہ بریکٹ "}" پر ختم ہوتا ہے۔ جب فنکشن چلتا ہے تو اس کے اندر لکھی ہدایات اپنا کام کرتی ہیں۔ *main* فنکشن کے جسم کے اندر C اسٹیٹمنٹس لکھی جاتی ہیں۔ || د *main* فنکشن له قوسونو وروسته د *main* بدنه په پرانیستونکي کږ قوس "{" پیلېږي او په تړونکي کږ قوس "}" پای ته رسېږي. کله چې فنکشن اجرا شي، په هغه کې لیکل شوې لارښوونې خپله دنده ترسره کوي. د *main* په بدنه کې C بیانونه لیکل کېږي.
### C statements || C اسٹیٹمنٹس || C بیانونه
p A C statement is an expression that can actually produces some effect. It is actually an instruction to the computer for taking an action. || C اسٹیٹمنٹ ایک ایسا اظہار ہے جو حقیقت میں کوئی اثر پیدا کرتا ہے۔ یہ دراصل کمپیوٹر کو کوئی عمل کرنے کی ہدایت ہے۔ || C بیان هغه افاده ده چې په رښتیا کوم اغېز جوړوي. دا په اصل کې کمپیوټر ته د یوه عمل لارښوونه ده.
p For example *printf ("Hello World");* is a C statement that performs the action of displaying the result "Hello World" on the screen. The C statements are normally written in lowercase letters. Each statement in C ends with a semicolon **;**. || مثلاً *printf ("Hello World");* ایک C اسٹیٹمنٹ ہے جو اسکرین پر نتیجہ "Hello World" ظاہر کرنے کا عمل انجام دیتی ہے۔ C اسٹیٹمنٹس عموماً چھوٹے حروف میں لکھی جاتی ہیں۔ C میں ہر اسٹیٹمنٹ سیمی کولن **;** پر ختم ہوتی ہے۔ || د بېلګې په توګه *printf ("Hello World");* یو C بیان دی چې پر پرده د "Hello World" پایلې ښودلو عمل کوي. C بیانونه معمولاً په وړو تورو لیکل کېږي. په C کې هر بیان په semicolon **;** پای ته رسېږي.
### 2.3.4 Comments in C || 2.3.4 C میں کمنٹس || ۲.۳.۴ په C کې comments
p A comment is an explanation or description of the source code of the program. It helps developer to explain logic of the code and improves program readability. It is used to provide a brief description of the purpose and operation of a computer program/statement(s); which makes the program more understandable to the users. Comments are non-executable lines and are ignored by the compiler during the translation. It is important to note that comment line(s) appear only in the program listing and have no effect on the program output. Comments may appear anywhere in the C program and programmer is free to write anything in the comment line. || کمنٹ پروگرام کے سورس کوڈ کی وضاحت یا تفصیل ہے۔ یہ ڈیولپر کو کوڈ کی منطق سمجھانے میں مدد دیتا ہے اور پروگرام کو پڑھنے میں آسان بناتا ہے۔ یہ کمپیوٹر پروگرام/اسٹیٹمنٹ کے مقصد اور کام کی مختصر وضاحت دینے کے لیے استعمال ہوتا ہے، جس سے پروگرام صارفین کے لیے زیادہ قابلِ فہم بنتا ہے۔ کمنٹس قابلِ عمل سطریں نہیں ہوتیں اور ترجمے کے دوران کمپائلر انہیں نظرانداز کر دیتا ہے۔ یہ بات اہم ہے کہ کمنٹ لائنیں صرف پروگرام لسٹنگ میں ظاہر ہوتی ہیں اور پروگرام کے آؤٹ پٹ پر کوئی اثر نہیں ڈالتیں۔ کمنٹس C پروگرام میں کہیں بھی آ سکتے ہیں اور پروگرامر کمنٹ لائن میں کچھ بھی لکھنے کے لیے آزاد ہے۔ || comment د پروګرام د source کوډ تشریح یا بیان دی. له پرمختیا کوونکي سره د کوډ د منطق په تشریح کې مرسته کوي او د پروګرام لوستل اسانه کوي. د کمپیوټري پروګرام/بیان د موخې او کار د لنډ بیان لپاره کارېږي، چې پروګرام کاروونکو ته د پوهېدو وړ کوي. comments د اجرا وړ کرښې نه دي او د ژباړې پر مهال compiler یې له پامه غورځوي. مهمه ده چې د comment کرښې یوازې د پروګرام په لست کې ښکاري او پر output اغېز نه لري. comments په C پروګرام کې هر ځای کېدای شي او پروګرامر آزاد دی چې په comment کرښه کې هر څه ولیکي.
p There are two ways of writing comments in C. || C میں کمنٹس لکھنے کے دو طریقے ہیں۔ || په C کې د comments لیکلو دوه لارې دي.
p A C comment is written in one of the following ways: || C کمنٹ درج ذیل میں سے کسی ایک طریقے سے لکھا جاتا ہے: || C comment په لاندې یوه لاره لیکل کېږي:
p **1. Single-line Comments:** Comments on single line are added by using // (two slashes). Anything written on the right side of // (two slash) is considered as comments. This style is useful to comment individual lines of a program.
