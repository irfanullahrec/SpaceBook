## 6.3 SIMPLIFICATION OF BOOLEAN FUNCTION USING KARNAUGH MAP || 6.3 کارناف میپ سے بولین فنکشن کو مختصر کرنا || ۶.۳ د کارناف نقشې په مرسته د بولین فنکشن لنډول
### Boolean function simplification || بولین فنکشن کا اختصار || د بولین فنکشن لنډول
p It is the process of reducing the number of terms and/or variables in a Boolean function without affecting the final output. Different methods are used for this purpose. Maurice Karnaugh, a telecommunications engineer, developed the Karnaugh map at Bell Labs in 1953. This is a simple method for simplification of Boolean functions. When a simplified Boolean function is converted into a logic circuit, it requires less number of gates and hence costs less. || یہ حتمی آؤٹ پٹ کو متاثر کیے بغیر بولین فنکشن میں اجزا اور/یا متغیرات کی تعداد کم کرنے کا عمل ہے۔ اس کے لیے مختلف طریقے استعمال ہوتے ہیں۔ ٹیلی کمیونیکیشن انجینئر موریس کارناف نے 1953 میں بیل لیبز میں کارناف میپ تیار کیا۔ یہ بولین فنکشنز کو مختصر کرنے کا ایک سادہ طریقہ ہے۔ جب مختصر بولین فنکشن کو لاجک سرکٹ میں بدلا جاتا ہے تو اسے کم گیٹس درکار ہوتے ہیں اور اس طرح لاگت کم آتی ہے۔ || دا د وروستي output له اغېزمنولو پرته په بولین فنکشن کې د برخو او/یا متغیرونو د شمېر کمولو بهیر دی. د دې لپاره بېلابېلې طریقې کارېږي. د مخابراتو انجنیر موریس کارناف په ۱۹۵۳ کې په Bell Labs کې کارناف نقشه جوړه کړه. دا د بولین فنکشنونو د لنډولو ساده طریقه ده. کله چې لنډ شوی بولین فنکشن منطقي سرکټ ته واوړي، لږې دروازې غواړي او لګښت یې کم وي.
### 6.3.1 Karnaugh Map (K-Map) || 6.3.1 کارناف میپ (K-Map) || ۶.۳.۱ کارناف نقشه (K-Map)
p The K-map method of solving the logical expressions is referred to as the graphical technique of simplifying Boolean expressions. K-maps are also referred to as 2D truth tables as each K-map is nothing but a different format of representing the values present in a one-dimensional truth table. || منطقی اظہارات حل کرنے کا K-map طریقہ بولین اظہارات کو مختصر کرنے کی گرافیکل تکنیک کہلاتا ہے۔ K-maps کو دو جہتی ٹروتھ ٹیبل بھی کہتے ہیں کیونکہ ہر K-map یک جہتی ٹروتھ ٹیبل کی قدروں کو ظاہر کرنے کی محض ایک مختلف صورت ہے۔ || د منطقي افادو د حل K-map طریقه د بولین افادو د لنډولو ګرافیکي تخنیک بلل کېږي. K-maps ته دوه بعدي truth tables هم وايي ځکه هره K-map د یو بعدي truth table د ارزښتونو د ښودلو بله بڼه ده.
p K-maps basically deal with the technique of inserting the values of the output variable in cells within a rectangle or square grid according to a definite pattern. The number of cells in the K-map is determined by the number of input variables and is mathematically expressed as two raised to the power of the number of input variables, i.e., 2ⁿ, where the number of input variables is n. || K-maps بنیادی طور پر آؤٹ پٹ متغیر کی قدروں کو ایک مقررہ ترتیب کے مطابق مستطیل یا مربع جال کے خانوں میں رکھنے کی تکنیک ہیں۔ K-map میں خانوں کی تعداد ان پٹ متغیرات کی تعداد سے طے ہوتی ہے اور ریاضیاتی طور پر 2ⁿ ہے، جہاں n ان پٹ متغیرات کی تعداد ہے۔ || K-maps اساساً د output متغیر ارزښتونه د ټاکلي ترتیب سره سم د مستطیل یا مربع جال په خانو کې د ایښودلو تخنیک دی. په K-map کې د خانو شمېر د input متغیرونو په شمېر ټاکل کېږي او 2ⁿ دی، چې n د input متغیرونو شمېر دی.
p Thus, to simplify a logical expression with two inputs, we require a K-map with 4 (=2²) cells. A four-input logical expression would lead to a 16 (=2⁴) celled-K-map, and so on. || یوں دو ان پٹ والے منطقی اظہار کو مختصر کرنے کے لیے 4 (=2²) خانوں والا K-map درکار ہے۔ چار ان پٹ والا اظہار 16 (=2⁴) خانوں والا K-map بنائے گا، وغیرہ۔ || نو د دوو inputs منطقي افادې د لنډولو لپاره د 4 (=2²) خانو K-map اړینه ده. د څلورو inputs افاده 16 (=2⁴) خانو K-map جوړوي، او داسې نور.
