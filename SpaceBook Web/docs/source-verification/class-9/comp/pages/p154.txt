### Exclusive-NOR Gate (XNOR) || ایکسکلوسو-NOR گیٹ (XNOR) || Exclusive-NOR دروازه (XNOR)
p The gate whose output is '1' when all the inputs are either 0s or 1s is called XNOR gate. So XNOR gate produces the output '1' for same input values, and produces '0' output for different input values. || وہ گیٹ جس کا آؤٹ پٹ 1 ہو جب تمام ان پٹ یا تو 0 ہوں یا 1، XNOR گیٹ کہلاتا ہے۔ یوں XNOR ایک جیسے ان پٹ پر 1 اور مختلف ان پٹ پر 0 دیتا ہے۔ || هغه دروازه چې output یې 1 وي کله چې ټول inputs یا 0 یا 1 وي، XNOR بلل کېږي. نو XNOR د یو شان inputs لپاره 1 او د بېلابېلو لپاره 0 ورکوي.
p If A and B are the two inputs to an XNOR gate and Y is the output from it, then the block diagram and truth table of Exclusive-NOR gate is shown in the figure 6.7 below. || اگر A اور B XNOR گیٹ کے دو ان پٹ اور Y اس کا آؤٹ پٹ ہو تو ایکسکلوسو-NOR گیٹ کا بلاک ڈایاگرام اور ٹروتھ ٹیبل نیچے شکل 6.7 میں ہے۔ || که A او B د XNOR دوه inputs او Y یې output وي، ډیاګرام او truth table یې په ۶.۷ شکل کې دي.
