## Key Points || اہم نکات || مهم ټکي
- A set of instructions that tells a computer what to do and how to do is called a program. || ہدایات کا وہ مجموعہ جو کمپیوٹر کو بتائے کہ کیا کرنا ہے اور کیسے کرنا ہے پروگرام کہلاتا ہے۔ || د لارښوونو هغه ټولګه چې کمپیوټر ته وايي څه او څنګه وکړي پروګرام بلل کېږي.
- Program syntax refers to the rules of a programming language according to which statements of a program are to be written. || پروگرام سنٹیکس سے مراد پروگرامنگ زبان کے وہ قواعد ہیں جن کے مطابق پروگرام کی اسٹیٹمنٹس لکھی جاتی ہیں۔ || د پروګرام syntax د پروګرامي ژبې هغه قواعد دي چې د پروګرام بیانونه ورسره سم لیکل کېږي.
- Program semantic describes meaning to statements of a programming language. || پروگرام سیمینٹک پروگرامنگ زبان کی اسٹیٹمنٹس کے معنی بیان کرتا ہے۔ || د پروګرام semantic د پروګرامي ژبې د بیانونو معنا بیانوي.
- A set of words, symbols and codes used to write programs is called programming language. || پروگرام لکھنے کے لیے استعمال ہونے والے الفاظ، علامات اور کوڈز کا مجموعہ پروگرامنگ زبان کہلاتا ہے۔ || د پروګرامونو د لیکلو لپاره د کلمو، نښو او کوډونو ټولګه پروګرامي ژبه بلل کېږي.
- Low Level Languages are near to computer hardware. || لو لیول زبانیں کمپیوٹر ہارڈویئر کے قریب ہیں۔ || ټیټې کچې ژبې کمپیوټري هارډوېر ته نږدې دي.
- A type of language in which instructions are written in binary form is called machine language. || وہ زبان جس میں ہدایات بائنری صورت میں لکھی جاتی ہیں مشینی زبان کہلاتی ہے۔ || هغه ژبه چې لارښوونې پکې په باینري بڼه لیکل کېږي ماشیني ژبه بلل کېږي.
- Assembly language is a low-level language. || اسمبلی زبان ایک لو لیول زبان ہے۔ || اسمبلي ژبه ټیټې کچې ژبه ده.
- High Level Languages are English-oriented languages. || ہائی لیول زبانیں انگریزی پر مبنی زبانیں ہیں۔ || لوړې کچې ژبې انګلیسي محوره ژبې دي.
- Interpreter is a high-level programming language translator. || انٹرپریٹر ہائی لیول پروگرامنگ زبان کا مترجم ہے۔ || Interpreter د لوړې کچې پروګرامي ژبې ژباړونکی دی.
- Compiler is system software that translates (compiles) high-level language source code into machine language object code. || کمپائلر ایسا سسٹم سافٹ ویئر ہے جو ہائی لیول زبان کے سورس کوڈ کو مشینی زبان کے آبجیکٹ کوڈ میں ترجمہ (کمپائل) کرتا ہے۔ || Compiler سیسټم سافټوېر دی چې د لوړې کچې ژبې source کوډ د ماشیني ژبې object کوډ ته ژباړي (compile کوي).
- Integrated Development Environment (IDE) is the programming language development tool to create, compile and run programs. || انٹیگریٹڈ ڈیولپمنٹ انوائرنمنٹ (IDE) پروگرام بنانے، کمپائل کرنے اور چلانے کا پروگرامنگ زبان کا ترقیاتی ٹول ہے۔ || IDE د پروګرامونو د جوړولو، compile کولو او چلولو پرمختیایي وسیله ده.
- Header files are collection of standard library functions to perform different tasks. || ہیڈر فائلیں مختلف کام انجام دینے کے معیاری لائبریری فنکشنز کا مجموعہ ہیں۔ || Header فایلونه د بېلابېلو دندو لپاره د معیاري کتابتون فنکشنونو ټولګه ده.
- The words that are used by the language for special purposes are called reserved words/keywords. || وہ الفاظ جو زبان خاص مقاصد کے لیے استعمال کرتی ہے مخصوص الفاظ/کی ورڈز کہلاتے ہیں۔ || هغه کلمې چې ژبه یې د ځانګړو موخو لپاره کاروي ساتل شوې کلمې/keywords بلل کېږي.
- The instructions that are given to the compiler before the beginning of the actual program are called Preprocessor Directives. || اصل پروگرام شروع ہونے سے پہلے کمپائلر کو دی جانے والی ہدایات پری پروسیسر ڈائریکٹوز کہلاتی ہیں۔ || د اصلي پروګرام له پیل مخکې compiler ته ورکړل شوې لارښوونې Preprocessor Directives بلل کېږي.
- A quantity whose value may change during execution of the program is called a variable. || ایسی مقدار جس کی قدر پروگرام کے چلنے کے دوران بدل سکے متغیر کہلاتی ہے۔ || هغه کمیت چې ارزښت یې د پروګرام د اجرا پر مهال بدلېدای شي متغیر بلل کېږي.
- Constant is a quantity that cannot be changed during program execution. || کانسٹنٹ ایسی مقدار ہے جو پروگرام کے چلنے کے دوران بدلی نہ جا سکے۔ || ثابت هغه کمیت دی چې د پروګرام د اجرا پر مهال نه بدلېږي.
- The process of converting one data type into another data type during execution is known as type casting. || چلنے کے دوران ایک ڈیٹا ٹائپ کو دوسری میں بدلنے کا عمل ٹائپ کاسٹنگ کہلاتا ہے۔ || د اجرا پر مهال د یوه ډېټا ډول بل ته اړول type casting بلل کېږي.
