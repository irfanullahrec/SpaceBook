### Working of Nested if-else Statement || نیسٹڈ if-else اسٹیٹمنٹ کا کام || د ځالي if-else بیان کار
p In this example of nested if-else, it first tests Condition1, if this condition is TRUE then it tests Condition2, if Condition2 evaluates to TRUE then Statement1 is executed otherwise, Statement2 will be executed. Similarly, if Condition1 is FALSE then it tests Condition3, if Condition3 evaluates to TRUE then Statement3 is executed otherwise Statement4 is executed. The working of nested *if-else* presented in this example can be further illustrated by following flowchart. || نیسٹڈ if-else کی اس مثال میں پہلے Condition1 جانچی جاتی ہے؛ اگر یہ درست ہو تو Condition2 جانچی جاتی ہے، اگر Condition2 درست ہو تو Statement1 ورنہ Statement2 چلتی ہے۔ اسی طرح اگر Condition1 غلط ہو تو Condition3 جانچی جاتی ہے، اگر وہ درست ہو تو Statement3 ورنہ Statement4 چلتی ہے۔ اس مثال میں نیسٹڈ *if-else* کا کام درج ذیل فلوچارٹ سے مزید واضح ہوتا ہے۔ || د ځالي if-else په دې بېلګه کې لومړی Condition1 ازمویل کېږي؛ که سم وي Condition2 ازمویل کېږي، که Condition2 سم وي Statement1 کنه Statement2 اجرا کېږي. همدارنګه که Condition1 ناسم وي Condition3 ازمویل کېږي، که سم وي Statement3 کنه Statement4 اجرا کېږي. د ځالي *if-else* کار په لاندې فلوچارټ نور هم روښانه کېږي.
