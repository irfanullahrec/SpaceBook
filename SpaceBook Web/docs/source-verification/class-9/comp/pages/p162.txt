- **Groups must contain 1, 2, 4, 8, or in general 2ⁿ cells.** || **گروپس میں 1، 2، 4، 8 یا عمومی طور پر 2ⁿ خانے ہونے چاہئیں۔** || **ډلې باید 1، 2، 4، 8 یا په عمومي ډول 2ⁿ خانې ولري.**
p That is if n = 1, a group will contain two 1's since 2¹ = 2. || یعنی اگر n = 1 ہو تو گروپ میں دو 1 ہوں گے کیونکہ 2¹ = 2۔ || یعنې که n = 1 وي، ډله به دوه 1 ولري ځکه 2¹ = 2.
p If n = 2, a group will contain four 1's since 2² = 4. || اگر n = 2 ہو تو گروپ میں چار 1 ہوں گے کیونکہ 2² = 4۔ || که n = 2 وي، ډله به څلور 1 ولري ځکه 2² = 4.
