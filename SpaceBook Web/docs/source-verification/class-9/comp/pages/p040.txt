## 2.1 INTRODUCTION TO PROGRAMMING || 2.1 پروگرامنگ کا تعارف || ۲.۱ د پروګرام جوړونې پېژندنه
p A computer is a device that follows the instructions given to it. A well-defined set of instructions given to the computer is called a computer program. Computer programming is the process of writing a computer program to solve a particular problem. There are many languages such as C, C++, Java, etc., each having its own features. Computer program controls the operation of a computer and it is developed in a computer language to perform a task. || کمپیوٹر ایک ایسا آلہ ہے جو اسے دی گئی ہدایات پر عمل کرتا ہے۔ کمپیوٹر کو دی گئی ہدایات کا واضح مجموعہ کمپیوٹر پروگرام کہلاتا ہے۔ کسی خاص مسئلے کو حل کرنے کے لیے کمپیوٹر پروگرام لکھنے کا عمل کمپیوٹر پروگرامنگ کہلاتا ہے۔ بہت سی زبانیں ہیں جیسے C، C++، Java وغیرہ، جن میں سے ہر ایک کی اپنی خصوصیات ہیں۔ کمپیوٹر پروگرام کمپیوٹر کے کام کو کنٹرول کرتا ہے اور کوئی کام انجام دینے کے لیے کمپیوٹر زبان میں تیار کیا جاتا ہے۔ || کمپیوټر یوه وسیله ده چې ورکړل شوې لارښوونې تعقیبوي. کمپیوټر ته د ورکړل شویو لارښوونو ښه تعریف شوې ټولګه کمپیوټري پروګرام بلل کېږي. د یوې ځانګړې ستونزې د حل لپاره د کمپیوټري پروګرام لیکلو بهیر کمپیوټري پروګرام جوړونه ده. ډېرې ژبې لکه C، C++، Java او نورې شته چې هره یې خپلې ځانګړنې لري. کمپیوټري پروګرام د کمپیوټر کار کنټرولوي او د یوې دندې د ترسره کولو لپاره په کمپیوټري ژبه جوړېږي.
### 2.1.1 Computer program || 2.1.1 کمپیوٹر پروگرام || ۲.۱.۱ کمپیوټري پروګرام
p A set of instruction that tells a computer what to do is called **program.** A computer works according to the given instructions in the program. A computer program is written in a programming language. Computer languages are also known as programming languages. A person who develops a program is called **programmer**. The programmer develops programs to instruct the computer how to process data to convert it into information. A programming language is a means of communication between a user and computer. The following two terms are associated with a program. || ہدایات کا وہ مجموعہ جو کمپیوٹر کو بتائے کہ کیا کرنا ہے **پروگرام** کہلاتا ہے۔ کمپیوٹر پروگرام میں دی گئی ہدایات کے مطابق کام کرتا ہے۔ کمپیوٹر پروگرام کسی پروگرامنگ زبان میں لکھا جاتا ہے۔ کمپیوٹر زبانوں کو پروگرامنگ زبانیں بھی کہا جاتا ہے۔ پروگرام تیار کرنے والا شخص **پروگرامر** کہلاتا ہے۔ پروگرامر ایسے پروگرام تیار کرتا ہے جو کمپیوٹر کو بتاتے ہیں کہ ڈیٹا کو معلومات میں بدلنے کے لیے کیسے پروسیس کرے۔ پروگرامنگ زبان صارف اور کمپیوٹر کے درمیان رابطے کا ذریعہ ہے۔ پروگرام سے متعلق درج ذیل دو اصطلاحات ہیں۔ || د لارښوونو هغه ټولګه چې کمپیوټر ته وايي څه وکړي **پروګرام** بلل کېږي. کمپیوټر په پروګرام کې د ورکړل شویو لارښوونو سره سم کار کوي. کمپیوټري پروګرام په یوه پروګرامي ژبه لیکل کېږي. کمپیوټري ژبې پروګرامي ژبې هم بلل کېږي. هغه کس چې پروګرام جوړوي **پروګرامر** بلل کېږي. پروګرامر داسې پروګرامونه جوړوي چې کمپیوټر ته ښيي ډېټا څنګه پروسس او په معلوماتو بدله کړي. پروګرامي ژبه د کاروونکي او کمپیوټر ترمنځ د اړیکې وسیله ده. له پروګرام سره دا دوه اصطلاحګانې تړلې دي.
### Program Syntax || پروگرام کا سنٹیکس || د پروګرام syntax
p Syntax refers to the rules that define the structure of a language. Syntax in computer programming means the rules that control the structure of the symbols, punctuation, and words of a programming language. Syntax of a programming language is similar to the grammar of a natural language. For example, in C language the output is presented using *printf()* statement, whose syntax is : || سنٹیکس سے مراد وہ قواعد ہیں جو کسی زبان کی ساخت متعین کرتے ہیں۔ کمپیوٹر پروگرامنگ میں سنٹیکس سے مراد وہ قواعد ہیں جو پروگرامنگ زبان کی علامات، رموزِ اوقاف اور الفاظ کی ساخت کو کنٹرول کرتے ہیں۔ پروگرامنگ زبان کا سنٹیکس قدرتی زبان کی گرامر کی طرح ہے۔ مثلاً C زبان میں آؤٹ پٹ *printf()* اسٹیٹمنٹ سے پیش کیا جاتا ہے جس کا سنٹیکس یہ ہے: || syntax هغه قواعد دي چې د ژبې جوړښت ټاکي. په کمپیوټري پروګرام جوړونه کې syntax هغه قواعد دي چې د پروګرامي ژبې د نښو، ټکي ګذارۍ او کلمو جوړښت کنټرولوي. د پروګرامي ژبې syntax د طبیعي ژبې ګرامر ته ورته دی. د بېلګې په توګه په C ژبه کې output د *printf()* بیان په مرسته وړاندې کېږي چې syntax یې دا دی:
m printf("escape sequence/format specifier/string", variable/expression/constant);
### Program Semantic || پروگرام کا سیمینٹک (معنی) || د پروګرام semantic (معنا)
p Semantics is the study of meaning in language. It can be applied to entire texts or to single words. It describes the sequence of steps to be performed by a computer when executing the statements of a computer program. For example, the following statement of a C program will multiply two variables x and y and store the result in variable *product*. || سیمینٹکس زبان میں معنی کا مطالعہ ہے۔ اسے پورے متن یا ایک ایک لفظ پر لاگو کیا جا سکتا ہے۔ یہ ان مراحل کی ترتیب بیان کرتا ہے جو کمپیوٹر پروگرام کی اسٹیٹمنٹس پر عمل کرتے وقت کمپیوٹر کو انجام دینے ہوتے ہیں۔ مثلاً C پروگرام کی درج ذیل اسٹیٹمنٹ دو متغیرات x اور y کو ضرب دے کر نتیجہ متغیر *product* میں محفوظ کرے گی۔ || semantics په ژبه کې د معنا مطالعه ده. پر ټول متن یا یوازې کلمو پلي کېدای شي. دا د هغو ګامونو لړۍ بیانوي چې کمپیوټر یې د پروګرام د بیانونو د اجرا پر مهال ترسره کوي. د بېلګې په توګه د C پروګرام لاندې بیان دوه متغیرونه x او y ضربوي او پایله په *product* متغیر کې ساتي.
m product=x*y;
