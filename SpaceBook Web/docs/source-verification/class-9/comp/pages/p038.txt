q 2 | Give short answers to the following questions. || درج ذیل سوالات کے مختصر جوابات دیں۔ || لاندې پوښتنو ته لنډ ځوابونه ورکړئ.
qp i | Define Problem analysis. || مسئلے کے تجزیے کی تعریف کریں۔ || د ستونزې شننه تعریف کړئ.
sol Model answer ## Problem analysis is the first step of problem solving: studying the problem carefully to understand what is given (input), what is required (output) and what processing links them, so the problem is clearly defined before a solution is designed.
qp ii | How the solution of the problem is planned? || مسئلے کے حل کی منصوبہ بندی کیسے کی جاتی ہے؟ || د ستونزې د حل پلان څنګه جوړېږي؟
sol Model answer ## The solution is planned by breaking the problem into smaller steps, choosing a method (algorithm), and writing the steps in order using an algorithm, flowchart or pseudocode, then checking them with sample data before coding.
qp iii | Define candid solution of a problem. || مسئلے کے ممکنہ (Candid) حل کی تعریف کریں۔ || د ستونزې ښکاره (Candid) حل تعریف کړئ.
sol Model answer ## A candidate solution is a possible solution of the problem; several candidate solutions may be listed and the best one (the simplest, fastest and most accurate) is selected after comparing them.
qp iv | Define any three problem solving techniques. || مسئلہ حل کرنے کی کوئی سی تین تکنیکوں کی تعریف کریں۔ || د ستونزې د حل هر درې تخنیکونه تعریف کړئ.
sol Model answer ## Three problem solving techniques: (1) Divide and conquer: break a big problem into smaller sub-problems; (2) Trial and error: try possible solutions until one works; (3) Algorithm / flowchart based step-by-step approach; (also working backwards, and using diagrams).
qp v | List various factors for selecting the best solution of any problem. || کسی بھی مسئلے کے بہترین حل کے انتخاب کے مختلف عوامل کی فہرست بنائیں۔ || د هرې ستونزې د غوره حل د ټاکلو بېلابېل عوامل ولیکئ.
sol See 1.1.2–1.1.5 ## i: The programmer (not the computer) studies the problem — what it is about, how often, when and where it occurs and who is affected — and finds its causes. ii: After analysis the solution is planned so that it is cost-effective, time-efficient, speedy and less complex. iii: Finding "the best" and "the most suited" of the several possible solutions, giving the desired optimal result with minimum cost. iv: e.g. Abstraction (solve a model first), Analogy (reuse a solution of a similar problem), Divide and conquer (break into smaller solvable problems). v: Speed, Cost and Complexity. || i: پروگرامر (نہ کہ کمپیوٹر) مسئلے کا مطالعہ کرتا ہے — یہ کس بارے میں ہے، کتنی بار، کب اور کہاں پیش آتا ہے اور کون متاثر ہوتا ہے — اور اس کی وجوہات معلوم کرتا ہے۔ ii: تجزیے کے بعد حل کی ایسی منصوبہ بندی کی جاتی ہے کہ وہ کم خرچ، وقت بچانے والا، تیز اور کم پیچیدہ ہو۔ iii: کئی ممکنہ حلوں میں سے "بہترین" اور "سب سے موزوں" حل تلاش کرنا جو کم لاگت پر مطلوبہ بہترین نتیجہ دے۔ iv: مثلاً تجرید (پہلے ماڈل پر حل)، مماثلت (ملتے جلتے مسئلے کا حل دوبارہ استعمال)، تقسیم کرو اور فتح کرو (چھوٹے قابلِ حل مسائل میں توڑنا)۔ v: رفتار، لاگت اور پیچیدگی۔ || i: پروګرامر (نه کمپیوټر) ستونزه څېړي — د څه په اړه ده، څو ځله، کله او چېرې پېښېږي او څوک اغېزمن کېږي — او لاملونه یې مومي. ii: له شننې وروسته حل داسې پلان کېږي چې ارزانه، د وخت سپمونکی، چټک او لږ پېچلی وي. iii: له څو ممکنو حلونو د "غوره" او "تر ټولو مناسب" حل موندل چې په لږ لګښت مطلوبه غوره پایله ورکړي. iv: لکه تجرید (لومړی پر ماډل حل)، ورته والی (د ورته ستونزې حل بیا کارول)، وېشه او وګټه (په وړو د حل وړ ستونزو ماتول). v: چټکتیا، لګښت او پېچلتیا.
q 3 | Define an algorithm and explain the role of algorithm in problem solving. || الگورتھم کی تعریف کریں اور مسئلہ حل کرنے میں الگورتھم کے کردار کی وضاحت کریں۔ || الګوریتم تعریف کړئ او د ستونزې په حل کې د الګوریتم رول تشریح کړئ.
sol Model answer ## An algorithm is a finite, ordered set of clear steps that solves a problem or does a task. Role: it gives a plan of the solution before coding, makes the logic clear and easy to check, helps to find errors early, can be turned into a program in any language, and lets us check the efficiency of a solution.
q 4 | Describe the criteria for measuring efficiency of an algorithm on the basis of: || درج ذیل کی بنیاد پر الگورتھم کی کارکردگی جانچنے کے معیار بیان کریں: || د لاندې پر بنسټ د الګوریتم د اغېزمنتیا د اندازه کولو معیارونه بیان کړئ:

qp b | Processing to be completed || مکمل کی جانے والی پروسیسنگ || بشپړېدونکی پروسس
sol Model answer ## The calculations and operations to be done on the inputs, e.g. adding, comparing, or repeating steps.

sol Model answer ## The choices to be made during processing, e.g. if a number is greater than another, choose the path to follow.

q 5 | What is flowchart? Explain flowchart symbols in detail. || فلوچارٹ کیا ہے؟ فلوچارٹ کی علامات تفصیل سے بیان کریں۔ || فلوچارټ څه دی؟ د فلوچارټ نښې په تفصیل تشریح کړئ.
sol Model answer ## A flowchart is a diagram that shows the steps of an algorithm using symbols joined by arrows. Symbols: Terminal (oval) for start and end; Input/Output (parallelogram) for reading and displaying data; Process (rectangle) for calculations and assignment; Decision (diamond) for a yes/no or true/false test; Flow lines (arrows) for the direction; Connector (small circle) to join parts and an off-page connector.
q 6 | Write an algorithm to calculate the factorial of a given number and draw flowchart for it. || دیے گئے عدد کا فیکٹوریل معلوم کرنے کا الگورتھم لکھیں اور اس کا فلوچارٹ بنائیں۔ || د ورکړل شوي عدد د فکټوریل د محاسبې الګوریتم ولیکئ او فلوچارټ یې رسم کړئ.
sol Model answer ## Algorithm: 1. Start. 2. Read the number n. 3. Set fact = 1 and i = 1. 4. While i is not greater than n, set fact = fact x i and i = i + 1. 5. Display fact. 6. Stop. Flowchart: Start, input n, fact = 1, i = 1, decision (i <= n?): yes: fact = fact * i, i = i + 1, back to the decision; no: output fact, stop.
q 7 | Write an algorithm and draw a flowchart to resolve quadratic equation. || دو درجی مساوات حل کرنے کا الگورتھم لکھیں اور فلوچارٹ بنائیں۔ || د دوه درجه یي معادلې د حل الګوریتم ولیکئ او فلوچارټ یې رسم کړئ.
sol Model answer ## Algorithm: 1. Start. 2. Read a, b, c. 3. Calculate d = b x b - 4 x a x c. 4. If d < 0 display no real roots and go to step 7. 5. Calculate x1 = (-b + sqrt(d)) / (2a) and x2 = (-b - sqrt(d)) / (2a). 6. Display x1 and x2. 7. Stop. Flowchart: start, input a b c, process d, decision d < 0 (yes: message; no: compute x1 and x2 and output), stop.
