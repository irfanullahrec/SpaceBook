qp i | What is the use of format specifiers? Give examples. || فارمیٹ اسپیسیفائرز کا کیا استعمال ہے؟ مثالیں دیں۔ || د format specifiers کارونه څه ده؟ بېلګې ورکړئ.
sol Model answer ## A format specifier tells printf() and scanf() the type of data to print or read: %d for int, %f for float, %c for char, %s for string, %lf for double. Example: printf("%d", 25); prints 25 and printf("%f", 3.5); prints 3.500000.
qp ii | Why escape sequences are used? Give examples. || ایسکیپ سیکوینسز کیوں استعمال ہوتے ہیں؟ مثالیں دیں۔ || escape sequences ولې کارېږي؟ بېلګې ورکړئ.
sol Model answer ## Escape sequences are special characters used inside strings to print things that cannot be typed directly: \n new line, \t tab, \b backspace, \\ backslash, \" double quote. Example: printf("Hello\nWorld"); prints on two lines.
qp iii | What is the purpose of *gets()* function? || *gets()* فنکشن کا مقصد کیا ہے؟ || د *gets()* فنکشن موخه څه ده؟
sol Model answer ## The gets() function reads a whole line of text, including spaces, from the keyboard and stores it in a string (character array) until Enter is pressed. Example: char name[30]; gets(name);
qp iv | Differentiate between *getch()* and *getche()* functions. || *getch()* اور *getche()* فنکشنز میں فرق کریں۔ || د *getch()* او *getche()* توپیر وکړئ.
sol Model answer ## getch() reads one character from the keyboard without displaying it on the screen and without waiting for Enter; getche() also reads one character without Enter, but the character is displayed (echoed) on the screen.
qp v | Evaluate the following expressions. a. 9-5*(6+2)  b. 60/10*24+3  c. 100%50-100%3 || درج ذیل اظہارات کی قدر معلوم کریں۔ (الف) 9-5*(6+2) (ب) 60/10*24+3 (ج) 100%50-100%3 || لاندې افادې وارزوئ. (الف) 9-5*(6+2) (ب) 60/10*24+3 (ج) 100%50-100%3
sol (a) -31 (b) 147 (c) -1 ## (a) 9 - 5 x (6 + 2) = 9 - 5 x 8 = 9 - 40 = -31. (b) 60 / 10 x 24 + 3 = 6 x 24 + 3 = 144 + 3 = 147. (c) 100 % 50 - 100 % 3 = 0 - 1 = -1.
qp vi | Differentiate between simple and compound assignment operators. || سادہ اور کمپاؤنڈ اسائنمنٹ آپریٹرز میں فرق کریں۔ || د ساده او مرکب assignment operators توپیر وکړئ.
sol Model answer ## Simple assignment (=) stores a value in a variable (a = 5). Compound assignment operators combine an arithmetic operation with assignment (+=, -=, *=, /=, %=): a += 5 means a = a + 5.
q 3 | What are operators? Explain different types of operators with examples. || آپریٹرز کیا ہیں؟ مختلف اقسام کے آپریٹرز کی مثالوں سے وضاحت کریں۔ || operators څه دي؟ بېلابېل ډولونه یې په بېلګو تشریح کړئ.
sol Model answer ## Operators are symbols that perform operations on operands. Types: arithmetic (+ - * / %), relational (< > <= >= == !=), logical (&& and, double bar for or, ! not), assignment (= += -=), increment/decrement (++ --), and conditional (?:). Examples: a + b, a > b, (a > 5) && (b < 3), x += 2, i++.
q 4 | What is output function? Describe in detail different types of output functions. || آؤٹ پٹ فنکشن کیا ہے؟ آؤٹ پٹ فنکشنز کی مختلف اقسام تفصیل سے بیان کریں۔ || output فنکشن څه دی؟ د output فنکشنونو ډولونه په تفصیل بیان کړئ.
sol Model answer ## Output functions send data to the screen. printf() prints text and values with format specifiers, e.g. printf("Sum = %d", s); puts() prints a string followed by a new line; putchar() prints one character; putch() (conio.h) prints a character.
q 5 | Discuss different format specifiers and escape sequences used in *printf()* function. || *printf()* فنکشن میں استعمال ہونے والے مختلف فارمیٹ اسپیسیفائرز اور ایسکیپ سیکوینسز پر بحث کریں۔ || په *printf()* کې کارېدونکي format specifiers او escape sequences وڅېړئ.
sol Model answer ## Format specifiers in printf(): %d (int), %f (float), %c (char), %s (string), %lf (double), %u (unsigned). Escape sequences: \n (new line), \t (tab), \a (alert sound), \\ (backslash), \" (quote), \b (backspace). Example: printf("Name: %s\tAge: %d\n", name, age);
q 6 | Explain different types of input functions with examples. || ان پٹ فنکشنز کی مختلف اقسام کی مثالوں سے وضاحت کریں۔ || د input فنکشنونو ډولونه په بېلګو تشریح کړئ.
sol Model answer ## Input functions read data from the keyboard: scanf() reads formatted values, e.g. scanf("%d", &a); getchar() reads one character and waits for Enter; getch() and getche() read one character without Enter; gets() reads a whole line of text. Example: char c; c = getchar();
