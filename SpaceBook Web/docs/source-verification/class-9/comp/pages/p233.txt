q 2 | What is website? Describe different types of websites with examples. || ویب سائٹ کیا ہے؟ ویب سائٹس کی مختلف اقسام مثالوں کے ساتھ بیان کریں۔ || وېب سایټ څه دی؟ د وېب سایټونو بېلابېل ډولونه په بېلګو بیان کړئ.
sol Model answer ## A website is a collection of related web pages with a common domain name stored on a web server. Types: personal (a student's home page), business/commercial (daraz.pk), educational (a school or university site), news (dawn.com), government (tbb.kp.gov.pk), social (facebook), entertainment, blogs and search engines (google).
q 3 | Write the HTML tags for the following? || درج ذیل کے لیے HTML ٹیگز لکھیں؟ || د لاندې لپاره HTML tags ولیکئ؟
qp i | Paragraph || پیراگراف || پاراګراف
sol Model answer ## <p>This is a paragraph</p>
qp ii | Heading || ہیڈنگ || سرلیک
sol Model answer ## <h1>Heading</h1> (headings run from <h1>, the largest, to <h6>, the smallest)
qp iii | Bold || بولڈ || Bold
sol Model answer ## <b>Bold text</b>
qp iv | Underline || انڈر لائن || Underline
sol Model answer ## <u>Underlined text</u>
qp v | Italic || اٹالک || Italic
sol Model answer ## <i>Italic text</i>
qp vi | Center text || متن درمیان میں || منځ ته متن
sol Model answer ## <center>Centered text</center> (or style="text-align:center")
qp vii | Superscript || سپر اسکرپٹ || Superscript
sol Model answer ## x<sup>2</sup> (superscript, raised text)
qp viii | Subscript || سب اسکرپٹ || Subscript
sol Model answer ## H<sub>2</sub>O (subscript, lowered text)

q 4 | Create a web page in HTML that displays image of a printer. The width of image should be 250 pixels and height 150 pixels. || HTML میں ایسا ویب پیج بنائیں جو پرنٹر کی تصویر دکھائے۔ تصویر کی چوڑائی 250 اور اونچائی 150 پکسل ہو۔ || په HTML کې داسې پاڼه جوړه کړئ چې د printer انځور وښيي. پلنوالی ۲۵۰ او لوړوالی ۱۵۰ پکسل وي.
sol Model answer ## <html><body><img src="printer.jpg" width="250" height="150" alt="Printer"></body></html>
q 5 | Describe how background color and image are applied to web page. || بیان کریں کہ ویب پیج پر پس منظر کا رنگ اور تصویر کیسے لگائی جاتی ہے۔ || بیان کړئ چې وېب پاڼې ته د شالید رنګ او انځور څنګه ورکول کېږي.
sol Model answer ## Background colour: <body bgcolor="yellow"> (or style="background-color:yellow"). Background image: <body background="picture.jpg"> (or style="background-image:url('picture.jpg')"). The image or colour is applied to the whole page behind the content.
q 6 | Create an HTML document that contains a graphical hyperlink. || ایسی HTML دستاویز بنائیں جس میں گرافیکل ہائپر لنک ہو۔ || داسې HTML سند جوړ کړئ چې ګرافیکي hyperlink ولري.
sol Model answer ## <html><body><a href="https://www.google.com"><img src="logo.jpg" width="100" height="50"></a></body></html> (the image inside the anchor tag works as a hyperlink)
q 7 | Create a web page in HTML that contains unordered and ordered lists. || HTML میں ایسا ویب پیج بنائیں جس میں غیر ترتیب وار اور ترتیب وار فہرستیں ہوں۔ || په HTML کې داسې پاڼه جوړه کړئ چې بې ترتیبه او ترتیب لرونکي لستونه ولري.
sol Model answer ## <html><body> Unordered: <ul><li>Apple</li><li>Mango</li></ul> Ordered: <ol><li>First</li><li>Second</li></ol> </body></html>
q 8 | Create an HTML document that contains hyperlinks to three websites. || ایسی HTML دستاویز بنائیں جس میں تین ویب سائٹس کے ہائپر لنکس ہوں۔ || داسې HTML سند جوړ کړئ چې درې وېب سایټونو ته hyperlinks ولري.
sol Model answer ## <html><body><a href="https://www.google.com">Google</a> <a href="https://www.wikipedia.org">Wikipedia</a> <a href="https://tbb.kp.gov.pk">KP Textbook Board</a></body></html>
