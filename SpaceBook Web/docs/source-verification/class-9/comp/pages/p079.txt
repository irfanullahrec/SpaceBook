p The *gets()* function is capable to accept a string with white space characters. In this case the string will be entered from the keyboard while running the program and will end when the user presses the Enter key. So here is a difference between *scanf()* and *gets()* functions. The *scanf()* reads all characters until white space (blanks, tabs, new line) is encountered, whereas *gets()* will read everything (including blanks and tabs) until user presses Enter key. || *gets()* فنکشن خالی جگہوں (white space) والی اسٹرنگ قبول کر سکتا ہے۔ اس صورت میں پروگرام چلتے وقت اسٹرنگ کی بورڈ سے لکھی جائے گی اور صارف کے Enter دبانے پر ختم ہوگی۔ یہی *scanf()* اور *gets()* میں فرق ہے۔ *scanf()* خالی جگہ (اسپیس، ٹیب، نئی سطر) آنے تک تمام حروف پڑھتا ہے، جبکہ *gets()* صارف کے Enter دبانے تک ہر چیز (اسپیس اور ٹیب سمیت) پڑھتا ہے۔ || *gets()* فنکشن د تشو ځایونو (white space) لرونکې string منلی شي. په دې حالت کې string د پروګرام د چلېدو پر مهال له کیبورډ لیکل کېږي او کله چې کاروونکی Enter کېښکاږي پای ته رسېږي. دا د *scanf()* او *gets()* توپیر دی. *scanf()* تر تش ځای (space، tab، نوې کرښه) پورې توري لولي، خو *gets()* هر څه (د space او tab په ګډون) تر Enter پورې لولي.
