### Web Server || ویب سرور || وېب سرور
p A web server is a computer that is used to store information for multiple users on the Internet. The basic objective of the web server is to store, process and deliver web pages to the users. This intercommunication is done using Hypertext Transfer Protocol (HTTP). A web server is much faster and powerful than ordinary computer. Every web server has an IP address and possibly a domain name. For example, if user enters the URL *https://www.urdupoint.com/news.html* in the browser, this sends a request to the web server whose domain name is *urdupoint.com*. The server then fetches the page named *news.html* and sends it to the user's browser. || ویب سرور ایک کمپیوٹر ہے جو انٹرنیٹ پر متعدد صارفین کے لیے معلومات محفوظ کرنے کے لیے استعمال ہوتا ہے۔ ویب سرور کا بنیادی مقصد ویب پیجز کو محفوظ، پروسیس اور صارفین تک پہنچانا ہے۔ یہ باہمی رابطہ ہائپر ٹیکسٹ ٹرانسفر پروٹوکول (HTTP) کے ذریعے ہوتا ہے۔ ویب سرور عام کمپیوٹر سے کہیں زیادہ تیز اور طاقتور ہوتا ہے۔ ہر ویب سرور کا ایک IP ایڈریس اور ممکنہ طور پر ایک ڈومین نیم ہوتا ہے۔ مثلاً اگر صارف براؤزر میں URL *https://www.urdupoint.com/news.html* لکھے تو یہ اس ویب سرور کو درخواست بھیجتا ہے جس کا ڈومین نیم *urdupoint.com* ہے۔ پھر سرور *news.html* نامی صفحہ نکال کر صارف کے براؤزر کو بھیج دیتا ہے۔ || وېب سرور هغه کمپیوټر دی چې په انټرنېټ کې د ډېرو کاروونکو لپاره معلومات ساتي. اصلي موخه یې د وېب پاڼو ساتل، پروسس او کاروونکو ته رسول دي. دا اړیکه د HTTP په مرسته کېږي. وېب سرور تر عادي کمپیوټر ډېر چټک او پیاوړی دی. هر وېب سرور IP پته او ښايي domain نوم لري. د بېلګې په توګه که کاروونکی په براوزر کې *https://www.urdupoint.com/news.html* ولیکي، هغه سرور ته غوښتنه ځي چې domain نوم یې *urdupoint.com* دی. بیا سرور *news.html* پاڼه راوړي او د کاروونکي براوزر ته یې لېږي.
p Any computer can be turned into a web server by installing server software and connecting the machine to the Internet. || کوئی بھی کمپیوٹر سرور سافٹ ویئر انسٹال کر کے اور انٹرنیٹ سے جوڑ کر ویب سرور بنایا جا سکتا ہے۔ || هر کمپیوټر د سرور سافټوېر په نصبولو او انټرنېټ ته په نښلولو وېب سرور کېدای شي.

### Uniform Resource Locator (URL) || یونیفارم ریسورس لوکیٹر (URL) || Uniform Resource Locator (URL)
p A URL (Uniform Resource Locator) is the unique address for a file that is accessible on the Internet. A common way to get to a website is to enter the URL of its home page file in the web browser's address line. However, any file within that website can also be specified with a URL. || URL انٹرنیٹ پر قابلِ رسائی فائل کا منفرد پتہ ہے۔ کسی ویب سائٹ تک پہنچنے کا عام طریقہ یہ ہے کہ ویب براؤزر کی ایڈریس لائن میں اس کے ہوم پیج کا URL لکھا جائے۔ تاہم اس ویب سائٹ کی کسی بھی فائل کو URL سے بتایا جا سکتا ہے۔ || URL په انټرنېټ کې د لاسرسي وړ فایل ځانګړې پته ده. وېب سایټ ته د رسېدو عامه لاره دا ده چې د کور پاڼې URL د براوزر د پتې په کرښه کې ولیکل شي. خو د وېب سایټ هر فایل هم په URL ټاکل کېدای شي.
p URLs have the following format: || URLs کی صورت یہ ہے: || د URLs بڼه دا ده:
m protocol://hostname/other_information
