### 7.6.5 Creating a Graphical Hyperlink || 7.6.5 گرافیکل ہائپر لنک بنانا || ۷.۶.۵ ګرافیکي hyperlink جوړول
p One of the best ways to create an impact with your web page is to add some graphics. Graphics can add color, depth and sparkle to a web page and can serve to catch the eye and retain viewer interest. || اپنے ویب پیج کو مؤثر بنانے کا ایک بہترین طریقہ گرافکس شامل کرنا ہے۔ گرافکس ویب پیج میں رنگ، گہرائی اور چمک پیدا کرتے ہیں اور نظر کو کھینچ کر دیکھنے والے کی دلچسپی برقرار رکھتے ہیں۔ || ستاسو وېب پاڼې د اغېز تر ټولو ښه لاره ګرافیک زیاتول دي. ګرافیک وېب پاڼې ته رنګ، ژوروالی او ځلا ورکوي او د لیدونکي پام جلبوي او لېوالتیا یې ساتي.
p The syntax for creating a graphical hyperlink to another web page is: || کسی دوسرے ویب پیج کا گرافیکل ہائپر لنک بنانے کا سنٹیکس یہ ہے: || بلې پاڼې ته د ګرافیکي hyperlink جوړولو syntax دا دی:
m <a href= "url"><img scr="name of image file"></a>
@issue The syntax line is printed with "scr" for "src"; the example below uses the correct "src". Kept as printed.
p For example: || مثلاً: || د بېلګې په توګه:
m <a href="http://www.fbise.edu.pk"><img src="image.jpg"></a>
p It will display the *image.jpg* image file in the browser window. When the reader moves the mouse pointer over the image, it will change to a small hand and clicking on the image will open the Federal Board website that has the URL www.fbise.edu.pk. || یہ براؤزر ونڈو میں *image.jpg* تصویر دکھائے گا۔ جب قاری ماؤس پوائنٹر کو تصویر پر لائے گا تو یہ چھوٹے ہاتھ میں بدل جائے گا اور تصویر پر کلک کرنے سے وفاقی بورڈ کی ویب سائٹ کھلے گی جس کا URL www.fbise.edu.pk ہے۔ || دا به په براوزر کې *image.jpg* انځور ښيي. کله چې لوستونکی ماوس پر انځور راولي، په کوچني لاس بدلېږي او پر انځور کلیک به د فدرالي بورډ وېب سایټ پرانیزي چې URL یې www.fbise.edu.pk دی.
