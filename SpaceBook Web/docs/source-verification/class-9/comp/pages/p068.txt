qp i | Differentiate between program syntax and program semantic. || پروگرام سنٹیکس اور پروگرام سیمینٹک میں فرق کریں۔ || د پروګرام syntax او semantic ترمنځ توپیر وکړئ.
sol Model answer ## Syntax is the set of grammar rules for writing statements of a language (a missing semicolon is a syntax error); semantics is the meaning of the statements, i.e. what the statement does (a program with correct syntax but wrong logic has a semantic error).
qp ii | Differentiate between Low level and high level languages. || لو لیول اور ہائی لیول زبانوں میں فرق کریں۔ || د ټیټې او لوړې کچې ژبو ترمنځ توپیر وکړئ.
sol Model answer ## Low-level languages (machine and assembly) are close to the hardware, machine dependent, fast but difficult to write and learn. High-level languages (C, Python, Java) use English-like words, are machine independent, easy to learn and write, but must be translated into machine code.
qp iii | What is IDE? || IDE کیا ہے؟ || IDE څه دی؟
sol Model answer ## IDE (Integrated Development Environment) is software that gives an editor, compiler, debugger and other tools in one place to write, compile, run and debug programs, e.g. Dev-C++, Code::Blocks, Visual Studio.
qp iv | What is OOP? || OOP کیا ہے؟ || OOP څه دی؟
sol Model answer ## OOP (Object-Oriented Programming) is a programming approach that organizes a program around objects, which combine data and the functions that work on it, using classes, encapsulation, inheritance and polymorphism (C++, Java).
