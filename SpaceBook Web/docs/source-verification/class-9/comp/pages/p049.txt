## 2.2 PROGRAMMING ENVIRONMENT || 2.2 پروگرامنگ کا ماحول || ۲.۲ د پروګرام جوړونې چاپېریال
p Programming environment is the set of processes and programming tools used to develop computer programs. It includes editor, compiler, linker, debugger, etc. It is called Integrated Development Environment (IDE) for developing computer programs. Integrated Development Environment is application software with a GUI. || پروگرامنگ کا ماحول ان عملوں اور پروگرامنگ ٹولز کا مجموعہ ہے جو کمپیوٹر پروگرام تیار کرنے کے لیے استعمال ہوتے ہیں۔ اس میں ایڈیٹر، کمپائلر، لنکر، ڈیبگر وغیرہ شامل ہیں۔ کمپیوٹر پروگرام تیار کرنے کے لیے اسے انٹیگریٹڈ ڈیولپمنٹ انوائرنمنٹ (IDE) کہا جاتا ہے۔ انٹیگریٹڈ ڈیولپمنٹ انوائرنمنٹ GUI والا ایپلی کیشن سافٹ ویئر ہے۔ || د پروګرام جوړونې چاپېریال د هغو بهیرونو او پروګرامي وسیلو ټولګه ده چې د کمپیوټري پروګرامونو د جوړولو لپاره کارېږي. editor، compiler، linker، debugger او نور پکې شامل دي. د کمپیوټري پروګرامونو د جوړولو لپاره ورته Integrated Development Environment (IDE) وايي. IDE د GUI لرونکی اپلیکېشن سافټوېر دی.
### 2.2.1 Integrated Developement Environment (IDE) || 2.2.1 انٹیگریٹڈ ڈیولپمنٹ انوائرنمنٹ (IDE) || ۲.۲.۱ یوځای پرمختیایي چاپېریال (IDE)
@issue Heading printed "Developement"; kept as printed.
p Integrated Development Environment (IDE) is the programming language development tool to create, compile and run programs. IDE is computer software that brings all the processes and tools required for program development into one environment. Today's modern IDEs have user-friendly GUI. C language also uses IDE, as shown in Figure 2.9. || انٹیگریٹڈ ڈیولپمنٹ انوائرنمنٹ (IDE) پروگرام بنانے، کمپائل کرنے اور چلانے کا پروگرامنگ زبان کا ترقیاتی ٹول ہے۔ IDE ایسا کمپیوٹر سافٹ ویئر ہے جو پروگرام کی تیاری کے لیے درکار تمام عمل اور ٹولز ایک ماحول میں لے آتا ہے۔ آج کے جدید IDEs صارف دوست GUI رکھتے ہیں۔ C زبان بھی IDE استعمال کرتی ہے، جیسا کہ شکل 2.9 میں دکھایا گیا ہے۔ || IDE د پروګرامونو د جوړولو، compile کولو او چلولو لپاره د پروګرامي ژبې پرمختیایي وسیله ده. IDE هغه کمپیوټري سافټوېر دی چې د پروګرام جوړونې ټول اړین بهیرونه او وسیلې یوه چاپېریال ته راولي. نن ورځ نوي IDEs د کاروونکي لپاره اسانه GUI لري. C ژبه هم IDE کاروي، لکه په ۲.۹ شکل کې.
