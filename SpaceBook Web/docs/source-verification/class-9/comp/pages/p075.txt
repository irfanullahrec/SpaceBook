### a. *scanf()* function || الف۔ *scanf()* فنکشن || الف. *scanf()* فنکشن
p *scanf()* function is used to read multiple data values of different data types from the keyboard. With *scanf()* function, a program will not be processed and the result will not be displayed until you type the input value(s) for variable(s). The *scanf()* function has the following syntax. || *scanf()* فنکشن کی بورڈ سے مختلف ڈیٹا ٹائپس کی کئی قدریں پڑھنے کے لیے استعمال ہوتا ہے۔ *scanf()* کے ساتھ پروگرام اس وقت تک پروسیس نہیں ہوگا اور نتیجہ ظاہر نہیں ہوگا جب تک آپ متغیرات کی ان پٹ قدریں نہ لکھیں۔ *scanf()* کا سنٹیکس یہ ہے۔ || *scanf()* فنکشن له کیبورډ د بېلابېلو ډېټا ډولونو ډېر ارزښتونه لوستلو لپاره کارېږي. د *scanf()* سره پروګرام تر هغه نه پروسس کېږي او پایله نه ښکاري تر څو د متغیرونو input ارزښتونه ونه لیکئ. د *scanf()* syntax دا دی.
m scanf ("format specifiers", &var1, &var2, &var3,………);
p Where, **"format specifiers"** specifies the format of variables through format specifiers. It is written within double quotes. **&var1, &var2, &var3,……** are the list of variables separated by commas, into which the values are to be assigned. The symbol & used in *scanf()* represents the address of memory location. || جہاں **"format specifiers"** فارمیٹ اسپیسیفائرز کے ذریعے متغیرات کا فارمیٹ بتاتے ہیں اور دوہرے واوین میں لکھے جاتے ہیں۔ **&var1، &var2، &var3،……** کوما سے الگ متغیرات کی فہرست ہے جن میں قدریں رکھی جانی ہیں۔ *scanf()* میں استعمال ہونے والی علامت & میموری مقام کا پتہ (ایڈریس) ظاہر کرتی ہے۔ || چې **"format specifiers"** د format specifiers له لارې د متغیرونو format ټاکي او په دوه ګونو quotes کې لیکل کېږي. **&var1، &var2، &var3،……** په کامو جلا متغیرونه دي چې ارزښتونه پکې ږدي. په *scanf()* کې & نښه د حافظې د ځای پته ښيي.
