### 2.2.2 Modules of the C Programing Environment || 2.2.2 C پروگرامنگ ماحول کے ماڈیولز || ۲.۲.۲ د C پروګرامي چاپېریال ماډیولونه
p The following are modules of the C programming environment. || C پروگرامنگ ماحول کے ماڈیولز درج ذیل ہیں۔ || د C پروګرامي چاپېریال ماډیولونه دا دي.
### 1. Editor || 1. ایڈیٹر || ۱. Editor
p Editor or text editor is a program that enables users to create and edit C language source program having extension *.c*, e.g., *student.c* is a C-language source program. Most of the editors automatically highlight compilation errors to easily remove them. || ایڈیٹر یا ٹیکسٹ ایڈیٹر ایک پروگرام ہے جو صارفین کو *.c* ایکسٹینشن والا C زبان کا سورس پروگرام بنانے اور اس میں ترمیم کرنے کے قابل بناتا ہے، مثلاً *student.c* ایک C زبان کا سورس پروگرام ہے۔ زیادہ تر ایڈیٹر کمپائلیشن کی غلطیوں کو خودبخود نمایاں کرتے ہیں تاکہ انہیں آسانی سے دور کیا جا سکے۔ || Editor یا text editor یو پروګرام دی چې کاروونکو ته د *.c* توسیع لرونکي C ژبې source پروګرام د جوړولو او سمولو وړتیا ورکوي، لکه *student.c* د C ژبې source پروګرام دی. ډېری editors د compilation تېروتنې پخپله برجسته کوي څو په اسانۍ لرې شي.
### 2. Compiler || 2. کمپائلر || ۲. Compiler
p A compiler is computer software that translates C language program (source program) into machine code (object program) that can be understood and executed by the computer. A compiled C-language program has an extension *.obj*, e.g., student.obj. Compilation process is shown in Figure 2.10. || کمپائلر ایسا کمپیوٹر سافٹ ویئر ہے جو C زبان کے پروگرام (سورس پروگرام) کو مشینی کوڈ (آبجیکٹ پروگرام) میں ترجمہ کرتا ہے جسے کمپیوٹر سمجھ کر چلا سکے۔ کمپائل شدہ C پروگرام کی ایکسٹینشن *.obj* ہوتی ہے، مثلاً student.obj۔ کمپائلیشن کا عمل شکل 2.10 میں دکھایا گیا ہے۔ || Compiler هغه کمپیوټري سافټوېر دی چې د C ژبې پروګرام (source پروګرام) ماشیني کوډ (object پروګرام) ته ژباړي چې کمپیوټر پرې پوه او اجرا یې کړي. د compile شوي C پروګرام توسیع *.obj* ده، لکه student.obj. د compilation بهیر په ۲.۱۰ شکل کې ښودل شوی.

### 3. Linker || 3. لنکر || ۳. Linker
p A computer program that takes one or more object codes generated by a compiler and combines them into a single executable program is called ***linker***. || وہ کمپیوٹر پروگرام جو کمپائلر کے بنائے ہوئے ایک یا زیادہ آبجیکٹ کوڈز لے کر انہیں ایک قابلِ عمل پروگرام میں جوڑ دے ***لنکر*** کہلاتا ہے۔ || هغه کمپیوټري پروګرام چې د compiler له خوا جوړ شوي یو یا څو object کوډونه اخلي او په یوه اجرا وړ پروګرام کې یې یوځای کوي ***linker*** بلل کېږي.
p C-language executable program has the extension *.exe*, e.g., student.exe. A complete linking process is shown in Figure 2.11. || C زبان کے قابلِ عمل پروگرام کی ایکسٹینشن *.exe* ہوتی ہے، مثلاً student.exe۔ لنکنگ کا مکمل عمل شکل 2.11 میں دکھایا گیا ہے۔ || د C ژبې د اجرا وړ پروګرام توسیع *.exe* ده، لکه student.exe. د linking بشپړ بهیر په ۲.۱۱ شکل کې ښودل شوی.
