q 1 | Choose the correct option. || درست آپشن منتخب کریں۔ || سم انتخاب وټاکئ.
qp i | The oxidation number of nitrogen N₂ is: (a) +1 (b) +3 (c) 0 (d) −3 || N₂ میں نائٹروجن کا تکسیدی عدد ہے: (a) +1 (b) +3 (c) 0 (d) −3 || په N₂ کې د نایتروجن د اکسیدېشن عدد دی: (a) +1 (b) +3 (c) 0 (d) −3
solution (c)
ss By rule, the oxidation number of an element in its free, uncombined elementary state (N2) is zero (0).
endsolution
qp ii | What is the oxidation number of C in CH₃OH? (a) −2 (b) −1 (c) 0 (d) +1 || CH₃OH میں C کا تکسیدی عدد کیا ہے؟ (a) −2 (b) −1 (c) 0 (d) +1 || په CH₃OH کې د C د اکسیدېشن عدد څو دی؟ (a) −2 (b) −1 (c) 0 (d) +1
solution (a)
ss In CH3OH: C + 4(H) + 1(O) = 0 => C + 4(+1) + (-2) = 0 => C + 4 - 2 = 0 => C + 2 = 0 => C = -2.
endsolution
qp iii | A cation is (a) neutral. (b) negatively charged. (c) without charge. (d) positively charged. || کیٹ آئن ہے: (a) غیر باردار۔ (b) منفی بار والا۔ (c) بار کے بغیر۔ (d) مثبت بار والا۔ || کاتیون دی: (a) بې‌طرفه. (b) منفي چارج لرونکی. (c) بې‌چارج. (d) مثبت چارج لرونکی.
solution (d)
ss A cation is formed when an atom loses one or more electrons, resulting in a net positive electrical charge.
endsolution
qp iv | Electrons are lost by the (a) reducing agent as it undergoes oxidation. (b) reducing agent as it undergoes reduction. (c) oxidizing agent as it undergoes oxidation. (d) oxidizing agent as it undergoes reduction. || الیکٹران کھوتا ہے: (a) تخفیفی عامل جب اس کی تکسید ہوتی ہے۔ (b) تخفیفی عامل جب اس کی تخفیف ہوتی ہے۔ (c) تکسیدی عامل جب اس کی تکسید ہوتی ہے۔ (d) تکسیدی عامل جب اس کی تخفیف ہوتی ہے۔ || الکترونونه بایلي: (a) ریډکشن کوونکی عامل چې اکسید کېږي. (b) ریډکشن کوونکی عامل چې ریډکشن کېږي. (c) اکسیدوونکی عامل چې اکسید کېږي. (d) اکسیدوونکی عامل چې ریډکشن کېږي.
solution (a)
ss A reducing agent donates (loses) electrons to another species, and in doing so, it undergoes oxidation itself.
endsolution
qp v | What is the oxidation number assigned to manganese in KMnO₄? (a) +7 (b) +3 (c) +2 (d) +4 || KMnO₄ میں مینگنیز کا مقرر تکسیدی عدد کیا ہے؟ (a) +7 (b) +3 (c) +2 (d) +4 || په KMnO₄ کې د منګنیز ټاکل شوی د اکسیدېشن عدد څو دی؟ (a) +7 (b) +3 (c) +2 (d) +4
solution (a)
ss In KMnO4: K(+1) + Mn + 4[O(-2)] = 0 => 1 + Mn - 8 = 0 => Mn - 7 = 0 => Mn = +7.
endsolution
qp vi | In a particular redox reaction, the oxidation number of phosphorus changed from −3 to 0. From this information, it may be concluded that phosphorus: (a) Lost 3 electrons and was reduced. (b) Lost 3 electrons and was oxidized. (c) Gained 3 electrons and was reduced. (d) Gained 3 electrons and was oxidized. || ایک ریڈوکس تعامل میں فاسفورس کا تکسیدی عدد −3 سے 0 ہو گیا۔ اس سے نتیجہ نکلتا ہے کہ فاسفورس نے: (a) 3 الیکٹران کھوئے اور تخفیف ہوئی۔ (b) 3 الیکٹران کھوئے اور تکسید ہوئی۔ (c) 3 الیکٹران حاصل کیے اور تخفیف ہوئی۔ (d) 3 الیکٹران حاصل کیے اور تکسید ہوئی۔ || په یوه ریډوکس تعامل کې د فاسفورس د اکسیدېشن عدد له −3 څخه 0 ته بدل شو. له دې معلومېږي چې فاسفورس: (a) 3 الکترونونه وبایلل او ریډکشن شو. (b) 3 الکترونونه وبایلل او اکسید شو. (c) 3 الکترونونه واخیستل او ریډکشن شو. (d) 3 الکترونونه واخیستل او اکسید شو.
solution (b)
ss An increase in oxidation number from -3 to 0 corresponds to a loss of 3 electrons, which is oxidation.
endsolution
