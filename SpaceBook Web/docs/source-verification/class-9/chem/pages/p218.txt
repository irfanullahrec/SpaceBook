qp viii | In which of the following does sulphur have an oxidation number of +7? (a) HSO₃⁻ (b) SO₃ (c) H₂SO₄ (d) H₂S₂O₈ || کس میں سلفر کا تکسیدی عدد +7 ہے؟ (a) HSO₃⁻ (b) SO₃ (c) H₂SO₄ (d) H₂S₂O₈ || په کوم یوه کې د سلفر د اکسیدېشن عدد +7 دی؟ (a) HSO₃⁻ (b) SO₃ (c) H₂SO₄ (d) H₂S₂O₈
sol None of the options (the maximum oxidation number of sulphur is +6) ## In HSO3- sulphur is +4; in SO3, H2SO4 and H2S2O8 it is +6 (in H2S2O8 two of the oxygens are in a peroxide link). No option gives +7, so the question as printed has no correct choice; (d) H2S2O8 is the intended trick option.

q i | Indicate which element is reduced in the following reactions: a. Ca(s) + Br₂(g) → CaBr₂(s); b. 2HCl + Zn → ZnCl₂ + H₂. || ان تعاملات میں تخفیف ہونے والا عنصر بتائیں: a. Ca(s) + Br₂(g) → CaBr₂(s)؛ b. 2HCl + Zn → ZnCl₂ + H₂۔ || په دې تعاملونو کې ریډکشن کېدونکی عنصر وښایئ: a. Ca(s) + Br₂(g) → CaBr₂(s)؛ b. 2HCl + Zn → ZnCl₂ + H₂.
qsolution a. In Ca + Br2 ──> CaBr2: Bromine (Br2) changes oxidation number from 0 to -1 (gains electrons), so Bromine (Br2) is reduced (Ca is oxidized from 0 to +2).
ss b. In 2HCl + Zn ──> ZnCl2 + H2: Hydrogen (H+ in HCl) changes oxidation number from +1 to 0 in H2 (gains electrons), so Hydrogen (H+) is reduced (Zn is oxidized from 0 to +2).
endsolution
q ii | What is the oxidation number of silver on each side of the following equation? 4Ag(s) + O₂(g) —Heat→ 2Ag₂O. || اس مساوات کے دونوں طرف چاندی کا تکسیدی عدد کیا ہے؟ 4Ag(s) + O₂(g) —حرارت→ 2Ag₂O۔ || د دې مساوات په هر لوري کې د سپینو زرو د اکسیدېشن عدد څو دی؟ 4Ag(s) + O₂(g) —تودوخه→ 2Ag₂O.
qsolution • Left-hand side (Reactants): Silver is in its free elementary state (Ag), so its oxidation number is 0.
ss • Right-hand side (Products): In Ag2O, oxygen is -2. Thus 2(Ag) + (-2) = 0 ──> 2(Ag) = +2 ──> Ag = +1.
ss Conclusion: Silver changes from 0 on the left to +1 on the right (undergoing oxidation).
endsolution
