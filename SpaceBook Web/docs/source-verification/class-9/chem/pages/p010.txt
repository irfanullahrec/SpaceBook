### Symbols of Elements
p In 1814, Berzelius suggested the system for representing elements with symbols. The shortest name of an element is called symbol. In most cases, the first letter of the name of an element is taken in capital letter as the symbol. In some cases, where the first letter has already been used, then the initial letters in capital together with a small any other letter from its name are used.
