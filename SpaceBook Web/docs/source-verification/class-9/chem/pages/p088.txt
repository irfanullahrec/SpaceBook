### EXAMPLE: 3.3 || مثال: 3.3 || بېلګه: 3.3
p Which set has the more similar chemical properties? (a) N, P, As (b) Li, C, F || کس مجموعے کی کیمیائی خصوصیات زیادہ ملتی جلتی ہیں؟ (a) N, P, As (b) Li, C, F || کومه مجموعه ډېرې ورته کیمیاوي ځانګړتیاوې لري؟ (a) N, P, As (b) Li, C, F
### Solution || حل || حل
p Set (b) is in the same period (2); set (a) is in the same group (VA). Set (a) has the more similar chemical properties because these elements are in the same group. || مجموعہ (b) ایک ہی دور (2) میں ہے؛ مجموعہ (a) ایک ہی گروہ (VA) میں ہے۔ مجموعہ (a) کی کیمیائی خصوصیات زیادہ ملتی جلتی ہیں کیونکہ یہ عناصر ایک ہی گروہ میں ہیں۔ || (b) مجموعه په یوه دوره (۲) کې ده؛ (a) مجموعه په یوه ډله (VA) کې ده. د (a) مجموعې کیمیاوي ځانګړتیاوې ډېرې ورته دي، ځکه دا عناصر په یوه ډله کې دي.
