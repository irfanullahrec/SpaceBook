## 6.3.3 Understanding function overloading concept || 6.3.3 فنکشن اوورلوڈنگ کے تصور کو سمجھنا || ۶.۳.۳ د فنکشن ډېرولو مفهوم پوهېدل
p For the complete understanding of the concept of function overloading, one should know those features of the overloaded functions which disambiguate them and make them unique in a single program. These features are listed below: || فنکشن اوورلوڈنگ کے تصور کو مکمل طور پر سمجھنے کے لیے اوورلوڈ فنکشنز کی وہ خصوصیات جاننی چاہییں جو انھیں ایک دوسرے سے ممیز کرتی ہیں اور ایک پروگرام میں منفرد بناتی ہیں۔ یہ خصوصیات ذیل میں درج ہیں: || د فنکشن ډېرولو د مفهوم د بشپړ پوهېدو لپاره باید د ډېر شویو فنکشنونو هغه ځانګړتیاوې وپېژنو چې یو له بله یې جلا کوي او په یوه پروګرام کې یې ځانګړي کوي. دا ځانګړتیاوې لاندې دي:
- Number of arguments || آرگیومنٹس کی تعداد || د دلیلونو شمېر
- Data types of arguments || آرگیومنٹس کی ڈیٹا ٹائپس || د دلیلونو ډېټا ډولونه
- Return type || ریٹرن ٹائپ || د بېرته ورکړې ډول
## a. Number of arguments || a. آرگیومنٹس کی تعداد || a. د دلیلونو شمېر
p Functions can be overloaded if they have different numbers of parameters. More than one functions with the same name but different number of parameters can be used in a single program. In the calls to these functions, the compiler disambiguates the calls by looking at the number of arguments and formal parameters in the function decelerators. Consider the following example: || فنکشنز اوورلوڈ کیے جا سکتے ہیں اگر ان کے پیرامیٹرز کی تعداد مختلف ہو۔ ایک ہی نام لیکن مختلف تعداد کے پیرامیٹرز والے ایک سے زیادہ فنکشنز ایک پروگرام میں استعمال ہو سکتے ہیں۔ ان فنکشنز کی کالز میں کمپائلر فنکشن ڈکلیریٹرز میں آرگیومنٹس اور رسمی پیرامیٹرز کی تعداد دیکھ کر کالز میں امتیاز کرتا ہے۔ درج ذیل مثال پر غور کریں: || فنکشنونه ډېرېدای شي که د پاراميټرونو شمېر یې بېل وي. د یو نوم خو د بېل شمېر پاراميټرونو له یوه ډېر فنکشنونه په یوه پروګرام کې کارېدای شي. دې فنکشنونو ته په غوښتنو کې کمپایلر د فنکشن په اعلانوونکو کې د دلیلونو او رسمي پاراميټرونو شمېر ته په کتلو غوښتنې جلا کوي. لاندې بېلګې ته پام وکړئ:
