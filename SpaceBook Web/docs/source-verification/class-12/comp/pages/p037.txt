qp iv | Multiprogramming refers to: (a) Having several programs in RAM at the same time (b) Multiprocessing (c) Writing programs in multiple languages (d) None of the above || ملٹی پروگرامنگ سے مراد ہے: (a) ایک ہی وقت میں RAM میں کئی پروگرام موجود ہونا (b) ملٹی پروسیسنگ (c) متعدد زبانوں میں پروگرام لکھنا (d) ان میں سے کوئی نہیں || څو-پروګرامي کار ته اشاره ده: (a) په یو وخت په RAM کې د څو پروګرامونو شتون (b) څو-پروسسي کار (c) په ډېرو ژبو پروګرامونه لیکل (d) له پورته هېڅ یو
sol Having several programs in RAM at the same time ## Multiprogramming means keeping several programs in main memory (RAM) at the same time so that the CPU switches to another program when one waits for I/O.
