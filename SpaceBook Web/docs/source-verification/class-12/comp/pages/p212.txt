## 6.2.3 return statement || 6.2.3 return بیان || ۶.۲.۳ return بیان
p If the return type of a function is any valid data type such as int, long, float, double, long double or char then return statement should be used in the function body to return the result to the calling program. || اگر فنکشن کی ریٹرن ٹائپ کوئی درست ڈیٹا ٹائپ ہو جیسے int، long، float، double، long double یا char تو کال کرنے والے پروگرام کو نتیجہ واپس کرنے کے لیے فنکشن کے جسم میں return بیان استعمال ہونا چاہیے۔ || که د فنکشن د بېرته ورکړې ډول هر سم ډېټا ډول وي لکه int، long، float، double، long double یا char، نو غوښتونکي پروګرام ته د پایلې د بېرته ورکولو لپاره باید د فنکشن په بدنه کې return بیان وکارول شي.
