## ii. User-defined constructor/ Explicit constructor || ii. یوزر ڈیفائنڈ کنسٹرکٹر/ واضح کنسٹرکٹر || ii. د کاروونکي-تعریف شوی جوړوونکی/ ښکاره جوړوونکی
p When users define constructors in class for their own purpose, especially for initialization of variables, then such types of constructors are called user defined constructors. When constructor is declared for a class, the compiler no longer provides an implicit default constructor. So, the objects should be declared according to the constructor prototypes that have been defined for the class. || جب صارفین اپنے مقصد کے لیے، خاص طور پر ویری ایبلز کو ابتدائی قدر دینے کے لیے، کلاس میں کنسٹرکٹرز بیان کرتے ہیں تو ایسے کنسٹرکٹرز یوزر ڈیفائنڈ کنسٹرکٹرز کہلاتے ہیں۔ جب کلاس کے لیے کنسٹرکٹر ڈکلیئر کیا جائے تو کمپائلر مزید implicit ڈیفالٹ کنسٹرکٹر فراہم نہیں کرتا۔ اس لیے آبجیکٹس کو کلاس کے لیے بیان کیے گئے کنسٹرکٹر پروٹوٹائپس کے مطابق ڈکلیئر کرنا چاہیے۔ || کله چې کاروونکي د خپلې موخې لپاره، په ځانګړي ډول د متغیرونو د لومړني ارزښت لپاره، په ټولګي کې جوړوونکي تعریف کړي، داسې جوړوونکي د کاروونکي-تعریف شوي جوړوونکي بلل کېږي. کله چې د ټولګي لپاره جوړوونکی اعلان شي، کمپایلر نور ضمني ډیفالټ جوړوونکی نه برابروي. نو شیان باید د هغو جوړوونکو نمونو سره سم اعلان شي چې د ټولګي لپاره تعریف شوې.
