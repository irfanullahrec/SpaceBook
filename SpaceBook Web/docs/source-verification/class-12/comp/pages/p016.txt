## d. Mac OS || d. میک او ایس || d. Mac OS
p Mac OS stands for Macintosh operating system. It is a series of operating systems having graphical user interfaces that have been developed by Apple Inc. On January 24, 1984, Apple Computer Inc. manufactured its first Macintosh personal computer and developed a system software for it which was later on renamed to Mac OS. || Mac OS سے مراد میکنٹوش آپریٹنگ سسٹم ہے۔ یہ گرافیکل یوزر انٹرفیس والے آپریٹنگ سسٹمز کا ایک سلسلہ ہے جو ایپل انکارپوریٹڈ نے تیار کیے ہیں۔ 24 جنوری 1984ء کو ایپل کمپیوٹر انکارپوریٹڈ نے اپنا پہلا میکنٹوش ذاتی کمپیوٹر تیار کیا اور اس کے لیے ایک سسٹم سافٹ ویئر بنایا جس کا نام بعد میں Mac OS رکھا گیا۔ || Mac OS د Macintosh عملیاتي سیسټم معنا لري. دا د ګرافیکي کاروونکي منځګړي لرونکو عملیاتي سیسټمونو یوه لړۍ ده چې Apple Inc. جوړه کړې. د ۱۹۸۴ز د جنوري په ۲۴مه Apple Computer Inc. خپل لومړی Macintosh شخصي کمپیوټر جوړ کړ او ورته یې سیسټم سافټویر جوړ کړ چې وروسته Mac OS ونومول شو.
p Mac OS can be divided into two groups which are: Mac OS Classic family and the Mac OS X family. So far, Mac OS has ten (10) versions with the names Mac OS 1, 2, 3, 4, 5, 6, 7, 8, 9 and X. Figure 1.5 shows the desktop interface of Mac OS. || Mac OS کو دو گروپوں میں تقسیم کیا جا سکتا ہے: Mac OS Classic فیملی اور Mac OS X فیملی۔ اب تک Mac OS کے دس (10) ورژن Mac OS 1، 2، 3، 4، 5، 6، 7، 8، 9 اور X کے ناموں سے آ چکے ہیں۔ شکل 1.5 میں Mac OS کا ڈیسک ٹاپ انٹرفیس دکھایا گیا ہے۔ || Mac OS په دوو ډلو وېشل کېدای شي: د Mac OS Classic کورنۍ او د Mac OS X کورنۍ. تر اوسه د Mac OS لس (۱۰) نسخې د Mac OS 1، 2، 3، 4، 5، 6، 7، 8، 9 او X په نومونو راغلې دي. ۱.۵ شکل د Mac OS د ډیسکټاپ منځګړی ښيي.
