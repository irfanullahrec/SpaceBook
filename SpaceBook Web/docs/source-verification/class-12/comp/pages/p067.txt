## 3.1 INTRODUCTION || 3.1 تعارف || ۳.۱ پېژندنه
p This Unit is about the introduction to Object Oriented Programming Language, C++, and covers its basics in detail. The Unit is focused on basic C++ program structure, variables used in C++, input/output statements and the use of operators in the language. || یہ یونٹ آبجیکٹ اورینٹڈ پروگرامنگ زبان C++ کے تعارف کے بارے میں ہے اور اس کی بنیادی باتوں کا تفصیل سے احاطہ کرتا ہے۔ یونٹ بنیادی C++ پروگرام کی ساخت، C++ میں استعمال ہونے والے ویری ایبلز، ان پٹ/آؤٹ پٹ بیانات اور زبان میں آپریٹرز کے استعمال پر مرکوز ہے۔ || دا څپرکی د شیانو ته متوجه پروګرامي ژبې C++ د پېژندنې په اړه دی او بنسټونه یې په تفصیل سره رانغاړي. څپرکی د C++ پر بنسټیز پروګرامي جوړښت، په C++ کې کارېدونکو متغیرونو، د ننوتو/وتو بیانونو او په ژبه کې د چلونکو پر کارونې تمرکز لري.
p Bjarne Stroustrup at Bell Labs initially developed C++ during the early 1980’s. It was designed to support the features of C such as efficiency and low-level support for system level coding. Added to this were features such as classes with inheritance and virtual functions, derived from the Simula language, and operator overloading, derived from Algol. C++ is best described as a superset of C, with full support for object-oriented programming. This language is in wide spread use. The first commercial release of the C++ language was in October of 1985. || بیل لیبز میں بیارنے اسٹراؤسٹرپ نے 1980ء کی دہائی کے اوائل میں ابتدائی طور پر C++ تیار کی۔ اسے C کی خصوصیات جیسے کارکردگی اور سسٹم کی سطح کی کوڈنگ کے لیے نچلی سطح کی معاونت کے لیے بنایا گیا تھا۔ اس میں Simula زبان سے ماخوذ وراثت اور ورچوئل فنکشنز والی کلاسز اور Algol سے ماخوذ آپریٹر اوورلوڈنگ جیسی خصوصیات شامل کی گئیں۔ C++ کو بہترین طور پر C کا ایک وسیع تر مجموعہ (superset) کہا جا سکتا ہے جو آبجیکٹ اورینٹڈ پروگرامنگ کی مکمل معاونت کرتا ہے۔ یہ زبان بڑے پیمانے پر استعمال ہوتی ہے۔ C++ زبان کا پہلا تجارتی اجراء اکتوبر 1985ء میں ہوا۔ || په بیل لابز کې بیارنې سټراوسټروپ په لومړي ځل د ۱۹۸۰مو کلونو په پیل کې C++ جوړه کړه. دا د C د ځانګړنو لکه اغېزمنتیا او د سیسټم د کچې کوډ لیکنې لپاره د ټیټې کچې ملاتړ لپاره ډیزاین شوې وه. ورسره داسې ځانګړنې ورزیاتې شوې لکه د میراث او مجازي فنکشنونو لرونکي ټولګي چې له Simula ژبې اخیستل شوي، او د چلونکو ډېرول (operator overloading) چې له Algol اخیستل شوی. C++ په ښه توګه د C پراخه ټولګه (superset) بلل کېدای شي چې د شیانو ته متوجه پروګرام‌سازۍ بشپړ ملاتړ کوي. دا ژبه په پراخه کچه کارېږي. د C++ ژبې لومړنی سوداګریز خپرېدل د ۱۹۸۵ز په اکتوبر کې وو.
## 3.1.1 Computer program || 3.1.1 کمپیوٹر پروگرام || ۳.۱.۱ کمپیوټري پروګرام
p A computer program is a set of instructions written in computer languages to perform a specified task for a computer. A computer program tells the computer that what to do and in which order to do. Different types of programming languages are used to develop programs. Some commonly used programming languages are C++, JAVA, SQL, HTML, etc. || کمپیوٹر پروگرام کمپیوٹر زبانوں میں لکھی گئی ہدایات کا ایک مجموعہ ہے جو کمپیوٹر کے لیے ایک مخصوص کام انجام دیتا ہے۔ کمپیوٹر پروگرام کمپیوٹر کو بتاتا ہے کہ کیا کرنا ہے اور کس ترتیب سے کرنا ہے۔ پروگرام تیار کرنے کے لیے مختلف اقسام کی پروگرامنگ زبانیں استعمال ہوتی ہیں۔ کچھ عام استعمال ہونے والی پروگرامنگ زبانیں C++، JAVA، SQL، HTML وغیرہ ہیں۔ || کمپیوټري پروګرام په کمپیوټري ژبو لیکل شویو لارښوونو یوه ټولګه ده چې د کمپیوټر لپاره یوه ټاکلې دنده ترسره کوي. کمپیوټري پروګرام کمپیوټر ته وايي چې څه وکړي او په کوم ترتیب یې وکړي. د پروګرامونو د جوړولو لپاره بېلابېل ډوله پروګرامي ژبې کارول کېږي. ځینې عام کارېدونکې پروګرامي ژبې C++، JAVA، SQL، HTML او نورې دي.
## 3.1.2 Header files and Reserved words || 3.1.2 ہیڈر فائلیں اور مخصوص الفاظ || ۳.۱.۲ سرلیک فایلونه او ځانګړې کلمې
p Header files and reserved words are the two important components of almost every C++ programs. || ہیڈر فائلیں اور مخصوص الفاظ تقریباً ہر C++ پروگرام کے دو اہم اجزاء ہیں۔ || سرلیک فایلونه او ځانګړې کلمې د نږدې هر C++ پروګرام دوه مهمې برخې دي.
## a. Header files || a. ہیڈر فائلیں || a. سرلیک فایلونه
p Header files also known as include files, are standard library files that have an extension of (.h) and which are used to hold declarations for other files. || ہیڈر فائلیں، جنھیں انکلوڈ فائلیں بھی کہا جاتا ہے، معیاری لائبریری فائلیں ہیں جن کی ایکسٹینشن (.h) ہوتی ہے اور جو دوسری فائلوں کے اعلانات رکھنے کے لیے استعمال ہوتی ہیں۔ || سرلیک فایلونه چې شاملې فایلونه (include files) هم بلل کېږي، معیاري کتابتون فایلونه دي چې (.h) پسوند لري او د نورو فایلونو د اعلانونو ساتلو لپاره کارول کېږي.
