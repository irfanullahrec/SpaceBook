## 3.3.2 Standard input (cin) || 3.3.2 معیاری ان پٹ (cin) || ۳.۳.۲ معیاري ننوتنه (cin)
p The standard input device used for entering input to the computer is keyboard. In C++, the stream extraction operator >> and object cin are used to handle the standard input. The operator >> must be followed by the variable that will store the data that is going to be extracted from the stream. Consider the following lines of code: || کمپیوٹر میں ان پٹ داخل کرنے کے لیے استعمال ہونے والا معیاری ان پٹ آلہ کی بورڈ ہے۔ C++ میں اسٹریم ایکسٹریکشن آپریٹر >> اور آبجیکٹ cin معیاری ان پٹ کو سنبھالنے کے لیے استعمال ہوتے ہیں۔ آپریٹر >> کے بعد وہ ویری ایبل ہونا چاہیے جو اسٹریم سے نکالا جانے والا ڈیٹا محفوظ کرے گا۔ کوڈ کی درج ذیل لائنوں پر غور کریں: || کمپیوټر ته د ننوتنې د لیکلو معیاري وسیله کیبورډ دی. په C++ کې د بهیر د راایستلو (extraction) چلونکی >> او cin شی د معیاري ننوتنې د سمبالولو لپاره کارول کېږي. د >> چلونکي وروسته باید هغه متغیر راشي چې له بهیر راایستل کېدونکې ډېټا ساتي. د کوډ لاندې کرښو ته پام وکړئ:
p int marks; cin >> marks; || int marks; cin >> marks; || int marks; cin >> marks;
p Here, the first statement, int marks; declares a variable of type int called ‘marks’, and the second statement waits for an input from cin in order to store it in this integer variable. || یہاں پہلا بیان int marks; ایک int قسم کا ویری ایبل ’marks‘ ڈکلیئر کرتا ہے، اور دوسرا بیان cin سے ان پٹ کا انتظار کرتا ہے تاکہ اسے اس انٹیجر ویری ایبل میں محفوظ کیا جائے۔ || دلته لومړی بیان int marks; د int ډول یو متغیر چې ‘marks’ نومېږي اعلانوي، او دویم بیان له cin د ننوتنې انتظار کوي څو یې په دې صحیح عددي متغیر کې وساتي.
