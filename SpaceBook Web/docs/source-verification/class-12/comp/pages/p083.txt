## i. int data type || i. int ڈیٹا ٹائپ || i. د int ډېټا ډول
p The keyword int stands for the integer data type in C++ and normally has two bytes of memory (16 bits). A 16 bit integer may fall in the range of $-2^{15}$ to $2^{15}-1$, which means that it can store values in the range of -32768 to 32767. || کی ورڈ int، C++ میں انٹیجر ڈیٹا ٹائپ کے لیے ہے اور عام طور پر میموری کے دو بائٹس (16 بٹس) لیتا ہے۔ 16 بٹ کا انٹیجر $-2^{15}$ سے $2^{15}-1$ کی حد میں ہو سکتا ہے، یعنی یہ -32768 سے 32767 تک کی قدریں محفوظ کر سکتا ہے۔ || د int کلیدي کلمه په C++ کې د صحیح عدد ډېټا ډول ښيي او عموماً د حافظې دوه بایټه (۱۶ بټه) لري. یو ۱۶-بټه صحیح عدد د $-2^{15}$ تر $2^{15}-1$ په حد کې کېدای شي، یعنې د -32768 تر 32767 پورې ارزښتونه ساتلی شي.
## ii. short int data type || ii. short int ڈیٹا ٹائپ || ii. د short int ډېټا ډول
p short int is used to declare the short integer data type in C++. The maximum size of the short int data type is 2 bytes (16 bits). It may fall in the range $-2^{15}$ to $2^{15}-1$, which means that it can store the values from -32768 to 32767. || short int، C++ میں شارٹ انٹیجر ڈیٹا ٹائپ ڈکلیئر کرنے کے لیے استعمال ہوتا ہے۔ short int ڈیٹا ٹائپ کا زیادہ سے زیادہ سائز 2 بائٹس (16 بٹس) ہے۔ یہ $-2^{15}$ سے $2^{15}-1$ کی حد میں ہو سکتا ہے، یعنی -32768 سے 32767 تک کی قدریں محفوظ کر سکتا ہے۔ || short int په C++ کې د لنډ صحیح عدد ډېټا ډول د اعلان لپاره کارول کېږي. د short int اعظمي اندازه ۲ بایټه (۱۶ بټه) ده. د $-2^{15}$ تر $2^{15}-1$ په حد کې کېدای شي، یعنې له -32768 تر 32767 ارزښتونه ساتلی شي.
## iii. long int data type || iii. long int ڈیٹا ٹائپ || iii. د long int ډېټا ډول
p long int stands for long integer data type and is used in C++ to store larger integer values. Its size is 4 bytes (32 bits) which means that it can stores values in the range of -2147483648 to 2147483647. || long int سے مراد لانگ انٹیجر ڈیٹا ٹائپ ہے اور یہ C++ میں بڑی صحیح عددی قدریں محفوظ کرنے کے لیے استعمال ہوتا ہے۔ اس کا سائز 4 بائٹس (32 بٹس) ہے، یعنی یہ -2147483648 سے 2147483647 تک کی قدریں محفوظ کر سکتا ہے۔ || long int د اوږد صحیح عدد ډېټا ډول دی او په C++ کې د لویو صحیح عددي ارزښتونو د ساتلو لپاره کارول کېږي. اندازه یې ۴ بایټه (۳۲ بټه) ده، یعنې له -2147483648 تر 2147483647 پورې ارزښتونه ساتلی شي.
## c. Floating point data type || c. فلوٹنگ پوائنٹ ڈیٹا ٹائپ || c. اعشاري ډېټا ډول

The data types which are used to store such type of data are called floating point data types. Variables of floating point types hold real numbers, such as 4.0, 2.5, 3.33, or 0.1226. - float || float || float

## i. float data type || i. float ڈیٹا ٹائپ || i. د float ډېټا ډول
