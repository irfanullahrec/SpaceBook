## 5.1 Introduction to array || 5.1 ایرے کا تعارف || ۵.۱ د لړۍ پېژندنه
p We group our everyday data into conceptual units rather than storing in individual pieces. We collect the data items into conceptual units and assign names to them. For a single conceptual unit we have a single name. This conceptual unit of homogeneous data having the same name for all the data items is called array. The array is used to store many items of the same type as a single unit or group. Consider the examples of storing the scores of all the students of a class in an array or storing their names. || ہم اپنے روزمرہ ڈیٹا کو الگ الگ ٹکڑوں میں رکھنے کے بجائے تصوراتی اکائیوں میں گروپ کرتے ہیں۔ ہم ڈیٹا آئٹمز کو تصوراتی اکائیوں میں جمع کر کے انھیں نام دیتے ہیں۔ ایک تصوراتی اکائی کا ایک ہی نام ہوتا ہے۔ یکساں ڈیٹا کی یہ تصوراتی اکائی جس کے تمام ڈیٹا آئٹمز کا نام ایک ہو، ایرے کہلاتی ہے۔ ایرے ایک ہی قسم کے بہت سے آئٹمز کو ایک اکائی یا گروپ کے طور پر محفوظ کرنے کے لیے استعمال ہوتا ہے۔ مثلاً کسی جماعت کے تمام طلبہ کے نمبر یا ان کے نام ایک ایرے میں محفوظ کرنا۔ || موږ خپل ورځنی ډېټا د جلا ټوټو پر ځای په مفهومي واحدونو کې ډله کوو. ډېټا توکي په مفهومي واحدونو کې راټولوو او نومونه ورکوو. د یوه مفهومي واحد لپاره یو نوم لرو. د ورته ډېټا دا مفهومي واحد چې ټول توکي یې یو نوم ولري، لړۍ بلل کېږي. لړۍ د یو ډول ډېرو توکو د یوه واحد یا ډلې په توګه ساتلو لپاره کارېږي. د بېلګې په توګه د یوه ټولګي د ټولو زده‌کوونکو نمرې یا نومونه په یوه لړۍ کې ساتل.
## 5.1.1 Concept of arrays || 5.1.1 ایریز کا تصور || ۵.۱.۱ د لړیو مفهوم
p An array is a collection of data items of the same data types placed in contiguous memory locations that can individually be referenced by using an index to a unique identifier. Consider the example for storing 7 values of type int in an array without having to declare 7 different variables each one with a different variable name. Instead of that, using an array we can store 7 different values of the same data type with a unique variable name. Consider an array X that contains 7 integer values of type int.
