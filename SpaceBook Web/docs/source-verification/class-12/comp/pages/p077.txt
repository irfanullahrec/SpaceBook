## b. Variables || b. ویری ایبلز || b. متغیرونه
p A variable in C++ is a name for a piece of memory that can be used to store information. A variable can be thought as a mailbox where information can be put and retrieved from. All computers have memory, called Random Access Memory (RAM) that is available for programs to use. When a variable is declared, a piece of that memory is set aside for that variable. || C++ میں ویری ایبل میموری کے ایک حصے کا نام ہے جو معلومات محفوظ کرنے کے لیے استعمال ہو سکتا ہے۔ ویری ایبل کو ایک ڈاک خانے کے ڈبے کی طرح سمجھا جا سکتا ہے جس میں معلومات رکھی اور نکالی جا سکتی ہیں۔ تمام کمپیوٹرز میں میموری ہوتی ہے جسے رینڈم ایکسیس میموری (RAM) کہتے ہیں اور جو پروگراموں کے استعمال کے لیے دستیاب ہوتی ہے۔ جب کوئی ویری ایبل ڈکلیئر کیا جاتا ہے تو اس میموری کا ایک حصہ اس ویری ایبل کے لیے مختص کر دیا جاتا ہے۔ || په C++ کې متغیر د حافظې د یوې برخې نوم دی چې د معلوماتو د ساتلو لپاره کارول کېدای شي. متغیر د لیک صندوق په څېر ګڼل کېدای شي چې معلومات پکې ایښودل او ترې اخیستل کېدای شي. ټول کمپیوټرونه حافظه لري چې تصادفي لاسرسي حافظه (RAM) بلل کېږي او د پروګرامونو د کارونې لپاره شته. کله چې یو متغیر اعلان شي، د هغې حافظې یوه برخه د هغه متغیر لپاره ځانګړې کېږي.
p Consider the following segment of code. || کوڈ کے درج ذیل حصے پر غور کریں۔ || د کوډ لاندې برخې ته پام وکړئ.
p int a = 5; int b = 2; int result = a - b; || int a = 5; int b = 2; int result = a - b; || int a = 5; int b = 2; int result = a - b;
p In this segment, a, b and result are the integer variables that reside in RAM and store integer values. || اس حصے میں a، b اور result انٹیجر ویری ایبلز ہیں جو RAM میں موجود ہیں اور صحیح عددی قدریں محفوظ کرتے ہیں۔ || په دې برخه کې a، b او result صحیح عددي متغیرونه دي چې په RAM کې اوسي او صحیح عددي ارزښتونه ساتي.
## 3.2.2 Rules for naming variables || 3.2.2 ویری ایبلز کے نام رکھنے کے قواعد || ۳.۲.۲ د متغیرونو د نوم ایښودو قاعدې
p The symbol used for a variable is called an identifier or variable name. A set of rules are used for naming variables. These rules are: || ویری ایبل کے لیے استعمال ہونے والی علامت کو شناخت کنندہ (identifier) یا ویری ایبل کا نام کہتے ہیں۔ ویری ایبلز کے نام رکھنے کے لیے قواعد کا ایک مجموعہ استعمال ہوتا ہے۔ یہ قواعد یہ ہیں: || هغه نښه چې د متغیر لپاره کارول کېږي، پېژندونکی (identifier) یا د متغیر نوم بلل کېږي. د متغیرونو د نوم ایښودو لپاره د قاعدو یوه ټولګه کارول کېږي. دا قاعدې دا دي:
- Valid identifier is a sequence of one or more letters, digits or underscores || درست شناخت کنندہ ایک یا زیادہ حروف، اعداد یا انڈر اسکور (_) کا || سم پېژندونکی د یوه یا ډېرو تورو، رقمونو یا د انډرسکور (_)
