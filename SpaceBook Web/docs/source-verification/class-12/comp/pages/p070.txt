## a. Preprocessor directives (#include, #define) || a. پری پروسیسر ڈائریکٹوز (#include، #define) || a. د مخکې پروسس لارښوونې (#include، #define)
p A preprocessor is a collection of special statements which are executed before the compilation process. || پری پروسیسر خصوصی بیانات کا مجموعہ ہے جو کمپائلیشن کے عمل سے پہلے چلائے جاتے ہیں۔ || مخکې پروسسوونکی (preprocessor) د ځانګړو بیانونو ټولګه ده چې د کمپایل له بهیر مخکې اجرا کېږي.
p Almost every C++ program contains a preprocessor directive. The #include preprocessor directives is commonly used to insert header files with extension ‘.h’. These header files are already stored in computer in include directory. In the above program, two #include directives have been used, #include<iostream.h> and #include<conio.h>. #include<iostream.h> is used for the C++ object cout and #include<conio.h> for the built-in function getch(). || تقریباً ہر C++ پروگرام میں پری پروسیسر ڈائریکٹو ہوتا ہے۔ #include پری پروسیسر ڈائریکٹو عام طور پر ‘.h’ ایکسٹینشن والی ہیڈر فائلیں شامل کرنے کے لیے استعمال ہوتا ہے۔ یہ ہیڈر فائلیں کمپیوٹر میں include ڈائریکٹری میں پہلے سے محفوظ ہوتی ہیں۔ اوپر والے پروگرام میں دو #include ڈائریکٹوز استعمال ہوئے ہیں، #include<iostream.h> اور #include<conio.h>۔ #include<iostream.h> C++ آبجیکٹ cout کے لیے اور #include<conio.h> بلٹ ان فنکشن getch() کے لیے استعمال ہوتا ہے۔ || نږدې هر C++ پروګرام د مخکې پروسس لارښوونه لري. د #include لارښوونه عموماً د ‘.h’ پسوند لرونکو سرلیک فایلونو د ورګډولو لپاره کارول کېږي. دا سرلیک فایلونه مخکې له مخکې په کمپیوټر کې په include لارښود کې ساتل شوي. په پورته پروګرام کې دوه #include لارښوونې کارول شوې، #include<iostream.h> او #include<conio.h>. #include<iostream.h> د C++ شي cout لپاره او #include<conio.h> د جوړ شوي فنکشن getch() لپاره کارول کېږي.
p In C++, the other commonly used preprocessor directive is #define which is used to define symbolic constants. Its general format is: || C++ میں دوسرا عام استعمال ہونے والا پری پروسیسر ڈائریکٹو #define ہے جو علامتی کانسٹنٹس کی تعریف کے لیے استعمال ہوتا ہے۔ اس کی عمومی شکل یہ ہے: || په C++ کې بله عام کارېدونکې د مخکې پروسس لارښوونه #define ده چې د سمبولیکو ثابتونو د تعریف لپاره کارول کېږي. عمومي بڼه یې دا ده:
p #define identifier value || #define identifier value || #define identifier value
p For example: || مثال کے طور پر: || د بېلګې په توګه:
p #define PI 3.14159 #define NEWLINE '\n' || #define PI 3.14159 #define NEWLINE '\n' || #define PI 3.14159 #define NEWLINE '\n'
p This defines two new constants: PI and NEWLINE. Once they are defined, they can be used in the rest of the program as if they were any other regular constant, for example: || یہ دو نئے کانسٹنٹس PI اور NEWLINE کی تعریف کرتا ہے۔ ایک بار تعریف ہو جانے کے بعد انھیں باقی پروگرام میں کسی بھی دوسرے عام کانسٹنٹ کی طرح استعمال کیا جا سکتا ہے، مثلاً: || دا دوه نوي ثابتونه PI او NEWLINE تعریفوي. کله چې یو ځل تعریف شي، په پاتې پروګرام کې د هر بل عادي ثابت په څېر کارول کېدای شي، لکه:
p #include <iostream.h> #include <conio.h> #define PI 3.14159 #define NEWLINE '\n' int main() || #include <iostream.h> #include <conio.h> #define PI 3.14159 #define NEWLINE '\n' int main() || #include <iostream.h> #include <conio.h> #define PI 3.14159 #define NEWLINE '\n' int main()
