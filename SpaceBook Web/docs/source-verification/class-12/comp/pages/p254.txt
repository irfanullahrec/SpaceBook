## iii. Constructor overloading || iii. کنسٹرکٹر اوورلوڈنگ || iii. د جوړوونکي ډېرول
p Using more than one constructors in the same class is called constructor overloading. Like any other function, a constructor can also be overloaded with more than one function that have the same name but different types or number of parameters. For an overloaded function, the compiler calls the function whose parameters match the arguments used in the function call. In the case of constructor overloading, that constructor is executed whose parameters match the arguments passed to the object declaration.
