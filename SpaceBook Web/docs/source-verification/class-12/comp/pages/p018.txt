p Multiprogramming operating system is that type of operating system which allows running of multiple computer programs simultaneously on a single processor. For example, you may be typing in MS Word, listening to music while in background Internet Explorer is downloading some pages from the Internet. Working in Windows 7, Vista, XP and Linux environment is multiprogramming. || ملٹی پروگرامنگ آپریٹنگ سسٹم آپریٹنگ سسٹم کی وہ قسم ہے جو ایک ہی پروسیسر پر بیک وقت متعدد کمپیوٹر پروگرام چلانے کی اجازت دیتی ہے۔ مثلاً آپ MS Word میں ٹائپ کر رہے ہوں، موسیقی سن رہے ہوں جبکہ پس منظر میں Internet Explorer انٹرنیٹ سے کچھ صفحات ڈاؤن لوڈ کر رہا ہو۔ Windows 7، Vista، XP اور Linux کے ماحول میں کام کرنا ملٹی پروگرامنگ ہے۔ || څو-پروګرامي عملیاتي سیسټم د عملیاتي سیسټم هغه ډول دی چې پر یوه پروسېسر په یو وخت د ډېرو کمپیوټري پروګرامونو د چلولو اجازه ورکوي. د بېلګې په توګه تاسو کېدای شي په MS Word کې ټایپ کوئ، موسیقي اورئ، په داسې حال کې چې په شاليد کې Internet Explorer له انټرنېټ ځینې پاڼې ښکته کوي. د Windows 7، Vista، XP او Linux په چاپېریال کې کار کول څو-پروګرامي کار دی.
p In multiprogramming operating systems, several programs, called jobs, are active at the same time in the main memory (RAM) of the computer. This means that multiple jobs are loaded into RAM and executed by a single processor. Figure 1.6 shows main memory partitioned into five (05) frames holding four (04) jobs. || ملٹی پروگرامنگ آپریٹنگ سسٹمز میں کئی پروگرام، جنھیں جابز کہا جاتا ہے، کمپیوٹر کی مین میموری (RAM) میں بیک وقت فعال ہوتے ہیں۔ اس کا مطلب ہے کہ متعدد جابز RAM میں لوڈ ہوتی ہیں اور ایک ہی پروسیسر انھیں چلاتا ہے۔ شکل 1.6 میں مین میموری کو پانچ (05) فریمز میں تقسیم دکھایا گیا ہے جن میں چار (04) جابز ہیں۔ || په څو-پروګرامي عملیاتي سیسټمونو کې څو پروګرامونه چې دندې بلل کېږي، د کمپیوټر په اصلي حافظه (RAM) کې په یو وخت فعال وي. مطلب یې دا دی چې ډېرې دندې RAM ته ورپورته کېږي او یو پروسېسر یې چلوي. ۱.۶ شکل اصلي حافظه ښيي چې په پنځو (۰۵) چوکاټونو وېشل شوې او څلور (۰۴) دندې لري.

## Advantages of multi-programming || ملٹی پروگرامنگ کے فوائد || د څو-پروګرامي کار ګټې
p Multiprogramming operating systems make efficient use of the processor by interleaving multiple actives jobs that reside in main memory. It also attempts to increase CPU utilization by always having something for the CPU to execute. Main memory (RAM) is efficiently utilized to hold more jobs at a time. || ملٹی پروگرامنگ آپریٹنگ سسٹم مین میموری میں موجود متعدد فعال جابز کو باری باری چلا کر پروسیسر کا مؤثر استعمال کرتے ہیں۔ یہ CPU کے لیے ہمیشہ کچھ نہ کچھ چلانے کو رکھ کر اس کے استعمال کو بڑھانے کی کوشش بھی کرتا ہے۔ مین میموری (RAM) کو بیک وقت زیادہ جابز رکھنے کے لیے مؤثر طریقے سے استعمال کیا جاتا ہے۔ || څو-پروګرامي عملیاتي سیسټمونه په اصلي حافظه کې د شته ډېرو فعالو دندو په نوبتي چلولو سره له پروسېسر اغېزمنه ګټه اخلي. دا هڅه هم کوي چې CPU ته تل د چلولو لپاره څه وي او په دې ډول یې کارونه زیاته کړي. اصلي حافظه (RAM) په یو وخت د ډېرو دندو ساتلو لپاره په اغېزمن ډول کارول کېږي.
