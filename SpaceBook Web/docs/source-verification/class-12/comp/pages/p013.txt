p DOS operating system was developed in 1980 by Microsoft when, in July 1980, the IBM assigned a project to Microsoft for the development of a 16-bit operating system for their personal computer. Microsoft developed the first version of DOS for the personal computer and named it PC-DOS. After this, Microsoft developed a Microsoft version of the same PC-DOS operating system and named it MS-DOS. Both PC-DOS and MS-DOS are almost similar and now users refer them with only DOS. || DOS آپریٹنگ سسٹم 1980ء میں مائیکروسافٹ نے اس وقت تیار کیا جب جولائی 1980ء میں IBM نے اپنے ذاتی کمپیوٹر کے لیے 16-بٹ آپریٹنگ سسٹم کی تیاری کا منصوبہ مائیکروسافٹ کو سونپا۔ مائیکروسافٹ نے ذاتی کمپیوٹر کے لیے DOS کا پہلا ورژن تیار کیا اور اس کا نام PC-DOS رکھا۔ اس کے بعد مائیکروسافٹ نے اسی PC-DOS آپریٹنگ سسٹم کا مائیکروسافٹ ورژن تیار کیا اور اس کا نام MS-DOS رکھا۔ PC-DOS اور MS-DOS دونوں تقریباً یکساں ہیں اور اب صارفین انھیں صرف DOS کہتے ہیں۔ || DOS عملیاتي سیسټم په ۱۹۸۰ز کې مایکروسافټ هغه وخت جوړ کړ چې د ۱۹۸۰ز په جولای کې IBM مایکروسافټ ته د خپل شخصي کمپیوټر لپاره د ۱۶-بټه عملیاتي سیسټم د جوړولو پروژه وسپارله. مایکروسافټ د شخصي کمپیوټر لپاره د DOS لومړۍ نسخه جوړه کړه او PC-DOS یې ونوماوه. له دې وروسته مایکروسافټ د همدې PC-DOS عملیاتي سیسټم د مایکروسافټ نسخه جوړه کړه او MS-DOS یې ونوماوه. PC-DOS او MS-DOS دواړه نږدې یو شان دي او اوس کاروونکي یې یوازې DOS بولي.
