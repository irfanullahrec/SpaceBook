## 5.3 Strings || 5.3 اسٹرنگز || ۵.۳ تارونه
## 5.3.1 What is String? || 5.3.1 اسٹرنگ کیا ہے؟ || ۵.۳.۱ تار څه دی؟
p The sequence of characters enclosed in quotation marks and is used to handle non-numeric data i.e. names, addresses etc. are called strings. || واوین میں بند حروف کی ترتیب جو غیر عددی ڈیٹا یعنی نام، پتے وغیرہ سنبھالنے کے لیے استعمال ہوتی ہے، اسٹرنگز کہلاتی ہے۔ || په نقل‌قولونو کې تړلې د تورو لړۍ چې د غیر عددي ډېټا یعنې نومونو، پتو او نورو د چلولو لپاره کارېږي، تارونه (strings) بلل کېږي.
## 5.3.2 Defining a C String || 5.3.2 C اسٹرنگ کی تعریف || ۵.۳.۲ د C تار تعریف
p General syntax for defining string in C is given below: || C میں اسٹرنگ کی تعریف کا عمومی طریقۂ تحریر ذیل میں دیا گیا ہے: || په C کې د تار د تعریف عمومي بڼه لاندې ورکړل شوې:
p data type name_of_string [size of string]; || data type name_of_string [size of string]; || data type name_of_string [size of string];
p In the above general syntax, data type, is char data type and name_of_string is the name of the string. The size (number of characters) of the string is specified in square brackets, [ ]. The following statement defines a string with the name str having size 20. || اوپر کے عمومی طریقۂ تحریر میں data type، char ڈیٹا ٹائپ ہے اور name_of_string اسٹرنگ کا نام ہے۔ اسٹرنگ کا سائز (حروف کی تعداد) مربع بریکٹس [ ] میں بتایا جاتا ہے۔ درج ذیل بیان str نام کی 20 سائز والی اسٹرنگ کی تعریف کرتا ہے۔ || په پورته عمومي بڼه کې data type د char ډېټا ډول دی او name_of_string د تار نوم دی. د تار اندازه (د تورو شمېر) په مربع قوسونو [ ] کې ښودل کېږي. لاندې بیان د str په نوم د ۲۰ اندازې تار تعریفوي.
p char str [20]; || char str [20]; || char str [20];
p For handling strings, the header file <cstring> is needed but in some implementations this library may be automatically included when the header file <iostream> is included. There are some limitations of strings in C. To overcome and remove these problems, C++ provides a class <string> that removes many of these problems. This class provides some typical string operations like comparison, concatenation, find and replace, and a function for obtaining substrings. The general syntax for defining strings in C++ is given below: || اسٹرنگز سنبھالنے کے لیے ہیڈر فائل <cstring> درکار ہے لیکن بعض نفاذ میں یہ لائبریری ہیڈر فائل <iostream> شامل کرنے پر خود بخود شامل ہو سکتی ہے۔ C میں اسٹرنگز کی کچھ حدود ہیں۔ ان مسائل پر قابو پانے اور انھیں دور کرنے کے لیے C++ ایک کلاس <string> فراہم کرتی ہے جو ان میں سے بہت سے مسائل دور کرتی ہے۔ یہ کلاس کچھ عام اسٹرنگ آپریشنز جیسے موازنہ، جوڑنا، تلاش اور تبدیلی، اور ذیلی اسٹرنگز حاصل کرنے کا فنکشن فراہم کرتی ہے۔ C++ میں اسٹرنگز کی تعریف کا عمومی طریقۂ تحریر ذیل میں ہے: || د تارونو د چلولو لپاره د <cstring> سرپاڼه دوتنې ته اړتیا ده، خو په ځینو پلیو کې دا کتابتون د <iostream> سرپاڼه دوتنې په شاملولو پخپله شامل کېدای شي. په C کې د تارونو ځینې محدودیتونه دي. د دې ستونزو د لرې کولو لپاره C++ د <string> ټولګی برابروي چې ډېرې دا ستونزې لرې کوي. دا ټولګی ځینې عادي د تار عملیې لکه پرتله، نښلول، موندل او بدلول، او د فرعي تارونو د ترلاسه کولو فنکشن برابروي. په C++ کې د تارونو د تعریف عمومي بڼه لاندې ده:
p string str; || string str; || string str;
p This statement defines a string name str of type string. || یہ بیان string قسم کی str نام کی اسٹرنگ کی تعریف کرتا ہے۔ || دا بیان د string ډول د str په نوم تار تعریفوي.
