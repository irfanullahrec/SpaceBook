p The actual parameters can be fixed values or variables holding values or expressions resulting in some values. || اصل پیرامیٹرز مقررہ قدریں، قدریں رکھنے والے ویری ایبلز یا کسی قدر پر منتج ہونے والے ایکسپریشنز ہو سکتے ہیں۔ || اصلي پاراميټرونه کېدای شي ټاکلي ارزښتونه، ارزښت لرونکي متغیرونه یا داسې افادې وي چې یو ارزښت ورکوي.
p In the function main, in the following example, rice, chicken and fruit are actual parameters when used to call calculate_bill. On the other hand, the corresponding variables in calculate_bill (namely diner1, diner2 and diner3, respectively) are formal parameters because they appear in the function definition and receive values passed in the function call. || درج ذیل مثال میں فنکشن main میں rice، chicken اور fruit اصل پیرامیٹرز ہیں جب انھیں calculate_bill کال کرنے کے لیے استعمال کیا جائے۔ دوسری طرف calculate_bill میں متعلقہ ویری ایبلز (یعنی بالترتیب diner1، diner2 اور diner3) رسمی پیرامیٹرز ہیں کیونکہ یہ فنکشن کی تعریف میں آتے ہیں اور فنکشن کال میں پاس کی گئی قدریں وصول کرتے ہیں۔ || په لاندې بېلګه کې د main په فنکشن کې rice، chicken او fruit اصلي پاراميټرونه دي کله چې د calculate_bill د غوښتلو لپاره وکارول شي. له بلې خوا په calculate_bill کې اړوند متغیرونه (یعنې په ترتیب سره diner1، diner2 او diner3) رسمي پاراميټرونه دي ځکه د فنکشن په تعریف کې راځي او د فنکشن په غوښتنه کې لېږدول شوي ارزښتونه ترلاسه کوي.
