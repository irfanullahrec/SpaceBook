p 1. Initialization: Generally it is an initial value setting for a counter variable. This is executed only once. || 1۔ ابتدائی قدر: عموماً یہ کاؤنٹر ویری ایبل کی ابتدائی قدر مقرر کرنا ہے۔ یہ صرف ایک بار چلتا ہے۔ || ۱. لومړنی ارزښت: عموماً دا د شمېرونکي متغیر لومړنی ارزښت ټاکل دي. دا یوازې یو ځل اجرا کېږي.
p 2. Condition: If it is true the loop continues, otherwise the loop ends and statement is skipped (not executed). || 2۔ شرط: اگر یہ درست ہو تو لوپ جاری رہتا ہے، ورنہ لوپ ختم ہو جاتا ہے اور بیان چھوڑ دیا جاتا ہے (نہیں چلتا)۔ || ۲. شرط: که true وي حلقه دوام کوي، که نه حلقه پای ته رسېږي او بیان پرېښودل کېږي (نه اجرا کېږي).
p 3. Loop Body: It can either be a single statement or a block enclosed in braces { }, for multiple statements. || 3۔ لوپ کا جسم: یہ ایک بیان یا متعدد بیانات کے لیے بریسز { } میں بند بلاک ہو سکتا ہے۔ || ۳. د حلقې بدنه: کېدای شي یو بیان یا د ډېرو بیانونو لپاره په لوړو قوسونو { } کې تړلی بلاک وي.
p 4. Finally, the loop counter is incremented/decremented and control goes back to step2. || 4۔ آخر میں لوپ کاؤنٹر میں اضافہ/کمی ہوتی ہے اور کنٹرول مرحلہ 2 پر واپس جاتا ہے۔ || ۴. په پای کې د حلقې شمېرونکی زیاتېږي/کمېږي او کنټرول دویم ګام ته ستنېږي.
