## 1.2 OPERATING SYSTEM FUNCTIONS || 1.2 آپریٹنگ سسٹم کے افعال || ۱.۲ د عملیاتي سیسټم دندې
p As operating system is the main controller of a computer system, therefore, it provides a variety of services and functions to the computer and its users which are listed below: || چونکہ آپریٹنگ سسٹم کمپیوٹر سسٹم کا مرکزی کنٹرولر ہے، اس لیے یہ کمپیوٹر اور اس کے صارفین کو مختلف خدمات اور افعال فراہم کرتا ہے جو درج ذیل ہیں: || څرنګه چې عملیاتي سیسټم د کمپیوټري سیسټم اصلي کنټرولوونکی دی، نو کمپیوټر او د هغه کاروونکو ته بېلابېل خدمتونه او دندې برابروي چې لاندې لیکل شوي:
- Process Management || پراسیس مینجمنٹ || د پروسې اداره
- Memory Management || میموری مینجمنٹ || د حافظې اداره
- File Management || فائل مینجمنٹ || د فایلونو اداره
- Input/output System Management || ان پٹ/آؤٹ پٹ سسٹم مینجمنٹ || د ننوتو/وتو د سیسټم اداره
- Secondary Storage Management || ثانوی اسٹوریج مینجمنٹ || د ثانوي زېرمې اداره
- Network Management || نیٹ ورک مینجمنٹ || د شبکې اداره
- Protection System || حفاظتی نظام || د ساتنې سیسټم
- Command-interpreter || کمانڈ انٹرپریٹر || د امرونو ژباړونکی
## Process management || پراسیس مینجمنٹ || د پروسې اداره
p A program under execution is called process. Early computer systems were able to run only one process on a single processor, but, now the concepts of multitasking and multiprogramming have enabled computers to run multiple programs on a single processor. Process management is that function of operating system in which it deals with running multiple processes on a single computer. Since, most of the computer systems contain one processor with one core, multitasking is done by simply switching processes quickly. If there are more processes to run on a processor, then the operating system decides whether to shorten the time slice for each process or to make the processes wait long for their next turns of execution. || زیرِ عمل پروگرام کو پراسیس کہتے ہیں۔ ابتدائی کمپیوٹر سسٹم ایک پروسیسر پر صرف ایک پراسیس چلا سکتے تھے، لیکن اب ملٹی ٹاسکنگ اور ملٹی پروگرامنگ کے تصورات نے کمپیوٹرز کو ایک پروسیسر پر متعدد پروگرام چلانے کے قابل بنا دیا ہے۔ پراسیس مینجمنٹ آپریٹنگ سسٹم کا وہ فعل ہے جس میں وہ ایک کمپیوٹر پر متعدد پراسیسز کو چلانے سے نمٹتا ہے۔ چونکہ زیادہ تر کمپیوٹر سسٹمز میں ایک کور والا ایک پروسیسر ہوتا ہے، اس لیے ملٹی ٹاسکنگ صرف پراسیسز کو تیزی سے بدل کر کی جاتی ہے۔ اگر پروسیسر پر چلانے کے لیے زیادہ پراسیسز ہوں تو آپریٹنگ سسٹم فیصلہ کرتا ہے کہ ہر پراسیس کا وقتی حصہ کم کرے یا پراسیسز کو اپنی اگلی باری کا زیادہ دیر انتظار کرائے۔ || د اجرا لاندې پروګرام ته پروسه ویل کېږي. لومړني کمپیوټري سیسټمونه پر یوه پروسېسر یوازې یوه پروسه چلولی شوه، خو اوس د څو-دندیز او څو-پروګرامي کار مفهومونو کمپیوټرونه دې وړ کړي چې پر یوه پروسېسر ډېر پروګرامونه وچلوي. د پروسې اداره د عملیاتي سیسټم هغه دنده ده چې پکې پر یوه کمپیوټر د ډېرو پروسو له چلولو سره سروکار لري. څرنګه چې ډېری کمپیوټري سیسټمونه یو پروسېسر د یوه زړه (core) سره لري، څو-دندیز کار یوازې د پروسو په چټک بدلولو کېږي. که پر پروسېسر د چلولو لپاره ډېرې پروسې وي، نو عملیاتي سیسټم پرېکړه کوي چې د هرې پروسې د وخت برخه لنډه کړي یا پروسې د خپل راتلونکي نوبت لپاره اوږد انتظار ته پرېږدي.
## Memory management || میموری مینجمنٹ || د حافظې اداره
p Computer memory is a vital hardware resource of the computer system and it should be properly managed. It is grouped into Registers, CPU cache, Random Access Memory (RAM) and Disk Storage. A module of operating system called memory manager is responsible for the coordination of these types of memory by tracking which memory is || کمپیوٹر میموری کمپیوٹر سسٹم کا ایک اہم ہارڈویئر وسیلہ ہے اور اس کا مناسب انتظام ہونا چاہیے۔ اسے رجسٹرز، CPU کیش، رینڈم ایکسیس میموری (RAM) اور ڈسک اسٹوریج میں تقسیم کیا جاتا ہے۔ آپریٹنگ سسٹم کا ایک ماڈیول جسے میموری مینیجر کہتے ہیں، ان اقسام کی میموری کی ہم آہنگی کا ذمہ دار ہے اور یہ ریکارڈ رکھتا ہے کہ کون سی میموری || کمپیوټري حافظه د کمپیوټري سیسټم یوه حیاتي هارډویري سرچینه ده او باید په سم ډول اداره شي. په ثبتونکو (Registers)، د CPU کیش، تصادفي لاسرسي حافظه (RAM) او ډیسکي زېرمه ډلبندي کېږي. د عملیاتي سیسټم یوه ماډیول چې د حافظې مدیر بلل کېږي، د دې ډولونو حافظې د همغږۍ مسؤول دی او څاري چې کومه حافظه
