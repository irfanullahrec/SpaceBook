## c. Return type || c. ریٹرن ٹائپ || c. د بېرته ورکړې ډول
p The return type of a function is not considered when functions are overloaded. It means that if two or more functions with the same name have same function signatures but different return types then they are not considered as overloaded and the compiler will generate error message. || فنکشنز اوورلوڈ کرتے وقت فنکشن کی ریٹرن ٹائپ پر غور نہیں کیا جاتا۔ اس کا مطلب ہے کہ اگر ایک ہی نام کے دو یا زیادہ فنکشنز کے فنکشن سگنیچر ایک جیسے لیکن ریٹرن ٹائپس مختلف ہوں تو انھیں اوورلوڈ نہیں سمجھا جاتا اور کمپائلر خرابی کا پیغام دے گا۔ || کله چې فنکشنونه ډېرېږي، د فنکشن د بېرته ورکړې ډول ته پام نه کېږي. معنا دا چې که د یو نوم دوه یا ډېر فنکشنونه ورته لاسلیکونه خو بېل د بېرته ورکړې ډولونه ولري، ډېر شوي نه ګڼل کېږي او کمپایلر به د تېروتنې پیغام ورکړي.
p Consider the following case: || درج ذیل صورت پر غور کریں: || لاندې حالت ته پام وکړئ:
p int display(); double display(); // This prototype generates error message || int display(); double display(); // This prototype generates error message || int display(); double display(); // This prototype generates error message
p Consider another example: || ایک اور مثال پر غور کریں: || بلې بېلګې ته پام وکړئ:
p int RandomNumber(); double RandomNumber(); // This prototype generates error message || int RandomNumber(); double RandomNumber(); // This prototype generates error message || int RandomNumber(); double RandomNumber(); // This prototype generates error message
p Here, the compiler generates an error message of re-declaration for the second declaration at line number 2. It is because that both the declarations have same number of parameters (zero in this case) but only the return types are different which do not play any role in the overloading. If we want to do it, for then, these functions will need to be given different names. || یہاں کمپائلر لائن نمبر 2 پر دوسری ڈکلیریشن کے لیے دوبارہ ڈکلیریشن کی خرابی کا پیغام دیتا ہے۔ اس کی وجہ یہ ہے کہ دونوں ڈکلیریشنز میں پیرامیٹرز کی تعداد ایک ہے (اس صورت میں صفر) لیکن صرف ریٹرن ٹائپس مختلف ہیں جو اوورلوڈنگ میں کوئی کردار ادا نہیں کرتیں۔ اگر ہم ایسا کرنا چاہیں تو ان فنکشنز کو مختلف نام دینے ہوں گے۔ || دلته کمپایلر په ۲ کرښه کې د دویم اعلان لپاره د بیا اعلان د تېروتنې پیغام ورکوي. لامل یې دا دی چې دواړه اعلانونه د پاراميټرونو یو شمېر لري (په دې حالت کې صفر) خو یوازې د بېرته ورکړې ډولونه بېل دي چې په ډېرولو کې هېڅ رول نه لري. که دا کار وغواړو، دې فنکشنونو ته به بېل نومونه ورکول اړین وي.
