## b. Object || b. آبجیکٹ || b. شی
p A variable of type class is called object. In C++, when we declare a variable of type class, we call it instantiating the class and the variable itself is called an instance or object of that class. Object is of great importance in OOP, because, a class cannot be used without creating its object. The general syntax for creating an object of a class is given below. || کلاس قسم کا ویری ایبل آبجیکٹ کہلاتا ہے۔ C++ میں جب ہم کلاس قسم کا ویری ایبل ڈکلیئر کرتے ہیں تو اسے کلاس کا انسٹینشی ایٹ کرنا کہتے ہیں اور خود ویری ایبل اس کلاس کا انسٹینس یا آبجیکٹ کہلاتا ہے۔ OOP میں آبجیکٹ کی بڑی اہمیت ہے کیونکہ کلاس کو اس کا آبجیکٹ بنائے بغیر استعمال نہیں کیا جا سکتا۔ کلاس کا آبجیکٹ بنانے کا عمومی طریقۂ تحریر ذیل میں دیا گیا ہے۔ || د ټولګي ډول متغیر شی (object) بلل کېږي. په C++ کې کله چې د ټولګي ډول متغیر اعلان کړو، دې ته د ټولګي نمونه‌جوړول وایو او پخپله متغیر د هغه ټولګي نمونه یا شی بلل کېږي. په OOP کې شی ډېر اهمیت لري ځکه ټولګی د خپل شي له جوړولو پرته نه شي کارېدای. د یوه ټولګي د شي د جوړولو عمومي بڼه لاندې ورکړل شوې.

p Here, R1, R2, R3 are the objects of the same class CRectangle that share the same data member and member functions. The definition of a class does not occupy any memory. When an object is created then memory is set aside for all the data members and member functions of that class. || یہاں R1، R2، R3 ایک ہی کلاس CRectangle کے آبجیکٹس ہیں جو ایک جیسے ڈیٹا ممبر اور ممبر فنکشنز رکھتے ہیں۔ کلاس کی تعریف کوئی میموری نہیں لیتی۔ یہ صرف بتاتی ہے کہ کلاس کیسی ہے۔ کلاس استعمال کرنے کے لیے اس کلاس قسم کا ویری ایبل ڈکلیئر کرنا ضروری ہے۔ جب آبجیکٹ بنتا ہے تو اس کلاس کے تمام ڈیٹا ممبرز اور ممبر فنکشنز کے لیے میموری مختص ہو جاتی ہے۔ || دلته R1، R2، R3 د یو ټولګي CRectangle شیان دي چې ورته د ډېټا غړی او غړي فنکشنونه شریکوي. د ټولګي تعریف هېڅ حافظه نه نیسي. یوازې ټاکي چې ټولګی څنګه ښکاري. د ټولګي د کارولو لپاره باید د هغه ټولګي ډول متغیر اعلان شي. کله چې شی جوړ شي، د هغه ټولګي د ټولو ډېټا غړو او غړو فنکشنونو لپاره حافظه ځانګړې کېږي.
