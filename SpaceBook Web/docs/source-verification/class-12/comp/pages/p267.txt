qp 6 | Q.9 What is object? How objects are created to access members of a class? || Q.9 آبجیکٹ کیا ہے؟ کلاس کے اراکین تک رسائی کے لیے آبجیکٹس کیسے بنائے جاتے ہیں؟ || Q.9 شی څه دی؟ د ټولګي غړو ته د لاسرسي لپاره شیان څنګه جوړېږي؟
solution جواب
ss An object is an instance of a class — a variable of the class type that has its own copy of the data members and can use the member functions. A class is a blueprint; objects are the real entities made from it.
ss Objects are created by declaring them with the class name: class_name object_name; e.g. Student s1, s2; Members are accessed with the dot (member access) operator: s1.getData(); s1.show(); (only public members can be accessed from outside the class; with a pointer the arrow operator is used: p->show();).
endsolution
qp 7 | Q.10 Explain inheritance and polymorphism with examples. || Q.10 وراثت اور پولی مورفزم کو مثالوں کے ساتھ واضح کریں۔ || Q.10 میراث او پولي‌مورفیزم د بېلګو سره تشریح کړئ.
solution جواب
ss Inheritance is the process of creating a new (derived) class from an existing (base) class; the derived class gets the members of the base class and can add its own, giving code reusability. Example: class Car : public Vehicle { … }; Car inherits speed and start() from Vehicle and adds airConditioner.
ss Polymorphism means 'many forms' — the same name behaves differently in different situations. Compile-time polymorphism: function overloading (area(int), area(int, int)) and operator overloading. Run-time polymorphism: virtual functions overridden in derived classes, e.g. Shape has virtual void draw(); Circle and Square each define draw() differently, and a Shape* calls the right one at run time.
endsolution
