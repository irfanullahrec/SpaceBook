## 5.1.2 Representation of array || 5.1.2 ایرے کی نمائندگی || ۵.۱.۲ د لړۍ ښودنه
p Array elements are stored in consecutive memory locations inside the computer memory. For example, if in the above array X we store the marks of seven students and the first element X[0] is stored at address 100, inside the computer memory, then X[1], X[2], X[3], X[4], X[5], X[6] will be stored at memory addresses 102,104,106, 108, 110, and 112 respectively. Here, the difference in the values of the memory addresses is two numbers because an int data type occupies 2 bytes of memory space. It is shown in figure 5.1. || ایرے کے عناصر کمپیوٹر میموری کے اندر لگاتار میموری مقامات پر محفوظ ہوتے ہیں۔ مثلاً اگر اوپر کے ایرے X میں ہم سات طلبہ کے نمبر محفوظ کریں اور پہلا عنصر X[0] کمپیوٹر میموری میں پتہ 100 پر محفوظ ہو تو X[1]، X[2]، X[3]، X[4]، X[5]، X[6] بالترتیب میموری پتوں 102، 104، 106، 108، 110 اور 112 پر محفوظ ہوں گے۔ یہاں میموری پتوں کی قدروں میں دو کا فرق ہے کیونکہ int ڈیٹا ٹائپ میموری میں 2 بائٹس جگہ لیتی ہے۔ یہ شکل 5.1 میں دکھایا گیا ہے۔ || د لړۍ عناصر د کمپیوټر د حافظې دننه په پرله‌پسې حافظه ځایونو کې ساتل کېږي. د بېلګې په توګه که په پورته لړۍ X کې د اوو زده‌کوونکو نمرې وساتو او لومړی عنصر X[0] د کمپیوټر په حافظه کې په 100 پته وساتل شي، نو X[1]، X[2]، X[3]، X[4]، X[5]، X[6] به په ترتیب سره په 102، 104، 106، 108، 110 او 112 پتو کې وساتل شي. دلته د حافظې د پتو په ارزښتونو کې دوه شمېرې توپیر دی ځکه int ډېټا ډول په حافظه کې ۲ بایټه ځای نیسي. دا په ۵.۱ شکل کې ښودل شوی.

## 5.1.3 Terminology used in Arrays || 5.1.3 ایریز میں استعمال ہونے والی اصطلاحات || ۵.۱.۳ په لړیو کې کارېدونکې اصطلاحګانې
p Arrays can be understood well by first knowing some commonly used terminologies such as name, size, and index. || ایریز کو پہلے کچھ عام اصطلاحات جیسے نام، سائز اور انڈیکس جان کر اچھی طرح سمجھا جا سکتا ہے۔ || لړۍ ښه پوهېدای شو که لومړی ځینې عام اصطلاحګانې لکه نوم، اندازه او شاخص وپېژنو.
