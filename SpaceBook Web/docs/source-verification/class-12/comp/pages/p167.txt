## 5.2.2 Definition and initialization of two dimensional arrays || 5.2.2 دو جہتی ایریز کی تعریف اور ابتدائی قدر || ۵.۲.۲ د دوه-بعدي لړیو تعریف او لومړنی ارزښت
p Like one-dimensional array, a two-dimensional array is defined and initialized before using it in a program. The following sections describe its definition and initialization with the help of examples. || یک جہتی ایرے کی طرح دو جہتی ایرے کی بھی پروگرام میں استعمال سے پہلے تعریف اور ابتدائی قدر دی جاتی ہے۔ درج ذیل حصے مثالوں کی مدد سے اس کی تعریف اور ابتدائی قدر بیان کرتے ہیں۔ || د یو-بعدي لړۍ په څېر دوه-بعدي لړۍ هم په پروګرام کې له کارولو مخکې تعریفېږي او لومړنی ارزښت ورکول کېږي. لاندې برخې د بېلګو په مرسته د هغې تعریف او لومړنی ارزښت بیانوي.

p The general syntax for the declaration of two dimensional arrays is given below. || دو جہتی ایریز کی ڈکلیریشن کا عمومی طریقۂ تحریر ذیل میں دیا گیا ہے۔ || د دوه-بعدي لړیو د اعلان عمومي بڼه لاندې ورکړل شوې.
p Data Type Array name [row index] [column index]; || Data Type Array name [row index] [column index]; || Data Type Array name [row index] [column index];
p In the above syntax, the data type is any valid data type, such as int, float, long etc., which is followed by array name and two indices. The first index is for number of rows and the second index is for number of columns in the array. || اوپر کے طریقۂ تحریر میں data type کوئی بھی درست ڈیٹا ٹائپ ہے، جیسے int، float، long وغیرہ، جس کے بعد ایرے کا نام اور دو انڈیسز آتے ہیں۔ پہلا انڈیکس قطاروں کی تعداد اور دوسرا انڈیکس ایرے میں کالموں کی تعداد کے لیے ہے۔ || په پورته بڼه کې data type هر سم ډېټا ډول دی، لکه int، float، long او نور، چې وروسته یې د لړۍ نوم او دوه شاخصونه راځي. لومړی شاخص د قطارونو شمېر او دویم شاخص په لړۍ کې د ستنو شمېر لپاره دی.
