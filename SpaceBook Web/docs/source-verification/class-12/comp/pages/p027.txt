## File management || فائل مینجمنٹ || د فایلونو اداره
p The data is stored in computer memory in files which are further arranged and organized in sub directories and root directory resulting in a hierarchical file system. A module of operating system that organizes and keeps track of all the files in computers is called file manager and the process of managing these files is called file management. For example, a hierarchical file system, shown in figure 1.7 and 1.8 depict that how files are arranged into root directory and sub-directories. This hierarchical file system is also called files system. || ڈیٹا کمپیوٹر میموری میں فائلوں میں محفوظ کیا جاتا ہے جنھیں مزید ذیلی ڈائریکٹریز اور روٹ ڈائریکٹری میں ترتیب اور منظم کیا جاتا ہے، جس سے درجہ وار فائل سسٹم بنتا ہے۔ آپریٹنگ سسٹم کا وہ ماڈیول جو کمپیوٹر میں تمام فائلوں کو منظم کرتا اور ان کا ریکارڈ رکھتا ہے فائل مینیجر کہلاتا ہے اور ان فائلوں کے انتظام کے عمل کو فائل مینجمنٹ کہتے ہیں۔ مثال کے طور پر شکل 1.7 اور 1.8 میں دکھایا گیا درجہ وار فائل سسٹم ظاہر کرتا ہے کہ فائلیں روٹ ڈائریکٹری اور ذیلی ڈائریکٹریز میں کیسے ترتیب دی جاتی ہیں۔ اس درجہ وار فائل سسٹم کو فائلز سسٹم بھی کہتے ہیں۔ || ډېټا د کمپیوټر په حافظه کې په فایلونو کې ساتل کېږي چې بیا په فرعي لارښودونو او ریښه لارښود کې ترتیب او تنظیمېږي، چې پایله یې درجه‌ییز فایل سیسټم دی. د عملیاتي سیسټم هغه ماډیول چې په کمپیوټرونو کې ټول فایلونه تنظیموي او ریکارډ یې ساتي، د فایل مدیر بلل کېږي او د دې فایلونو د ادارې بهیر ته د فایلونو اداره ویل کېږي. د بېلګې په توګه په ۱.۷ او ۱.۸ شکلونو کې ښودل شوی درجه‌ییز فایل سیسټم ښيي چې فایلونه څنګه په ریښه لارښود او فرعي لارښودونو کې ترتیبېږي. دې درجه‌ییز فایل سیسټم ته د فایلونو سیسټم هم ویل کېږي.
