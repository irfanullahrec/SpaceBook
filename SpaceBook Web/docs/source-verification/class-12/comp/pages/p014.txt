## b. Windows || b. ونڈوز || b. وینډوز
p Windows operating systems are the most commonly used operating systems that are based on Graphical User Interfaces (GUI). || ونڈوز آپریٹنگ سسٹم سب سے زیادہ استعمال ہونے والے آپریٹنگ سسٹم ہیں جو گرافیکل یوزر انٹرفیس (GUI) پر مبنی ہیں۔ || وینډوز عملیاتي سیسټمونه تر ټولو ډېر کارېدونکي عملیاتي سیسټمونه دي چې پر ګرافیکي کاروونکي منځګړي (GUI) ولاړ دي.
## i. Brief history of windows operating system || i. ونڈوز آپریٹنگ سسٹم کی مختصر تاریخ || i. د وینډوز عملیاتي سیسټم لنډ تاریخ
p The history of windows operating system goes back to 1983. The first windows operating system “Windows 1.0” was launched on November 20, 1985. The graphical support with desktop icons was introduced in “windows 2.0” that was launched on December 9, 1987. On August 24, 1995, “windows 95” was launched. Windows 98, XP and Vista were released on June 25, 1998, October 25, 2001 and 2006 respectively. In October 2009 windows 7 was released and Windows 8 was released on October 2012. || ونڈوز آپریٹنگ سسٹم کی تاریخ 1983ء تک جاتی ہے۔ پہلا ونڈوز آپریٹنگ سسٹم ’’Windows 1.0‘‘ 20 نومبر 1985ء کو جاری ہوا۔ ڈیسک ٹاپ آئیکنز کے ساتھ گرافیکل معاونت ’’windows 2.0‘‘ میں متعارف ہوئی جو 9 دسمبر 1987ء کو جاری ہوا۔ 24 اگست 1995ء کو ’’windows 95‘‘ جاری ہوا۔ Windows 98، XP اور Vista بالترتیب 25 جون 1998ء، 25 اکتوبر 2001ء اور 2006ء میں جاری ہوئے۔ اکتوبر 2009ء میں windows 7 اور اکتوبر 2012ء میں Windows 8 جاری ہوا۔ || د وینډوز عملیاتي سیسټم تاریخ ۱۹۸۳ز ته رسېږي. لومړنی وینډوز عملیاتي سیسټم "Windows 1.0" د ۱۹۸۵ز د نومبر په ۲۰مه خپور شو. د ډیسکټاپ نښو سره ګرافیکي ملاتړ په "windows 2.0" کې معرفي شو چې د ۱۹۸۷ز د ډسمبر په ۹مه خپور شو. د ۱۹۹۵ز د اګست په ۲۴مه "windows 95" خپور شو. Windows 98، XP او Vista په ترتیب سره د ۱۹۹۸ز د جون په ۲۵مه، د ۲۰۰۱ز د اکتوبر په ۲۵مه او په ۲۰۰۶ز کې خپاره شول. د ۲۰۰۹ز په اکتوبر کې windows 7 او د ۲۰۱۲ز په اکتوبر کې Windows 8 خپور شو.
## ii. Features of windows operating system || ii. ونڈوز آپریٹنگ سسٹم کی خصوصیات || ii. د وینډوز عملیاتي سیسټم ځانګړنې
- Windows operating system has improved graphical user interface that can be easily used by every type of user. || ونڈوز آپریٹنگ سسٹم کا گرافیکل یوزر انٹرفیس بہتر ہے جسے ہر قسم کا صارف آسانی سے استعمال کر سکتا ہے۔ || د وینډوز عملیاتي سیسټم ښه شوی ګرافیکي کاروونکي منځګړی لري چې هر ډول کاروونکی یې په اسانۍ کارولی شي.
- Windows operating systems are user friendly. || ونڈوز آپریٹنگ سسٹم صارف دوست ہیں۔ || وینډوز عملیاتي سیسټمونه کاروونکي-دوست دي.
- These are the best operating systems running on PCs. || یہ ذاتی کمپیوٹرز پر چلنے والے بہترین آپریٹنگ سسٹم ہیں۔ || دا په شخصي کمپیوټرونو چلېدونکي تر ټولو ښه عملیاتي سیسټمونه دي.
- Windows series of operating systems are not very expensive for home users. || ونڈوز کے آپریٹنگ سسٹم گھریلو صارفین کے لیے زیادہ مہنگے نہیں ہیں۔ || د وینډوز لړۍ عملیاتي سیسټمونه د کور کاروونکو لپاره ډېر ګران نه دي.
- Windows operating systems are supported by most of the software. || زیادہ تر سافٹ ویئر ونڈوز آپریٹنگ سسٹم کو سپورٹ کرتے ہیں۔ || ډېری سافټویرونه د وینډوز عملیاتي سیسټمونو ملاتړ کوي.
