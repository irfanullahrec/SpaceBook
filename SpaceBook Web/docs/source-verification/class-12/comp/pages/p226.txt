## 7.1.3 Reference operator & || 7.1.3 حوالہ آپریٹر & || ۷.۱.۳ د حوالې چلونکی &
p As pointers are the variables which hold the addresses of other variables, therefore, while assigning addresses to them, a programmer needs a special type of operator called address-of operator that is denoted by ampersand & symbol. This provides address of a memory location. || چونکہ پوائنٹرز وہ ویری ایبلز ہیں جو دوسرے ویری ایبلز کے پتے رکھتے ہیں، اس لیے انھیں پتے دیتے وقت پروگرامر کو ایک خاص قسم کے آپریٹر کی ضرورت ہوتی ہے جسے address-of آپریٹر کہتے ہیں اور جو ایمپرسینڈ & نشان سے ظاہر ہوتا ہے۔ یہ میموری مقام کا پتہ فراہم کرتا ہے۔ || څرنګه چې پوائنټرونه هغه متغیرونه دي چې د نورو متغیرونو پتې ساتي، نو هغوی ته د پتو ورکولو پر مهال پروګرام جوړوونکی یو ځانګړي چلونکي ته اړتیا لري چې address-of چلونکی بلل کېږي او د امپرسنډ & نښې ښودل کېږي. دا د حافظې د یوه ځای پته ورکوي.
p To understand it, consider the following segment of code. || اسے سمجھنے کے لیے کوڈ کے درج ذیل حصے پر غور کریں۔ || د دې د پوهېدو لپاره د کوډ لاندې برخې ته پام وکړئ.

p In this pictorial representation, the variable x has a float value 5.5 that is stored at location 1000. The pointer variable fPointer points to the variable x by holding its address 1000 as its value. In this case, if we want to print the value of the variable x it will display 5.5 but if we print the value of fPointer it will display 1000. || اس تصویری نمائندگی میں ویری ایبل x کی float قدر 5.5 ہے جو مقام 1000 پر محفوظ ہے۔ پوائنٹر ویری ایبل fPointer اپنی قدر کے طور پر x کا پتہ 1000 رکھ کر ویری ایبل x کی طرف اشارہ کرتا ہے۔ اس صورت میں اگر ہم ویری ایبل x کی قدر پرنٹ کریں تو 5.5 دکھائے گا لیکن اگر fPointer کی قدر پرنٹ کریں تو 1000 دکھائے گا۔ || په دې انځوریزه ښودنه کې x متغیر د float ارزښت 5.5 لري چې په 1000 ځای کې ساتل شوی. د پوائنټر متغیر fPointer د خپل ارزښت په توګه د x پته 1000 ساتي او x متغیر ته اشاره کوي. په دې حالت کې که د x متغیر ارزښت چاپ کړو 5.5 به ښيي، خو که د fPointer ارزښت چاپ کړو 1000 به ښيي.
