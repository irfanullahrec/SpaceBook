## b. Global functions || b. عالمی فنکشنز || b. نړیوال فنکشنونه
p A function declared outside any function is called global function. A global function can be accessed from any part of the program. Normally, user-defined functions are considered as global function if they are defined before the main () function and are thus accessible to every part of the program. || کسی بھی فنکشن کے باہر ڈکلیئر کیا گیا فنکشن عالمی فنکشن کہلاتا ہے۔ عالمی فنکشن تک پروگرام کے کسی بھی حصے سے رسائی ہو سکتی ہے۔ عموماً یوزر ڈیفائنڈ فنکشنز عالمی فنکشن سمجھے جاتے ہیں اگر وہ main () فنکشن سے پہلے بیان کیے گئے ہوں اور یوں پروگرام کے ہر حصے کے لیے قابلِ رسائی ہوتے ہیں۔ || هغه فنکشن چې له هر فنکشن بهر اعلان شي، نړیوال فنکشن بلل کېږي. نړیوال فنکشن ته د پروګرام له هرې برخې لاسرسی کېدای شي. عموماً د کاروونکي-تعریف شوي فنکشنونه نړیوال ګڼل کېږي که د main () فنکشن مخکې تعریف شوي وي او په دې توګه د پروګرام هرې برخې ته د لاسرسي وړ وي.
## 6.1.8 inline function || 6.1.8 inline فنکشن || ۶.۱.۸ inline فنکشن
p Using function calls in program, a lot of time is wasted in passing control from the calling function to the called function and returning control back to the calling function. This limitation can be overcome by the use of inline function. || پروگرام میں فنکشن کالز استعمال کرنے سے کال کرنے والے فنکشن سے کال کیے گئے فنکشن تک کنٹرول منتقل کرنے اور کنٹرول کو واپس کال کرنے والے فنکشن تک لانے میں کافی وقت ضائع ہوتا ہے۔ اس حد پر inline فنکشن کے استعمال سے قابو پایا جا سکتا ہے۔ || په پروګرام کې د فنکشن غوښتنو په کارولو، له غوښتونکي فنکشن څخه غوښتل شوي فنکشن ته د کنټرول په لېږدولو او بېرته غوښتونکي فنکشن ته د کنټرول په راګرځولو کې ډېر وخت ضایع کېږي. دا محدودیت د inline فنکشن په کارولو لرې کېدای شي.
p C++ offers a way to combine the advantages of functions with the speed of code written in-place with the help of inline functions. In inline function, the function return type is preceded by the inline keyword which requests the compiler to treat the function as an inline and do not jump again and again to the called function. In the case of inline function, when the compiler compiles the code, all inline functions are expanded in-place, that is, the function call is replaced with a copy of the code of the function itself, which removes the function call overhead. || C++ inline فنکشنز کی مدد سے فنکشنز کے فوائد کو اپنی جگہ لکھے گئے کوڈ کی رفتار کے ساتھ ملانے کا طریقہ فراہم کرتی ہے۔ inline فنکشن میں فنکشن کی ریٹرن ٹائپ سے پہلے inline کلیدی لفظ آتا ہے جو کمپائلر سے درخواست کرتا ہے کہ فنکشن کو inline سمجھے اور بار بار کال کیے گئے فنکشن پر نہ جائے۔ inline فنکشن کی صورت میں جب کمپائلر کوڈ کمپائل کرتا ہے تو تمام inline فنکشنز اپنی جگہ پھیلا دیے جاتے ہیں، یعنی فنکشن کال کو خود فنکشن کے کوڈ کی نقل سے بدل دیا جاتا ہے، جس سے فنکشن کال کا اضافی بوجھ ختم ہو جاتا ہے۔ || C++ د inline فنکشنونو په مرسته لاره برابروي چې د فنکشنونو ګټې په ځای لیکل شوي کوډ له سرعت سره یوځای کړي. په inline فنکشن کې د فنکشن د بېرته ورکړې ډول ته inline کلیدي کلمه مخکې لیکل کېږي چې له کمپایلر غوښتنه کوي فنکشن inline وګڼي او بیا بیا غوښتل شوي فنکشن ته ټوپ ونه وهي. د inline فنکشن په حالت کې کله چې کمپایلر کوډ کمپایل کړي، ټول inline فنکشنونه په ځای پراخېږي، یعنې د فنکشن غوښتنه د فنکشن د کوډ په کاپي بدلېږي، چې د فنکشن غوښتنې اضافي بار لرې کوي.
p The disadvantage of the inline function is that it can make the compiled code quite larger, especially if the inline function is long and/or there are many calls to the inline function. || inline فنکشن کا نقصان یہ ہے کہ یہ کمپائل شدہ کوڈ کو کافی بڑا کر سکتا ہے، خاص طور پر اگر inline فنکشن لمبا ہو اور/یا inline فنکشن کو بہت سی کالز ہوں۔ || د inline فنکشن زیان دا دی چې کمپایل شوی کوډ ډېر لویولی شي، په ځانګړي ډول که inline فنکشن اوږد وي او/یا inline فنکشن ته ډېرې غوښتنې وي.
