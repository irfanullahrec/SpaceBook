## Glossary || فرہنگ || وییپانګه
## A || A || A
p Actual parameters: Actual parameters are those parameters which appear in function calls. || Actual parameters: اصل پیرامیٹرز وہ پیرامیٹرز ہیں جو فنکشن کالز میں آتے ہیں۔ || Actual parameters: اصلي پاراميټرونه هغه پاراميټرونه دي چې د فنکشن په غوښتنو کې راځي.
p Address: A memory location within computer that is used to store value. || Address: کمپیوٹر کے اندر میموری کا وہ مقام جو قدر محفوظ کرنے کے لیے استعمال ہوتا ہے۔ || Address: د کمپیوټر دننه د حافظې هغه ځای چې د ارزښت د ساتلو لپاره کارېږي.
p Algorithm: A finite set of well-defined rules for the solution of a problem in a finite number of steps. || Algorithm: محدود مراحل میں کسی مسئلے کے حل کے لیے واضح قواعد کا محدود مجموعہ۔ || Algorithm: په محدودو ګامونو کې د یوې ستونزې د حل لپاره د ښه تعریف شویو قواعدو محدوده ټولګه.
p Allocate: To assign a resource to a process for performing a specific task. || Allocate: کسی مخصوص کام کی انجام دہی کے لیے کسی پروسیس کو وسیلہ تفویض کرنا۔ || Allocate: د یوې ځانګړې دندې د ترسره کولو لپاره یوې پروسې ته سرچینه ورکول.
p Alphanumeric: A character set that contains letters, digits, and usually other characters such as punctuation marks. || Alphanumeric: حروف کا ایسا مجموعہ جس میں حروفِ تہجی، ہندسے اور عموماً دوسرے حروف جیسے رموزِ اوقاف شامل ہوں۔ || Alphanumeric: د تورو هغه ټولګه چې توري، عددي رقمونه او عموماً نور توري لکه د تنقیط نښې لري.
p Analysis phase: In this phase, the in-charge of the project team must decide if the project should go ahead with the available resources or not. || Analysis phase: اس مرحلے میں پروجیکٹ ٹیم کے انچارج کو فیصلہ کرنا ہوتا ہے کہ پروجیکٹ دستیاب وسائل کے ساتھ آگے بڑھے یا نہیں۔ || Analysis phase: په دې پړاو کې د پروژې د ټیم مسؤل باید پرېکړه وکړي چې پروژه د شته سرچینو سره مخکې ولاړه شي که نه.
p Analyst: Analyst is a profession al in the field of software development that studies the problems, plans solutions for them, recommends software systems, and coordinates development to meet business or other requirements. || Analyst: تجزیہ کار سافٹ ویئر ڈیولپمنٹ کے شعبے کا ماہر ہے جو مسائل کا مطالعہ کرتا ہے، ان کے حل کی منصوبہ بندی کرتا ہے، سافٹ ویئر سسٹمز تجویز کرتا ہے اور کاروباری یا دیگر ضروریات پوری کرنے کے لیے ڈیولپمنٹ کو مربوط کرتا ہے۔ || Analyst: شنونکی د سافټویر پراختیا په برخه کې هغه مسلکي کس دی چې ستونزې څېړي، د حل پلان یې جوړوي، سافټویري سیسټمونه وړاندیز کوي او د سوداګریزو یا نورو اړتیاوو د پوره کولو لپاره پراختیا همغږې کوي.
p Argument: A value passed to a function from the calling program, “main()” function. || Argument: کال کرنے والے پروگرام، ’’main()‘‘ فنکشن، سے کسی فنکشن کو پاس کی گئی قدر۔ || Argument: هغه ارزښت چې له غوښتونکي پروګرام، "main()" فنکشن، څخه یوه فنکشن ته لېږدول کېږي.
p Argument passing: The process of passing values to the formal parameters mentioned in the function declator. || Argument passing: فنکشن ڈکلیریٹر میں درج رسمی پیرامیٹرز کو قدریں پاس کرنے کا عمل۔ || Argument passing: د فنکشن په اعلانوونکي کې یادو رسمي پاراميټرونو ته د ارزښتونو د لېږدولو بهیر.
p Array: An n-dimensional ordered set of data items identified by a single name and one or more indices, so that each element of the set is individually addressable; e.g., a matrix, or table. || Array: ڈیٹا آئٹمز کا n جہتی مرتب مجموعہ جس کی شناخت ایک نام اور ایک یا زیادہ انڈیسز سے ہوتی ہے تاکہ مجموعے کے ہر عنصر تک الگ رسائی ہو سکے؛ مثلاً میٹرکس یا جدول۔ || Array: د ډېټا توکو n-بعدي ترتیب شوې ټولګه چې په یوه نوم او یوه یا ډېرو شاخصونو پېژندل کېږي ترڅو د ټولګې هر عنصر ته جلا لاسرسی وشي؛ لکه ماتریکس یا جدول.
p Assignment operator: The operator denoted by the symbol (=) which is used to assign values to variables. || Assignment operator: نشان (=) سے ظاہر ہونے والا آپریٹر جو ویری ایبلز کو قدریں دینے کے لیے استعمال ہوتا ہے۔ || Assignment operator: هغه چلونکی چې په (=) نښه ښودل کېږي او متغیرونو ته د ارزښتونو ورکولو لپاره کارېږي.
p Auxiliary storage: Storage devices other than main memory e.g., disks and tapes. || Auxiliary storage: مرکزی میموری کے علاوہ اسٹوریج آلات مثلاً ڈسکس اور ٹیپس۔ || Auxiliary storage: له اصلي حافظې پرته د زېرمې وسایل، لکه ډیسکونه او ټېپونه.
## B || B || B
p Base class: A class from which other classes are derived. Also called parent class or super class. || Base class: وہ کلاس جس سے دوسری کلاسز اخذ کی جاتی ہیں۔ اسے پیرنٹ کلاس یا سپر کلاس بھی کہتے ہیں۔ || Base class: هغه ټولګی چې نور ټولګي ترې مشتق کېږي. مور/پلار ټولګی یا لوړ ټولګی هم بلل کېږي.
p Batch: A group of records or data processing jobs brought together for processing or transmission. || Batch: ریکارڈز یا ڈیٹا پروسیسنگ کاموں کا گروپ جو پروسیسنگ یا ترسیل کے لیے اکٹھا کیا جائے۔ || Batch: د ریکارډونو یا د ډېټا پروسس دندو ډله چې د پروسس یا لېږد لپاره سره راټولېږي.
p Batch processing: A feature of operating system in which more than one records (a batch) are accumulated and processed after a regular interval of time. || Batch processing: آپریٹنگ سسٹم کی ایک خصوصیت جس میں ایک سے زیادہ ریکارڈز (ایک بیچ) جمع کر کے وقت کے باقاعدہ وقفے کے بعد پروسیس کیے جاتے ہیں۔ || Batch processing: د عملیاتي سیسټم یوه ځانګړتیا چې پکې له یوه ډېر ریکارډونه (یوه ډله) راټولېږي او د منظم وخت له وقفې وروسته پروسس کېږي.
