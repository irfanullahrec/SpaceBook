## 6.1 Functions || 6.1 فنکشنز || ۶.۱ فنکشنونه
p In C++ program, when a set of related statements are grouped together, in a particular format, to accomplish a specific task is called function. Function is one of the main building blocks of any programming language. There are some functions whose work has been fixed by the developers of C++ programming language. These are called built-in functions. Built-in functions are specific in its functionalities; therefore, the programmers develop their own functions called user-defined functions. These functions are the main focus point of this unit. || C++ پروگرام میں جب متعلقہ بیانات کا ایک مجموعہ کسی خاص کام کی انجام دہی کے لیے ایک مخصوص شکل میں اکٹھا کیا جائے تو اسے فنکشن کہتے ہیں۔ فنکشن کسی بھی پروگرامنگ زبان کے بنیادی اجزا میں سے ایک ہے۔ کچھ فنکشنز ایسے ہیں جن کا کام C++ پروگرامنگ زبان کے بنانے والوں نے مقرر کر دیا ہے۔ انھیں بلٹ اِن فنکشنز کہتے ہیں۔ بلٹ اِن فنکشنز اپنی کارکردگی میں مخصوص ہیں؛ اس لیے پروگرامرز اپنے فنکشنز بناتے ہیں جنھیں یوزر ڈیفائنڈ فنکشنز کہتے ہیں۔ یہ فنکشنز اس یونٹ کا مرکزی موضوع ہیں۔ || په C++ پروګرام کې کله چې د اړوندو بیانونو یوه ټولګه د یوې ځانګړې دندې د ترسره کولو لپاره په یوه ټاکلې بڼه یوځای شي، فنکشن بلل کېږي. فنکشن د هرې پروګرامي ژبې له اصلي جوړوونکو برخو یو دی. ځینې فنکشنونه شته چې کار یې د C++ پروګرامي ژبې جوړوونکو ټاکلی دی. دا جوړ شوي (built-in) فنکشنونه بلل کېږي. جوړ شوي فنکشنونه په خپلو دندو کې ځانګړي دي؛ نو پروګرام جوړوونکي خپل فنکشنونه جوړوي چې د کاروونکي-تعریف شوي فنکشنونه بلل کېږي. دا فنکشنونه د دې څپرکي اصلي تمرکز دی.
## 6.1.1 Concept and types of functions || 6.1.1 فنکشنز کا تصور اور اقسام || ۶.۱.۱ د فنکشنونو مفهوم او ډولونه
p Function is an important feature of any programming language. It makes the work easier by writing the code once and executing it again and again. ## a. Concept of function || a. فنکشن کا تصور || a. د فنکشن مفهوم
p Whenever we want to perform a task again and again in a program such as calculating the square or cube for multiple integer values then it is too difficult to write the same code multiple times, say 5 times for 5 different integer values, in the same program. || جب بھی ہم کسی پروگرام میں کوئی کام بار بار کرنا چاہیں، جیسے متعدد صحیح قدروں کا مربع یا مکعب معلوم کرنا، تو ایک ہی پروگرام میں ایک ہی کوڈ کو کئی بار، مثلاً 5 مختلف صحیح قدروں کے لیے 5 بار، لکھنا بہت مشکل ہے۔ || کله چې وغواړو په یوه پروګرام کې یوه دنده بیا بیا ترسره کړو، لکه د ډېرو صحیح ارزښتونو مربع یا مکعب موندل، نو په یوه پروګرام کې یو کوډ څو ځله، مثلاً د ۵ بېلو صحیح ارزښتونو لپاره ۵ ځله، لیکل ډېر ستونزمن دي.
