qp i | A function cannot be overloaded only by its return type. || فنکشن کو صرف اس کی ریٹرن ٹائپ سے اوورلوڈ نہیں کیا جا سکتا۔ || فنکشن یوازې د بېرته ورکړې په ډول نه شي ډېرېدای.
sol True ## True — functions that differ only in return type cannot be overloaded; the parameter list must differ.
qp ii | A function can be overloaded with a different return type if it has all the parameters same. || اگر فنکشن کے تمام پیرامیٹرز ایک جیسے ہوں تو اسے مختلف ریٹرن ٹائپ کے ساتھ اوورلوڈ کیا جا سکتا ہے۔ || که د فنکشن ټول پاراميټرونه ورته وي، د بېل د بېرته ورکړې ډول سره ډېرېدای شي.
sol False ## False — if all the parameters are the same, changing only the return type does not overload the function; it is a compile error.
