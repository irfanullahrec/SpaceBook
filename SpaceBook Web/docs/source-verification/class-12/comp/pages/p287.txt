qp 1 | Q.4 Define file. Describe different types of file. || Q.4 فائل کی تعریف کریں۔ فائل کی مختلف اقسام بیان کریں۔ || Q.4 دوتنه تعریف کړئ. د دوتنې بېلابېل ډولونه بیان کړئ.
solution جواب
ss A file is a named collection of related data stored permanently on a secondary storage device (hard disk, USB) so that it remains after the program ends.
ss Types: (1) Text files — store data as readable ASCII characters in lines ending with newline; can be opened in a text editor (.txt). (2) Binary files — store data in the same binary form as in memory; not human-readable, but faster and more compact (.bin, .dat, images, executables).
ss By access, files may be sequential (read from start to end) or random-access (any record read directly using seekg/seekp).
endsolution
qp 2 | Q.5 Describe different types of operations performed on the files. || Q.5 فائلز پر کیے جانے والے مختلف قسم کے عمل بیان کریں۔ || Q.5 پر دوتنو د ترسره کېدونکو عملیو بېلابېل ډولونه بیان کړئ.
solution جواب
ss Operations on files: (1) Creating/opening a file — open() or the stream constructor, e.g. ofstream f("data.txt"); (2) Writing data — using << or put()/write(); (3) Reading data — using >>, get(), getline() or read().
ss (4) Appending — adding data at the end with ios::app; (5) Searching/moving within the file — seekg(), seekp(), tellg(), tellp(); (6) Checking end of file — eof(); (7) Closing the file — close(); also deleting or renaming files (remove(), rename()).
endsolution
qp 3 | Q.6 Define streams. Describe input and output streams in detail. || Q.6 اسٹریمز کی تعریف کریں۔ ان پٹ اور آؤٹ پٹ اسٹریمز تفصیل سے بیان کریں۔ || Q.6 بهیرونه تعریف کړئ. د ننوتنې او وتنې بهیرونه په تفصیل بیان کړئ.
solution جواب
ss A stream is a sequence (flow) of bytes between a program and an input/output device or file. C++ handles all I/O through streams.
ss Input stream — data flows from a source (keyboard or file) into the program; cin is the standard input stream (istream), and ifstream is used to read from files using >>, get(), getline().
ss Output stream — data flows from the program to a destination (screen, printer or file); cout is the standard output stream (ostream), and ofstream writes to files using <<, put(). fstream supports both input and output.
endsolution
qp 4 | Q.7 What is meant by the term mode of file opening? Describe different modes of opening file. || Q.7 فائل کھولنے کے موڈ کی اصطلاح سے کیا مراد ہے؟ فائل کھولنے کے مختلف موڈز بیان کریں۔ || Q.7 د دوتنې د پرانیستلو د حالت اصطلاح څه معنا لري؟ د دوتنې د پرانیستلو بېلابېل حالتونه بیان کړئ.
solution جواب
ss The mode of file opening specifies the purpose for which a file is opened (reading, writing, appending etc.); it is passed as the second argument of open(), e.g. f.open("a.txt", ios::out);
ss Modes: ios::in — open for reading; ios::out — open for writing (creates the file or erases old contents); ios::app — append, all output at the end; ios::ate — open and move to the end of file; ios::trunc — delete existing contents; ios::binary — open in binary mode; ios::nocreate / ios::noreplace (older compilers). Modes can be combined with {{BAR}}, e.g. ios::out {{BAR}} ios::binary.
endsolution
qp 5 | Q.8 What is file handling? Explain it in detail. || Q.8 فائل ہینڈلنگ کیا ہے؟ تفصیل سے وضاحت کریں۔ || Q.8 د دوتنو چلول څه دي؟ په تفصیل یې تشریح کړئ.
solution جواب
ss File handling is the process of storing data in files and retrieving it using a program, so that data is kept permanently instead of being lost when the program ends.
ss In C++ it uses the header <fstream> with the classes ofstream (write), ifstream (read) and fstream (both). Steps: include <fstream> → create a stream object → open the file with a mode → read/write data → check errors/eof → close the file.
ss #include <fstream> #include <iostream> using namespace std; int main() { ofstream out("data.txt"); out << "Hello file" << endl; out.close(); ifstream in("data.txt"); string line; while (getline(in, line)) cout << line << endl; in.close(); return 0; }
endsolution
