## a. Function prototype || a. فنکشن پروٹوٹائپ || a. د فنکشن نمونه
p A function prototype is that part of a function that tells the compiler the name of the function, the type of data returned by the function, the number of parameters the function expects to receive, the types of the parameters, and the order of parameters. || فنکشن پروٹوٹائپ فنکشن کا وہ حصہ ہے جو کمپائلر کو فنکشن کا نام، فنکشن کی طرف سے واپس کیے جانے والے ڈیٹا کی قسم، فنکشن کے متوقع پیرامیٹرز کی تعداد، پیرامیٹرز کی اقسام اور پیرامیٹرز کی ترتیب بتاتا ہے۔ || د فنکشن نمونه د فنکشن هغه برخه ده چې کمپایلر ته د فنکشن نوم، د فنکشن له خوا د بېرته ورکړل شوي ډېټا ډول، د هغو پاراميټرونو شمېر چې فنکشن یې د ترلاسه کولو تمه لري، د پاراميټرونو ډولونه او د پاراميټرونو ترتیب ښيي.
p A function prototype is also called function declaration and is used in situation whenever the function is defined after the main() function. The function prototype ends with a semicolon (;). || فنکشن پروٹوٹائپ کو فنکشن ڈکلیریشن بھی کہتے ہیں اور یہ اس صورت میں استعمال ہوتا ہے جب فنکشن main() فنکشن کے بعد بیان کیا گیا ہو۔ فنکشن پروٹوٹائپ سیمی کولن (;) پر ختم ہوتا ہے۔ || د فنکشن نمونه د فنکشن اعلان هم بلل کېږي او هغه وخت کارېږي چې فنکشن د main() فنکشن وروسته تعریف شوی وي. د فنکشن نمونه په سیمي‌کولن (;) پای ته رسېږي.
p The function prototype for a function named “maximum” to calculate maximum number out of three integers is given below: || تین صحیح اعداد میں سے سب سے بڑا عدد معلوم کرنے والے ’’maximum‘‘ نامی فنکشن کا پروٹوٹائپ ذیل میں دیا گیا ہے: || د "maximum" په نوم د هغه فنکشن نمونه چې له درېیو صحیح عددونو تر ټولو لوی عدد حسابوي، لاندې ورکړل شوې:
p int maximum( int a, int b, int c); || int maximum( int a, int b, int c); || int maximum( int a, int b, int c);
p The compiler use function prototypes to validate function call. In a prototype, argument names are optional; however, the types are necessary as shown below: || کمپائلر فنکشن کال کی توثیق کے لیے فنکشن پروٹوٹائپس استعمال کرتا ہے۔ پروٹوٹائپ میں آرگیومنٹس کے نام اختیاری ہیں؛ تاہم اقسام ضروری ہیں جیسا کہ ذیل میں دکھایا گیا ہے: || کمپایلر د فنکشن غوښتنې د تایید لپاره د فنکشن نمونې کاروي. په نمونه کې د دلیلونو نومونه اختیاري دي؛ خو ډولونه اړین دي لکه لاندې:
p int maximum( int , int , int ); || int maximum( int , int , int ); || int maximum( int , int , int );
p Function prototype is used in C++ program only when the function is defined after the definition of main() function. If the function definition lies before the main() function then there is no need for the function prototype. || C++ پروگرام میں فنکشن پروٹوٹائپ صرف اس وقت استعمال ہوتا ہے جب فنکشن main() فنکشن کی تعریف کے بعد بیان کیا گیا ہو۔ اگر فنکشن کی تعریف main() فنکشن سے پہلے ہو تو فنکشن پروٹوٹائپ کی ضرورت نہیں۔ || په C++ پروګرام کې د فنکشن نمونه یوازې هغه وخت کارېږي چې فنکشن د main() فنکشن له تعریف وروسته تعریف شوی وي. که د فنکشن تعریف د main() فنکشن مخکې وي، د فنکشن نمونې ته اړتیا نشته.
## b. Function definition || b. فنکشن کی تعریف || b. د فنکشن تعریف
p A function definition specifies what a function does. It has two parts: a declaration /header and function body enclosed in { }. Function declarator is similar to function prototype with the only difference that it has the variables name for the parameters and without semicolon (;). Consider the following function declarator. || فنکشن کی تعریف بتاتی ہے کہ فنکشن کیا کرتا ہے۔ اس کے دو حصے ہیں: ڈکلیریشن/ہیڈر اور { } میں بند فنکشن کا جسم۔ فنکشن ڈکلیریٹر فنکشن پروٹوٹائپ جیسا ہے، فرق صرف یہ ہے کہ اس میں پیرامیٹرز کے لیے ویری ایبلز کے نام ہوتے ہیں اور سیمی کولن (;) نہیں ہوتا۔ درج ذیل فنکشن ڈکلیریٹر پر غور کریں۔ || د فنکشن تعریف ښيي چې فنکشن څه کوي. دوه برخې لري: اعلان/سرلیک او په { } کې تړلې د فنکشن بدنه. د فنکشن اعلانوونکی د فنکشن نمونې ته ورته دی، یوازینی توپیر یې دا دی چې د پاراميټرونو لپاره د متغیرونو نومونه لري او سیمي‌کولن (;) نه لري. لاندې د فنکشن اعلانوونکي ته پام وکړئ.
