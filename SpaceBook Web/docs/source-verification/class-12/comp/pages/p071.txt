## b. main( ) Function || b. main( ) فنکشن || b. main( ) فنکشن
p The main function is the point by where all C++ programs start their execution. It does not matter whether there are other functions with other names defined before or after it, the instructions contained within this function’s definition will always be the first ones to be executed in any C++ program.
