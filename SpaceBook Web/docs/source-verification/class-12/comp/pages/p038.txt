qp i | The operating system acts as an interface between the computer hardware and the human user. || آپریٹنگ سسٹم کمپیوٹر ہارڈویئر اور انسانی صارف کے درمیان انٹرفیس کا کام کرتا ہے۔ || عملیاتي سیسټم د کمپیوټري هارډویر او انساني کاروونکي ترمنځ د منځګړي کار کوي.
sol True ## True — the OS is the interface between the hardware and the user.
qp ii | Multiprogramming allows the processor to make use of idle time caused by I/O wait. || ملٹی پروگرامنگ پروسیسر کو I/O انتظار سے پیدا ہونے والے فارغ وقت کو استعمال کرنے دیتی ہے۔ || څو-پروګرامي کار پروسېسر ته اجازه ورکوي چې د I/O انتظار له امله له وزګار وخت ګټه واخلي.
sol True ## True — while one program waits for I/O, the processor runs another program, using the idle time.
qp iii | An operating system controls the execution of applications and acts as an interface between applications and the computer hardware. || آپریٹنگ سسٹم ایپلیکیشنز کے چلنے کو کنٹرول کرتا ہے اور ایپلیکیشنز اور کمپیوٹر ہارڈویئر کے درمیان انٹرفیس کا کام کرتا ہے۔ || عملیاتي سیسټم د کاريالونو اجرا کنټرولوي او د کاريالونو او کمپیوټري هارډویر ترمنځ د منځګړي کار کوي.
sol True ## True — the OS controls the execution of applications and acts as an interface between applications and hardware.
qp iv | In the early computers, the operating systems did not exist. || ابتدائی کمپیوٹرز میں آپریٹنگ سسٹم موجود نہیں تھے۔ || په لومړنیو کمپیوټرونو کې عملیاتي سیسټمونه نه وو.
sol True ## True — the earliest computers had no operating system; programs were loaded and run manually.
qp v | Multi-programming do not provide better utilization of system resources than multiprogramming. || ملٹی پروگرامنگ، ملٹی پروگرامنگ کے مقابلے میں سسٹم کے وسائل کا بہتر استعمال فراہم نہیں کرتی۔ || څو-پروګرامي کار د څو-پروګرامي کار په پرتله د سیسټم د سرچینو ښه کارونه نه برابروي.
sol False ## False — multiprogramming provides better utilisation of system resources (CPU and I/O) than uniprogramming.
qp vi | In a time sharing system, when a process is assigned to the CPU for execution, it remains there till its completion. || ٹائم شیئرنگ سسٹم میں جب کوئی پراسیس چلانے کے لیے CPU کو تفویض کیا جاتا ہے تو وہ مکمل ہونے تک وہیں رہتا ہے۔ || په وخت شریکونکي سیسټم کې کله چې یوه پروسه د اجرا لپاره CPU ته وسپارل شي، تر بشپړېدو هلته پاتې کېږي.
sol False ## False — in a time-sharing system each process gets the CPU only for a short time slice (quantum) and then the CPU switches to another process.
qp vii | A process is a dispatchable unit of thread. || پراسیس تھریڈ کی ایک قابلِ روانگی اکائی ہے۔ || پروسه د تار د لېږلو وړ واحد دی.
sol False ## False — a thread is the dispatchable unit of a process (a process contains one or more threads).
qp viii | A process is directly assigned to the CPU for processing from a block state when the event for which it is waiting happens. || جب وہ واقعہ پیش آ جائے جس کا پراسیس انتظار کر رہا ہو تو اسے بلاک حالت سے براہِ راست پراسیسنگ کے لیے CPU کو تفویض کر دیا جاتا ہے۔ || کله چې هغه پېښه وشي چې پروسه یې انتظار باسي، پروسه له بند حالت مستقیم د پروسس لپاره CPU ته سپارل کېږي.
sol False ## False — when the awaited event occurs, a blocked process moves to the ready state, not directly to the CPU (running).
