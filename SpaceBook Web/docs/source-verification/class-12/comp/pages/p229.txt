p and can be read as "address of" and * is the dereference operator that can be read as "value pointed by". These operators are complementary of each other and have opposite meanings. A variable referenced with & can be dereferenced with *. || … جا سکتا ہے اور * ڈی ریفرنس آپریٹر ہے جسے "value pointed by" پڑھا جا سکتا ہے۔ یہ آپریٹرز ایک دوسرے کے تکمیلی ہیں اور ان کے معنی متضاد ہیں۔ & سے حوالہ دیا گیا ویری ایبل * سے ڈی ریفرنس کیا جا سکتا ہے۔ || … په توګه لوستل کېدای شي او * د حوالې‌لرې کولو چلونکی دی چې د "value pointed by" په توګه لوستل کېدای شي. دا چلونکي یو د بل بشپړوونکي دي او متضادې معناوې لري. هغه متغیر چې په & حواله شوی وي، په * حواله‌لرې کېدای شي.
## 7.1.5 Declaring variables of pointer types || 7.1.5 پوائنٹر اقسام کے ویری ایبلز ڈکلیئر کرنا || ۷.۱.۵ د پوائنټر ډولونو متغیرونه اعلانول
p The declaration of pointer is simple and is similar to the declaration of a regular variable with a minor difference of the use of an asterisk * symbol between the data type and the variable name. Consider the following general format: || پوائنٹر کی ڈکلیریشن آسان ہے اور عام ویری ایبل کی ڈکلیریشن جیسی ہے، معمولی فرق یہ ہے کہ ڈیٹا ٹائپ اور ویری ایبل کے نام کے درمیان ستارہ * نشان استعمال ہوتا ہے۔ درج ذیل عمومی شکل پر غور کریں: || د پوائنټر اعلان اسانه دی او د عادي متغیر اعلان ته ورته دی، یوازې لږ توپیر دا دی چې د ډېټا ډول او د متغیر د نوم ترمنځ د ستوري * نښه کارېږي. لاندې عمومي بڼې ته پام وکړئ:
p Data type * nameVariable; || Data type * nameVariable; || Data type * nameVariable;
p Here, data type is the type of the value of that variable to which this pointer will point. This date type is not the type of the pointer itself but the type of the data the pointer points to. To understand it, consider the following examples of pointers declaration. || یہاں data type اس ویری ایبل کی قدر کی قسم ہے جس کی طرف یہ پوائنٹر اشارہ کرے گا۔ یہ ڈیٹا ٹائپ خود پوائنٹر کی قسم نہیں بلکہ اس ڈیٹا کی قسم ہے جس کی طرف پوائنٹر اشارہ کرتا ہے۔ اسے سمجھنے کے لیے پوائنٹرز ڈکلیریشن کی درج ذیل مثالوں پر غور کریں۔ || دلته data type د هغه متغیر د ارزښت ډول دی چې دا پوائنټر به ورته اشاره کوي. دا ډېټا ډول د پوائنټر خپل ډول نه دی بلکې د هغه ډېټا ډول دی چې پوائنټر ورته اشاره کوي. د دې د پوهېدو لپاره د پوائنټر اعلانونو لاندې بېلګو ته پام وکړئ.
p int* totalMarks; char *Name; float * percentage; || int* totalMarks; char *Name; float * percentage; || int* totalMarks; char *Name; float * percentage;
p In this example, three pointers totalMarks, Name and percentage are declared. Each one is intended to point to a different data type. All these pointers occupy space in memory. The first pointer points to an int, the second to a char and the last one to a float. || اس مثال میں تین پوائنٹرز totalMarks، Name اور percentage ڈکلیئر کیے گئے ہیں۔ ہر ایک کا مقصد مختلف ڈیٹا ٹائپ کی طرف اشارہ کرنا ہے۔ یہ تمام پوائنٹرز میموری میں جگہ لیتے ہیں۔ پہلا پوائنٹر int کی طرف، دوسرا char کی طرف اور آخری float کی طرف اشارہ کرتا ہے۔ || په دې بېلګه کې درې پوائنټرونه totalMarks، Name او percentage اعلان شوي. هر یو د یوه بېل ډېټا ډول ته د اشارې لپاره دی. دا ټول پوائنټرونه په حافظه کې ځای نیسي. لومړی پوائنټر int ته، دویم char ته او وروستی float ته اشاره کوي.
p It is notable that the asterisk * symbol used between the data type and the name of the variable is the indication for the pointer declaration and is not used for multiplication. There are three ways to place the asterisk. These are: placing next to the data type, the variable name, or in the middle. All these variations are shown in the above declarations of variables totalMarks, Name and percentage. || قابلِ ذکر ہے کہ ڈیٹا ٹائپ اور ویری ایبل کے نام کے درمیان استعمال ہونے والا ستارہ * نشان پوائنٹر ڈکلیریشن کی علامت ہے اور ضرب کے لیے استعمال نہیں ہوتا۔ ستارہ رکھنے کے تین طریقے ہیں: ڈیٹا ٹائپ کے ساتھ، ویری ایبل کے نام کے ساتھ یا درمیان میں۔ یہ تمام صورتیں ویری ایبلز totalMarks، Name اور percentage کی اوپر کی ڈکلیریشنز میں دکھائی گئی ہیں۔ || د یادونې وړ ده چې د ډېټا ډول او د متغیر د نوم ترمنځ کارېدونکې د ستوري * نښه د پوائنټر د اعلان نښه ده او د ضرب لپاره نه کارېږي. د ستوري د ایښودلو درې لارې دي: د ډېټا ډول تر څنګ، د متغیر د نوم تر څنګ، یا په منځ کې. دا ټول بڼې د totalMarks، Name او percentage متغیرونو په پورته اعلانونو کې ښودل شوې.
