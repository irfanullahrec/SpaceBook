p A pointer of type int can only points to a variable of type int and cannot to some other type of variable. Same is the case for other data types as well, but, there is a special type of pointer named void pointer or generic pointer that can point to an objects of any data type. Its declaration is similar to the declaration of normal pointers with the only difference of the use of void keyword as the pointer’s type. Consider the following statement of declaration of the void pointer: || int قسم کا پوائنٹر صرف int قسم کے ویری ایبل کی طرف اشارہ کر سکتا ہے، کسی اور قسم کے ویری ایبل کی طرف نہیں۔ دوسری ڈیٹا ٹائپس کا بھی یہی حال ہے، لیکن ایک خاص قسم کا پوائنٹر ہے جسے void پوائنٹر یا عمومی پوائنٹر کہتے ہیں جو کسی بھی ڈیٹا ٹائپ کی شے کی طرف اشارہ کر سکتا ہے۔ اس کی ڈکلیریشن عام پوائنٹرز جیسی ہے، فرق صرف یہ ہے کہ پوائنٹر کی قسم کے طور پر void کلیدی لفظ استعمال ہوتا ہے۔ void پوائنٹر کی ڈکلیریشن کے درج ذیل بیان پر غور کریں: || د int ډول پوائنټر یوازې د int ډول متغیر ته اشاره کولی شي، د بل ډول متغیر ته نه. د نورو ډېټا ډولونو حالت هم همداسې دی، خو یو ځانګړی پوائنټر شته چې void پوائنټر یا عمومي پوائنټر بلل کېږي او د هر ډېټا ډول شي ته اشاره کولی شي. اعلان یې د عادي پوائنټرونو اعلان ته ورته دی، یوازینی توپیر دا دی چې د پوائنټر د ډول په توګه void کلیدي کلمه کارېږي. د void پوائنټر د اعلان لاندې بیان ته پام وکړئ:
p void *pointerVoid; // pointerVoid is a void pointer || void *pointerVoid; // pointerVoid is a void pointer || void *pointerVoid; // pointerVoid is a void pointer
p As, a void pointer can point to objects of any data type, therefore, consider the following statements. || چونکہ void پوائنٹر کسی بھی ڈیٹا ٹائپ کی اشیا کی طرف اشارہ کر سکتا ہے، اس لیے درج ذیل بیانات پر غور کریں۔ || څرنګه چې void پوائنټر د هر ډېټا ډول شیانو ته اشاره کولی شي، نو لاندې بیانونو ته پام وکړئ.
p int X; float Y; void *pointerVoid; pointerVoid = &X; // valid pointerVoid = &Y; // valid || int X; float Y; void *pointerVoid; pointerVoid = &X; // valid pointerVoid = &Y; // valid || int X; float Y; void *pointerVoid; pointerVoid = &X; // valid pointerVoid = &Y; // valid
p In this segment of code, pointerVoid, stores the address of both integer variable X and floating point variable Y. The compiler decides at run time that the address of which type of variable should be assigned to this pointer. || کوڈ کے اس حصے میں pointerVoid، integer ویری ایبل X اور فلوٹنگ پوائنٹ ویری ایبل Y دونوں کا پتہ محفوظ کرتا ہے۔ کمپائلر رن ٹائم پر فیصلہ کرتا ہے کہ اس پوائنٹر کو کس قسم کے ویری ایبل کا پتہ دیا جائے۔ || د کوډ په دې برخه کې pointerVoid د integer متغیر X او د اعشاري متغیر Y دواړو پته ساتي. کمپایلر د اجرا پر مهال پرېکړه کوي چې دې پوائنټر ته د کوم ډول متغیر پته ورکړل شي.
## 7.1.6 Pointer initialization || 7.1.6 پوائنٹر کو ابتدائی قدر دینا || ۷.۱.۶ پوائنټر ته لومړنی ارزښت ورکول
p Assigning values to pointers at declaration time is called pointer initialization. As we know that the values of pointers are the addresses of other variables, therefore, sometimes when we declare pointers we may want to explicitly specify to which variables they will point. || ڈکلیریشن کے وقت پوائنٹرز کو قدریں دینا پوائنٹر انیشیلائزیشن کہلاتا ہے۔ جیسا کہ ہم جانتے ہیں کہ پوائنٹرز کی قدریں دوسرے ویری ایبلز کے پتے ہوتی ہیں، اس لیے بعض اوقات پوائنٹرز ڈکلیئر کرتے وقت ہم واضح طور پر بتانا چاہتے ہیں کہ وہ کن ویری ایبلز کی طرف اشارہ کریں گے۔ || د اعلان پر مهال پوائنټرونو ته د ارزښتونو ورکول د پوائنټر لومړنی ارزښت ورکول بلل کېږي. لکه څنګه چې پوهېږو چې د پوائنټرونو ارزښتونه د نورو متغیرونو پتې دي، نو کله کله د پوائنټرونو د اعلان پر مهال غواړو په ښکاره وټاکو چې کومو متغیرونو ته به اشاره کوي.
