## 3.3 Input/Output Handling || 3.3 ان پٹ/آؤٹ پٹ کا انتظام || ۳.۳ د ننوتو/وتو اداره
p For input/output operations, C++ uses streams in sequential media such as the screen or the keyboard. A stream is an object where a C++ program inserts characters to or extracts the characters from stream. All the standard input and output stream objects are declared within the header file iostream which is a part of the standard C++ library. || ان پٹ/آؤٹ پٹ کے عمل کے لیے C++ ترتیبی ذرائع جیسے اسکرین یا کی بورڈ میں اسٹریمز استعمال کرتی ہے۔ اسٹریم ایک آبجیکٹ ہے جس میں C++ پروگرام حروف داخل کرتا ہے یا اس سے حروف نکالتا ہے۔ تمام معیاری ان پٹ اور آؤٹ پٹ اسٹریم آبجیکٹس ہیڈر فائل iostream میں ڈکلیئر ہوتے ہیں جو معیاری C++ لائبریری کا حصہ ہے۔ || د ننوتو/وتو عملیو لپاره C++ په ترتیبي رسنیو لکه پرده یا کیبورډ کې بهیرونه (streams) کاروي. بهیر یو شی دی چې C++ پروګرام پکې توري ورننباسي یا ترې توري راباسي. ټول معیاري د ننوتو او وتو بهیر شیان په iostream سرلیک فایل کې اعلان شوي چې د معیاري C++ کتابتون برخه ده.
## 3.3.1 Standard output (cout) || 3.3.1 معیاری آؤٹ پٹ (cout) || ۳.۳.۱ معیاري وتنه (cout)
p The default standard output of a C++ program is the screen, and cout is the C++ stream object which defines it. cout is used in conjunction with the insertion operator, which is written as <<.
