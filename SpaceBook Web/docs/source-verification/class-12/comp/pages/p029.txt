## Secondary Storage Management || ثانوی اسٹوریج مینجمنٹ || د ثانوي زېرمې اداره
p Secondary storage consists of those devices which stores data permanently for a long time. These devices includes tape drives, hard disks, CD and DVD disks, flash memory and other media designed to hold information for long life. The data stored in the secondary storage is accessed in primary storage and then into cache and CPU registers. The data loaded from secondary storage is ordinarily divided into fixed number of bytes or words. The function of operating system is to manage secondary storage devices and handle proper flow of data among primary and secondary storage devices is called secondary storage management. || ثانوی اسٹوریج ان آلات پر مشتمل ہے جو ڈیٹا کو طویل عرصے تک مستقل طور پر محفوظ رکھتے ہیں۔ ان آلات میں ٹیپ ڈرائیوز، ہارڈ ڈسکس، CD اور DVD ڈسکس، فلیش میموری اور دیگر ذرائع شامل ہیں جو معلومات کو طویل مدت تک رکھنے کے لیے بنائے گئے ہیں۔ ثانوی اسٹوریج میں محفوظ ڈیٹا تک پہلے پرائمری اسٹوریج اور پھر کیش اور CPU رجسٹرز میں رسائی ہوتی ہے۔ ثانوی اسٹوریج سے لوڈ ہونے والا ڈیٹا عموماً بائٹس یا الفاظ کی مقررہ تعداد میں تقسیم ہوتا ہے۔ آپریٹنگ سسٹم کا ثانوی اسٹوریج آلات کا انتظام کرنا اور پرائمری اور ثانوی اسٹوریج آلات کے درمیان ڈیٹا کے مناسب بہاؤ کو سنبھالنا ثانوی اسٹوریج مینجمنٹ کہلاتا ہے۔ || ثانوي زېرمه له هغو وسایلو جوړه ده چې ډېټا د اوږدې مودې لپاره دایمي ساتي. په دې وسایلو کې د ټېپ ډرایوونه، هارډ ډیسکونه، CD او DVD ډیسکونه، فلش حافظه او نورې رسنۍ شاملې دي چې د اوږدې مودې لپاره د معلوماتو ساتلو ته جوړې شوې. په ثانوي زېرمه کې ساتل شوې ډېټا ته لومړی په لومړنۍ زېرمه او بیا په کیش او د CPU په ثبتونکو کې لاسرسی کېږي. له ثانوي زېرمې پورته شوې ډېټا عموماً په ټاکلي شمېر بایټونو یا کلمو وېشل کېږي. د عملیاتي سیسټم دنده چې ثانوي زېرمې وسایل اداره کړي او د لومړنیو او ثانوي زېرمې وسایلو ترمنځ د ډېټا سم بهیر سمبال کړي، د ثانوي زېرمې اداره بلل کېږي.
p In storage, each location has an address. The set of all addresses available to a program is called an address space which is managed by the secondary storage management module of the operating system. || اسٹوریج میں ہر مقام کا ایک پتہ ہوتا ہے۔ کسی پروگرام کو دستیاب تمام پتوں کے مجموعے کو ایڈریس اسپیس کہتے ہیں جس کا انتظام آپریٹنگ سسٹم کا ثانوی اسٹوریج مینجمنٹ ماڈیول کرتا ہے۔ || په زېرمه کې هر ځای یوه پته لري. یوه پروګرام ته د شته ټولو پتو ټولګې ته د پتې فضا ویل کېږي چې د عملیاتي سیسټم د ثانوي زېرمې د ادارې ماډیول یې اداره کوي.
