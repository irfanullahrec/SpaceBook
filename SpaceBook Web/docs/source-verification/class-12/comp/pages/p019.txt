## Limitation of multi-programming || ملٹی پروگرامنگ کی حد || د څو-پروګرامي کار محدودیت
p Multiprogramming requires context switching since several programs (processes) sequentially share the CPU. This typically introduces processing delay compared to a dedicated unshared process. || ملٹی پروگرامنگ میں کانٹیکسٹ سوئچنگ ضروری ہوتی ہے کیونکہ کئی پروگرام (پراسیسز) باری باری CPU کو استعمال کرتے ہیں۔ اس سے عموماً ایک مخصوص غیر مشترک پراسیس کے مقابلے میں پراسیسنگ میں تاخیر پیدا ہوتی ہے۔ || څو-پروګرامي کار د زمینې بدلون (context switching) ته اړتیا لري، ځکه څو پروګرامونه (پروسې) په ترتیب سره CPU شریکوي. دا عموماً د یوې ځانګړې نه‌شریکې پروسې په پرتله په پروسس کې ځنډ راولي.
## c. Multi-tasking operating system || c. ملٹی ٹاسکنگ آپریٹنگ سسٹم || c. څو-دندیز عملیاتي سیسټم
p Multitasking is the process in which the operating system performs multiple tasks simultaneously on a single processor in such a way that creates the impression of parallel executions. Practically, all modern OS has the ability of multitasking. || ملٹی ٹاسکنگ وہ عمل ہے جس میں آپریٹنگ سسٹم ایک ہی پروسیسر پر بیک وقت متعدد کام اس طرح انجام دیتا ہے کہ متوازی طور پر چلنے کا تاثر پیدا ہوتا ہے۔ عملی طور پر تمام جدید آپریٹنگ سسٹم ملٹی ٹاسکنگ کی صلاحیت رکھتے ہیں۔ || څو-دندیز کار هغه بهیر دی چې پکې عملیاتي سیسټم پر یوه پروسېسر په یو وخت ډېرې دندې داسې ترسره کوي چې د موازي اجرا تاثر پیدا کوي. په عمل کې ټول نوي عملیاتي سیسټمونه د څو-دندیز کار وړتیا لري.
p Multitasking does not mean that the computer has multiple processors to execute multiple processes simultaneously. It means that the operating system switches the jobs so quickly on a single processor that the user thinks all these processes are executing in parallel. || ملٹی ٹاسکنگ کا مطلب یہ نہیں کہ کمپیوٹر میں بیک وقت متعدد پراسیسز چلانے کے لیے کئی پروسیسر ہیں۔ اس کا مطلب یہ ہے کہ آپریٹنگ سسٹم ایک ہی پروسیسر پر جابز کو اتنی تیزی سے بدلتا ہے کہ صارف سمجھتا ہے کہ یہ تمام پراسیسز متوازی طور پر چل رہے ہیں۔ || څو-دندیز کار دا معنا نه لري چې کمپیوټر د ډېرو پروسو د یوځای اجرا لپاره ډېر پروسېسرونه لري. معنا یې دا ده چې عملیاتي سیسټم پر یوه پروسېسر دندې دومره چټکې بدلوي چې کاروونکی فکر کوي دا ټولې پروسې په موازي ډول اجرا کېږي.
p Multitasking can be either pre-emptive or cooperative. In pre-emptive version, the operating system divides the CPU time and allocates one slot to each of the programs. Operating systems that support preemptive multitasking are: Solaris, UNIX, Windows 2000, Windows XP, Mac OS X and Linux. In cooperative multitasking, processes cooperate with each other to achieve simultaneous execution. Operating system that supports cooperative multitasking is Windows 3.x. || ملٹی ٹاسکنگ یا تو پری ایمپٹیو ہوتی ہے یا کوآپریٹو۔ پری ایمپٹیو ورژن میں آپریٹنگ سسٹم CPU کا وقت تقسیم کرتا ہے اور ہر پروگرام کو ایک حصہ دیتا ہے۔ پری ایمپٹیو ملٹی ٹاسکنگ کو سپورٹ کرنے والے آپریٹنگ سسٹم یہ ہیں: Solaris، UNIX، Windows 2000، Windows XP، Mac OS X اور Linux۔ کوآپریٹو ملٹی ٹاسکنگ میں پراسیسز بیک وقت چلنے کے لیے ایک دوسرے سے تعاون کرتے ہیں۔ کوآپریٹو ملٹی ٹاسکنگ کو سپورٹ کرنے والا آپریٹنگ سسٹم Windows 3.x ہے۔ || څو-دندیز کار یا مخکې‌نیونکی (pre-emptive) وي یا همکار (cooperative). په مخکې‌نیونکې نسخه کې عملیاتي سیسټم د CPU وخت وېشي او هر پروګرام ته یوه برخه ورکوي. هغه عملیاتي سیسټمونه چې د مخکې‌نیونکي څو-دندیز کار ملاتړ کوي: Solaris، UNIX، Windows 2000، Windows XP، Mac OS X او Linux. په همکار څو-دندیز کار کې پروسې د یوځای اجرا لپاره له یو بل سره همکاري کوي. هغه عملیاتي سیسټم چې د همکار څو-دندیز کار ملاتړ کوي Windows 3.x دی.
## d. Time-Sharing operating system || d. ٹائم شیئرنگ آپریٹنگ سسٹم || d. د وخت شریکونکی عملیاتي سیسټم
p Time sharing operating systems are those operating systems which slice processor (CPU) time into small fixed time slices and assign the processes to the CPU for that time slice to be executed. If the process is completed in its allotted time slice, it quits the system and CPU is assigned to the new process waiting on the top of the ready queue. If the time slice expires and the process still remains incomplete, it is added at the back of the ready queue for its next turn. || ٹائم شیئرنگ آپریٹنگ سسٹم وہ آپریٹنگ سسٹم ہیں جو پروسیسر (CPU) کے وقت کو چھوٹے مقررہ ٹکڑوں (time slices) میں تقسیم کرتے ہیں اور پراسیسز کو اس وقتی ٹکڑے میں چلنے کے لیے CPU کو تفویض کرتے ہیں۔ اگر پراسیس اپنے مقررہ وقت میں مکمل ہو جائے تو وہ سسٹم سے نکل جاتا ہے اور CPU ریڈی قطار کے اوپر انتظار کرنے والے نئے پراسیس کو دے دیا جاتا ہے۔ اگر وقتی ٹکڑا ختم ہو جائے اور پراسیس نامکمل رہے تو اسے اگلی باری کے لیے ریڈی قطار کے آخر میں شامل کر دیا جاتا ہے۔ || د وخت شریکونکي عملیاتي سیسټمونه هغه دي چې د پروسېسر (CPU) وخت په کوچنیو ټاکلو برخو (time slices) وېشي او پروسې د هغې برخې د اجرا لپاره CPU ته سپاري. که پروسه په خپله ټاکلې برخه کې بشپړه شي، له سیسټم وځي او CPU د چمتو کتار پر سر انتظار ایستونکې نوې پروسې ته ورکول کېږي. که د وخت برخه پای ته ورسېږي او پروسه لا نیمګړې وي، د راتلونکي نوبت لپاره د چمتو کتار شا ته ورزیاتېږي.
