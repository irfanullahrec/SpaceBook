## 5.3.3 Initializing string || 5.3.3 اسٹرنگ کو ابتدائی قدر دینا || ۵.۳.۳ تار ته لومړنی ارزښت ورکول
p 1. Strings in C can be initialized as arrays are initialized because string is a character array. || 1۔ C میں اسٹرنگز کو اسی طرح ابتدائی قدر دی جا سکتی ہے جیسے ایریز کو، کیونکہ اسٹرنگ حروف کا ایرے ہے۔ || ۱. په C کې تارونو ته د لړیو په څېر لومړنی ارزښت ورکول کېدای شي ځکه تار د تورو لړۍ ده.
p Consider the following example: || درج ذیل مثال پر غور کریں: || لاندې بېلګې ته پام وکړئ:
p char greeting [6] = { 'H', 'e', 'l', 'l', 'o', '\0' }; || char greeting [6] = { 'H', 'e', 'l', 'l', 'o', '\0' }; || char greeting [6] = { 'H', 'e', 'l', 'l', 'o', '\0' };
p The above statement declares a string named “greeting” with six elements of type char that are initialized with the characters that form the word "Hello" plus a null character '\0' at the end. Another method for initializing a string in C is to enclose the string in double quotes, "" as shown below: || اوپر کا بیان ’’greeting‘‘ نام کی اسٹرنگ ڈکلیئر کرتا ہے جس کے char قسم کے چھ عناصر ہیں جنھیں لفظ "Hello" بنانے والے حروف اور آخر میں ایک null حرف '\0' سے ابتدائی قدر دی گئی ہے۔ C میں اسٹرنگ کو ابتدائی قدر دینے کا ایک اور طریقہ اسٹرنگ کو ڈبل کوٹس "" میں بند کرنا ہے جیسا کہ ذیل میں دکھایا گیا ہے: || پورته بیان د "greeting" په نوم یو تار اعلانوي چې د char ډول شپږ عناصر لري او د "Hello" کلمې جوړوونکو تورو او په پای کې د null توري '\0' سره لومړنی ارزښت ورکړل شوی. په C کې تار ته د لومړني ارزښت ورکولو بله لاره دا ده چې تار په دوه‌ګونو نقل‌قولونو "" کې وتړل شي لکه لاندې:
p char greeting [ ] = “Hello”; || char greeting [ ] = “Hello”; || char greeting [ ] = “Hello”;
p In both cases, the array of characters greeting is declared with a size of 6 elements of type char: the 5 characters that compose the word “Hello” plus a final null character ('\0') which specifies the end of the sequence and that, in the second case, when using double quotes (") it is appended automatically. || دونوں صورتوں میں حروف کا ایرے greeting، char قسم کے 6 عناصر کے سائز سے ڈکلیئر ہوتا ہے: لفظ ’’Hello‘‘ بنانے والے 5 حروف اور ایک آخری null حرف ('\0') جو ترتیب کا اختتام بتاتا ہے، اور دوسری صورت میں ڈبل کوٹس (") استعمال کرنے پر یہ خود بخود شامل ہو جاتا ہے۔ || په دواړو حالتونو کې د تورو لړۍ greeting د char ډول ۶ عناصرو په اندازه اعلانېږي: د "Hello" کلمې جوړوونکي ۵ توري او یو وروستی null توری ('\0') چې د لړۍ پای ښيي، او په دویم حالت کې د دوه‌ګونو نقل‌قولونو (") په کارولو پخپله ورزیاتېږي.
p Consider an example to ask for your name and then display a greeting message on the screen as shown below using string: || ایک مثال پر غور کریں جو اسٹرنگ کے ذریعے آپ کا نام پوچھتی ہے اور پھر اسکرین پر خوش آمدیدی پیغام دکھاتی ہے جیسا کہ ذیل میں ہے: || یوې بېلګې ته پام وکړئ چې د تار په مرسته ستاسو نوم پوښتي او بیا پر پرده د ښه راغلاست پیغام ښيي لکه لاندې:
p #include <iostream.h> #include<conio.h> int main() { char question[] = "Please, enter your first name: "; char greeting[] = "Hello, "; char yourname [80]; || #include <iostream.h> #include<conio.h> int main() { char question[] = "Please, enter your first name: "; char greeting[] = "Hello, "; char yourname [80]; || #include <iostream.h> #include<conio.h> int main() { char question[] = "Please, enter your first name: "; char greeting[] = "Hello, "; char yourname [80];
