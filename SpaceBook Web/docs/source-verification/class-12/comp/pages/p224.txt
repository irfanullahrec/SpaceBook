## INTRODUCTION || تعارف || سریزه
p When variables are declared, computer reserves space in its memory for some objects. The variable name refers to that memory space that is occupied by that object. This allows us to store the value of those variables in the space reserved. Computer refers to these spaces using their addresses. To refer to memory addresses, C++ provides the facility of pointers. The objective of this Unit is to understand how variables are stored in computer memory and how spaces are allocated to them. Sometimes, a programmer needs to refer to another memory location which can only be done by the use of pointers. Pointer is one of the most powerful tool to handle memory addresses. This Unit covers the concept of memory addresses in detail and explains the working of reference operator & and dereference operator * with the help of examples. It also focuses on how to declare pointer type variables and how to initialize them in a program. || جب ویری ایبلز ڈکلیئر کیے جاتے ہیں تو کمپیوٹر کچھ اشیا کے لیے اپنی میموری میں جگہ مختص کرتا ہے۔ ویری ایبل کا نام اس میموری جگہ کی طرف اشارہ کرتا ہے جو اس شے نے گھیری ہوتی ہے۔ اس سے ہم ان ویری ایبلز کی قدر مختص جگہ میں محفوظ کر سکتے ہیں۔ کمپیوٹر ان جگہوں کا حوالہ ان کے پتوں سے دیتا ہے۔ میموری پتوں کا حوالہ دینے کے لیے C++ پوائنٹرز کی سہولت فراہم کرتی ہے۔ اس یونٹ کا مقصد یہ سمجھنا ہے کہ ویری ایبلز کمپیوٹر میموری میں کیسے محفوظ ہوتے ہیں اور انھیں جگہیں کیسے مختص کی جاتی ہیں۔ بعض اوقات پروگرامر کو کسی دوسرے میموری مقام کا حوالہ دینا ہوتا ہے جو صرف پوائنٹرز کے استعمال سے ممکن ہے۔ پوائنٹر میموری پتوں کو سنبھالنے کا سب سے طاقتور ذریعہ ہے۔ یہ یونٹ میموری پتوں کا تصور تفصیل سے بیان کرتا ہے اور مثالوں کی مدد سے حوالہ آپریٹر & اور ڈی ریفرنس آپریٹر * کا عمل واضح کرتا ہے۔ یہ اس پر بھی توجہ دیتا ہے کہ پوائنٹر قسم کے ویری ایبلز کیسے ڈکلیئر کیے جائیں اور پروگرام میں انھیں ابتدائی قدر کیسے دی جائے۔ || کله چې متغیرونه اعلان شي، کمپیوټر د ځینو شیانو لپاره په خپله حافظه کې ځای ساتي. د متغیر نوم هغه حافظه ځای ته اشاره کوي چې هغه شي نیولی. دا موږ ته اجازه راکوي چې د دې متغیرونو ارزښت په ساتل شوي ځای کې وساتو. کمپیوټر دې ځایونو ته د پتو له لارې اشاره کوي. د حافظې پتو ته د اشارې لپاره C++ د پوائنټرونو اسانتیا برابروي. د دې څپرکي موخه دا پوهېدل دي چې متغیرونه د کمپیوټر په حافظه کې څنګه ساتل کېږي او ځایونه ورته څنګه ټاکل کېږي. کله کله پروګرام جوړوونکی اړتیا لري چې بل حافظه ځای ته اشاره وکړي چې یوازې د پوائنټرونو په کارولو کېدای شي. پوائنټر د حافظې پتو د چلولو تر ټولو پیاوړې وسیله ده. دا څپرکی د حافظې د پتو مفهوم په تفصیل بیانوي او د بېلګو په مرسته د حوالې چلونکي & او د حوالې‌لرې کولو چلونکي * کار تشریح کوي. همداراز په دې تمرکز کوي چې د پوائنټر ډول متغیرونه څنګه اعلان شي او په پروګرام کې څنګه لومړنی ارزښت ورکړل شي.
