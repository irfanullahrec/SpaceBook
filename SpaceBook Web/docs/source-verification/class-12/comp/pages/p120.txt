p If the condition is true, the statement after if will be executed and if the condition is false, the statement will be skipped. If we want to execute multiple statements with one if statement then the statements should be enclosed in a pair of curly braces { }. || اگر شرط درست ہو تو if کے بعد والا بیان چلایا جائے گا اور اگر شرط غلط ہو تو بیان چھوڑ دیا جائے گا۔ اگر ہم ایک if بیان کے ساتھ متعدد بیانات چلانا چاہیں تو بیانات کو بریسز { } کے جوڑے میں بند کرنا چاہیے۔ || که شرط true وي، د if وروسته بیان اجرا کېږي او که شرط false وي، بیان پرېښودل کېږي. که وغواړو د یوه if بیان سره ډېر بیانونه اجرا کړو، بیانونه باید د لوړو قوسونو { } په یوه جوړه کې وتړل شي.
