## a. Local/Automatic variables || a. مقامی/خودکار ویری ایبلز || a. محلي/خپلکاره متغیرونه
p The variables defined within a block are called local variables and its scope is local to block. These variables are not accessible from outside the block and thus their visibility remains only to that block. For example, in the following code segment, the variables a, b and c are local variables and cannot be used outside this boundary. || کسی بلاک کے اندر بیان کیے گئے ویری ایبلز مقامی ویری ایبلز کہلاتے ہیں اور ان کا دائرہ بلاک تک محدود ہوتا ہے۔ یہ ویری ایبلز بلاک کے باہر سے قابلِ رسائی نہیں ہوتے اور یوں ان کی نمائش صرف اسی بلاک تک رہتی ہے۔ مثلاً درج ذیل کوڈ کے حصے میں ویری ایبلز a، b اور c مقامی ویری ایبلز ہیں اور اس حد کے باہر استعمال نہیں ہو سکتے۔ || هغه متغیرونه چې د یوه بلاک دننه تعریف شي، محلي متغیرونه بلل کېږي او ساحه یې په بلاک پورې محدوده ده. دا متغیرونه له بلاک بهر د لاسرسي وړ نه دي او لیدل یې یوازې په همغه بلاک پورې پاتې کېږي. د بېلګې په توګه په لاندې کوډ کې a، b او c محلي متغیرونه دي او له دې پولې بهر نه شي کارېدای.

p It is impossible to use the variables x, y or z defined in maximum( ) function directly within main function because these variables are local to the maximum function. || maximum( ) فنکشن میں بیان کیے گئے ویری ایبلز x، y یا z کو main فنکشن میں براہِ راست استعمال کرنا ناممکن ہے کیونکہ یہ ویری ایبلز maximum فنکشن کے لیے مقامی ہیں۔ || په maximum( ) فنکشن کې تعریف شوي x، y یا z متغیرونه په main فنکشن کې مستقیم کارول ناشوني دي ځکه دا متغیرونه د maximum فنکشن لپاره محلي دي.
