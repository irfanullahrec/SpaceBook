## 7.1.4 Dereference operator * || 7.1.4 ڈی ریفرنس آپریٹر * || ۷.۱.۴ د حوالې‌لرې کولو چلونکی *
p Pointers are used to store the address of another variable. If we want to store the value of the variable through the pointer, then we need a special type of operator called dereference operator denoted by asterisk *. To use dereference operator, precede the pointer variable with asterisk * symbol. This operator can be read as “value pointed by”. || پوائنٹرز دوسرے ویری ایبل کا پتہ محفوظ کرنے کے لیے استعمال ہوتے ہیں۔ اگر ہم پوائنٹر کے ذریعے ویری ایبل کی قدر محفوظ کرنا چاہیں تو ہمیں ایک خاص قسم کے آپریٹر کی ضرورت ہوتی ہے جسے ڈی ریفرنس آپریٹر کہتے ہیں اور جو ستارہ * سے ظاہر ہوتا ہے۔ ڈی ریفرنس آپریٹر استعمال کرنے کے لیے پوائنٹر ویری ایبل سے پہلے ستارہ * نشان لگائیں۔ اس آپریٹر کو ’’value pointed by‘‘ پڑھا جا سکتا ہے۔ || پوائنټرونه د بل متغیر د پتې د ساتلو لپاره کارېږي. که وغواړو د پوائنټر له لارې د متغیر ارزښت وساتو، نو یو ځانګړي چلونکي ته اړتیا لرو چې د حوالې‌لرې کولو (dereference) چلونکی بلل کېږي او په ستوري * ښودل کېږي. د دې چلونکي د کارولو لپاره د پوائنټر متغیر ته د ستوري * نښه مخکې ولیکئ. دا چلونکی د "value pointed by" په توګه لوستل کېدای شي.
