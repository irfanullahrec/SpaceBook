## 7.1 Pointers || 7.1 پوائنٹرز || ۷.۱ پوائنټرونه
p Pointer is an important and powerful feature of C++ language, in which a variable points to another variable by holding its address. || پوائنٹر C++ زبان کی ایک اہم اور طاقتور خصوصیت ہے جس میں ایک ویری ایبل دوسرے ویری ایبل کا پتہ رکھ کر اس کی طرف اشارہ کرتا ہے۔ || پوائنټر د C++ ژبې مهمه او پیاوړې ځانګړتیا ده چې پکې یو متغیر د بل متغیر پته ساتي او هغه ته اشاره کوي.
## 7.1.1 Pointer || 7.1.1 پوائنٹر || ۷.۱.۱ پوائنټر
p A pointer is a variable that holds the address of another variable. In memory, each and every variable has an address assigned to it by the compiler and if a programmer wants to access that address, another variable called “pointer” is needed. For the declaration of pointer, an asterisk * symbol is used between the data type and the variable name. || پوائنٹر ایک ویری ایبل ہے جو دوسرے ویری ایبل کا پتہ رکھتا ہے۔ میموری میں ہر ویری ایبل کو کمپائلر ایک پتہ دیتا ہے اور اگر پروگرامر اس پتے تک رسائی چاہے تو ’’پوائنٹر‘‘ نامی ایک اور ویری ایبل درکار ہوتا ہے۔ پوائنٹر کی ڈکلیریشن کے لیے ڈیٹا ٹائپ اور ویری ایبل کے نام کے درمیان ستارہ * نشان استعمال ہوتا ہے۔ || پوائنټر هغه متغیر دی چې د بل متغیر پته ساتي. په حافظه کې هر متغیر ته کمپایلر یوه پته ورکوي او که پروګرام جوړوونکی وغواړي هغې پتې ته لاسرسی ومومي، بل متغیر ته اړتیا ده چې "پوائنټر" بلل کېږي. د پوائنټر د اعلان لپاره د ډېټا ډول او د متغیر د نوم ترمنځ د ستوري * نښه کارېږي.
p Consider the following pointers declaration of the integer variable marks, floating point variable percentage and character type variable name: || integer ویری ایبل marks، فلوٹنگ پوائنٹ ویری ایبل percentage اور character قسم کے ویری ایبل name کے درج ذیل پوائنٹرز ڈکلیریشن پر غور کریں: || د integer متغیر marks، اعشاري متغیر percentage او د character ډول متغیر name لاندې پوائنټر اعلانونو ته پام وکړئ:
p int * marks; float * percentage; char * name; || int * marks; float * percentage; char * name; || int * marks; float * percentage; char * name;
## 7.1.2 Memory addresses || 7.1.2 میموری پتے || ۷.۱.۲ د حافظې پتې
p When writing a program, variables need to be declared. Declaration of variable is simple and its declaration tells the computer to reserve space in memory for this variable. The name of the variable refers to that memory space. This task is automatically performed by the operating system during runtime. When variables are declared, programmers store data in these variables. Computer refers to that space using an address. Therefore, everything a programmer declares has an address. It is analogous to the home address of some person. Using pointer variables, one can easily find out the address of a particular variable. || پروگرام لکھتے وقت ویری ایبلز ڈکلیئر کرنے ہوتے ہیں۔ ویری ایبل کی ڈکلیریشن آسان ہے اور یہ کمپیوٹر کو اس ویری ایبل کے لیے میموری میں جگہ مختص کرنے کا کہتی ہے۔ ویری ایبل کا نام اس میموری جگہ کی طرف اشارہ کرتا ہے۔ یہ کام رن ٹائم کے دوران آپریٹنگ سسٹم خود بخود کرتا ہے۔ ویری ایبلز ڈکلیئر ہونے کے بعد پروگرامرز ان میں ڈیٹا محفوظ کرتے ہیں۔ کمپیوٹر اس جگہ کا حوالہ پتے سے دیتا ہے۔ اس لیے پروگرامر جو کچھ ڈکلیئر کرتا ہے اس کا ایک پتہ ہوتا ہے۔ یہ کسی شخص کے گھر کے پتے کی طرح ہے۔ پوائنٹر ویری ایبلز کے ذریعے کسی خاص ویری ایبل کا پتہ آسانی سے معلوم کیا جا سکتا ہے۔ || د پروګرام د لیکلو پر مهال متغیرونه باید اعلان شي. د متغیر اعلان اسانه دی او کمپیوټر ته وايي چې د دې متغیر لپاره په حافظه کې ځای وساتي. د متغیر نوم هغه حافظه ځای ته اشاره کوي. دا کار د اجرا پر مهال عملیاتي سیسټم پخپله ترسره کوي. کله چې متغیرونه اعلان شي، پروګرام جوړوونکي پکې ډېټا ساتي. کمپیوټر هغه ځای ته د پتې له لارې اشاره کوي. نو هر هغه څه چې پروګرام جوړوونکی یې اعلانوي، یوه پته لري. دا د یوه کس د کور پتې ته ورته ده. د پوائنټر متغیرونو په مرسته د یوه ځانګړي متغیر پته په اسانۍ موندل کېدای شي.
