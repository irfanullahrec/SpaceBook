p The built-in functions are defined in the C++ library which should be included in the program before using these functions. These functions are used for the most commonly and frequently used operations and cannot be modified according to the users need. This feature of the functions is its main limitation. To overcome this problem, C++ provides a new set of functions that can be defined by the users itself. The following section describes this set of functions in detail. || بلٹ اِن فنکشنز C++ لائبریری میں بیان کیے گئے ہیں جسے ان فنکشنز کے استعمال سے پہلے پروگرام میں شامل کرنا چاہیے۔ یہ فنکشنز سب سے عام اور بار بار استعمال ہونے والے کاموں کے لیے استعمال ہوتے ہیں اور صارفین کی ضرورت کے مطابق تبدیل نہیں کیے جا سکتے۔ فنکشنز کی یہ خصوصیت ان کی بنیادی حد ہے۔ اس مسئلے پر قابو پانے کے لیے C++ فنکشنز کا ایک نیا مجموعہ فراہم کرتی ہے جسے صارفین خود بیان کر سکتے ہیں۔ درج ذیل حصہ فنکشنز کے اس مجموعے کو تفصیل سے بیان کرتا ہے۔ || جوړ شوي فنکشنونه د C++ په کتابتون کې تعریف شوي چې د دې فنکشنونو له کارولو مخکې باید په پروګرام کې شامل شي. دا فنکشنونه د تر ټولو عامو او ډېر کارېدونکو عملیو لپاره کارېږي او د کاروونکو د اړتیا سره سم نه شي بدلېدای. د فنکشنونو دا ځانګړتیا یې اصلي محدودیت دی. د دې ستونزې د حل لپاره C++ د فنکشنونو نوې ټولګه برابروي چې کاروونکي یې پخپله تعریفولی شي. لاندې برخه د فنکشنونو دا ټولګه په تفصیل بیانوي.
## ii. User-defined functions || ii. یوزر ڈیفائنڈ فنکشنز || ii. د کاروونکي-تعریف شوي فنکشنونه
p The functions defined by the users, according to their needs, to perform their own tasks are called users-defined functions. These functions are used to overcome the limitations of build-in functions. || صارفین کی طرف سے اپنی ضرورت کے مطابق اپنے کام انجام دینے کے لیے بیان کیے گئے فنکشنز یوزر ڈیفائنڈ فنکشنز کہلاتے ہیں۔ یہ فنکشنز بلٹ اِن فنکشنز کی حدود پر قابو پانے کے لیے استعمال ہوتے ہیں۔ || هغه فنکشنونه چې کاروونکي یې د خپلو اړتیاوو سره سم د خپلو دندو د ترسره کولو لپاره تعریفوي، د کاروونکي-تعریف شوي فنکشنونه بلل کېږي. دا فنکشنونه د جوړ شویو فنکشنونو د محدودیتونو د لرې کولو لپاره کارېږي.
