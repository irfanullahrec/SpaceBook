## 8.1.4 Data hiding || 8.1.4 ڈیٹا ہائیڈنگ || ۸.۱.۴ د ډېټا پټول
p Data Hiding is an important concept of C++ programming language in which the members of a class are protected against illegal access from outside the class. In C language, struct is used but it cannot hide data of its data members. Whereas in C++, we got the facility of hiding data using different access levels: private, protected, public in classes. || ڈیٹا ہائیڈنگ C++ پروگرامنگ زبان کا ایک اہم تصور ہے جس میں کلاس کے اراکین کو کلاس کے باہر سے غیر قانونی رسائی سے محفوظ رکھا جاتا ہے۔ C زبان میں struct استعمال ہوتا ہے لیکن یہ اپنے ڈیٹا ممبرز کا ڈیٹا چھپا نہیں سکتا۔ جبکہ C++ میں ہمیں کلاسز میں مختلف رسائی کی سطحوں private، protected، public کے ذریعے ڈیٹا چھپانے کی سہولت ملی۔ || د ډېټا پټول د C++ پروګرامي ژبې مهم مفهوم دی چې پکې د ټولګي غړي له ټولګي بهر د ناقانونه لاسرسي څخه ساتل کېږي. په C ژبه کې struct کارېږي خو د خپلو ډېټا غړو ډېټا نه شي پټولی. په داسې حال کې چې په C++ کې موږ ته په ټولګیو کې د لاسرسي د بېلو کچو private، protected، public په مرسته د ډېټا د پټولو اسانتیا ترلاسه شوه.
p Private data members and member functions can only be accessed by the members of the same class defining them and cannot be accessed from outside the class. Similarly, protected members (data members and member functions) of a class can be accessed only by the class defining them and its derived classes. By using friend function, the private and protected members (data members and member functions) of a class can also be accessed. Except these, private and protected members are not accessible || private ڈیٹا ممبرز اور ممبر فنکشنز تک صرف انھیں بیان کرنے والی کلاس کے اراکین رسائی کر سکتے ہیں اور کلاس کے باہر سے رسائی نہیں ہو سکتی۔ اسی طرح کلاس کے protected اراکین (ڈیٹا ممبرز اور ممبر فنکشنز) تک صرف انھیں بیان کرنے والی کلاس اور اس کی ماخوذ کلاسز رسائی کر سکتی ہیں۔ friend فنکشن کے ذریعے کلاس کے private اور protected اراکین (ڈیٹا ممبرز اور ممبر فنکشنز) تک بھی رسائی ہو سکتی ہے۔ || private د ډېټا غړو او غړو فنکشنونو ته یوازې د هغه ټولګي غړي لاسرسی کولی شي چې تعریف کړي یې دي او له ټولګي بهر لاسرسی نه کېږي. همداراز د ټولګي protected غړو (د ډېټا غړي او غړي فنکشنونه) ته یوازې تعریفوونکی ټولګی او د هغه مشتق ټولګي لاسرسی کولی شي. د friend فنکشن په کارولو د ټولګي private او protected غړو ته هم لاسرسی کېدای شي. له دې پرته private او protected غړي بل هېڅ ځای د لاسرسي وړ نه دي او په دې توګه د ډېټا د پټولو اسانتیا برابروي.
