## i. Embedded operating system || i. ایمبیڈڈ آپریٹنگ سسٹم || i. ننښتی (Embedded) عملیاتي سیسټم
p Embedded operating systems are those operating systems which are designed for use in embedded computer systems. An embedded computer system is a computer which is a part of another system such as robot, missile etc. || ایمبیڈڈ آپریٹنگ سسٹم وہ آپریٹنگ سسٹم ہیں جو ایمبیڈڈ کمپیوٹر سسٹمز میں استعمال کے لیے بنائے جاتے ہیں۔ ایمبیڈڈ کمپیوٹر سسٹم ایسا کمپیوٹر ہے جو کسی دوسرے نظام کا حصہ ہو، جیسے روبوٹ، میزائل وغیرہ۔ || ننښتي عملیاتي سیسټمونه هغه دي چې په ننښتو کمپیوټري سیسټمونو کې د کارولو لپاره ډیزاین شوي. ننښتی کمپیوټري سیسټم داسې کمپیوټر دی چې د بل سیسټم برخه وي، لکه روبوټ، توغندی او نور.
p These operating systems are designed for the operations of small machines like Personal Digital Assistant (PDA) with less autonomy. They can operate with limited number of resources. By design, these operating systems are very compact in size and efficient in performance. Windows CE, Embedded Linux and Android are the examples of embedded operating systems. || یہ آپریٹنگ سسٹم کم خود مختاری والی چھوٹی مشینوں جیسے پرسنل ڈیجیٹل اسسٹنٹ (PDA) کے کاموں کے لیے بنائے جاتے ہیں۔ یہ محدود وسائل کے ساتھ کام کر سکتے ہیں۔ ساخت کے لحاظ سے یہ آپریٹنگ سسٹم سائز میں بہت مختصر اور کارکردگی میں مؤثر ہوتے ہیں۔ Windows CE، Embedded Linux اور Android ایمبیڈڈ آپریٹنگ سسٹمز کی مثالیں ہیں۔ || دا عملیاتي سیسټمونه د لږ خپلواکۍ لرونکو کوچنیو ماشینونو لکه شخصي ډیجیټل مرستیال (PDA) د چارو لپاره ډیزاین شوي. دوی د محدودو سرچینو سره کار کولی شي. د ډیزاین له مخې دا عملیاتي سیسټمونه په اندازه کې ډېر وړوکي او په کارکردګۍ کې اغېزمن وي. Windows CE، Embedded Linux او Android د ننښتو عملیاتي سیسټمونو بېلګې دي.
## 1.1.4 Single-user and Multi-user Operating Systems || 1.1.4 سنگل یوزر اور ملٹی یوزر آپریٹنگ سسٹم || ۱.۱.۴ یو-کاروونکی او ډېر-کاروونکي عملیاتي سیسټمونه
p Operating systems can be divided into two categories as for as number of users are concerned. || جہاں تک صارفین کی تعداد کا تعلق ہے، آپریٹنگ سسٹمز کو دو زمروں میں تقسیم کیا جا سکتا ہے۔ || تر هغه ځایه چې د کاروونکو شمېر ته اړه لري، عملیاتي سیسټمونه په دوو ډلو وېشل کېدای شي.
## a. Single-user operating systems || a. سنگل یوزر آپریٹنگ سسٹم || a. یو-کاروونکی عملیاتي سیسټمونه
p Single-user operating systems are those operating systems which are usable by a single user at a time. These operating systems execute a single process at a time on a single processor. Batch processing operating systems are the examples of single user operating systems. || سنگل یوزر آپریٹنگ سسٹم وہ آپریٹنگ سسٹم ہیں جنھیں ایک وقت میں ایک ہی صارف استعمال کر سکتا ہے۔ یہ آپریٹنگ سسٹم ایک وقت میں ایک ہی پروسیسر پر ایک پراسیس چلاتے ہیں۔ بیچ پراسیسنگ آپریٹنگ سسٹم سنگل یوزر آپریٹنگ سسٹمز کی مثالیں ہیں۔ || یو-کاروونکي عملیاتي سیسټمونه هغه دي چې په یو وخت کې یوازې یو کاروونکی یې کارولی شي. دا عملیاتي سیسټمونه په یو وخت پر یوه پروسېسر یوه پروسه اجرا کوي. ډله‌ییز پروسس عملیاتي سیسټمونه د یو-کاروونکي عملیاتي سیسټمونو بېلګې دي.
## b. Multi-user operating systems || b. ملٹی یوزر آپریٹنگ سسٹم || b. ډېر-کاروونکي عملیاتي سیسټمونه
p Multi-user operating systems are those operating systems which allow multiple users to access a computer system at the same time. Time-sharing operating system is an example of multi-user operating systems as they enable multiple users to access a single computer by sharing of time. UNIX is an example of multi user operating system. || ملٹی یوزر آپریٹنگ سسٹم وہ آپریٹنگ سسٹم ہیں جو متعدد صارفین کو ایک ہی وقت میں کمپیوٹر سسٹم تک رسائی کی اجازت دیتے ہیں۔ ٹائم شیئرنگ آپریٹنگ سسٹم ملٹی یوزر آپریٹنگ سسٹمز کی مثال ہے کیونکہ یہ وقت کی شراکت کے ذریعے متعدد صارفین کو ایک ہی کمپیوٹر تک رسائی دیتے ہیں۔ UNIX ملٹی یوزر آپریٹنگ سسٹم کی ایک مثال ہے۔ || ډېر-کاروونکي عملیاتي سیسټمونه هغه دي چې ډېرو کاروونکو ته په یو وخت کمپیوټري سیسټم ته د لاسرسي اجازه ورکوي. وخت شریکونکی عملیاتي سیسټم د ډېر-کاروونکي عملیاتي سیسټمونو بېلګه ده، ځکه د وخت په شریکولو ډېرو کاروونکو ته یوه کمپیوټر ته لاسرسی ورکوي. UNIX د ډېر-کاروونکي عملیاتي سیسټم بېلګه ده.
