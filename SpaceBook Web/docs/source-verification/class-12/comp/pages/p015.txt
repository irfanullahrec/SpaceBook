## c. UNIX Operating System || c. یونکس آپریٹنگ سسٹم || c. د UNIX عملیاتي سیسټم
p UNIX is a multitasking and multi-user operating system that was developed by Ken Thompson, Dennis Ritchie and their group members at Bell Labs in 1969. It was first developed in assembly language. Later on, in 1973, it was re-developed in C language. This version of UNIX has facilitated its further development and support to other hardware. || UNIX ایک ملٹی ٹاسکنگ اور ملٹی یوزر آپریٹنگ سسٹم ہے جسے کین تھامسن، ڈینس رچی اور ان کے گروپ کے اراکین نے 1969ء میں بیل لیبز میں تیار کیا۔ اسے پہلے اسمبلی لینگویج میں تیار کیا گیا۔ بعد ازاں 1973ء میں اسے C لینگویج میں دوبارہ تیار کیا گیا۔ UNIX کے اس ورژن نے اس کی مزید ترقی اور دوسرے ہارڈویئر کی معاونت کو آسان بنایا۔ || UNIX یو څو-دندیز او ډېر-کاروونکي عملیاتي سیسټم دی چې کېن تامسن، ډېنس ریچي او د هغوی د ډلې غړو په ۱۹۶۹ز کې په بیل لابز کې جوړ کړ. لومړی په اسمبلي ژبه جوړ شو. وروسته په ۱۹۷۳ز کې په C ژبه بیا جوړ شو. د UNIX دې نسخې د هغه نورې ودې او د نورو هارډویرونو ملاتړ ته لاره اسانه کړه.
p UNIX operating systems also have a graphical user interface (GUI) similar to Microsoft Windows which provides an easy to use environment for naive users. || UNIX آپریٹنگ سسٹم میں بھی مائیکروسافٹ ونڈوز جیسا گرافیکل یوزر انٹرفیس (GUI) ہوتا ہے جو نئے صارفین کو استعمال میں آسان ماحول فراہم کرتا ہے۔ || د UNIX عملیاتي سیسټمونه هم د مایکروسافټ وینډوز په څېر ګرافیکي کاروونکي منځګړی (GUI) لري چې نوو کاروونکو ته د کارولو اسانه چاپېریال برابروي.
p Different versions of UNIX operating system have been developed so far which have some features in common. The most popular types of UNIX operating system are Sun Solaris, GNU/Linux and Mac OS X. || اب تک UNIX آپریٹنگ سسٹم کے مختلف ورژن تیار کیے جا چکے ہیں جن کی کچھ خصوصیات مشترک ہیں۔ UNIX آپریٹنگ سسٹم کی سب سے مقبول اقسام Sun Solaris، GNU/Linux اور Mac OS X ہیں۔ || تر اوسه د UNIX عملیاتي سیسټم بېلابېلې نسخې جوړې شوې چې ځینې ځانګړنې یې ګډې دي. د UNIX عملیاتي سیسټم تر ټولو مشهور ډولونه Sun Solaris، GNU/Linux او Mac OS X دي.
p When you want to open the UNIX terminal window, click on Application menu and then select Terminal icon. || جب آپ UNIX ٹرمینل ونڈو کھولنا چاہیں تو Application مینو پر کلک کریں اور پھر Terminal آئیکن منتخب کریں۔ || کله چې غواړئ د UNIX ټرمینل کړکۍ پرانیزئ، پر Application مینو کلیک وکړئ او بیا د Terminal نښه وټاکئ.
p After selecting Terminal from the menu, the UNIX Terminal window will open having % prompt as shown in figure 1.4. The user will enter the command in this prompt to execute. || مینو سے Terminal منتخب کرنے کے بعد UNIX ٹرمینل ونڈو % پرامپٹ کے ساتھ کھل جائے گی جیسا کہ شکل 1.4 میں دکھایا گیا ہے۔ صارف کمانڈ چلانے کے لیے اسے اس پرامپٹ میں درج کرے گا۔ || له مینو د Terminal له ټاکلو وروسته د UNIX ټرمینل کړکۍ د % پرامپټ سره پرانیستل کېږي لکه څنګه چې په ۱.۴ شکل کې ښودل شوي. کاروونکی به د چلولو لپاره امر په دې پرامپټ کې ولیکي.
