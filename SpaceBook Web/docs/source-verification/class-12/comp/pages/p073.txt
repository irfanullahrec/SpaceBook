## 3.1.4 Statement terminator (;) || 3.1.4 اسٹیٹمنٹ ٹرمینیٹر (;) || ۳.۱.۴ د بیان پای‌ټکی (;)
p Each C++ statement is terminated by a symbol named semicolon (;) which is called statement terminator. In C++, the separation between statements is specified with this ending semicolon (;) at the end of each statement. It does not matter to write more than one statement on a single line but matter if you do not separate them with semicolons. The use of each statement on a separate line is only to add clarity in the program. || ہر C++ بیان سیمی کولن (;) نامی علامت سے ختم ہوتا ہے جسے اسٹیٹمنٹ ٹرمینیٹر کہتے ہیں۔ C++ میں بیانات کے درمیان علیحدگی ہر بیان کے آخر میں اس سیمی کولن (;) سے ظاہر کی جاتی ہے۔ ایک لائن پر ایک سے زیادہ بیان لکھنے سے کوئی فرق نہیں پڑتا لیکن انھیں سیمی کولنز سے الگ نہ کرنے سے فرق پڑتا ہے۔ ہر بیان کو الگ لائن پر لکھنا صرف پروگرام میں وضاحت پیدا کرنے کے لیے ہے۔ || هر C++ بیان د سیمي‌کولن (;) په نوم یوې نښې پای ته رسېږي چې د بیان پای‌ټکی بلل کېږي. په C++ کې د بیانونو ترمنځ جلاوالی د هر بیان په پای کې په دې سیمي‌کولن (;) ښودل کېږي. په یوه کرښه له یوه زیات بیانونه لیکل توپیر نه کوي، خو که یې په سیمي‌کولنونو جلا نه کړئ، توپیر کوي. په جلا کرښه د هر بیان لیکل یوازې پروګرام ته روښانتیا ورکوي.
## 3.1.5 Comments and their syntax in C++ || 3.1.5 C++ میں تبصرے اور ان کا طریقۂ تحریر || ۳.۱.۵ په C++ کې تبصرې او د لیکلو بڼه یې
p Comments are parts of the source code ignored by the compiler. They do nothing but simply increase the readability and understandability of a program. Their purpose is only to allow the programmers to insert notes or descriptions within the source code. C++ supports two types of comments: || تبصرے سورس کوڈ کے وہ حصے ہیں جنھیں کمپائلر نظر انداز کرتا ہے۔ یہ کچھ نہیں کرتے بلکہ صرف پروگرام کو پڑھنے اور سمجھنے میں آسانی بڑھاتے ہیں۔ ان کا مقصد صرف پروگرامرز کو سورس کوڈ کے اندر نوٹس یا وضاحتیں شامل کرنے کی اجازت دینا ہے۔ C++ دو قسم کے تبصروں کو سپورٹ کرتی ہے: || تبصرې د سرچینې کوډ هغه برخې دي چې کمپایلر یې له پامه غورځوي. هېڅ نه کوي، یوازې د پروګرام د لوستلو او پوهېدو وړتیا زیاتوي. موخه یې یوازې دا ده چې پروګرام جوړوونکي د سرچینې کوډ دننه یادښتونه یا تشریحات ورګډ کړي. ## a. Single line comment || a. ایک لائن کا تبصرہ || a. یو-کرښیزه تبصره
p It is represented by the double slash symbol //. It discards everything from where the pair of slashes signs // is found up to the end of the same line. || اسے دوہری سلیش علامت // سے ظاہر کیا جاتا ہے۔ یہ جہاں سلیش کا جوڑا // ملے وہاں سے اسی لائن کے آخر تک ہر چیز کو نظر انداز کر دیتا ہے۔ || دا د دوه‌ګوني سلیش نښې // په مرسته ښودل کېږي. له هغه ځایه چې د سلیشونو جوړه // پیدا شي، د همغې کرښې تر پایه هر څه پرېږدي.
## b. Multiline comment || b. متعدد لائنوں کا تبصرہ || b. څو-کرښیزه تبصره
p These types of comments are represented by the symbols /* ....... */. It ignores everything between the /* characters and the first appearance of the */ characters, with the possibility of including more than one line. || اس قسم کے تبصرے علامات /* ....... */ سے ظاہر کیے جاتے ہیں۔ یہ /* حروف اور */ حروف کی پہلی موجودگی کے درمیان ہر چیز کو نظر انداز کرتا ہے، اور اس میں ایک سے زیادہ لائنیں شامل ہو سکتی ہیں۔ || دا ډول تبصرې د /* ....... */ نښو په مرسته ښودل کېږي. د /* تورو او د */ تورو د لومړي راتلو ترمنځ هر څه پرېږدي، او کېدای شي له یوې زیاتې کرښې پکې شاملې وي.
