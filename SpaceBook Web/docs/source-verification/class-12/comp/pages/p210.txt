## 6.2.2 Default arguments || 6.2.2 ڈیفالٹ آرگیومنٹس || ۶.۲.۲ ډیفالټ دلیلونه
p When declaring a function we can specify a default value for each of the last parameters. This value will be used if the corresponding argument is left blank when calling to the function. To do this, we simply have to use the assignment operator and a value for the arguments in the function declaration. If a value for that parameter is not passed when the function is called, the default value is used, but if a value is specified this default value is ignored and the passed value is used instead. || فنکشن ڈکلیئر کرتے وقت ہم آخری پیرامیٹرز میں سے ہر ایک کے لیے ڈیفالٹ قدر مقرر کر سکتے ہیں۔ یہ قدر اس وقت استعمال ہوگی جب فنکشن کال کرتے ہوئے متعلقہ آرگیومنٹ خالی چھوڑ دیا جائے۔ اس کے لیے ہمیں بس فنکشن ڈکلیریشن میں آرگیومنٹس کے لیے اسائنمنٹ آپریٹر اور ایک قدر استعمال کرنی ہوتی ہے۔ اگر فنکشن کال کرتے وقت اس پیرامیٹر کی قدر پاس نہ کی جائے تو ڈیفالٹ قدر استعمال ہوتی ہے، لیکن اگر قدر دی جائے تو یہ ڈیفالٹ قدر نظر انداز ہو جاتی ہے اور پاس کی گئی قدر استعمال ہوتی ہے۔ || د فنکشن د اعلان پر مهال کولی شو د وروستیو پاراميټرونو هر یوه ته ډیفالټ ارزښت وټاکو. دا ارزښت به هغه وخت وکارول شي چې د فنکشن د غوښتلو پر مهال اړوند دلیل تش پرېښودل شي. د دې لپاره یوازې باید د فنکشن په اعلان کې د دلیلونو لپاره د ګمارنې چلونکی او یو ارزښت وکاروو. که د فنکشن د غوښتلو پر مهال د هغه پاراميټر ارزښت ونه لېږدول شي، ډیفالټ ارزښت کارېږي، خو که ارزښت وټاکل شي دا ډیفالټ ارزښت له پامه غورځول کېږي او لېږدول شوی ارزښت کارېږي.
