qp 1 | Q.4 Define software development life cycle (SDLC). What are its objectives? || Q.4 سافٹ ویئر ڈویلپمنٹ لائف سائیکل (SDLC) کی تعریف کریں۔ اس کے مقاصد کیا ہیں؟ || Q.4 د سافټویر د پراختیا د ژوند دوره (SDLC) تعریف کړئ. موخې یې کومې دي؟
solution جواب
ss SDLC (Software/System Development Life Cycle) is a structured process of phases followed to plan, create, test, deploy and maintain an information system: planning/problem identification → feasibility study → analysis (requirements) → design → development (coding) → testing → deployment (implementation) → maintenance.
ss Objectives: to develop high-quality software that meets user requirements; to complete the project within time and budget; to give a clear plan with defined deliverables for each phase; to reduce risks and errors; to make management, control and documentation easier; and to make the system easy to maintain.
endsolution
qp 2 | Q.5 What is a system? Where exactly the testing activities begin in SDLC? || Q.5 نظام کیا ہے؟ SDLC میں جانچ کی سرگرمیاں ٹھیک کہاں سے شروع ہوتی ہیں؟ || Q.5 سیسټم څه دی؟ په SDLC کې د ازموینې فعالیتونه په سمه توګه له کومه ځایه پیلېږي؟
solution جواب
ss A system is a set of interrelated components (people, hardware, software, data and procedures) working together to achieve a common goal, e.g. a payroll system or a library management system.
ss Testing activities really begin early — test planning starts in the requirements/analysis phase (writing test cases from requirements) and design reviews, while actual execution of tests takes place after the coding phase in the testing phase (unit, integration, system and acceptance testing).
endsolution
qp 3 | Q.6 Why software development life cycle is important for the development of software? || Q.6 سافٹ ویئر کی تیاری کے لیے سافٹ ویئر ڈویلپمنٹ لائف سائیکل کیوں اہم ہے؟ || Q.6 د سافټویر د جوړولو لپاره د سافټویر د پراختیا د ژوند دوره ولې مهمه ده؟
sol جواب ## SDLC is important because it provides a clear, step-by-step framework so that nothing is missed; it helps understand user requirements before coding; it allows planning of time, cost and resources; each phase has defined outputs, making progress easy to monitor; errors are found early when they are cheaper to fix; it improves quality and documentation; and it makes the software easier to maintain and upgrade.
qp 4 | Q.7 Who are stakeholders of SDLC? Describe their responsibilities. || Q.7 SDLC کے اسٹیک ہولڈرز کون ہیں؟ ان کی ذمہ داریاں بیان کریں۔ || Q.7 د SDLC ښکېل اړخونه څوک دي؟ مسؤولیتونه یې بیان کړئ.
solution جواب
ss Stakeholders are people or organisations who are involved in or affected by the project.
ss Responsibilities: Customer/users — state requirements, give feedback and accept the system; Project manager — plans, schedules, budgets and controls the project and team; System analyst — studies the existing system, gathers requirements and designs the solution; Programmers/developers — write and document the code.
ss Software testers — test the software to find errors; Database administrator — designs and maintains the database; Network engineer — sets up hardware and networks; Management/sponsors — provide funds and approve decisions.
endsolution
qp 5 | Q.8 What is meant by the term software requirement? Differentiate between functional and non-functional requirements. || Q.8 سافٹ ویئر کی ضرورت سے کیا مراد ہے؟ فعالیاتی اور غیر فعالیاتی ضروریات میں فرق کریں۔ || Q.8 د سافټویر اړتیا څه معنا لري؟ د دندیزو او نادندیزو اړتیاوو ترمنځ توپیر وکړئ.
solution جواب
ss A software requirement is a description of a service the system must provide or a constraint under which it must operate — what users need from the software.
ss Functional requirements describe what the system should do — its functions and behaviour, e.g. 'the system shall calculate students' grades', 'users can log in'.
ss Non-functional requirements describe how well the system performs — quality attributes such as speed, reliability, security, usability, availability and maintainability, e.g. 'the page shall load within 2 seconds'.
endsolution
