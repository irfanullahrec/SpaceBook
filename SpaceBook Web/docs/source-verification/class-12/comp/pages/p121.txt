p In if construct, the statements in the body of if are executed only if the condition is true and nothing is executed if it is false. Sometimes the programmers need to execute some other part of a program even if the condition in if statement is false. For this purpose, if-else statement is used. || if ساخت میں if کے جسم کے بیانات صرف اسی وقت چلتے ہیں جب شرط درست ہو، اور غلط ہونے پر کچھ نہیں چلتا۔ بعض اوقات پروگرامرز کو if بیان کی شرط غلط ہونے پر بھی پروگرام کا کوئی اور حصہ چلانا ہوتا ہے۔ اس مقصد کے لیے if-else بیان استعمال ہوتا ہے۔ || په if جوړښت کې د if د بدنې بیانونه یوازې هغه وخت اجرا کېږي چې شرط true وي، او که false وي هېڅ نه اجرا کېږي. کله کله پروګرام جوړوونکي اړتیا لري چې د if بیان شرط false هم وي، د پروګرام بله برخه اجرا کړي. د دې موخې لپاره if-else بیان کارول کېږي.
