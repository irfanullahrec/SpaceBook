## 6.3.1 Definition || 6.3.1 تعریف || ۶.۳.۱ تعریف
p In programming languages, two or more variables or functions with the same name cannot be used in a single program or block of code. Function overloading is a feature of C++ that allows us to create multiple functions with the same name, so long as they have different number or types of parameters. || پروگرامنگ زبانوں میں ایک ہی نام کے دو یا زیادہ ویری ایبلز یا فنکشنز ایک پروگرام یا کوڈ کے بلاک میں استعمال نہیں ہو سکتے۔ فنکشن اوورلوڈنگ C++ کی ایک خصوصیت ہے جو ہمیں ایک ہی نام کے متعدد فنکشنز بنانے دیتی ہے، بشرطیکہ ان کے پیرامیٹرز کی تعداد یا اقسام مختلف ہوں۔ || په پروګرامي ژبو کې د یو نوم دوه یا ډېر متغیرونه یا فنکشنونه په یوه پروګرام یا د کوډ په یوه بلاک کې نه شي کارېدای. د فنکشن ډېرول د C++ ځانګړتیا ده چې موږ ته اجازه راکوي د یو نوم څو فنکشنونه جوړ کړو، تر هغه چې د پاراميټرونو شمېر یا ډولونه یې بېل وي.
