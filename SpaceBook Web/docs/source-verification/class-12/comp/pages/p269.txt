## 9.1.1 Types of files || 9.1.1 فائلز کی اقسام || ۹.۱.۱ د دوتنو ډولونه
p C++ divides files into two different types based on how they store data. These are: || C++ فائلز کو ڈیٹا محفوظ کرنے کے طریقے کی بنیاد پر دو مختلف اقسام میں تقسیم کرتی ہے۔ یہ ہیں: || C++ دوتنې د ډېټا د ساتلو د طریقې پر بنسټ په دوو بېلو ډولونو وېشي. دا دي:
- Text files || ٹیکسٹ فائلز || متني دوتنې
- Binary files || بائنری فائلز || باینري دوتنې
p Text files are those files that store data in text format which is readable by humans. Example of text file is the C++ source program which can be read by human. || ٹیکسٹ فائلز وہ فائلز ہیں جو ڈیٹا کو ٹیکسٹ شکل میں محفوظ کرتی ہیں جو انسان پڑھ سکتے ہیں۔ ٹیکسٹ فائل کی مثال C++ سورس پروگرام ہے جسے انسان پڑھ سکتا ہے۔ || متني دوتنې هغه دوتنې دي چې ډېټا په متني بڼه ساتي چې انسانان یې لوستلی شي. د متني دوتنې بېلګه د C++ سرچینه پروګرام دی چې انسان یې لوستلی شي.
p Binary files store data in binary format which is not readable by the humans but readable by the computers. Binary files are directly processed by the computers. Binary files are normally used to store large data files. They take less space to store data as compared to text files. For example, an integer having length of six digits will take six bytes to accommodate in a text file while in binary files they will take only two bytes. The best example of binary file is the object file of a C++ source file that is generated by the compiler of C++. || بائنری فائلز ڈیٹا کو بائنری شکل میں محفوظ کرتی ہیں جو انسان نہیں پڑھ سکتے لیکن کمپیوٹر پڑھ سکتے ہیں۔ بائنری فائلز پر کمپیوٹر براہِ راست عمل کرتے ہیں۔ بائنری فائلز عموماً بڑی ڈیٹا فائلز محفوظ کرنے کے لیے استعمال ہوتی ہیں۔ یہ ٹیکسٹ فائلز کے مقابلے میں ڈیٹا محفوظ کرنے کے لیے کم جگہ لیتی ہیں۔ مثلاً چھ ہندسوں والا صحیح عدد ٹیکسٹ فائل میں چھ بائٹس لے گا جبکہ بائنری فائلز میں صرف دو بائٹس۔ بائنری فائل کی بہترین مثال C++ سورس فائل کی آبجیکٹ فائل ہے جو C++ کا کمپائلر بناتا ہے۔ || باینري دوتنې ډېټا په باینري بڼه ساتي چې انسانان یې نه شي لوستلی خو کمپیوټرونه یې لوستلی شي. پر باینري دوتنو کمپیوټرونه مستقیم پروسس کوي. باینري دوتنې عموماً د لویو ډېټا دوتنو د ساتلو لپاره کارېږي. د متني دوتنو په پرتله د ډېټا د ساتلو لپاره لږ ځای نیسي. د بېلګې په توګه د شپږو عددي رقمونو اوږدوالي صحیح عدد په متني دوتنه کې شپږ بایټه نیسي، په داسې حال کې چې په باینري دوتنو کې یوازې دوه بایټه نیسي. د باینري دوتنې غوره بېلګه د C++ سرچینه دوتنې شي دوتنه (object file) ده چې د C++ کمپایلر یې جوړوي.
