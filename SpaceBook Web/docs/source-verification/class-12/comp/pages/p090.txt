p cin object stops reading characters when it gets any blank space character, so in this case of entering strings, the object will get only one word. For example, if one wants to input a sentence using cin object, it will only accept the first word of the sentence and will discard the rest of the words. || cin آبجیکٹ جب کوئی خالی جگہ (space) پاتا ہے تو حروف پڑھنا بند کر دیتا ہے، اس لیے اسٹرنگز داخل کرنے کی اس صورت میں آبجیکٹ صرف ایک لفظ حاصل کرے گا۔ مثال کے طور پر اگر کوئی cin آبجیکٹ کے ذریعے جملہ داخل کرنا چاہے تو یہ صرف جملے کا پہلا لفظ قبول کرے گا اور باقی الفاظ ترک کر دے گا۔ || cin شی کله چې کومه تشه (space) ومومي، د تورو لوستل بندوي، نو د تارونو د لیکلو په دې حالت کې شی یوازې یوه کلمه ترلاسه کوي. د بېلګې په توګه که څوک وغواړي د cin په مرسته یوه جمله ولیکي، یوازې د جملې لومړۍ کلمه مني او پاتې کلمې پرېږدي.
