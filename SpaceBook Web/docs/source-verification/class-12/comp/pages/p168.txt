## b. Initializing two dimensional arrays || b. دو جہتی ایریز کو ابتدائی قدر دینا || b. دوه-بعدي لړیو ته لومړنی ارزښت ورکول
p To initialize a two-dimensional array, it is easiest to use nested braces, with each set of numbers representing a row: || دو جہتی ایرے کو ابتدائی قدر دینے کے لیے نیسٹڈ بریسز استعمال کرنا سب سے آسان ہے، جن میں اعداد کا ہر مجموعہ ایک قطار ظاہر کرتا ہے: || دوه-بعدي لړۍ ته د لومړني ارزښت ورکولو لپاره ځالې لوړ قوسونه کارول تر ټولو اسانه دي، چې د عددونو هره ټولګه یو قطار ښيي:
p // two dimensional array initialization int anArray[3][5] = { { 1, 2, 3, 4, 5 }, // row 0 { 6, 7, 8, 9, 10 }, // row 1 { 11, 12, 13, 14, 15 } // row 2 }; || // two dimensional array initialization int anArray[3][5] = { { 1, 2, 3, 4, 5 }, // row 0 { 6, 7, 8, 9, 10 }, // row 1 { 11, 12, 13, 14, 15 } // row 2 }; || // two dimensional array initialization int anArray[3][5] = { { 1, 2, 3, 4, 5 }, // row 0 { 6, 7, 8, 9, 10 }, // row 1 { 11, 12, 13, 14, 15 } // row 2 };
p If we want to initialize a two-dimensional array to 0 then it can be done as follows: || اگر ہم دو جہتی ایرے کو 0 ابتدائی قدر دینا چاہیں تو یوں کیا جا سکتا ہے: || که وغواړو دوه-بعدي لړۍ ته 0 لومړنی ارزښت ورکړو، داسې کېدای شي:
p int anArray[3][5] = { 0 }; || int anArray[3][5] = { 0 }; || int anArray[3][5] = { 0 };
## 5.2 .3 Accessing and writing at an index in a two dimensional array || 5.2.3 دو جہتی ایرے میں کسی انڈیکس پر رسائی اور لکھنا || ۵.۲.۳ په دوه-بعدي لړۍ کې پر یوه شاخص لاسرسی او لیکل
p To operate on the elements of two dimensional arrays, the elements should be first accessed and then updated. Writing at an index of an array is also done when a new two dimensional array is declared. Accessing and writing at an index of a two dimensional array is similar to one dimensional array. The following sections discuss them with the help of examples. || دو جہتی ایریز کے عناصر پر عمل کرنے کے لیے پہلے عناصر تک رسائی اور پھر انھیں تازہ کرنا چاہیے۔ نیا دو جہتی ایرے ڈکلیئر کرتے وقت بھی ایرے کے کسی انڈیکس پر لکھا جاتا ہے۔ دو جہتی ایرے کے کسی انڈیکس پر رسائی اور لکھنا یک جہتی ایرے جیسا ہے۔ درج ذیل حصے مثالوں کی مدد سے ان پر بات کرتے ہیں۔ || د دوه-بعدي لړیو پر عناصرو د عملیې لپاره، لومړی باید عناصرو ته لاسرسی وشي او بیا تازه شي. د نوې دوه-بعدي لړۍ د اعلان پر مهال هم د لړۍ پر یوه شاخص لیکل کېږي. د دوه-بعدي لړۍ پر یوه شاخص لاسرسی او لیکل د یو-بعدي لړۍ په څېر دي. لاندې برخې د بېلګو په مرسته دا څېړي.
## a. Accessing two dimensional arrays || a. دو جہتی ایریز تک رسائی || a. دوه-بعدي لړیو ته لاسرسی
p Accessing two dimensional arrays need two indices, one for the row and the other for the column. For example, if we have an array anArray[3][5] and want to access an element at second row and third column. Then it can be written as: || دو جہتی ایریز تک رسائی کے لیے دو انڈیسز درکار ہیں، ایک قطار کے لیے اور دوسرا کالم کے لیے۔ مثلاً اگر ہمارے پاس ایرے anArray[3][5] ہو اور ہم دوسری قطار اور تیسرے کالم کے عنصر تک رسائی چاہیں تو اسے یوں لکھا جا سکتا ہے: || دوه-بعدي لړیو ته لاسرسی دوو شاخصونو ته اړتیا لري، یو د قطار لپاره او بل د ستنې لپاره. د بېلګې په توګه که anArray[3][5] لړۍ ولرو او د دویم قطار او درېیمې ستنې عنصر ته لاسرسی وغواړو، داسې لیکل کېدای شي:
p anArray[1][2]; || anArray[1][2]; || anArray[1][2];
