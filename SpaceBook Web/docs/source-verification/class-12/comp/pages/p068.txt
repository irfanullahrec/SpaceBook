p This program prints the string “Hello, world!” to the screen using cout. However, this program never defines cout, so how does the compiler know about the object cout? The answer for this is that cout has been declared in a header file called “iostream”. When the line #include <iostream.h> is used in the program, the compiler locates and read all the declarations from a header file named “iostream”. || یہ پروگرام cout کے ذریعے اسٹرنگ ’’Hello, world!‘‘ اسکرین پر پرنٹ کرتا ہے۔ تاہم یہ پروگرام کبھی cout کی تعریف نہیں کرتا، تو کمپائلر کو آبجیکٹ cout کا کیسے پتہ چلتا ہے؟ اس کا جواب یہ ہے کہ cout کا اعلان ’’iostream‘‘ نامی ہیڈر فائل میں کیا گیا ہے۔ جب پروگرام میں #include <iostream.h> لائن استعمال ہوتی ہے تو کمپائلر ’’iostream‘‘ نامی ہیڈر فائل کو تلاش کر کے اس کے تمام اعلانات پڑھتا ہے۔ || دا پروګرام د cout په مرسته "Hello, world!" تار پر پرده چاپوي. خو دا پروګرام هېڅکله cout نه تعریفوي، نو کمپایلر د cout شي څخه څنګه خبرېږي؟ ځواب یې دا دی چې cout په "iostream" نومي سرلیک فایل کې اعلان شوی. کله چې په پروګرام کې د #include <iostream.h> کرښه وکارول شي، کمپایلر "iostream" نومی سرلیک فایل پیدا کوي او ټول اعلانونه یې لولي.
