qp 1 | Q.4 Define the term pointer. Describe the advantages of using pointer variables. || Q.4 پوائنٹر کی اصطلاح کی تعریف کریں۔ پوائنٹر ویری ایبلز کے استعمال کے فوائد بیان کریں۔ || Q.4 د پوائنټر اصطلاح تعریف کړئ. د پوائنټر متغیرونو د کارونې ګټې بیان کړئ.
solution جواب
ss A pointer is a variable that holds the memory address of another variable of a given type, declared as type *name; e.g. int *p = &x;
ss Advantages: allow direct access and manipulation of memory; let functions change the caller's variables (pass by address) and return more than one value; make array and string handling efficient; are required for dynamic memory allocation (new/delete); allow building data structures such as linked lists and trees; can save memory and increase speed.
endsolution
qp 2 | Q.5 What is the difference between the dereference operator * and reference operator &? Explain with the help of some lines of code. || Q.5 ڈی ریفرنس آپریٹر * اور حوالہ آپریٹر & میں کیا فرق ہے؟ کوڈ کی چند لائنوں کی مدد سے وضاحت کریں۔ || Q.5 د حوالې‌لرې کولو چلونکي * او د حوالې چلونکي & ترمنځ څه توپیر دی؟ د کوډ د څو کرښو په مرسته یې تشریح کړئ.
solution جواب
ss The reference (address-of) operator & gives the memory address of a variable; the dereference operator * gives the value stored at the address held by a pointer.
ss int x = 25; int *p = &x; // & : p gets the address of x cout << p; // prints an address, e.g. 0x7ffd5c cout << *p; // * : prints 25, the value at that address *p = 40; // changes x to 40 through the pointer
endsolution
qp 3 | Q.6 What is meant by the term pointer initialization? Write a simple program to illustrate this concept. || Q.6 پوائنٹر انیشیلائزیشن کی اصطلاح سے کیا مراد ہے؟ اس تصور کی وضاحت کے لیے ایک سادہ پروگرام لکھیں۔ || Q.6 د پوائنټر د لومړني ارزښت ورکولو اصطلاح څه معنا لري؟ د دې مفهوم د ښودلو لپاره یو ساده پروګرام ولیکئ.
solution جواب
ss Pointer initialization means assigning an address to a pointer at the time of its declaration, so it does not hold a garbage address.
ss #include <iostream> using namespace std; int main() { int num = 50; int *ptr = &num; // pointer initialized with the address of num cout << "Value of num = " << num << endl; cout << "Address of num = " << ptr << endl; cout << "Value through pointer = " << *ptr << endl; return 0; }
endsolution
qp 4 | Q.7 How the declaration of a pointer variable is different from the declaration of a variable. || Q.7 پوائنٹر ویری ایبل کی ڈکلیریشن عام ویری ایبل کی ڈکلیریشن سے کیسے مختلف ہے۔ || Q.7 د پوائنټر متغیر اعلان د یوه متغیر له اعلان څخه څنګه توپیر لري.
solution جواب
ss An ordinary variable declaration reserves memory to store a data value: int a; — a holds an integer value.
ss A pointer declaration uses an asterisk (*) before the name: int *p; — p holds the address of an integer variable, not an integer value. The data type of a pointer is the type of variable it points to, and it is given an address with &: p = &a;
endsolution
