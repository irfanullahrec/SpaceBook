p Floating point constants: The numeric constants having a decimal point are called floating point constants e.g. 33.55 and -0.22 etc. These constants can be either positive signed or negative signed. These constants can also be represented in its exponential form by the use of alphabet ‘e’ or ‘E’ to denote the exponents of the numbers. For example. || فلوٹنگ پوائنٹ کانسٹنٹس: اعشاریہ والے عددی کانسٹنٹس فلوٹنگ پوائنٹ کانسٹنٹس کہلاتے ہیں، مثلاً 33.55 اور -0.22 وغیرہ۔ یہ کانسٹنٹس مثبت یا منفی علامت والے ہو سکتے ہیں۔ ان کانسٹنٹس کو اعداد کی قوت (exponent) ظاہر کرنے کے لیے حرف ‘e’ یا ‘E’ کے استعمال سے قوت نما شکل میں بھی ظاہر کیا جا سکتا ہے۔ مثلاً: || اعشاري ثابتونه: هغه شمېریز ثابتونه چې اعشاري ټکی لري، اعشاري (floating point) ثابتونه بلل کېږي، لکه 33.55 او -0.22 او نور. دا ثابتونه کېدای شي مثبت یا منفي نښه ولري. دا ثابتونه د عددونو د توان (exponent) د ښودلو لپاره د ‘e’ یا ‘E’ توري په کارولو په توانیزه بڼه هم ښودل کېدای شي. د بېلګې په توګه:
p 9010E10 7810.11E-11 -10.990e8 -1.001e-1 || 9010E10 7810.11E-11 -10.990e8 -1.001e-1 || 9010E10 7810.11E-11 -10.990e8 -1.001e-1
p Hexadecimal constants: The constants represented in hexadecimal number system are called hexadecimal constants. To represent a hexadecimal constant, begin the constant with 0x or 0X, followed by a sequence of digits in the range 0 through 9 and a through f (or A through F). The digits a to f (or A to F) represent values in the range 10 through 15. For example. || ہیکسا ڈیسیمل کانسٹنٹس: ہیکسا ڈیسیمل عددی نظام میں ظاہر کیے گئے کانسٹنٹس ہیکسا ڈیسیمل کانسٹنٹس کہلاتے ہیں۔ ہیکسا ڈیسیمل کانسٹنٹ ظاہر کرنے کے لیے اسے 0x یا 0X سے شروع کریں، اس کے بعد 0 سے 9 اور a سے f (یا A سے F) کے اعداد کا سلسلہ۔ اعداد a سے f (یا A سے F) 10 سے 15 تک کی قدریں ظاہر کرتے ہیں۔ مثلاً: || شپاړسیز ثابتونه: هغه ثابتونه چې په شپاړسیز عددي سیسټم کې ښودل کېږي، شپاړسیز ثابتونه بلل کېږي. د شپاړسیز ثابت د ښودلو لپاره یې په 0x یا 0X پیل کړئ، وروسته د 0 تر 9 او a تر f (یا A تر F) د عددونو لړۍ. عددونه a تر f (یا A تر F) له ۱۰ تر ۱۵ پورې ارزښتونه ښيي. د بېلګې په توګه:
p int i = 0x3fff; // Hexadecimal constant int j = 0X3FFF; // Hexadecimal constant || int i = 0x3fff; // Hexadecimal constant int j = 0X3FFF; // Hexadecimal constant || int i = 0x3fff; // Hexadecimal constant int j = 0X3FFF; // Hexadecimal constant
p Octal constants: The representation of constants in octal number system is called octal constants. To specify an octal constant, begin the specification with 0, followed by a sequence of digits in the range 0 through 7. Consider the following example: || آکٹل کانسٹنٹس: آکٹل عددی نظام میں کانسٹنٹس کی نمائندگی آکٹل کانسٹنٹس کہلاتی ہے۔ آکٹل کانسٹنٹ متعین کرنے کے لیے اسے 0 سے شروع کریں، اس کے بعد 0 سے 7 تک کے اعداد کا سلسلہ۔ درج ذیل مثال پر غور کریں: || اتیز ثابتونه: په اتیز عددي سیسټم کې د ثابتونو ښودنه اتیز ثابتونه بلل کېږي. د اتیز ثابت د ټاکلو لپاره یې په 0 پیل کړئ، وروسته د 0 تر 7 پورې د عددونو لړۍ. لاندې بېلګې ته پام وکړئ:
p int i = 0377; // Octal constant int j = 0397; // Error: 9 is not an octal digit || int i = 0377; // Octal constant int j = 0397; // Error: 9 is not an octal digit || int i = 0377; // Octal constant int j = 0397; // Error: 9 is not an octal digit
p Octal numbers are integer numbers of base 8 and their digits are 0 to 7. || آکٹل اعداد 8 کی اساس والے صحیح اعداد ہیں اور ان کے اعداد 0 سے 7 تک ہیں۔ || اتیز عددونه د ۸ اساس صحیح عددونه دي او رقمونه یې له 0 تر 7 دي.
