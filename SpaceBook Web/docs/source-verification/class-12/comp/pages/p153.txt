qp 6 | Q.9 Write a C++ program to find out the area of a triangle and if any side is zero then display the message “There is no triangle”. || Q.9 مثلث کا رقبہ معلوم کرنے کا C++ پروگرام لکھیں اور اگر کوئی ضلع صفر ہو تو پیغام ’’There is no triangle‘‘ دکھائیں۔ || Q.9 یو C++ پروګرام ولیکئ چې د مثلث مساحت پیدا کړي او که کومه ضلع صفر وي، "There is no triangle" پیغام وښيي.
solution جواب
ss #include <iostream> #include <cmath> using namespace std; int main() { float a, b, c, s, area; cout << "Enter the three sides of the triangle: "; cin >> a >> b >> c; if (a == 0 {{OR}} b == 0 {{OR}} c == 0) cout << "There is no triangle" << endl; else { s = (a + b + c) / 2; area = sqrt(s * (s - a) * (s - b) * (s - c)); cout << "Area of triangle = " << area << endl; } return 0; }
ss Heron's formula is used: area = √(s(s − a)(s − b)(s − c)), where s is half the perimeter.
endsolution
