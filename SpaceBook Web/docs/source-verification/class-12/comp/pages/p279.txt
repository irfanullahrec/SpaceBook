p Input streams take any sequence of bytes from an input device such as a keyboard, a file, or a network, while output streams are used to hold output for a particular data consumer, such as a monitor, a file, or a printer. When writing data to an output device, the device may not be ready to accept that data e.g. the printer may still be warming up when the program writes data to its output stream.
