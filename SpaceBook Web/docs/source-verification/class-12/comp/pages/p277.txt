## a. bof() – beginning-of-file || a. bof() – فائل کا آغاز || a. bof() – د دوتنې پیل
p The bof() is a pointer which returns true if the current position of the pointer is at the beginning of the input file stream, and false otherwise. It means that it tells the compiler whether the cursor is at the beginning of file or not. || bof() ایک پوائنٹر ہے جو true واپس کرتا ہے اگر پوائنٹر کا موجودہ مقام ان پٹ فائل اسٹریم کے آغاز پر ہو، ورنہ false۔ یعنی یہ کمپائلر کو بتاتا ہے کہ کرسر فائل کے آغاز پر ہے یا نہیں۔ || bof() یو پوائنټر دی چې true بېرته ورکوي که د پوائنټر اوسنی ځای د ننوتنې دوتنې بهیر په پیل کې وي، او که نه false. یعنې کمپایلر ته وايي چې کرسر د دوتنې په پیل کې دی که نه.

## b. eof() – end-of-file || b. eof() – فائل کا اختتام || b. eof() – د دوتنې پای
p The eof() is a pointer which returns true when there are no more data to be read from an input file stream, and false otherwise. It means that this function checks whether control has reached to the end of file or not. This function is very useful in the case when we do not know the exact number of records in a file. || eof() ایک پوائنٹر ہے جو true واپس کرتا ہے جب ان پٹ فائل اسٹریم سے پڑھنے کے لیے مزید ڈیٹا نہ ہو، ورنہ false۔ یعنی یہ فنکشن جانچتا ہے کہ کنٹرول فائل کے اختتام تک پہنچ گیا ہے یا نہیں۔ یہ فنکشن اس صورت میں بہت مفید ہے جب ہمیں فائل میں ریکارڈز کی درست تعداد معلوم نہ ہو۔ || eof() یو پوائنټر دی چې true بېرته ورکوي کله چې د ننوتنې دوتنې له بهیر د لوستلو لپاره نور ډېټا پاتې نه وي، او که نه false. یعنې دا فنکشن ګوري چې کنټرول د دوتنې پای ته رسېدلی که نه. دا فنکشن هغه وخت ډېر ګټور دی چې په دوتنه کې د ریکارډونو دقیق شمېر ونه پېژنو.
p Rules for using eof( ) || eof( ) کے استعمال کے اصول || د eof( ) د کارونې قواعد
- Always test for the end-of-file condition before processing data. || ڈیٹا پر عمل کرنے سے پہلے ہمیشہ فائل کے اختتام کی شرط جانچیں۔ || د ډېټا له پروسس مخکې تل د دوتنې د پای شرط وازمویئ.
