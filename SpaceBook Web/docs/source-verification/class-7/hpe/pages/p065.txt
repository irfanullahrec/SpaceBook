p یہ صفحہ پاکستان کے قومی ترانے کے لیے مخصوص ہے۔ اس میں ترانے کے تین بند چھپے ہیں جن میں سرزمین، قوم اور پرچم کی شان بیان کی گئی ہے۔ || This page is set aside for the national anthem of Pakistan.
