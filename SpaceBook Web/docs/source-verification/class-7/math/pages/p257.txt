### Class Boundaries || جماعتی سرحدیں || د ټولګي سرحدونه
p Class boundaries are the midpoints between the upper class limit of a class and the lower class limit of the next class in the sequence. Each class has an upper and lower class boundary. || جماعتی سرحدیں کسی جماعت کی بالائی جماعتی حد اور ترتیب میں اگلی جماعت کی زیریں جماعتی حد کے درمیان وسطی نقاط ہیں۔ ہر جماعت کی ایک بالائی اور ایک زیریں جماعتی سرحد ہوتی ہے۔ || د ټولګي سرحدونه د یوه ټولګي د پورتنۍ پولې او په لړۍ کې د بل ټولګي د ښکتنۍ پولې ترمنځ منځني ټکي دي. هر ټولګی یو پورتنی او یو ښکتنی سرحد لري.
p The following example will explain this. || درج ذیل مثال اس کی وضاحت کرے گی۔ || لاندې بېلګه به دا تشریح کړي.
example 6 | Let's observe the class boundaries for the given class intervals. || آئیے دیے گئے جماعتی وقفوں کی جماعتی سرحدوں کا مشاہدہ کریں۔ || راځئ د ورکړل شویو واټنونو د ټولګي سرحدونه وګورو.
p **Solution:** Here, the mid point of 57 and 58 is $\frac{58-57}{2} = 0.5$, so by adding and subtracting 0.5, we get the class boundaries. || **حل:** یہاں 57 اور 58 کا وسطی نقطہ $\frac{58-57}{2} = 0.5$ ہے، لہٰذا 0.5 جمع اور تفریق کر کے ہمیں جماعتی سرحدیں ملتی ہیں۔ || **حل:** دلته د 57 او 58 منځنی ټکی $\frac{58-57}{2} = 0.5$ دی، نو د 0.5 په جمع او تفریق سره د ټولګي سرحدونه ترلاسه کوو.
