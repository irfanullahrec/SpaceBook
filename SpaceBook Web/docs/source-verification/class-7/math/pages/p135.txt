# 8.1 Solving Linear Equations || 8.1 خطی مساواتیں حل کرنا || 8.1 د خطي معادلو حل
p A linear equation in one variable is an open sentence. The process to find the value of the involved variable which makes the linear equation true is known as its solution. The value of the variable which satisfies the equation is known as the root or solution of the equation. When solving an equation, we actually look for the value of the variable that satisfies the equation and makes it true. During this we try to separate the variable alone on one side of the equation and gather the remaining terms/constants/coefficients on the other side. This process of separating the variable on one side of the equation is called "isolation of variable". Let's recall some properties of equality. || ایک متغیر میں خطی مساوات ایک کھلا جملہ ہے۔ شامل متغیر کی وہ قیمت معلوم کرنے کا عمل جو خطی مساوات کو درست بنائے، اس کا حل کہلاتا ہے۔ متغیر کی وہ قیمت جو مساوات کو پورا کرے، مساوات کا جذر یا حل کہلاتی ہے۔ مساوات حل کرتے وقت ہم دراصل متغیر کی وہ قیمت تلاش کرتے ہیں جو مساوات کو پورا کرے اور اسے درست بنائے۔ اس دوران ہم متغیر کو مساوات کی ایک طرف اکیلا کرنے اور باقی ارکان/مستقلات/عددی سروں کو دوسری طرف جمع کرنے کی کوشش کرتے ہیں۔ متغیر کو مساوات کی ایک طرف الگ کرنے کے اس عمل کو "متغیر کو علیحدہ کرنا" کہتے ہیں۔ آئیے مساوات کی کچھ خصوصیات یاد کریں۔ || په یوه متحول کې خطي معادله یوه خلاصه جمله ده. د شامل متحول د هغه ارزښت د موندلو بهیر چې خطي معادله سمه کړي، د هغې حل بلل کېږي. د متحول هغه ارزښت چې معادله پوره کړي، د معادلې جذر یا حل بلل کېږي. د معادلې د حل پر مهال په حقیقت کې د متحول هغه ارزښت لټوو چې معادله پوره او سمه کړي. په دې کې هڅه کوو چې متحول د معادلې په یوه خوا کې یوازې کړو او پاتې حدونه/ثابت/ضریبونه بلې خوا ته راټول کړو. د معادلې په یوه خوا کې د متحول د جلا کولو دې بهیر ته "د متحول جلا کول" ویل کېږي. راځئ د برابرۍ ځینې ځانګړتیاوې را یاد کړو.

### Addition Property of Equality: || مساوات کی جمعی خاصیت: || د برابرۍ جمعي ځانګړتیا:
p If the same number is added to both sides of an equation, the equation still remains equal. In general, for all numbers x, y, and z: If $x = y$, then $x + z = y + z$. || اگر مساوات کے دونوں اطراف میں ایک ہی عدد جمع کیا جائے تو مساوات برابر رہتی ہے۔ عام طور پر تمام اعداد x، y اور z کے لیے: اگر $x = y$ تو $x + z = y + z$۔ || که د معادلې دواړو خواوو ته یو عدد ور زیات شي، معادله برابره پاتې کېږي. په عمومي ډول د ټولو عددونو x، y او z لپاره: که $x = y$ وي، نو $x + z = y + z$.
### Subtraction Property of Equality: || مساوات کی تفریقی خاصیت: || د برابرۍ تفریقي ځانګړتیا:
p If the same number is subtracted from both sides of an equation, the equation still remains equal. In general, for all numbers x, y, and z: If $x = y$, then $x - z = y - z$. || اگر مساوات کے دونوں اطراف سے ایک ہی عدد تفریق کیا جائے تو مساوات برابر رہتی ہے۔ عام طور پر تمام اعداد x، y اور z کے لیے: اگر $x = y$ تو $x - z = y - z$۔ || که د معادلې له دواړو خواوو یو عدد تفریق شي، معادله برابره پاتې کېږي. په عمومي ډول د ټولو عددونو x، y او z لپاره: که $x = y$ وي، نو $x - z = y - z$.
