### Equivalent sets || ہم قدر سیٹ || معادل سېټونه
p If two sets contain the same number of elements they are said to be equivalent sets. It's not necessary for all elements of equivalent sets to be the same. They just need to be the same in number. In other words, if any set A is equivalent to set B, then their cardinality is the same. i.e. n(A) = n(B). || اگر دو سیٹوں میں ارکان کی تعداد برابر ہو تو انہیں ہم قدر سیٹ کہتے ہیں۔ ہم قدر سیٹوں کے تمام ارکان کا ایک جیسا ہونا ضروری نہیں۔ صرف ان کی تعداد برابر ہونی چاہیے۔ دوسرے الفاظ میں اگر کوئی سیٹ A سیٹ B کے ہم قدر ہو تو ان کی عددی قدر (cardinality) برابر ہوتی ہے۔ یعنی n(A) = n(B)۔ || که دوه سېټونه برابر شمېر غړي ولري، معادل سېټونه بلل کېږي. اړینه نه ده چې د معادلو سېټونو ټول غړي یو شان وي. یوازې باید په شمېر کې برابر وي. په بل عبارت، که سېټ A له سېټ B سره معادل وي، د هغوی عددي ارزښت (cardinality) یو شان دی. یعنې n(A) = n(B).
p **Examples:** || **مثالیں:** || **بېلګې:**
m i) A = {a, b, c, d, e}, B = {Monday, Tuesday, Wednesday, Thursday, Friday}
p We can see that A and B have completely different elements but they have the same number of elements, which is 5. So set A and set B are equivalent sets as n(A)=n(B). We use the symbol "~" for equivalent sets. Here A ~ B. We read it as set A is equivalent to set B. || ہم دیکھ سکتے ہیں کہ A اور B کے ارکان بالکل مختلف ہیں لیکن ان کے ارکان کی تعداد برابر یعنی 5 ہے۔ لہٰذا سیٹ A اور سیٹ B ہم قدر سیٹ ہیں کیونکہ n(A)=n(B)۔ ہم ہم قدر سیٹوں کے لیے علامت "~" استعمال کرتے ہیں۔ یہاں A ~ B۔ ہم اسے یوں پڑھتے ہیں: سیٹ A، سیٹ B کے ہم قدر ہے۔ || لیدلی شو چې A او B بشپړ بېل غړي لري خو د غړو شمېر یې یو شان یعنې 5 دی. نو سېټ A او سېټ B معادل سېټونه دي ځکه n(A)=n(B). د معادلو سېټونو لپاره د "~" نښه کاروو. دلته A ~ B. داسې یې لولو: سېټ A له سېټ B سره معادل دی.
m ii) R = {sweater, shirt, cap, pants}, S = {oranges, bananas, dates}
p These are not equivalent sets because they have a different number of elements i.e. n(R)≠n(S). || یہ ہم قدر سیٹ نہیں کیونکہ ان کے ارکان کی تعداد مختلف ہے یعنی n(R)≠n(S)۔ || دا معادل سېټونه نه دي ځکه چې د غړو شمېر یې توپیر لري یعنې n(R)≠n(S).

### Disjoint Sets and Overlapping Sets || غیر مشترک اور مشترک سیٹ || جلا سېټونه او ګډ سېټونه
p **a) Disjoint Sets** || **a) غیر مشترک سیٹ** || **a) جلا سېټونه**
p Two sets are said to be disjoint, if they have no common elements. In other words, if the intersection of any two sets is an empty set, they are known as disjoint sets. For example, we consider two sets A = {1, 2, 3} and B = {5, 7, 9}. || دو سیٹوں کو غیر مشترک کہتے ہیں اگر ان میں کوئی مشترک رکن نہ ہو۔ دوسرے الفاظ میں اگر کسی دو سیٹوں کا انٹرسیکشن خالی سیٹ ہو تو انہیں غیر مشترک سیٹ کہتے ہیں۔ مثلاً ہم دو سیٹ A = {1, 2, 3} اور B = {5, 7, 9} لیتے ہیں۔ || دوه سېټونه جلا بلل کېږي که هېڅ ګډ غړی ونه لري. په بل عبارت، که د هرو دوو سېټونو تقاطع تش سېټ وي، جلا سېټونه بلل کېږي. د بېلګې په توګه دوه سېټونه A = {1, 2, 3} او B = {5, 7, 9} په پام کې نیسو.
