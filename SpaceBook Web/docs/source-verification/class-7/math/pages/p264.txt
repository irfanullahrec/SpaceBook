## 13.6.3 Median || 13.6.3 وسطانیہ || 13.6.3 منځنی (میډین)
p "Median is the value which divides a given data into two halves when the data is written in ascending order". To find the median, arrange the values of the given data in ascending order. If the number of values of the data is odd, then the middle value is the median value. If the number of values of the data is even, then the median will be the arithmetic mean of the two middle values. || "وسطانیہ وہ قیمت ہے جو ڈیٹا کو صعودی ترتیب میں لکھنے پر اسے دو برابر حصوں میں تقسیم کرتی ہے"۔ وسطانیہ معلوم کرنے کے لیے دیے گئے ڈیٹا کی قیمتوں کو صعودی ترتیب میں رکھیں۔ اگر ڈیٹا کی قیمتوں کی تعداد طاق ہو تو درمیانی قیمت وسطانیہ ہے۔ اگر قیمتوں کی تعداد جفت ہو تو وسطانیہ دو درمیانی قیمتوں کا حسابی اوسط ہوگا۔ || "منځنی هغه ارزښت دی چې کله معلومات په صعودي ترتیب ولیکل شي، هغه په دوو نیمو برخو وېشي". د منځني پیدا کولو لپاره د ورکړل شویو معلوماتو ارزښتونه په صعودي ترتیب کړئ. که د ارزښتونو شمېر طاق وي، منځنی ارزښت میډین دی. که د ارزښتونو شمېر جفت وي، میډین به د دوو منځنیو ارزښتونو حسابي اوسط وي.
