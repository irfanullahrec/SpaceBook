### Transposition Method: || منتقلی کا طریقہ: || د لېږد طریقه:
p Let's learn about the transposition method of solving linear equations in one variable by observing the following examples. || آئیے درج ذیل مثالوں کا مشاہدہ کر کے ایک متغیر میں خطی مساواتیں حل کرنے کا منتقلی کا طریقہ سیکھیں۔ || راځئ د لاندې بېلګو په کتلو په یوه متحول کې د خطي معادلو د حل د لېږد طریقه زده کړو.
example 1 | Solve: $x + 7 = 12$ || حل کریں: $x + 7 = 12$ || حل کړئ: $x + 7 = 12$
p **Solution:** $x + 7 = 12$. 7 is being added on LHS, so it will be subtracted on the other side. || **حل:** $x + 7 = 12$۔ بائیں طرف 7 جمع ہو رہا ہے، لہٰذا دوسری طرف یہ تفریق ہوگا۔ || **حل:** $x + 7 = 12$. په کیڼ اړخ کې 7 جمع کېږي، نو په بله خوا کې به تفریق شي.
eq x = 12 - 7 \;\Rightarrow\; x = 5
p **Verification:** Let's put the value of x in the original equation. $x + 7 = 12$, $5 + 7 = 12$, $12 = 12$, LHS = RHS. So, our solution is correct. || **تصدیق:** آئیے x کی قیمت اصل مساوات میں رکھیں۔ $x + 7 = 12$، $5 + 7 = 12$، $12 = 12$، بایاں طرف = دایاں طرف۔ لہٰذا ہمارا حل درست ہے۔ || **تایید:** راځئ د x ارزښت په اصلي معادله کې کېږدو. $x + 7 = 12$، $5 + 7 = 12$، $12 = 12$، کیڼ اړخ = ښي اړخ. نو زموږ حل سم دی.
endexample
example 2 | Solve: $\frac{5x + 6}{3x + 9} = \frac{16}{15}$ || حل کریں: $\frac{5x + 6}{3x + 9} = \frac{16}{15}$ || حل کړئ: $\frac{5x + 6}{3x + 9} = \frac{16}{15}$
p **Solution:** By cross multiplication || **حل:** آڑی ضرب سے || **حل:** د متقابل ضرب په مرسته
eq 15(5x + 6) = 16(3x + 9)
box teach | Teaching Point || تدریسی نکتہ || د تدریس ټکی
p Explain to the students about transposition method of solving linear equations. Also tell them to verify the solution by putting back the solution in the equation. || طلبہ کو خطی مساواتیں حل کرنے کا منتقلی کا طریقہ سمجھائیں۔ انہیں یہ بھی بتائیں کہ حل کو واپس مساوات میں رکھ کر اس کی تصدیق کریں۔ || زده کوونکو ته د خطي معادلو د حل د لېږد طریقه تشریح کړئ. دا هم ورته ووایاست چې حل بېرته په معادله کې کېږدي او تایید یې کړي.
endbox
