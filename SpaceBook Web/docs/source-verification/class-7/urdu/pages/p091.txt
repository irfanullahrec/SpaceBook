Find the antonyms of the words given in Column A from Column B, write them in Column C, and then use the antonyms in sentences. (Column A: height, sun, decline, fertile, spacious; Column B: progress, barren, narrow, lowness, moon) || ۶. په الف کالم کې ورکړل شوو کلمو متضاد له ب کالم موندلئ، په ج کالم کې یې ولیکئ او بیا په جملو کې یې وکاروئ.
