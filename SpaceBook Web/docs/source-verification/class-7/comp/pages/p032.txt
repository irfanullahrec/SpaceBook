## 2.2.6 Format Tab || ۲.۲.۶ فارمیٹ ٹیب || ۲.۲.۶ د بڼې ټېب
p The format tab is used to edit the image. It appears by clicking the image. || فارمیٹ ٹیب تصویر میں ترمیم کے لیے استعمال ہوتا ہے۔ یہ تصویر پر کلک کرنے سے ظاہر ہوتا ہے۔ || د بڼې ټېب د انځور سمولو لپاره کارېږي. دا په انځور د کلیک کولو سره ښکاره کېږي.
@deco Images: the Picture Tools Format ribbon (Remove Background, Corrections, Color, Artistic Effects, Picture Styles, Picture Border, Picture Effects, Picture Layout, Position, Wrap Text, Selection Pane, Align, Crop, Size) with a zoomed callout of "Crop".
p The images' position can be specifically defined by: || تصاویر کی جگہ خاص طور پر ان کے ذریعے متعین کی جا سکتی ہے: || د انځورونو ځای په ځانګړي ډول د دې په مټ ټاکل کېدای شي:
- Arrange Group. || ارینج گروپ۔ || د ترتیب ګروپ (Arrange).
- Position: Multiple options as per the location of images on the document are available. Any text around it will automatically wrap around the image. || پوزیشن: دستاویز میں تصاویر کی جگہ کے مطابق کئی اختیارات دستیاب ہیں۔ اس کے ارد گرد کا کوئی بھی متن خود بخود تصویر کے گرد لپٹ جائے گا۔ || ځای (Position): په سند کې د انځورونو د ځای مطابق ډېر انتخابونه شته. شاوخوا متن به په اتومات ډول د انځور شاوخوا ونغاړل شي.
- Wrap Text: Feature used to set up how text wraps around the image. || ریپ ٹیکسٹ: وہ خصوصیت جس سے طے ہوتا ہے کہ متن تصویر کے گرد کیسے لپٹے۔ || متن نغاړل (Wrap Text): هغه ځانګړتیا چې ټاکي متن د انځور شاوخوا څنګه نغاړل کېږي.
- You can align the image on the page or rotate it. || آپ تصویر کو صفحے پر ترتیب دے سکتے یا گھما سکتے ہیں۔ || تاسو انځور په مخ ترتیب کولای یا وګرځولای شئ.
- Cropping option is also available. || تراشنے (کراپ) کا اختیار بھی دستیاب ہے۔ || پرې کولو (Crop) انتخاب هم شته.
- You can add text in an image by inserting a Text-Box. || ٹیکسٹ باکس ڈال کر آپ تصویر میں متن شامل کر سکتے ہیں۔ || د متن بکس په داخلولو سره تاسو په انځور کې متن اضافه کولای شئ.
@deco Images: the Position gallery (In Line with Text; With Text Wrapping nine positions; More Layout Options) and the Wrap Text menu (In Line with Text, Square, Tight, Through, Top and Bottom, Behind Text, In Front of Text, Edit Wrap Points, Move with Text, Fix Position on Page, More Layout Options, Set as Default Layout).
