## 4.5.2 Repeat Until Command || ۴.۵.۲ ریپیٹ انٹل کمانڈ || ۴.۵.۲ د repeat until کمانډ
p **Repeat until** command is used to run the code inside the loop until the given condition/test remains false. It will exit the loop when the condition becomes true. || **ریپیٹ انٹل** کمانڈ لوپ کے اندر کوڈ اس وقت تک چلانے کے لیے استعمال ہوتی ہے جب تک دی گئی شرط/ٹیسٹ غلط رہے۔ جب شرط درست ہو جائے تو یہ لوپ سے نکل جائے گی۔ || **Repeat until** کمانډ د لوپ دننه کوډ تر هغه چلولو لپاره کارېږي چې ورکړل شوی شرط/ازموینه غلطه پاتې شي. کله چې شرط سم شي نو له لوپ نه وځي.
p The code will do the following steps: 1. It will take the sprite to middle of the stage i.e., position (0, 0). 2. Will check if the position of "x" of sprite is greater than 50 or not. If the position is not greater than 50, then it will go inside the repeat until loop and perform: a. Move 10 steps; b. play sound; c. go back to Repeat Until loop to check given condition again. When sprite moves 10 steps forward the loop will run 6 times. || کوڈ درج ذیل مراحل انجام دے گا: ۱۔ یہ اسپرائٹ کو اسٹیج کے وسط یعنی پوزیشن (0,0) پر لے جائے گا۔ ۲۔ یہ جانچے گا کہ اسپرائٹ کی "x" کی پوزیشن ۵۰ سے بڑی ہے یا نہیں۔ اگر پوزیشن ۵۰ سے بڑی نہ ہو تو یہ ریپیٹ انٹل لوپ کے اندر جا کر انجام دے گا: (الف) ۱۰ قدم چلیں؛ (ب) آواز بجائیں؛ (ج) دی گئی شرط دوبارہ جانچنے کے لیے ریپیٹ انٹل لوپ پر واپس جائیں۔ جب اسپرائٹ ۱۰ قدم آگے بڑھتا ہے تو لوپ ۶ بار چلے گا۔ || کوډ به لاندې ګامونه ترسره کړي: ۱. سپرایټ به د سټېج منځ ته یعنې ځای (0,0) ته وړي. ۲. به وګوري چې د سپرایټ د "x" ځای له ۵۰ نه لوی دی که نه. که ځای له ۵۰ نه لوی نه وي نو به د repeat until لوپ دننه ځي او به ترسره کړي: (الف) ۱۰ ګامه حرکت؛ (ب) غږ؛ (ج) د ورکړل شوي شرط د بیا ازمېښت لپاره repeat until لوپ ته بېرته. کله چې سپرایټ ۱۰ ګامه مخکې ځي نو لوپ ۶ ځله چلېږي.

## 4.5.3 Forever Command || ۴.۵.۳ فور ایور کمانڈ || ۴.۵.۳ د forever کمانډ
p Forever is a command that allows the code inside it to run forever. A user can use Stop button on the top to end the loop. Forever block is used to run a block of code forever (until externally stopped). Any number of commands can be listed inside Forever command. || فور ایور ایسی کمانڈ ہے جو اس کے اندر موجود کوڈ کو ہمیشہ چلنے دیتی ہے۔ صارف لوپ ختم کرنے کے لیے اوپر موجود اسٹاپ بٹن استعمال کر سکتا ہے۔ فور ایور بلاک کوڈ کے بلاک کو ہمیشہ (بیرونی طور پر روکے جانے تک) چلانے کے لیے استعمال ہوتا ہے۔ فور ایور کمانڈ کے اندر کتنی ہی کمانڈز درج کی جا سکتی ہیں۔ || Forever داسې کمانډ دی چې دننه کوډ ته اجازه ورکوي تل وچلېږي. کاروونکی کولای شي د لوپ د پای ته رسولو لپاره پورته Stop تڼۍ وکاروي. Forever بلاک د کوډ بلاک تل (تر بهرنۍ درولو پورې) چلولو لپاره کارېږي. د Forever کمانډ دننه هر شمېر کمانډونه لیست کېدای شي.
