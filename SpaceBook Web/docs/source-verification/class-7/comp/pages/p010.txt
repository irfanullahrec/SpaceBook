## 1.1.9 Self-Driving Cars || ۱.۱.۹ خود چلنے والی کاریں || ۱.۱.۹ پخپله چلېدونکې موټرې
p Self-Driving Cars rely on sensors, actuators, complex algorithms, machine learning systems, and powerful processors to execute software. Sophisticated software is used that accepts input from the sensors and sends instructions to the car's actuators. The car actuators control the steering, braking, speed and parking of the car. The software is designed to follow all the traffic rules. Various sensors create and maintain a map of car surroundings. || خود چلنے والی کاریں سافٹ ویئر چلانے کے لیے سینسرز، ایکچویٹرز، پیچیدہ الگورتھمز، مشین لرننگ سسٹمز اور طاقت ور پروسیسرز پر انحصار کرتی ہیں۔ جدید سافٹ ویئر سینسرز سے ان پٹ لیتا اور کار کے ایکچویٹرز کو ہدایات بھیجتا ہے۔ کار کے ایکچویٹرز اسٹیئرنگ، بریک، رفتار اور پارکنگ کو کنٹرول کرتے ہیں۔ سافٹ ویئر کو ٹریفک کے تمام قواعد پر عمل کرنے کے لیے ڈیزائن کیا گیا ہے۔ مختلف سینسرز کار کے ماحول کا نقشہ بناتے اور برقرار رکھتے ہیں۔ || پخپله چلېدونکې موټرې په سافټویر چلولو کې په سینسرونو، ایکچویټرونو، پېچلو الګوریتمونو، د ماشین زده کړې سیسټمونو او ځواکمنو پروسیسرونو تکیه کوي. پرمختللی سافټویر له سینسرونو ان پټ اخلي او د موټر ایکچویټرونو ته لارښوونې لېږي. ایکچویټرونه د موټر سټیرنګ، بریک، ګړندیتوب او پارکینګ کنټرولوي. سافټویر د ټرافیک ټول قواعد په پام کې نیولو سره جوړ شوی. مختلف سینسرونه د موټر د چاپېریال نقشه جوړوي او ساتي.

## 1.1.10 3D Printing || ۱.۱.۱۰ تھری ڈی پرنٹنگ || ۱.۱.۱۰ ۳ ډي چاپ
p 3D Printing uses a computer software to create a 3D object. The file of the object created on the computer can be stored on an SD card. The SD card reader inside the 3D printer is used to read the file and start printing, a computer is no longer necessary. The 3D printer uses material such as plastics and bio-materials (ceramics, glass, metals and polymers) to create objects of different shape, size and color. || تھری ڈی پرنٹنگ تین جہتی چیز بنانے کے لیے کمپیوٹر سافٹ ویئر استعمال کرتی ہے۔ کمپیوٹر پر بنائی گئی چیز کی فائل ایس ڈی کارڈ پر محفوظ کی جا سکتی ہے۔ تھری ڈی پرنٹر کے اندر ایس ڈی کارڈ ریڈر فائل پڑھنے اور پرنٹنگ شروع کرنے کے لیے استعمال ہوتا ہے، اب کمپیوٹر ضروری نہیں رہا۔ تھری ڈی پرنٹر مختلف شکل، سائز اور رنگ کی اشیا بنانے کے لیے پلاسٹک اور بائیو مٹیریلز (سرامکس، شیشہ، دھاتیں اور پولیمر) جیسا مواد استعمال کرتا ہے۔ || ۳ ډي چاپ د ۳ ډي شي جوړولو لپاره کمپیوټر سافټویر کاروي. په کمپیوټر جوړ شوی د شي فایل په SD کارت ساتل کېدای شي. د ۳ ډي چاپګر دننه SD کارت لوستونکی د فایل لوستلو او چاپ پیلولو لپاره کارېږي، اوس کمپیوټر اړین نه دی. ۳ ډي چاپګر د بېلابېلو شکل، اندازې او رنګ شیان جوړولو لپاره پلاستیک او بایو موادو (سرامیک، شیشه، فلزات او پولیمر) غوندې مواد کاروي.
