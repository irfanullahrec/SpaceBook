# 4.8 Create a Countdown Timer || ۴.۸ کاؤنٹ ڈاؤن ٹائمر بنانا || ۴.۸ د معکوس شمېرې ټایمر جوړول
p To create a timer, first select and place a 'when flag clicked' event. This way, whenever the green flag is clicked, the instructions following this event are executed. Next create a variable named 'Timer' and set value of timer to 10. || ٹائمر بنانے کے لیے پہلے 'when flag clicked' ایونٹ منتخب کر کے رکھیں۔ اس طرح جب بھی گرین فلیگ پر کلک ہو گا تو اس ایونٹ کے بعد کی ہدایات پر عمل ہو گا۔ پھر 'Timer' نامی ایک متغیر بنائیں اور ٹائمر کی قدر ۱۰ مقرر کریں۔ || د ټایمر د جوړولو لپاره لومړی 'when flag clicked' پېښه غوره او کېږدئ. په دې ډول هر کله چې شین بیرغ وکېکاږل شي، د دې پېښې وروسته لارښوونې ترسره کېږي. بیا د 'Timer' په نوم یو متغیر جوړ کړئ او د ټایمر ارزښت ۱۰ وټاکئ.
@deco Image: the script "when flag clicked; set Timer to 10; forever { wait 1 secs; change Timer by -1 }" and the stage with a "Timer 10" variable monitor next to the green flag and red stop buttons.
p Thereafter, incorporate a forever loop where we will decrement the value of Timer by -1. Additionally, set delay by adding wait command and set its value to 1 second. Now, let us execute it by clicking the green flag. It works, but 'Timer' does not stop on 0 but keeps decrementing and shows negative values on decreasing such that negative values start to show. || اس کے بعد ایک فور ایور لوپ شامل کریں جس میں ہم ٹائمر کی قدر میں ۱- کی کمی کریں گے۔ مزید برآں ویٹ کمانڈ شامل کر کے تاخیر مقرر کریں اور اس کی قدر ۱ سیکنڈ رکھیں۔ اب گرین فلیگ پر کلک کر کے اسے چلائیں۔ یہ کام کرتا ہے، لیکن 'Timer' ۰ پر نہیں رکتا بلکہ کم ہوتا رہتا ہے اور کم ہونے پر منفی قدریں دکھانے لگتا ہے۔ || بیا یو forever لوپ شامل کړئ چېرته چې د ټایمر ارزښت په ۱- کمېږو. سربېره پر دې د wait کمانډ په اضافه کولو ځنډ وټاکئ او ارزښت یې ۱ ثانیه کړئ. اوس د شین بیرغ په کېکاږلو یې وچلوئ. کار کوي، خو 'Timer' په ۰ نه درېږي بلکې کمېدو ته دوام ورکوي او منفي ارزښتونه ښيي.
@deco Image: the Timer monitor showing a negative value (-3) beside the flag and stop buttons.
p Thus, the starting is fine but we need to fix the terminating condition such that program stops smoothly. It means we have to check for condition that if timer reaches 0, it should stop and this is achieved through the code block as shown in figure. || چناں چہ آغاز ٹھیک ہے لیکن ہمیں ختم ہونے کی شرط درست کرنی ہے تاکہ پروگرام آسانی سے رک جائے۔ اس کا مطلب ہے کہ ہمیں یہ شرط جانچنی ہے کہ اگر ٹائمر ۰ تک پہنچ جائے تو اسے رک جانا چاہیے اور یہ شکل میں دکھائے گئے کوڈ بلاک کے ذریعے حاصل ہوتا ہے۔ || نو پیل سم دی خو باید د پای شرط سم کړو چې پروګرام په اسانۍ ودرېږي. مانا دا چې باید شرط وګورو چې که ټایمر ۰ ته ورسېږي نو باید ودرېږي او دا په انځور کې ښودل شوي کوډ بلاک ترلاسه کېږي.
@deco Image: a script "if Timer = 0 then play sound meow until done; stop all".
p Hence, the final code looks like the figure below and when executed it stops successfully when value of timer reaches 0. || لہٰذا حتمی کوڈ نیچے دی گئی شکل کی طرح نظر آتا ہے اور چلانے پر ٹائمر کی قدر ۰ پر پہنچنے پر کامیابی سے رک جاتا ہے۔ || نو وروستی کوډ لاندې انځور غوندې ښکاري او کله چې وچلېږي کله چې د ټایمر ارزښت ۰ ته ورسېږي په بریالیتوب درېږي.
