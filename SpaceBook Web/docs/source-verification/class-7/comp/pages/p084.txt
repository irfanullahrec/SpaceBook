# 4.4 Scratch Code Blocks || ۴.۴ اسکریچ کوڈ بلاکس || ۴.۴ د سکریچ کوډ بلاکونه
## 4.4.1 Working with Scratch Code Blocks || ۴.۴.۱ اسکریچ کوڈ بلاکس کے ساتھ کام || ۴.۴.۱ د سکریچ کوډ بلاکونو سره کار
p Blocks are the commands that are used to create programmes in scratch, these are 'Drag n Drop' blocks which allow the user to write programmes without typing commands. There are a number of block types like motion, looks, sounds, etc. These blocks can be found on the left most of the screen in Blocks Palette. Clicking on each block category reveals the command blocks related to that block. A user can drag and drop blocks in the middle to make a programme. These blocks can be joined over or under other blocks to make a group; grouped blocks can be moved together by dragging. || بلاکس وہ کمانڈز ہیں جو اسکریچ میں پروگرام بنانے کے لیے استعمال ہوتی ہیں، یہ 'ڈریگ اینڈ ڈراپ' بلاکس ہیں جو صارف کو کمانڈز ٹائپ کیے بغیر پروگرام لکھنے دیتے ہیں۔ بلاکس کی کئی اقسام ہیں جیسے موشن، لُکس، ساؤنڈز وغیرہ۔ یہ بلاکس اسکرین کے بائیں سرے پر بلاکس پیلیٹ میں ملتے ہیں۔ ہر بلاک کیٹیگری پر کلک کرنے سے اس سے متعلق کمانڈ بلاکس ظاہر ہوتے ہیں۔ صارف بلاکس کو بیچ میں گھسیٹ کر پروگرام بنا سکتا ہے۔ ان بلاکس کو دوسرے بلاکس کے اوپر یا نیچے جوڑ کر گروپ بنایا جا سکتا ہے؛ گروپ شدہ بلاکس کو گھسیٹ کر ایک ساتھ حرکت دی جا سکتی ہے۔ || بلاکونه هغه کمانډونه دي چې په سکریچ کې د پروګرامونو جوړولو لپاره کارېږي، دا 'ډریګ این ډراپ' بلاکونه دي چې کاروونکي ته اجازه ورکوي پرته له کمانډ ټایپ کولو پروګرامونه ولیکي. د بلاکونو ډېر ډولونه شته لکه موشن، لوکس، ساؤنډز او نور. دا بلاکونه د سکرین په چپ سر کې د بلاکونو پالټ کې موندل کېږي. په هره بلاک کټګورۍ کېکاږل ورپورې اړوند کمانډ بلاکونه ښيي. کاروونکی کولای شي بلاکونه په منځ کې راکاږي او پروګرام جوړ کړي. دا بلاکونه د نورو بلاکونو پر سر یا لاندې ټولیدای شي چې ډله جوړه شي؛ ډله شوي بلاکونه په کېښلو یوځای خوځول کېدای شي.
p Try to drag 'point towards' block in the middle, and then click it. Notice the sprite turns towards the mouse pointer regardless of its position. However, if you use 'glide' block instead, the sprite moves towards the mouse pointer or towards a random position; in the number of seconds mentioned. || 'point towards' بلاک کو بیچ میں گھسیٹ کر آزمائیں، پھر اس پر کلک کریں۔ دیکھیں کہ اسپرائٹ اپنی پوزیشن سے قطع نظر ماؤس پوائنٹر کی طرف مڑ جاتا ہے۔ تاہم اگر آپ اس کے بجائے 'glide' بلاک استعمال کریں تو اسپرائٹ مذکورہ سیکنڈوں میں ماؤس پوائنٹر یا کسی بے ترتیب پوزیشن کی طرف حرکت کرتا ہے۔ || 'point towards' بلاک په منځ کې راکاږئ او بیا پرې کېکاږئ. ګورئ چې سپرایټ د خپل ځای پرته د موږک اشاره کوونکي لوري ته اوړي. خو که د دې پر ځای 'glide' بلاک وکاروئ، سپرایټ د یادو ثانیو کې د موږک اشاره کوونکي یا تصادفي ځای لوري ته حرکت کوي.
p The block 'change y by' and 'change x by' move the sprite in terms of the mentioned steps in y and x axis, respectively. || بلاک 'change y by' اور 'change x by' اسپرائٹ کو بالترتیب y اور x محور میں مذکورہ قدموں کے مطابق حرکت دیتے ہیں۔ || بلاک 'change y by' او 'change x by' سپرایټ په ترتیب د y او x محور د یادو ګامونو سره سم خوځوي.

## 4.4.2 Changing position of Sprites via code || ۴.۴.۲ کوڈ کے ذریعے اسپرائٹس کی پوزیشن بدلنا || ۴.۴.۲ په کوډ د سپرایټونو د ځای بدلول
p A user can change the position of the sprite by using 'go to' command. There are two variants of 'go to': || صارف 'go to' کمانڈ کے ذریعے اسپرائٹ کی پوزیشن بدل سکتا ہے۔ 'go to' کی دو اقسام ہیں: || کاروونکی د 'go to' کمانډ په کارولو د سپرایټ ځای بدلولای شي. د 'go to' دوه ډولونه شته:
- 'go to random position' which takes the sprite to a random position on screen; when clicked it takes the sprite to a random position on the output area. || 'go to random position' جو اسپرائٹ کو اسکرین پر کسی بے ترتیب پوزیشن پر لے جاتا ہے؛ کلک کرنے پر یہ اسپرائٹ کو آؤٹ پٹ ایریا میں بے ترتیب پوزیشن پر لے جاتا ہے۔ || 'go to random position' چې سپرایټ پر سکرین تصادفي ځای ته وړي؛ کېکاږلو سره دا سپرایټ آوټ پټ ساحې په تصادفي ځای کې وړي.
- 'go to x: y:' which moves the sprite to a given position on the stage; when clicked it takes the sprite to a fixed location as provided in the code block. A user can change coordinates to see the effect. || 'go to x: y:' جو اسپرائٹ کو اسٹیج پر دی گئی پوزیشن پر لے جاتا ہے؛ کلک کرنے پر یہ اسپرائٹ کو کوڈ بلاک میں دی گئی مقررہ جگہ پر لے جاتا ہے۔ صارف اثر دیکھنے کے لیے محدد (کوآرڈینیٹس) بدل سکتا ہے۔ || 'go to x: y:' چې سپرایټ په سټېج ورکړل شوي ځای ته وړي؛ کېکاږلو سره دا سپرایټ د کوډ بلاک ورکړل شوي ټاکلي ځای ته وړي. کاروونکی کولای شي اغېز لیدو لپاره همغږي بدلې کړي.
