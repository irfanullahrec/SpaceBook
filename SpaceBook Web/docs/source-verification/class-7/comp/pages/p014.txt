## Difference between RAM and ROM || ریم اور روم میں فرق || د RAM او ROM توپیر
table Difference between RAM and ROM
th RAM || ریم || RAM | ROM || روم || ROM
tr RAM stores operating system, application programs and data in use. || ریم آپریٹنگ سسٹم، ایپلی کیشن پروگرام اور زیرِ استعمال ڈیٹا محفوظ کرتی ہے۔ || RAM عملیاتي سیسټم، اپلېکېشن پروګرامونه او کارول کېدونکي معلومات ساتي. | ROM contains programs used for booting up the computer and BIOS. || روم میں کمپیوٹر کو شروع کرنے اور بائیوس کے لیے استعمال ہونے والے پروگرام ہوتے ہیں۔ || ROM هغه پروګرامونه لري چې کمپیوټر پیلولو او BIOS لپاره کارېږي.
tr Data in RAM can be modified. || ریم میں ڈیٹا تبدیل کیا جا سکتا ہے۔ || په RAM کې معلومات بدلېدای شي. | Data in ROM cannot be modified. || روم میں ڈیٹا تبدیل نہیں کیا جا سکتا۔ || په ROM کې معلومات نشي بدلېدای.
tr RAM is volatile memory. || ریم غیر مستقل (عارضی) میموری ہے۔ || RAM بې ثباته حافظه ده. | ROM is non volatile memory. || روم مستقل میموری ہے۔ || ROM ثابته حافظه ده.
tr Types of RAM are: Dynamic RAM; Static RAM. || ریم کی اقسام: ڈائنامک ریم؛ اسٹیٹک ریم۔ || د RAM ډولونه: ډینامیک RAM؛ سټېټیک RAM. | Types of ROM are: PROM (Programmable ROM); EPROM (Erasable PROM); EEPROM (Electronically Erasable PROM); UVEPROM (Ultra Violet Erasable PROM). || روم کی اقسام: پی روم (پروگرام ہونے والی روم)؛ ای پی روم (مٹائی جا سکنے والی پی روم)؛ ای ای پی روم (برقی طور پر مٹائی جا سکنے والی پی روم)؛ یو وی ای پی روم (الٹرا وائلٹ سے مٹائی جا سکنے والی پی روم)۔ || د ROM ډولونه: PROM (پروګرام کېدونکی ROM)؛ EPROM؛ EEPROM؛ UVEPROM.
endtable
svg Primary Memory is divided into Random Access Memory (RAM: DRAM, SRAM) and Read Only Memory (ROM: PROM, EPROM, EEPROM, UVEPROM). || پرائمری میموری ریم (ڈی ریم، ایس ریم) اور روم (پی روم، ای پی روم، ای ای پی روم، یو وی ای پی روم) میں تقسیم ہے۔ || لومړنۍ حافظه په RAM (DRAM، SRAM) او ROM (PROM، EPROM، EEPROM، UVEPROM) ویشل کېږي.
