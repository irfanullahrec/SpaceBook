## Memory Unit || میموری یونٹ || حافظې واحد
p The main memory (Primary Memory) is directly accessed by the CPU to store and retrieve information. || مین میموری (پرائمری میموری) تک سی پی یو براہِ راست رسائی حاصل کرتا ہے تاکہ معلومات محفوظ کرے اور واپس حاصل کرے۔ || اصلي حافظه (لومړنۍ حافظه) CPU مستقیماً کاروي چې معلومات خوندي او بېرته ترلاسه کړي.
p Different kinds of primary memory are: || پرائمری میموری کی مختلف اقسام یہ ہیں: || د لومړنۍ حافظې مختلف ډولونه دا دي:
- Random Access Memory (RAM) is used to read and write data but the data is volatile or temporary i.e., whenever the power is switched off the contents of RAM are lost. All computer programs must be loaded into the RAM before execution. The size of the memory is measured by the number of bytes available for use. || ریندم ایکسیس میموری (ریم) ڈیٹا پڑھنے اور لکھنے کے لیے استعمال ہوتی ہے لیکن ڈیٹا غیر مستقل یا عارضی ہوتا ہے، یعنی جب بھی بجلی بند کی جائے ریم کا مواد ختم ہو جاتا ہے۔ تمام کمپیوٹر پروگراموں کو چلنے سے پہلے ریم میں لوڈ کرنا ضروری ہے۔ میموری کا سائز استعمال کے لیے دستیاب بائٹس کی تعداد سے ناپا جاتا ہے۔ || تصادفي لاسرسي حافظه (RAM) د معلوماتو لوستلو او لیکلو لپاره کارېږي خو معلومات بې ثباته یا لنډمهاله وي، یعنې هر کله چې برېښنا بنده شي د RAM منځپانګه له منځه ځي. ټول کمپیوټر پروګرامونه باید د اجرا مخکې په RAM کې بار شي. د حافظې اندازه د کارولو لپاره شته د بایټونو شمېره اندازه کېږي.

- Read Only Memory (ROM) is non volatile memory. Instructions in ROM are embedded permanently at the time of its manufacturing. ROM contains Basic Input Output System (BIOS) and programs that start the computer. || ریڈ اونلی میموری (روم) غیر عارضی میموری ہے۔ روم میں ہدایات اس کی تیاری کے وقت مستقل طور پر شامل کر دی جاتی ہیں۔ روم میں بنیادی ان پٹ آؤٹ پٹ سسٹم (بائیوس) اور وہ پروگرام ہوتے ہیں جو کمپیوٹر کو شروع کرتے ہیں۔ || یوازې لوستونکې حافظه (ROM) بې ثباته نه ده. په ROM کې لارښوونې د جوړېدو پر مهال همېشه لپاره ځای پر ځای کېږي. ROM بنسټیز ان پټ آوټ پټ سیسټم (BIOS) او هغه پروګرامونه لري چې کمپیوټر پیلوي.
