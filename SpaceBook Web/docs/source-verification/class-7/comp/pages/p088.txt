p Looks block category contains blocks related to appearance of Sprites. With Sprite-1 selected, write the given code in script area. Notice the purple blocks 'switch costumes to ...'. These are two different postures of Sprite-1 represented as 'costume1' and 'costume2', changing the costume with movement makes the sprite appear walking. || لُکس بلاک کیٹیگری میں اسپرائٹس کی ظاہری شکل سے متعلق بلاکس ہیں۔ اسپرائٹ-۱ منتخب کر کے دیا گیا کوڈ اسکرپٹ ایریا میں لکھیں۔ جامنی بلاکس 'switch costumes to ...' دیکھیں۔ یہ اسپرائٹ-۱ کی دو مختلف حالتیں ہیں جنھیں 'costume1' اور 'costume2' کہا گیا ہے؛ حرکت کے ساتھ کاسٹیوم بدلنے سے اسپرائٹ چلتا ہوا نظر آتا ہے۔ || د لوکس بلاک کټګورۍ د سپرایټونو د ظاهري بڼې اړوند بلاکونه لري. سپرایټ-۱ غوره کړئ او ورکړل شوی کوډ په سکرېپټ ساحه کې ولیکئ. ارغواني بلاکونه 'switch costumes to ...' وګورئ. دا د سپرایټ-۱ دوه بېلابېلې بڼې دي چې 'costume1' او 'costume2' بلل کېږي، د حرکت سره د جامې بدلول سپرایټ د تګ کوونکي ښيي.

# 4.7 Developing a Basic Game || ۴.۷ بنیادی گیم بنانا || ۴.۷ بنسټیزه لوبه جوړول
p This example helps to get started with building interactive games with scratch. It works with two sprites: a Cat and a Chick. You can select these Sprites from Sprites list. Select Sprite1 (the cat) and develop code as shown in the picture. || یہ مثال اسکریچ سے انٹرایکٹو گیمز بنانے کا آغاز کرنے میں مدد دیتی ہے۔ یہ دو اسپرائٹس کے ساتھ کام کرتی ہے: ایک بلی اور ایک چوزہ۔ آپ ان اسپرائٹس کو اسپرائٹس کی فہرست سے منتخب کر سکتے ہیں۔ Sprite1 (بلی) منتخب کریں اور تصویر میں دکھایا گیا کوڈ تیار کریں۔ || دا بېلګه د سکریچ سره د متقابلو لوبو جوړولو په پیل کې مرسته کوي. دا له دوو سپرایټونو سره کار کوي: یوه پیشو او یو چرګوړی. تاسو دا سپرایټونه له سپرایټونو لیست نه غوره کولای شئ. Sprite1 (پیشو) غوره کړئ او کوډ د انځور سره سم جوړ کړئ.
