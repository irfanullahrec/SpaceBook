# 4.5 Control Block in Scratch || ۴.۵ اسکریچ میں کنٹرول بلاک || ۴.۵ په سکریچ کې کنټرول بلاک
p **Loops** are used to repeat a certain block of code for a known or unknown number of times. Common loop commands used in scratch are: Repeat, Repeat until, Forever. || **لوپس** کوڈ کے کسی بلاک کو معلوم یا نامعلوم تعداد میں دہرانے کے لیے استعمال ہوتے ہیں۔ اسکریچ میں استعمال ہونے والی عام لوپ کمانڈز یہ ہیں: Repeat، Repeat until، Forever۔ || **لوپونه** د کوډ ټاکلي بلاک د پېژندل شوې یا نه پېژندل شوې شمېرې ځله تکرارولو لپاره کارېږي. په سکریچ کې عام لوپ کمانډونه دا دي: Repeat، Repeat until، Forever.

## 4.5.1 Repeat Command || ۴.۵.۱ ریپیٹ کمانڈ || ۴.۵.۱ د تکرار کمانډ
p **Repeat** command is used when a block of code is required to run for a given number of times. || **ریپیٹ** کمانڈ اس وقت استعمال ہوتی ہے جب کوڈ کے بلاک کو دی گئی تعداد میں چلانا مطلوب ہو۔ || **Repeat** کمانډ هغه مهال کارېږي چې د کوډ بلاک ته ورکړل شوې شمېرې ځله چلېدو ته اړتیا وي.
### Example: || مثال: || بېلګه:
p If 5 is used as an argument in repeat command, it will repeat the code blocks inside the 'repeat' loop 5 times. The code in figure will make the sprite to move 10 steps forward and play sound. Then, sprite will take another 10 steps and play the sound again. All together steps taken and playing of sound will iterate for 5 times. || اگر ریپیٹ کمانڈ میں آرگومنٹ کے طور پر ۵ استعمال ہو تو یہ 'ریپیٹ' لوپ کے اندر کوڈ بلاکس کو ۵ بار دہرائے گا۔ شکل میں دیا گیا کوڈ اسپرائٹ کو ۱۰ قدم آگے بڑھائے گا اور آواز بجائے گا۔ پھر اسپرائٹ مزید ۱۰ قدم لے گا اور دوبارہ آواز بجائے گا۔ مجموعی طور پر قدم اٹھانے اور آواز بجانے کا عمل ۵ بار دہرایا جائے گا۔ || که په repeat کمانډ کې ۵ د دلیل په توګه وکارول شي، دا به د 'repeat' لوپ دننه کوډ بلاکونه ۵ ځله تکرار کړي. په انځور کې کوډ به سپرایټ ۱۰ ګامه مخکې وړي او غږ به غږوي. بیا به سپرایټ نور ۱۰ ګامونه واخلي او بیا به غږ وغږوي. ټول یوځای ګامونه اخیستل او غږ غږول به ۵ ځله تکرار شي.
svg Scratch script: repeat 5 { move 10 steps; play sound Meow until done }. || اسکریچ اسکرپٹ: ۵ بار دہرائیں { ۱۰ قدم چلیں؛ آواز "میاؤں" بجائیں جب تک ختم نہ ہو }۔ || سکریچ سکرېپټ: ۵ ځله تکرار { ۱۰ ګامه حرکت؛ د "میاو" غږ تر پایه }.
