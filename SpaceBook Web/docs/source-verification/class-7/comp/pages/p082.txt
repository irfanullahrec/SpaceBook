# 4.3 Introduction to Scratch Interface || ۴.۳ اسکریچ انٹرفیس کا تعارف || ۴.۳ د سکریچ انټرفیس پېژندنه
@deco Image: the Scratch editor with labels: Load Tutorials, Code Blocks, Programming Area, Background, Stage, Block Categories, Block Palette, Tutorial, Sprite, Sprite Properties; caption "Main components of Scratch interface". The stage shows the orange Scratch cat in front of balloons; the programming area shows a "when flag clicked / go to x: 0 y: 0" script.
p **Blocks Palette** contains all building blocks for Scratch known as Code Blocks. There are a number of categories of Code Blocks presented in various colored dots. A user can drag the blocks to the programming or script area. || **بلاکس پیلیٹ** میں اسکریچ کے تمام تعمیراتی بلاکس ہوتے ہیں جنھیں کوڈ بلاکس کہتے ہیں۔ کوڈ بلاکس کے کئی زمرے رنگین نقطوں کی صورت میں ہوتے ہیں۔ صارف بلاکس کو پروگرامنگ یا اسکرپٹ ایریا میں گھسیٹ سکتا ہے۔ || **د بلاکونو پالټ** د سکریچ ټول جوړونکي بلاکونه لري چې کوډ بلاکونه بلل کېږي. د کوډ بلاکونو ډېر ډولونه په رنګین ټکو کې ښودل کېږي. کاروونکی کولای شي بلاکونه پروګرامینګ یا سکرېپټ ساحې ته راکاږي.
p **Blocks Category** contains groups of commands related to specific purposes. A user can click on these categories to see the commands/Code Blocks in Blocks Palette. || **بلاکس کیٹیگری** میں مخصوص مقاصد سے متعلق کمانڈز کے گروپ ہوتے ہیں۔ صارف ان زمروں پر کلک کر کے بلاکس پیلیٹ میں کمانڈز/کوڈ بلاکس دیکھ سکتا ہے۔ || **د بلاکونو کټګورۍ** د ځانګړو موخو اړوند د کمانډونو ډلې لري. کاروونکی کولای شي پر دې کټګوریو کېکاږي او په بلاکونو پالټ کې کمانډونه/کوډ بلاکونه وګوري.
p **Programming area** (or script area) is where user creates sequences of codes to be run. This is the actual working space. || **پروگرامنگ ایریا** (یا اسکرپٹ ایریا) وہ جگہ ہے جہاں صارف چلائے جانے والے کوڈز کی ترتیبیں بناتا ہے۔ یہ اصل کام کی جگہ ہے۔ || **د پروګرامینګ ساحه** (یا سکرېپټ ساحه) هغه ځای دی چېرته چې کاروونکی د چلېدو لپاره د کوډونو لړۍ جوړوي. دا اصلي کاري ځای دی.
box info | Tip: Tutorials || نکتہ: ٹیوٹوریلز || ګټوره خبره: ټیوټوریلونه
p Try using the built-in help feature; and apply the given instructions. Help is also available under "Tutorials" section, do explore them. || بلٹ اِن مدد کی خصوصیت استعمال کر کے دیکھیں اور دی گئی ہدایات پر عمل کریں۔ مدد "ٹیوٹوریلز" سیکشن میں بھی دستیاب ہے، انھیں ضرور دریافت کریں۔ || په جوړ شوې مرسته ځانګړتیا کار واخلئ او ورکړل شوې لارښوونې عملي کړئ. مرسته د "Tutorials" برخه کې هم شته، هغه وګورئ.
