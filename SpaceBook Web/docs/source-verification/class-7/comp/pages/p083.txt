p **The Stage** (or display area) is a window where the code outcomes are seen. Lower part of the Stage shows the list of added Sprites and their properties. It also contains buttons to add Sprites and backgrounds. It is 480 pixels wide and 360 pixels tall; the center point is referred to as (0,0). || **اسٹیج** (یا ڈسپلے ایریا) وہ ونڈو ہے جہاں کوڈ کے نتائج نظر آتے ہیں۔ اسٹیج کا نچلا حصہ شامل کیے گئے اسپرائٹس اور ان کی خصوصیات کی فہرست دکھاتا ہے۔ اس میں اسپرائٹس اور پس منظر شامل کرنے کے بٹن بھی ہیں۔ یہ ۴۸۰ پکسل چوڑا اور ۳۶۰ پکسل اونچا ہے؛ مرکزی نقطہ (0,0) کہلاتا ہے۔ || **سټېج** (یا ښودلو ساحه) هغه کړکۍ ده چېرته چې د کوډ پایلې ښکاري. د سټېج ښکته برخه اضافه شوي سپرایټونه او د هغو ځانګړتیاوې ښيي. دا د سپرایټونو او شالیدونو د اضافه کولو تڼۍ هم لري. دا ۴۸۰ پکسل پلن او ۳۶۰ پکسل لوړ دی؛ مرکزي نقطه (0,0) بلل کېږي.
p **Sprites** are characters or images that you have in your project. By default, a cat like symbol named 'Sprite1' is selected. You can add as many sprites as you wish, but it is recommended not to add unnecessary sprites because it will create difficulty in coding. It is advised to start with one or two sprites only, and add more if you need them. || **اسپرائٹس** وہ کردار یا تصاویر ہیں جو آپ کے پروجیکٹ میں ہوں۔ ڈیفالٹ طور پر بلی جیسی علامت 'Sprite1' منتخب ہوتی ہے۔ آپ جتنے چاہیں اسپرائٹس شامل کر سکتے ہیں، لیکن غیر ضروری اسپرائٹس شامل نہ کرنے کی سفارش ہے کیوں کہ اس سے کوڈنگ میں مشکل پیدا ہوگی۔ مشورہ ہے کہ صرف ایک یا دو اسپرائٹس سے شروع کریں اور ضرورت پڑنے پر مزید شامل کریں۔ || **سپرایټونه** هغه کرکټرونه یا انځورونه دي چې ستاسو په پروژه کې وي. په ډیفالټ ډول د پیشو غوندې نښه 'Sprite1' غوره وي. تاسو کولای شئ ډېر سپرایټونه اضافه کړئ، خو سپارښتنه کېږي چې ناغوښتل شوي سپرایټونه اضافه نه کړئ ځکه چې په کوډ کولو کې ستونزه پېښوي. مشوره ده چې یوازې یو یا دوه سپرایټونو پیل کړئ او اړتیا لرئ نو نور اضافه کړئ.
p **Sprite Properties** presents the current position, size and direction of the selected sprite. In this image, the sprite is in the middle of the field (notice position x is 0, and y is also 0). || **اسپرائٹ پراپرٹیز** منتخب اسپرائٹ کی موجودہ پوزیشن، سائز اور سمت دکھاتی ہے۔ اس تصویر میں اسپرائٹ میدان کے وسط میں ہے (دیکھیں کہ پوزیشن x ۰ ہے اور y بھی ۰ ہے)۔ || **د سپرایټ ځانګړتیاوې** د غوره شوي سپرایټ اوسنی ځای، اندازه او سمت ښيي. په دې انځور کې سپرایټ د ساحې په منځ کې دی (وګورئ چې ځای x ۰ دی او y هم ۰).
