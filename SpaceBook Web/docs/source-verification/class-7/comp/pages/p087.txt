# 4.6 Handling Events || ۴.۶ ایونٹس کو سنبھالنا || ۴.۶ د پېښو سمبالول
p Scratch provides an effective way of interacting with the external events, for example, it can detect when mouse pointer is moved, or any key is pressed. A user can control code for a particular sprite to run when any of such event takes place. || اسکریچ بیرونی واقعات (ایونٹس) سے تعامل کا مؤثر طریقہ فراہم کرتا ہے، مثلاً یہ پتا لگا سکتا ہے کہ ماؤس پوائنٹر کب حرکت کرتا ہے یا کوئی کی کب دبائی جاتی ہے۔ صارف کسی خاص اسپرائٹ کے کوڈ کو ایسے کسی واقعے کے ہونے پر چلانے کے لیے کنٹرول کر سکتا ہے۔ || سکریچ له بهرنیو پېښو سره د اړیکې اغېزمن لار برابروي، د بېلګې په توګه دا موندلای شي چې کله د موږک اشاره کوونکی خوځي یا کومه کیلۍ ټکول کېږي. کاروونکی کولای شي د یوه ځانګړي سپرایټ کوډ د داسې کومې پېښې پر پېښېدو چلېدو لپاره کنټرول کړي.

## 4.6.1 Controlling Sprite Movement (heading faint) || ۴.۶.۱ اسپرائٹ کی حرکت کو کنٹرول کرنا (عنوان دھندلا) || ۴.۶.۱ د سپرایټ د حرکت کنټرول (سرلیک تیاره)
p Add a new sprite, like a basketball; and write the code provided in figure. You will see that now you can control the movement of the sprite 'ball' using the four directional/arrow keys. This is a good breakthrough towards creating interactive games. || ایک نیا اسپرائٹ، مثلاً باسکٹ بال، شامل کریں؛ اور شکل میں دیا گیا کوڈ لکھیں۔ آپ دیکھیں گے کہ اب آپ چار سمتی/تیر والی کیز کی مدد سے اسپرائٹ 'بال' کی حرکت کو کنٹرول کر سکتے ہیں۔ یہ انٹرایکٹو گیمز بنانے کی طرف اچھی پیش رفت ہے۔ || نوی سپرایټ لکه باسکټبال اضافه کړئ؛ او په انځور کې ورکړل شوی کوډ ولیکئ. تاسو به وګورئ چې اوس تاسو کولای شئ د څلورو سمتي/غشي کیلیو په مټ د سپرایټ 'بال' حرکت کنټرول کړئ. دا د متقابلو لوبو جوړولو لوري ته ښه پرمختګ دی.
svg Four key scripts for moving the ball: when up arrow pressed → change y by 5; when down arrow pressed → change y by -5; when left arrow pressed → change x by -5; when right arrow pressed → change x by 5. || گیند کو حرکت دینے کے چار کی اسکرپٹس: اوپر کا تیر دبانے پر y میں ۵ کا اضافہ؛ نیچے کا تیر دبانے پر y میں ۵- کی تبدیلی؛ بائیں تیر پر x میں ۵- کی تبدیلی؛ دائیں تیر پر x میں ۵ کا اضافہ۔ || د بال د خوځولو لپاره څلور کیلۍ سکرېپټونه: پورتنی غشی کېکاږل → y په ۵ بدل؛ ښکتنی غشی → y په ۵- بدل؛ چپ غشی → x په ۵- بدل؛ ښي غشی → x په ۵ بدل.
