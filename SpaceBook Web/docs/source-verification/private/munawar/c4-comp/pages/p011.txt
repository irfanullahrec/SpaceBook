## Hardware || ہارڈ ویئر || هارډویر
p Hardware is a physical device that you are able to touch and see. It refers to the physical components of the computer that run the software, such as hard drive, motherboard, monitor, keyboard and mouse etc. || ہارڈ ویئر ایک مادی آلہ ہے جسے آپ چھو اور دیکھ سکتے ہیں۔ یہ کمپیوٹر کے ان طبعی اجزا کو کہتے ہیں جو سافٹ ویئر چلاتے ہیں، جیسے ہارڈ ڈرائیو، مدر بورڈ، مانیٹر، کی بورڈ اور ماؤس وغیرہ۔ || هارډویر یو فزیکي وسیله ده چې تاسو یې لمس کولی او لیدلی شئ. دا د کمپیوټر هغو فزیکي برخو ته وايي چې سافټویر چلوي، لکه هارډ ډرایو، مدربورډ، مانیټر، کیبورډ او ماوس او نور.
p For example; the monitor of a computer is used for viewing the information (video, text, images) and a mouse is used for navigation. These are considered as computer hardware which forms the actual body of the computer system. || مثلاً کمپیوٹر کا مانیٹر معلومات (ویڈیو، متن، تصاویر) دیکھنے کے لیے استعمال ہوتا ہے اور ماؤس رہنمائی کے لیے۔ انہیں کمپیوٹر ہارڈ ویئر سمجھا جاتا ہے جو کمپیوٹر سسٹم کا اصل جسم بناتا ہے۔ || د مثال په توګه د کمپیوټر مانیټر د معلوماتو (ویډیو، متن، انځورونه) د لیدلو لپاره کارول کیږي او ماوس د لارښوونې لپاره. دا د کمپیوټر هارډویر ګڼل کیږي چې د کمپیوټر سیسټم اصلي بدن جوړوي.
## Software || سافٹ ویئر || سافټویر
p Software is a collection of code and instructions that tell a computer and/or hardware how to operate. Software is considered as the soul in a computer hardware. CPU is considered as human brain, not the software; they are just a set of instructions. || سافٹ ویئر کوڈ اور ہدایات کا مجموعہ ہے جو کمپیوٹر اور/یا ہارڈ ویئر کو بتاتا ہے کہ کیسے کام کرنا ہے۔ سافٹ ویئر کو کمپیوٹر ہارڈ ویئر میں روح کی حیثیت حاصل ہے۔ سی پی یو کو انسانی دماغ سمجھا جاتا ہے، سافٹ ویئر نہیں؛ وہ تو صرف ہدایات کا مجموعہ ہیں۔ || سافټویر د کوډ او لارښوونو یوه ټولګه ده چې کمپیوټر او/یا هارډویر ته وايي چې څنګه کار وکړي. سافټویر د کمپیوټر په هارډویر کې د روح په څېر ګڼل کیږي. CPU د انسان ذهن ګڼل کیږي، نه سافټویر؛ دوی یوازې د لارښوونو ټولګه ده.
p A set of instructions for a particular work given to the computer is called a program. Software is a set of programs that a user installs on his/her computer to help do different kinds of work for example WordPad, Paint and computer games etc. || کسی خاص کام کے لیے کمپیوٹر کو دی جانے والی ہدایات کے مجموعے کو پروگرام کہتے ہیں۔ سافٹ ویئر پروگراموں کا مجموعہ ہے جو صارف مختلف کام کرنے میں مدد کے لیے اپنے کمپیوٹر پر نصب کرتا ہے، مثلاً ورڈ پیڈ، پینٹ اور کمپیوٹر گیمز وغیرہ۔ || د یوه ځانګړي کار لپاره کمپیوټر ته ورکړل شوې د لارښوونو ټولګې ته پروګرام وايي. سافټویر د پروګرامونو یوه ټولګه ده چې کاروونکی یې په خپل کمپیوټر نصبوي ترڅو د بېلابېلو کارونو په کولو کې مرسته وکړي، د مثال په توګه ورډپېډ، پینټ او کمپیوټري لوبې او نور.
