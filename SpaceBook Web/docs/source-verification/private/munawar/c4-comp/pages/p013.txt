## iii. Storage Devices and Memory || ۳۔ ذخیرہ کرنے کے آلات اور میموری || ۳. ذخیره کولو وسایل او حافظه
p A memory is used to store data in a computer. It can hold and store information both temporarily and permanently. These two devices are considered as memory. There is a difference between storage and memory. Examples of memory are: || میموری کمپیوٹر میں ڈیٹا ذخیرہ کرنے کے لیے استعمال ہوتی ہے۔ یہ معلومات کو عارضی اور مستقل دونوں طرح رکھ اور محفوظ کر سکتی ہے۔ یہ دونوں آلات میموری سمجھے جاتے ہیں۔ ذخیرے اور میموری میں فرق ہے۔ میموری کی مثالیں یہ ہیں: || حافظه په کمپیوټر کې د ډاټا د ذخیره کولو لپاره کارول کیږي. دا کولی شي معلومات هم په لنډمهاله او هم په دایمي توګه وساتي او ذخیره کړي. دا دواړه وسایل د حافظې په توګه ګڼل کیږي. د ذخیره کولو او حافظې ترمنځ توپیر شته. د حافظې مثالونه دا دي:
- Primary Memory: RAM, ROM || بنیادی میموری: ریم، روم || لومړنۍ حافظه: RAM، ROM
- Secondary Memory: Hard Disk, Floppy, Memory Card, Pen Drive, Tape, CD/DVD || ثانوی میموری: ہارڈ ڈسک، فلاپی، میموری کارڈ، پین ڈرائیو، ٹیپ، سی ڈی/ڈی وی ڈی || دویمه حافظه: هارډ ډیسک، فلاپي، میموري کارډ، پین ډرایو، ټیپ، CD/DVD
