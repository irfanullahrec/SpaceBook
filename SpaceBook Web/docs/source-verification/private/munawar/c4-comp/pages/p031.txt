## Creating a New Document using Short Keys || شارٹ کیز سے نیا دستاویز بنانا || د لنډلارو کیلیو په کارولو نوی سند جوړول
- Use Ctrl + N short key to create a new blank document. || نیا خالی دستاویز بنانے کے لیے Ctrl + N شارٹ کی استعمال کریں۔ || د نوي خالي سند د جوړولو لپاره Ctrl + N لنډلاره کیلي وکاروئ.
## Editing Text || متن میں ترمیم || د متن سمون
p Editing means making changes in already created document. For this purpose, open an existing file and place cursor at the place where you want changes in the document. || ایڈیٹنگ کا مطلب پہلے سے بنائے گئے متن میں تبدیلیاں کرنا ہے۔ اس مقصد کے لیے موجودہ فائل کھولیں اور کرسر وہاں رکھیں جہاں سے آپ دستاویز میں تبدیلیاں چاہتے ہیں۔ || سمون د مخکې جوړ شوي متن کې د بدلونونو کولو مانا لري. د دې موخې لپاره موجوده فایل پرانیزئ او کرسر هلته کېږدئ چېرته چې تاسو په سند کې بدلونونه غواړئ.
p DEL key is used to delete text from right side and Backspace key is pressed to delete data from left-hand side. For this purpose we have to learn the procedure to load or open an existing file. || ڈیل کی کرسر کے دائیں طرف کا متن مٹانے کے لیے استعمال ہوتی ہے اور بیک اسپیس کی کرسر کے بائیں طرف کا ڈیٹا مٹانے کے لیے دبائی جاتی ہے۔ اس مقصد کے لیے ہمیں موجودہ فائل لوڈ کرنے یا کھولنے کا طریقہ سیکھنا ہوگا۔ || ډیل (DEL) کیلي د کرسر د ښي لوري متن د ړنګولو لپاره کارول کیږي او بیکسپیس (Backspace) کیلي د کرسر د کیڼ لوري ډاټا د ړنګولو لپاره کېکاږل کیږي. د دې موخې لپاره موږ باید د موجوده فایل د پورته کولو یا پرانیستلو بهیر زده کړو.
## Open an Existing Document/file || موجودہ دستاویز/فائل کھولنا || د موجوده سند/فایل پرانیستل
p We can open an existing document in Microsoft Word 2010 using one of the following methods: || ہم مائیکروسافٹ ورڈ ۲۰۱۰ میں موجودہ دستاویز درج ذیل طریقوں میں سے کسی ایک سے کھول سکتے ہیں: || موږ په مایکروسافټ ورډ ۲۰۱۰ کې موجود سند د لاندې طریقو څخه د یوې په کارولو پرانیستلای شو:
- using Office button || آفس بٹن کے ذریعے || د آفس تڼۍ په کارولو
- using Quick Access toolbar || کوئیک ایکسیس ٹول بار کے ذریعے || د چټک لاسرسي د وسایلو پټۍ په کارولو
- using Short key || شارٹ کی کے ذریعے || د لنډلارې کیلي په کارولو
