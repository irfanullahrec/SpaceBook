## Font Size || فونٹ سائز || د فونټ اندازه
p Font size means length and width of the letters or characters. Default font size of Word 2010 is 11; it was 12 in all previous versions of Microsoft Word. We can edit font size by clicking on combo box option of font size or using Ctrl + D short key and changing font size from that dialog box. || فونٹ سائز کا مطلب حروف یا علامات کی لمبائی اور چوڑائی ہے۔ ورڈ ۲۰۱۰ کا ڈیفالٹ فونٹ سائز ۱۱ ہے؛ مائیکروسافٹ ورڈ کے تمام پچھلے ورژنوں میں یہ ۱۲ تھا۔ ہم فونٹ سائز کے کومبو باکس آپشن پر کلک کر کے یا Ctrl + D شارٹ کی استعمال کر کے اور اس ڈائیلاگ باکس سے فونٹ سائز بدل کر فونٹ سائز میں ترمیم کر سکتے ہیں۔ || د فونټ اندازه د توریو یا نښو اوږدوالی او پلنوالی ته وايي. د ورډ ۲۰۱۰ تلواله فونټ اندازه ۱۱ ده؛ دا د مایکروسافټ ورډ په ټولو پخوانیو نسخو کې ۱۲ وه. موږ کولای شو د فونټ د اندازې په کومبو بکس اختیار کلیک کولو یا د Ctrl + D لنډلارې کیلي په کارولو او د هغه د خبرو اترو بکس څخه د فونټ اندازې په بدلولو سره د فونټ اندازه سمه کړو.
