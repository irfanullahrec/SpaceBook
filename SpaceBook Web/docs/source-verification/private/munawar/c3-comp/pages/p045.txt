## Opening an Existing Document/file || موجودہ دستاویز/فائل کھولنا || د موجوده سند/فایل پرانیستل
p We can open an existing document in Microsoft Word 2010 by using one of the following methods: || ہم مائیکروسافٹ ورڈ ۲۰۱۰ میں موجودہ دستاویز درج ذیل طریقوں میں سے کسی ایک سے کھول سکتے ہیں: || موږ په مایکروسافټ ورډ ۲۰۱۰ کې موجود سند د لاندې طریقو څخه د یوې په کارولو پرانیستلای شو:

## Opening/ Loading Existing Document using Office Button || آفس بٹن سے موجودہ دستاویز کھولنا/لوڈ کرنا || د آفس تڼۍ په کارولو موجود سند پرانیستل/پورته کول
