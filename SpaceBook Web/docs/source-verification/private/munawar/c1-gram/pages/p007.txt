q 2 | Change these nouns into plurals by adding only 's'. Rule: we add 's' to most singular nouns to change them into plural nouns, for example pen - pens, fan - fans, bird - birds, boy - boys, book - books, toy - toys. If the singular noun ends in -s, -ss, -sh, -ch or -x, add -es to the end, for example bus - buses, class - classes, dish - dishes, bench - benches, box - boxes. || ان اسماء کو صرف 's' لگا کر جمع بنائیں۔ اصول: ہم زیادہ تر واحد اسماء کو جمع بنانے کے لیے 's' لگاتے ہیں، مثلاً pen - pens، fan - fans، bird - birds، boy - boys، book - books، toy - toys۔ اگر واحد اسم کے آخر میں -s، -ss، -sh، -ch یا -x ہو تو اس کے آخر میں -es لگائیں، مثلاً bus - buses، class - classes، dish - dishes، bench - benches، box - boxes۔ || دا نومونه یوازې 's' اضافه کولو سره جمع کړئ. اصل: موږ ډېری مفرد نومونو ته د جمع کولو لپاره 's' اضافه کوو، لکه pen - pens، fan - fans، bird - birds، boy - boys، book - books، toy - toys. که مفرد نوم په -s، -ss، -sh، -ch یا -x پای ته رسېږي نو په پای کې -es اضافه کړئ، لکه bus - buses، class - classes، dish - dishes، bench - benches، box - boxes.
