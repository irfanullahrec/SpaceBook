# معصومه ابی

slo په بیان کښې په استعمال شوو روزمرو، محاورو او متلونو وغېره داسې پوهه شي چې په خپلله ئې هم د پکارولو توان ولري۔

p لنډیز: د معصومې ابي خپل نوم معصوم جان وۀ چې د ملاکنډ اجنسۍ د بټ ځلې کلي په یوه درنه کورني کښې د توتي خان سلطان خېل بلې یوسفزي په کال 1855ء کښې پېدا شوې وه۔ هغه د کلي د مشرانو حېثیت درلود او د معصومې جرګې مرکې او روغې جوړې به ئې کولې۔ د هغې د پلار ورور د ملاکنډ په یوه معتبره کورنۍ کښې د عبدالاکبر خان زوي شمس الدین سره واده شو او د هغۀ دوه زامن دواخان او شېر خان پېدا شول۔
p د انګرېز راتلو نه مخکښې د پښتنو په علاقو کښې به په جمهوري طریقه جوړېده، د کومې ډلې به چې اکثریت وۀ هغې ته ئې «ډله باندې» وئیل۔ د علاقې د امن په خاطر به د علاقې مشرانو د «ډله باندې» ته او «ډله لاندې» ته جمهوري طریقه اختیار ورکړو۔
