# د سپین تنګي غزا
p د دې سبق وئیلو نه پس به زده کوونکي:
slo د رائې د اختلاف په وخت د لوے زړۀ څرګندونه وکړے شي۔
slo د تولنیز او سماجي شعور په اړوند د یو فعال انسان په حېث برخه واخلي۔
slo د یو بیان، لیک یا پېښې په حقله خپله کوټلي رائې ورکولے شي۔
slo د ګران عبارت، قیصې، تقریر په اوربدو د لنډیز کولو جوګه شي۔
