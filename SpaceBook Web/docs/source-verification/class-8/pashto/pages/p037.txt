sol د کتاب د فرهنګ له مخې: پېغام = خبر؛ برداشت = زغم؛ زغل = منده؛ راستي = په نېغه لاره تلل، بېداري؛ سمسور = ښېرازه؛ دا لفظونه په فرهنګ کښې نشته: پرېزو۔ || From the glossary (فرهنګ) at the end of the book: پېغام = خبر; برداشت = زغم; زغل = منده; راستي = په نېغه لاره تلل، بېداري; سمسور = ښېرازه; not in the glossary: پرېزو. || کتاب کے آخر کے فرہنگ کے مطابق: پېغام = خبر؛ برداشت = زغم؛ زغل = منده؛ راستي = په نېغه لاره تلل، بېداري؛ سمسور = ښېرازه؛ فرہنگ میں موجود نہیں: پرېزو۔
