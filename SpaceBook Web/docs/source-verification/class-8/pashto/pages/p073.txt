# پښتانۀ قدرونه
p د دې سبق وئیلو نه پس به زده کوونکي:
slo د اوربدلو بیانونو په ذریعه خپل ملي او سماجي قدرونه په عمل کښې راوستو جوګه شي۔
slo د خپلو ساهو قدرونو او ژوند ژواک په حقله دومره واوري چې په دلیل سره پرې د خبرو کولو جوګه شي۔
slo د خپل تهذیب، تاریخ او ثقافت په حقله لیکونه په تنقیدي نظر ولوستے شي۔
slo د پښتو او پښتونولۍ د خانګرتیا نه نور خلق خبر کړے شي۔
slo خپل ساهو قدرونه او مثبت رواجونه هم خپل کړي او هم پرې فخر کولے شي۔
@issue Summarised: long continuous prose, summarised page by page.
p لنډیز: کلچر یا ثقافت (Culture) د یو قام د ژوند د ځانګړي طور طریقو نوم دے۔ دا د یو قام هغه خاصه ژبه، جامې، پېژندګلو، رسمونه او رواجونه، مذهبي عقیدې، روایات، عادتونه، نفسیات او تصورات دي۔ پښتو قام هم د ډېرو نورو قامونو په شان خپل یو ستر ثقافت لري۔
