# د ملاکنډ غزا
p د دې سبق وئیلو نه پس به زده کوونکي:
slo د خپل تهذیب، تاریخ او ثقافت لوست په حقیقت پسندۍ وکړے شي۔
slo د خپلو روایاتو په حواله ورسره دلیل نیم وي۔
slo د رایې د اختلاف په حال کښې خپله خبره په مدلل انداز او سره سینه کولے شي۔
slo د اسم نکره قسمونه بیان کړے شي۔
