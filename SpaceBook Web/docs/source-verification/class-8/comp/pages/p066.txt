p In Program # 7, we created a nested loop structure using 2 variables, i.e. 'i' and 'j' to print a table of numbers. In line 1, we initialize the variable 'table_size' to 5. This way, our table will consists of 5 rows and 5 columns. In line 2, the outer loop is controlled via 'i' which starts with value 0 and thereafter program moves to inner loop which is controlled through 'j'. Hence, for every iteration of the outer loop, the inner loop will complete and then the value of outer loop will increment and the inner loop will execute again; till the outer loop completes and terminates.
