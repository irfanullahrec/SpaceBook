## 1.4 Communication Devices || 1.4 مواصلاتی آلات || 1.4 د مخابرې وسایل
p A communication device is used for communication between different ICT devices. It transmits information using wired or wireless connection. || مواصلاتی آلہ مختلف ICT آلات کے درمیان رابطے کے لیے استعمال ہوتا ہے۔ یہ تار والے یا وائرلیس رابطے کے ذریعے معلومات منتقل کرتا ہے۔ || د مخابرې وسیله د بېلابېلو ICT وسایلو ترمنځ د اړیکې لپاره کارول کېږي. دا د تار لرونکې یا بېسیمه اړیکې په مرسته معلومات لېږدوي.
### 1.4.1 Network Hub || 1.4.1 نیٹ ورک ہب || 1.4.1 د شبکې هب
p A hub is a network device that connects multiple computer together in a small network. Generally, it is used in a LAN. It receives data from a computer and transmits it to all the computers in the network. Only the computer to which it is destined will accept the data while the others will ignore it. || ہب ایک نیٹ ورک آلہ ہے جو چھوٹے نیٹ ورک میں متعدد کمپیوٹرز کو آپس میں جوڑتا ہے۔ عموماً یہ LAN میں استعمال ہوتا ہے۔ یہ ایک کمپیوٹر سے ڈیٹا وصول کر کے نیٹ ورک کے تمام کمپیوٹرز کو بھیج دیتا ہے۔ صرف وہی کمپیوٹر ڈیٹا قبول کرے گا جس کے لیے وہ ہو، باقی اسے نظر انداز کر دیں گے۔ || هب د شبکې داسې وسیله ده چې په وړوکې شبکه کې څو کمپیوټرونه یو ځای سره نښلوي. عموماً دا په LAN کې کارول کېږي. دا له یوه کمپیوټر څخه ډېټا ترلاسه کوي او په شبکه کې ټولو کمپیوټرونو ته یې لېږي. یوازې هغه کمپیوټر به ډېټا ومني چې د هغه لپاره وي، نور به یې له پامه غورځوي.
### 1.4.2 Network Switch || 1.4.2 نیٹ ورک سوئچ || 1.4.2 د شبکې سویچ
p Network switch is a device that allows computers in a network to connect with one another using wired communication. It receives message from any device connected to the network and transmits that message directly to its destination computer. It maintains a table (MAC) for forwarding data. || نیٹ ورک سوئچ ایسا آلہ ہے جو نیٹ ورک میں کمپیوٹرز کو تار والے رابطے کے ذریعے ایک دوسرے سے جڑنے دیتا ہے۔ یہ نیٹ ورک سے جڑے کسی بھی آلے سے پیغام وصول کر کے اسے براہ راست منزل کے کمپیوٹر کو بھیجتا ہے۔ یہ ڈیٹا آگے بھیجنے کے لیے ایک جدول (MAC) رکھتا ہے۔ || د شبکې سویچ داسې وسیله ده چې په شبکه کې کمپیوټرونه د تار لرونکې اړیکې په کارولو سره یو له بل سره نښلېدو ته اجازه ورکوي. دا د شبکې سره تړل شوې هر وسیله څخه پیغام ترلاسه کوي او مستقیم یې د رسېدو کمپیوټر ته لېږي. دا د ډېټا د مخ په وړاندې لېږلو لپاره یو جدول (MAC) ساتي.
### 1.4.3 Router || 1.4.3 راؤٹر || 1.4.3 روټر
p A router is a network device which connects two or more LANs. It forwards incoming message using the best route towards the destination. It maintains routing table for forwarding data. || راؤٹر ایک نیٹ ورک آلہ ہے جو دو یا زیادہ LANs کو جوڑتا ہے۔ یہ آنے والے پیغام کو منزل کی طرف بہترین راستے سے آگے بھیجتا ہے۔ یہ ڈیٹا آگے بھیجنے کے لیے روٹنگ ٹیبل رکھتا ہے۔ || روټر د شبکې داسې وسیله ده چې دوه یا زیات LANs سره نښلوي. دا راتلونکی پیغام د رسېدو ځای ته د غوره لارې په کارولو سره مخ په وړاندې لېږي. دا د ډېټا د لېږلو لپاره د لارې جدول ساتي.
