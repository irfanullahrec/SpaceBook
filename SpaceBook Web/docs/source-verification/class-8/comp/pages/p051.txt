- 1. Write a pseudocode that tells a user that the number entered is not a five or a six. || 1۔ ایسا سوڈو کوڈ لکھیں جو صارف کو بتائے کہ درج کیا گیا عدد پانچ یا چھ نہیں ہے۔ || ۱. داسې سوډو کوډ ولیکئ چې کاروونکي ته ووايي چې داخل شوې شمېره پنځه یا شپږ نه ده.
- 2. Write pseudo code that performs the following: Ask a user to enter a number. If the number is between 0 and 10, write the word blue. If the number is between 10 and 20, write the word red. If the number is between 20 and 30, write the word green. If it is any other number, write that 'it is not a correct color option'. || 2۔ ایسا سوڈو کوڈ لکھیں جو درج ذیل کام کرے: صارف سے ایک عدد درج کرنے کو کہیں۔ اگر عدد 0 اور 10 کے درمیان ہو تو لفظ blue لکھیں۔ اگر عدد 10 اور 20 کے درمیان ہو تو لفظ red لکھیں۔ اگر عدد 20 اور 30 کے درمیان ہو تو لفظ green لکھیں۔ اگر کوئی اور عدد ہو تو لکھیں کہ 'it is not a correct color option'۔ || ۲. داسې سوډو کوډ ولیکئ چې دا ترسره کړي: له کاروونکي وغواړئ چې یوه شمېره داخله کړي. که شمېره د ۰ او ۱۰ ترمنځ وي نو کلمه blue ولیکئ. که د ۱۰ او ۲۰ ترمنځ وي نو کلمه red ولیکئ. که د ۲۰ او ۳۰ ترمنځ وي نو کلمه green ولیکئ. که بله هره شمېره وي نو ولیکئ چې 'it is not a correct color option'.
- 3. Give pseudocode of rolling a dice program between 2 players, turn by turn. If dice rolls a 6, the same player rolls the dice again. || 3۔ دو کھلاڑیوں کے درمیان باری باری پانسہ پھینکنے کے پروگرام کا سوڈو کوڈ دیں۔ اگر پانسہ 6 آئے تو وہی کھلاڑی دوبارہ پانسہ پھینکے۔ || ۳. د دوو لوبغاړو ترمنځ په نوبت د ډوب (ډایس) غورځولو پروګرام سوډو کوډ ورکړئ. که ډوب ۶ راشي نو همدا لوبغاړی بیا ډوب وغورځوي.
- 4. Develop the pseudocode, that execute the above pseudocode 10 times, count the score of both players and announce the winner or match drawn; in the end. || 4۔ ایسا سوڈو کوڈ تیار کریں جو اوپر والے سوڈو کوڈ کو 10 بار چلائے، دونوں کھلاڑیوں کا اسکور گنے اور آخر میں فاتح یا میچ برابر ہونے کا اعلان کرے۔ || ۴. داسې سوډو کوډ جوړ کړئ چې پورتنی سوډو کوډ ۱۰ ځله اجرا کړي، د دواړو لوبغاړو سکور وشمېري او په پای کې ګټونکی یا برابره لوبه اعلان کړي.
