### 4.3.4 Cloning a Sprite || 4.3.4 اسپرائٹ کی کلوننگ || 4.3.4 د سپرایټ کلوننګ
p Scratch allows a sprite to be duplicated, not only once but multiple times. It is useful in cases where you can create a snowflake and replicate it multiple times to give the effect of snowfall. Similarly, in games you can design a bullet and reproduce it to be used in a game, etc. In the figure, 'create clone of sprite_name' is used to replicate 'Snowflake' sprite wherever a mouse is clicked. The corresponding code is shown as well. || Scratch اسپرائٹ کو نہ صرف ایک بار بلکہ کئی بار نقل کرنے کی اجازت دیتا ہے۔ یہ ان صورتوں میں مفید ہے جہاں آپ ایک برف کا گالا بنا کر اسے کئی بار دہرا سکتے ہیں تاکہ برف باری کا تاثر پیدا ہو۔ اسی طرح گیمز میں آپ ایک گولی ڈیزائن کر کے اسے دوبارہ پیدا کر کے گیم میں استعمال کر سکتے ہیں وغیرہ۔ شکل میں 'create clone of sprite_name' استعمال کیا گیا ہے تاکہ ماؤس کلک ہونے پر 'Snowflake' اسپرائٹ کی نقل ہو۔ متعلقہ کوڈ بھی دکھایا گیا ہے۔ || Scratch اجازه ورکوي چې یو سپرایټ نه یوازې یو ځل بلکې څو ځله نقل شي. دا په هغو حالتونو کې ګټور دی چېرته چې تاسو یو واورې پاڼه جوړولای شئ او څو ځله یې تکرار کړئ ترڅو د واورې اورېدو اغېز ورکړئ. همداسې په لوبو کې تاسو کولای شئ یوه ګولۍ ډیزاین کړئ او یې بیا جوړه کړئ ترڅو په لوبه کې وکارول شي او نور. په انځور کې 'create clone of sprite_name' کارول شوی ترڅو 'Snowflake' سپرایټ هر چېرته چې موږک کلیک شي نقل کړي. اړوند کوډ هم ښودل شوی.
