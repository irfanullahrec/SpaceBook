### 4.3.3 Rounding off Numbers || 4.3.3 اعداد کو راؤنڈ آف کرنا || 4.3.3 شمېرې شاوخوا کول (Rounding off)
p To round-off numbers, round( ) function is used. However, for round-down floor( ) function and for round-up. Ceiling( ) function is used as shown in figures. || اعداد کو راؤنڈ آف کرنے کے لیے round( ) فنکشن استعمال ہوتا ہے۔ تاہم نیچے کی طرف راؤنڈ کرنے کے لیے floor( ) فنکشن اور اوپر کی طرف راؤنڈ کرنے کے لیے ceiling( ) فنکشن استعمال ہوتا ہے جیسا کہ شکلوں میں دکھایا گیا ہے۔ || د شمېرو د شاوخوا کولو لپاره round( ) فنکشن کارول کېږي. خو د ښکته شاوخوا کولو لپاره floor( ) فنکشن او د پورته شاوخوا کولو لپاره ceiling( ) فنکشن کارول کېږي لکه څنګه چې په انځورونو کې ښودل شوي.
- round() rounds up a number for every decimal number greater than 4, else the said number is round down. || round() ہر اس اعشاری عدد کو اوپر راؤنڈ کرتا ہے جو 4 سے بڑا ہو، ورنہ مذکورہ عدد نیچے راؤنڈ ہوتا ہے۔ || round() هره اعشاري شمېره چې له ۴ لویه وي پورته شاوخوا کوي، که نه نو ویل شوې شمېره ښکته شاوخوا کېږي.
