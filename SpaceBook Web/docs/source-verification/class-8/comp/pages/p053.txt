## 4.1 Visual versus Textual Programming || 4.1 بصری بمقابلہ متنی پروگرامنگ || 4.1 لیدنی پروګرامینګ په پرتله متني پروګرامینګ
p Generally, programming languages are either textual or visual in nature. In former, input is taken from user and corresponding code for processing is created via keyboard like in Python, whereas in latter like Scratch, program is created through drag & drop components. Visual programming is more appropriate for novice or casual programmers whereas textual programming is suggested for the ones having already some skills. In this unit, some basic components of Python language will also be discussed. || عموماً پروگرامنگ زبانیں فطرت میں یا تو متنی ہوتی ہیں یا بصری۔ پہلی قسم میں صارف سے ان پٹ لیا جاتا ہے اور پروسیسنگ کا متعلقہ کوڈ کی بورڈ کے ذریعے بنایا جاتا ہے جیسے Python میں، جبکہ دوسری قسم میں، جیسے Scratch، پروگرام ڈریگ اینڈ ڈراپ اجزا کے ذریعے بنتا ہے۔ بصری پروگرامنگ نئے یا کبھی کبھار پروگرامنگ کرنے والوں کے لیے زیادہ موزوں ہے جبکہ متنی پروگرامنگ ان کے لیے تجویز کی جاتی ہے جن کے پاس پہلے سے کچھ مہارت ہو۔ اس یونٹ میں Python زبان کے کچھ بنیادی اجزا پر بھی بات کی جائے گی۔ || په عمومي ډول پروګرامینګ ژبې یا متني وي یا لیدنۍ. په لومړي ډول کې له کاروونکي څخه ان پټ اخیستل کېږي او د پروسس اړوند کوډ د کیبورډ له لارې جوړېږي لکه په Python کې، پداسې حال کې چې په دویم ډول کې، لکه Scratch، پروګرام د ډراګ او ډراپ اجزاوو له لارې جوړېږي. لیدنی پروګرامینګ د نویو یا کله ناکله پروګرامرانو لپاره ډېر مناسب دی پداسې حال کې چې متني پروګرامینګ د هغو لپاره وړاندیز کېږي چې مخکې ځینې مهارتونه لري. په دې یونټ کې به د Python ژبې ځینې بنسټیزې برخې هم وڅېړل شي.
