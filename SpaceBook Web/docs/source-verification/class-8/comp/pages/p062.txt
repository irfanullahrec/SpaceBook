## 4.5 An Overview of Textual Programming Language: Python || 4.5 متنی پروگرامنگ زبان کا جائزہ: Python || 4.5 د متني پروګرامینګ ژبې کتنه: Python
p Among the textual programming languages, Python is the one that has become quite popular in recent years. Python is not only fun to learn but also a platform to develop projects for state-of-the-art technologies. Python is free and its programs can run on any platform. Furthermore, as compared to other textual programming languages, code is generally smaller when written in Python; approximately half. The applications of Python programs currently in use include traffic control systems, e-commerce, movies and entertainment (most famous being YouTube), etc. || متنی پروگرامنگ زبانوں میں Python وہ زبان ہے جو حالیہ برسوں میں کافی مقبول ہو گئی ہے۔ Python سیکھنا نہ صرف دلچسپ ہے بلکہ جدید ترین ٹیکنالوجیز کے منصوبے تیار کرنے کا پلیٹ فارم بھی ہے۔ Python مفت ہے اور اس کے پروگرام کسی بھی پلیٹ فارم پر چل سکتے ہیں۔ مزید یہ کہ دیگر متنی پروگرامنگ زبانوں کے مقابلے میں Python میں لکھا گیا کوڈ عموماً چھوٹا، تقریباً آدھا، ہوتا ہے۔ فی الحال استعمال میں Python پروگراموں کی ایپلی کیشنز میں ٹریفک کنٹرول سسٹم، ای کامرس، فلمیں اور تفریح (جن میں سب سے مشہور YouTube ہے) وغیرہ شامل ہیں۔ || د متني پروګرامینګ ژبو په منځ کې Python هغه ده چې په وروستیو کلونو کې ډېره مشهوره شوې. Python نه یوازې د زده کړې لپاره په زړه پورې دی بلکې د وروستیو ټکنالوژیو د پروژو د جوړولو پلیټفارم هم دی. Python وړیا دی او پروګرامونه یې په هر پلیټفارم چلېدای شي. سربېره پر دې د نورو متني پروګرامینګ ژبو په پرتله په Python کې لیکل شوی کوډ عموماً کوچنی، نږدې نیم، وي. د Python پروګرامونو اوسني کارول کېدونکي اپلېکېشنونه د ټرافیک کنټرول سیستمونه، بریښنایي سوداګري، فلمونه او تفریح (ډېر مشهور یې YouTube) او نور شامل دي.
### 4.5.1 Storing Data in Variables || 4.5.1 متغیرات میں ڈیٹا محفوظ کرنا || 4.5.1 په متغیرونو کې ډېټا ذخیره کول
