p A loop is a set of instructions which needs to be iterated repeatedly, to acquire a particular result. A 'for' loop syntax is shown in program-5. Python sets the value of variable 'i' to 0 by default and is incremented by 1 in every iteration. Since, the range we have defined is '3', the program will iterate 3 times but as the value of variable 'i' started from 0, therefore at the end of the loop the value of 'i' will be 2.
