### 3.2.5 Nested Loops || 3.2.5 نیسٹڈ لوپس || 3.2.5 نیسټ شوي لوپونه
p Loops can be enclosed inside another loop (called nested loops). Nested loops are useful when an iterative task is to be done for multiple times. || لوپس کو دوسرے لوپ کے اندر رکھا جا سکتا ہے (جنھیں نیسٹڈ لوپس کہتے ہیں)۔ نیسٹڈ لوپس اس وقت مفید ہوتے ہیں جب کوئی تکراری کام کئی بار کرنا ہو۔ || لوپونه په بل لوپ کې شاملېدای شي (چې نیسټ شوي لوپونه بلل کېږي). نیسټ شوي لوپونه هغه مهال ګټور دي چې یو تکراري کار څو ځله باید ترسره شي.
p Consider the example of clock, where the large hand (minute hand) points to the minutes. It goes once around the clock every 60 minutes making one hour and moving the small hand (hour hand). This is perfect example of nesting loop. Let us study the same concept from computer's perspective. || گھڑی کی مثال پر غور کریں جہاں بڑی سوئی (منٹ کی سوئی) منٹ بتاتی ہے۔ یہ ہر 60 منٹ میں گھڑی کا ایک چکر لگاتی ہے جس سے ایک گھنٹہ بنتا ہے اور چھوٹی سوئی (گھنٹے کی سوئی) آگے بڑھتی ہے۔ یہ نیسٹنگ لوپ کی بہترین مثال ہے۔ آئیے اسی تصور کو کمپیوٹر کے نقطۂ نظر سے پڑھیں۔ || د ګړۍ بېلګې ته پام وکړئ چېرته چې لویه ستنه (دقیقې ستنه) دقیقې ښيي. دا هر ۶۰ دقیقې کې یو ځل د ګړۍ شاوخوا ګرځي چې یو ساعت جوړوي او وړه ستنه (د ساعت ستنه) حرکت کوي. دا د نیسټ شوي لوپ ښه بېلګه ده. راځئ همدا مفکوره د کمپیوټر له نظره ولولو.
box code | Nested loops || نیسٹڈ لوپس || نیسټ شوي لوپونه
m Line 0:  pseudocode
m Line 1:  Loop1:
m Line 2:      Loop2:
m Line 3:          pseudocode...
m Line 4:          pseudocode...
m Line 5:          pseudocode...
m Line 6:      End loop2
m Line 7:  End loop1
endbox
p Example 7: The pseudocode below calculates a mathematical table and displays on screen from 2 to 10, where each mathematical table is displayed for the first 10 values. || مثال 7: نیچے دیا گیا سوڈو کوڈ 2 سے 10 تک ریاضی کا پہاڑا نکال کر اسکرین پر دکھاتا ہے، جہاں ہر پہاڑا پہلی 10 قدروں کے لیے دکھایا جاتا ہے۔ || بېلګه ۷: لاندې سوډو کوډ له ۲ څخه تر ۱۰ پورې ریاضيکي جدول محاسبه کوي او په سکرین یې ښيي، چېرته چې هر ریاضيکي جدول د لومړیو ۱۰ ارزښتونو لپاره ښودل کېږي.
box code | Pseudocode (Example 7) || سوڈو کوڈ (مثال 7) || سوډو کوډ (۷ بېلګه)
m Line 0:  Set table = 2
m Line 1:  Loop1: repeat:
m Line 2:      Set index = 1
m Line 3:      Loop2: repeat:
m Line 4:          Result = Multiply table with index
m Line 5:          Display "table X index = Result"
m Line 6:          Increase index by 1.
m Line 7:      Until <index 11>
m Line 8:  Increase table by 1.
m Line 9:  Until <table 11>
endbox
