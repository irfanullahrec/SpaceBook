@issue Properties a)–g) on pages 24–25 (reflexive … division) are properties of equality, but the book prints no sub-heading for them; none is added.
p **a) Reflexive Property** || **a) انعکاسی خاصیت** || **a) انعکاسي ځانګړتیا**
p This property states that $\forall\, a \in R$: $a = a$ i.e. a number or value is equal to itself. This property states that for all real numbers. || یہ خاصیت بیان کرتا ہے کہ $\forall\, a \in R$: $a = a$ یعنی کوئی عدد یا قیمت اپنے برابر ہوتی ہے۔ یہ خاصیت تمام حقیقی اعداد کے لیے درست ہے۔ || دا ځانګړتیا وايي چې $\forall\, a \in R$: $a = a$ یعنې یو عدد یا ارزښت له خپل ځان سره برابر دی. دا ځانګړتیا د ټولو حقیقي عددونو لپاره ده.
p For example, || مثال کے طور پر، || د بېلګې په توګه،
m $3 = 3$
m $\sqrt{2} = \sqrt{2}$
m $-1.3 = -1.3$
m $1.3 + \sqrt{7} = 1.3 + \sqrt{7}$ and so on.
p **b) Symmetric Property** || **b) تشاکلی خاصیت** || **b) تناظري ځانګړتیا**
p This property states that $\forall\, a \in R$: if $a = b$ then $b = a$. i.e. interchange the sides of an equation doesn't affect the result. || یہ خاصیت بیان کرتا ہے کہ $\forall\, a \in R$: اگر $a = b$ تو $b = a$۔ یعنی مساوات کے اطراف آپس میں بدلنے سے نتیجہ متاثر نہیں ہوتا۔ || دا ځانګړتیا وايي چې $\forall\, a \in R$: که $a = b$ وي نو $b = a$. یعنې د معادلې د خواوو بدلول پایله نه اغېزمنوي.
p For example: || مثال کے طور پر: || د بېلګې په توګه:
m If $a + b = c$, then $c = a + b$
m If $2 + a = b$, then $b = 2 + a$
m $8 - x = c$ then $c = 8 - x$ and so on.
p **c) Transitive Property** || **c) متعدی خاصیت** || **c) لېږدېدونکې ځانګړتیا**
p This property states that $\forall\, a, b, c \in R$, if $a = b$ and $b = c$, then $a = c$. i.e. if $a$ is related to $b$ under a rule, and $b$ is related to $c$ under the same rule, then $a$ is related to $c$ under the same rule. For example, || یہ خاصیت بیان کرتا ہے کہ $\forall\, a, b, c \in R$، اگر $a = b$ اور $b = c$ تو $a = c$۔ یعنی اگر کسی اصول کے تحت $a$ کا تعلق $b$ سے ہو اور اسی اصول کے تحت $b$ کا تعلق $c$ سے ہو تو اسی اصول کے تحت $a$ کا تعلق $c$ سے ہوگا۔ مثال کے طور پر، || دا ځانګړتیا وايي چې $\forall\, a, b, c \in R$، که $a = b$ او $b = c$ وي، نو $a = c$. یعنې که $a$ د یوه قاعدې له مخې له $b$ سره اړیکه ولري، او $b$ د همدې قاعدې له مخې له $c$ سره اړیکه ولري، نو $a$ د همدې قاعدې له مخې له $c$ سره اړیکه لري. د بېلګې په توګه،
m $3x + 5 = y$ and $y = x - 1$, then $3x + 5 = x - 1$.
p **d) Addition Property** || **d) جمع کی خاصیت** || **d) د جمع ځانګړتیا**
p This property states that $\forall\, a, b, c \in R$, if $a = b$, then $a + c = b + c$. i.e., adding the same number on both sides of equation, doesn't change the equation. || یہ خاصیت بیان کرتا ہے کہ $\forall\, a, b, c \in R$، اگر $a = b$ تو $a + c = b + c$۔ یعنی مساوات کے دونوں طرف ایک ہی عدد جمع کرنے سے مساوات تبدیل نہیں ہوتی۔ || دا ځانګړتیا وايي چې $\forall\, a, b, c \in R$، که $a = b$ وي، نو $a + c = b + c$. یعنې د معادلې دواړو خواوو ته د یوه عدد جمع کول معادله نه بدلوي.
p For example: || مثال کے طور پر: || د بېلګې په توګه:
m If $x = 5$, then $x + 1 = 5 + 1$.
p **e) Subtraction Property** || **e) تفریق کی خاصیت** || **e) د تفریق ځانګړتیا**
p This property states that $\forall\, a, b, c \in R$, if $a = b$, then $a - c = b - c$, i.e., subtracting the same number from both sides of equation, doesn't change the equation. || یہ خاصیت بیان کرتا ہے کہ $\forall\, a, b, c \in R$، اگر $a = b$ تو $a - c = b - c$، یعنی مساوات کے دونوں طرف سے ایک ہی عدد تفریق کرنے سے مساوات تبدیل نہیں ہوتی۔ || دا ځانګړتیا وايي چې $\forall\, a, b, c \in R$، که $a = b$ وي، نو $a - c = b - c$، یعنې د معادلې له دواړو خواوو څخه د یوه عدد کمول معادله نه بدلوي.
p For example: || مثال کے طور پر: || د بېلګې په توګه:
m If $x = 6$, then $x - 2 = 6 - 2$.
