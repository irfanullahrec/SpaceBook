p Let us now find all possible subsets of a set. || آئیے اب کسی سیٹ کے تمام ممکنہ ذیلی سیٹ معلوم کریں۔ || راځئ اوس د یوه سېټ ټول ممکنه فرعي سېټونه ومومو.
example 2
p List all possible subsets of the set X = {1, 2, 3} || سیٹ X = {1, 2, 3} کے تمام ممکنہ ذیلی سیٹوں کی فہرست بنائیں || د X = {1, 2, 3} سېټ ټول ممکنه فرعي سېټونه لېست کړئ
## Solution: || حل: || حل:
qp i | ϕ is the subset of the set X. || ϕ سیٹ X کا ذیلی سیٹ ہے۔ || ϕ د X سېټ فرعي سېټ دی.
qp ii | Singleton subsets of X are, {1}, {2}, {3} || X کے واحد رکنی ذیلی سیٹ {1}، {2}، {3} ہیں || د X یو عنصري فرعي سېټونه {1}، {2}، {3} دي
qp iii | Subset of X having two elements are; {1, 2}, {2,3}, {1,3} || X کے دو ارکان والے ذیلی سیٹ ہیں؛ {1, 2}، {2,3}، {1,3} || د X دوه عنصري فرعي سېټونه دي؛ {1, 2}، {2,3}، {1,3}
qp iv | Since each set is an improper subset of itself, therefore the set itself i.e. {1, 2, 3} is also a subset of itself. || چونکہ ہر سیٹ اپنا غیر واجب ذیلی سیٹ ہوتا ہے، اس لیے سیٹ خود یعنی {1, 2, 3} بھی اپنا ذیلی سیٹ ہے۔ || څرنګه چې هر سېټ د خپل ځان ناواجب فرعي سېټ دی، نو سېټ پخپله یعنې {1, 2, 3} هم د خپل ځان فرعي سېټ دی.
p Now count the subsets of X. These are 8. We can organise the subsets as follows; || اب X کے ذیلی سیٹ گنیں۔ یہ 8 ہیں۔ ہم ذیلی سیٹوں کو یوں ترتیب دے سکتے ہیں؛ || اوس د X فرعي سېټونه وشمېرئ. دا 8 دي. فرعي سېټونه داسې تنظیمولی شو؛

p Observe that the set X has 3 elements and the number of subsets of X is $2^3 = 8$. || غور کریں کہ سیٹ X میں 3 ارکان ہیں اور X کے ذیلی سیٹوں کی تعداد $2^3 = 8$ ہے۔ || وګورئ چې X سېټ 3 عناصر لري او د X د فرعي سېټونو شمېر $2^3 = 8$ دی.

example 3
p Find all the possible subsets of the set B = {2, 4, 6, 8} || سیٹ B = {2, 4, 6, 8} کے تمام ممکنہ ذیلی سیٹ معلوم کریں || د B = {2, 4, 6, 8} سېټ ټول ممکنه فرعي سېټونه ومومئ
## Solution: || حل: || حل:
p All possible subsets of the set B are listed as; || سیٹ B کے تمام ممکنہ ذیلی سیٹ یوں درج ہیں؛ || د B سېټ ټول ممکنه فرعي سېټونه داسې لېست شوي؛
m ϕ, {2}, {4}, {6}, {8}, {2, 4}, {2, 6}, {2, 8}, {4, 6}, {4, 8}, {6, 8}, {2, 4, 6}, {2, 4, 8}, {2, 6, 8}, {4, 6, 8}, {2, 4, 6, 8}.
p These are 16. Observe that the set B has 4 elements and $2^4 = 16$ || یہ 16 ہیں۔ غور کریں کہ سیٹ B میں 4 ارکان ہیں اور $2^4 = 16$ || دا 16 دي. وګورئ چې B سېټ 4 عناصر لري او $2^4 = 16$
endexample
p From the above two examples; we see that the set having 3 elements has $2^3 = 8$ subsets and the set having 4 elements has $2^4 = 16$ subsets. || اوپر کی دونوں مثالوں سے ہم دیکھتے ہیں کہ 3 ارکان والے سیٹ کے $2^3 = 8$ ذیلی سیٹ اور 4 ارکان والے سیٹ کے $2^4 = 16$ ذیلی سیٹ ہوتے ہیں۔ || له پورتنیو دوو بېلګو ګورو چې د 3 عناصرو لرونکی سېټ $2^3 = 8$ فرعي سېټونه او د 4 عناصرو لرونکی سېټ $2^4 = 16$ فرعي سېټونه لري.
p In general; || عام طور پر؛ || په عمومي ډول؛
p A set having n elements has $2^n$ possible subsets. || n ارکان والے سیٹ کے $2^n$ ممکنہ ذیلی سیٹ ہوتے ہیں۔ || د n عناصرو لرونکی سېټ $2^n$ ممکنه فرعي سېټونه لري.
