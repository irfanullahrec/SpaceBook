@sec u5-summary | Summary || خلاصہ || لنډیز
## Summary || خلاصہ || لنډیز
- In set builder form, instead of listing the elements, a common rule, characteristic or formula is written in the shortest possible form that describes the elements of the set. || سیٹ بلڈر شکل میں ارکان کی فہرست کے بجائے ایک مشترکہ اصول، خصوصیت یا فارمولا مختصر ترین شکل میں لکھا جاتا ہے جو سیٹ کے ارکان کو بیان کرتا ہے۔ || د سېټ جوړونکې په بڼه کې د عناصرو د لېست پر ځای، یوه ګډه قاعده، ځانګړتیا یا فورمول په تر ټولو لنډه بڼه لیکل کېږي چې د سېټ عناصر تشریح کوي.
- The set that consists of all the subsets of a set is called the power set of that set. For any set X; the power set of X is written as P (X). || وہ سیٹ جو کسی سیٹ کے تمام ذیلی سیٹوں پر مشتمل ہو، اس سیٹ کا پاور سیٹ کہلاتا ہے۔ کسی بھی سیٹ X کے لیے X کا پاور سیٹ P (X) لکھا جاتا ہے۔ || هغه سېټ چې د یوه سېټ ټول فرعي سېټونه ولري، د هغه سېټ د توان سېټ بلل کېږي. د هر سېټ X لپاره، د X د توان سېټ P (X) لیکل کېږي.
