@sec 8.3 | Substitution Method || تعویض کا طریقہ || د ځای ناستي طریقه
# 8.3 Substitution Method || 8.3 تعویض کا طریقہ || 8.3 د ځای ناستي طریقه
p In this method, we take any one of the given equations first and find the value of one of the variables in terms of the other. Then we substitute this value of the variable in the second equation. In this way, the second equation reduces to a third equation which is a linear equation in one variable. Hence, the value of one of the variables is found by solving the third equation. Finally, we substitute (put) this value of one variable in any of the given equations that gives us the value of the other variable on solving it. This method has ben further explained with the help of the following examples. || اس طریقے میں ہم پہلے دی گئی مساواتوں میں سے کوئی ایک لیتے ہیں اور ایک متغیر کی قیمت دوسرے کی صورت میں معلوم کرتے ہیں۔ پھر متغیر کی یہ قیمت دوسری مساوات میں رکھتے ہیں۔ اس طرح دوسری مساوات ایک تیسری مساوات میں بدل جاتی ہے جو ایک متغیر میں خطی مساوات ہے۔ لہٰذا تیسری مساوات حل کر کے ایک متغیر کی قیمت معلوم ہوتی ہے۔ آخر میں ہم ایک متغیر کی یہ قیمت دی گئی کسی بھی مساوات میں رکھتے ہیں جسے حل کرنے سے دوسرے متغیر کی قیمت ملتی ہے۔ اس طریقے کو درج ذیل مثالوں کی مدد سے مزید واضح کیا گیا ہے۔ || په دې طریقه کې لومړی له ورکړل شویو معادلو یوه اخلو او د یوه متغیر ارزښت د بل په بڼه مومو. بیا د متغیر دا ارزښت په دوهمه معادله کې ږدو. په دې ډول دوهمه معادله درېیمې معادلې ته اوړي چې په یوه متغیر کې خطي معادله ده. نو د درېیمې معادلې په حلولو د یوه متغیر ارزښت موندل کېږي. په پای کې د یوه متغیر دا ارزښت په ورکړل شوې هره معادله کې ږدو چې په حلولو یې د بل متغیر ارزښت لاسته راځي. دا طریقه د لاندې بېلګو په مرسته نوره هم تشریح شوې.
example 1
