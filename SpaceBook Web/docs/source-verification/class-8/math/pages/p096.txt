## 5.2.2 Power Set || 5.2.2 پاور سیٹ || 5.2.2 د توان سېټ
p The set that consists of all the subsets of a set is called the power set of that set. For any set X; the power set of X is written as P (X). || وہ سیٹ جو کسی سیٹ کے تمام ذیلی سیٹوں پر مشتمل ہو، اس سیٹ کا پاور سیٹ کہلاتا ہے۔ کسی بھی سیٹ X کے لیے X کا پاور سیٹ P (X) لکھا جاتا ہے۔ || هغه سېټ چې د یوه سېټ ټول فرعي سېټونه ولري، د هغه سېټ د توان سېټ بلل کېږي. د هر سېټ X لپاره، د X د توان سېټ P (X) لیکل کېږي.
example 1
p Find the power set of the set Y = {0, 1} || سیٹ Y = {0, 1} کا پاور سیٹ معلوم کریں || د Y = {0, 1} سېټ د توان سېټ معلوم کړئ
## Solution: || حل: || حل:
m Y = {0, 1}
m Power set of Y = P (Y) = {ϕ, {0}, {1}, {0, 1}}
p Note: || نوٹ: || یادونه:
m Number of elements of the set Y = 2
m Number of possible subsets of Y = $2^2 = 4$
endexample

example 2
p Find the power set of the set A = {a, e, i} || سیٹ A = {a, e, i} کا پاور سیٹ معلوم کریں || د A = {a, e, i} سېټ د توان سېټ معلوم کړئ
## Solution: || حل: || حل:
m P (A) = {ϕ, {a}, {e}, {i}, {a, e}, {a, i}, {e, i}, {a, e, i}}
p Observe that the elements of power set are all subsets themselves. || غور کریں کہ پاور سیٹ کے ارکان خود تمام ذیلی سیٹ ہیں۔ || وګورئ چې د توان سېټ عناصر پخپله ټول فرعي سېټونه دي.
endexample
example 3
p Find the power set of the set X = {a, b, c, d} || سیٹ X = {a, b, c, d} کا پاور سیٹ معلوم کریں || د X = {a, b, c, d} سېټ د توان سېټ معلوم کړئ
## Solution: || حل: || حل:
p The power set of X is; || X کا پاور سیٹ ہے؛ || د X د توان سېټ دی؛
m P (X) = {ϕ, {a}, {b}, {c}, {d}, {a, b}, {b, c}, {b, d}, {a, c}, {a, d}, {c, d}, {a, b, c}, {a, b, d}, {a, c, d}, {b, c, d}, {a, b, c, d}}
endexample

box teach | Teaching Point || تدریسی نکتہ || د تدریس ټکی
