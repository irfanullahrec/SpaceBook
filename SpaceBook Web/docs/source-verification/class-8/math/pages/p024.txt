# 2.4 Real Numbers || 2.4 حقیقی اعداد || 2.4 حقیقي عددونه
p The sets of rational and irrational numbers together make up the set of real numbers. All these natural numbers, whole numbers, integers, decimals, fractions, irrational numbers etc. are subsets of the set of real numbers. || ناطق اور غیر ناطق اعداد کے سیٹ مل کر حقیقی اعداد کا سیٹ بناتے ہیں۔ یہ تمام قدرتی اعداد، مکمل اعداد، صحیح اعداد، اعشاریہ، کسور، غیر ناطق اعداد وغیرہ حقیقی اعداد کے سیٹ کے ذیلی سیٹ ہیں۔ || د ناطقو او غیر ناطقو عددونو سېټونه یوځای د حقیقي عددونو سېټ جوړوي. دا ټول طبیعي عددونه، بشپړ عددونه، تام عددونه، اعشاري، کسرونه، غیر ناطق عددونه او نور د حقیقي عددونو د سېټ فرعي سېټونه دي.

## 2.4.1 Number Line || 2.4.1 عددی خط || 2.4.1 د عددونو کرښه
p We know that a number line helps us represent and display numbers by linking each number with a unique point on it. || ہم جانتے ہیں کہ عددی خط ہر عدد کو اس پر ایک منفرد نقطے سے جوڑ کر اعداد کو ظاہر کرنے اور دکھانے میں ہماری مدد کرتا ہے۔ || موږ پوهېږو چې د عددونو کرښه له موږ سره مرسته کوي چې هر عدد پر هغې د یوه ځانګړي ټکي سره وتړو او عددونه وښیو.
p We can represent real number on numbers line by drawing a horizontal line with arrows on both ends. These arrows indicate that the number line keeps extending on both sides endlessly, as there are infinite positive and negative real numbers. As in the set of real numbers, we have positive, negative and zero, so we must choose a point to represent the number zero on it. For a real number line, this point zero acts as an origin. || ہم دونوں سروں پر تیر والی ایک افقی لکیر کھینچ کر حقیقی عدد کو عددی خط پر ظاہر کر سکتے ہیں۔ یہ تیر ظاہر کرتے ہیں کہ عددی خط دونوں طرف لامتناہی طور پر پھیلتا رہتا ہے، کیونکہ مثبت اور منفی حقیقی اعداد لامحدود ہیں۔ چونکہ حقیقی اعداد کے سیٹ میں مثبت، منفی اور صفر ہیں، اس لیے ہمیں اس پر صفر کو ظاہر کرنے کے لیے ایک نقطہ منتخب کرنا ہوگا۔ حقیقی عددی خط کے لیے یہ نقطہ صفر مبدا کا کام کرتا ہے۔ || موږ کولی شو د یوې افقي کرښې په رسمولو چې دواړو سرونو ته غشي ولري، حقیقي عدد د عددونو پر کرښه وښیو. دا غشي ښيي چې د عددونو کرښه دواړو خواوو ته بې پایه غځېږي، ځکه چې مثبت او منفي حقیقي عددونه بې شمېره دي. څرنګه چې د حقیقي عددونو په سېټ کې مثبت، منفي او صفر شته، نو باید پر هغې د صفر د ښودلو لپاره یو ټکی وټاکو. د حقیقي عددونو د کرښې لپاره دا صفر ټکی د مبدا په توګه کار کوي.
