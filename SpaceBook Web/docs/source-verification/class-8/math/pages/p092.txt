p Some examples are given below. || کچھ مثالیں نیچے دی گئی ہیں۔ || ځینې بېلګې لاندې ورکړل شوې دي.
m a) Y = $\{x \mid x$ is an integer, $x > -4\}$, or
m Y = $\{x \mid x \in Y \wedge x > -4\}$
p We read it as: "Y is the set of all elements x such that x is an integer and it is greater than −4". We can write it in tabular form as: Y = {−3, −2, −1, 0, +1, +2, +3, ...}. || ہم اسے یوں پڑھتے ہیں: "Y تمام ارکان x کا سیٹ ہے اس طرح کہ x ایک صحیح عدد ہے اور یہ −4 سے بڑا ہے"۔ ہم اسے جدولی شکل میں یوں لکھ سکتے ہیں: Y = {−3, −2, −1, 0, +1, +2, +3, ...}۔ || موږ یې داسې لولو: "Y د ټولو x عناصرو سېټ دی داسې چې x یو تام عدد دی او له −4 څخه لوی دی". په جدولي بڼه یې داسې لیکلی شو: Y = {−3, −2, −1, 0, +1, +2, +3, ...}.
m b) T = $\{x \mid x$ is an odd number, $5 \leq x \leq 11\}$ or
m T = $\{x \mid x \in T \wedge 5 \leq x \leq 11\}$
p We read it as; "T is the set of all elements x such that x is an odd number which is greater than or equal to 5 and less than or equal to 11. || ہم اسے یوں پڑھتے ہیں؛ "T تمام ارکان x کا سیٹ ہے اس طرح کہ x ایک طاق عدد ہے جو 5 سے بڑا یا برابر اور 11 سے کم یا برابر ہے۔ || موږ یې داسې لولو؛ "T د ټولو x عناصرو سېټ دی داسې چې x یو طاق عدد دی چې له 5 څخه لوی یا برابر او له 11 څخه کوچنی یا برابر دی.
m Thus, we write it in tabular form as: T = {5, 7, 9, 11}
m c) F = $\{x \mid x =$ vowels in the English alphabet$\}$
m Thus, we write it in tabular form as: F = {a, e, i, o, u}

p A set can be written by using ":" instead of "|". For example, set builder notation of natural numbers is: N = $\{x : x$ is a natural number$\}$. || سیٹ کو "|" کی جگہ ":" استعمال کر کے بھی لکھا جا سکتا ہے۔ مثال کے طور پر قدرتی اعداد کی سیٹ بلڈر علامت ہے: N = $\{x : x$ ایک قدرتی عدد ہے$\}$۔ || سېټ د "|" پر ځای د ":" په کارولو هم لیکل کېدای شي. د بېلګې په توګه، د طبیعي عددونو د سېټ جوړونکې نښه ده: N = $\{x : x$ یو طبیعي عدد دی$\}$.
endbox
