## vii) Movement
p Movement shows action, or the path the viewer's eye follows through an artwork. Movement is created by using the elements of art to give the feeling of motion and to guide the viewer's eyes through an artwork. Techniques such as scale and proportion can be used to create an effect of movement in an artwork. For instance, an element that is farther into the background is smaller in scale and lighter in value. The same element repeated in different places within the same image can create the illusion of movement. See fig: 2.16, 2.17, 2.18, 2.19.
