# Chapter 3: APPLICATION OF DRAWING
p At the end of this chapter, the students will be able to:
slo recall knowledge of stencil making and its uses.
slo use stencil to transfer designs on selected materials applying transferring techniques.
slo understand advanced use of stencil in real life.
slo show proficiency in block making techniques using available and man-made materials.
slo make block of selected designs applying block making techniques.
slo print designs on available surfaces.
slo use card board cut out to make hollow models of solids using folding and unfolding techniques.
slo create, models of solids using clay, flour, plasticine and other available material.
