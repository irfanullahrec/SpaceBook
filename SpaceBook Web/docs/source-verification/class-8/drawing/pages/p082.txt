## Step-2: Starting the drawing
p In any still life, you should start to draw the objects as if they are transparent with visible lines of construction. This technique helps you to be fully aware of the shape of each individual form and its composition in relation to the other forms. It is important to sketch the object lightly as this makes it easier to change any mistake and erase any line of construction.
