## How to Make a Rose from Modelling Clay/Plasticine
## 1. Select clay of any colour:
p Colour choice does not matter if you want to paint it later. If you do not want to paint it then use red and green. (Green for the stem)
@deco Fig. 3.10: a pink and a green bar of plasticine
p 2. Start by working with the clay to make it softer and more malleable: Sometimes clay can become a bit stiff if it has not been used for long. This can make the whole process difficult. Knead it for a while to make it softer.
