q ii | Read the given words with the same beginning or ending sounds. Think one more word that has the same ending sound. || ایک جیسی ابتدائی یا آخری آواز والے دیے گئے الفاظ پڑھیں۔ ایک ایک مزید لفظ سوچیں۔ || د یو شان لومړني یا وروستي غږ لرونکې ورکړل شوې کلمې ولولئ. یوه بله کلمه فکر کړئ.
qp a | Same beginning sound: mat, bag, net, light, grinny, sun
sol For example: mat → man, bag → bat, net → nest, light → lion, grinny → green, sun → sit ## Keep the first sound the same. || پہلی آواز وہی رکھیں۔ || لومړی غږ همغه وساتئ.
qp b | Same ending sound: him, tab, ten, pencil, evening, less
sol For example: him → swim, tab → cab, ten → hen, pencil → until, evening → morning, less → dress ## Keep the last sound the same. || آخری آواز وہی رکھیں۔ || وروستی غږ همغه وساتئ.
endexercise
