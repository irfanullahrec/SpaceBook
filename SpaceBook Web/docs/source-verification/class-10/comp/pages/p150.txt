### یونیفارم ریسورس لوکیٹر (URL) || Uniform Resource Locator (URL) || یونیفارم ریسورس لوکیټر (URL)
p یو آر ایل (یونیفارم ریسورس لوکیٹر) ایک ایسی فائل کا منفرد ایڈریس ہے جو انٹرنیٹ پر قابلِ رسائی ہے۔ کسی ویب سائٹ تک جانے کا ایک عام طریقہ یہ ہے کہ ویب براؤزر کی ایڈریس لائن میں اس کے ہوم پیج فائل کا URL درج کریں۔ تاہم، اس ویب سائٹ میں موجود کسی بھی فائل کو URL کے ساتھ بھی لکھا جا سکتا ہے۔ یو آر ایل کی درج ذیل شکل ہے۔ || A URL (Uniform Resource Locator) is the unique address of a file that can be reached on the internet. A common way to go to a website is to type the URL of its home-page file in the address line of the web browser. However, any file on that website can also be written with the URL. A URL has the following form. || URL (Uniform Resource Locator) د هغې فایل ځانګړې پته ده چې په انټرنېټ کې د لاسرسي وړ وي. ویب سایټ ته د تګ عامه لار دا ده چې د ویب براوزر د پتې په کرښه کې د کور پاڼې د فایل URL ولیکئ. خو د دې ویب سایټ هره فایل هم د URL سره لیکل کېدای شي. URL دا بڼه لري:
m protocol://hostname/other_information
p مثال کے طور پر، فیڈرل ایجوکیشن بورڈ کے ہوم پیج کا URL یہ ہے: https://www.fbise.edu.pk/ || For example, the URL of the Federal Education Board's home page is: https://www.fbise.edu.pk/ || د بېلګې په توګه، د فدرال تعلیمي بورډ د کور پاڼې URL دا دی: https://www.fbise.edu.pk/
p (HTTP: ہائپر ٹیکسٹ ٹرانسفر پروٹوکول) بتاتا ہے کہ لنک سے معلومات کو کس طرح منتقل کیا جائے گا۔ ڈومین کا نام www.fbise، وہ کمپیوٹر ہے جس پر وسائل موجود ہیں۔ مخصوص فائلوں یا ذیلی ڈائریکٹریوں کے لنکس Domain name کے بعد مزید واضح ہو سکتے ہیں۔ ڈائریکٹری کے نام ایک فارورڈ سلیش کے ذریعہ الگ کر دیئے جاتے ہیں۔ URL https://www.fbise.edu.pk/result-main.php نتائج کے پیج کو دکھائے گا جیسا کہ شکل نمبر 7.5 میں دکھایا گیا ہے۔ || HTTP (Hypertext Transfer Protocol) tells how information is to be transferred from the link. The domain name, www.fbise, is the computer on which the resources are located. Links to particular files or sub-directories can be made more specific after the domain name; directory names are separated by a forward slash. The URL https://www.fbise.edu.pk/result-main.php will show the results page, as shown in Figure 7.5. || HTTP (هایپرټیکسټ ټرانسفر پروټوکول) ښيي چې معلومات له لینک څخه څنګه ولېږدول شي. د ډومین نوم www.fbise هغه کمپیوټر دی چې سرچینې پرې دي. د ځانګړو فایلونو یا فرعي ډایرکټریو لینکونه د ډومین نوم وروسته نور څرګندېدای شي؛ د ډایرکټریو نومونه د مخکیني سلیش (/) په واسطه جلا کېږي. https://www.fbise.edu.pk/result-main.php URL به د پایلو پاڼه وښيي، لکه څنګه چې په ۷.۵ شکل کې ښودل شوي.
