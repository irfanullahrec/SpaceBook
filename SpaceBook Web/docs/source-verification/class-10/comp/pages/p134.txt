## 6.3 بولین فنکشن کو کارناف میپ کی مدد سے مختصر کرنا || 6.3 Simplifying a Boolean function with a Karnaugh map || ۶.۳ د کارناف نقشې (Karnaugh Map) په مرسته د بولین فنکشن لنډول
### بولین فنکشن کا اختصار (Simplification of Boolean Function) || Simplification of a Boolean function || د بولین فنکشن لنډول (Simplification of Boolean Function)
p بولین فنکشن میں موجود اصطلاحات کی تعداد کو کم سے کم یا ختم کرنے کے عمل کو، تاکہ آخری آؤٹ پُٹ پر کوئی فرق نہ پڑے، اختصار (Simplification) کہا جاتا ہے۔ اس مقصد کے لئے مختلف طریقوں کا استعمال کیا جاتا ہے۔ ٹیلی کمیونیکیشن کے انجینئر، ماریس کارناف (Maurice Karnaugh) نے 1953ء میں Bell Labs میں Karnaugh Map تیار کیا۔ K-map بولین فنکشن کو آسان بنانے کا بہترین طریقہ ہے۔ جب مختصر بولین فنکشن ایک لاجک سرکٹ میں تبدیل ہوتا ہے تو اس کے لئے لاجک گیٹس کم تعداد میں درکار ہوتے ہیں اور اس وجہ سے اس کی لاگت بھی کم ہو جاتی ہے۔ || The process of reducing to a minimum, or removing, the terms in a Boolean function without changing the final output is called simplification. Various methods are used for this. The telecommunications engineer Maurice Karnaugh developed the Karnaugh map at Bell Labs in 1953. The K-map is an excellent way to simplify Boolean functions. When a simplified Boolean function is converted into a logic circuit, fewer logic gates are needed, and so its cost is also lower. || په بولین فنکشن کې د اصطلاحګانو د شمېر کمولو یا لرې کولو ته، داسې چې وروستي output ته توپیر ونه رسېږي، لنډول (Simplification) وايي. د دې لپاره بېلابېلې لارې کارېږي. د مخابراتو انجنیر ماریس کارناف (Maurice Karnaugh) په ۱۹۵۳ کال کې په Bell Labs کې Karnaugh Map جوړ کړ. K-map د بولین فنکشن د اسانه کولو غوره لاره ده. کله چې لنډ شوی بولین فنکشن په منطقي سرکټ بدل شي، لږې منطقي دروازې ته اړتیا وي او له همدې امله لګښت یې هم کمېږي.

@sec 6-3-1 | 6.3.1 کارناف میپ || 6.3.1 Karnaugh map || ۶.۳.۱ کارناف نقشه
### 6.3.1 کارناف میپ (Karnaugh Map) || 6.3.1 Karnaugh map || ۶.۳.۱ کارناف نقشه (Karnaugh Map)
p کارناف میپ یا K-map بولین ایکسپریشن کا ایک تصویری خاکہ ہے۔ Karnaugh Map کو 2D ٹرُتھ ٹیبل بھی کہا جاتا ہے کیونکہ ہر K-map، 1D ٹرُتھ ٹیبل میں موجود قیمتوں کو ظاہر کرنے کا ایک مختلف فارمیٹ ہے۔ || A Karnaugh map, or K-map, is a pictorial layout of a Boolean expression. A Karnaugh map is also called a 2D truth table, because every K-map is a different format for showing the values in a 1D truth table. || کارناف نقشه یا K-map د بولین عبارت انځوریز خاکه ده. Karnaugh Map ته 2D د حقیقت جدول هم وايي، ځکه هر K-map د 1D د حقیقت جدول د ارزښتونو د ښودلو یوه بېله بڼه ده.
p K-map بنیادی طور پر مربع نما خانوں پر مشتمل ہوتا ہے جنہیں سیلز (Cells) کہا جاتا ہے۔ بولین فنکشن کے تمام ممکنہ امتزاج سیلوں کے اندر انکی متعین جگہوں پر لکھے ہوتے ہیں۔ دو ویری ایبلز والا K-map 2² = 4 سیلوں پر مشتمل ہوتا ہے، 4 ویری ایبل والا K-map 2⁴ = 16 سیلوں پر مشتمل ہوتا ہے، اور اسی طرح آگے بھی۔ || A K-map basically consists of square boxes called cells. All the possible combinations of the Boolean function are written in their fixed places inside the cells. A K-map with two variables has 2² = 4 cells; a K-map with 4 variables has 2⁴ = 16 cells, and so on. || K-map په بنسټیز ډول له مربع خونو جوړ وي چې حجرې (Cells) بلل کېږي. د بولین فنکشن ټول ممکن ترکیبونه په حجرو کې په خپلو ټاکلو ځایونو لیکل کېږي. دوه متغیر لرونکی K-map له 2² = 4 حجرو، او 4 متغیر لرونکی K-map له 2⁴ = 16 حجرو جوړ وي، او داسې نور.
p کارناف میپ کی مدد سے ہم ان تمام ویری ایبلز کو گروپ کی شکل دے سکتے ہیں جن میں کوئی نہ کوئی قدر مشترک ہو اس طرح ہر غیر ضروری ویری ایبل کو ختم کر سکتے ہیں۔ کارناف میپ کو ہم ٹرُتھ ٹیبل کی مخصوص شکل بھی کہہ سکتے ہیں۔ درج ذیل شکل دو ویری ایبل والے ٹرُتھ ٹیبل اور کارناف میپ کے درمیان مطابقت کا ظاہر کرتی ہے۔ || With a Karnaugh map we can group together all the terms that have something in common, and in this way remove every unnecessary variable. We can also call the Karnaugh map a special form of truth table. The following figure shows the correspondence between a two-variable truth table and a Karnaugh map. || د کارناف نقشې په مرسته هغه ټول متغیرونه ډله کولای شو چې یو څه ګډ لري، او په دې ډول هر غیر اړین متغیر لرې کولای شو. کارناف نقشې ته د حقیقت جدول ځانګړې بڼه هم ویلای شو. لاندې شکل د دوه متغیره د حقیقت جدول او کارناف نقشې ترمنځ سمون ښيي.
p مربعوں کے درمیان موجودہ قیمتیں ٹرُتھ ٹیبل کے آؤٹ پُٹ کالم سے لی گئی ہیں۔ اس لیے ٹرُتھ ٹیبل کی ہر قطار یعنی Row کے لیے K-map میں ایک مربع مختص ہے۔ کارناف میپ کے کناروں پر دونوں اِن پُٹ ویری ایبل کی قیمتیں درج ہیں۔ A کی قیمتیں بالائی (TOP) کی … || The values inside the squares are taken from the output column of the truth table, so for each row of the truth table one square is set aside in the K-map. The values of both input variables are written along the edges of the Karnaugh map. The values of A … the top (TOP) … || په مربعو کې ارزښتونه د حقیقت جدول د output له ستنې اخیستل شوي؛ نو د حقیقت جدول د هرې کرښې (Row) لپاره په K-map کې یو مربع ټاکل شوی. د کارناف نقشې پر غاړو د دواړو input متغیرونو ارزښتونه لیکل شوي. د A ارزښتونه پاس (TOP) …
