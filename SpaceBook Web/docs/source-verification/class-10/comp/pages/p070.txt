### 3.1.3 اسٹیٹمنٹ ٹرمینیٹر (Statement Terminator) || 3.1.3 Statement terminator || ۳.۱.۳ د بیان پای ټکی (Statement Terminator)
p C کے ہر پروگرام میں ایک اسٹیٹمنٹ کو دوسری اسٹیٹمنٹ سے جدا کرنے کے لیے اسٹیٹمنٹ کے اختتام پر سیمی کالن ( ; ) کا استعمال کیا جاتا ہے۔ یہ سیمی کالن کمپائلر کو بتاتا ہے کہ ایک اسٹیٹمنٹ اس جگہ ختم ہو گئی ہے۔ اگر ایک اسٹیٹمنٹ کو سیمی کالن سے ختم نہیں کیا جاتا تو، C کا کمپائلر کمپائل کرنے کے عمل کے دوران Error Message دے گا اور پروگرام کمپائل نہیں کیا جائے گا۔ || In every C program a semicolon ( ; ) is used at the end of a statement to separate it from the next statement. The semicolon tells the compiler that a statement has ended at that point. If a statement is not ended with a semicolon, the C compiler gives an error message during compilation and the program is not compiled. || د C په هر پروګرام کې د یوه بیان د بل څخه د جلا کولو لپاره د بیان په پای کې سیمي کولن ( ; ) کارېږي. سیمي کولن کمپایلر ته وايي چې بیان دلته پای ته ورسېد. که بیان په سیمي کولن پای ته ونه رسېږي، د C کمپایلر د کمپایل پر مهال Error Message ورکوي او پروګرام نه کمپایلېږي.
p مثال کے طور پر، || For example, || د بېلګې په توګه،
m printf("Hello, World! \n"); // Semicolon is used to show end of statement
