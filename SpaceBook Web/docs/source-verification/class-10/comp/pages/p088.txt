## 4.1 کنٹرول سٹرکچر (Control Structure) || 4.1 Control structure || ۴.۱ د کنټرول جوړښت (Control Structure)
p کنٹرول سٹرکچر در حقیقت سٹرکچرڈ پروگرامنگ لینگویج کے بنیادی اجزاء ہیں۔ کنٹرول سٹرکچرز پروگرام کے چلنے کی عمومی ترتیب کو بدلنے کے لیے استعمال ہوتے ہیں۔ ہمیں پروگرام کے چلنے کی ترتیب کو بدلنے کی ضرورت کیوں ہوتی ہے؟ اس کی وجہ "فیصلہ سازی (Decision Making)" ہے۔ || Control structures are in fact the basic components of a structured programming language. Control structures are used to change the normal order in which a program runs. Why do we need to change the order in which a program runs? The reason is "decision making". || د کنټرول جوړښتونه په حقیقت کې د جوړښتي پروګرامي ژبې بنسټیزې برخې دي. د کنټرول جوړښتونه د پروګرام د چلېدو د عادي ترتیب د بدلولو لپاره کارېږي. ولې د پروګرام د چلېدو ترتیب بدلولو ته اړتیا لرو؟ لامل یې "پرېکړه کول (Decision Making)" دی.
p حقیقی زندگی میں ایسے حالات آتے ہیں جب ہمیں کچھ فیصلے کرنے کی ضرورت ہوتی ہے اور ان فیصلوں کی بنیاد پر، ہم فیصلہ کرتے ہیں کہ ہمیں آگے کیا کرنا چاہئے۔ مثال کے طور پر، ہمیں مختلف اختیارات دیئے جا سکتے ہیں جیسے "میڈیکل" یا "انجینئرنگ" کرنا۔ ہم کچھ شرائط (جیسے اپنی ذاتی دلچسپی، مواقع کی گنجائش وغیرہ) کا تجزیہ کر کے فیصلہ کرتے ہیں جو فیصلہ کرتے ہیں اس سے ہم اپنی زندگی کی سمت کے بہاؤ کو بدل دیتے ہیں۔ C پروگرامنگ میں بھی اسی طرح کے حالات پیدا ہوتے ہیں جہاں ہمیں کسی فیصلے کی بنیاد پر پروگرام کو ایک یا دوسرے راستے پر چلانے کی ضرورت ہوتی ہے۔ || In real life there are situations when we need to take decisions, and on the basis of those decisions we decide what to do next. For example, we may be given different options such as doing "medical" or "engineering". We decide by analysing some conditions (such as our own interest, the scope of opportunities and so on), and the decision we take changes the direction of our life. Similar situations arise in C programming, where we need to run a program along one path or another on the basis of a decision. || په ریښتیني ژوند کې داسې حالتونه راځي چې پرېکړې ته اړتیا لرو او د دې پرېکړو پر بنسټ ټاکو چې وروسته څه وکړو. د بېلګې په توګه، ممکن بېلابېل انتخابونه ولرو لکه "طب" یا "انجنیري". ځینې شرطونه (لکه شخصي لېوالتیا، د فرصتونو ګنجایش او نور) شننو او پرېکړه کوو؛ همدا پرېکړه زموږ د ژوند لوری بدلوي. په C پروګرام جوړونه کې هم داسې حالتونه راځي چې باید د یوې پرېکړې پر بنسټ پروګرام په یوه یا بله لار وچلوو.

### 4.1.1 کنٹرول اسٹیٹمنٹس (Control Statements) || 4.1.1 Control statements || ۴.۱.۱ د کنټرول بیانونه (Control Statements)
p پروگراموں میں کچھ ایسے سیکشنز یا ہدایات کے بلاکس ہوتے ہیں جو صرف ضرورت پڑنے پر ہی کام میں لائے جاتے ہیں۔ ضرورت پڑنے پر پروگرام کا کوئی خاص حصہ ہی چلایا جاتا ہے۔ جبکہ کوڈ کا ایک حصہ مصروف ہو تو دوسرے حصے غیر فعال ہوتے ہیں۔ کنٹرول اسٹیٹمنٹ کی مدد سے پروگرامر اس بات کی نشاندہی کرتے ہیں کہ کوڈ کے کون سے سیکشن مخصوص اوقات میں استعمال ہوں۔ تاہم، کسی مسئلے کی ضرورت کو سامنے رکھتے ہوئے پروگرام کے کسی خاص حصے کو چلانے یا نہ چلانے کا فیصلہ کیا جاتا ہے۔ کنٹرول اسٹیٹمنٹ سورس کوڈ میں شامل عناصر ہوتے ہیں جو پروگرام پر عمل درآمد کے بہاؤ کو کنٹرول کرتے ہیں۔ ایسی اسٹیٹمنٹ جو پروگرام چلنے کے دوران اس کی اسٹیٹمنٹ کی ترتیب کا تعین کرتی ہیں کنٹرول اسٹیٹمنٹس (Control Statements) کہلاتی ہیں۔ || Programs have some sections or blocks of instructions that are used only when needed; a particular part of the program is run only when it is needed, and while one part of the code is busy the other parts are inactive. With control statements, programmers indicate which sections of code are to be used at particular times. Whether or not to run a particular part of the program is decided according to the needs of the problem. Control statements are elements of the source code that control the flow of the program's execution. Statements that fix the order of a program's statements while it runs are called control statements. || په پروګرامونو کې د لارښوونو ځینې برخې یا بلاکونه شته چې یوازې د اړتیا پر مهال کارېږي؛ د اړتیا پر مهال یوازې د پروګرام ځانګړې برخه چلېږي، او کله چې د کوډ یوه برخه بوخته وي نورې برخې غیر فعالې وي. د کنټرول بیانونو په مرسته پروګرامر ښيي چې د کوډ کومې برخې په ځانګړو وختونو کې وکارول شي. د ستونزې د اړتیا له مخې پرېکړه کېږي چې د پروګرام یوه ځانګړې برخه وچلول شي که نه. د کنټرول بیانونه د سرچینه کوډ هغه توکي دي چې د پروګرام د اجرا بهیر کنټرولوي. هغه بیانونه چې د پروګرام د چلېدو پر مهال د بیانونو ترتیب ټاکي د کنټرول بیانونه (Control Statements) بلل کېږي.
