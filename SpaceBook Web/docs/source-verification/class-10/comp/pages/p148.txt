Information on the web is obtained through URLs. Web browsers let users open several websites at the same time, in different browser windows or in different tabs of one window. There are many web browsers, but a few popular ones are Google Chrome, Internet Explorer, Microsoft Edge and Mozilla Firefox, shown in Figures 7.3(a), 7.3(b), 7.3(c) and 7.3(d) respectively.
