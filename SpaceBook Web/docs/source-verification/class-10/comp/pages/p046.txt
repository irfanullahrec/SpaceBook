p C کے ہر مکمل پروگرام میں ایک فنکشن ہوتا ہے جس کو main() (مین) فنکشن کہا جاتا ہے۔ فنکشن در حقیقت بہت ساری اسٹیٹمنٹس کا مجموعہ ہوتا ہے جو کوئی نہ کوئی کام انجام دینے کے لئے استعمال ہوتا ہے۔ جب پروگرام چلتا ہے تو سب سے پہلے main فنکشن ہی چلایا جاتا ہے۔ اور فنکشن کے ذریعے ہم دوسرے فنکشن چلا سکتے ہیں، چاہے وہ یوزر کے بنائے ہوئے ہوں یا بلٹ ان (Built-in)۔ C کمپائلر کے ساتھ آنے والے سٹینڈرڈ فنکشنز تک رسائی کے لیے آپ کو #include کی مدد سے ہیڈر (header) فائل شامل کرنے کی ضرورت ہوتی ہے۔ || Every complete C program has a function called the main() function. A function is in fact a set of many statements used to carry out some task. When a program runs, the main function is run first, and through functions we can run other functions, whether they are user-made or built-in. To access the standard functions that come with a C compiler, you need to include a header file with the help of #include. || د C هر بشپړ پروګرام یو فنکشن لري چې main() فنکشن بلل کېږي. فنکشن په حقیقت کې د ډېرو بیانونو ټولګه ده چې یو کار ترسره کوي. کله چې پروګرام چلېږي، لومړی main فنکشن چلېږي، او د فنکشنونو له لارې نور فنکشنونه چلولای شو، که د کاروونکي جوړ کړي وي یا جوړ شوي (Built-in). د C کمپایلر سره راغلو معیاري فنکشنونو ته د لاسرسي لپاره باید د #include په مرسته هېډر (header) فایل شامل کړئ.

### 2.3.1 ہیڈر فائل (Header File) || 2.3.1 Header file || ۲.۳.۱ هېډر فایل
p مختلف کاموں کو انجام دینے کے لئے ہیڈر فائلیں سٹینڈرڈ لائبریری فنکشن کا ایک مجموعہ ہیں۔ مختلف مقاصد کے لئے بہت ساری ہیڈر فائلیں ہیں۔ ہر ہیڈر فائل میں مختلف قسم کے بنے بنائے فنکشن ہوتے ہیں۔ ایک ہی پروگرام میں بہت ساری ہیڈر فائلوں کو شامل کیا جا سکتا ہے۔ پروگرام میں ہیڈر فائل کو اپنے اندر موجود کسی بھی فنکشن کے استعمال سے پہلے پہلے، شامل کرنا ضروری ہے۔ || Header files are a collection of standard library functions for carrying out various tasks. There are many header files for different purposes, and each header file contains various kinds of ready-made functions. Many header files can be included in one program. A header file must be included in the program before any function it contains is used. || هېډر فایلونه د بېلابېلو کارونو د ترسره کولو لپاره د معیاري کتابتون فنکشنونو ټولګه ده. د بېلابېلو موخو لپاره ډېر هېډر فایلونه شته او هر هېډر فایل بېلابېل جوړ شوي فنکشنونه لري. په یوه پروګرام کې ډېر هېډر فایلونه شاملېدای شي. په پروګرام کې هېډر فایل باید د هغه د کوم فنکشن له کارولو مخکې شامل شي.
p ہیڈر فائل کی ایکسٹینشن h. ہے۔ پروگراموں میں ہیڈر فائلوں کو شامل کرنے کے لئے #include پری پروسیسر ڈائریکٹو استعمال کیا جاتا ہے۔ یہ فائلیں C کمپائلر سسٹم میں پہلے سے دستیاب ہوتی ہیں۔ || The extension of a header file is .h. The #include preprocessor directive is used to include header files in programs. These files are already available in the C compiler system. || د هېډر فایل توسیع ‎.h ده. په پروګرامونو کې د هېډر فایلونو د شاملولو لپاره د #include پري پروسسر لارښود (directive) کارېږي. دا فایلونه مخکې له مخکې د C کمپایلر په سیسټم کې شته.

The name of the header file is written in angle brackets < >. For example: || هېډر فایلونه عموماً د INCLUDE په فرعي ډایرکټري کې ساتل کېږي. د هېډر فایل نوم په زاویه ییزو قوسونو < > کې لیکل کېږي. د بېلګې په توګه:
m # include <stdio.h>
