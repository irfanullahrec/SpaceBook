### 3۔ لنکر (Linker) || 3. Linker || ۳. لینکر
p ایک کمپیوٹر پروگرام جو ایک یا ایک سے زیادہ آبجیکٹ کوڈ لیتا ہے اور ان کو ایک ہی قابلِ عمل پروگرام میں جوڑتا ہے، اسے لنکر کہتے ہیں۔ C لینگویج ایگزیکیوٹیبل پروگرام کی ایکسٹینشن exe. ہے جیسے student.exe۔ لنکر کے پورے عمل کو شکل نمبر 2.11 میں دکھایا گیا ہے۔ || A computer program that takes one or more object codes and joins them into a single executable program is called a linker. The extension of a C-language executable program is .exe, for example student.exe. The whole linking process is shown in Figure 2.11. || هغه کمپیوټري پروګرام چې یو یا څو object کوډونه اخلي او په یوه اجرا وړ پروګرام کې یې یوځای کوي لینکر بلل کېږي. د C ژبې د اجرا وړ پروګرام توسیع ‎.exe ده، لکه student.exe. د لینکر ټول بهیر په ۲.۱۱ شکل کې ښودل شوی.

### 4۔ لوڈر (Loader) || 4. Loader || ۴. لوډر
p یہ ایک پروگرام ہے جو C زبان کے پروگراموں کو میموری میں لوڈ کرتا ہے اور پھر ان پر عمل درآمد کرتا ہے۔ || It is a program that loads C-language programs into memory and then executes them. || دا یو پروګرام دی چې د C ژبې پروګرامونه حافظې ته پورته کوي او بیا یې اجرا کوي.
### 5۔ ڈیبگر (Debugger) || 5. Debugger || ۵. ډیبګر
p کمپیوٹرز میں ڈیبگنگ، کمپیوٹر پروگرام کوڈ میں موجود غلطیوں (Errors) کو تلاش کرنے اور ٹھیک کرنے کے عمل کو کہتے ہیں۔ || In computers, debugging is the process of finding and correcting the errors in computer program code. || په کمپیوټرونو کې ډیبګینګ د کمپیوټري پروګرام په کوډ کې د تېروتنو (Errors) د موندلو او سمولو بهیر ته وايي.
p C لینگویج ڈیبگر ایک کمپیوٹر پروگرام ہے جو صارفین کو پروگرام چلانے دیتا ہے، متغیر کی اقدار کی جانچ پڑتال یا فنکشن کو بھیجی گئی اقدار کو دیکھنے اور پروگرام میں غلطیوں کو ڈھونڈنے اور دور کرنے میں مدد کرتا ہے۔ || A C-language debugger is a computer program that lets users run a program, check the values of variables or see the values sent to a function, and helps to find and remove errors in the program. || د C ژبې ډیبګر یو کمپیوټري پروګرام دی چې کاروونکو ته د پروګرام چلولو اجازه ورکوي، د متغیرونو ارزښتونه ازمویي یا فنکشن ته لېږل شوي ارزښتونه ښيي، او په پروګرام کې د تېروتنو په موندلو او لرې کولو کې مرسته کوي.

### C پروگرامنگ کا آغاز (Getting started with C) || Getting started with C || د C پروګرام جوړونې پیل
p C ایک مشہور اور مؤثر پروگرامنگ زبان ہے جو سسٹم اور ایپلی کیشن سافٹ ویئر کے لئے وسیع پیمانے پر استعمال ہوتی ہے۔ || C is a well-known and effective programming language that is widely used for system and application software. || C یوه مشهوره او اغېزمنه پروګرامي ژبه ده چې د سیسټم او اپلیکېشن سافټویر لپاره پراخه کارېږي.
