### 4.1.3 if اسٹیٹمنٹ || 4.1.3 The if statement || ۴.۱.۳ if بیان
p if اسٹیٹمنٹ ایک فیصلہ ساز اسٹیٹمنٹ ہے۔ یہ سلیکشن سٹرکچر کی سب سے سادہ شکل ہے۔ یہ کسی دی گئی شرط کی بنیاد پر ایک اسٹیٹمنٹ یا اسٹیٹمنٹس کے مجموعہ کو چلاتی ہے یا نظر انداز کر دیتی ہے۔ اس کو کبھی کبھار بائنری سلیکشن بھی کہا جاتا ہے کیونکہ عملدرآمد کی دو ممکنہ راہیں ہیں۔ || The if statement is a decision-making statement. It is the simplest form of selection structure. On the basis of a given condition it runs or skips a statement or a set of statements. It is sometimes also called binary selection, because there are two possible paths of execution. || if بیان د پرېکړې بیان دی. دا د انتخابي جوړښت تر ټولو ساده بڼه ده. د ورکړل شوي شرط پر بنسټ یو بیان یا د بیانونو ټولګه چلوي یا یې پرېږدي. کله کله ورته باینري انتخاب هم وايي ځکه د اجرا دوه ممکنې لارې لري.
p شرط (Relational Expression) کی شکل میں لکھی جاتی ہے۔ اگر شرط کا نتیجہ درست (True) ہے تو، اسٹیٹمنٹ یا اسٹیٹمنٹس کا مجموعہ جو کہ if اسٹیٹمنٹ کے بعد آتا ہے اسے چلا دیا جاتا ہے ورنہ نظر انداز کر دیا جاتا ہے۔ if اسٹیٹمنٹ کا سائنٹکس درج ذیل ہے: || The condition is written in the form of a relational expression. If the condition is true, the statement or set of statements that follows the if statement is run; otherwise it is skipped. The syntax of the if statement is: || شرط د نسبتي عبارت (Relational Expression) په بڼه لیکل کېږي. که شرط سم (True) وي، هغه بیان یا د بیانونو ټولګه چې له if وروسته راځي چلېږي؛ که نه، پرېښودل کېږي. د if بیان ترکیب دا دی:
m if (condition)
m     statement;
p مذکورہ سائنٹکس ایک اکیلی اسٹیٹمنٹ کے لیے استعمال ہوتا ہے۔ اسٹیٹمنٹس کے مجموعہ کو بھی مشروط کیا جا سکتا ہے۔ ایسی صورت میں اسٹیٹمنٹس کے مجموعہ کو قوسین { } کے درمیان لکھا جاتا ہے۔ اسٹیٹمنٹس کے اس مجموعہ کو کمپاؤنڈ اسٹیٹمنٹس (Compound Statements) یا اسٹیٹمنٹس کا بلاک بھی کہا جاتا ہے۔ کمپاؤنڈ اسٹیٹمنٹس کے لیے if اسٹیٹمنٹ کا سائنٹکس درج ذیل ہے: || The syntax above is used for a single statement. A set of statements can also be made conditional; in that case the set of statements is written between braces { }. Such a set of statements is also called compound statements, or a block of statements. The syntax of the if statement for compound statements is: || پورتنی ترکیب د یوه بیان لپاره کارېږي. د بیانونو ټولګه هم شرطي کېدای شي؛ په دې حالت کې د بیانونو ټولګه د { } قوسونو ترمنځ لیکل کېږي. دې ټولګې ته مرکب بیانونه (Compound Statements) یا د بیانونو بلاک هم وايي. د مرکب بیانونو لپاره د if ترکیب دا دی:
m if (condition)
m {
m     statement 1;
m     statement 2;
m     .
m     .
m     Statement n;
m }
