Different methods are used to make lists in HTML. || د جوړښت له نظره لېستونه ښه دي ځکه سند پوهېدل اسانه کوي. په HTML کې د لېست جوړولو لپاره بېلابېلې لارې کارېږي.

### 7.4.1 لسٹ کی اقسام || 7.4.1 Kinds of lists || ۷.۴.۱ د لېستونو ډولونه
p جب ہم کسی ویب سائٹ پر لسٹ استعمال کرنا چاہتے ہیں تو، HTML چار مختلف اقسام کی لسٹ فراہم کرتا ہے۔ unordered list، ordered list، definition list اور Nested list ہیں۔ || When we want to use a list on a website, HTML provides four different kinds of list: the unordered list, the ordered list, the definition list and the nested list. || کله چې غواړو په ویب سایټ کې لېست وکاروو، HTML څلور بېل ډوله لېستونه برابروي: بې ترتیبه (unordered)، ترتیبي (ordered)، تعریفي (definition) او ځالې (nested) لېست.
### ان آرڈرڈ لسٹ || Unordered list || بې ترتیبه لېست
p یہ لسٹ متعلقہ اشیاء کا ایک مجموعہ ہے جس کی کوئی خاص ترتیب نہیں ہوتی۔ اس لسٹ میں شامل ہر شے کے سامنے ایک … لگا دیا گیا ہے۔ <ul></ul> ٹیگز کو ایسی لسٹ بنانے کے لئے استعمال کیا جاتا ہے اور فہرست کی ہر شے کو <li></li> ٹیگز کے ساتھ … لیا جاتا ہے۔ || This list is a collection of related items with no particular order. A bullet is placed in front of each item in the list. The <ul></ul> tags are used to make such a list, and each item of the list is enclosed in <li></li> tags. || دا لېست د اړوندو توکو ټولګه ده چې ځانګړی ترتیب نه لري. د لېست د هر توکي مخې ته یو ټکی (bullet) ایښودل کېږي. د داسې لېست د جوړولو لپاره <ul></ul> ټیګونه کارېږي، او د لېست هر توکی په <li></li> ټیګونو کې تړل کېږي.
@issue Words at the right edge are cut off in the scan ("…کے سامنے ایک … لگا دیا گیا ہے", "…کے ساتھ … لیا جاتا ہے"); "bullet" and "enclosed" are supplied from context.
### آرڈرڈ لسٹ || Ordered list || ترتیبي لېست
p اس لسٹ میں لسٹ کے تمام آئٹمز ایک نمبر سے شروع ہوتے ہیں اور نمبر بڑھتی ہوئی ترتیب میں ہوتے ہیں۔ <ol></ol> ٹیگز آرڈرڈ لسٹ بنانے کے لیے استعمال ہوتے ہیں اور فہرست کی ہر شے کو <li></li> ٹیگز کے ساتھ گھیر لیا جاتا ہے۔ || In this list all the items start with a number, and the numbers go up in order. The <ol></ol> tags are used to make an ordered list, and each item of the list is enclosed in <li></li> tags. || په دې لېست کې ټول توکي په یوه شمېره پیلېږي او شمېرې په ډېرېدونکي ترتیب وي. <ol></ol> ټیګونه د ترتیبي لېست د جوړولو لپاره کارېږي، او د لېست هر توکی په <li></li> ټیګونو کې تړل کېږي.
### تعریفی لسٹ || Definition list || تعریفي لېست
p HTML ایک لسٹ اسٹائل کی تائید کرتا ہے جس کو Definition list کہا جاتا ہے جہاں اندراجات کسی لسٹ یا انسائیکلوپیڈیا کی طرح درج ہیں۔ Definition list ایک لغت، اصطلاحات کی لسٹ، یا دوسرے نام/قیمت کی لسٹ پیش کرنے کا ایک مثالی طریقہ ہے۔ یہ آئٹمز کی لسٹ نہیں ہے۔ یہ اصطلاحات کی وضاحت کے ساتھ لسٹ ہے۔ <dl></dl>، <dt></dt> اور <dd></dd> ٹیگز کا استعمال کر کے definition لسٹ بنائی جاتی ہے۔ || HTML supports a list style called the definition list, in which entries are listed as in a glossary or an encyclopedia. A definition list is an ideal way to present a dictionary, a list of terms, or another list of names/values. It is not a list of items; it is a list of terms with their explanations. A definition list is made with the <dl></dl>, <dt></dt> and <dd></dd> tags. || HTML د لېست یوه بڼه ملاتړ کوي چې Definition list بلل کېږي، چې پکې ننوتنې د لغت یا دایرة المعارف په څېر لیکل کېږي. Definition list د قاموس، اصطلاحګانو د لېست، یا د نوم/ارزښت د نورو لېستونو د وړاندې کولو غوره لاره ده. دا د توکو لېست نه دی؛ دا د اصطلاحګانو او د هغو د تشریح لېست دی. Definition لېست د <dl></dl>، <dt></dt> او <dd></dd> ټیګونو په کارولو جوړېږي.
- <dl></dl>: یہ ٹیگ definition list بنانے کے لئے استعمال ہوتے ہیں۔ || <dl></dl>: these tags are used to make a definition list. || <dl></dl>: دا ټیګونه د definition list د جوړولو لپاره کارېږي.
- <dt></dt>: یہ ٹیگ definition list کی ہر اصطلاح کی تعریف کے لئے استعمال ہوتے ہیں۔ || <dt></dt>: these tags are used for each term of the definition list. || <dt></dt>: دا ټیګونه د definition list د هرې اصطلاح لپاره کارېږي.
- <dd></dd>: یہ ٹیگ تعریف کی فہرست کی ہر اصطلاح کی وضاحت کے لئے استعمال ہوتے ہیں۔ || <dd></dd>: these tags are used for the explanation of each term in the definition list. || <dd></dd>: دا ټیګونه د تعریفي لېست د هرې اصطلاح د تشریح لپاره کارېږي.
### نیسٹڈ لسٹ || Nested list || ځالې لېست
p ایک لسٹ میں دوسری لسٹ کو بند کرنے کو نیسٹڈ (Nested) لسٹ کہا جاتا ہے۔ نیسٹڈ لسٹ بنانے کے لیے آرڈرڈ (Ordered) اور ان آرڈرڈ (Unordered) لسٹ کا کوئی بھی امتزاج بنایا جا سکتا ہے۔ || Enclosing one list inside another is called a nested list. Any combination of ordered and unordered lists can be used to make a nested list. || د یوه لېست دننه د بل لېست تړلو ته ځالې (Nested) لېست وايي. د ځالې لېست د جوړولو لپاره د ترتیبي (Ordered) او بې ترتیبه (Unordered) لېستونو هر ترکیب جوړېدای شي.
@issue The <dt> tag holds the term itself, not its "definition" (تعریف) as printed; the definition goes in <dd>.
