## 7.7 ٹیبل / جدول بنانا (Creating Tables) || 7.7 Creating tables || ۷.۷ جدولونه جوړول (Creating Tables)
p ٹیبلز کا استعمال اکثر ویب پیجز میں منظم انداز میں معلومات پیش کرنے کے لئے کیا جاتا ہے جسے یوزر کے لیے پڑھنا اور سمجھنا آسان ہوتا ہے۔ ایک ٹیبل قطاروں (Rows) اور کالموں (Columns) پر مشتمل ہوتا ہے۔ ایک ٹیبل آپ کو تیزی سے اور آسانی سے ایسی معلومات تلاش کرنے کی اجازت دیتا ہے جو مختلف قسم کے ڈیٹا کے درمیان کسی نہ کسی طرح کے تعلق کی نشاندہی کرتی ہیں، مثال کے طور پر، افراد کے نام اور ان کی عمر، یا ہفتے کا ایک دن، یا کلاسوں کا ٹائم ٹیبل۔ || Tables are often used in web pages to present information in an organised way that is easy for the user to read and understand. A table consists of rows and columns. A table lets you quickly and easily find information that shows some kind of relationship between different kinds of data — for example, people's names and their ages, a day of the week, or a class timetable. || جدولونه اکثر په ویب پاڼو کې په منظم ډول د معلوماتو وړاندې کولو لپاره کارېږي چې کاروونکي ته یې لوستل او پوهېدل اسانه وي. جدول له کرښو (Rows) او ستنو (Columns) جوړ وي. جدول تاسو ته اجازه درکوي چې ژر او اسانه هغه معلومات ومومئ چې د بېلابېلو ډېټاوو ترمنځ یو ډول اړیکه ښيي، لکه د وګړو نومونه او عمرونه، د اونۍ یوه ورځ، یا د ټولګیو مهالوېش.
p HTML ٹیبل یوزر کو ڈیٹا یعنی ٹیکسٹ، تصاویر، لنکس، فارم، فارم فیلڈز، دیگر ٹیبلز وغیرہ کو سیلوں اور قطاروں میں ترتیب دینے کی سہولت دیتا ہے۔ ہر ٹیبل کا کوئی نام ہو سکتا ہے جو ٹیبل کے مقصد کی مختصر وضاحت فراہم کرتا ہے۔ ٹیبل کے متعلق تفصیلی معلومات بھی فراہم کی جا سکتی ہیں جو کہ بریلے استعمال کرنے والوں کے لیے آسانی فراہم کرتی ہیں۔ ٹیبل بنانے کے لئے درج ذیل ٹیگز استعمال ہوتے ہیں۔ || An HTML table lets the user arrange data — text, pictures, links, forms, form fields, other tables and so on — in cells and rows. Each table can have a name (caption) that briefly explains its purpose. Detailed information about the table can also be provided, which helps people who use Braille. The following tags are used to make a table. || HTML جدول کاروونکي ته اجازه ورکوي چې ډېټا — متن، انځورونه، لینکونه، فورمې، د فورم ساحې، نور جدولونه او نور — په حجرو او کرښو کې ترتیب کړي. هر جدول کولای شي یو نوم (سرلیک) ولري چې د جدول موخه په لنډه توګه ښيي. د جدول په اړه تفصیلي معلومات هم ورکول کېدای شي چې د بریل کاروونکو لپاره اسانتیا برابروي. د جدول جوړولو لپاره لاندې ټیګونه کارېږي.
- <table></table>: یہ ٹیگ ٹیبل بنانے کیلئے استعمال ہوتے ہیں۔ || <table></table>: these tags are used to make a table. || <table></table>: دا ټیګونه د جدول جوړولو لپاره کارېږي.
- <tr></tr>: یہ ٹیگ قطار بنانے کے لیے استعمال ہوتے ہیں۔ || <tr></tr>: these tags are used to make a row. || <tr></tr>: دا ټیګونه د کرښې جوړولو لپاره کارېږي.
- <td></td>: یہ ٹیگ ڈیٹا سیل (Data Cell) بنانے کے لیے استعمال ہوں گے۔ ہر قطار کے ایک کالم کو ڈیٹا سیل کہا جاتا ہے۔ ایک ڈیٹا سیل میں ٹیکسٹ، تصویر، پیراگراف وغیرہ ہو سکتے ہیں۔ || <td></td>: these tags are used to make a data cell. One column of each row is called a data cell. A data cell can contain text, a picture, a paragraph and so on. || <td></td>: دا ټیګونه د ډېټا حجرې (Data Cell) جوړولو لپاره کارېږي. د هرې کرښې یوې ستنې ته ډېټا حجره وايي. په ډېټا حجره کې متن، انځور، پاراګراف او نور کېدای شي.
