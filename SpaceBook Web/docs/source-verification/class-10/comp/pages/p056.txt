### 2۔ ظاہری ٹائپ کاسٹنگ (Explicit Type Casting) || 2. Explicit type casting || ۲. ښکاره ډول بدلون (Explicit Type Casting)
p اس طرح کی ٹائپ کاسٹنگ پروگرامر خود کرتا ہے۔ یہ کاسٹ آپریٹر (Cast operator) کا استعمال کر کے کی جاتی ہے۔ کاسٹ آپریٹر کمپیوٹر کو یہ بتاتا ہے کہ ڈیٹا کو ایک قسم سے دوسری قسم میں تبدیل کرنا ہے۔ || The programmer does this kind of type casting himself. It is done using the cast operator, which tells the computer that data is to be converted from one type to another. || دا ډول بدلون پروګرامر پخپله کوي. د cast عملګر (Cast operator) په کارولو ترسره کېږي. cast عملګر کمپیوټر ته وايي چې ډېټا له یوه ډول بل ډول ته واړوي.
p کاسٹ آپریٹر کا سائنٹکس یہ ہے: || The syntax of the cast operator is: || د cast عملګر ترکیب دا دی:
m (type) expression;
p (type): یہ ڈیٹا کی قسم کو ظاہر کرتا ہے جس میں اوپرینڈ (operand) کو تبدیل کرنا ہے۔ || (type): shows the data type into which the operand is to be converted. || (type): هغه ډېټا ډول ښيي چې عملوند (operand) ورته بدلېږي.
p expression: یہ کانسٹنٹ، ویری ایبل یا expression کو ظاہر کرتا ہے جس کی ڈیٹا ٹائپ کو تبدیل کرنا ہے۔ || expression: shows the constant, variable or expression whose data type is to be converted. || expression: هغه ثابت، متغیر یا expression ښيي چې ډېټا ډول یې بدلېږي.
p مثال: فرض کیا x اور y دو float قسم کے ویری ایبل ہیں۔ x کی قیمت 10.3 ہے اور y کی قیمت 5.2 ہے اور ہم نے ذیل کی عبارت کو حل کرنا ہے: || Example: suppose x and y are two variables of type float. The value of x is 10.3 and the value of y is 5.2, and we have to evaluate the following expression: || بېلګه: فرض کړئ x او y دوه float ډوله متغیرونه دي. د x ارزښت 10.3 او د y ارزښت 5.2 دی، او باید لاندې عبارت حل کړو:
m x%y
p مندرجہ بالا عمل پروگرام میں ایک غلطی (error) پیدا کر دے گا کیونکہ x اور y کی ڈیٹا قسم float ہے اور موڈولس (Modulus) پر آپریٹر % کسی float ویری ایبل کے ساتھ کام نہیں کر سکتا۔ یہ صرف انٹیجر پر ہی عمل کرتا ہے۔ اس لیے مندرجہ بالا عبارت کو اس طرح لکھا جا سکتا ہے تاکہ غلطی پیدا نہ ہو۔ || The above operation will produce an error in the program, because the data type of x and y is float and the modulus operator % cannot work with a float variable; it works only on integers. So the above expression can be written like this so that no error occurs: || پورتنۍ عملیه به په پروګرام کې تېروتنه (error) پیدا کړي، ځکه د x او y ډېټا ډول float دی او د پاتې (Modulus) عملګر % له float متغیر سره کار نه شي کولای؛ یوازې پر بشپړو عددونو کار کوي. نو پورتنی عبارت داسې لیکل کېدای شي چې تېروتنه پیدا نه شي:
m (int) x% (int) y
p اس عبارت میں x اور y کی قیمتیں پہلے انٹیجر میں تبدیل کر دی جائیں گی اور پھر ان کو حل کیا جائے گا۔ x کی قیمت کو 10 میں اور y کی قیمت کو 5 میں تبدیل کر دیا جائے گا۔ اس عبارت کا نتیجہ 0 (صفر) ہو گا۔ || In this expression the values of x and y are first converted into integers and then evaluated: x becomes 10 and y becomes 5. The result of this expression will be 0 (zero). || په دې عبارت کې د x او y ارزښتونه لومړی بشپړو عددونو ته بدلېږي او بیا حلېږي: د x ارزښت 10 او د y ارزښت 5 کېږي. د دې عبارت پایله 0 (صفر) ده.

### 2.4.6 const کا استعمال (Constant Qualifier) || 2.4.6 Using const (the constant qualifier) || ۲.۴.۶ د const کارول (Constant Qualifier)
p const کو پروگرام کے اندر کانسٹنٹ (Constant) کی تعریف کرنے کے لیے استعمال کیا جاتا ہے۔ کانسٹنٹ کی تعریف کرنے کے لیے اس کا نام اور اس کی ڈیٹا ٹائپ لکھنا لازمی ہے۔ کانسٹنٹ کو ابتدائی قیمت دینا ضروری ہے۔ ابتدائی قیمت پروگرام چلنے کے دوران تبدیل نہیں کی جا سکتی۔ || const is used to define a constant inside a program. To define a constant, its name and its data type must be written. A constant must be given an initial value, and this initial value cannot be changed while the program is running. || const په پروګرام کې د ثابت (Constant) د تعریف لپاره کارېږي. د ثابت د تعریف لپاره د هغه نوم او ډېټا ډول لیکل اړین دي. ثابت ته لومړنی ارزښت ورکول اړین دي او دا لومړنی ارزښت د پروګرام د چلېدو پر مهال نه شي بدلېدای.
p سائنٹکس: const کی مدد سے کانسٹنٹ بنانے کو ذیل میں دکھایا گیا ہے: || Syntax: creating a constant with const is shown below: || ترکیب: د const په مرسته د ثابت جوړول لاندې ښودل شوي:
m const data type identifier = value;
