### 2۔ فلوٹنگ پوائنٹ ڈیٹا ٹائپ (float, double, long double) || 2. Floating-point data types (float, double, long double) || ۲. اعشاري ډېټا ډولونه (float, double, long double)
p نقطہ اعشاریہ والے اعداد اصل میں حقیقی اعداد کے اظہار کے لیے استعمال ہوتے ہیں۔ ان اعداد کی نقطہ اعشاریہ کے بعد 7 اعداد تک درست قیمت ظاہر ہوتی ہے۔ فلوٹنگ پوائنٹ نمبرز کو کی ورڈ float کے ذریعے ظاہر کیا جاتا ہے۔ جب فلوٹنگ پوائنٹ نمبر کی درستگی ناکافی ہوتی ہے تو، ہم نمبر کی وضاحت کے لئے double اور long double کا استعمال کر سکتے ہیں۔ پروگرام میں فلوٹنگ پوائنٹ کی تعریف کرنے کے لیے درج ذیل اسٹیٹمنٹ لکھی جا سکتی ہے۔ || Numbers with a decimal point are used to represent real numbers. Their value is shown correctly up to 7 digits after the decimal point. Floating-point numbers are declared with the keyword float. When the precision of a floating-point number is not enough, we can use double and long double to specify the number. The following statement can be written to declare a floating-point variable in a program: || د اعشاري ټکي لرونکي عددونه په اصل کې د حقیقي عددونو د ښودلو لپاره کارېږي. د دې عددونو ارزښت د اعشاري ټکي وروسته تر 7 عددونو پورې سم ښکاري. اعشاري عددونه د float کلیدي کلمې په مرسته ښودل کېږي. کله چې د اعشاري عدد دقت بس نه وي، د عدد د ښودلو لپاره double او long double کارولای شو. په پروګرام کې د اعشاري متغیر د تعریف لپاره لاندې بیان لیکل کېدای شي:

### 3۔ کریکٹر (char) ڈیٹا ٹائپ (Character datatype) || 3. Character (char) data type || ۳. توری (char) ډېټا ډول
