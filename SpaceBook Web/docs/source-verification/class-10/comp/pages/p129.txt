### XOR گیٹ (Exclusive-OR Gate) || The XOR gate (Exclusive-OR gate) || XOR دروازه (Exclusive-OR Gate)
p وہ گیٹ جس کی آؤٹ پُٹ '0' ہوتی ہے جب ساری اِن پُٹ 0 یا 1 کی ہوتی ہے تو اسے XOR گیٹ کہا جاتا ہے۔ لہٰذا XOR گیٹ ایک جیسی اِن پُٹ کی بنیاد پر '0' آؤٹ پُٹ دیتا ہے، اور مختلف اِن پُٹ کی بنیاد پر '1' آؤٹ پُٹ دیتا ہے۔ || A gate whose output is '0' when all its inputs are 0 or all are 1 is called an XOR gate. So the XOR gate gives a '0' output for identical inputs and a '1' output for different inputs. || هغه دروازه چې کله یې ټول inputs 0 یا ټول 1 وي output یې '0' وي، XOR دروازه بلل کېږي. نو XOR دروازه د یو شان inputs لپاره '0' او د بېلابېلو inputs لپاره '1' output ورکوي.

### XOR گیٹ کا ٹرُتھ ٹیبل || Truth table of the XOR gate || د XOR دروازې د حقیقت جدول
table جدول نمبر 6.8 دو اِن پُٹ والے XOR گیٹ کا ٹرُتھ ٹیبل || Table 6.8 Truth table of a two-input XOR gate || ۶.۸ جدول د دوه input لرونکې XOR دروازې د حقیقت جدول
th | A | B | Y = (A⊕B) = A̅B + AB̅
tr | 0 | 0 | 0
tr | 0 | 1 | 1
tr | 1 | 0 | 1
tr | 1 | 1 | 0
endtable
@issue Table 6.8's heading prints both bars over A ("ĀB + ĀB"); the correct XOR expression, as in Figure 6.6, is ĀB + AB̄. Corrected above. For more than two inputs XOR is 1 when an odd number of inputs are 1, so "all inputs 0 or 1 give 0" holds only for two inputs.
@deco Both truth tables have a two-level header in the book: "اِن پُٹ" (Input) over A/B and "آؤٹ پُٹ" (Output) over Y.
