p درج ذیل پروگرام if اسٹیٹمنٹ کے استعمال کو واضح کرتا ہے۔ || The following program shows the use of the if statement. || لاندې پروګرام د if بیان کارونه ښيي.
### پروگرام 4.1 ایک پروگرام جو اس وقت اِن پُٹ کیے ہوئے نمبر کو پرنٹ کرے گا جب وہ 50 سے بڑا ہو۔ || Program 4.1 A program that prints the input number when it is greater than 50 || پروګرام ۴.۱ داسې پروګرام چې داخل شوی عدد هغه وخت چاپوي چې له 50 لوی وي
m #include<stdio.h>
m void main()
m {
m     int x;
m     printf("\n Enter an integer = ");
m     scanf("%d",&x);
m     if(x >50)
m     printf("%d", x);
m }
box info | آؤٹ پُٹ || Output || Output
m Enter an integer = 75
m 75
endbox
### پروگرام 4.2 درج ذیل پروگرام ایک اکیلی اسٹیٹمنٹ کو چلائے گا اگر if اسٹیٹمنٹ میں دی گئی شرط کا نتیجہ True آتا ہے۔ || Program 4.2 The following program runs a single statement if the condition given in the if statement is true || پروګرام ۴.۲ لاندې پروګرام یو بیان چلوي که د if په بیان کې ورکړل شوی شرط True وي
m #include<stdio.h>
m void main()
m {
m     int a, b;
m     a=1000;
m     b=500;
m     if(a>b) {
m         printf("Value of a is greater than b\n"); }
m         printf("Thank You");
m     }
m }
box info | آؤٹ پُٹ || Output || Output
m Value of a is greater than b
m Thank You
endbox
@issue Program 4.2 has an extra closing brace: the if block already closes with "}" after the first printf, so the "}" after "Thank You" ends main() and the last "}" is a syntax error. The "Thank You" line is printed indented as if inside the if, but it runs regardless of the condition. The scan shows typographic quotes (“ ”) in several printf calls; straight quotes are required in C.
