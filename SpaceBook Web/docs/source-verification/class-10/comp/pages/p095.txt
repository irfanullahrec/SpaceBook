### 4.1.5 switch اسٹیٹمنٹ (The switch Statement) || 4.1.5 The switch statement || ۴.۱.۵ switch بیان
@issue The English heading is misspelled "swtich"; corrected to "switch".
p C میں switch اسٹیٹمنٹ ویری ایبل کی قیمت کی جانچ کرتا ہے اور اس کا ایک سے زیادہ case کے ساتھ موازنہ کرتا ہے۔ ایک بار جب case میچ ہو جاتا ہے تو، اس خاص case سے وابستہ اسٹیٹمنٹ کا ایک بلاک چلایا جاتا ہے۔ || In C the switch statement checks the value of a variable and compares it with more than one case. Once a case matches, the block of statements associated with that particular case is run. || په C کې switch بیان د متغیر ارزښت ازمویي او له ګڼو case سره یې پرتله کوي. کله چې یو case سمون ومومي، د هماغه case سره تړلی د بیانونو بلاک چلېږي.
p switch کے ایک بلاک میں ہر case کا ایک مختلف نام / نمبر ہوتا ہے جسے آئیڈینٹیفائر (Identifier) کہا جاتا ہے۔ یوزر کی فراہم کردہ قیمت کا موازنہ switch بلاک کے اندر موجود تمام cases سے کیا جاتا ہے۔ اگر کوئی case میچ نہیں ملا تو default اسٹیٹمنٹ پر عمل درآمد ہو جاتا ہے، اور کنٹرول switch بلاک سے باہر نکل جاتا ہے۔ || In a switch block each case has a different name/number, called an identifier. The value supplied by the user is compared with all the cases inside the switch block. If no case matches, the default statement is executed and control leaves the switch block. || د switch په یوه بلاک کې هر case یو بېل نوم/شمېره لري چې پېژندونکی (Identifier) بلل کېږي. د کاروونکي ورکړل شوی ارزښت د switch بلاک له ټولو case سره پرتله کېږي. که هېڅ case سمون ونه مومي، default بیان اجرا کېږي او کنټرول له switch بلاک وځي.
