### آبجیکٹ اورینٹڈ پروگرامنگ لینگویج (Object Oriented Programming Language) || Object-oriented programming language || شي محوره پروګرامي ژبه
p آبجیکٹ اورینٹڈ پروگرامنگ میں، پروگرام آبجیکٹس کے ایک سیٹ کا استعمال کر کے تیار کیا جاتا ہے۔ ایک آبجیکٹ پروگرام ایک ایسا جزو ہے جس سے ماڈلز یو کا ایک سیٹ اور ڈیٹا سٹرکچر منسلک ہوتے ہیں۔ یہ پروگرام کو ڈیزائن کرنے کے لئے ایک جدید اور آسان تکنیک ہے۔ ایک بار جب کسی بھی پروگرام کے لئے کوئی آبجیکٹ ڈیزائن ہو جائے تو پھر اسے کسی بھی دوسرے پروگرام میں دوبارہ استعمال کیا جا سکتا ہے۔ کچھ مقبول اور عام استعمال ہونے والی آبجیکٹ اورینٹڈ پروگرامنگ (OOP) لینگویجز کی مثالیں C++ اور JAVA ہیں۔ || In object-oriented programming, a program is prepared using a set of objects. An object is a program component to which a set of modules and data structures is attached. It is a modern and easy technique for designing programs. Once an object has been designed for any program, it can be reused in any other program. Examples of some popular and commonly used object-oriented programming (OOP) languages are C++ and JAVA. || په شي محوره پروګرام جوړونه کې پروګرام د شیانو (objects) د یوې ټولګې په کارولو جوړېږي. شی (object) د پروګرام هغه برخه ده چې د ماډیولونو یوه ټولګه او ډېټا جوړښتونه ورسره تړلي وي. دا د پروګرام د ډیزاین لپاره یوه نوې او اسانه طریقه ده. کله چې د یوه پروګرام لپاره یو شی ډیزاین شي، بیا په هر بل پروګرام کې بیا کارېدای شي. د ځینو مشهورو او عام کارېدونکو شي محوره (OOP) ژبو بېلګې C++ او JAVA دي.
@issue "ماڈلز یو کا ایک سیٹ" is a misprint of "ماڈیولز کا ایک سیٹ" (a set of modules); transcribed as printed and translated as "modules". "C ++" is printed with a space; read as C++.

### 2.1.3 ہائی لیول پروگرامنگ لینگویجز کی خصوصیات (Characteristic of High Level Programming Languages) || 2.1.3 Characteristics of high-level programming languages || ۲.۱.۳ د لوړې کچې پروګرامي ژبو ځانګړنې
p ہائی لیول پروگرامنگ لینگویجز کی چند خصوصیات درج ذیل ہیں۔ || Some characteristics of high-level programming languages are as follows. || د لوړې کچې پروګرامي ژبو ځینې ځانګړنې دا دي.
### سیکھنے میں آسان (Easy to Learn) || Easy to learn || زده کول یې اسانه دي
p لو لیول پروگرامنگ کے مقابلے میں ہائی لیول پروگرامنگ لینگویجز سیکھنے میں بہت آسان ہوتی ہیں۔ پروگرام کے لئے لکھی گئی اسٹیٹمنٹس بالکل انگریزی زبان جیسے جملوں کی طرح ہی ہوتی ہیں۔ || Compared with low-level programming, high-level programming languages are very easy to learn. The statements written for a program are just like sentences of the English language. || د ټیټې کچې پروګرام جوړونې په پرتله لوړې کچې پروګرامي ژبې زده کول ډېر اسانه دي. د پروګرام لپاره لیکل شوي بیانونه بالکل د انګرېزي ژبې د جملو په څېر وي.
### سمجھنے میں آسان (Easy to Understand) || Easy to understand || پوهېدل یې اسانه دي
p ہائی لیول پروگرامنگ لینگویج میں ایک پروگرامر کا لکھا ہوا کوئی بھی پروگرام دوسرا پروگرامر آسانی سے سمجھ سکتا ہے۔ کیونکہ پروگرام میں لکھی گئی ہدایات انگریزی زبان کی طرح ہی ہوتی ہیں۔ || Any program written by one programmer in a high-level programming language can easily be understood by another programmer, because the instructions written in the program are just like the English language. || په لوړې کچې پروګرامي ژبه د یوه پروګرامر لیکلی هر پروګرام بل پروګرامر په اسانۍ پوهېدای شي، ځکه په پروګرام کې لیکل شوې لارښوونې د انګرېزي ژبې په څېر وي.
