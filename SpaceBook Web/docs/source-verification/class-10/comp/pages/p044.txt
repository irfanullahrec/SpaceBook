### 2.2.2 C پروگرامنگ انوائرمنٹ کے مختلف اجزاء (Modules of the C Programming Environment) || 2.2.2 Modules of the C programming environment || ۲.۲.۲ د C پروګرامي چاپېریال برخې
p ذیل میں C لینگویج میں پروگرامنگ کے لیے درکار اجزاء بیان کیے گئے ہیں۔ || The components needed for programming in the C language are described below. || لاندې په C ژبه کې د پروګرام جوړونې لپاره اړینې برخې بیان شوې دي.
### 1۔ ایڈیٹر (Editor) || 1. Editor || ۱. اډیټر
p ایڈیٹر یا ٹیکسٹ ایڈیٹر ایک ایسا پروگرام ہے جو صارفین کو C لینگویج سورس پروگرام بنانے اور اس میں ترمیم کرنے کے قابل بناتا ہے۔ C کے پروگرام کی ایکسٹینشن c. ہوتی ہے۔ مثلاً student.c ایسا ہی ایک پروگرام ہے۔ تقریباً ہر ایک ایڈیٹر پروگرام کمپائل کرنے کے دوران پروگرام میں موجود تمام غلطیوں کو واضح کرتا ہے تاکہ انہیں آسانی سے دور کیا جا سکے۔ || An editor, or text editor, is a program that enables users to create a C-language source program and modify it. A C program has the extension .c; for example, student.c is such a program. Almost every editor points out all the errors in the program while it is being compiled, so that they can be removed easily. || اډیټر یا متن اډیټر داسې پروګرام دی چې کاروونکي د C ژبې سرچینه پروګرام جوړولو او سمولو ته وړ کوي. د C پروګرام توسیع (extension) ‎.c وي؛ لکه student.c. نږدې هر اډیټر د کمپایل پر مهال په پروګرام کې ټولې تېروتنې روښانه کوي چې په اسانۍ لرې شي.
@issue The extension is printed ".c" with the dot placed after the letter by the right-to-left layout ("c."); it is ".c".
### 2۔ کمپائلر (Compiler) || 2. Compiler || ۲. کمپایلر
p ایک ایسا کمپیوٹر سافٹ ویئر ہے جو C لینگویج پروگرام سورس کوڈ (Source Code) کو مشین کوڈ (آبجیکٹ پروگرام) میں ترجمہ کرتا ہے تاکہ کمپیوٹر اسے سمجھ کر چلا (execute) سکے۔ C لینگویج کے کسی بھی کمپائل شدہ پروگرام کی ایکسٹینشن (پہچان) obj. ہوتی ہے۔ مثلاً student.obj۔ کمپائل کرنے کے عمل کو ذیل میں شکل نمبر 2.10 میں دکھایا گیا ہے۔ || It is computer software that translates C-language program source code into machine code (an object program) so that the computer can understand and execute it. Any compiled program of the C language has the extension .obj, for example student.obj. The process of compiling is shown below in Figure 2.10. || داسې کمپیوټري سافټویر دی چې د C ژبې د پروګرام سرچینه کوډ (Source Code) ماشین کوډ (object پروګرام) ته ژباړي چې کمپیوټر یې پوه او اجرا (execute) کړي. د C ژبې د هر کمپایل شوي پروګرام توسیع ‎.obj وي، لکه student.obj. د کمپایل کولو بهیر لاندې په ۲.۱۰ شکل کې ښودل شوی.
