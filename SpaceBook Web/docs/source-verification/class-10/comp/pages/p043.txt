### انٹرپریٹر (Interpreter) || Interpreter || انټرپریټر
p انٹرپریٹر بھی ہائی لیول پروگرامنگ لینگویج کا مترجم ہے جو پروگرام کی اسٹیٹمنٹ کو ایک ایک کر کے ترجمہ کرتا ہے اور ساتھ ہی ساتھ چلاتا بھی ہے۔ یہ پروگرام کی ایک اسٹیٹمنٹ کو لے کر اسے مشین لینگویج میں تبدیل کرتا ہے، اس پر عمل درآمد کرتا ہے، اور پھر اگلی اسٹیٹمنٹ پر چلا جاتا ہے۔ || An interpreter is also a translator of high-level programming languages; it translates the statements of a program one by one and runs them at the same time. It takes one statement of the program, converts it into machine language, executes it, and then moves on to the next statement. || انټرپریټر هم د لوړې کچې پروګرامي ژبې ژباړونکی دی چې د پروګرام بیانونه یو په یو ژباړي او ورسره سم یې چلوي هم. د پروګرام یو بیان اخلي، د ماشین ژبې ته یې بدلوي، اجرا کوي یې او بیا راتلونکي بیان ته ځي.
p ہر دفعہ جب کوئی اسٹیٹمنٹ پڑھی جائے گی تو اسے چلانے سے پہلے ضرور مشین لینگویج میں ترجمہ کیا جائے گا۔ کمپائلر کمپیوٹر پر کسی پروگرام کو چلانے سے پہلے پورے پروگرام کو ایک ہی بار پڑھتا ہے اور آبجیکٹ پروگرام میں ترجمہ کرتا ہے۔ انٹرپریٹر کا استعمال کرنے والی پروگرامنگ لینگویجز کی مثالوں میں جاوا اسکرپٹ (JAVA Script)، BASIC، Visual Basic اور Perl شامل ہیں۔ || Every time a statement is read, it must be translated into machine language before it is run. A compiler, by contrast, reads the whole program at once before the program is run on the computer and translates it into an object program. Examples of programming languages that use an interpreter include JavaScript, BASIC, Visual Basic and Perl. || هر ځل چې یو بیان ولوستل شي، د چلولو مخکې باید د ماشین ژبې ته وژباړل شي. کمپایلر په کمپیوټر د پروګرام له چلولو مخکې ټول پروګرام په یو ځل لولي او object پروګرام ته یې ژباړي. د انټرپریټر کارونکو پروګرامي ژبو بېلګې JavaScript، BASIC، Visual Basic او Perl دي.

## 2.2 پروگرامنگ کا انوائرمنٹ (Programming Environment) || 2.2 Programming environment || ۲.۲ د پروګرام جوړونې چاپېریال
p پروگرامنگ انوائرمنٹ پروگرامنگ ٹولز کا ایک مجموعہ ہے جو کمپیوٹر پروگرام بنانے، کمپائل کرنے اور انہیں چلانے کے لیے استعمال کیا جاتا ہے۔ اس میں ایڈیٹر (Editor)، کمپائلر (Compiler)، لنکر (Linker)، ڈی بگر (Debugger) وغیرہ شامل ہیں۔ اسے انٹیگریٹڈ ڈویلپمنٹ انوائرمنٹ (IDE) کا نام بھی دیا جاتا ہے جو کمپیوٹر پروگرام بنانے میں مدد کرتا ہے۔ انٹیگریٹڈ ڈویلپمنٹ انوائرمنٹ در حقیقت ایک ایپلیکیشن سافٹ ویئر ہے جو گرافیکل یوزر انٹرفیس (GUI) مہیا کرتا ہے۔ || A programming environment is a set of programming tools used to make, compile and run computer programs. It includes an editor, compiler, linker, debugger and so on. It is also called an Integrated Development Environment (IDE), which helps in making computer programs. An integrated development environment is in fact application software that provides a graphical user interface (GUI). || د پروګرام جوړونې چاپېریال د پروګرامي وسیلو یوه ټولګه ده چې د کمپیوټري پروګرامونو د جوړولو، کمپایل کولو او چلولو لپاره کارېږي. په دې کې اډیټر (Editor)، کمپایلر (Compiler)، لینکر (Linker)، ډیبګر (Debugger) او نور شامل دي. دې ته یوځای شوی پراختیايي چاپېریال (IDE) هم ویل کېږي چې د کمپیوټري پروګرامونو په جوړولو کې مرسته کوي. IDE په حقیقت کې یو اپلیکېشن سافټویر دی چې ګرافیکي کارن انټرفېس (GUI) برابروي.
