### 2.1.1 کمپیوٹر پروگرام (Computer Program) || 2.1.1 Computer program || ۲.۱.۱ کمپیوټري پروګرام
p کمپیوٹر پروگرام ہدایات (Instructions) کا ایسا مجموعہ ہے جو کمپیوٹر کو بتا سکے کہ کیا کرنا اور کیسے کرنا ہے۔ کوئی بھی کمپیوٹر، کمپیوٹر پروگرام میں دی گئی ہدایات کے مطابق عمل کرتا ہے۔ کمپیوٹر پروگرام کسی بھی پروگرامنگ لینگویج میں لکھے جاتے ہیں۔ جو فرد کمپیوٹر پروگرام بناتا ہے اسے پروگرامر کہا جاتا ہے۔ پروگرامر پروگرام بنا کر کمپیوٹر کو ہدایات دیتا ہے کہ کس طرح ڈیٹا کو پروسیس کرے تاکہ وہ انفارمیشن میں تبدیل ہو جائے۔ پروگرامر مختلف پروگرامنگ لینگویج یا پروگرامنگ آلات کو استعمال کر کے پروگرام بناتا ہے۔ ذیل میں دی گئی دو اصطلاحات کمپیوٹر پروگرام سے متعلق ہیں۔ || A computer program is a set of instructions that can tell the computer what to do and how to do it. Any computer works according to the instructions given in a computer program. Computer programs are written in some programming language. The person who makes a computer program is called a programmer. By making a program, the programmer instructs the computer how to process data so that it is turned into information. The programmer makes programs using various programming languages or programming tools. The two terms given below relate to computer programs. || کمپیوټري پروګرام د لارښوونو (Instructions) هغه ټولګه ده چې کمپیوټر ته وايي څه وکړي او څنګه یې وکړي. هر کمپیوټر د کمپیوټري پروګرام د لارښوونو سره سم کار کوي. کمپیوټري پروګرامونه په یوه پروګرامي ژبه لیکل کېږي. هغه کس چې کمپیوټري پروګرام جوړوي پروګرامر بلل کېږي. پروګرامر د پروګرام په جوړولو کمپیوټر ته لارښوونه کوي چې ډېټا څنګه پروسس کړي چې په معلوماتو بدله شي. پروګرامر د بېلابېلو پروګرامي ژبو یا وسیلو په کارولو پروګرام جوړوي. لاندې دوه اصطلاحګانې له کمپیوټري پروګرام سره تړاو لري.
