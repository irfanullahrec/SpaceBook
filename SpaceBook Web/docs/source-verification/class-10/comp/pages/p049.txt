### کچھ اہم ہیڈر فائلیں: || Some important header files: || ځینې مهم هېډر فایلونه:
m <stdio.h>
p stdio.h ہیڈر فائل سٹینڈرڈ اِن پُٹ آؤٹ پُٹ ہیڈر کے لئے ہے۔ اس میں پروگرام میں سٹینڈرڈ اِن پُٹ / آؤٹ پُٹ فنکشنز یعنی scanf() اور printf() شامل ہیں۔ || The stdio.h header file is for the standard input-output header. It contains the standard input/output functions used in a program, i.e. scanf() and printf(). || د stdio.h هېډر فایل د معیاري input-output هېډر لپاره دی. دا د پروګرام معیاري input/output فنکشنونه یعنې scanf() او printf() لري.
m <conio.h>
p یہ کنسول اِن پُٹ / آؤٹ پُٹ کے لئے ہے۔ C پروگرامنگ میں استعمال ہونے والی conio.h ہیڈر فائل کنسول اِن پُٹ / آؤٹ پُٹ فنکشنز پر مشتمل ہوتی ہے۔ conio.h کے عام طور پر استعمال ہونے والے کچھ فنکشنز ہیں clrscr()، getch()، getche() وغیرہ۔ conio.h کے فنکشنز کو اسکرین کو صاف کرنے، ٹیکسٹ اور رنگ تبدیل کرنے، ٹیکسٹ کو حرکت دینے، کونسی key دبائی گئی ہے اس کا پتہ لگانے اور اس کے علاوہ بہت سارے کاموں کے لیے استعمال کیا جاتا ہے۔ || It is for console input/output. The conio.h header file used in C programming contains console input/output functions. Some commonly used functions of conio.h are clrscr(), getch(), getche() and so on. The functions of conio.h are used to clear the screen, change text and colours, move text, detect which key was pressed, and for many other tasks. || دا د کنسول input/output لپاره دی. په C پروګرام جوړونه کې کارېدونکی conio.h هېډر فایل د کنسول input/output فنکشنونه لري. د conio.h ځینې عام کارېدونکي فنکشنونه clrscr()، getch()، getche() او نور دي. د conio.h فنکشنونه د سکرین پاکولو، د متن او رنګ بدلولو، د متن خوځولو، د دې موندلو چې کومه key کېښکاږل شوه، او ډېرو نورو کارونو لپاره کارېږي.
m <math.h>
p math.h ہیڈر فائل ریاضی کے عمل کو انجام دینے کے لئے استعمال ہوتے ہیں۔ یوزر پروگراموں میں ریاضی کے فنکشنز استعمال کر سکتے ہیں، اعداد کی مطلق قیمت کا حساب لگانے، لاگرتھم معلوم کرنے اور کسی زاویہ کے sine، cosine معلوم کرنے کے لئے ٹرگونومیٹرک فنکشن استعمال کرتے ہیں۔ || The math.h header file is used to carry out mathematical operations. Users can use mathematical functions in programs: to calculate the absolute value of numbers, find logarithms, and use trigonometric functions to find the sine and cosine of an angle. || د math.h هېډر فایل د ریاضي عملیاتو لپاره کارېږي. کاروونکي په پروګرامونو کې ریاضي فنکشنونه کارولای شي: د عددونو مطلق ارزښت حسابول، لوګاریتم موندل، او د زاویې د sine او cosine موندلو لپاره مثلثاتي فنکشنونه کارول.
m <string.h>
p سٹرنگ لائبریری string.h میں ایسے مفید فنکشنز ہوتے ہیں جن کو سٹرنگ کے لیے استعمال کیا جاتا ہے۔ جیسے strcpy()، strcat()، strcmp()، strlen()، وغیرہ۔ || The string library string.h has useful functions that are used for strings, such as strcpy(), strcat(), strcmp(), strlen() and so on. || د سټرنګ کتابتون string.h ګټور فنکشنونه لري چې د سټرنګونو لپاره کارېږي، لکه strcpy()، strcat()، strcmp()، strlen() او نور.
### main() فنکشن || The main() function || main() فنکشن
p یہ فنکشن ہر C پروگرام میں ہمیشہ موجود رہنا چاہئے۔ main فنکشن سے ہی C پروگرام پر عمل درآمد شروع ہوتا ہے۔ جب C کا کوئی بھی پروگرام چلایا جاتا ہے تو کنٹرول سب سے پہلے براہِ راست main() فنکشن میں منتقل ہو جاتا ہے۔ اگر پروگرام میں مین فنکشن نہ ہو تو پروگرام کمپائل نہیں ہو گا اور غلطی کا پیغام (Error Message) ظاہر ہو گا۔ || This function must always be present in every C program. Execution of a C program begins from the main function. When any C program is run, control first passes directly to the main() function. If a program has no main function, the program will not compile and an error message will appear. || دا فنکشن باید تل په هر C پروګرام کې وي. د C پروګرام اجرا له main فنکشن څخه پیلېږي. کله چې د C هر پروګرام وچلول شي، کنټرول لومړی مستقیم main() فنکشن ته ځي. که په پروګرام کې main فنکشن نه وي، پروګرام به کمپایل نه شي او د تېروتنې پیغام (Error Message) به ښکاره شي.
@issue Strictly, a program without main() compiles but fails to link ("undefined reference to main"); the book attributes the error to compilation.
p main() فنکشن کا سائنٹکس یہ ہے: || The syntax of the main() function is: || د main() فنکشن ترکیب دا دی:
m main()
m {
m     Program statement……
m }
