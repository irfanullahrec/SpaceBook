## 3.1 اِن پُٹ اور آؤٹ پُٹ فنکشنز || 3.1 Input and output functions || ۳.۱ د input او output فنکشنونه
p C پروگرام تین اہم کام انجام دیتا ہے یعنی وہ ڈیٹا اِن پُٹ کے طور پر حاصل کرتا ہے، ڈیٹا پر کارروائی کرتا ہے اور آؤٹ پُٹ تیار کرتا ہے۔ اِن پُٹ سے مراد ڈیٹا کو وصول کرنا ہے جبکہ آؤٹ پُٹ سے مراد ڈیٹا کا اظہار ہے۔ عام طور پر اِن پُٹ کی بورڈ سے وصول کیا جاتا ہے اور آؤٹ پُٹ اسکرین پر ظاہر ہوتا ہے۔ ہر پروگرامنگ لینگویج میں اِن پُٹ / آؤٹ پُٹ آپریشن سب سے اہم کام ہوتا ہے۔ C لینگویج بہت سے اِن پُٹ / آؤٹ پُٹ فنکشن پیش کرتی ہے۔ ڈیٹا حاصل کرنے اور پھر اسے ویری ایبل کو تفویض کرنے کے لئے استعمال ہونے والے فنکشن کو اِن پُٹ فنکشن کہتے ہیں۔ وہ فنکشن جو کمپیوٹر میموری سے ڈیٹا وصول کرنے اور پھر اسے آؤٹ پُٹ ڈیوائسز کو بھیجنے کے لئے استعمال ہوتے ہیں انہیں آؤٹ پُٹ فنکشن کہا جاتا ہے۔ || A C program does three main things: it takes data as input, processes the data and produces output. Input means receiving data, while output means showing data. Usually input is received from the keyboard and output appears on the screen. In every programming language the input/output operation is the most important task. The C language offers many input/output functions. Functions used to obtain data and then assign it to a variable are called input functions. Functions used to take data from the computer's memory and then send it to output devices are called output functions. || C پروګرام درې مهم کارونه کوي: ډېټا د input په توګه اخلي، پر ډېټا عملیات کوي او output جوړوي. input یعنې د ډېټا ترلاسه کول او output یعنې د ډېټا ښودل. عموماً input له کیبورډ څخه ترلاسه کېږي او output په سکرین ښکاري. په هره پروګرامي ژبه کې د input/output عملیات تر ټولو مهم کار دی. C ژبه ډېر input/output فنکشنونه لري. هغه فنکشنونه چې ډېټا ترلاسه او بیا یې متغیر ته ورکوي input فنکشنونه بلل کېږي. هغه فنکشنونه چې د کمپیوټر له حافظې ډېټا اخلي او output وسیلو ته یې لېږي output فنکشنونه بلل کېږي.
### 3.1.1 آؤٹ پُٹ فنکشن (Output Functions) || 3.1.1 Output functions || ۳.۱.۱ د output فنکشنونه
p C لینگویج درج ذیل آؤٹ پُٹ فنکشن کا استعمال کرتی ہے، جیسے: || The C language uses the following output functions: || C ژبه لاندې output فنکشنونه کاروي:
- printf() || printf() || printf()
- puts() || puts() || puts()
p جبکہ C++ لینگویج آؤٹ پُٹ کے لئے درج ذیل کو استعمال کرتی ہے۔ || whereas the C++ language uses the following for output: || په داسې حال کې چې C++ ژبه د output لپاره لاندې کاروي:
- cout || cout || cout
### (a) printf() فنکشن || (a) The printf() function || (a) printf() فنکشن
p C میں سب سے عام آؤٹ پُٹ فنکشن میں سے ایک printf() فنکشن ہے۔ printf() اسکرین پر آؤٹ پُٹ ظاہر کرنے کے لئے استعمال ہوتا ہے۔ || One of the most common output functions in C is printf(). printf() is used to show output on the screen. || په C کې یو له تر ټولو عامو output فنکشنونو printf() دی. printf() په سکرین د output ښودلو لپاره کارېږي.
p یہ پیغامات، ویری ایبل کی قیمت اور ریاضی کی عبارتوں (Arithmetic Expressions) کے جوابات کو پرنٹ کرنے کے لئے استعمال ہوتا ہے۔ printf میں "f" فارمیٹڈ کی مختصر شکل ہے اور اشارہ کرتا ہے کہ اسکرین پر چھپی ہوئی عبارت کو فارمیٹ کیا جائے گا۔ فنکشن printf کو print-eff کے نام سے ظاہر کیا جاتا ہے۔ اس کی وضاحت سٹینڈرڈ ہیڈر فائل stdio.h میں کی گئی ہے۔ لہٰذا printf() کو استعمال کرنے کے لیے ہمیں اپنے پروگرام میں ہیڈر فائل stdio.h شامل کرنا چاہئے۔ || It is used to print messages, the values of variables and the results of arithmetic expressions. The "f" in printf is short for "formatted" and indicates that the text printed on the screen will be formatted. The function printf is pronounced "print-eff". It is declared in the standard header file stdio.h, so to use printf() we must include the header file stdio.h in our program. || دا د پیغامونو، د متغیرونو د ارزښت او د ریاضي عبارتونو (Arithmetic Expressions) د ځوابونو د چاپولو لپاره کارېږي. په printf کې "f" د formatted لنډیز دی او ښيي چې په سکرین چاپ شوی متن به فارمېټ شي. printf د print-eff په نوم لوستل کېږي. په معیاري هېډر فایل stdio.h کې اعلان شوی، نو د printf() د کارولو لپاره باید stdio.h هېډر فایل په پروګرام کې شامل کړو.
p printf کا سائنٹکس || The syntax of printf || د printf ترکیب
m printf("String");
p یا || or || یا
m printf("format string", var1, var2, var3, ..., varN);
p format string یہ بتاتا ہے کہ کتنے آرگومنٹس استعمال کئے گئے ہیں اور ان کی اقسام کیا ہیں۔ آرگومنٹ var1، var2، …، varN وہ ویری ایبل ہیں جن کی format string میں دیئے گئے سپیسیفائر (specifier) کے مطابق تشکیل اور پرنٹ کی جاتی ہے۔ قیمت ڈیٹا ٹائپ کے مطابق استعمال کیا جاتا ہے۔ آرگومنٹس کی تعداد، ترتیب اور ٹائپ کا format specifier سے مماثل ہونا ضروری ہوتا ہے۔ || The format string tells how many arguments are used and what their types are. The arguments var1, var2, …, varN are the variables that are formatted and printed according to the specifiers given in the format string; each value is used according to its data type. The number, order and type of the arguments must match the format specifiers. || format string ښيي چې څو دلیلونه (arguments) کارول شوي او ډولونه یې څه دي. var1، var2، …، varN هغه متغیرونه دي چې د format string د مشخص کوونکو (specifiers) سره سم فارمېټ او چاپېږي؛ ارزښت د ډېټا ډول سره سم کارېږي. د دلیلونو شمېر، ترتیب او ډول باید له format specifier سره سمون ولري.
