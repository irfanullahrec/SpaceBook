### 2.1.4 چند مقبول ہائی لیول پروگرامنگ لینگویجز (Some Popular High Level Programming Languages) || 2.1.4 Some popular high-level programming languages || ۲.۱.۴ ځینې مشهورې لوړې کچې پروګرامي ژبې
### C لینگویج (C Language) || The C language || C ژبه
@deco A photograph of Dennis Ritchie, captioned "ڈینس رچی، بانی C لینگویج" (Dennis Ritchie, founder of the C language), stands beside this text; photographs are not reproduced.
p C ایک عمومی مقاصد کے لیے استعمال ہونے والی کمپیوٹر پروگرامنگ لینگویج ہے جو 1972ء میں امریکہ کے اے ٹی اینڈ ٹی بیل لیبارٹریز میں ڈینس رچی (Denis Richie) نے تیار کی۔ || C is a general-purpose computer programming language developed in 1972 by Dennis Ritchie at AT&T Bell Laboratories in the USA. || C د عمومي موخو لپاره کارېدونکې کمپیوټري پروګرامي ژبه ده چې په ۱۹۷۲ کال کې د امریکا په AT&T بېل لابراتوارونو کې ډېنس ریچي (Dennis Ritchie) جوړه کړه.
@issue The name is printed "Denis Richie"; the correct spelling is Dennis Ritchie.
p C ایک سادہ اور سٹرکچر اورینٹڈ پروسیجرل پروگرامنگ لینگویج ہے۔ یہ مختلف پلیٹ فارم پر آسانی سے منتقل ہو سکتی ہے۔ اور اسی وجہ سے صنعت اور پیشہ ورانہ پروگرامنگ میں وسیع پیمانے پر استعمال ہوتی ہے۔ یونکس UNIX آپریٹنگ سسٹم C میں تیار کیا گیا ہے۔ || C is a simple, structure-oriented procedural programming language. It can easily be moved to different platforms, and for this reason it is widely used in industry and professional programming. The UNIX operating system was developed in C. || C یوه ساده او جوړښت محوره پروسیجرل پروګرامي ژبه ده. په بېلابېلو پلېټفارمونو په اسانۍ لېږدول کېدای شي، او له همدې امله په صنعت او مسلکي پروګرام جوړونه کې پراخه کارول کېږي. د UNIX عملیاتي سیسټم په C کې جوړ شوی دی.
### C++ لینگویج (C++ Language) || The C++ language || C++ ژبه
p C++ 1980ء کی دہائی کے شروع میں بجرنے سٹراسٹرپ (Bjarne Stroustrup) نے تیار کی تھی۔ یہ ایک آبجیکٹ اورینٹڈ پروگرامنگ (OOP) لینگویج ہے۔ یہ C لینگویج کی ہی توسیع ہے۔ C++ میں C لینگویج کے تمام عناصر شامل ہیں اور ساتھ ہی ساتھ آبجیکٹ، کلاسز، ایونٹ اور دیگر آبجیکٹ اورینٹڈ کے تمام تصورات کے ساتھ کام کرنے کی اضافی خصوصیات ہیں۔ زیادہ تر ایپلی کیشن پروگرام، جیسے ورڈ پروسیسرز اور اسپریڈ شیٹ C++ میں ہی تیار کی گئی ہیں۔ || C++ was developed in the early 1980s by Bjarne Stroustrup. It is an object-oriented programming (OOP) language and an extension of the C language. C++ includes all the elements of the C language and also has additional features for working with objects, classes, events and all the other object-oriented concepts. Most application programs, such as word processors and spreadsheets, have been developed in C++. || C++ د ۱۹۸۰ لسیزې په پیل کې بیارنې سټراوسټروپ (Bjarne Stroustrup) جوړه کړه. دا یوه شي محوره پروګرامي (OOP) ژبه ده او د C ژبې پراختیا ده. C++ د C ژبې ټول توکي لري او ورسره د شیانو، ټولګیو (classes)، پېښو (events) او نورو ټولو شي محوره مفاهیمو سره د کار اضافي ځانګړنې لري. ډېری اپلیکېشن پروګرامونه لکه ورډ پروسیسرونه او سپرېډشیټونه په C++ کې جوړ شوي دي.
@issue "C++" is printed throughout as "++ C" / "C ++" (spaced and reversed by the right-to-left layout); normalised to C++.
### وژول پروگرامنگ لینگویجز (Visual Programming Languages) || Visual programming languages || لیدنیزې پروګرامي ژبې
p وژول پروگرامنگ کی اصطلاح ونڈوز پر مبنی ایپلی کیشنز یا گرافیکل یوزر انٹرفیس (GUI) ایپلی کیشنز بنانے یا تیار کرنے کے لیے استعمال ہوتی ہے۔ وژول پروگرامنگ لینگویجز، جن کو بعض اوقات پانچویں نسل کی پروگرامنگ لینگویج بھی کہا جاتا ہے، آبجیکٹ اورینٹڈ پروگرامنگ لینگویجز ہیں۔ اس پروگرامنگ لینگویج میں وژول یا گرافیکل یوزر انٹرفیس (GUI) کی سہولیات ہونے کی وجہ سے یہ GUI والی ایپلی کیشنز تیار کرنے کے لیے نہایت مفید ہے۔ || The term visual programming is used for making or developing Windows-based applications or graphical user interface (GUI) applications. Visual programming languages, which are sometimes also called fifth generation programming languages, are object-oriented programming languages. Because they have visual or graphical user interface (GUI) facilities, they are very useful for developing applications with a GUI. || لیدنیزه پروګرام جوړونه هغه اصطلاح ده چې د وینډوز پر بنسټ یا ګرافیکي کارن انټرفېس (GUI) اپلیکېشنونو د جوړولو لپاره کارېږي. لیدنیزې پروګرامي ژبې، چې کله کله ورته د پنځم نسل پروګرامي ژبې هم وايي، شي محوره پروګرامي ژبې دي. په دې ژبو کې د لیدنیز یا ګرافیکي کارن انټرفېس (GUI) اسانتیاوې شته، نو د GUI لرونکو اپلیکېشنونو د جوړولو لپاره ډېرې ګټورې دي.
p بہت مقبول اور وسیع پیمانے پر استعمال ہونے والی وژول پروگرامنگ لینگویجز کی مثال وژول بیسک (VB)، وژول C++، C# اور Java ہیں۔ || Examples of very popular and widely used visual programming languages are Visual Basic (VB), Visual C++, C# and Java. || د ډېرو مشهورو او پراخه کارېدونکو لیدنیزو پروګرامي ژبو بېلګې Visual Basic (VB)، Visual C++، C# او Java دي.
