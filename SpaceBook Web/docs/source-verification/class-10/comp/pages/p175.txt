### 7.5.2 ویب پیج میں تصویر کا سائز مقرر کرنا || 7.5.2 Setting the size of a picture on a web page || ۷.۵.۲ په ویب پاڼه کې د انځور اندازه ټاکل
p یوزر پیج میں موجود تصویر میں تبدیلی لانے کے لئے <img> ٹیگ میں height، width اور alt کا استعمال کر سکتا ہے۔ || To change a picture on the page, the user can use height, width and alt in the <img> tag. || کاروونکی په پاڼه کې د انځور د بدلولو لپاره په <img> ټیګ کې height، width او alt کارولای شي.
@issue The Urdu misspells "height" as "hight".
- height: تصویر کی اونچائی کو پکسلز میں واضح کرنے کے لئے <img> ٹیگ میں لکھا جاتا ہے۔ یہ تصویر کی اصل اونچائی سے مختلف ہو سکتا ہے۔ براؤزر <img> ٹیگ کے مطابق تصویر کی height کا سائز تبدیل کرتا ہے۔ || height: written in the <img> tag to give the picture's height in pixels. It can differ from the picture's real height; the browser resizes the picture's height according to the <img> tag. || height: د انځور لوړوالی په پکسلونو ښودلو لپاره په <img> ټیګ کې لیکل کېږي. دا کېدای شي د انځور له اصلي لوړوالي توپیر ولري؛ براوزر د <img> ټیګ سره سم د انځور لوړوالی بدلوي.
- width: تصویر کی چوڑائی کو پکسلز میں واضح کرنے کے لئے <img> ٹیگ میں لکھا جاتا ہے۔ یہ تصویر کی اصل چوڑائی سے مختلف ہو سکتا ہے۔ براؤزر <img> ٹیگ کے مطابق تصویر کی چوڑائی کا سائز تبدیل کرتا ہے۔ || width: written in the <img> tag to give the picture's width in pixels. It can differ from the picture's real width; the browser resizes the picture's width according to the <img> tag. || width: د انځور پلنوالی په پکسلونو ښودلو لپاره په <img> ټیګ کې لیکل کېږي. دا کېدای شي د انځور له اصلي پلنوالي توپیر ولري؛ براوزر د <img> ټیګ سره سم د انځور پلنوالی بدلوي.
- alt: alt ایک ٹیکسٹ ہوتا ہے جو کسی تصویر کی وضاحت کے لیے استعمال کیا جاتا ہے۔ alt براہِ راست <img> ٹیگ میں لکھا جاتا ہے۔ اگر کسی وجہ سے کسی تصویر کو ظاہر نہیں کیا جا سکتا تو، alt تصویر کے بجائے متبادل ٹیکسٹ دکھاتا ہے۔ یہ یوزر کے لیے اور خاص طور پر بینائی سے محروم یوزر کے لیے متبادل ٹیکسٹ مہیا کرنے کے لئے مفید ہے۔ || alt: a text used to describe a picture. alt is written directly in the <img> tag. If for some reason the picture cannot be shown, alt shows alternative text in place of the picture. It is useful for giving alternative text to users, especially visually impaired users. || alt: یو متن دی چې د انځور د تشریح لپاره کارېږي. alt مستقیم په <img> ټیګ کې لیکل کېږي. که په کوم دلیل انځور ونه ښودل شي، alt د انځور پر ځای بدیل متن ښيي. دا کاروونکو، په ځانګړې توګه له لید څخه بې برخې کاروونکو، ته د بدیل متن برابرولو لپاره ګټور دی.
