### 2.4.5 ٹائپ کاسٹنگ (Type Casting) || 2.4.5 Type casting || ۲.۴.۵ د ډول بدلون (Type Casting)
p پروگرام چلنے کے عمل کے دوران کسی ایک ڈیٹا ٹائپ کو کسی دوسری ڈیٹا ٹائپ میں تبدیل کرنے کے عمل کو ٹائپ کاسٹنگ کے نام سے جانا جاتا ہے۔ ٹائپ کاسٹنگ دو طریقوں سے کی جا سکتی ہے۔ || The process of converting one data type into another data type while a program is running is known as type casting. Type casting can be done in two ways. || د پروګرام د چلېدو پر مهال د یوه ډېټا ډول بل ډېټا ډول ته د بدلولو بهیر د ډول بدلون (type casting) په نوم یادېږي. د ډول بدلون په دوو لارو کېدای شي.
- مخفی ٹائپ کاسٹنگ || Implicit type casting || پټ ډول بدلون
- ظاہری ٹائپ کاسٹنگ || Explicit type casting || ښکاره ډول بدلون
### 1۔ مخفی ٹائپ کاسٹنگ (Implicit Type Casting) || 1. Implicit type casting || ۱. پټ ډول بدلون (Implicit Type Casting)
p C کمپائلر اس قسم کی ٹائپ کاسٹنگ خود کر لیتا ہے۔ ریاضی کے عمل میں شامل آپریندز کو ایک ہی قسم کا ہونا چاہئے۔ اگر پر آپریندز (operands) کی ڈیٹا ٹائپ مختلف ہیں تو، چھوٹی ڈیٹا ٹائپ والی ویلیو کو بڑی ڈیٹا ٹائپ میں تبدیل کیا جاتا ہے۔ || The C compiler does this kind of type casting by itself. The operands in an arithmetic operation should be of the same type; if the data types of the operands are different, the value with the smaller data type is converted into the larger data type. || C کمپایلر دا ډول بدلون پخپله کوي. په ریاضي عملیه کې شامل عملوندونه (operands) باید یو ډول وي؛ که د عملوندونو ډېټا ډولونه بېل وي، د کوچني ډېټا ډول ارزښت لوی ډېټا ډول ته بدلېږي.
@issue "اگر پر آپریندز" contains a stray "پر"; read as "اگر آپریندز".

p مثال: فرض کریں x کوئی انٹیجر ہے اور y ایک long ویری ایبل ہے اور اگر درج ذیل کو ہم حل کرنا چاہیں: || Example: suppose x is an integer and y is a long variable, and we want to evaluate the following: || بېلګه: فرض کړئ x یو بشپړ عدد او y یو long متغیر دی، او غواړو لاندې حل کړو:
m x+y
p اگرچہ x کی ڈیٹا ٹائپ y کی ڈیٹا ٹائپ سے چھوٹی ہے اس لیے جمع کے عمل کے دوران x کی قیمت کو بھی long ڈیٹا ٹائپ میں تبدیل کر دیا جائے گا۔ || Since the data type of x is smaller than the data type of y, the value of x will also be converted into the long data type during the addition. || څرنګه چې د x ډېټا ډول د y له ډېټا ډول کوچنی دی، د جمع پر مهال به د x ارزښت هم long ډېټا ډول ته بدل شي.
@issue The Urdu "اگرچہ" (although) should be "چونکہ" (since); the sentence gives a reason, not a concession.
