### main() فنکشن کی باڈی (Body of main() Function) || Body of the main() function || د main() فنکشن بدنه
p پروگرام کی اسٹیٹمنٹس main() فنکشن کے اندر لکھی جاتی ہیں، main فنکشن کی باڈی { } بریکٹ پر مشتمل ہوتی ہے۔ یہ اسٹیٹمنٹس پروگرام کی باڈی کہلاتی ہیں۔ جب فنکشن چلایا جاتا ہے تو اِس میں موجود اسٹیٹمنٹس اپنا کام انجام دیتی ہیں۔ || The statements of a program are written inside the main() function; the body of the main function consists of the braces { }. These statements are called the body of the program. When the function is run, the statements in it carry out their work. || د پروګرام بیانونه د main() فنکشن دننه لیکل کېږي؛ د main فنکشن بدنه د { } قوسونو څخه جوړه ده. دې بیانونو ته د پروګرام بدنه ویل کېږي. کله چې فنکشن وچلول شي، په هغه کې بیانونه خپل کار ترسره کوي.
### C اسٹیٹمنٹس (C Statements) || C statements || د C بیانونه
p C اسٹیٹمنٹ ایک ایسی عبارت ہے جو حقیقت میں کچھ کر کے دکھاتی ہے۔ اصل میں کمپیوٹر کو کوئی کام کرنے کی ہدایت ہے۔ || A C statement is an expression that actually does something; in fact it is an instruction to the computer to do some task. || د C بیان داسې عبارت دی چې په حقیقت کې یو کار ترسره کوي؛ په اصل کې کمپیوټر ته د یوه کار د کولو لارښوونه ده.
p مثال کے طور پر printf("Hello World"); ایک C اسٹیٹمنٹ ہے جو اسکرین پر Hello World لکھا ہوا دکھاتی ہے۔ C کے اسٹیٹمنٹ عام طور پر چھوٹے حروف میں لکھے جاتے ہیں۔ C میں ہر اسٹیٹمنٹ سیمی کالن (Semicolon) کے ساتھ ختم ہوتی ہے۔ || For example, printf("Hello World"); is a C statement that shows Hello World written on the screen. C statements are usually written in small letters. In C every statement ends with a semicolon. || د بېلګې په توګه printf("Hello World"); د C یو بیان دی چې په سکرین Hello World لیکلی ښيي. د C بیانونه عموماً په وړو تورو لیکل کېږي. په C کې هر بیان په سیمي کولن (Semicolon) پای ته رسېږي.
@issue The scan shows the example as ;("Hello World") with the function name printf missing; the intended statement is printf("Hello World");.

### 2.3.4 C میں تبصرے یا کمنٹس کا استعمال (Comments in C) || 2.3.4 Using comments in C || ۲.۳.۴ په C کې د تبصرو کارول
p ایک کمنٹ پروگرام کے سورس کوڈ کی وضاحت ہے۔ یہ ڈویلپر کو کوڈ کی لاجک کی وضاحت کرنے میں مدد کرتا ہے اور پروگرام کو بہتر بناتا ہے۔ اس کا استعمال کمپیوٹر پروگرام / اسٹیٹمنٹ کے مقصد اور عمل کی ایک مختصر وضاحت فراہم کرنے کے لئے کیا جاتا ہے۔ جو پروگرام کو صارفین کے لئے زیادہ قابلِ فہم بناتا ہے۔ کمنٹس عمل درآمد نہ کرنے والی لائنیں ہیں اور ترجمے کے دوران کمپائلر ان کو نظر انداز کرتا ہے۔ یہ نوٹ کرنا ضروری ہے کہ کمنٹس لائن صرف پروگرام کے کوڈ میں ظاہر ہوتی ہیں اور پروگرام کے آؤٹ پُٹ پر ان کا کوئی اثر نہیں ہوتا ہے۔ C پروگرام میں کہیں بھی کمنٹس ظاہر ہو سکتے ہیں اور پروگرامر کمنٹ لائن میں کچھ بھی لکھنے کے لئے آزاد ہے۔ || A comment is an explanation of the program's source code. It helps the developer explain the logic of the code and improves the program. It is used to give a short explanation of the purpose and working of a computer program or statement, which makes the program more understandable for users. Comments are non-executable lines, and the compiler ignores them during translation. It is important to note that comment lines appear only in the program's code and have no effect on the program's output. Comments can appear anywhere in a C program, and the programmer is free to write anything in a comment line. || تبصره (comment) د پروګرام د سرچینه کوډ وضاحت دی. له پراختیا کوونکي سره د کوډ د منطق په روښانه کولو کې مرسته کوي او پروګرام ښه کوي. د کمپیوټري پروګرام/بیان د موخې او کار د لنډ وضاحت لپاره کارېږي چې پروګرام کاروونکو ته د پوهېدو وړ کوي. تبصرې نه اجرا کېدونکې کرښې دي او کمپایلر یې د ژباړې پر مهال له پامه غورځوي. باید پام وشي چې د تبصرې کرښې یوازې د پروګرام په کوډ کې ښکاري او د پروګرام په output هېڅ اغېز نه لري. په C پروګرام کې تبصرې هر ځای راتلای شي او پروګرامر آزاد دی چې د تبصرې په کرښه کې هر څه ولیکي.
p C میں کمنٹس لکھنے کے دو طریقے ہیں۔ || There are two ways of writing comments in C. || په C کې د تبصرو د لیکلو دوه طریقې دي.
p 1۔ سنگل لائن کمنٹ: سنگل لائن پر کمنٹ // (دو سلیش) استعمال کر کے شامل کیے جاتے ہیں۔ // (دو سلیش) کے دائیں طرف لکھی ہوئی عبارت کمنٹس کے طور پر سمجھی جاتی ہے۔ یہ انداز کسی پروگرام کی ایک اسٹیٹمنٹ پر کمنٹ لکھنے کے لئے مفید ہے۔ مثال کے طور پر: || 1. Single-line comment: comments on a single line are added using // (two slashes). The text written to the right of // is treated as a comment. This style is useful for writing a comment on one statement of a program. For example: || ۱. یوه کرښه تبصره: په یوه کرښه تبصره د // (دوه سلیش) په کارولو اضافه کېږي. د // ښي خوا ته لیکل شوی متن تبصره ګڼل کېږي. دا طریقه د پروګرام په یوه بیان د تبصرې لیکلو لپاره ګټوره ده. د بېلګې په توګه:
m //this is a comment line
m // Sorting process
m //Function 1 starts here
p 2۔ ملٹی لائن کمنٹس: کمنٹ کے آغاز میں ملٹی لائن کمنٹ کو /* سے کوڈ میں شامل کیا جاتا ہے۔ کثیر لائن تبصرے ختم کرنے کے لئے */ کا استعمال کیا جاتا ہے۔ جب کوئی کمنٹ کئی لائنوں پر مشتمل ہو تو یہ انداز سب سے زیادہ کارآمد ہے۔ مثال کے طور پر: || 2. Multi-line comments: a multi-line comment is added to the code with /* at the start of the comment, and */ is used to end a multi-line comment. This style is most useful when a comment spans several lines. For example: || ۲. څو کرښې تبصرې: د تبصرې په پیل کې څو کرښې تبصره د /* سره کوډ ته اضافه کېږي او د پای لپاره یې */ کارېږي. کله چې تبصره څو کرښې ولري دا طریقه تر ټولو ګټوره ده. د بېلګې په توګه:
m /*
m Program-Name:      Examination Record
m Programmer-Name:   M. Khalid
m Date:              6th May
m Purpose:           Program to show Examination Record
m */
p سلیش-ایسٹیریسک */ کمنٹ کمپائلر کو بتاتا ہے کہ اس کے بعد آنے والی ہر چیز کو نظر انداز کر دے جب تک کہ اس کو */ کا نشان دوبارہ نہیں مل جاتا۔ || The slash-asterisk /* comment tells the compiler to ignore everything that follows it until it again finds the */ mark. || سلیش-ستوری /* تبصره کمپایلر ته وايي چې له هغې وروسته هر څه له پامه وغورځوي تر هغه چې بیا د */ نښه ومومي.
@issue In the Urdu text the comment markers are printed mirror-ordered by the right-to-left layout ("*/" at the start, "/*" at the end, and the last sentence "*/ … /*"); the correct C markers are /* to open and */ to close, used here in all three slots.
