### 7.6.4 ویب پیج کے اندر ہائپر لنک بنانا || 7.6.4 Making a hyperlink within a web page || ۷.۶.۴ د ویب پاڼې دننه هایپرلینک جوړول
### <a> میں name کا استعمال || Using name in <a> || په <a> کې د name کارونه
p اینکر کو اپنے ہی ایٹریبیوٹ name کے ساتھ استعمال کر کے ویب پیج کے اندر ہی ہائپر لنک بنایا جا سکتا ہے۔ یہ دو مرحلوں میں ہو گا۔ پہلے اینکر بنائیں اور پھر اینکر کو ہائپر لنک بنائیں۔ || By using the anchor with its own attribute name, a hyperlink can be made within the same web page. This is done in two steps: first make the anchor, then make a hyperlink to the anchor. || د اینکر د خپلې name ځانګړتیا په کارولو د همدې ویب پاڼې دننه هایپرلینک جوړېدای شي. دا په دوو پړاوونو کېږي: لومړی اینکر جوړ کړئ، بیا اینکر ته هایپرلینک جوړ کړئ.
@issue The name attribute on <a> is obsolete in HTML5; an id on any element (e.g. <h2 id="top">) is used as the link target instead.
