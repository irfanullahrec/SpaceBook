### لو لیول لینگویجز (Low Level Languages) || Low-level languages || ټیټې کچې ژبې
p کمپیوٹر ہائی لیول لینگویجز یا انگریزی میں دی جانے والی ہدایات کو براہِ راست نہیں سمجھ سکتا۔ یہ صرف مشین لینگویج جیسے بائنری لینگویج، میں دی گئی ہدایات کو سمجھ اور چلا سکتا ہے۔ یہ لینگویجز کمپیوٹر ہارڈ ویئر کے بہت قریب ہیں اس لیے کمپیوٹر اِن لینگویجز کو با آسانی سمجھ سکتا ہے۔ ان لینگویج میں پروگرامنگ کرنے کے لیے کمپیوٹر کے ہارڈ ویئر کی ساخت سے متعلق بہت گہرا مطالعہ ہونا ضروری ہے۔ || A computer cannot directly understand instructions given in high-level languages or English. It can understand and execute only instructions given in machine language, i.e. binary language. These languages are very close to the computer hardware, so the computer understands them easily. Programming in these languages requires a very deep knowledge of the structure of the computer's hardware. || کمپیوټر د لوړې کچې ژبو یا انګرېزي لارښوونې مستقیم نه پوهېږي. یوازې د ماشین ژبې یعنې باینري ژبې لارښوونې پوهېږي او چلوي یې. دا ژبې د کمپیوټر هارډویر ته ډېرې نږدې دي، نو کمپیوټر یې په اسانۍ پوهېږي. په دې ژبو کې د پروګرام جوړونې لپاره د کمپیوټر د هارډویر د جوړښت ژوره پوهه اړینه ده.
p لو لیول لینگویجز کی دو اقسام ہیں۔ || There are two kinds of low-level languages. || ټیټې کچې ژبې دوه ډوله دي.
### 1۔ مشین لینگویج (Machine Language) || 1. Machine language || ۱. د ماشین ژبه
p زبان کی وہ قسم جس میں ہم ہدایات کو بائنری شکل میں لکھتے ہیں مشینی زبان کہلاتی ہے۔ یہ کمپیوٹر کی وہ واحد زبان ہے جسے کمپیوٹر براہِ راست سمجھ جاتا ہے۔ یہ کمپیوٹر کی بنیادی یا اساسی زبان ہے۔ اس زبان میں لکھے گئے پروگرام کمپیوٹر پر بہت تیزی کے ساتھ چلتے ہیں۔ کمپیوٹر کے اندر مشین لینگویج کو بائنری اعداد (bits) یعنی 0 اور 1 کے تسلسل سے ظاہر کیا جاتا ہے۔ 0 کی علامت چارج کی غیر موجودگی اور 1 چارج کی موجودگی کو ظاہر کرتا ہے۔ انسان کے لیے مشینی زبان سمجھنا زیادہ مشکل ہے۔ اس زبان میں پروگرام لکھنا یا لکھے ہوئے پروگرام میں ترمیم کرنا بہت دیر طلب کام ہے۔ مشینی زبان کو پہلی نسل کی زبان (First Generation Language) بھی کہا جاتا ہے۔ || The kind of language in which we write instructions in binary form is called machine language. It is the only language the computer understands directly; it is the computer's basic or fundamental language. Programs written in it run very fast. Inside the computer, machine language is represented by a sequence of binary digits (bits), i.e. 0 and 1; 0 represents the absence of charge and 1 its presence. Machine language is very hard for humans to understand, and writing a program in it or modifying a written program is very time-consuming. Machine language is also called the first generation language. || هغه ډول ژبه چې پکې لارښوونې په باینري بڼه لیکو د ماشین ژبه بلل کېږي. دا د کمپیوټر یوازینۍ ژبه ده چې کمپیوټر یې مستقیم پوهېږي؛ دا د کمپیوټر بنسټیزه ژبه ده. په دې ژبه لیکل شوي پروګرامونه ډېر چټک چلېږي. په کمپیوټر کې د ماشین ژبه د باینري عددونو (bits) یعنې 0 او 1 په لړۍ ښودل کېږي؛ 0 د چارج نشتوالی او 1 د چارج شتون ښيي. د انسان لپاره د ماشین ژبه پوهېدل ډېر ستونزمن دي او په دې ژبه پروګرام لیکل یا سمول ډېر وخت نیسي. د ماشین ژبې ته د لومړي نسل ژبه (First Generation Language) هم ویل کېږي.
