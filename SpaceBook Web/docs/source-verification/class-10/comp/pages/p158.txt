## 7.2 HTML کا تعارف || 7.2 Introduction to HTML || ۷.۲ د HTML پېژندنه
p HTML کا مطلب ہائپر ٹیکسٹ مارک اپ لینگویج ہے، جو ویب پیجز تیار کرنے کے لئے ویب پر سب سے زیادہ استعمال ہونے والی لینگویج ہے۔ HTML کو برنرز لی نے 1991 میں بنایا تھا۔ HTML ڈاکومنٹ کو پڑھنے اور اسے اسکرین پر ویب پیجز کی حیثیت سے ظاہر کرنے کے لئے، انٹرنیٹ ایکسپلورر یا گوگل کروم جیسے براؤزر کا استعمال ہوتا ہے۔ || HTML stands for Hypertext Markup Language, the language most used on the web to create web pages. HTML was created by Berners-Lee in 1991. A browser such as Internet Explorer or Google Chrome is used to read an HTML document and show it on the screen as a web page. || HTML د Hypertext Markup Language لنډیز دی، چې په ویب کې د ویب پاڼو د جوړولو لپاره تر ټولو ډېره کارېدونکې ژبه ده. HTML په ۱۹۹۱ کې د برنرز لي له لوري جوړه شوه. د HTML سند د لوستلو او په سکرین د ویب پاڼې په توګه د ښودلو لپاره د Internet Explorer یا Google Chrome په څېر براوزر کارېږي.
@sec 7-2-1 | 7.2.1 ہائپر ٹیکسٹ مارک اپ لینگویج || 7.2.1 Hypertext Markup Language || ۷.۲.۱ هایپرټیکسټ مارک اپ ژبه
### 7.2.1 ہائپر ٹیکسٹ مارک اپ لینگویج || 7.2.1 Hypertext Markup Language || ۷.۲.۱ هایپرټیکسټ مارک اپ ژبه
p HTML ایک مارک اپ لینگویج ہے کیونکہ اس میں وہ ٹیگ استعمال ہوتے ہیں جو ویب براؤزر کو بتاتے ہیں کہ ویب پیج کو کیسے ظاہر کرنا ہے۔ ہر پیج میں دوسرے پیج سے رابطہ کی ایک سیریز ہوتی ہے جسے ہائپر لنکس (Hyperlinks) کہتے ہیں۔ انٹرنیٹ پر آپ کو نظر آنے والا ہر ویب پیج HTML کے کسی بھی ورژن کے استعمال سے لکھا جاتا ہے۔ اس کو ہائپر ٹیکسٹ دستاویزات بنانے کے لئے استعمال کیا جاتا ہے جو ٹیکسٹ، تصاویر، آوازیں، ویڈیو کلپس اور سبھی کو ایک جگہ پر لے آتا ہے۔ HTML فائلیں سادہ ٹیکسٹ فائلیں ہیں، لہٰذا انھیں سادہ ایڈیٹر جیسے Notepad یا Wordpad یا Notepad++ اور Visual Studio Code کا استعمال کرتے ہوئے تخلیق کیا جا سکتا ہے۔ || HTML is a markup language because it uses tags that tell the web browser how to display a web page. Each page has a series of connections to other pages, called hyperlinks. Every web page you see on the internet is written using some version of HTML. It is used to make hypertext documents that bring text, pictures, sounds and video clips all together in one place. HTML files are plain text files, so they can be created with a simple editor such as Notepad, WordPad, Notepad++ or Visual Studio Code. || HTML یوه مارک اپ ژبه ده ځکه داسې ټیګونه کاروي چې ویب براوزر ته ښيي ویب پاڼه څنګه وښيي. هره پاڼه له نورو پاڼو سره د اړیکو لړۍ لري چې هایپرلینکونه (Hyperlinks) بلل کېږي. هره ویب پاڼه چې په انټرنېټ کې یې ګورئ د HTML د یوې نسخې په کارولو لیکل شوې. دا د هایپرټیکسټ اسنادو د جوړولو لپاره کارېږي چې متن، انځورونه، غږونه او ویډیو کلیپونه ټول یو ځای راټولوي. HTML فایلونه ساده متني فایلونه دي، نو د Notepad، WordPad، Notepad++ یا Visual Studio Code په څېر ساده اډیټرونو جوړېدای شي.

### 7.2.2 HTML ڈاکومنٹ بنانا اور براؤزر میں دکھانا || 7.2.2 Creating an HTML document and showing it in a browser || ۷.۲.۲ د HTML سند جوړول او په براوزر کې ښودل
p اس یونٹ میں Notepad++ کو HTML ڈاکومنٹ بنانے کے لئے استعمال کیا گیا ہے۔ اس ایڈیٹر کو https://notepad-plus-plus.org/downloads/ لنک کا استعمال کرتے ہوئے انٹرنیٹ سے ڈاؤن لوڈ کیا جا سکتا ہے۔ || In this unit Notepad++ is used to create HTML documents. This editor can be downloaded from the internet using the link https://notepad-plus-plus.org/downloads/. || په دې څپرکي کې د HTML سند د جوړولو لپاره Notepad++ کارول شوی. دا اډیټر د https://notepad-plus-plus.org/downloads/ لینک په کارولو له انټرنېټ ښکته کېدای شي.
