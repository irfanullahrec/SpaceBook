### OR گیٹ || The OR gate || OR دروازه
p OR گیٹ ایک لاجک گیٹ ہے جو لاجیکل جمع کے لیے استعمال ہوتا ہے۔ لاجیکل OR آپریشن کی آؤٹ پُٹ صرف اُس صورت میں High (1) ہو گی جب اس کی کوئی ایک اِن پُٹ High ہو (یعنی اگر ایک ہی اِن پُٹ High ہو تو آؤٹ پُٹ High ہو گی) اور اگر کوئی ایک اِن پُٹ بھی High نہیں ہے تو، آؤٹ پُٹ Low (0) کے نتائج برآمد ہوں گے۔ || The OR gate is a logic gate used for logical addition. The output of the logical OR operation is High (1) when any one of its inputs is High (that is, if even one input is High the output is High); if not even one input is High, the output is Low (0). || OR دروازه منطقي دروازه ده چې د منطقي جمع لپاره کارېږي. د منطقي OR عمل output هغه وخت High (1) وي چې یو input یې High وي (یعنې که یوازې یو input هم High وي output به High وي)؛ او که هېڅ input High نه وي، output به Low (0) وي.
@issue "صرف اُس صورت میں … جب اس کی کوئی ایک اِن پُٹ High ہو" could be read as "only when exactly one input is High"; in fact OR is also High when both inputs are High.
p اگر A اور B دو اِن پُٹ ہیں، تو آؤٹ پُٹ Y کو ریاضی کے مطابق ہم ایسے ظاہر کر سکتے ہیں Y = A + B یہاں پلس سائن (+) OR عمل کی نشاندہی کرتا ہے۔ OR گیٹ کی نمائندگی مندرجہ ذیل علامت سے ہوتی ہے۔ || If A and B are two inputs, the output Y can be written mathematically as Y = A + B; here the plus sign (+) represents the OR operation. The OR gate is represented by the following symbol. || که A او B دوه inputs وي، output Y په ریاضي ډول داسې لیکلای شو: Y = A + B؛ دلته د جمع نښه (+) د OR عمل ښيي. OR دروازه په لاندې نښه ښودل کېږي.

### NOT گیٹ || The NOT gate || NOT دروازه
p NOT گیٹ کا استعمال کسی بھی اِن پُٹ ویلیو کو معکوس (Reverse) کرنے کے لئے استعمال کیا جاتا ہے۔ یہ ایک ایسا گیٹ ہے جس کی آؤٹ پُٹ اِن پُٹ کے اُلٹ ہوتی ہے۔ NOT گیٹ ایک اِن پُٹ لیتا ہے اور ایک ہی آؤٹ پُٹ دیتا ہے۔ اگر NOT گیٹ میں اِن پُٹ '0' ہے تو آؤٹ پُٹ '1' ہو گا۔ اگر اِن پُٹ '1' ہے تو آؤٹ پُٹ '0' ہو گا۔ || The NOT gate is used to reverse any input value. It is a gate whose output is the opposite of its input. The NOT gate takes one input and gives one output. If the input of a NOT gate is '0' the output is '1'; if the input is '1' the output is '0'. || NOT دروازه د هر input ارزښت د سرچپه کولو (Reverse) لپاره کارېږي. دا داسې دروازه ده چې output یې د input برعکس وي. NOT دروازه یو input اخلي او یو output ورکوي. که د NOT دروازې input '0' وي، output به '1' وي؛ که input '1' وي، output به '0' وي.
p NOT گیٹ چونکہ اِن پُٹ کو معکوس کر دیتا ہے اس لیے اسے انورٹر (Inverter) بھی کہا جاتا ہے۔ || Because the NOT gate reverses its input, it is also called an inverter. || NOT دروازه input سرچپه کوي، نو ورته انورټر (Inverter) هم وايي.

### 6.2.3 ٹرُتھ ٹیبل (Truth Table) || 6.2.3 Truth table || ۶.۲.۳ د حقیقت جدول (Truth Table)
p یہ ایک ٹیبل ہے جس میں اِن پُٹ ویلیوز اور ان کے مطابق آؤٹ پُٹ ویلیوز کے تمام ممکنہ امتزاج کو اکھٹا لکھا ہوتا ہے۔ اگر اِن پُٹ ویری ایبلز کی تعداد n ہو تو اِن پُٹ کے کل 2ⁿ ممکنہ امتزاج ہوں گے۔ ٹرُتھ ٹیبل کا استعمال بولین فنکشن یا ایکسپریشن یا لاجک گیٹس کے تمام ممکنہ امتزاج کی نمائندگی کرنے کے لئے کیا جاتا ہے۔ بولین فنکشن / ایکسپریشن بولین ویری ایبل، کانسٹنٹ اور بولین آپریٹرز کا مجموعہ ہے۔ || A truth table is a table in which all the possible combinations of input values, and the output values for each, are written together. If the number of input variables is n, there are 2ⁿ possible input combinations in all. A truth table is used to represent all the possible combinations of a Boolean function or expression, or of logic gates. A Boolean function/expression is a combination of Boolean variables, constants and Boolean operators. || دا یو جدول دی چې پکې د input ارزښتونو او اړوندو output ارزښتونو ټول ممکن ترکیبونه یوځای لیکل شوي وي. که د input متغیرونو شمېر n وي، د input ټول 2ⁿ ممکن ترکیبونه به وي. د حقیقت جدول د بولین فنکشن یا عبارت یا منطقي دروازو د ټولو ممکنو ترکیبونو د ښودلو لپاره کارېږي. بولین فنکشن/عبارت د بولین متغیرونو، ثابتونو او بولین عملګرونو ټولګه ده.
@issue The scan prints "کل 2 ممکنہ امتزاج" with the superscript n lost; the number of combinations is 2ⁿ.
