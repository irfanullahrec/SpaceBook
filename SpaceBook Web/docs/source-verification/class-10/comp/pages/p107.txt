### 5.1.2 for لوپ || 5.1.2 The for loop || ۵.۱.۲ for لوپ
p for لوپ کی مدد سے ایک یا ایک سے زیادہ اسٹیٹمنٹس کو جتنی دفعہ (Times) چاہیں چلا سکتے ہیں۔ اس لوپ کو پروگرامر بہت زیادہ استعمال کرتے ہیں۔ اس لوپ کا سائنٹکس اور استعمال بہت آسان ہے۔ اس کا سائنٹکس درج ذیل ہے: || With the for loop we can run one or more statements as many times as we wish. Programmers use this loop a great deal; its syntax and use are very easy. Its syntax is: || د for لوپ په مرسته یو یا څو بیانونه هر څومره ځله چې وغواړو چلولای شو. پروګرامران دا لوپ ډېر کاروي؛ ترکیب او کارونه یې ډېره اسانه ده. ترکیب یې دا دی:
m for(initialization;condition;increment/decrement)
m {
m         Body of the loop
m }
p Initialization: اس سے مراد وہ عبارت (Expression) ہے جس سے کاؤنٹر ویری ایبل کی ابتدائی قیمت رکھی جاتی ہے۔ اس کا مطلب ہے کہ یہ حصہ لوپ میں صرف ایک بار چلتا ہے۔ || Initialization: the expression that sets the initial value of the counter variable. This part runs only once in the loop. || Initialization: هغه عبارت (Expression) چې د شمېرونکي متغیر لومړنی ارزښت ټاکي. دا برخه په لوپ کې یوازې یو ځل چلېږي.
p condition: یہ کوئی بھی ریلیشنل ایکسپریشن ہو سکتا ہے۔ لوپ کے اندر تمام اسٹیٹمنٹس اس وقت چلائی جائیں گی جب تک اس condition کا نتیجہ True رہے، جیسے ہی اس condition کا نتیجہ False ہوا تو اسٹیٹمنٹ پھر نہیں چلائی جائیں گی اور کنٹرول لوپ کے بعد پروگرام میں اگلی اسٹیٹمنٹ پر منتقل ہو جائے گا جیسا کہ شکل نمبر 5.1 میں دکھایا گیا ہے۔ || condition: any relational expression. All the statements inside the loop are run as long as this condition is true; as soon as it becomes false the statements are no longer run and control passes to the next statement in the program after the loop, as shown in Figure 5.1. || condition: هر نسبتي عبارت کېدای شي. د لوپ دننه ټول بیانونه تر هغه چلېږي چې شرط True وي؛ کله چې False شي، بیانونه نور نه چلېږي او کنټرول له لوپ وروسته د پروګرام راتلونکي بیان ته ځي، لکه څنګه چې په ۵.۱ شکل کې ښودل شوي.
p Increment/Decrement: لوپ کا یہ حصہ لوپ کے ہر تکرار (Iteration) کے بعد کاؤنٹر ویری ایبل کی قیمت میں تبدیلی کرتا ہے۔ || Increment/Decrement: this part of the loop changes the value of the counter variable after every iteration of the loop. || Increment/Decrement: د لوپ دا برخه د لوپ له هر تکرار (Iteration) وروسته د شمېرونکي متغیر ارزښت بدلوي.
p Body of loop: یہ ایک اسٹیٹمنٹ یا اسٹیٹمنٹس کا ایک گروپ ہے جسے بار بار چلایا جاتا ہے یہ قوسین { } کے اندر بند ہوتا ہے۔ || Body of loop: one statement or a group of statements that is run repeatedly; it is enclosed in braces { }. || Body of loop: یو بیان یا د بیانونو ډله چې بیا بیا چلېږي؛ په { } قوسونو کې تړل کېږي.

p تکرار کی تعداد لوپ کے اجزاء، Initialization، Condition اور Increment/Decrement پر منحصر ہے۔ Initialization والا حصہ ایک دفعہ ہی چلتا ہے جب کنٹرول لوپ میں داخل ہوتا ہے۔ Initialization کے بعد Condition کو چیک کیا جاتا ہے۔ اگر اس کا نتیجہ True ہو تو، کنٹرول لوپ کی باڈی میں داخل ہو کر تمام اسٹیٹمنٹس پر عمل درآمد کرتا ہے۔ پھر Increment/Decrement حصہ پر عمل درآمد کیا جاتا ہے جو کاؤنٹر ویری ایبل کی قیمت کو تبدیل کرتا ہے۔ کنٹرول ایک بار پھر Condition والے حصے پر چلا جائے گا۔ یہ عمل بدستور اس وقت تک جاری رہے گا جب تک condition کا نتیجہ True رہتا ہے جیسے ہی یہ False ہو گا لوپ کو منقطع (Terminate) کر دیا جائے گا۔ || The number of repetitions depends on the parts of the loop: initialization, condition and increment/decrement. The initialization part runs only once, when control enters the loop. After initialization the condition is checked; if it is true, control enters the body of the loop and executes all its statements. Then the increment/decrement part is executed, which changes the value of the counter variable, and control goes back to the condition. This continues as long as the condition remains true; as soon as it becomes false the loop is terminated. || د تکرار شمېر د لوپ په برخو — Initialization، Condition او Increment/Decrement — پورې اړه لري. Initialization برخه یوازې یو ځل چلېږي، کله چې کنټرول لوپ ته ننوځي. له هغې وروسته شرط ازمویل کېږي؛ که True وي، کنټرول د لوپ بدنې ته ننوځي او ټول بیانونه اجرا کوي. بیا Increment/Decrement برخه اجرا کېږي چې د شمېرونکي متغیر ارزښت بدلوي، او کنټرول بیرته شرط ته ځي. دا کار تر هغه دوام کوي چې شرط True وي؛ کله چې False شي لوپ پای ته رسېږي (Terminate).
