m do
m {
m Body of the loop

p do: یہ وہ کلیدی لفظ ہے جو لوپ کے آغاز کی طرف اشارہ کرتا ہے۔ || do: the keyword that marks the start of the loop. || do: هغه کلیدي کلمه چې د لوپ پیل ښيي.
p Condition: یہ ریلیشنل ایکسپریشن ہے۔ اگر شرط کا نتیجہ درست ہو تو باڈی کے اندر اسٹیٹمنٹس پر عمل درآمد کیا جاتا رہے گا۔ اگر شرط کا نتیجہ False ہو جائے، تو باڈی کے اندر اسٹیٹمنٹس صرف ایک بار چلیں گی کیونکہ اس میں شرط آخر میں چیک کی جاتی ہے۔ لوپ کو سیمی کالن کے ساتھ ختم ہونا ضروری ہے۔ || Condition: a relational expression. If the condition is true, the statements in the body keep being executed. If the condition is false, the statements in the body run only once, because in this loop the condition is checked at the end. The loop must end with a semicolon. || Condition: نسبتي عبارت دی. که شرط سم وي، د بدنې بیانونه اجرا کېږي. که شرط False وي، د بدنې بیانونه یوازې یو ځل چلېږي ځکه په دې لوپ کې شرط په پای کې ازمویل کېږي. لوپ باید په سیمي کولن پای ته ورسېږي.
p Body of the loop: یہ قوسین { } کے درمیان اسٹیٹمنٹ یا اسٹیٹمنٹ کا ایک گروپ ہے جس کو بار بار چلانا ہے۔ || Body of the loop: the statement or group of statements between braces { } that is to be run repeatedly. || Body of the loop: د { } قوسونو ترمنځ بیان یا د بیانونو ډله چې باید بیا بیا وچلېږي.
