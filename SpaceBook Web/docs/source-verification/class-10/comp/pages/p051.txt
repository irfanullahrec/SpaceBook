## 2.4 متغیرات اور مستقلات (Variables and Constants) || 2.4 Variables and constants || ۲.۴ متغیرونه او ثابتونه
### 2.4.1 متغیر (Variable) || 2.4.1 Variable || ۲.۴.۱ متغیر
p ایک ایسی مقدار جس کی قیمت پروگرام کے عمل کے دوران تبدیل ہو جائے اسے متغیر یا ویری ایبل (Variable) کہا جاتا ہے۔ ایک ویری ایبل کمپیوٹر میموری میں اسٹوریج یا میموری والے مقام کو ظاہر کرتا ہے۔ اسی وجہ سے ویری ایبل میں ذخیرہ شدہ ڈیٹا بھی عارضی ہوتا ہے۔ یہ صرف پروگرام چلنے کے دوران استعمال ہوتا ہے اور اس پر کارروائی کی جا سکتی ہے۔ ویری ایبل میں ذخیرہ شدہ ڈیٹا پروگرام ختم ہونے پر خود بخود ختم ہو جاتا ہے۔ || A quantity whose value can change while the program is running is called a variable. A variable represents a storage or memory location in the computer's memory. For this reason the data stored in a variable is also temporary: it is used, and can be operated on, only while the program is running. The data stored in a variable is automatically lost when the program ends. || هغه مقدار چې ارزښت یې د پروګرام د چلېدو پر مهال بدلېدای شي متغیر (Variable) بلل کېږي. متغیر د کمپیوټر په حافظه کې د ساتنې یا حافظې ځای ښيي. له همدې امله په متغیر کې ساتل شوې ډېټا هم لنډمهاله وي؛ یوازې د پروګرام د چلېدو پر مهال کارېږي او پرې عملیات کېدای شي. د پروګرام په پای ته رسېدو په متغیر کې ساتل شوې ډېټا پخپله له منځه ځي.

### ویری ایبل کی اقسام || Kinds of variables || د متغیرونو ډولونه
p ویری ایبل دو قسم کے ہوتے ہیں، عددی اور حرفی (Numeric & Character)۔ || Variables are of two kinds: numeric and character. || متغیرونه دوه ډوله دي: عددي او حرفي (Numeric & Character).
p عددی (Numeric) ویری ایبل کا استعمال کمپیوٹر پروگراموں میں عددی اقدار کو ظاہر کرنے کے لئے کیا جاتا ہے۔ وہ انٹیجر اور فلوٹنگ پوائنٹ ویلیو کی نمائندگی کرتے ہیں۔ عددی ویری ایبل کی کچھ مثالوں میں marks، sum، n، width وغیرہ ہیں۔ || Numeric variables are used in computer programs to represent numeric values; they represent integer and floating-point values. Some examples of numeric variables are marks, sum, n, width and so on. || عددي (Numeric) متغیرونه په کمپیوټري پروګرامونو کې د عددي ارزښتونو د ښودلو لپاره کارېږي؛ هغوی بشپړ (integer) او اعشاري (floating-point) ارزښتونه ښيي. د عددي متغیرونو ځینې بېلګې marks، sum، n، width او نور دي.
