### gets() فنکشن || The gets() function || gets() فنکشن
p gets() فنکشن اس قابل ہے کہ یہ کریکٹر سٹرنگ کے درمیان خالی جگہ (White Spaces) کو بھی بطور سٹرنگ لیتا ہے۔ gets فنکشن اسٹرنگ کی ایک لائن یا حرفوں کی ترتیب کو پڑھتا ہے جب تک کہ یوزر Enter key نہ دبائے۔ اس کی عمومی شکل درج ذیل ہے۔ || The gets() function is able to take the blank spaces (white spaces) inside a character string as part of the string. gets reads a line of string, or a sequence of characters, until the user presses the Enter key. Its general form is: || gets() فنکشن کولای شي د تورو د سټرنګ په منځ کې تشې (White Spaces) هم د سټرنګ برخه واخلي. gets د سټرنګ یوه کرښه یا د تورو لړۍ لولي تر هغه چې کاروونکی Enter key کېښکاږي. عمومي بڼه یې دا ده:

p gets() فنکشن خالی جگہ (White space) کے حروف کے ساتھ ایک سٹرنگ لیتا ہے۔ اس صورت میں، پروگرام چلاتے وقت کی بورڈ سے اسٹرنگ اِن پُٹ کی جائے گی اور جب یوزر Enter بٹن دبائے گا تب اِن پُٹ مکمل ہو گی۔ scanf() اور gets() کے فنکشنز میں یہ فرق ہے کہ scanf() تمام حروف کو اس وقت تک پڑھتا ہے جب تک کہ space نہیں آ جاتا یعنی ٹیب یا نئی لائن کا سامنا نہ کرنا پڑے، جب کہ gets() خالی جگہوں اور ٹیب سمیت سب کچھ پڑھے گا جب تک کہ یوزر Enter key نہیں دباتا۔ || The gets() function takes a string together with white-space characters. Here the string is input from the keyboard while the program runs, and the input is complete when the user presses the Enter key. The difference between scanf() and gets() is that scanf() reads characters only until it meets a space, i.e. a tab or new line, whereas gets() reads everything, including spaces and tabs, until the user presses the Enter key. || gets() فنکشن د تشو (White space) تورو سره سټرنګ اخلي. په دې حالت کې د پروګرام د چلېدو پر مهال سټرنګ له کیبورډ داخلېږي او کله چې کاروونکی Enter کېښکاږي input بشپړېږي. د scanf() او gets() توپیر دا دی چې scanf() توري تر هغه لولي چې تشه، ټب یا نوې کرښه ورته مخې ته نه وي راغلې، خو gets() تشې او ټبونه ټول لولي تر هغه چې کاروونکی Enter key کېښکاږي.
@issue gets() has no limit on input length and can overflow the array (here 20 characters); it was removed from the C11 standard. fgets(name, 20, stdin) is the safe replacement.
