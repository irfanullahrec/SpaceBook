### C# لینگویج (C# Language) || The C# language || C# ژبه
p C# یا سی شارپ (C-Sharp) ایک آبجیکٹ اورینٹڈ پروگرامنگ لینگویج ہے۔ اسے مائیکروسافٹ کارپوریشن نے سن 2000ء میں تیار کیا۔ یہ Visual Basic اور Java کے عناصر اور اجزاء کے ساتھ C++ پر مبنی ہے۔ اس کا استعمال ایسی ویب ایپلی کیشنز میں کیا جاتا ہے جسے انٹرنیٹ پر استعمال کیا جا سکے۔ C# میں کمپیوٹر گیم، یوٹیلیٹی پروگرام، آپریٹنگ سسٹم، کمپائلر، کاروباری ایپلی کیشنز اور ویب ایپلی کیشنز سمیت تمام قسم کے پروگرام تیار کیے جا سکتے ہیں۔ || C#, or C-Sharp, is an object-oriented programming language. It was developed by Microsoft Corporation in the year 2000. It is based on C++ with elements and components of Visual Basic and Java. It is used in web applications that can be used on the Internet. All kinds of programs, including computer games, utility programs, operating systems, compilers, business applications and web applications, can be developed in C#. || C# یا سي شارپ (C-Sharp) یوه شي محوره پروګرامي ژبه ده. مایکروسافټ کارپوریشن په ۲۰۰۰ کال کې جوړه کړه. دا د Visual Basic او Java د توکو او برخو سره پر C++ ولاړه ده. په هغو وېب اپلیکېشنونو کې کارېږي چې په انټرنېټ کارېدای شي. په C# کې کمپیوټري لوبې، ګټور پروګرامونه، عملیاتي سیسټمونه، کمپایلرونه، سوداګریز اپلیکېشنونه او وېب اپلیکېشنونه، ټول ډوله پروګرامونه جوړېدای شي.
### جاوا لینگویج (JAVA Language) || The Java language || Java ژبه
p Java ایک ہائی لیول آبجیکٹ اورینٹڈ پروگرامنگ لینگویج ہے جو سن مائیکروسسٹمز (Sun Microsystems) نے 1991ء میں تیار کی۔ یہ بھی C++ کی طرح ہی ہے لیکن یہ خاص طور پر ویب پیج ڈیزائننگ کے لئے استعمال کی جاتی ہے۔ جاوا ایپلیٹس (Applets) کو جاوا لینگویج میں ہی تیار کیا جاتا ہے۔ جاوا ایپلیٹ ایک چھوٹا جاوا پروگرام ہے جو کسی اور پروگرام جیسے ویب براؤزر میں چلایا جاتا ہے۔ جاوا ایپلیٹ کو ویب پیجز کے اندر سمو دیا جاتا ہے تاکہ انٹرنیٹ پر کسی تصویر یا امیج اینیمیشن کو متحرک دکھایا جا سکے اور کسی ڈیٹا بیس تک رسائی حاصل کی جا سکے۔ || Java is a high-level object-oriented programming language developed by Sun Microsystems in 1991. It is like C++, but it is used especially for web page design. Java applets are developed in the Java language. A Java applet is a small Java program that runs inside another program such as a web browser. Java applets are embedded in web pages so that a picture or image animation can be shown moving on the Internet and a database can be accessed. || Java یوه لوړې کچې شي محوره پروګرامي ژبه ده چې سن مایکروسیسټمز (Sun Microsystems) په ۱۹۹۱ کال کې جوړه کړه. دا هم د C++ په څېر ده خو په ځانګړي ډول د وېب پاڼو د ډیزاین لپاره کارېږي. جاوا اپلېټونه (Applets) په Java ژبه جوړېږي. جاوا اپلېټ یو کوچنی Java پروګرام دی چې په بل پروګرام لکه وېب براوزر کې چلېږي. جاوا اپلېټونه په وېب پاڼو کې ځای کېږي چې په انټرنېټ کوم انځور یا انیمېشن خوځنده وښودل شي او یو ډېټابېس ته لاسرسی وشي.
