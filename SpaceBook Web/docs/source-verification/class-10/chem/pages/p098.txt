qp 4 | Using structural formulae, give balanced equations for the following reactions. (a) Ethene with chlorine. (b) Ethene with hydrogen. Name the catalyst used. Which industrial process uses a similar reaction? (c) Ethene with hydrogen bromide. (d) Ethene with KMnO₄. || ساختی فارمولوں کی مدد سے درج ذیل تعاملات کی متوازن مساواتیں لکھیں۔ (a) ایتھین کا کلورین سے۔ (b) ایتھین کا ہائیڈروجن سے۔ استعمال ہونے والے عمل انگیز کا نام لکھیں۔ کون سا صنعتی عمل ایسا ہی تعامل استعمال کرتا ہے؟ (c) ایتھین کا ہائیڈروجن برومائیڈ سے۔ (d) ایتھین کا KMnO₄ سے۔ || د جوړښتي فورمولونو په مرسته د لاندې تعاملونو متوازنې معادلې ولیکئ. (a) ایتین له کلورین سره. (b) ایتین له هایدروجن سره. کارېدلی کتلست ونوموئ. کومه صنعتي پروسه ورته تعامل کاروي؟ (c) ایتین له هایدروجن برومایډ سره. (d) ایتین له KMnO₄ سره.
sol Model answer ## (a) $CH_2=CH_2 + Cl_2 \rightarrow CH_2Cl-CH_2Cl$ (1,2-dichloroethane). (b) $CH_2=CH_2 + H_2 \xrightarrow{Ni,\,200^\circ C} CH_3-CH_3$; the catalyst is nickel; the industrial process using a similar reaction is the hydrogenation of vegetable oils to make ghee (margarine). (c) $CH_2=CH_2 + HBr \rightarrow CH_3-CH_2Br$. (d) $3CH_2=CH_2 + 2KMnO_4 + 4H_2O \rightarrow 3CH_2OH-CH_2OH + 2MnO_2 + 2KOH$.
