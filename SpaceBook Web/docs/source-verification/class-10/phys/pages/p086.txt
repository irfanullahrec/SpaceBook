# 12.8 THE LENS EQUATION
p To calculate the precise location and size of the image formed by a lens, we use an equation that is analogous to the mirror equation. The lens equation is a precise mathematical relationship between the object distance and the image distance for a given lens. This formula is accurate only if the thickness of the lens is small compared to its diameter.
p The following quantities are included in lens formula:
- f = the focal length of the lens
- hₒ = the height of the object
- hᵢ = the height of the image
- dₒ = the distance of the object from the lens
- dᵢ = the distance of the image from the lens
- M = the magnification of the image
p This equation can be derived by referring to Figure 12.25, which shows the image produced by a convex lens, along with the O and A - rays that locate the image.
