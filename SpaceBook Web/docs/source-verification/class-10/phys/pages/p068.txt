example 12.1 | IMAGE DISTANCE IN SPOON
p The concave side of a spoon has a focal length of 5.00 cm. Find the image distance for this 'mirror' when the object distance is (a) 12.0 cm, (b) 10.0 cm, (c) 7.50 cm, (d) 5.00 cm and (e) 2.00 cm.
### GIVEN
p Focal length 'f' = 5.00 cm. (a) Object Distance 'dₒ' = 12.0 cm, (b) Object Distance 'dₒ' = 10.0 cm (c) Object Distance 'dₒ' = 7.50 cm (d) Object Distance 'dₒ' = 5.00 cm (e) Object Distance 'dₒ' = 2.00 cm
### REQUIRED
p (a) to (e) Image Distance 'dᵢ' = ?
### SOLUTION
p by mirror equation 1/f = 1/dᵢ + 1/dₒ or 1/dᵢ = 1/f − 1/dₒ
p Taking LCM 1/dᵢ = (dₒ − f)/(f dₒ) or dᵢ = f dₒ / (dₒ − f)   ①
