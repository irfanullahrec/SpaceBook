p In another 1600 years, one-half of the remaining radium atoms will have disintegrated, leaving only one-fourth of the original number intact. Let N represent the amount of the original sample remaining after any given time interval 'Δt' and '$N_0$' represent the original amount in the sample; given in the same units as 'N'. Then || مزید 1600 سال میں باقی ریڈیم ایٹموں کا آدھا حصہ ٹوٹ چکا ہوگا اور اصل تعداد کا صرف ایک چوتھائی باقی رہ جائے گا۔ فرض کریں N کسی دیے گئے وقفۂ وقت 'Δt' کے بعد اصل نمونے کی باقی مقدار اور '$N_0$' نمونے کی اصل مقدار ہے، دونوں ایک ہی اکائی میں۔ تب || په نورو 1600 کلونو کې د پاتې راډیم اتومونو نیمایي به تجزیه شوې وي او د اصلي شمېر یوازې څلورمه برخه به روغه پاتې وي. فرض کړئ N د یوه ټاکلي وختي واټن 'Δt' وروسته د اصلي نمونې پاتې اندازه او '$N_0$' په نمونه کې اصلي اندازه ده؛ دواړه په یو واحد. نو
eq \text{After 1 half-life}\quad N = \frac{1}{2}N_0
eq \text{After 2 half-lives}\quad N = \frac{1}{2}\times\frac{1}{2}N_0 = \left(\frac{1}{2}\right)^2 N_0
eq \text{After 3 half-lives}\quad N = \frac{1}{2}\times\frac{1}{2}\times\frac{1}{2}N_0 = \left(\frac{1}{2}\right)^3 N_0
eq \text{Generally}\quad N = \frac{1}{2}\times\frac{1}{2}\times\frac{1}{2}\cdots N_0 = \left(\frac{1}{2}\right)^n N_0 \qquad (18.4)
