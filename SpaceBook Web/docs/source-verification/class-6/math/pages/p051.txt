## d) Additive Identity || (d) جمعی ذاتی عدد || (d) جمعي پېژند
p 0 is the called the **additive identity** because when we add 0 to any integer the result is the integer itself. || 0 کو **جمعی ذاتی عدد** کہتے ہیں کیونکہ جب ہم کسی بھی صحیح عدد میں 0 جمع کرتے ہیں تو نتیجہ وہی صحیح عدد ہوتا ہے۔ || 0 ته **جمعي پېژند** وايي ځکه کله چې له هر تام عدد سره 0 جمع کړو، پایله پخپله همغه تام عدد وي.
example 1 | If we add 0 and +7, we get +7. || اگر ہم 0 اور +7 جمع کریں تو ہمیں +7 ملتا ہے۔ || که 0 او +7 جمع کړو، +7 لاسته راځي.
m $0 + (+7) = 0 + 7 = +7$
endexample
example 2 | If we add 0 and -5, we get -5. || اگر ہم 0 اور -5 جمع کریں تو ہمیں -5 ملتا ہے۔ || که 0 او -5 جمع کړو، -5 لاسته راځي.
m $0 + (-5) = 0 - 5 = -5$
endexample
## e) Additive Inverse || (e) جمعی معکوس || (e) جمعي معکوس
p If the sum of two integers is zero (the additive identity), then both integers are called the **additive inverse** of each other. || اگر دو صحیح اعداد کا مجموعہ صفر (جمعی ذاتی عدد) ہو تو دونوں صحیح اعداد ایک دوسرے کے **جمعی معکوس** کہلاتے ہیں۔ || که د دوو تامو عددونو مجموعه صفر (جمعي پېژند) وي، نو دواړه تام عددونه یو د بل **جمعي معکوس** بلل کېږي.
example 1 | If we add 3 and –3, we get 0. || اگر ہم 3 اور –3 جمع کریں تو ہمیں 0 ملتا ہے۔ || که 3 او –3 جمع کړو، 0 لاسته راځي.
m $3 + (-3) = 3 - 3 = 0$
p here, 3 and -3 are the additive inverse of each other. || یہاں 3 اور -3 ایک دوسرے کے جمعی معکوس ہیں۔ || دلته 3 او -3 یو د بل جمعي معکوس دي.
endexample
example 2 | If we add -4 and +4, we get 0. || اگر ہم -4 اور +4 جمع کریں تو ہمیں 0 ملتا ہے۔ || که -4 او +4 جمع کړو، 0 لاسته راځي.
m $-4 + (+4) = -4 + 4 = 0$
p here, –4 and +4 are the additive inverse of each other. || یہاں –4 اور +4 ایک دوسرے کے جمعی معکوس ہیں۔ || دلته –4 او +4 یو د بل جمعي معکوس دي.
endexample
