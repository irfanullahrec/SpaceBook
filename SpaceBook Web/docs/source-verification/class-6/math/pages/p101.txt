## a) Finite set || (a) متناہی سیٹ || (a) محدود سېټ
p A set that consists of a **limited** number of elements is called a **finite set**. || وہ سیٹ جس کے ارکان کی تعداد **محدود** ہو **متناہی سیٹ** کہلاتا ہے۔ || هغه سېټ چې د غړو شمېر یې **محدود** وي **محدود سېټ** بلل کېږي.
example 1
q i) | The set of natural numbers up to 50. || 50 تک قدرتی اعداد کا سیٹ۔ || تر 50 پورې د طبیعي عددونو سېټ.
m A $= \{1, 2, 3, 4, \ldots, 50\}$
p In set A, the number of elements is limited and we can enlist all of them. So, it is a finite set. || سیٹ A میں ارکان کی تعداد محدود ہے اور ہم ان سب کی فہرست بنا سکتے ہیں۔ اس لیے یہ متناہی سیٹ ہے۔ || په A سېټ کې د غړو شمېر محدود دی او د ټولو لیست جوړولی شو. نو دا محدود سېټ دی.
q ii) | The set of English alphabets. || انگریزی حروفِ تہجی کا سیٹ۔ || د انګلیسي الفبا سېټ.
m B $= \{a, b, c, d, e, \ldots, z\}$
p Set B is also a finite set because its elements are limited and we can enlist them. || سیٹ B بھی متناہی سیٹ ہے کیونکہ اس کے ارکان محدود ہیں اور ہم ان کی فہرست بنا سکتے ہیں۔ || B سېټ هم محدود سېټ دی ځکه غړي یې محدود دي او لیست یې جوړولی شو.
endexample

So the set R is a finite set. || نوٹ کریں کہ K = کسی شہر کے لوگوں کے ناموں کا سیٹ، کے ارکان کو گننا اور ان کی فہرست بنانا بہت مشکل ہے۔ تاہم آخرکار ہم اس کے ارکان کی فہرست بنا سکتے ہیں۔ اس لیے سیٹ R متناہی سیٹ ہے۔ || پام وکړئ چې د K = په یوه ښار کې د خلکو د نومونو سېټ، غړي شمېرل او لیستول ډېر ستونزمن دي. خو بالاخره یې لیست جوړولی شو. نو R سېټ محدود سېټ دی.
## b) Infinite sets || (b) غیر متناہی سیٹ || (b) نامحدود سېټونه
p A set that consist of unlimited or an **uncountable number** of elements is called an infinite set. || وہ سیٹ جس کے ارکان لامحدود یا **ناقابلِ شمار** ہوں غیر متناہی سیٹ کہلاتا ہے۔ || هغه سېټ چې غړي یې نامحدود یا **نه شمېرل کېدونکي** وي نامحدود سېټ بلل کېږي.
example 2
q i) | N = Set of all natural numbers. || N = تمام قدرتی اعداد کا سیٹ۔ || N = د ټولو طبیعي عددونو سېټ.
m N $= \{1, 2, 3, 4, 5, \ldots\}$
p Set N is an infinite set because its elements are unlimited and it is not possible to enlist or count them. || سیٹ N غیر متناہی سیٹ ہے کیونکہ اس کے ارکان لامحدود ہیں اور ان کی فہرست بنانا یا انہیں گننا ممکن نہیں۔ || N سېټ نامحدود سېټ دی ځکه غړي یې نامحدود دي او لیستول یا شمېرل یې ممکن نه دي.
q ii) | M = Set of all multiples of 100. || M = 100 کے تمام اضعاف کا سیٹ۔ || M = د 100 د ټولو ضربونو سېټ.
m M $= \{100, 200, 300, 400, 500, \ldots\}$
p Set M is an infinite set because it has unlimited elements. || سیٹ M غیر متناہی سیٹ ہے کیونکہ اس کے ارکان لامحدود ہیں۔ || M سېټ نامحدود سېټ دی ځکه نامحدود غړي لري.
endexample
