## 11.4.3 Mode || 11.4.3 عادہ || 11.4.3 ډېرتکراری
p The **frequently occurring value** (or values) in the data denoted by $\hat{X}$ is called **mode**. || ڈیٹا میں **سب سے زیادہ آنے والی قیمت** (یا قیمتیں)، جسے $\hat{X}$ سے ظاہر کیا جاتا ہے، **عادہ** کہلاتی ہے۔ || په معلوماتو کې **تر ټولو ډېر راتلونکی ارزښت** (یا ارزښتونه)، چې په $\hat{X}$ ښودل کېږي، **ډېرتکراری** بلل کېږي.
p To find the mode; || عادہ معلوم کرنے کے لیے؛ || د ډېرتکراري د موندلو لپاره؛
qp i | Calculate frequencies for all values in the data. || ڈیٹا کی تمام قیمتوں کے تعدد معلوم کریں۔ || د معلوماتو د ټولو ارزښتونو تکرارونه معلوم کړئ.
qp ii | The mode is the value with the greatest frequency. || عادہ وہ قیمت ہے جس کا تعدد سب سے زیادہ ہو۔ || ډېرتکراری هغه ارزښت دی چې تر ټولو ډېر تکرار لري.
p If each value occurs the same number of times, then there is no mode. If two or more values occur the same number of times but more frequently than any of the other values, then there is more than one modes, which is the main difference between mode and mean and median because a data has only one mean and median. || اگر ہر قیمت ایک جتنی بار آئے تو کوئی عادہ نہیں ہوتا۔ اگر دو یا زیادہ قیمتیں ایک جتنی بار مگر باقی قیمتوں سے زیادہ آئیں تو ایک سے زیادہ عادے ہوتے ہیں، جو عادہ اور اوسط و وسطانیہ کا بنیادی فرق ہے کیونکہ ڈیٹا کا صرف ایک اوسط اور ایک وسطانیہ ہوتا ہے۔ || که هر ارزښت یو شان ځلونه راشي، ډېرتکراری نشته. که دوه یا ډېر ارزښتونه یو شان ځلونه خو تر نورو ډېر راشي، له یو ډېر ډېرتکراري شته، چې دا د ډېرتکراري او اوسط او منځني اصلي توپیر دی ځکه معلومات یوازې یو اوسط او یو منځنی لري.
