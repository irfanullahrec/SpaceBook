## e) Universal Set || (e) عالمگیر سیٹ || (e) عمومي سېټ
p A universal set is the set of all elements of the sets which are under consideration in a particular context. The universal set is denoted by the capital letter "U". In other words, we can say that all the sets which are under consideration are the subsets of the universal set. || عالمگیر سیٹ کسی خاص سیاق و سباق میں زیرِ غور سیٹوں کے تمام ارکان کا سیٹ ہے۔ عالمگیر سیٹ کو بڑے حرف "U" سے ظاہر کیا جاتا ہے۔ دوسرے الفاظ میں ہم کہہ سکتے ہیں کہ زیرِ غور تمام سیٹ عالمگیر سیٹ کے ذیلی سیٹ ہیں۔ || عمومي سېټ په یوه ځانګړي حالت کې د تر پام لاندې سېټونو د ټولو غړو سېټ دی. عمومي سېټ په لوي توري "U" ښودل کېږي. په بله وینا، ټول تر پام لاندې سېټونه د عمومي سېټ فرعي سېټونه دي.
p Let's consider the set of whole numbers, the set of composite numbers and the set of prime numbers. || آئیے مکمل اعداد کا سیٹ، مرکب اعداد کا سیٹ اور مفرد اعداد کا سیٹ لیں۔ || راځئ د بشپړو عددونو سېټ، د مرکبو عددونو سېټ او د لومړنیو عددونو سېټ په پام کې ونیسو.
p We can see that the set of whole numbers contains all the elements of the remaining two sets. So, in this case, the set of whole numbers is the universal set. || ہم دیکھ سکتے ہیں کہ مکمل اعداد کے سیٹ میں باقی دونوں سیٹوں کے تمام ارکان موجود ہیں۔ اس لیے اس صورت میں مکمل اعداد کا سیٹ عالمگیر سیٹ ہے۔ || ګورو چې د بشپړو عددونو سېټ د نورو دوو سېټونو ټول غړي لري. نو په دې حالت کې د بشپړو عددونو سېټ عمومي سېټ دی.

## 5.3.1 Venn Diagram || 5.3.1 وین شکل || 5.3.1 وین ډیاګرام
p A diagram that represents mathematical sets and their relationships is called a **Venn diagram**. In a Venn diagram, the sets are shown using circles or closed curves bounded in a rectangle. The rectangle represents the universal set. || ریاضیاتی سیٹوں اور ان کے تعلقات کو ظاہر کرنے والی شکل کو **وین شکل** کہتے ہیں۔ وین شکل میں سیٹوں کو ایک مستطیل میں بند دائروں یا بند منحنیوں سے دکھایا جاتا ہے۔ مستطیل عالمگیر سیٹ کو ظاہر کرتا ہے۔ || هغه ډیاګرام چې ریاضي سېټونه او د هغوی اړیکې ښيي **وین ډیاګرام** بلل کېږي. په وین ډیاګرام کې سېټونه په یوه مستطیل کې د تړلو دایرو یا تړلو منحنیو په مرسته ښودل کېږي. مستطیل عمومي سېټ ښيي.
p We can represent various set relationships with the help of Venn diagrams. || ہم وین اشکال کی مدد سے سیٹوں کے مختلف تعلقات ظاہر کر سکتے ہیں۔ || موږ کولی شو د وین ډیاګرامونو په مرسته د سېټونو بېلابېلې اړیکې وښیو.
