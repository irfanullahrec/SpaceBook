@sec 4.4 | Debugging a Program || پروگرام کی غلطیاں دور کرنا || د پروګرام غلطۍ لرې کول
# 4.4 Debugging a Program || 4.4 پروگرام کی غلطیاں دور کرنا (ڈیبگنگ) || 4.4 د پروګرام ډیبګ کول
p Debugging a program is the process of finding and removing bugs (errors) in a program. Scratch allows programs to run in single-stepping mode in which program runs slowly so that course-of-program-execution can be monitored. This way, a 'trace' list can be introduced for the variable by which the values can be monitored. Scratch also highlights every command that is executed, so that it becomes easier to track which command is affecting the value of the variable. || پروگرام کو ڈیبگ کرنا پروگرام میں بگز (غلطیاں) ڈھونڈنے اور دور کرنے کا عمل ہے۔ اسکریچ پروگراموں کو سنگل اسٹیپنگ موڈ میں چلنے دیتا ہے جس میں پروگرام آہستہ چلتا ہے تاکہ اس کے چلنے کے عمل کی نگرانی کی جا سکے۔ اس طرح ویری ایبل کے لیے ایک ’trace‘ فہرست بنائی جا سکتی ہے جس سے قدروں کی نگرانی ہو۔ اسکریچ ہر چلنے والے حکم کو نمایاں (ہائی لائٹ) بھی کرتا ہے تاکہ معلوم کرنا آسان ہو کہ کون سا حکم ویری ایبل کی قدر پر اثر ڈال رہا ہے۔ || ډیبګ کول د پروګرام د غلطیو (بګونو) موندل او لرې کول دي. سکرېچ پروګرام په ورو یو یو ګام چلوي چې د اجرا بهیر وڅارل شي؛ د متغیر لپاره 'trace' لېست جوړېدای شي. سکرېچ هر اجرا شوی امر روښانه کوي چې معلومه شي کوم امر پر متغیر اغېز کوي.
