## 4.2.1 Scratch interface: an overview || 4.2.1 اسکریچ انٹرفیس: ایک جائزہ || 4.2.1 د سکرېچ انټرفېس: یوه کتنه
p Scratch is a block programming language that provides a visual programming interface for children. It has been developed by MIT to develop computational thinking and problem solving skills among students. It is freely available in more than 70 languages. || اسکریچ ایک بلاک پروگرامنگ زبان ہے جو بچوں کے لیے بصری پروگرامنگ انٹرفیس فراہم کرتی ہے۔ اسے ایم آئی ٹی (MIT) نے طلبہ میں کمپیوٹیشنل سوچ اور مسئلہ حل کرنے کی مہارتیں پیدا کرنے کے لیے بنایا ہے۔ یہ 70 سے زیادہ زبانوں میں مفت دستیاب ہے۔ || سکرېچ بلاکي پروګرامي ژبه ده چې ماشومانو ته لیدونکی پروګرامي انټرفېس ورکوي. MIT جوړه کړې چې زده کوونکو کې کمپیوټري فکر او د ستونزې د حل مهارتونه وروزي. له 70 ډېرو ژبو کې وړیا ده.

p **Block Palette** consists of the building blocks, and is also known as Code Blocks, for Scratch. You can drag blocks to the programming or script area and click on it to see the effect of script. Within the palette the code blocks are divided into different categories. || **بلاک پیلیٹ** اسکریچ کے تعمیری بلاکوں پر مشتمل ہے جنھیں کوڈ بلاکس بھی کہتے ہیں۔ آپ بلاکوں کو پروگرامنگ یا اسکرپٹ ایریا میں گھسیٹ کر ان پر کلک کر کے اسکرپٹ کا اثر دیکھ سکتے ہیں۔ پیلیٹ میں کوڈ بلاکس مختلف زمروں میں تقسیم ہیں۔ || **بلاک پالټ** د سکرېچ جوړوونکي بلاکونه لري چې کوډ بلاکونه هم بلل کېږي. بلاکونه پروګرامي سیمې ته کش کړئ او کلیک یې کړئ چې اغېز یې وګورئ. په پالټ کې بلاکونه په کټګوریو وېشل شوي.
p **Block Category** consists of collections of scripts linked to particular purpose. There a number of categories of Code Blocks presented in different colored dots. By clicking on these categories, the relevant commands/Code Blocks in Block Palette are visible. The color of the script is same as that of the category in this way it is easier to understand what purpose a particular Code Block fulfills. || **بلاک کیٹیگری** خاص مقصد سے جڑے اسکرپٹس کے مجموعوں پر مشتمل ہے۔ کوڈ بلاکس کی کئی کیٹیگریاں مختلف رنگوں کے نقطوں سے دکھائی گئی ہیں۔ ان پر کلک کرنے سے بلاک پیلیٹ میں متعلقہ احکامات/کوڈ بلاکس نظر آتے ہیں۔ اسکرپٹ کا رنگ کیٹیگری کے رنگ جیسا ہوتا ہے، اس طرح سمجھنا آسان ہوتا ہے کہ کوئی کوڈ بلاک کس مقصد کے لیے ہے۔ || **د بلاک کټګوري** د ځانګړې موخې اړوند سکرېپټونه لري. کټګورۍ په رنګه ټکو ښودل شوې؛ پرې کلیک اړوند بلاکونه ښيي. د سکرېپټ رنګ د کټګورۍ رنګ دی، نو موخه یې اسانه پېژندل کېږي.
p **Programming Area** (Script Area) is the actual working space where you can drag and drop Code Blocks that are to be executed. || **پروگرامنگ ایریا** (اسکرپٹ ایریا) کام کی اصل جگہ ہے جہاں آپ چلائے جانے والے کوڈ بلاکس گھسیٹ کر رکھتے ہیں۔ || **پروګرامي سیمه** (سکرېپټ سیمه) د کار اصلي ځای دی چې د اجرا بلاکونه پکې کش او ږدئ.
