# 2.3 Managing files and folders || 2.3 فائلوں اور فولڈروں کا انتظام || 2.3 د فایلونو او فولډرونو اداره
## 2.3.1 File || 2.3.1 فائل || 2.3.1 فایل
p The main function of a computer is to manage data and information. The stored data and information on computer are called files. A file can be a text, a photo, a music track, a presentation or a video etc. || کمپیوٹر کا اہم کام ڈیٹا اور معلومات کا انتظام ہے۔ کمپیوٹر پر محفوظ ڈیٹا اور معلومات فائلیں کہلاتی ہیں۔ فائل متن، تصویر، موسیقی، پریزنٹیشن یا ویڈیو وغیرہ ہو سکتی ہے۔ || د کمپیوټر اصلي دنده د ډېټا او معلوماتو اداره ده. پر کمپیوټر خوندي ډېټا او معلومات فایلونه بلل کېږي. فایل متن، انځور، موسیقي، پریزنټېشن یا ویډیو کېدای شي.
p Each type of file has a specific icon, which helps to understand what kind of file it is. || ہر قسم کی فائل کا ایک خاص آئیکن ہوتا ہے جس سے پتا چلتا ہے کہ وہ کس قسم کی فائل ہے۔ || هر ډول فایل ځانګړی ایکن لري چې د فایل ډول ښيي.
svg File icons: Document File (W), Image File (picture), Text File (lines on a page), Presentation File (P). || فائل آئیکن: دستاویزی فائل، تصویری فائل، متنی فائل، پریزنٹیشن فائل۔ || د فایل ایکنونه: سند، انځور، متن، پریزنټېشن.

## 2.3.2 Folder || 2.3.2 فولڈر || 2.3.2 فولډر
p A folder (directory) is a way to organize files on the storage device. A folder can also contain other folders, called sub-folders. || فولڈر (ڈائریکٹری) اسٹوریج آلے پر فائلوں کو منظم کرنے کا طریقہ ہے۔ فولڈر میں دوسرے فولڈر بھی ہو سکتے ہیں جنھیں ذیلی فولڈر کہتے ہیں۔ || فولډر (ډایرکټري) پر زېرمه وسیله د فایلونو د تنظیم لاره ده. فولډر نور فولډرونه هم لري چې فرعي فولډرونه بلل کېږي.
@deco Two "Project" folder icons on a blue desktop background.
## 2.3.3 Shortcut || 2.3.3 شارٹ کٹ || 2.3.3 شارټکټ
p Shortcut is an icon that points to a program or data file for easy access. Shortcut can be placed on the desktop or stored in other folders. Double clicking a shortcut is the same as double clicking the original file. || شارٹ کٹ ایک آئیکن ہے جو آسان رسائی کے لیے کسی پروگرام یا ڈیٹا فائل کی طرف اشارہ کرتا ہے۔ شارٹ کٹ ڈیسک ٹاپ پر رکھا یا دوسرے فولڈروں میں محفوظ کیا جا سکتا ہے۔ شارٹ کٹ پر ڈبل کلک کرنا اصل فائل پر ڈبل کلک کرنے کے برابر ہے۔ || شارټکټ یو ایکن دی چې د اسانه لاسرسي لپاره پروګرام یا فایل ته اشاره کوي. پر ډېسکټاپ یا نورو فولډرونو کې ایښودل کېږي. پر شارټکټ دوه ځله کلیک د اصلي فایل پر دوه ځله کلیک سره یو شان دی.
@deco A "Project - Shortcut" icon with the small shortcut arrow.

p Shortcut is a link to original file/Program. || شارٹ کٹ اصل فائل/پروگرام کا ربط (لنک) ہے۔ || شارټکټ اصلي فایل/پروګرام ته لینک دی.
