# UNIT 4: PROGRAMMING || یونٹ 4: پروگرامنگ || یونټ 4: پروګرامینګ
## Learning Outcomes || سیکھنے کے نتائج || د زده کړې پایلې
### Knowledge || علم || پوهه
p Students will be able to: || طلبہ اس قابل ہوں گے کہ: || زده کوونکي به وکولای شي:
slo Determine the need for a programming language. || پروگرامنگ زبان کی ضرورت کا تعین کر سکیں۔ || د پروګرامي ژبې اړتیا وټاکي.
slo List ways in which programming is important in today's world. || آج کی دنیا میں پروگرامنگ کی اہمیت کے پہلو بیان کر سکیں۔ || په نننۍ نړۍ کې د پروګرامینګ اهمیت ولیکي.
slo Define 'Program'. || ’پروگرام‘ کی تعریف کر سکیں۔ || 'پروګرام' تعریف کړي.
slo List different applications of computer programming. || کمپیوٹر پروگرامنگ کے مختلف استعمالات بیان کر سکیں۔ || د پروګرامینګ بېلابېلې کارونې ولیکي.
slo Identify programming languages and their uses. || پروگرامنگ زبانیں اور ان کے استعمالات پہچان سکیں۔ || پروګرامي ژبې او کارونې یې وپېژني.
slo List the fundamental programming constructs that enable a computer to interpret a computer program. The constructs are: an event is an action from the user (or something outside the computer); a sequence is a series of actions that are completed in a specific order — computers follow all instructions in the sequence in which they are written; a loop repeats instructions until a specific stopping condition is met; a variable is used to store data/information called a value; a conditional statement asks a question to figure out which path to take next. || وہ بنیادی پروگرامنگ ساختیں بیان کر سکیں جن سے کمپیوٹر پروگرام سمجھتا ہے: ایونٹ — صارف (یا کمپیوٹر سے باہر کی کسی چیز) کا عمل؛ سیکوئنس — خاص ترتیب میں مکمل ہونے والے اعمال کا سلسلہ، کمپیوٹر ہدایات اسی ترتیب سے چلاتا ہے جس میں لکھی گئی ہوں؛ لوپ — رکنے کی شرط پوری ہونے تک ہدایات دہراتا ہے؛ ویری ایبل — ڈیٹا/معلومات (ویلیو) محفوظ کرتا ہے؛ مشروط بیان — سوال پوچھ کر طے کرتا ہے کہ آگے کون سا راستہ لینا ہے۔ || هغه بنسټیز جوړښتونه ولیکي چې کمپیوټر پرې پروګرام پوهېږي: پېښه — د کارن کړنه؛ ترتیب — په ټاکلي ترتیب کړنې؛ لوپ — تر ودرېدو شرط پورې تکرار؛ متغیر — ارزښت ساتي؛ شرطي بیان — پوښتنه کوي چې کومه لار ونیسي.
slo Analyze ways to debug a computer program. || کمپیوٹر پروگرام کی غلطیاں دور (ڈیبگ) کرنے کے طریقوں کا تجزیہ کر سکیں۔ || د پروګرام د غلطیو لرې کولو (ډیبګ) لارې وڅېړي.
### Skills || مہارتیں || مهارتونه
p Students will be able to: || طلبہ اس قابل ہوں گے کہ: || زده کوونکي به وکولای شي:
slo Differentiate between an algorithm and a program. || الگورتھم اور پروگرام میں فرق کر سکیں۔ || د الګوریتم او پروګرام توپیر وکړي.
slo Convert an algorithm into a program. || الگورتھم کو پروگرام میں بدل سکیں۔ || الګوریتم په پروګرام واړوي.
slo Recognize that a program executes in a sequence – write computer programs accordingly. || پہچان سکیں کہ پروگرام ترتیب سے چلتا ہے اور اسی کے مطابق پروگرام لکھ سکیں۔ || وپېژني چې پروګرام په ترتیب اجرا کېږي او همداسې یې ولیکي.
slo Write a program using the following constructs: Event – take input from the user e.g. when the user presses an arrow key on the keyboard, or when the user clicks the mouse button – a certain action is executed; Loop – repeats an instruction(s) a finite number of times or forever; Motion – that involves the motion of a sprite/object; Variable – creates and assigns values to a variable(s) (as per the event e.g. create an integer variable such as a score or a counter, and increase or decrease the value when certain events take place); Conditional statement (if-else block) – running a block of code only if a specific condition is true. || درج ذیل ساختوں سے پروگرام لکھ سکیں: ایونٹ — صارف سے ان پٹ (مثلاً تیر والی کی یا ماؤس کا بٹن دبانے پر کوئی عمل)؛ لوپ — ہدایت کو محدود تعداد میں یا ہمیشہ دہرانا؛ موشن — اسپرائٹ/شے کی حرکت؛ ویری ایبل — ویری ایبل بنا کر قدر دینا (مثلاً اسکور یا کاؤنٹر بنا کر واقعات پر بڑھانا گھٹانا)؛ مشروط بیان (if-else) — شرط درست ہونے پر ہی کوڈ چلانا۔ || په دې جوړښتونو پروګرام ولیکي: پېښه (د کیلي یا موږک کېکاږل)؛ لوپ (محدود یا تلپاتې تکرار)؛ خوځښت (د سپرایټ)؛ متغیر (لکه نمره یا شمېرونکی)؛ شرطي بیان (if-else).
slo Debug a computer program. || کمپیوٹر پروگرام کی غلطیاں دور کر سکیں۔ || د پروګرام غلطۍ لرې کړي.
