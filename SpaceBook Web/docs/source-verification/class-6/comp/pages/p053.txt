## Short response questions: || مختصر جوابی سوالات: || لنډ ځوابه پوښتنې:
q 1 | Define Operating System. List different examples of Operating System. || آپریٹنگ سسٹم کی تعریف کریں اور اس کی مختلف مثالیں لکھیں۔ || عامل سیسټم تعریف کړئ او بېلګې یې ولیکئ.
sol An operating system (OS) is system software that acts as an interface between the computer user and the components of the computer; it coordinates hardware and software, loads programs, manages storage and provides security. Examples: Microsoft Windows (10, 8, 7, Vista, XP), MS DOS, macOS, Chrome OS, BlackBerry, Android, Solaris, Linux, Ubuntu. ## || آپریٹنگ سسٹم صارف اور کمپیوٹر کے اجزا کے درمیان رابطہ ہے؛ مثالیں: ونڈوز، ڈاس، میک او ایس، کروم او ایس، اینڈرائیڈ، لینکس، اوبنٹو۔ || عامل سیسټم د کارن او کمپیوټر منځګړی دی؛ بېلګې: وینډوز، DOS، macOS، انډرایډ، لینکس، اوبونټو.
q 2 | What is utility program? Give two examples. || یوٹیلیٹی پروگرام کیا ہے؟ دو مثالیں دیں۔ || ګټور پروګرام څه دی؟ دوه بېلګې ورکړئ.
sol Utility programs (service programs) perform specific tasks related to managing computer functions, resources or files — e.g. antivirus software, disk/system cleanup, backup, file management, password protection. ## || یوٹیلیٹی پروگرام کمپیوٹر کے انتظام کے مخصوص کام کرتے ہیں، مثلاً اینٹی وائرس اور سسٹم کلین اپ۔ || ګټور پروګرامونه د کمپیوټر اداره کوي، لکه انټي ویروس او د سیسټم پاکول.
q 3 | Differentiate between a file and folder. || فائل اور فولڈر میں فرق کریں۔ || د فایل او فولډر توپیر وښیاست.
sol A file is stored data or information (a text, photo, music track, presentation or video), shown with an icon for its type. A folder (directory) is a container used to organise files on a storage device; it can hold files and other sub-folders. ## || فائل محفوظ ڈیٹا ہے؛ فولڈر فائلوں کو منظم کرنے والا خانہ ہے جس میں ذیلی فولڈر بھی ہو سکتے ہیں۔ || فایل خوندي ډېټا ده؛ فولډر د فایلونو د تنظیم ځای دی او فرعي فولډرونه هم لري.
