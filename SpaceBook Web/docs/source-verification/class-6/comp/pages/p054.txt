q 4 | Write down steps to create a shortcut of Microsoft Word application on desktop. || ڈیسک ٹاپ پر مائیکروسافٹ ورڈ ایپلیکیشن کا شارٹ کٹ بنانے کے مراحل لکھیں۔ || پر ډېسکټاپ د مایکروسافټ ورډ شارټکټ جوړولو ګامونه ولیکئ.
sol 1) Find Word in the Start menu and right-click it. 2) Click Open File Location. 3) In the file-location window, right-click the Word program icon. 4) Click Create Shortcut. 5) The Shortcut pop-up asks whether to place the shortcut on the desktop instead. 6) Click Yes. 7) The Word shortcut is added to the desktop. ## || اسٹارٹ مینو میں ورڈ پر رائٹ کلک ← Open File Location ← آئیکن پر رائٹ کلک ← Create Shortcut ← Yes ← شارٹ کٹ ڈیسک ٹاپ پر۔ || په سټارټ کې پر ورډ ښي کلیک ← Open File Location ← Create Shortcut ← Yes.
q 5 | Write down the steps to restore a deleted file. || حذف شدہ فائل واپس لانے کے مراحل لکھیں۔ || د ړنګ شوي فایل د بېرته راوستلو ګامونه ولیکئ.
sol 1) Double-click the Recycle Bin icon on the desktop to see deleted items. 2) Right-click the deleted file and select Restore; the file returns to its original location. ## || ری سائیکل بن کھولیں، فائل پر رائٹ کلک کر کے Restore چنیں۔ || ریسایکل بن پرانیزئ، پر فایل ښي کلیک او Restore.
q 6 | Define application software and list three types of application software. || ایپلیکیشن سافٹ ویئر کی تعریف کریں اور اس کی تین اقسام لکھیں۔ || کاریال سافټویر تعریف کړئ او درې ډولونه یې ولیکئ.
sol Application software is software developed to help the user perform a specific task. Types: (1) Entertainment software (games, videos, music); (2) Productivity software (word processors, presentations, spreadsheets, databases); (3) Education and reference software (encyclopedias, dictionaries, tutorials, simulations). ## || صارف کو خاص کام میں مدد دینے والا سافٹ ویئر؛ اقسام: تفریحی، پروڈکٹیویٹی، تعلیمی و حوالہ جاتی۔ || د ځانګړي کار سافټویر؛ ډولونه: ساتېري، تولیدي، تعلیمي او مرجع.
q 7 | Write down the steps to create a folder. || فولڈر بنانے کے مراحل لکھیں۔ || د فولډر جوړولو ګامونه ولیکئ.
sol 1) Go to the folder or desktop where you want it. 2) Right-click an empty area. 3) Select New. 4) Select Folder. 5) Type a name for the new folder and press Enter. ## || خالی جگہ پر رائٹ کلک ← New ← Folder ← نام لکھیں۔ || پر خالي ځای ښي کلیک ← New ← Folder ← نوم ولیکئ.
