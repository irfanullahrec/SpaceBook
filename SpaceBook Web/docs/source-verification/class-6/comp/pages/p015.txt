## 1.6.4 System Unit || 1.6.4 سسٹم یونٹ || 1.6.4 سیسټم یونټ
p The system unit is the case that contains all the electronic components of a computer system like mother board, power supply, RAM, CPU (micro processor), Hard Disk Drive, Optical Drive etc. || سسٹم یونٹ وہ ڈبا (کیس) ہے جس میں کمپیوٹر سسٹم کے تمام برقی اجزا ہوتے ہیں، جیسے مدر بورڈ، پاور سپلائی، RAM، CPU (مائیکروپروسیسر)، ہارڈ ڈسک ڈرائیو، آپٹیکل ڈرائیو وغیرہ۔ || سیسټم یونټ هغه بکس دی چې د کمپیوټر ټولې برېښنايي برخې لري، لکه مادربورډ، د برېښنا رسونکی، RAM، CPU (مایکروپروسیسر)، هارډ ډیسک او نوري ډرایو.
svg System unit: inside are the Power Supply, Fan, ROM chip and RAM module; the front panel has the Power switch, Restart switch, USB Port, Speaker Port and Microphone Port. || سسٹم یونٹ: اندر پاور سپلائی، پنکھا، ROM چپ اور RAM؛ سامنے پاور سوئچ، ری اسٹارٹ سوئچ، USB پورٹ، اسپیکر پورٹ اور مائیکروفون پورٹ۔ || سیسټم یونټ: دننه د برېښنا رسونکی، پکه، ROM او RAM؛ مخې ته د برېښنا تڼۍ، بیا پیلولو تڼۍ، USB، سپیکر او مایکروفون پورټونه.
