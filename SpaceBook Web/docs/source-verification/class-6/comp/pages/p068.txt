# 4.1 PROGRAM AND ALGORITHM || 4.1 پروگرام اور الگورتھم || 4.1 پروګرام او الګوریتم
## 4.1.1 Computer Program || 4.1.1 کمپیوٹر پروگرام || 4.1.1 کمپیوټري پروګرام
p A computer program is a sequence of instructions that are to be executed by a computer. The program interacts with the user for some input, processes according to the instructions and produces result. The simple program requires one algorithm to build but large programs can contain multiple algorithms for various tasks in a single program. A programming language, like a natural language that humans use, consists of a set of keywords and grammatical structure which is understandable to computers. Programming languages are used to solve our problems. || کمپیوٹر پروگرام ہدایات کا ایک سلسلہ ہے جن پر کمپیوٹر عمل کرتا ہے۔ پروگرام صارف سے کچھ ان پٹ لیتا ہے، ہدایات کے مطابق عمل کرتا ہے اور نتیجہ دیتا ہے۔ سادہ پروگرام بنانے کے لیے ایک الگورتھم کافی ہے، لیکن بڑے پروگراموں میں مختلف کاموں کے لیے کئی الگورتھم ہو سکتے ہیں۔ پروگرامنگ زبان، انسانوں کی قدرتی زبان کی طرح، کلیدی الفاظ اور گرامر کے ڈھانچے پر مشتمل ہوتی ہے جسے کمپیوٹر سمجھتا ہے۔ پروگرامنگ زبانیں ہمارے مسائل حل کرنے میں استعمال ہوتی ہیں۔ || کمپیوټري پروګرام د لارښوونو لړۍ ده چې کمپیوټر یې اجرا کوي. پروګرام له کارن ننوت اخلي، د لارښوونو سره سم یې پروسس کوي او پایله ورکوي. ساده پروګرام یو الګوریتم غواړي، خو لوی پروګرامونه څو الګوریتمونه لري. پروګرامي ژبه، د انسان د طبیعي ژبې په څېر، کلیدي ټکي او ګرامري جوړښت لري چې کمپیوټر پرې پوهېږي. پروګرامي ژبې زموږ ستونزې حلوي.

## 4.1.2 Difference between Algorithm and Program || 4.1.2 الگورتھم اور پروگرام میں فرق || 4.1.2 د الګوریتم او پروګرام توپیر
p The basic difference is that an algorithm is a step-by-step problem solving strategy that provides recommendations that are to be taken care of while developing a program for computer. A program on the other hand is a set of instructions that when executed sequentially on a computer is the best possible way to implement that algorithm. Moreover, an algorithm is created at design time whereas programs are written at implementation time. || بنیادی فرق یہ ہے کہ الگورتھم مسئلہ حل کرنے کی مرحلہ وار حکمتِ عملی ہے جو کمپیوٹر کا پروگرام بناتے وقت ملحوظ رکھنے والی سفارشات دیتی ہے۔ دوسری طرف پروگرام ہدایات کا مجموعہ ہے جو کمپیوٹر پر ترتیب سے چلایا جائے تو اس الگورتھم کو نافذ کرنے کا بہترین طریقہ ہے۔ مزید یہ کہ الگورتھم ڈیزائن کے وقت بنایا جاتا ہے جبکہ پروگرام نفاذ کے وقت لکھے جاتے ہیں۔ || اساسي توپیر دا دی چې الګوریتم د ستونزې د حل ګام په ګام ستراتیژي ده چې د پروګرام جوړولو پر مهال لارښوونې ورکوي؛ پروګرام د لارښوونو ټولګه ده چې په کمپیوټر په ترتیب اجرا شي او هغه الګوریتم پلي کړي. الګوریتم د ډیزاین پر مهال جوړېږي، پروګرام د پلي کولو پر مهال لیکل کېږي.

p **Computer code** is a set of statements that is developed in any programming language according to the grammar/syntax. **Keyword** is an important expression/notion in a programming language that has some specific meaning. || **کمپیوٹر کوڈ** بیانات کا مجموعہ ہے جو کسی پروگرامنگ زبان میں اس کی گرامر/سنٹیکس کے مطابق لکھا جاتا ہے۔ **کی ورڈ** پروگرامنگ زبان کا اہم لفظ/تصور ہے جس کا ایک خاص مطلب ہوتا ہے۔ || **کمپیوټري کوډ** د بیانونو ټولګه ده چې په یوه پروګرامي ژبه د هغې د ګرامر/سنټکس سره سم لیکل کېږي. **کلیدي ټکی** په پروګرامي ژبه کې ځانګړې مانا لري.

## 4.1.3 Convert Algorithm into Program || 4.1.3 الگورتھم کو پروگرام میں بدلنا || 4.1.3 الګوریتم په پروګرام اړول
