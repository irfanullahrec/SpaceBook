box key | Key Fact || اہم حقیقت || مهم حقیقت
p Using unitary method, we find out the value of one unit and use it to find the value of multiple units. || اکائی کے طریقے میں ہم ایک اکائی کی قیمت معلوم کرتے ہیں اور اسے کئی اکائیوں کی قیمت معلوم کرنے کے لیے استعمال کرتے ہیں۔ || د واحد په طریقه کې د یوه واحد ارزښت معلوموو او د ډېرو واحدونو د ارزښت معلومولو لپاره یې کاروو.
endbox
