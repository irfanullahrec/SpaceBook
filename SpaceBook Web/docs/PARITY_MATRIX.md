# Web / App parity matrix

Generated from `docs/parity.json` by `node tools/parity/check.js --write-matrix`. **Do not edit this file**: change the JSON, run the command, commit both.
The product is one: SpaceBook Web (`SpaceBook Web/`) and SpaceBook App (`SpaceBook App/`, its own repository) have the same functions, the same data and one database (`tafseelk_spacebook`, reached only through the PHP API); only the user interface differs. Rules: `D:\SpaceBook\CLAUDE.md`.

Status: **same** (one implementation or two with identical data and rules) · **platform-specific** (each platform does it its own way for a reason of the platform, the counterpart is named) · **web-only / app-only / partial / blocked** (open: each carries a written reason and what is planned) · **retired** (was there, is not reachable or wanted any more).

## The owner's sync switch

One owner switch, published by the server (flags.syncV2 in api/auth.php?action=me and api/v2/entitlements.php, from api/lib/flags.php; off until api/flags.local.php says true or the default is changed and pushed).
